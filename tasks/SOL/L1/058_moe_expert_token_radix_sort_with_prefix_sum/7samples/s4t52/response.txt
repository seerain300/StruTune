- The previous attempts failed to match the original outputs exactly and also had issues with Triton kernel invocation. The main risk areas were:

  - In-kernel scan correctness: Triton does not provide tl.cumsum; a manual inclusive scan must be carefully implemented.
- Strategy to ensure correctness while complying with Triton-only:

    - Pass 2: compute global offset per bin by summing first_greater across all bins, writing offsets to out.

import triton.language as tl


@triton.jit
def histogram_kernel(flat_ptr, counts_ptr, N: tl.int32, num_experts: tl.int32):
    """
    Compute histogram of flattened values (int32) into counts_ptr (length num_experts).
    counts_ptr[i] = number of occurrences of value == i in flat_ptr[:N].
    """
    # One program instance processes the entire flat vector; atomic add per element.
    i = 0
    while i < N:
        val = tl.load(flat_ptr + i)
        # Ensure val is within [0, num_experts-1]. Triton int32 atomic add is supported.
        tl.atomic_add(counts_ptr + val, 1)
        i += 1
