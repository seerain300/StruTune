Analysis and plan
- Original computation:
  - Concatenate along the sequence dimension: concatenated = cat([encoder_hidden_states, hidden_states], dim=1), shape [B, T + I, H].
  - Linear projection: processed = concatenated @ process_weight.T, where process_weight has shape [H, H] (no bias).
  - Split back into two streams: processed[:, :T, :] and processed[:, T:, :].
- Robust Triton strategy:
  - Avoid materializing the concatenation. Compute the linear projection directly in Triton by choosing the source per output token: if t < T, read from encoder; else read from image at t - T.
  - Implement one Triton kernel that:
    - Iterates over the output tokens T+I in chunks of BLOCK_T (e.g., 128).
    - For each chunk, launches a 2D grid of programs over (batch, token in the chunk). Each program computes the entire output vector for a specific (b, t) by looping over the hidden dimension H in tiles of BLOCK_H and accumulating in float32. This avoids complex 3D broadcasting and reduces masking complexity.
  - This design:
    - Keeps loads/stores simple: tl.load/tl.store on 1D vectors for inputs and 2D tiles for weights.
    - Uses explicit masks for partial tiles along H and tokens.
    - Computes the full processed tensor [B, T+I, H] and then slices.

Correctness safeguards
- Ensure inputs and weights are contiguous before launching Triton.
- Use float32 accumulation for numerical stability.
- Use explicit grid and meta-parameters (BLOCK_T, BLOCK_H) and masks to avoid out-of-bounds memory access.

def triton_concat_linear(image: torch.Tensor, encoder: torch.Tensor, weight: torch.Tensor) -> torch.Tensor:
    # Ensure inputs are contiguous
    image = image.contiguous()
    encoder = encoder.contiguous()
    weight = weight.contiguous()

    B = image.shape[0]
    I = image.shape[1]
    T = encoder.shape[1]
    H = image.shape[2]
    total_tokens = T + I

    # Output tensor: float32 accumulator, then cast back to input dtype if needed
    out = torch.empty((B, total_tokens, H), device=image.device, dtype=torch.float32)

    # Strides (in elements)
    image_stride_b = image.stride(0)
    image_stride_i = image.stride(1)
    image_stride_h = image.stride(2)

    encoder_stride_b = encoder.stride(0)
    encoder_stride_t = encoder.stride(1)
    encoder_stride_h = encoder.stride(2)

    weight_stride_w = weight.stride(0)  # along H (rows)
    weight_stride_k = weight.stride(1)  # along H (cols), usually 1

    out_stride_b = out.stride(0)
    out_stride_t = out.stride(1)
    out_stride_h = out.stride(2)

    # Launch grid: one program per (batch, token)
    grid = (B, total_tokens)

    # Choose BLOCK_K=H to cover entire hidden dim in one iteration
    BLOCK_K = H

    concat_linear_single_token_kernel[grid](
        image, encoder, weight, out,
        B, I, T, H,
        image_stride_b, image_stride_i, image_stride_h,
        encoder_stride_b, encoder_stride_t, encoder_stride_h,
        weight_stride_w, weight_stride_k,
        out_stride_b, out_stride_t, out_stride_h,
        BLOCK_K=BLOCK_K,
        num_warps=4, num_stages=2,
    )

    return out
