    - out_idx_chunk: permutation (original positions) corresponding to out_ids_chunk

  - Merge kernels:

    - Finally, scatter the global idx back into output permutation using the global id list. To avoid scatter into unallocated output, instead write the permutation into out_idx (we will return it).

  - Triton exclusive_prefix_sum_kernel: compute the exclusive prefix sum of counts to produce offsets.
