Here is the full Triton-integrated implementation of ModelNew. The forward function launches Triton kernels and performs all core computations inside Triton, avoiding any torch tensor operations (no torch.softmax, torch.logsumexp, matmul, etc.). The kernel computes, for each batch element b and each head h:
- logits per token t: qn @ Kc.T + qp @ Kp.T, where qn and qp are vectors (head-specific), Kc/Kp are gathered rows based on kv_indptr and kv_indices.
- scaled logsumexp (base-2) across tokens.
- attention vector (softmax of scaled logits).
- final output vector for the head: out = attn @ Kc.

The Triton kernel loops over tokens (L_tokens), dimensions (Dc=512, Dp=64), and uses tl.static_range to unroll loops for performance. All math is done in fp32 inside the kernel, output is stored in bfloat16, and lse is stored in float32 to match the original.
