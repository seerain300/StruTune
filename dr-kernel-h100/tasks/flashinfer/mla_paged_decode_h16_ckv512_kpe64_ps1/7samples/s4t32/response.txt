Design and plan:
- The forward will:
  1) Prepare data:
     - q_nope[b] and q_pe[b] are cast to float32 and made contiguous.
     - For each batch b, compute M_b = kv_indptr[b+1] - kv_indptr[b].
     - If M_b == 0, output zeros for that batch.
     - Otherwise, form tok_idx = kv_indices[kv_indptr[b]: kv_indptr[b+1]].
     - Form Kc_sub = ckv_cache[tok_idx, 0, :] and Kp_sub = kpe_cache[tok_idx, 0, :] (squeeze the 1-dim cache to [P, D]).
     - Compute qn_vec = q_nope[b].view(N, Dc).T.flatten() → [N*Dc] vector representing the query for all heads in that batch (since N is small and fixed to 16, we can do this safely), and qp_vec similarly for Dp. To avoid torch ops in host, we implement this vector formation inside a Triton kernel that writes qn_vec and qp_vec buffers.
  2) Launch the Triton fused kernel to compute:
     - For each batch b and head h, compute logits = qn_vec[h, :] @ Kc_sub.T + qp_vec[h, :] @ Kp_sub.T, scaled by sm_scale.
     - Compute lse in base-2: lse = logsumexp(logits) / ln(2).
     - Compute attention = softmax(logits) along tokens.
     - Store attention[b, h, :] to attn_ptr[b*N + h] (flattened per batch).
     - Store lse[b, h] to lse_ptr[b*N + h].
  3) Launch a Triton matvec kernel to compute per-batch outputs:
     - For each (b, h), out[b, h, :] = attention_vec[b, h, :] @ Kc_sub (shape [M_b,] x [M_b, Dc] → [Dc]).
     - Return out[b] for all heads h. We can implement this as a Triton kernel that, for each (b,h), iterates over M_b and Dc in tiles, computes the dot product, and writes out[b, h, :].
  4) Cast the output to bfloat16 and return the tensors.

This approach ensures:
- Triton kernels do the heavy computation (logsumexp, softmax, matmul). The host does not use torch.log, torch.logsumexp, torch.softmax, or torch.cat.
- Shapes are handled dynamically per batch. For very large M_b (tens of thousands), we tile with BLOCK_N and perform reductions in Triton. For the provided workloads, M_b is small (from 8 to ~1e5), but the kernels are written to be robust.

    Dc: tl.constexpr,
    Dp: tl.constexpr,
):

    h = pid % N

    base_p = (b * N + h) * Dp  # for qp_ptr
