Thanks for the detailed error reports. I’ll address the root causes and ensure the implementation is fully Triton-based, with correct shape handling and no host-side torch ops.

Diagnosis
- The Triton compilation errors point to invalid vector operations on scalars. I attempted to use running_max and running_sum as vectors and applied vectorized ops like tl.maximum and tl.exp on a scalar logits. Triton requires vector operations to be applied elementwise to vectors, not mixed with scalars in those ways.
- Also, earlier we had shape mismatches because k_cache/v_cache can be [num_pages, num_kv_heads, head_dim] (no size-1 axis at dim=1). I must not rely on a size-1 at axis 1. The kernel must compute addresses based on provided strides and shapes.

Correctness strategy
- Avoid all host-side tensor operations: no .log(), .stack(), .item(), and no slicing that assumes a specific axis dimension.
- Compute everything in Triton:
  - One Triton program per (b, h). Grid = (B, num_qo_heads).
  - First pass over tokens:
    - For each token t: load q_vec[h, :], k_vec from k_cache[token_index, kv_head, :], compute logits = dot(q_vec, k_vec).
    - scale = logits * sm_scale, sm_scale = 1/sqrt(128). Compute max_scale = max(max_scale, scale), sum_exp = sum_exp * exp(old_max - new_max) + exp(scale - new_max).
    - After loop, lse = log(sum_exp) + max_scale, then divide by ln(2) via multiply with LOG2_INV.
  - Second pass over tokens:
    - Recompute scale, compute attn = exp(scale - lse), and accumulate output vector: out_vec += attn * v_vec[token_index, kv_head, :].
- Addressing for k_cache/v_cache:
  - Use element-wise addressing with provided strides. We cannot assume any specific dim=1 size. We pass k_cache and v_cache tensors and use their strides to compute offsets. Triton will handle loading 128-dim vectors from these tensors.

Performance notes
- Each program handles a single (b, h) and loops over tokens. This is fine given typical num_tokens sizes in the workloads. All computations are fused in Triton without intermediate host tensors.

Final code (ModelNew using Triton, no torch ops in forward except dtype casts and allocations)

import torch
import math
import triton
import triton.language as tl


@triton.jit
def softmax_attention_bh(
    q_ptr,            # *fp32, shape [B, num_qo_heads, head_dim]
    k_ptr,            # *fp32, shape [num_pages, num_kv_heads, head_dim]
    v_ptr,            # *fp32, shape [num_pages, num_kv_heads, head_dim]
    out_ptr,          # *fp32, shape [B, num_qo_heads, head_dim] output
    lse_ptr,          # *fp32, shape [B, num_qo_heads]
    # runtime scalars
    B, H,             # batch_size, num_qo_heads
    num_tokens,       # int32
    head_dim,         # int32
    kv_head,          # int32
    start_idx,        # int32: kv_indptr[b]
    kv_indices_ptr,   # *int32, shape [num_tokens]
    sm_scale,         # fp32
    LOG2_INV,         # fp32
    stride_q_b, stride_q_h, stride_q_d,   # strides for q
    stride_k_p, stride_k_h, stride_k_d,   # strides for k
    stride_v_p, stride_v_h, stride_v_d,   # strides for v
    BLOCK_SIZE: tl.constexpr = 128,
):
    # This program computes for a single (b, h). We get b from out_ptr/out_lse_ptr allocation, h is passed as an argument?
    # To decode program_id(1) -> h, we need to know H; Triton provides program_id(0), not program_id(1). So launch grid=(B, H),
    # and pass b as program_id(0). Inside kernel, use pid_b = program_id(0) and h = program_id(1).
    pid_b = program_id(0)
    h = program_id(1)

    # Base offset for q[h, :] and output[b, h, :]
    q_base = pid_b * stride_q_b + h * stride_q_h
    out_base = pid_b * (H * head_dim) + h * head_dim  # out is [B, H, D] contiguous
    lse_off = pid_b * H + h

    # Initialize running max and sum for logsumexp
    # We use fp32 accumulators
    max_scale = -float('inf')
    sum_exp = 0.0

    # First pass: compute lse over scaled logits
    # Loop over tokens
    for t in range(0, num_tokens):
        idx = tl.load(kv_indices_ptr + t)  # int32 index
        # Load q_vec[h, :]
        q_vec = tl.load(q_ptr + q_base + tl.arange(0, BLOCK_SIZE), mask=tl.arange(0, BLOCK_SIZE) < head_dim, other=0.0)
        # Load k_vec from k_cache[idx, kv_head, :]
        k_base = idx * stride_k_p + kv_head * stride_k_h
        k_vec = tl.load(k_ptr + k_base + tl.arange(0, BLOCK_SIZE), mask=tl.arange(0, BLOCK_SIZE) < head_dim, other=0.0)
        # Dot product: sum(q * k)
        logits = tl.sum(q_vec * k_vec, axis=0)  # scalar
        scaled = logits * sm_scale  # scalar
        # Numerically stable update
        new_max = tl.maximum(max_scale, scaled)
        # rescale previous sum_exp to new_max if max changed
        if max_scale < new_max:
            sum_exp = sum_exp * tl.exp(max_scale - new_max)
        sum_exp = sum_exp + tl.exp(scaled - new_max)
        max_scale = new_max

    # Compute lse and store
    lse_val = tl.log(sum_exp) + max_scale  # fp32
    # Divide by ln(2): lse = lse / log(2)
    lse_val = lse_val * LOG2_INV
    tl.store(lse_ptr + lse_off, lse_val)

    # Second pass: compute output vector
    for t in range(0, num_tokens):
        idx = tl.load(kv_indices_ptr + t)
        q_vec = tl.load(q_ptr + q_base + tl.arange(0, BLOCK_SIZE), mask=tl.arange(0, BLOCK_SIZE) < head_dim, other=0.0)
        k_base = idx * stride_k_p + kv_head * stride_k_h
        k_vec = tl.load(k_ptr + k_base + tl.arange(0, BLOCK_SIZE), mask=tl.arange(0, BLOCK_SIZE) < head_dim, other=0.0)
        logits = tl.sum(q_vec * k_vec, axis=0)  # scalar
        scaled = logits * sm_scale
        attn = tl.exp(scaled - lse_val)  # scalar
        v_base = idx * stride_v_p + kv_head * stride_v_h
        v_vec = tl.load(v_ptr + v_base + tl.arange(0, BLOCK_SIZE), mask=tl.arange(0, BLOCK_SIZE) < head_dim, other=0.0)
        out_vec = attn * v_vec  # elementwise
        # Accumulate into out[b, h, :]
        out_base_ptr = out_ptr + out_base + tl.arange(0, BLOCK_SIZE)
        # out is [B, H, D] contiguous, so stride along D is 1; out_base + d
        tl.store(out_base_ptr, out_vec, mask=tl.arange(0, BLOCK_SIZE) < head_dim)

    lse_val = tl.log(sum_exp) + max_scale
    lse_val = lse_val * LOG2_INV
    tl.store(lse_ptr + lse_off, lse_val)

    # Second pass: compute output
    for t in range(0, num_tokens):
        idx = tl.load(kv_indices_ptr + t)
        q_vec = tl.load(q_ptr + q_base + tl.arange(0, BLOCK_SIZE), mask=tl.arange(0, BLOCK_SIZE) < head_dim, other=0.0)

        logits = tl.sum(q_vec * k_vec, axis=0)
        scaled = logits * sm_scale
        attn = tl.exp(scaled - lse_val)
        v_base = idx * stride_v_p + kv_head * stride_v_h
        v_vec = tl.load(v_ptr + v_base + tl.arange(0, BLOCK_SIZE), mask=tl.arange(0, BLOCK_SIZE) < head_dim, other=0.0)
        out_vec = attn * v_vec
        out_base_ptr = out_ptr + out_base + tl.arange(0, BLOCK_SIZE)
        tl.store(out_base_ptr, out_vec, mask=tl.arange(0, BLOCK_SIZE) < head_dim)
