Analysis, root cause, and optimization plan

1) What the original PyTorch code does
- Inputs:
  - q: [B, Nq, D], Nq=32, D=128 (bfloat16).
  - k_cache, v_cache: [Np, 1, Nkv, D], Nkv=8, D=128; squeezed to [Np, Nkv, D] and cast to float32 for compute.
  - kv_indptr: [B+1], int32, prefix sum of token counts per batch; start = kv_indptr[b], end = kv_indptr[b+1], T = end - start.
  - kv_indices: [T_total], int32, indices into k_cache/v_cache.
  - sm_scale = 1.0 / sqrt(128) (float32 scalar).

- For each batch b and each query head h:
  - Compute kv_head = h // (Nq // Nkv) = h // 4 (GQA).
  - For each token i in [start, end):
    - idx = kv_indices[start + i]
    - k_i = k_cache[idx, kv_head], v_i = v_cache[idx, kv_head], vectors of length D.
    - attn_i = dot(q[b, h], k_i)
    - scaled = attn_i * sm_scale
  - Compute lse for this (b, h): m = max(scaled), sum_exp = sum(exp(scaled - m)), lse = log(sum_exp) + m, then divide by log(2).
  - Compute softmax: softmax[i] = exp(scaled[i] - m) / sum_exp.
  - Output vector: out[b, h, :] = softmax @ v_selected (sum over i of softmax[i] * v_i[:]).
  - Store output as bfloat16 and lse as float32.

2) Why previous submissions failed
- The evaluation logs show assertions like “head_dim mismatch” and earlier “too many values to unpack (expected 3)”. These are host-side issues, not Triton kernel issues.
  - The “too many values to unpack” error was due to accessing .shape on tensors before ensuring contiguity or expecting exactly 3 dims; some environments may expose more dims or non-contiguous views. We should only access .shape on known-good tensors and pass shapes to Triton as constexpr, not unpack from tensors.
  - The “head_dim mismatch” error indicates that in some configurations, the code attempted to assert head_dim values that didn’t match the actual input. To make this robust across the provided workload variations, we should not hardcode assertions on head_dim, num_qo_heads, num_kv_heads. Instead, derive them from the input q and k_cache shapes in the host code and pass them to Triton as compile-time constants.

3) Triton design for correctness and robustness
- We will implement two Triton kernels:
  a) lse_kernel: one Triton program per (b, h) that loops over tokens, computes m and sum_exp, and writes lse[b, h] divided by log(2).
  b) output_kernel: one Triton program per (b, h) that recomputes m and sum_exp, computes softmax, and produces the output vector out[b, h, :] by looping tokens and accumulating soft_i * v_i[j]. This avoids any reliance on host-side torch ops and keeps numeric work in Triton.

- Careful host-side handling:
  - Ensure all tensors are contiguous and on CUDA.
  - Compute shapes from q and k_cache (after .contiguous()).
  - Pass B, Nq, Nkv, D, gqa_ratio (Nq//Nkv) as tl.constexpr to Triton kernels. Triton requires compile-time constants for strides and grid sizing; we’ll pass strides as int32.
  - Avoid any torch matmul/softmax on host; purely data movement and kernel launches.

4) Performance considerations
- Parallelization: one program per (b, h) gives B*Nq programs. For typical B in {1, 16, 64}, this is enough. Each program performs a dynamic loop over tokens T. For large T, we could vectorize in chunks, but Triton’s while loops with scalar i are simple and correct. If further speed is needed after correctness is established, consider:
  - Chunked vectorized reduction for m and sum_exp (BLOCK_T loop with tl.arange).
  - Fusing kernels or caching m/sum_exp, but that requires inter-kernel communication and isn’t necessary for correctness.

import math
import torch
import triton
import triton.language as tl


@triton.jit
def lse_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    B: tl.constexpr,          # batch size
    Nq: tl.constexpr,         # num_qo_heads
    Nkv: tl.constexpr,        # num_kv_heads
    D: tl.constexpr,          # head_dim
    gqa_ratio: tl.constexpr,  # Nq // Nkv (4)
    stride_q_b, stride_q_h, stride_q_d,  # strides for q
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio  # GQA mapping

    # Load q[b, h] as float32
    q_base = q_ptr + b * stride_q_b + h * stride_q_h
    q_vec = tl.load(q_base + tl.arange(0, D) * stride_q_d).to(tl.float32)  # [D], f32

    # Token window [start, end)
    start = tl.load(indptr_ptr + b)         # int32
    end = tl.load(indptr_ptr + b + 1)      # int32
    T = end - start

    # Accumulate max and sum_exp for logsumexp
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)

    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_i = tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32)  # [D]
        attn = tl.sum(q_vec * k_i, axis=0)  # scalar
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        exp_term = tl.exp(scaled - m)
        sum_exp += exp_term
        i += 1

    # lse = log(sum_exp) + m; divide by log(2) to match original
    log2 = 0.6931471805599453
    lse_val = tl.log(sum_exp) + m
    tl.store(lse_ptr + b * Nq + h, lse_val / log2)


@triton.jit
def output_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    v_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    out_ptr,        # *bf16, [B, Nq, D]
    B: tl.constexpr,          # batch size
    Nq: tl.constexpr,         # num_qo_heads
    Nkv: tl.constexpr,        # num_kv_heads
    D: tl.constexpr,          # head_dim
    gqa_ratio: tl.constexpr,  # Nq // Nkv (4)
    stride_q_b, stride_q_h, stride_q_d,
    stride_k_p, stride_k_h, stride_k_d,
    stride_v_p, stride_v_h, stride_v_d,
    stride_out_b, stride_out_h, stride_out_d,
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio  # GQA mapping

    # Load q[b, h] vector of length D
    q_base = q_ptr + b * stride_q_b + h * stride_q_h
    q_vec = tl.load(q_base + tl.arange(0, D) * stride_q_d).to(tl.float32)  # [D], f32

    # Token window [start, end)
    start = tl.load(indptr_ptr + b)         # int32
    end = tl.load(indptr_ptr + b + 1)      # int32
    T = end - start

    # Recompute m and sum_exp
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)

    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_i = tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32)  # [D]
        attn = tl.sum(q_vec * k_i, axis=0)  # scalar
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        exp_term = tl.exp(scaled - m)
        sum_exp += exp_term
        i += 1

    # Output vector out[b, h, :]
    out_base = out_ptr + b * stride_out_b + h * stride_out_h
    j = 0
    while j < D:
        out_scalar = tl.zeros((), dtype=tl.float32)
        i = 0
        while i < T:
            idx = tl.load(indices_ptr + start + i).to(tl.int32)
            v_base = v_ptr + idx * (Nkv * D) + kv_head * D
            v_i = tl.load(v_base + tl.arange(0, D) * 1).to(tl.float32)  # [D]
            attn = tl.sum(q_vec * tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32), axis=0)  # scalar
            scaled = attn * sm_scale
            softmax_i = tl.exp(scaled - m) / sum_exp
            out_scalar += softmax_i * v_i[j]
            i += 1
        tl.store(out_base + j * stride_out_d, out_scalar.to(tl.bfloat16))
        j += 1


class ModelNew(torch.nn.Module):
    def forward(self, q, k_cache, v_cache, kv_indptr, kv_indices, sm_scale):
        # Ensure device and contiguity; do not rely on .shape until after .contiguous()
        device = q.device
        assert q.is_cuda and k_cache.is_cuda and v_cache.is_cuda and kv_indptr.is_cuda and kv_indices.is_cuda, "All tensors must be on CUDA"

        q = q.contiguous()
        k_cache = k_cache.contiguous()
        v_cache = v_cache.contiguous()
        kv_indptr = kv_indptr.contiguous()
        kv_indices = kv_indices.contiguous()

        # Derive shapes robustly from inputs
        B, Nq, D = q.shape
        Np, Nkv, _ = k_cache.shape  # Np is num_pages; original code uses squeeze(1), so it's [Np, Nkv, D]
        # For output tensor, we need head_dim D; assume D is consistent across k_cache and v_cache
        # Output: [B, Nq, D], lse: [B, Nq]
        output = torch.empty((B, Nq, D), dtype=torch.bfloat16, device=device)
        lse = torch.empty((B, Nq), dtype=torch.float32, device=device)

        # gqa_ratio = Nq // Nkv
        gqa_ratio = Nq // Nkv

        # Strides for Triton (as int32)
        stride_q_b = q.stride(0)
        stride_q_h = q.stride(1)
        stride_q_d = q.stride(2)
        stride_k_p = k_cache.stride(0)
        stride_k_h = k_cache.stride(1)
        stride_k_d = k_cache.stride(2)
        stride_v_p = v_cache.stride(0)
        stride_v_h = v_cache.stride(1)
        stride_v_d = v_cache.stride(2)
        stride_out_b = output.stride(0)
        stride_out_h = output.stride(1)
        stride_out_d = output.stride(2)

        # Launch Triton kernels: one program per (b, h)
        grid = (B * Nq,)

        # Kernel 1: compute lse
        lse_kernel[grid](
            q, k_cache, kv_indptr, kv_indices, sm_scale, lse,
            B, Nq, Nkv, D, gqa_ratio,
            stride_q_b, stride_q_h, stride_q_d,
            num_warps=4, num_stages=2,
        )

        # Kernel 2: compute output vectors
        output_kernel[grid](
            q, k_cache, v_cache, kv_indptr, kv_indices, sm_scale, lse, output,
            B, Nq, Nkv, D, gqa_ratio,
            stride_q_b, stride_q_h, stride_q_d,
            stride_k_p, stride_k_h, stride_k_d,
            stride_v_p, stride_v_h, stride_v_d,
            stride_out_b, stride_out_h, stride_out_d,
            num_warps=4, num_stages=2,
        )

        return output, lse

  - Hardcoding assertions like head_dim == 128 can fail when inputs vary. We must derive shapes from the actual inputs and pass them to Triton as compile-time constants.
- The core computation is:
  - For each batch b and query head h:
    - Compute tokens = kv_indices[kv_indptr[b]:kv_indptr[b+1]] with T = end - start.
    - For each token i: k_i, v_i selected via kv_head = h // (Nq // Nkv).
    - attn_i = dot(q[b, h], k_i), scaled = attn_i * sm_scale.
    - lse[b, h] = logsumexp(scaled) in base 2: log(sum_exp) + m, divide by log(2).
    - softmax[i] = exp(scaled[i] - m) / sum_exp.
    - out[b, h, :] = softmax @ v_selected (elementwise accumulation).
- Triton strategy:
  - Implement two Triton kernels:
    1) lse_kernel: one program per (b, h), loops over tokens, computes m and sum_exp, writes lse[b, h].
    2) output_kernel: one program per (b, h), recomputes m and sum_exp, computes softmax, and produces out[b, h, :] by looping tokens and accumulating soft_i * v_i[j].
  - Ensure q, k_cache, v_cache, kv_indptr, kv_indices are contiguous and on CUDA. Derive B, Nq, Nkv, D from inputs. Pass them as tl.constexpr to Triton. Use strides as int32.

import math
import torch
import triton
import triton.language as tl


@triton.jit
def lse_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    B: tl.constexpr,          # batch size
    Nq: tl.constexpr,         # num_qo_heads
    Nkv: tl.constexpr,        # num_kv_heads
    D: tl.constexpr,          # head_dim
    gqa_ratio: tl.constexpr,  # Nq // Nkv (4)
    stride_q_b, stride_q_h, stride_q_d,  # strides for q
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio  # GQA mapping

    # Load q[b, h] as float32
    q_base = q_ptr + b * stride_q_b + h * stride_q_h
    q_vec = tl.load(q_base + tl.arange(0, D) * stride_q_d).to(tl.float32)  # [D], f32

    # Token window [start, end)
    start = tl.load(indptr_ptr + b)         # int32
    end = tl.load(indptr_ptr + b + 1)      # int32
    T = end - start

    # Accumulate max and sum_exp for logsumexp
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)

    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_i = tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32)  # [D]
        attn = tl.sum(q_vec * k_i, axis=0)  # scalar
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        exp_term = tl.exp(scaled - m)
        sum_exp += exp_term
        i += 1

    # lse = log(sum_exp) + m; divide by log(2) to match original
    log2 = 0.6931471805599453
    lse_val = tl.log(sum_exp) + m
    tl.store(lse_ptr + b * Nq + h, lse_val / log2)
