        kv_end = tl.load(kv_indptr_ptr + b + 1)     # i32
        num_tokens = kv_end - kv_start              # i32 scalar

            logits = tl.zeros((), dtype=tl.float32)

        tl.store(lse_ptr + b * num_qo_heads + h, lse_scaled)

Summary of the original logic
- Inputs:
  - q: [B, num_qo_heads, HEAD_DIM], with num_qo_heads=32, HEAD_DIM=128
  - k_cache: [num_pages, 1, num_kv_heads, HEAD_DIM], num_kv_heads=8
  - v_cache: [num_pages, 1, num_kv_heads, HEAD_DIM]
  - kv_indptr: [B+1], int32, with kv_indptr[0]=0 and kv_indptr[B]=total_tokens
  - kv_indices: not used in the original computation (the code asserts len_indptr==batch_size+1 and num_kv_indices == kv_indptr[-1].item(), but the run does not use kv_indices)
  - sm_scale: float32, usually 1/sqrt(HEAD_DIM)
- GQA mapping: num_qo_heads // num_kv_heads = 4. For each query head h, the corresponding KV head is kv_head = h // 4.
- Per (b, h):
  - num_tokens = kv_indptr[b+1] - kv_indptr[b]
  - For each token t in [0, num_tokens):
    - idx = t + kv_indptr[b] (this is consistent with the original, since the total_tokens is the sum of per-batch ranges and kv_indices isn’t used).
    - k_t = k_cache[idx, 0, kv_head, :], v_t = v_cache[idx, 0, kv_head, :]
    - logits = q[b, h] · k_t
    - scaled = logits * sm_scale
    - Maintain lse = logsumexp(scaled) and accumulate out_vec += exp(scaled - lse) * v_t
  - Store out_vec to output[b, h] (bfloat16) and lse / ln(2) to lse[b, h].

Triton kernel design
- One Triton program per (b, h): grid size = (B * num_qo_heads,).
- Inside the program:
  - Load q[b, h] as float32.
  - Compute num_tokens from kv_indptr[b] and kv_indptr[b+1].
  - Iterate t in [0, num_tokens):
    - idx = kv_indptr[b] + t
    - kv_head = h // 4 (GQA).
    - Compute base linear offset for k_ptr/v_ptr: base = idx * (num_kv_heads * HEAD_DIM) + kv_head * HEAD_DIM. This linearizes the cache layout [num_pages, num_kv_heads, HEAD_DIM] as [num_pages*num_kv_heads, HEAD_DIM].
    - Load k_t and v_t vectors of length HEAD_DIM (bf16/f16). Cast to float32 for compute.
    - Compute dot q_vec · k_t by looping over HEAD_DIM (128).
    - scaled = logits * sm_scale.
    - Update lse and accumulation vector using a numerically stable logsumexp: maintain lse and acc where acc = sum(exp(scaled - lse)). For each new s:
      - If lse == -inf: lse = s; acc = 1.
      - Else: m = max(lse, s); new_lse = m + log(exp(lse - m) + exp(s - m)); acc = acc*exp(lse - new_lse) + exp(s - new_lse); lse = new_lse.
    - out_vec += exp(s - lse) * v_t.
  - Store out_vec (float32) to output and lse / ln(2) to lse.

Forward
- Ensure inputs are on CUDA and contiguous.
- Allocate output (float32) and lse (float32).
- Launch the Triton kernel with grid = (B * num_qo_heads,).
- Cast output to bfloat16 to match original.
