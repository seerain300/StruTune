Thanks for the detailed error logs. The previous submissions hit Triton compilation/runtime issues primarily due to:
- Using dynamic while loops inside Triton kernels for token iteration. Triton supports static control flow and vectorization better; runtime while-loops are error-prone.
- Complex indexing and mask usage for scalar loads and mixed dtypes, which led to type inference and compilation problems.
- Not properly structuring the grid and handling H as a separate grid dimension. Triton requires compile-time-like behavior for indexing within kernels; using runtime variables in intricate pointer arithmetic inside the kernel can cause compilation failures.

Diagnosis
- The original PyTorch run function performs per-(b, h) attention over a set of tokens selected by kv_indptr and kv_indices. It assumes k_cache and v_cache are squeezed to [N, D] (dim 1 removed) and works for any P (num_pages), but the provided evaluation varies P across workloads. The code uses kv_indptr[b:b+1] to define a range [start, end) and then uses kv_indices[start:start+num_tokens].
- We need to implement the same logic in Triton without relying on unsupported dynamic loops and with robust indexing. The key is:
  - For each (b, h), compute num_tokens = kv_indptr[b+1] - kv_indptr[b].
  - For t in 0..num_tokens-1, tok_idx = kv_indices[start + t]; then compute logits_scaled[h, t] = dot(q[b, h, :], k_cache.squeeze(1)[kvhead, tok_idx, :]) * sm_scale.
  - lse[b, h] = logsumexp(logits_scaled, axis=0) / log(2.0).
  - Output[b, h, :] = sum_t softmax(logits_scaled)[t] * v_cache.squeeze(1)[kvhead, tok_idx, :].

Plan for a robust Triton implementation
- Avoid dynamic while-loops; instead, tile tokens with a fixed BLOCK_T and use static for-loops. We will set BLOCK_T = 128 (matches head_dim D=128 in the given setup; masks handle smaller num_tokens).
- Launch grid over (B, H). Each Triton program computes the LSE and the output for one (b, h) pair. Inside the kernel, we iterate over tokens in chunks of BLOCK_T:
  - Build k_chunk [BLOCK_T, D] and v_chunk [BLOCK_T, D] for those token indices and kv_head = h // gqa_ratio (GQA mapping).
  - Compute q_vec = q[b, h, :] and q_dot_k_chunk = q_vec · k_chunk per chunk, scaled by sm_scale.
  - Track max over chunks for numerical stability and accumulate sum_exp per chunk. After the first pass, compute lse.
  - Second pass: recompute attn per chunk and accumulate output as acc += sum_t attn[t] * v_chunk[t, :].
- Use masks to handle cases where t_idx >= num_tokens, so out-of-range elements contribute zero.
- Ensure q, k_ptr, v_ptr are in float32 inside the kernel; output can be bfloat16.

This approach avoids dynamic loops, keeps indexing simple, and should compile reliably. It also supports arbitrary num_tokens up to BLOCK_T via chunking and masking.

```python
import math
import torch
import triton
import triton.language as tl


@triton.jit
def gqa_attention_kernel_bh(
    q_ptr,          # *bfloat16, shape [B, H, D], contiguous
    k_ptr,          # *float32,  shape [N, D], contiguous (k_cache.squeeze(1).to(float32))
    v_ptr,          # *float32,  shape [N, D], contiguous (v_cache.squeeze(1).to(float32))
    kv_indptr_ptr,  # *int32,    shape [B+1]
    kv_indices_ptr, # *int32,    shape [num_kv_indices]
    out_ptr,        # *bfloat16, shape [B, H, D]
    lse_ptr,        # *float32,  shape [B, H], initialized to -inf
    sm_scale,       # float32 scalar
    B: tl.constexpr,          # batch size
    H: tl.constexpr,          # num query heads
    D: tl.constexpr,          # head dim (e.g., 128)
    N: tl.constexpr,          # num kv heads (e.g., 8)
    gqa_ratio: tl.constexpr,  # H // N (e.g., 4)
    BLOCK_T: tl.constexpr,    # token chunk size (e.g., 128)
):
    # Each program handles one (b, h) pair
    b = tl.program_id(0)
    h = tl.program_id(1)

    # GQA mapping: each query head h uses KV head kvh = h // gqa_ratio
    kvh = h // gqa_ratio

    # Read the token range for this batch
    start = tl.load(kv_indptr_ptr + b).to(tl.int32)
    end = tl.load(kv_indptr_ptr + b + 1).to(tl.int32)
    num_tokens = end - start  # number of tokens for this batch element

    # Prepare output accumulator
    # We'll accumulate in float32 and cast to bfloat16 at the end.
    acc = tl.zeros((D,), dtype=tl.float32)

    # First pass: compute max over tokens for numerical stability and sum of exp
    max_logit = -float("inf")
    sum_exp = 0.0

    for t_off in range(0, BLOCK_T):
        t = start + t_off
        # Mask for valid tokens
        valid = t < num_tokens

        # Load token index
        tok_idx = tl.load(kv_indices_ptr + t, mask=valid, other=0).to(tl.int32)

        # Load q vector for this (b, h): q layout [B, H, D] contiguous
        # offset = b*(H*D) + h*D
        q_off = b * (H * D) + h * D
        q_vec = tl.load(q_ptr + q_off, mask=valid, other=0.0).to(tl.float32)  # [D]

        # Load k_chunk and compute dot: k_ptr[kvh, tok_idx, :] -> k_ptr[kvh*D + tok_idx*D + offs]
        k_off = kvh * D + tok_idx * D
        k_chunk = tl.load(k_ptr + k_off + tl.arange(0, D), mask=valid, other=0.0)  # [D]
        # q·k
        dot_qk = tl.sum(q_vec * k_chunk, axis=0)  # scalar

        # Scale
        logits_scaled = dot_qk * sm_scale

        # Update max and sum_exp (ignore invalid tokens by setting logits_scaled = -inf)
        # If invalid, set logits_scaled to -inf so it doesn't affect max/sum
        logits_scaled = tl.where(valid, logits_scaled, -float("inf"))

        # Maintain running max and sum_exp across chunks
        max_logit = tl.maximum(max_logit, logits_scaled)
        sum_exp = tl.where(valid, sum_exp + tl.exp(logits_scaled - max_logit), sum_exp)

    # Compute lse[b, h] = logsumexp(logits_scaled, axis=0) / log(2.0)
    # lse_ptr layout: lse[b*H + h]
    lse_off = b * H + h
    lse_val = max_logit + tl.log(sum_exp) / tl.log(2.0)
    tl.store(lse_ptr + lse_off, lse_val)

    # Second pass: compute attn for each token chunk and accumulate output
    for t_off in range(0, BLOCK_T):
        t = start + t_off
        valid = t < num_tokens

        tok_idx = tl.load(kv_indices_ptr + t, mask=valid, other=0).to(tl.int32)

        q_off = b * (H * D) + h * D
        q_vec = tl.load(q_ptr + q_off, mask=valid, other=0.0).to(tl.float32)

        k_off = kvh * D + tok_idx * D
        k_chunk = tl.load(k_ptr + k_off + tl.arange(0, D), mask=valid, other=0.0)  # [D]

        dot_qk = tl.sum(q_vec * k_chunk, axis=0)  # scalar
        logits_scaled = dot_qk * sm_scale

        # attn for this token, ignoring invalid
        attn = tl.where(valid, tl.exp(logits_scaled - max_logit) / sum_exp, 0.0)

        # Load v_chunk for this token and accumulate
        v_off = kvh * D + tok_idx * D
        v_chunk = tl.load(v_ptr + v_off + tl.arange(0, D), mask=valid, other=0.0)  # [D]
        acc += attn * v_chunk

    # Store output[b, h, :] in bfloat16
    out_off = b * (H * D) + h * D
    # Cast acc (float32) to bfloat16 and store
    tl.store(out_ptr + out_off, acc.to(tl.bfloat16))


class ModelNew(torch.nn.Module):
    def __init__(self):
        super().__init__()

    def forward(self, q, k_cache, v_cache, kv_indptr, kv_indices, sm_scale):
        # Ensure on CUDA
        assert q.is_cuda and k_cache.is_cuda and v_cache.is_cuda and kv_indptr.is_cuda and kv_indices.is_cuda, \
            "All tensors must be CUDA tensors."

        # Shapes
        B, H, D = q.shape
        # k_cache, v_cache: [P, 1, N, D] -> squeeze dim 1 to [N, D]
        # Convert to float32 for kernel computation
        k_squeezed = k_cache.squeeze(1).to(torch.float32)
        v_squeezed = v_cache.squeeze(1).to(torch.float32)
        device = q.device

        # Output and LSE
        output = torch.empty((B, H, D), dtype=torch.bfloat16, device=device)
        lse = torch.empty((B, H), dtype=torch.float32, device=device).fill_(-float("inf"))

        # GQA ratio
        gqa_ratio = H // 8  # assert num_kv_heads == 8 in original; H//N = 4

        # Launch Triton kernel: grid over (B, H)
        grid = (B, H)
        # BLOCK_T set to 128 to match D; masks handle smaller num_tokens.
        gqa_attention_kernel_bh[grid](
            q, k_squeezed, v_squeezed, kv_indptr, kv_indices, output, lse, sm_scale,
            B=B, H=H, D=D, N=8, gqa_ratio=gqa_ratio, BLOCK_T=128,
            num_warps=4, num_stages=2,
        )

        return output, lse
```

    B: tl.constexpr,          # batch size

    N: tl.constexpr,          # num kv heads (e.g., 8)
    gqa_ratio: tl.constexpr,  # H // N (e.g., 4)
    BLOCK_H: tl.constexpr,    # number of query heads per program (e.g., 8 or 16)
    BLOCK_T: tl.constexpr,    # token chunk size (e.g., 128)

    pid_h_block = tl.program_id(1)

    b = pid_b
    h_start = pid_h_block * BLOCK_H

    # Build vector of query heads indices for this block
    offs_h = tl.arange(0, BLOCK_H)
    h_vec = h_start + offs_h  # shape [BLOCK_H], int32

    # Compute number of valid query heads in this block
    valid_h = h_vec < H  # shape [BLOCK_H], bool

    # GQA mapping vectorized
    kvh_vec = h_vec // gqa_ratio  # shape [BLOCK_H]

    # Read token range for this batch
    start = tl.load(kv_indptr_ptr + b).to(tl.int32)
    end = tl.load(kv_indptr_ptr + b + 1).to(tl.int32)
    num_tokens = end - start  # number of tokens for this batch element

    # Prepare output accumulator per head (float32)
    acc = tl.zeros((BLOCK_H, D), dtype=tl.float32)

    # First pass: compute max over tokens per head and sum of exp for stability
    # Initialize vectors
    max_logit = tl.full((BLOCK_H,), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((BLOCK_H,), dtype=tl.float32)

    for t_off in range(0, BLOCK_T):
        t = start + t_off  # int32
        valid_t = t < num_tokens  # scalar bool

        # Load token index for this t
        tok_idx = tl.load(kv_indices_ptr + t, mask=valid_t, other=0).to(tl.int32)

        # Load q vectors for this block of heads: q layout [B, H, D] contiguous
        # offset = b*(H*D) + h_vec*D
        q_base = b * (H * D) + h_vec * D
        q_vec = tl.load(q_ptr + q_base, mask=valid_h, other=0.0).to(tl.float32)  # [BLOCK_H, D]

        # Build k_chunk for this token and heads: [BLOCK_H, D]
        # k_ptr[kvh_vec, tok_idx, :] -> k_ptr[kvh_vec*D + tok_idx*D + offs]
        k_offs = kvh_vec * D + tok_idx * D + tl.arange(0, D)  # [BLOCK_H, D]
        k_chunk = tl.load(k_ptr + k_offs, mask=valid_h[:, None], other=0.0)  # [BLOCK_H, D]
        # q·k per head
        dot_qk = tl.sum(q_vec * k_chunk, axis=1)  # [BLOCK_H] scalar per head

        # Scale
        logits_scaled = dot_qk * sm_scale

        # Update max and sum_exp per head
        # If valid_t is False, do nothing for sum; but we need to keep shape [BLOCK_H]
        logits_scaled = tl.where(valid_t, logits_scaled, -float("inf"))
        max_logit = tl.maximum(max_logit, logits_scaled)
        sum_exp = tl.where(valid_t, sum_exp + tl.exp(logits_scaled - max_logit), sum_exp)

    # Compute lse per head: lse[b, h] = max + log(sum_exp) / log(2)
    lse_offs = b * H + h_vec  # [BLOCK_H]
    lse_vals = max_logit + tl.log(sum_exp) / tl.log(2.0)
    tl.store(lse_ptr + lse_offs, lse_vals, mask=valid_h)

    # Second pass: compute attn per token and accumulate output
    for t_off in range(0, BLOCK_T):
        t = start + t_off
        valid_t = t < num_tokens

        tok_idx = tl.load(kv_indices_ptr + t, mask=valid_t, other=0).to(tl.int32)

        # Load q vectors
        q_base = b * (H * D) + h_vec * D
        q_vec = tl.load(q_ptr + q_base, mask=valid_h, other=0.0).to(tl.float32)  # [BLOCK_H, D]

        # Load k_chunk [BLOCK_H, D]
        k_offs = kvh_vec * D + tok_idx * D + tl.arange(0, D)
        k_chunk = tl.load(k_ptr + k_offs, mask=valid_h[:, None], other=0.0)  # [BLOCK_H, D]
        dot_qk = tl.sum(q_vec * k_chunk, axis=1)  # [BLOCK_H]

        logits_scaled = dot_qk * sm_scale

        attn = tl.where(valid_t, tl.exp(logits_scaled - max_logit) / sum_exp, 0.0)  # [BLOCK_H]

        # Load v_chunk [BLOCK_H, D]
        v_offs = kvh_vec * D + tok_idx * D + tl.arange(0, D)
        v_chunk = tl.load(v_ptr + v_offs, mask=valid_h[:, None], other=0.0)  # [BLOCK_H, D]

        # Accumulate per head
        acc += attn[:, None] * v_chunk

    # Store output[b, h_vec, :] in bfloat16
    out_base = b * (H * D) + h_vec * D  # [BLOCK_H]
    tl.store(out_ptr + out_base[:, None] + tl.arange(0, D)[None, :], acc.to(tl.bfloat16), mask=valid_h[:, None])
