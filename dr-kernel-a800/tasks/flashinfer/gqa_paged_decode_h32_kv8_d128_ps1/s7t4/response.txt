Diagnosis and plan

- The evaluation keeps reporting “too many values to unpack (expected 3)” across multiple workloads. This error happens on the host side when we attempt to unpack exactly three values from a tensor’s shape. In the earlier attempts, I accessed q.shape and k_cache.shape before ensuring they were contiguous or had the expected 3D structure. If q or k_cache are non-contiguous or have more than 3 dims due to views, .shape returns a tuple with more than 3 elements, and Python’s tuple unpacking raises the “too many values to unpack (expected 3)” error. This was purely a host-side data handling bug, not a Triton compile/runtime error.

- Additionally, using Python for-loops inside Triton kernels can be brittle; Triton supports while loops and tl.arange for vectorized operations. To be robust, we will:
  - Make sure q, k_cache, v_cache, kv_indptr, kv_indices are contiguous and on CUDA.
  - Pass shapes as compile-time constants (B, Nq, Nkv, D) to Triton kernels.
  - Avoid Python for-loops in Triton; use while loops and scalar indexing.

Fixes to prevent recurrence
- In ModelNew.forward:
  - Ensure all inputs are moved to device and made contiguous: q = q.contiguous(), k_cache = k_cache.contiguous(), v_cache = v_cache.contiguous(), kv_indptr = kv_indptr.contiguous(), kv_indices = kv_indices.contiguous().
  - Pass shapes B, Nq, Nkv, D explicitly as tl.constexpr to Triton kernels, not relying on tensor.shape unpacking.
  - No torch matmul/softmax in host code; all computations are done by Triton kernels.

Correctness details to match original
- GQA mapping: kv_head = h // (Nq // Nkv) = h // 4.
- Compute logits_scaled = q·k_i * sm_scale, m = max(logits_scaled), sum_exp = sum(exp(logits_scaled - m)).
- lse[b, h] = log(sum_exp) + m, then divide by log(2) as in the original.
- Softmax: exp(logits_scaled - m) / sum_exp.
- Output vector: out[b, h, :] = softmax @ v_selected (elementwise accumulation). We store output as bfloat16.

Performance notes
- The kernels are designed to be simple and robust. We parallelize across (b, h) programs, each handling the entire output vector of length D for that head. While each program loops over tokens, the total number of programs is B * Nq, which can provide sufficient parallelism. num_warps=4 and num_stages=2 are reasonable defaults.
- Further performance improvements (e.g., vectorized reductions over chunks, fusing kernels, precomputing m and sum_exp) can be added once correctness is established across workloads.

import math
import torch
import triton
import triton.language as tl


@triton.jit
def lse_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    B: tl.constexpr,          # batch size
    Nq: tl.constexpr,         # num_qo_heads
    Nkv: tl.constexpr,        # num_kv_heads
    D: tl.constexpr,          # head_dim
    gqa_ratio: tl.constexpr,  # Nq // Nkv (4)
    stride_q_b, stride_q_h, stride_q_d,  # strides for q
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio  # GQA mapping

    # Load q[b, h] vector of length D
    q_base = q_ptr + b * stride_q_b + h * stride_q_h
    # Since q_ptr is [B, Nq, D] bf16, we need to index D dimension stride
    # We can access q[b, h, :] by loading with tl.arange over D
    q_vec = tl.load(q_base + tl.arange(0, D) * stride_q_d).to(tl.float32)  # [D], f32

    # Determine token window [start, end)
    start = tl.load(indptr_ptr + b)         # int32
    end = tl.load(indptr_ptr + b + 1)      # int32
    T = end - start

    # Accumulate max and sum_exp for logsumexp
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)

    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D  # idx * Nkv, then kv_head * D
        k_i = tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32)  # [D]
        attn = tl.sum(q_vec * k_i, axis=0)  # scalar
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        exp_term = tl.exp(scaled - m)
        sum_exp += exp_term
        i += 1

    # lse = log(sum_exp) + m; divide by log(2) to match original
    log2 = 0.6931471805599453
    lse_val = tl.log(sum_exp) + m
    tl.store(lse_ptr + b * Nq + h, lse_val / log2)


@triton.jit
def output_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    v_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    out_ptr,        # *bf16, [B, Nq, D]
    B: tl.constexpr,          # batch size
    Nq: tl.constexpr,         # num_qo_heads
    Nkv: tl.constexpr,        # num_kv_heads
    D: tl.constexpr,          # head_dim
    gqa_ratio: tl.constexpr,  # Nq // Nkv (4)
    stride_q_b, stride_q_h, stride_q_d,
    stride_k_p, stride_k_h, stride_k_d,
    stride_v_p, stride_v_h, stride_v_d,
    stride_out_b, stride_out_h, stride_out_d,
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio  # GQA mapping

    # Load q[b, h] vector of length D
    q_base = q_ptr + b * stride_q_b + h * stride_q_h
    q_vec = tl.load(q_base + tl.arange(0, D) * stride_q_d).to(tl.float32)  # [D], f32

    # Determine token window [start, end)
    start = tl.load(indptr_ptr + b)         # int32
    end = tl.load(indptr_ptr + b + 1)      # int32
    T = end - start

    # Compute m and sum_exp again to get softmax
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)
    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_i = tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32)  # [D]
        attn = tl.sum(q_vec * k_i, axis=0)
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        exp_term = tl.exp(scaled - m)
        sum_exp += exp_term
        i += 1

    log2 = 0.6931471805599453
    # Initialize output vector
    out_base = out_ptr + b * stride_out_b + h * stride_out_h
    # out[b, h, :] = sum_i softmax[i] * v_i
    j = 0
    while j < D:
        out_vec_j = tl.zeros((), dtype=tl.float32)
        i = 0
        while i < T:
            idx = tl.load(indices_ptr + start + i).to(tl.int32)
            k_base = k_ptr + idx * (Nkv * D) + kv_head * D
            v_base = v_ptr + idx * (Nkv * D) + kv_head * D
            k_i = tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32)  # [D]
            v_i = tl.load(v_base + tl.arange(0, D) * 1).to(tl.float32)  # [D]
            attn = tl.sum(q_vec * k_i, axis=0)
            scaled = attn * sm_scale
            soft = tl.exp(scaled - m) / sum_exp
            out_vec_j += soft * v_i[j]
            i += 1
        tl.store(out_base + j * stride_out_d, out_vec_j.to(tl.bfloat16))
        j += 1


class ModelNew(torch.nn.Module):
    def forward(self, q, k_cache, v_cache, kv_indptr, kv_indices, sm_scale):
        # Ensure device and contiguity; make shapes explicit for Triton
        device = q.device
        assert q.is_cuda and k_cache.is_cuda and v_cache.is_cuda and kv_indptr.is_cuda and kv_indices.is_cuda, "Inputs must be CUDA tensors"
        q = q.contiguous()
        k_cache = k_cache.contiguous()
        v_cache = v_cache.contiguous()
        kv_indptr = kv_indptr.contiguous()
        kv_indices = kv_indices.contiguous()

        B = q.shape[0]
        Nq = q.shape[1]
        D = q.shape[2]
        Np = k_cache.shape[0]
        Nkv = k_cache.shape[1]
        # k_cache and v_cache are [Np, Nkv, D]
        assert k_cache.shape == v_cache.shape, "k_cache and v_cache must have the same shape"
        assert k_cache.shape[2] == D, "head_dim mismatch"
        assert Nkv == 8, "num_kv_heads must be 8"
        assert Nq == 32, "num_qo_heads must be 32"
        assert D == 128, "head_dim must be 128"

        # Prepare output and lse
        output = torch.empty((B, Nq, D), dtype=torch.bfloat16, device=device)
        lse = torch.empty((B, Nq), dtype=torch.float32, device=device)

        # Compute strides (in elements, not bytes)
        stride_q_b, stride_q_h, stride_q_d = q.stride(0), q.stride(1), q.stride(2)
        stride_k_p, stride_k_h, stride_k_d = k_cache.stride(0), k_cache.stride(1), k_cache.stride(2)
        stride_v_p, stride_v_h, stride_v_d = v_cache.stride(0), v_cache.stride(1), v_cache.stride(2)
        stride_out_b, stride_out_h, stride_out_d = output.stride(0), output.stride(1), output.stride(2)

        # Launch Triton kernels: one program per (b, h)
        grid = (B * Nq,)
        lse_kernel[grid](
            q, k_cache, kv_indptr, kv_indices, sm_scale, lse,
            B=B, Nq=Nq, Nkv=Nkv, D=D, gqa_ratio=Nq // Nkv,
            stride_q_b=stride_q_b, stride_q_h=stride_q_h, stride_q_d=stride_q_d,
            num_warps=4, num_stages=2,
        )

        output_kernel[grid](
            q, k_cache, v_cache, kv_indptr, kv_indices, sm_scale, lse, output,
            B=B, Nq=Nq, Nkv=Nkv, D=D, gqa_ratio=Nq // Nkv,
            stride_q_b=stride_q_b, stride_q_h=stride_q_h, stride_q_d=stride_q_d,
            stride_k_p=stride_k_p, stride_k_h=stride_k_h, stride_k_d=stride_k_d,
            stride_v_p=stride_v_p, stride_v_h=stride_v_h, stride_v_d=stride_v_d,
            stride_out_b=stride_out_b, stride_out_h=stride_out_h, stride_out_d=stride_out_d,
            num_warps=4, num_stages=2,
        )

        return output, lse

  - kv_indptr: [B+1], int32, prefix sum of tokens per batch b: [start, end) => T = end - start. Note: It’s not a cumsum over all batches; each batch has its own [start,end). In the provided get_inputs, len_indptr = 2 and kv_indptr = [0, 10], so B=1 and T=10.
  - kv_indices: [T_total], int32, sampled token indices into k_cache. Each batch uses its own subset kv_indices[start:end).

- Reference PyTorch behavior per (b, h):
  - kv_head = h // (Nq // Nkv) = h // 4. Always maps 4 query heads to the same kv head (8 total).
  - For i in [0..T-1]:
    - k_i = k_cache[token_indices[start+i], kv_head], v_i = v_cache[token_indices[start+i], kv_head].
    - attn_i = q[b, h] · k_i.
    - scaled[i] = attn_i * sm_scale.
  - Compute logsumexp in base-2: m = max(scaled), sum_exp = sum(exp(scaled - m)), lse[b, h] = log(sum_exp) + m, then divide by log(2).
  - softmax[i] = exp(scaled[i] - m) / sum_exp.
  - out[b, h, :] = softmax @ v_selected (i.e., elementwise j loop: out[j] = sum_i softmax[i] * v_i[j]).

def lse_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    B: tl.constexpr,          # batch size
    Nq: tl.constexpr,         # num_qo_heads
    Nkv: tl.constexpr,        # num_kv_heads
    D: tl.constexpr,          # head_dim
    gqa_ratio: tl.constexpr,  # Nq // Nkv (4)
    stride_q_b, stride_q_h, stride_q_d,  # strides for q
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio  # GQA mapping

    # Load q[b, h] vector of length D
    q_base = q_ptr + b * stride_q_b + h * stride_q_h
    q_vec = tl.load(q_base + tl.arange(0, D) * stride_q_d).to(tl.float32)  # [D], f32

    # Token window [start, end)
    start = tl.load(indptr_ptr + b)         # int32
    end = tl.load(indptr_ptr + b + 1)      # int32
    T = end - start

    # Accumulate max and sum_exp for logsumexp
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)

    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_i = tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32)  # [D]
        attn = tl.sum(q_vec * k_i, axis=0)  # scalar
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        exp_term = tl.exp(scaled - m)
        sum_exp += exp_term
        i += 1

    # lse = log(sum_exp) + m; divide by log(2) to match original
    log2 = 0.6931471805599453
    lse_val = tl.log(sum_exp) + m
    tl.store(lse_ptr + b * Nq + h, lse_val / log2)
