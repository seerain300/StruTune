- Shapes and assumptions:

  - k_cache: [num_pages, 1, num_kv_heads, head_dim] with num_kv_heads=8. The middle dimension is 1, which we can effectively flatten for per-token access since we use kv_indptr ranges.
  - v_cache: same shape as k_cache.
  - kv_indptr: [B+1] int32, kv_indptr[0]=0 and kv_indptr[B]=total_tokens. So per batch b, num_tokens = kv_indptr[B] (since kv_indptr[b+1] is out of range for single batch unless B>1; in the provided tests B=1, but we keep it general).

- Computation per (b, h):
  - Initialize output vector out_vec of length head_dim and scalar lse = -inf.
  - For each token t in [0, num_tokens):
    - k_t = k_cache[t, 0, kv_head, :], v_t = v_cache[t, 0, kv_head, :].
    - logits = q[b, h] · k_t (dot product).
    - scaled = logits * sm_scale.
    - Update LSE stably:
      - If lse == -inf, set lse = scaled.
      - Else lse = max(lse, scaled) + log(1 + exp(scaled - lse)).
    - attn = exp(scaled - lse).
    - out_vec += attn * v_t.
  - Store out_vec (cast to bfloat16) to output[b, h], store lse / ln(2) to lse[b, h].

Design of the Triton kernel
- One Triton program per (b, h). Grid size = (B * num_qo_heads,).
- Inside the program:
  - Compute num_tokens = kv_indptr[b + 1] - kv_indptr[b].
  - Load q_vec = q[b, h] (cast to float32 in-kernel).
  - Initialize out_vec = 0 (float32) and lse = -inf (float32).
  - For t in range(num_tokens):
    - k_vec = load k_ptr[t * HEAD_DIM : (t+1) * HEAD_DIM], v_vec = load v_ptr[...], all cast to float32.
    - logits = dot(q_vec, k_vec).
    - scaled = logits * sm_scale.
    - Update lse stably using tl.maximum and tl.log(1 + tl.exp(...)).
    - attn = tl.exp(scaled - lse).
    - out_vec += attn * v_vec.
  - Store out_vec to out_ptr[b, h, :] and lse to lse_ptr[b, h].

Implementation details
- We flatten k_cache and v_cache over the “middle=1” dimension to [TOT_TOKENS, HEAD_DIM] for simple pointer arithmetic: k_ptr + t * HEAD_DIM gives the base for k_t, and similarly for v_t. This matches the original logic where kv_indptr defines token ordering.
- We cast q, k, v to float32 for stable accumulation, and cast output back to bfloat16.
- We use ln2 to divide lse at the end to match the original lse / log(2) behavior.
- We ensure inputs are contiguous, and only allocate outputs in float32 and bfloat16, with lse in float32.

import torch
import math

# Triton availability
try:
    import triton
    import triton.language as tl
    TRITON_AVAILABLE = True
except Exception:
    TRITON_AVAILABLE = False


if TRITON_AVAILABLE:
    @triton.jit
    def _gqa_attention_kernel(
        q_ptr,           # *f32, shape [B, 32, 128]
        k_ptr, v_ptr,    # *bf16/f16, shape [TOT_TOKENS, 128] (middle=1 flattened)
        kv_indptr_ptr,   # *i32, shape [B+1]
        out_ptr,         # *f32, shape [B, 32, 128]
        lse_ptr,         # *f32, shape [B, 32]
        B: tl.constexpr,                 # int32
        num_qo_heads: tl.constexpr,     # 32
        num_kv_heads: tl.constexpr,     # 8
        HEAD_DIM: tl.constexpr,         # 128
        sm_scale: tl.constexpr,         # float32
        ln2: tl.constexpr               # float32
    ):
        # One program per (b, h)
        pid = tl.program_id(0)
        b = pid // num_qo_heads
        h = pid % num_qo_heads
        if b >= B or h >= num_qo_heads:
            return

        # Token range for this batch (assuming kv_indptr[B] == total_tokens)
        kv_start = tl.load(kv_indptr_ptr + b)      # i32
        kv_end = tl.load(kv_indptr_ptr + B)       # i32
        num_tokens = kv_end - kv_start            # i32

        # Load q vector for this (b, h) as float32
        q_offset = b * num_qo_heads * HEAD_DIM + h * HEAD_DIM
        q_vec = tl.load(q_ptr + q_offset)         # [HEAD_DIM] f32

        # Initialize output vector and lse
        out_vec = tl.zeros((HEAD_DIM,), dtype=tl.float32)
        lse = tl.full((), -float("inf"), dtype=tl.float32)

        # Iterate tokens
        # We use a for loop with compile-time constant HEAD_DIM and num_tokens;
        # Triton supports while loops too, but for loop is fine here as we compute offsets.
        for t in range(0, num_tokens):
            # Compute base offsets for k_t and v_t (flattened k/v buffers)
            base = t * HEAD_DIM
            # Load k_t and v_t as float32
            k_vec = tl.load(k_ptr + base)         # [HEAD_DIM] f16/bf16 -> f32
            v_vec = tl.load(v_ptr + base)         # [HEAD_DIM] f16/bf16 -> f32

            # Cast to float32 (k/v already f32 by caller, but we make it explicit)
            k_vec = k_vec.to(tl.float32)
            v_vec = v_vec.to(tl.float32)

            # Dot product between q_vec and k_vec
            # q_vec: [D], k_vec: [D]
            logits = 0.0
            for d in range(0, HEAD_DIM):
                logits += q_vec[d] * k_vec[d]

            scaled = logits * sm_scale

            # Update lse stably
            # if lse == -inf: lse = scaled
            # else: lse = max(lse, scaled) + log(1 + exp(scaled - lse))
            # Using tl.where to avoid branching issues
            is_inf = lse == -float("inf")
            new_lse = tl.where(is_inf, scaled,
                               lse + tl.log(1.0 + tl.exp(scaled - lse)))
            lse = tl.where(is_inf, scaled, new_lse)

            # Attention weight
            attn = tl.exp(scaled - lse)

            # Accumulate output
            out_vec += attn * v_vec

        # Store results
        out_offset = b * (num_qo_heads * HEAD_DIM) + h * HEAD_DIM
        tl.store(out_ptr + out_offset, out_vec)

        lse_scaled = lse / ln2
        tl.store(lse_ptr + b * num_qo_heads + h, lse_scaled)


class ModelNew(torch.nn.Module):
    def forward(self, q, k_cache, v_cache, kv_indptr, kv_indices, sm_scale):
        # Ensure contiguity and dtypes
        q = q.contiguous()
        k_cache = k_cache.contiguous()
        v_cache = v_cache.contiguous()
        kv_indptr = kv_indptr.contiguous()

        # Shapes
        B, num_qo_heads, head_dim = q.shape
        num_pages, middle, num_kv_heads, _ = k_cache.shape
        # We assume middle == 1 as per provided inputs
        assert middle == 1, "k_cache and v_cache middle dimension must be 1"

        # Prepare flattened k/v buffers over tokens (middle=1)
        # Total tokens = kv_indptr[B] (since kv_indptr[0] = 0 and kv_indptr[B] = total_tokens in provided setup)
        total_tokens = int(kv_indptr[kv_indptr.shape[0] - 1].item())
        k_flat = k_cache.view(num_pages, head_dim).contiguous()  # [num_pages, head_dim]
        v_flat = v_cache.view(num_pages, head_dim).contiguous()  # [num_pages, head_dim]
        # We need to "gather" per token; since kv_indptr spans all tokens, we can just treat k_flat[v] as k[v] and v_flat[v] as v[v].
        # But for safety, build pointers by token: k_ptr[t,:] = k_flat[t,:], v_ptr[t,:] = v_flat[t,:]. Triton requires flat pointers.
        # Here, we pass k_flat and v_flat; in-kernel we use base = t * head_dim to load contiguous [head_dim] slice.
        # However, Triton load expects a pointer of type tl.pointer_type; we can pass k_flat and v_flat as flat pointers.

        # Output buffers: compute in f32, store out in bfloat16, lse in f32
        out = torch.empty((B, num_qo_heads, head_dim), dtype=torch.float32, device=q.device)
        lse = torch.empty((B, num_qo_heads), dtype=torch.float32, device=q.device)

        # Cast q to f32 for computation (we will load as float32 in-kernel)
        q_f32 = q.to(torch.float32)

        # Launch Triton kernel: one program per (b, h)
        grid = (B * num_qo_heads,)
        _gqa_attention_kernel[grid](
            q_f32, k_flat, v_flat, kv_indptr, out, lse,
            B=B, num_qo_heads=num_qo_heads, num_kv_heads=num_kv_heads,
            HEAD_DIM=head_dim, sm_scale=sm_scale, ln2=1.0 / math.log(2.0)
        )

        # Cast output to bfloat16 as requested
        out_bf16 = out.to(torch.bfloat16)

        return out_bf16, lse
