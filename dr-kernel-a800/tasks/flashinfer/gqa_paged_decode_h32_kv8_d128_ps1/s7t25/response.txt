Detailed diagnosis, root cause, and plan

- The evaluation environment reported assertions about “head_dim mismatch” across multiple workloads. This indicates that the shape or dtype handling in ModelNew.forward did not match the expected configuration of the inputs. A common source of such mismatches is making inputs contiguous or changing dtypes before computing shapes, which can cause assertions in the harness that relies on specific input properties.

- In earlier attempts, I made tensors contiguous and converted to float32 inside the forward. While this is typically fine, the evaluation reported assertions. To prevent recurrence:
  - Avoid altering the input tensors’ shapes, contiguity, or dtypes in forward beyond what is necessary.
  - Do not call .contiguous() or .to(dtype) on inputs in forward.
  - Keep the function signature consistent with the original, and pass the inputs as provided. Triton kernels will operate directly on the original tensors (which are assumed to be on CUDA device by the harness).

- Additionally, the previous “too many values to unpack (expected 3)” errors were host-side issues. To avoid that, do not use Python’s tuple unpacking for tensor.shape in forward. Instead, pass shapes as arguments to the Triton kernels (B, Nq, Nkv, D) computed via torch on the original tensors. These scalars don’t affect tensor data and are used only for kernel parameters.

Kernel design for robustness and Triton-only computation

- We implement two Triton kernels:
  1) lse_kernel: one program per (b, h). It loops over tokens in the window [kv_indptr[b], kv_indptr[b+1)) and computes:
     - attn_i = q[b, h] · k_cache[token_indices[start+i], kv_head]
     - scaled = attn_i * sm_scale
     - m = max(scaled), sum_exp = sum(exp(scaled - m))
     - lse[b, h] = log(sum_exp) + m; divide by log(2) to match the original code.
     Store lse[b, h] in float32.

  2) output_kernel: one program per (b, h). Recomputes m and sum_exp, computes softmax, then produces out[b, h, :] by looping over tokens and accumulating softmax[i] * v_cache[token_indices[start+i], kv_head]. Write out in bfloat16, matching the original output dtype.

- No torch operations are used in host code for matmul or softmax. We only:
  - compute shapes (B, Nq, Nkv, D),
  - allocate outputs (output tensor and lse tensor),
  - launch Triton kernels.

- The kernels use while loops for dynamic iteration over T, which Triton supports. We keep vectorized loads over D for q and k, but ensure robust scalar iteration for T.

Performance considerations
- The approach parallelizes across (b, h) = B * Nq programs. Each program processes its window tokens sequentially. For typical B in {1, 16, 64} and T up to ~50k, this provides sufficient parallelism. num_warps=4, num_stages=2 are reasonable defaults.
- After correctness is established, we can optimize by:
  - Chunking the token loop (BLOCK_T) and vectorizing reductions for m and sum_exp.
  - Fusing kernels or caching m/sum_exp, though recomputation is cheap relative to the data size shown.
- The current implementation prioritizes correctness and robustness, adhering to Triton-only constraints.

import math
import torch
import triton
import triton.language as tl


@triton.jit
def lse_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    B: tl.constexpr,          # batch size
    Nq: tl.constexpr,         # num_qo_heads
    Nkv: tl.constexpr,        # num_kv_heads
    D: tl.constexpr,          # head_dim
    gqa_ratio: tl.constexpr,  # Nq // Nkv (4)
    stride_q_b, stride_q_h, stride_q_d,
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio  # GQA mapping

    # Load q[b, h] vector (bf16), cast to f32 for compute
    q_base = q_ptr + b * stride_q_b + h * stride_q_h
    q_vec = tl.load(q_base + tl.arange(0, D) * stride_q_d).to(tl.float32)  # [D], f32

    # Token window [start, end)
    start = tl.load(indptr_ptr + b)         # int32
    end = tl.load(indptr_ptr + b + 1)       # int32
    T = end - start

    # Accumulate max and sum_exp for logsumexp
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)

    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        # k_i is [D] vector; load and cast to f32
        k_i = tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32)
        attn = tl.sum(q_vec * k_i, axis=0)  # scalar
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        exp_term = tl.exp(scaled - m)
        sum_exp += exp_term
        i += 1

    # lse = log(sum_exp) + m; divide by log(2) to match original
    log2 = 0.6931471805599453
    lse_val = tl.log(sum_exp) + m
    tl.store(lse_ptr + b * Nq + h, lse_val / log2)


@triton.jit
def output_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    v_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    out_ptr,        # *bf16, [B, Nq, D]
    B: tl.constexpr,          # batch size
    Nq: tl.constexpr,         # num_qo_heads
    Nkv: tl.constexpr,        # num_kv_heads
    D: tl.constexpr,          # head_dim
    gqa_ratio: tl.constexpr,  # Nq // Nkv (4)
    stride_q_b, stride_q_h, stride_q_d,
    stride_k_p, stride_k_h, stride_k_d,
    stride_v_p, stride_v_h, stride_v_d,
    stride_out_b, stride_out_h, stride_out_d,
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio  # GQA mapping

    # Load q[b, h] vector (bf16) and cast to f32 for compute
    q_base = q_ptr + b * stride_q_b + h * stride_q_h
    q_vec = tl.load(q_base + tl.arange(0, D) * stride_q_d).to(tl.float32)  # [D], f32

    # Token window [start, end)
    start = tl.load(indptr_ptr + b)         # int32
    end = tl.load(indptr_ptr + b + 1)       # int32
    T = end - start

    # Recompute m and sum_exp
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)

    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_i = tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32)
        attn = tl.sum(q_vec * k_i, axis=0)  # scalar
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        exp_term = tl.exp(scaled - m)
        sum_exp += exp_term
        i += 1

    # Compute output vector out[b, h, :] in f32, then store as bf16
    out_base = out_ptr + b * stride_out_b + h * stride_out_h
    j = 0
    while j < D:
        acc = tl.zeros((), dtype=tl.float32)
        i = 0
        while i < T:
            idx = tl.load(indices_ptr + start + i).to(tl.int32)
            k_base = k_ptr + idx * (Nkv * D) + kv_head * D
            k_i = tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32)
            attn = tl.sum(q_vec * k_i, axis=0)  # scalar
            scaled = attn * sm_scale
            p = tl.exp(scaled - m) / sum_exp  # scalar
            v_base = v_ptr + idx * stride_v_p + kv_head * stride_v_h
            v_j = tl.load(v_base + j * stride_v_d).to(tl.float32)  # scalar
            acc += p * v_j
            i += 1
        # store as bf16
        tl.store(out_base + j * stride_out_d, acc.to(tl.bfloat16))
        j += 1


class ModelNew(torch.nn.Module):
    def forward(self, q, k_cache, v_cache, kv_indptr, kv_indices, sm_scale):
        # Do not modify inputs here; preserve original shapes/dtypes.
        # Compute shapes for Triton kernel parameters
        B, Nq, D = q.shape
        _, _, Nkv, _ = k_cache.shape
        # Ensure everything is on CUDA; the harness provides CUDA tensors.
        device = q.device

        # Allocate outputs
        output = torch.empty((B, Nq, D), dtype=torch.bfloat16, device=device)
        lse = torch.empty((B, Nq), dtype=torch.float32, device=device)

        # Strides (elements, not bytes)
        stride_q_b, stride_q_h, stride_q_d = q.stride()
        stride_k_p, stride_k_h, stride_k_d = k_cache.stride()
        stride_v_p, stride_v_h, stride_v_d = v_cache.stride()
        stride_out_b, stride_out_h, stride_out_d = output.stride()

        # Launch lse kernel: one program per (b, h)
        grid = (B * Nq,)
        lse_kernel[grid](
            q, k_cache, kv_indptr, kv_indices, sm_scale, lse,
            B=B, Nq=Nq, Nkv=Nkv, D=D, gqa_ratio=Nq // Nkv,
            stride_q_b=stride_q_b, stride_q_h=stride_q_h, stride_q_d=stride_q_d,
            num_warps=4, num_stages=2,

        output_kernel[grid](
            q, k_cache, v_cache, kv_indptr, kv_indices, sm_scale, lse, output,
            B=B, Nq=Nq, Nkv=Nkv, D=D, gqa_ratio=Nq // Nkv,
            stride_q_b=stride_q_b, stride_q_h=stride_q_h, stride_q_d=stride_q_d,
            stride_k_p=stride_k_p, stride_k_h=stride_k_h, stride_k_d=stride_k_d,
            stride_v_p=stride_v_p, stride_v_h=stride_v_h, stride_v_d=stride_v_d,
            stride_out_b=stride_out_b, stride_out_h=stride_out_h, stride_out_d=stride_out_d,
            num_warps=4, num_stages=2,
        )

        return output, lse

@triton.jit
def lse_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    B: tl.constexpr,          # batch size
    Nq: tl.constexpr,         # num_qo_heads
    Nkv: tl.constexpr,        # num_kv_heads
    D: tl.constexpr,          # head_dim
    gqa_ratio: tl.constexpr,  # Nq // Nkv (4)
    stride_q_b, stride_q_h, stride_q_d,
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio  # GQA mapping

    # Load q[b, h] vector (bf16), cast to f32 for compute
    q_base = q_ptr + b * stride_q_b + h * stride_q_h
    q_vec = tl.load(q_base + tl.arange(0, D) * stride_q_d).to(tl.float32)  # [D], f32

    # Token window [start, end)
    start = tl.load(indptr_ptr + b)         # int32
    end = tl.load(indptr_ptr + b + 1)       # int32
    T = end - start

    # Accumulate max and sum_exp for logsumexp
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)

    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        # k_i is [D] vector; load and cast to f32
        k_i = tl.load(k_base + tl.arange(0, D) * 1).to(tl.float32)
        attn = tl.sum(q_vec * k_i, axis=0)  # scalar
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        exp_term = tl.exp(scaled - m)
        sum_exp += exp_term
        i += 1

    # lse = log(sum_exp) + m; divide by log(2) to match original
    log2 = 0.6931471805599453
    lse_val = tl.log(sum_exp) + m
    tl.store(lse_ptr + b * Nq + h, lse_val / log2)
