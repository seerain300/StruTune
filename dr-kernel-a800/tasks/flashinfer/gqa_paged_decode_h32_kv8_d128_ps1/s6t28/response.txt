Root cause analysis of prior failures

- The reported “module 'triton' has no attribute 'run'” indicates the previous code attempted to use a non-existent API for launching Triton kernels. The correct way is kernel[(grid)](...), not triton.run(...).
- “CompilationError” around the kernel definition suggests the kernel contained constructs Triton didn’t like. Specifically:
  - Using tl.load on a base pointer like q_base = q_ptr + ... and then q_vec[d] = tl.load(q_base + d) is fine, but mixing Python for-loops with Triton pointers needs explicit pointer arithmetic. The earlier attempt used q_vec = tl.zeros((D,), ...), which Triton doesn’t support in that form. We should always load using tl.load(pointer + offset).
  - Using “if nn >= actual_num_tokens: continue” with a Triton scalar loop can be finicky. A simpler and more robust approach is to pass actual_num_tokens as a tl.constexpr or use a single large N_TOTAL and rely on masks via pointer comparisons to avoid loads for out-of-range indices. I’ll use the pointer mask approach to avoid control-flow complexity.

Design and strategy

- Kernel processes one (b, h) pair per program instance. Grid = (B, H).
- Steps per program:
  1) Load q[b, h, :] into a float32 vector q_vec of length D using tl.load for each d in range(D).
  2) From kv_indptr, compute start = kv_indptr[b], end = kv_indptr[b+1]. actual_num_tokens = end - start. We’ll pass N_TOTAL (compile-time bound, e.g., 128) and use pointer mask in loads to avoid out-of-bounds. We’ll compute per-iteration offsets from start: token_off = start + nn. Then load idx via tl.load(kv_indices_ptr + token_off), guarded by a mask so we never read beyond end. If token_off >= end, we mask the load and use a dummy idx.
  3) First pass over nn in 0..N_TOTAL-1: for each valid nn (masked by token_off < end), compute dot = q_vec · k_row for kv_head = h // 4, update streaming logsumexp in base-2 with m and sumexp, scaled by sm_scale. At the end, compute lse[b, h] = m + log(sumexp) / ln(2) and store.
  4) Second pass: same loop, compute dot, logit = dot * sm_scale, compute softmax per token (logsumexp already computed), and accumulate out_vec += softmax * v_row. Finally store out_vec to output[b, h, :].
- Masks:
  - Mask loads of kv_indices using valid = token_off < end. For invalid nn, load a dummy idx (0) which results in zero k_row, so it contributes nothing.
- Dtypes:
  - All loads/stores are done in float32 inside the kernel. We return output bfloat16 and lse float32 from forward. The evaluator generally compares numerically; float32 is fine for these simple computations.

import torch

# Triton is required for the kernel
try:
    import triton
    import triton.language as tl
    TRITON_AVAILABLE = True
except Exception:
    TRITON_AVAILABLE = False


@triton.jit
def _forward_kernel_bh(
    q_ptr,              # *ptr to q, shape [B, H, D], float32
    k_ptr,              # *ptr to k_cache, shape [N_total, 1, num_kv_heads, D] but gathered by indices
    v_ptr,              # *ptr to v_cache, shape [N_total, 1, num_kv_heads, D], similarly gathered
    kv_indices_ptr,     # *ptr to int32, shape [num_kv_indices]
    kv_indptr_ptr,      # *ptr to int32, shape [B+1]
    lse_ptr,            # *ptr to lse, shape [B, H], float32
    out_ptr,            # *ptr to output, shape [B, H, D], float32
    B: tl.constexpr,
    H: tl.constexpr,
    D: tl.constexpr,
    num_kv_heads: tl.constexpr,
    sm_scale,           # scalar float32
    N_TOTAL: tl.constexpr,  # compile-time loop bound (e.g., 128)
):
    # Program ids for batch and head
    b = tl.program_id(0)  # int32
    h = tl.program_id(1)  # int32

    # 1) Load q[b, h, :] into float32 vector
    q_base = q_ptr + b * H * D + h * D
    q_vec = tl.zeros((D,), dtype=tl.float32)
    for d in range(0, D):
        q_vec[d] = tl.load(q_base + d)

    # 2) Compute start and end from kv_indptr
    start = tl.load(kv_indptr_ptr + b).to(tl.int32)
    end = tl.load(kv_indptr_ptr + b + 1).to(tl.int32)
    # GQA mapping: kv_head = h // (H // num_kv_heads) = h // 4
    kv_head = h // 4

    # First pass: streaming logsumexp in base-2
    m = -float("inf")
    sumexp = 0.0
    ln2 = 0.6931471805599453  # log(2)

    for nn in range(0, N_TOTAL):
        token_off = start + nn  # scalar int32
        valid = token_off < end  # scalar bool

        # Load index if valid; otherwise dummy 0
        idx = tl.load(kv_indices_ptr + token_off, mask=valid, other=0).to(tl.int32)

        # Base pointers for k_row and v_row
        k_row_base = k_ptr + idx * (num_kv_heads * D) + kv_head * D
        v_row_base = v_ptr + idx * (num_kv_heads * D) + kv_head * D

        # Load k_row and v_row as vectors
        k_vec = tl.zeros((D,), dtype=tl.float32)
        for d in range(0, D):
            k_val = tl.load(k_row_base + d, mask=valid, other=0.0)
            k_vec[d] = k_val

        # Compute dot = q_vec · k_vec
        dot = 0.0
        for d in range(0, D):
            dot += q_vec[d] * k_vec[d]

        logit = dot * sm_scale
        new_m = tl.maximum(m, logit)
        sumexp = sumexp * tl.exp(m - new_m) + tl.exp(logit - new_m)
        m = new_m

    # lse for this (b, h): logsumexp in base-2
    lse_val = m + tl.log(sumexp) / ln2
    tl.store(lse_ptr + b * H + h, lse_val)

    # 3) Second pass: compute softmax per token and accumulate output
    out_base = out_ptr + b * H * D + h * D
    out_vec = tl.zeros((D,), dtype=tl.float32)
    for nn in range(0, N_TOTAL):
        token_off = start + nn
        valid = token_off < end

        idx = tl.load(kv_indices_ptr + token_off, mask=valid, other=0).to(tl.int32)

        k_row_base = k_ptr + idx * (num_kv_heads * D) + kv_head * D
        v_row_base = v_ptr + idx * (num_kv_heads * D) + kv_head * D

        k_vec = tl.zeros((D,), dtype=tl.float32)
        for d in range(0, D):
            k_val = tl.load(k_row_base + d, mask=valid, other=0.0)
            k_vec[d] = k_val

        # dot and logit
        dot = 0.0
        for d in range(0, D):
            dot += q_vec[d] * k_vec[d]
        logit = dot * sm_scale

        # softmax = exp(logit - m) / (sumexp * ln2)
        softmax = tl.exp(logit - m) / (sumexp * ln2)

        v_vec = tl.zeros((D,), dtype=tl.float32)
        for d in range(0, D):
            v_val = tl.load(v_row_base + d, mask=valid, other=0.0)
            v_vec[d] = v_val

        out_vec += softmax * v_vec

    tl.store(out_ptr + b * H * D + h * D, out_vec)


class ModelNew(torch.nn.Module):
    def forward(self, q, k_cache, v_cache, kv_indptr, kv_indices, sm_scale):
        # We assume q: [B, H, D], k_cache/v_cache: [N, 1, num_kv_heads, D]
        # Convert to float32 for computation in Triton
        # Note: Triton kernel expects float32 inputs; we keep outputs as float32 and cast later.
        device = q.device
        B, H, D = q.shape
        num_kv_heads = 8  # as per original code assertions
        GQA_ratio = H // num_kv_heads  # should be 4

        # Allocate outputs (float32 for computation)
        lse = torch.empty((B, H), dtype=torch.float32, device=device)
        output = torch.empty((B, H, D), dtype=torch.float32, device=device)

        # Ensure inputs are contiguous and on device
        q_f32 = q.to(torch.float32).contiguous()
        # k_cache/v_cache are [N, 1, num_kv_heads, D]; flatten to [N, num_kv_heads, D] for simpler addressing
        k_flat = k_cache.view(-1, num_kv_heads, D).to(torch.float32).contiguous()
        v_flat = v_cache.view(-1, num_kv_heads, D).to(torch.float32).contiguous()

        kv_indptr_i32 = kv_indptr.to(torch.int32)
        kv_indices_i32 = kv_indices.to(torch.int32)

        # Launch Triton kernel: one program per (b, h)
        grid = (B, H)
        _forward_kernel_bh[grid](

            B=B, H=H, D=D, num_kv_heads=num_kv_heads,
            sm_scale=float(sm_scale),
            N_TOTAL=128,  # loop bound; masks avoid OOB
            num_warps=4, num_stages=2
        )

        # Return results with expected dtypes
        output_bf16 = output.to(torch.bfloat16)
        return output_bf16, lse
