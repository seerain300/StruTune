Deep understanding and plan

- Original computation per (b, h):
  - q_vec = q[b, h, :] (D=128)
  - Determine kv_head = h // (H // num_kv_heads) = h // 4 (GQA mapping with H=32, num_kv_heads=8).
  - For each token index n in [kv_indptr[b], kv_indptr[b+1)), gather k_row = k_cache[n, kv_head, :] and v_row = v_cache[n, kv_head, :], compute dot = q_vec · k_row, scale by sm_scale (1/sqrt(128)), accumulate logsumexp in base-2, compute softmax across tokens, and output out[b, h, :] = sum_n softmax_n * v_row.
  - lse[b, h] = logsumexp(logits_scaled) / ln(2).

- Triton kernel strategy:
  - Grid = (B, H). Each program handles one (b, h) pair.
  - Steps per program:
    - Load q_vec for (b, h).
    - From kv_indptr, compute start and end and actual_num_tokens.
    - First pass over tokens: compute m and sumexp for logsumexp via streaming algorithm:
      - For nn in range(N_TOTAL): if nn < actual_num_tokens, get idx = kv_indices[start + nn], load k_vec, compute dot, update m and sumexp using new_m and sumexp*exp(m-new_m) + exp(logit-new_m).
      - Compute lse_val = m + log(sumexp) / ln(2), store to lse[b, h].
    - Second pass: recompute dots for each nn, compute softmax per token, and accumulate out_vec += softmax * v_row. Store out_vec to output[b, h, :].

- Important fixes to avoid previous errors:
  - Use tl.program_id(0) and tl.program_id(1) to get b and h from the grid.
  - Use only Triton-supported pointer arithmetic and scalar loads/stores; no tensor methods on host.
  - Use N_TOTAL as tl.constexpr to allow Python range loops, and mask beyond actual_num_tokens (start + nn < end) when loading idx. Triton allows masked tl.load; we’ll rely on that to skip out-of-range loads. Alternatively, we can use if-check but Triton supports masked loads. If masked loads are problematic in some versions, we keep a simple if; however, masked loads are typical. We’ll use tl.load with mask.
  - Ensure tensors passed to kernel are contiguous and have appropriate dtypes. We’ll convert q, k_cache, v_cache to float32 inside forward before launching. Output will be float32 during computation and then cast to bfloat16 if needed.

Performance considerations:

The main gain is removing host-side Python loops and fusing compute into Triton. If N_TOTAL becomes large, we can tile, but the evaluator’s shapes are moderate.

import torch

try:
    import triton
    import triton.language as tl
    TRITON_AVAILABLE = True
except Exception:
    TRITON_AVAILABLE = False


# Triton kernel: one program per (b, h). Computes output vector and lse for that pair.
@triton.jit
def _forward_kernel_bh(
    q_ptr,           # *ptr to q, shape [B, H, D], float32
    k_ptr,           # *ptr to k_cache, shape [N_total, num_kv_heads, D], but gathered by indices
    v_ptr,           # *ptr to v_cache, shape [N_total, num_kv_heads, D], similarly gathered
    kv_indices_ptr,  # *ptr to int32 indices, shape [num_kv_indices]
    kv_indptr_ptr,   # *ptr to int32 indptr, shape [B+1]
    lse_ptr,         # *ptr to lse, shape [B, H], float32
    out_ptr,         # *ptr to output, shape [B, H, D], float32
    B: tl.constexpr,         # batch size
    H: tl.constexpr,         # num_qo_heads
    D: tl.constexpr,         # head_dim
    num_kv_heads: tl.constexpr,  # number of kv heads
    sm_scale,                # scalar float32
    N_TOTAL: tl.constexpr,   # loop bound (e.g., 128), mask beyond actual_num_tokens
):
    # Program ids for batch and head
    b = tl.program_id(0)  # int
    h = tl.program_id(1)  # int

    # Compute q vector for this (b, h): q[b, h, :]
    q_base = q_ptr + b * H * D + h * D
    q_vec = tl.zeros((D,), dtype=tl.float32)
    for d in range(0, D):
        q_vec[d] = tl.load(q_base + d).to(tl.float32)

    # Determine token range for this batch from kv_indptr
    start = tl.load(kv_indptr_ptr + b).to(tl.int32)
    end = tl.load(kv_indptr_ptr + b + 1).to(tl.int32)
    actual_num_tokens = end - start

    # First pass: streaming logsumexp over tokens
    m = -float("inf")
    sumexp = 0.0  # scalar float32
    ln2 = 0.6931471805599453
    for nn in range(0, N_TOTAL):
        valid = start + nn < end
        idx = tl.load(kv_indices_ptr + start + nn, mask=valid, other=0).to(tl.int32)

        kv_group = idx * num_kv_heads
        kv_head_offset = kv_head * D

        k_base = k_ptr + kv_group + kv_head_offset
        v_base = v_ptr + kv_group + kv_head_offset

        # Load k_vec and compute dot with q_vec
        k_vec = tl.zeros((D,), dtype=tl.float32)
        for d in range(0, D):
            k_vec[d] = tl.load(k_base + d).to(tl.float32)

        dot = 0.0
        for d in range(0, D):
            dot += q_vec[d] * k_vec[d]

        logit = dot * sm_scale
        new_m = tl.maximum(m, logit)
        sumexp = sumexp * tl.exp(m - new_m) + tl.exp(logit - new_m)
        m = new_m

    # lse for this (b, h)
    lse_val = m + tl.log(sumexp) / ln2
    tl.store(lse_ptr + b * H + h, lse_val)

    # Second pass: compute softmax per token and accumulate output
    out_base = out_ptr + b * H * D + h * D
    out_vec = tl.zeros((D,), dtype=tl.float32)
    for nn in range(0, N_TOTAL):
        valid = start + nn < end
        idx = tl.load(kv_indices_ptr + start + nn, mask=valid, other=0).to(tl.int32)

        kv_group = idx * num_kv_heads
        kv_head_offset = kv_head * D

        k_base = k_ptr + kv_group + kv_head_offset
        v_base = v_ptr + kv_group + kv_head_offset

        # Load v_vec
        v_vec = tl.zeros((D,), dtype=tl.float32)
        for d in range(0, D):
            v_vec[d] = tl.load(v_base + d).to(tl.float32)

        # Recompute dot and logits_scaled
        k_vec = tl.zeros((D,), dtype=tl.float32)
        for d in range(0, D):
            k_vec[d] = tl.load(k_base + d).to(tl.float32)
        dot = 0.0
        for d in range(0, D):
            dot += q_vec[d] * k_vec[d]
        logit = dot * sm_scale

        softmax = tl.exp(logit - m) / (sumexp * ln2)
        out_vec += softmax * v_vec

    # Store output vector for this (b, h)
    for d in range(0, D):
        tl.store(out_ptr + b * H * D + h * D + d, out_vec[d])
