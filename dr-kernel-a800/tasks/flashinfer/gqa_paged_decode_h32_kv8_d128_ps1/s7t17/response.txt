Rigorous diagnosis, reasoning, and plan

- The original PyTorch run function computes, for each batch b and query head h:
  - Token window: start = kv_indptr[b], end = kv_indptr[b+1], T = end - start.
  - For each token i in [start, end):
    - idx = kv_indices[start + i]
    - kv_head = h // (Nq // Nkv) = h // 4 (GQA mapping).
    - k_i = k_cache[idx, kv_head], v_i = v_cache[idx, kv_head] (shape [D]).
    - attn_i = dot(q[b, h], k_i), scaled = attn_i * sm_scale.
  - lse[b, h] = logsumexp(scaled) in natural log, then divided by log(2) (base-2 normalization).
  - softmax[i] = exp(scaled[i] - max(scaled)).
  - output[b, h, :] = softmax @ v_selected vector (sum over i of softmax[i] * v_i).

- Previous attempts had:
  - Host-side shape-unpacking errors (“too many values to unpack expected 3”). This happens when .shape is called on non-contiguous or unexpected-shaped tensors. We must ensure inputs are contiguous and on the right device, then use .shape safely.
  - “head_dim mismatch” assertions failed because D may not be 128 in some workloads. We should not assert; instead, implement kernels that work for arbitrary D and handle runtime strides.

- Numerical issues in the last submission:
  - Very large relative error (abs ~1.0–1.3, rel ~1–7k) indicates our output differs substantially from the reference. The reference uses torch.softmax and torch.matmul with PyTorch’s default precision (float32). Our Triton kernels must match this exactly. In Triton, we should:
    - Use float32 for computation.
    - Ensure we reproduce torch’s softmax (including dtype/device) and the matmul exactly. Any small deviation in accumulation order or dtype can lead to large discrepancies.
    - Avoid fusing softmax and matmul unless we can guarantee the exact same rounding behavior; safer is to compute softmax in Triton (as we did) and then perform the dot product via torch operations, but that would reintroduce torch, which is not allowed. Therefore, we will compute both softmax and the dot in Triton with float32 to match torch behavior closely.

- Design choices:
  - We keep two Triton kernels:
    1) lse_kernel: one program per (b, h). Loop over tokens; compute max and sum_exp; store lse[b, h] = log(sum_exp) + m divided by log(2).
    2) output_kernel: one program per (b, h). Recompute m and sum_exp to get softmax, then compute output vector elementwise by summing softmax[i] * v_i[j] for j in [0..D-1]. All math in float32; outputs stored as bfloat16.
  - Ensure tensors are contiguous and on CUDA. Pass shapes as runtime ints; D and Nq // Nkv passed as tl.constexpr so Triton can unroll small loops where applicable. While dynamic loops are used for T, D loops in Triton use tl.arange and are fine for D up to 1024 (common head dims). For D=128 or arbitrary D, this works.

- Preventing recurrence:
  - Explicitly make q, k_cache, v_cache, kv_indptr, kv_indices contiguous and on the same device.
  - No torch operations for softmax/matmul on outputs. All numeric work in Triton.
  - No hard assertions on head_dim; handle arbitrary D.

Performance notes
- The kernels parallelize over (b, h). For B in {1, 16, 64} and Nq=32, that’s 32 or 512–2048 programs. Each program loops over tokens. This gives reasonable parallelism. Using num_warps=4 and num_stages=2 is a decent starting point. Further optimizations (chunked vector reductions, fused kernels) can be added after correctness is verified.

import math
import torch
import triton
import triton.language as tl


@triton.jit
def lse_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    B: tl.constexpr,
    Nq: tl.constexpr,
    Nkv: tl.constexpr,
    D: tl.constexpr,
    gqa_ratio: tl.constexpr,  # Nq // Nkv (e.g., 4)
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio

    # Load q[b, h] vector of length D
    q_base = q_ptr + b * (Nq * D) + h * D
    q_vec = tl.load(q_base + tl.arange(0, D)).to(tl.float32)  # [D], f32

    # Token window [start, end)
    start = tl.load(indptr_ptr + b).to(tl.int32)     # int32
    end = tl.load(indptr_ptr + b + 1).to(tl.int32)   # int32
    T = end - start

    # Accumulate max and sum_exp for logsumexp
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)

    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)  # token index
        # k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_i = tl.load(k_base + tl.arange(0, D)).to(tl.float32)  # [D], f32
        attn = tl.sum(q_vec * k_i, axis=0)  # scalar f32
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        sum_exp += tl.exp(scaled - m)
        i += 1

    # lse = log(sum_exp) + m; divide by log(2) to match original
    log2 = 0.6931471805599453
    lse_val = tl.log(sum_exp) + m
    tl.store(lse_ptr + b * Nq + h, lse_val / log2)


@triton.jit
def output_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    v_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    out_ptr,        # *bf16, [B, Nq, D]
    B: tl.constexpr,
    Nq: tl.constexpr,
    Nkv: tl.constexpr,
    D: tl.constexpr,
    gqa_ratio: tl.constexpr,  # Nq // Nkv (e.g., 4)
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio

    # Load q[b, h] vector of length D
    q_base = q_ptr + b * (Nq * D) + h * D
    q_vec = tl.load(q_base + tl.arange(0, D)).to(tl.float32)  # [D], f32

    # Token window [start, end)
    start = tl.load(indptr_ptr + b).to(tl.int32)     # int32
    end = tl.load(indptr_ptr + b + 1).to(tl.int32)   # int32
    T = end - start

    # Recompute m and sum_exp for softmax normalization
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)

    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)  # token index
        # k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_i = tl.load(k_base + tl.arange(0, D)).to(tl.float32)  # [D], f32
        attn = tl.sum(q_vec * k_i, axis=0)  # scalar f32
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        sum_exp += tl.exp(scaled - m)
        i += 1

    # Output vector accumulation: out[b, h, j] = sum_i softmax[i] * v_i[j]
    out_base = out_ptr + b * (Nq * D) + h * D
    for j in range(D):
        acc = tl.zeros((), dtype=tl.float32)
        i = 0
        while i < T:
            idx = tl.load(indices_ptr + start + i).to(tl.int32)  # token index
            v_base = v_ptr + idx * (Nkv * D) + kv_head * D
            v_j = tl.load(v_base + j).to(tl.float32)  # scalar f32
            # softmax[i] = exp(scaled[i] - m) / sum_exp
            # We don't store scaled; recompute attn for softmax here
            k_base = k_ptr + idx * (Nkv * D) + kv_head * D
            k_i = tl.load(k_base + tl.arange(0, D)).to(tl.float32)  # [D], f32
            attn = tl.sum(q_vec * k_i, axis=0)  # scalar f32
            scaled_i = attn * sm_scale
            soft_i = tl.exp(scaled_i - m) / sum_exp
            acc += soft_i * v_j
            i += 1
        # Store as bfloat16
        tl.store(out_base + j, acc.to(tl.bfloat16))

    def forward(self, q, k_cache, v_cache, kv_indptr, kv_indices, sm_scale):
        # Ensure CUDA and contiguous; use the device of q
        device = q.device
        dtype = q.dtype  # typically bfloat16

        # Make sure inputs are on the same device and contiguous
        q = q.contiguous()
        k_cache = k_cache.contiguous()
        v_cache = v_cache.contiguous()
        kv_indptr = kv_indptr.contiguous().to(torch.int32)
        kv_indices = kv_indices.contiguous().to(torch.int32)

        # Shapes
        B, Nq, D = q.shape
        Np, Nkv, D_k = k_cache.shape  # squeeze dim=1 not used in original, D_k should match D
        assert D_k == D, "k_cache/v_cache last dim must match q's head_dim"
        Nkv_actual = k_cache.shape[1]
        assert Nkv_actual == Nkv, "num_kv_heads must match k_cache shape"

        # Output allocations
        output = torch.empty((B, Nq, D), dtype=torch.bfloat16, device=device)
        lse = torch.empty((B, Nq), dtype=torch.float32, device=device)

        # Launch lse kernel: one program per (b, h)
        grid = (B * Nq,)
        # Stride for q: q is [B, Nq, D], contiguous, strides: (Nq*D, D, 1)
        lse_kernel[grid](
            q, k_cache, kv_indptr, kv_indices, sm_scale, lse,
            B=B, Nq=Nq, Nkv=Nkv, D=D, gqa_ratio=Nq // Nkv,
            num_warps=4, num_stages=2,
        )

        # Launch output kernel: one program per (b, h)
        output_kernel[grid](
            q, k_cache, v_cache, kv_indptr, kv_indices, sm_scale, lse, output,
            B=B, Nq=Nq, Nkv=Nkv, D=D, gqa_ratio=Nq // Nkv,
            num_warps=4, num_stages=2,
        )

        return output, lse

- Parallelize across (b, h). For B in {1, 16, 64} and Nq=32, that’s up to 2048 programs. Use num_warps=4 and num_stages=2 as a starting point.
- The output kernel recomputes m and sum_exp; this is simple and robust. Further speedups can be considered after correctness is verified.

@triton.jit
def lse_kernel(
    q_ptr,          # *bf16, [B, Nq, D]
    k_ptr,          # *bf16, [Np, Nkv, D]
    indptr_ptr,     # *i32,  [B+1]
    indices_ptr,    # *i32,  [T_total]
    sm_scale,       # f32
    lse_ptr,        # *f32,  [B, Nq]
    B: tl.constexpr,
    Nq: tl.constexpr,
    Nkv: tl.constexpr,
    D: tl.constexpr,
    gqa_ratio: tl.constexpr,  # Nq // Nkv (e.g., 4)
):
    pid = tl.program_id(0)  # one program per (b, h)
    b = pid // Nq
    h = pid % Nq
    kv_head = h // gqa_ratio

    # Load q[b, h] vector of length D
    # q is [B, Nq, D], contiguous => strides: (Nq*D, D, 1)
    q_base = q_ptr + b * (Nq * D) + h * D
    q_vec = tl.load(q_base + tl.arange(0, D)).to(tl.float32)  # [D], f32

    # Token window [start, end)
    start = tl.load(indptr_ptr + b).to(tl.int32)     # int32
    end = tl.load(indptr_ptr + b + 1).to(tl.int32)   # int32
    T = end - start

    # Accumulate max and sum_exp for logsumexp
    m = tl.full((), -float("inf"), dtype=tl.float32)
    sum_exp = tl.zeros((), dtype=tl.float32)

    i = 0
    while i < T:
        idx = tl.load(indices_ptr + start + i).to(tl.int32)  # token index
        # k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_base = k_ptr + idx * (Nkv * D) + kv_head * D
        k_i = tl.load(k_base + tl.arange(0, D)).to(tl.float32)  # [D], f32
        attn = tl.sum(q_vec * k_i, axis=0)  # scalar f32
        scaled = attn * sm_scale
        m = tl.maximum(m, scaled)
        sum_exp += tl.exp(scaled - m)
        i += 1

    # lse = log(sum_exp) + m; divide by log(2) to match original
    log2 = 0.6931471805599453
    lse_val = tl.log(sum_exp) + m
    tl.store(lse_ptr + b * Nq + h, lse_val / log2)
