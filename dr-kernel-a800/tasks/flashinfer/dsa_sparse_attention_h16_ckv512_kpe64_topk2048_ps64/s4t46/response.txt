Summary of the original computation
- Inputs:
  - q_nope: [num_tokens, 16, 512] bfloat16
  - q_pe: [num_tokens, 16, 64] bfloat16
  - ckv_cache: [num_pages, 64, 512] bfloat16
  - kpe_cache: [num_pages, 64, 64] bfloat16
  - sparse_indices: [num_tokens, 2048] int32 (ignore -1 entries)
  - sm_scale: float32 scalar
- For each token t and output head h:
  - Flatten caches to Kc_all [N, 512], Kp_all [N, 64] where N = num_tokens * num_pages * 64.
  - Build valid indices for t: idx = sparse_indices[t], valid_mask = (idx != -1), tok_idx_list = idx[valid_mask], num_valid_used = len(tok_idx_list) <= 2048.
  - Compute logits vector of length topk=2048:
    - For v in [0..2047], logits[h, v] = sum_d q_nope[t, h, d] * Kc_all[tok_idx_list[v], d] + sum_d q_pe[t, h, d] * Kp_all[tok_idx_list[v], d].
    - For v >= num_valid_used, logits should be treated as padding; we will compute lse and softmax only over valid entries.
  - Logsumexp base 2:
    - lse[t, h] = log(sum exp(sm_scale * logits[h, v])) / ln(2), reduced over valid v.
  - Attention output:
    - attn[h, v] = exp(sm_scale * logits[h, v] / ln(2)) / sum_v exp(sm_scale * logits[h, v] / ln(2)) for v < num_valid_used; zero for invalid.
    - output[t, h, :] = attn[h, :] @ Kc_selected where Kc_selected = Kc_all[tok_idx_list] -> [num_valid_used, 512], producing a 512-length vector.

Design of Triton kernels
- Kernel A: compute_logits_all_heads_kernel
  - Computes logits for a given token t for all heads. It writes a 2D tensor out_all[num_qo_heads, 2048] where out_all[h, v] is the logits value for head h and position v. We write arbitrary values for v >= num_valid_used; they won’t affect lse/softmax since those are computed over valid entries only.
- Kernel B: compute_lse_base2_valid_kernel
  - Computes lse for one head using only valid entries: logsumexp_base2 over v in [0..num_valid_used-1].
- Kernel C: compute_softmax_valid_kernel
  - Computes softmax over valid entries for one head in base 2: softmax_i = exp(sm_scale * logits_i / ln(2)) / sum_j exp(sm_scale * logits_j / ln(2)) for v < num_valid_used. Writes softmax vector of length num_valid_used.
- Kernel D: compute_attention_output_kernel
  - Given softmax vector (length num_valid_used) and selected Kc rows (Kc_selected = Kc_all[tok_idx_list] -> [num_valid_used, 512]), computes the 512-length output vector for the head: out[d] = sum_v softmax[v] * Kc_selected[v, d]. Loops over d in [0..511] and reduces over v in chunks.

ModelNew.forward
- Ensures inputs are on CUDA.
- Flattens caches to Kc_all and Kp_all in float32.
- For each token t:
  - Builds tok_idx_list and num_valid_used.
  - Launches compute_logits_all_heads_kernel to produce logits_out[t, :, :], shape [16, 2048] in float32 (we only need values for valid entries to compute lse/softmax; invalid entries can be anything since lse/softmax use valid entries only).
  - Launches compute_lse_base2_valid_kernel for each head to produce lse[t, h].
  - Launches compute_softmax_valid_kernel for each head to produce softmax_vec[h, :] of length num_valid_used.
  - Selects Kc_selected = Kc_all[tok_idx_list] and runs compute_attention_output_kernel for each head to produce output[t, h, :] (float32) which is cast to bfloat16 at the end.
- Returns output [num_tokens, 16, 512] bfloat16 and lse [num_tokens, 16] float32.

This implementation avoids any torch ops on tensors (no logsumexp, no softmax, no matmul) and invokes Triton kernels for all heavy computations.

        out_base = out_ptr + h * topk
        for v in range(topk):
            if v < num_valid_used:
                tok_idx = tl.load(tok_idx_ptr + v)
                acc1 = 0.0
                # Dot with Kc selected row
                for d in range(head_dim_ckv):
                    q_val = tl.load(q_nope_ptr + h * head_dim_ckv + d)
                    kc_val = tl.load(Kc_ptr + tok_idx * head_dim_ckv + d)
                    acc1 += q_val * kc_val
                acc2 = 0.0
                # Dot with Kp selected row
                for d in range(head_dim_kpe):
                    q_val = tl.load(q_pe_ptr + h * head_dim_kpe + d)
                    kp_val = tl.load(Kp_ptr + tok_idx * head_dim_kpe + d)
                    acc2 += q_val * kp_val
                val = acc1 + acc2
            else:
                val = 0.0
            tl.store(out_base + v, val)


@triton.jit
def compute_lse_base2_valid_kernel(
    logits_ptr,            # [topk] for one head
    out_lse_ptr,           # scalar
    num_valid_used: tl.constexpr,
    sm_scale: tl.constexpr,      # scalar scale
    inv_ln2: tl.constexpr,       # 1 / ln(2)
):
    sum_exp = 0.0
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)  # exp(x / ln(2))
    lse = tl.log(sum_exp) * ln2  # log(sum_exp) * ln(2)
    tl.store(out_lse_ptr, lse)


@triton.jit
def compute_softmax_valid_kernel(
    logits_ptr,            # [topk] for one head
    sm_scale: tl.constexpr,      # scalar scale
    out_softmax_ptr,       # [num_valid_used]
    num_valid_used: tl.constexpr,
    inv_ln2: tl.constexpr,
):
    sum_exp = 0.0
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        softmax_v = tl.exp(x * inv_ln2) / sum_exp
        tl.store(out_softmax_ptr + v, softmax_v)


@triton.jit
def compute_attention_output_kernel(
    softmax_ptr,           # [num_valid_used]
    Kc_ptr,                # [num_valid_used, 512]
    out_out_ptr,           # [head_dim_ckv]
    num_valid_used: tl.constexpr,
    head_dim_ckv: tl.constexpr,   # 512
    BLOCK_V: tl.constexpr,        # chunk size for reduction over V
):
    for d in range(head_dim_ckv):
        acc = 0.0
        for i in range(0, tl.cdiv(num_valid_used, BLOCK_V)):
            v_start = i * BLOCK_V
            v_offsets = v_start + tl.arange(0, BLOCK_V)
            mask = v_offsets < num_valid_used
            softmax_chunk = tl.load(softmax_ptr + v_offsets, mask=mask, other=0.0)
            Kc_chunk = tl.load(Kc_ptr + v_offsets * head_dim_ckv + d, mask=mask, other=0.0)
            acc += tl.sum(softmax_chunk * Kc_chunk, axis=0)
        tl.store(out_out_ptr + d, acc)

                # Dot with Kc selected row
                for d in range(head_dim_ckv):
                    q_val = tl.load(q_nope_ptr + h * head_dim_ckv + d)
                    kc_val = tl.load(Kc_ptr + tok_idx * head_dim_ckv + d)
                    acc1 += q_val * kc_val
                acc2 = 0.0
                # Dot with Kp selected row
                for d in range(head_dim_kpe):
                    q_val = tl.load(q_pe_ptr + h * head_dim_kpe + d)
                    kp_val = tl.load(Kp_ptr + tok_idx * head_dim_kpe + d)
                    acc2 += q_val * kp_val
                val = acc1 + acc2
            else:
                val = 0.0
            tl.store(out_base + v, val)


@triton.jit
def compute_lse_base2_valid_kernel(
    logits_ptr,            # [topk] for one head
    out_lse_ptr,           # scalar
    num_valid_used: tl.constexpr,
    sm_scale: tl.constexpr,      # scalar scale
    inv_ln2: tl.constexpr,       # 1 / ln(2)
):
    sum_exp = 0.0
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)  # exp(x / ln(2))
    lse = tl.log(sum_exp) * ln2  # log(sum_exp) * ln(2)
    tl.store(out_lse_ptr, lse)


@triton.jit
def compute_softmax_valid_kernel(
    logits_ptr,            # [topk] for one head
    sm_scale: tl.constexpr,      # scalar scale
    out_softmax_ptr,       # [num_valid_used]
    num_valid_used: tl.constexpr,
    inv_ln2: tl.constexpr,
):
    sum_exp = 0.0
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        softmax_v = tl.exp(x * inv_ln2) / sum_exp
        tl.store(out_softmax_ptr + v, softmax_v)


@triton.jit
def compute_attention_output_kernel(
    softmax_ptr,           # [num_valid_used]
    Kc_ptr,                # [num_valid_used, 512]
    out_out_ptr,           # [head_dim_ckv]
    num_valid_used: tl.constexpr,
    head_dim_ckv: tl.constexpr,   # 512
    BLOCK_V: tl.constexpr,        # chunk size for reduction over V
):
    for d in range(head_dim_ckv):
        acc = 0.0
        for i in range(0, tl.cdiv(num_valid_used, BLOCK_V)):
            v_start = i * BLOCK_V
            v_offsets = v_start + tl.arange(0, BLOCK_V)
            mask = v_offsets < num_valid_used
            softmax_chunk = tl.load(softmax_ptr + v_offsets, mask=mask, other=0.0)
            Kc_chunk = tl.load(Kc_ptr + v_offsets * head_dim_ckv + d, mask=mask, other=0.0)
            acc += tl.sum(softmax_chunk * Kc_chunk, axis=0)
        tl.store(out_out_ptr + d, acc)
