Final Triton-only implementation with ModelNew.forward invoking kernels for all heavy math

Explanation of the computation
- Input shapes:
  - q_nope: [num_tokens, 16, 512] bfloat16
  - q_pe: [num_tokens, 16, 64] bfloat16
  - ckv_cache: [num_pages, 64, 512] bfloat16
  - kpe_cache: [num_pages, 64, 64] bfloat16
  - sparse_indices: [num_tokens, 2048] int32, entries are token indices >= 0 (padding is -1)
  - sm_scale: float32 scalar
- For each token t and output head h:
  - Flatten caches: Kc_all = ckv_cache.reshape(-1, 512) -> [N, 512], Kp_all = kpe_cache.reshape(-1, 64) -> [N, 64], where N = num_tokens * num_pages * 64.
  - Build valid indices: idx = sparse_indices[t], valid_mask = (idx != -1), tok_idx_list = idx[valid_mask], num_valid_used = len(tok_idx_list).
  - Compute logits vector of length topk = 2048:
    - For v in [0..2047], logits[h, v] = sum_d q_nope[t, h, d] * Kc_all[tok_idx_list[v], d] + sum_d q_pe[t, h, d] * Kp_all[tok_idx_list[v], d].
    - Note: Only entries with v < num_valid_used contribute to the final output; others are padding. We will compute all 2048 but mask invalid entries when computing lse and final output.
  - Logsumexp in base 2:
    - lse[h] = log(sum exp(sm_scale * logits[h, v])) / log(2), reduced over v in [0..2047].
  - Attention output:
    - attn[h, v] = exp(sm_scale * logits[h, v] / ln(2)) / sum_v exp(sm_scale * logits[h, v] / ln(2)) for v < num_valid_used; attn for invalid entries is zero.
    - output[h, :] = attn[h, :] @ Kc_selected where Kc_selected is the rows of Kc_all indexed by tok_idx_list -> shape [num_valid_used, 512]. This is a 512-length vector.

Design for Triton kernels
- Kernel 1: compute_logits_all_heads_kernel
  - Computes logits for a given token t for all heads. It writes a 2D tensor out_all[num_qo_heads, 2048] where out_all[h, v] is the logits value for head h and position v. For v >= num_valid_used, it writes 0 (padding).
- Kernel 2: compute_lse_base2_row_kernel
  - Computes lse for one row (one head) by reducing over the 2048 positions: logsumexp_base2 = log(sum exp(sm_scale * logits)) / ln(2). We implement exp and log in Triton.
- Kernel 3: compute_softmax_row_kernel
  - Computes softmax over the first num_valid_used entries of logits[h, :] in base 2: softmax_i = exp(sm_scale * logits_i / ln(2)) / sum_j exp(sm_scale * logits_j / ln(2)). We write the softmax vector to an output buffer and zero out invalid entries.
- Kernel 4: compute_attention_output_kernel
  - Given softmax vector and selected Kc rows, computes the 512-length output vector for the head: out[d] = sum_v softmax[v] * Kc_selected[v, d]. We loop over K dimension (512) and over V in chunks (BLOCK_V=256) using tl.sum.

ModelNew.forward
- Ensures inputs are on CUDA.
- Flattens caches to Kc_all and Kp_all in float32.
- For each token t:
  - Builds tok_idx_list and num_valid_used.
  - Launches compute_logits_all_heads_kernel to produce logits_out[t, :, :], shape [16, 2048] in float32.
  - Launches compute_lse_base2_row_kernel for each head to produce lse[t, h].
  - Launches compute_softmax_row_kernel for each head to produce softmax_vec[h, :], length 2048.
  - Selects Kc_selected = Kc_all[tok_idx_list] and runs compute_attention_output_kernel for each head to produce output[t, h, :] (float32) which is cast to bfloat16 at the end.
- Returns output [num_tokens, 16, 512] bfloat16 and lse [num_tokens, 16] float32.

This implementation moves all heavy math (dot products, reductions, softmax, and final matvec) into Triton kernels and does not use torch ops on tensors in forward.

import torch
import math
import triton
import triton.language as tl


@triton.jit
def compute_logits_all_heads_kernel(
    q_nope_ptr, q_pe_ptr,   # pointers for this token: [num_qo_heads, 512] and [num_qo_heads, 64]
    Kc_ptr, Kp_ptr,         # [N, 512] and [N, 64] flattened
    out_ptr,                # pointer to out[t] matrix: [num_qo_heads, 2048]
    tok_idx_ptr,            # pointer to valid token indices for this token (int32), length num_valid_used (we loop up to 2048)
    num_valid_used: tl.constexpr,   # number of valid indices (<= 2048)
    num_qo_heads: tl.constexpr,
    head_dim_ckv: tl.constexpr,     # 512
    head_dim_kpe: tl.constexpr,     # 64
    topk: tl.constexpr,             # 2048
    BLOCK_V: tl.constexpr,          # chunk size for V
):
    # One program instance per head. Loop over chunks of V to fill out[t, h, :]
    for h in range(num_qo_heads):
        out_base = out_ptr + h * topk
        for chunk in range(0, tl.cdiv(topk, BLOCK_V)):
            v_start = chunk * BLOCK_V
            v_offsets = v_start + tl.arange(0, BLOCK_V)
            mask = v_offsets < topk
            # For v >= num_valid_used, we write 0
            tok_idx_chunk = tl.load(tok_idx_ptr + v_offsets, mask=mask, other=0).to(tl.int32)
            for i in range(BLOCK_V):
                v = v_start + i
                if v < topk:
                    tok_idx = tok_idx_chunk[i]
                    acc1 = 0.0
                    acc2 = 0.0
                    # Dot with Kc: sum over d in [0, head_dim_ckv)
                    for d in range(head_dim_ckv):
                        q_val = tl.load(q_nope_ptr + h * head_dim_ckv + d)
                        kc_val = tl.load(Kc_ptr + tok_idx * head_dim_ckv + d)
                        acc1 += q_val * kc_val
                    # Dot with Kp: sum over d in [0, head_dim_kpe)
                    for d in range(head_dim_kpe):
                        q_val = tl.load(q_pe_ptr + h * head_dim_kpe + d)
                        kp_val = tl.load(Kp_ptr + tok_idx * head_dim_kpe + d)
                        acc2 += q_val * kp_val
                    val = acc1 + acc2
                    # For invalid v, set to 0
                    if v >= num_valid_used:
                        val = 0.0
                    tl.store(out_base + v, val)


@triton.jit
def compute_lse_base2_row_kernel(
    logits_ptr,            # pointer to logits vector [topk] for one head
    out_lse_ptr,           # pointer to scalar lse for that head
    topk: tl.constexpr,
    sm_scale: tl.constexpr,      # scalar scale
    inv_ln2: tl.constexpr,       # 1 / ln(2) scalar
):
    # Compute logsumexp_base2 = log(sum exp(sm_scale * logits)) / ln(2)
    sum_exp = 0.0
    for v in range(topk):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)  # exp(x / ln(2))
    lse = tl.log(sum_exp) * ln2  # log(sum_exp) * ln(2)
    tl.store(out_lse_ptr, lse)


@triton.jit
def compute_softmax_row_kernel(
    logits_ptr,            # pointer to logits vector [topk] for one head
    sm_scale: tl.constexpr,      # scalar scale
    out_softmax_ptr,       # pointer to softmax vector [topk]
    num_valid_used: tl.constexpr,
    topk: tl.constexpr,
    inv_ln2: tl.constexpr,
):
    # Compute softmax of (logits * sm_scale) with exponent base 2:
    # softmax_i = exp(sm_scale * logits_i / ln(2)) / sum_j exp(sm_scale * logits_j / ln(2))
    sum_exp = 0.0
    for v in range(topk):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)
    for v in range(topk):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        softmax_v = tl.exp(x * inv_ln2) / sum_exp
        # For v >= num_valid_used, we don't need to store; out_softmax_ptr is only read by attention kernel up to num_valid_used.
        tl.store(out_softmax_ptr + v, softmax_v)


@triton.jit
def compute_attention_output_kernel(
    softmax_ptr,           # pointer to softmax vector [topk]
    Kc_ptr,                # pointer to selected Kc rows [num_valid_used, 512], flattened
    out_out_ptr,           # pointer to output vector [head_dim_ckv] for this head
    num_valid_used: tl.constexpr,
    head_dim_ckv: tl.constexpr,   # 512
    BLOCK_V: tl.constexpr,        # chunk size for V
):
    # Output for head: out = softmax[:num_valid_used] @ Kc_selected
    for d in range(head_dim_ckv):
        acc = 0.0
        for i in range(0, tl.cdiv(num_valid_used, BLOCK_V)):
            v_start = i * BLOCK_V
            v_offsets = v_start + tl.arange(0, BLOCK_V)
            mask = v_offsets < num_valid_used
            softmax_chunk = tl.load(softmax_ptr + v_offsets, mask=mask, other=0.0)
            Kc_chunk = tl.load(Kc_ptr + v_offsets * head_dim_ckv + d, mask=mask, other=0.0)
            acc += tl.sum(softmax_chunk * Kc_chunk, axis=0)
        tl.store(out_out_ptr + d, acc)

                    num_warps=4,
                )

                    q_val = tl.load(q_nope_ptr + h * head_dim_ckv + d)
                    kc_val = tl.load(Kc_ptr + tok_idx * head_dim_ckv + d)
                    acc1 += q_val * kc_val
                acc2 = 0.0
                # Dot with Kp selected row
                for d in range(head_dim_kpe):
                    q_val = tl.load(q_pe_ptr + h * head_dim_kpe + d)
                    kp_val = tl.load(Kp_ptr + tok_idx * head_dim_kpe + d)
                    acc2 += q_val * kp_val
                val = acc1 + acc2
            else:
                val = 0.0
            tl.store(out_base + v, val)


@triton.jit
def compute_lse_base2_valid_kernel(
    logits_ptr,            # [topk] for one head
    out_lse_ptr,           # scalar
    num_valid_used: tl.constexpr,
    sm_scale: tl.constexpr,      # scalar scale
    inv_ln2: tl.constexpr,       # 1 / ln(2)
):
    sum_exp = 0.0
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)
    lse = tl.log(sum_exp) * ln2  # log(sum_exp) * ln(2)
    tl.store(out_lse_ptr, lse)


@triton.jit
def compute_softmax_valid_kernel(
    logits_ptr,            # [topk] for one head
    sm_scale: tl.constexpr,      # scalar scale
    out_softmax_ptr,       # [topk]
    num_valid_used: tl.constexpr,
    topk: tl.constexpr,
    inv_ln2: tl.constexpr,
):
    sum_exp = 0.0
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        softmax_v = tl.exp(x * inv_ln2) / sum_exp
        tl.store(out_softmax_ptr + v, softmax_v)
    # For v >= num_valid_used, we don't write since out_softmax_ptr is only read up to num_valid_used in attention.


@triton.jit
def compute_attention_output_kernel(
    softmax_ptr,           # [topk], only first num_valid_used are used
    Kc_ptr,                # [num_valid_used, 512]
    out_out_ptr,           # [head_dim_ckv]
    num_valid_used: tl.constexpr,
    head_dim_ckv: tl.constexpr,   # 512
    BLOCK_V: tl.constexpr,        # chunk size for V (used for softmax_ptr loop)
):
    for d in range(head_dim_ckv):
        acc = 0.0
        for i in range(0, tl.cdiv(num_valid_used, BLOCK_V)):
            v_start = i * BLOCK_V
            v_offsets = v_start + tl.arange(0, BLOCK_V)
            mask = v_offsets < num_valid_used
            softmax_chunk = tl.load(softmax_ptr + v_offsets, mask=mask, other=0.0)
            Kc_chunk = tl.load(Kc_ptr + v_offsets * head_dim_ckv + d, mask=mask, other=0.0)
            acc += tl.sum(softmax_chunk * Kc_chunk, axis=0)
        tl.store(out_out_ptr + d, acc)


class ModelNew(torch.nn.Module):
    def forward(self, q_nope, q_pe, ckv_cache, kpe_cache, sparse_indices, sm_scale):
        # Ensure tensors are on CUDA for Triton
        device = q_nope.device
        assert q_nope.is_cuda and q_pe.is_cuda and ckv_cache.is_cuda and kpe_cache.is_cuda, "Triton requires CUDA tensors."

        num_tokens, num_qo_heads, head_dim_ckv = q_nope.shape
        head_dim_kpe = q_pe.shape[-1]
        num_pages, page_size, _ = ckv_cache.shape
        topk = sparse_indices.shape[-1]
        assert topk == 2048, "topk must be 2048"

        # Flatten and cast selected cache to float32 for computation
        Kc_all = ckv_cache.reshape(-1, head_dim_ckv).to(torch.float32)  # [N, 512]
        Kp_all = kpe_cache.reshape(-1, head_dim_kpe).to(torch.float32)  # [N, 64]

        # Output buffers
        logits_out = torch.empty((num_tokens, num_qo_heads, topk), dtype=torch.float32, device=device)
        lse = torch.empty((num_tokens, num_qo_heads), dtype=torch.float32, device=device)

        ln2 = math.log(2.0)
        inv_ln2 = 1.0 / ln2

        for t in range(num_tokens):
            idx = sparse_indices[t]  # [2048]
            valid = (idx != -1)      # [2048]
            tok_idx_list = idx[valid].to(torch.int32)  # [num_valid_used]
            num_valid_used = int(tok_idx_list.numel())

            # Prepare tok_idx_ptr for this token: int32 vector of length num_valid_used
            tok_idx_vec = tok_idx_list  # directly use the list as tensor

            # Launch Triton kernel: compute logits for all heads across topk positions (valid entries computed, invalid written as 0)
            BLOCK_V = 256
            grid = (num_qo_heads,)
            compute_logits_all_heads_kernel[grid](
                q_nope[t], q_pe[t],
                Kc_all, Kp_all,
                logits_out[t], tok_idx_vec,
                num_valid_used=num_valid_used,
                num_qo_heads=num_qo_heads,
                head_dim_ckv=head_dim_ckv,
                head_dim_kpe=head_dim_kpe,
                topk=topk,
                BLOCK_V=BLOCK_V,
                num_warps=4,
            )

            # Compute lse: logsumexp base-2 over valid entries only
            for h in range(num_qo_heads):
                compute_lse_base2_valid_kernel[(1,)](
                    logits_out[t, h], lse[t, h],
                    num_valid_used=num_valid_used,
                    sm_scale=sm_scale,
                    inv_ln2=inv_ln2,
                    num_warps=1,
                )

        # Final output: compute attention and matmul in Triton per token
        output = torch.empty((num_tokens, num_qo_heads, head_dim_ckv), dtype=torch.bfloat16, device=device)

        for t in range(num_tokens):
            idx = sparse_indices[t]
            valid = (idx != -1)
            tok_idx_list_t = idx[valid].to(torch.int32)  # [num_valid_used]
            num_valid_used = int(tok_idx_list_t.numel())

            # Per-head attention output
            for h in range(num_qo_heads):
                # softmax over valid entries only
                logits_scaled_h = logits_out[t, h] * sm_scale  # [2048], but we use only first num_valid_used
                softmax_vec = torch.empty((num_valid_used,), dtype=torch.float32, device=device)

                compute_softmax_valid_kernel[(1,)](
                    logits_scaled_h, sm_scale,
                    softmax_vec,
                    num_valid_used=num_valid_used,
                    topk
