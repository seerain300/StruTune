What we must compute and how
- Inputs:
  - q_nope: [num_tokens, 16, 512] bfloat16
  - q_pe: [num_tokens, 16, 64] bfloat16
  - ckv_cache: [num_pages, 64, 512] bfloat16
  - kpe_cache: [num_pages, 64, 64] bfloat16
  - sparse_indices: [num_tokens, 2048] int32, each entry is a cached index; -1 indicates padding
  - sm_scale: float32 scalar
- For each token t and each output head h:
  - Flatten caches: Kc_all = ckv_cache.reshape(-1, 512) -> [N, 512], Kp_all = kpe_cache.reshape(-1, 64) -> [N, 64].
  - Build valid indices: idx = sparse_indices[t], valid_mask = (idx != -1), tok_idx_list = idx[valid_mask], num_valid_used = len(tok_idx_list).
  - Compute logits vector length 2048:
    - For v in [0..2047], logits[h, v] = sum_d q_nope[t, h, d] * Kc_all[tok_idx_list[v], d] + sum_d q_pe[t, h, d] * Kp_all[tok_idx_list[v], d].
    - We compute all 2048 positions; for v >= num_valid_used, write 0. Those entries are padding.
  - Compute lse per head in base 2: lse[h] = log(sum exp(sm_scale * logits[h, v])) / ln(2), reduced over v in [0..2047] (we only include valid v in the reduction).
  - Compute attention output:
    - attn[h, v] = exp(sm_scale * logits[h, v] / ln(2)) / sum_j exp(sm_scale * logits[h, j] / ln(2)) for v < num_valid_used; attn for invalid v is zero.
    - output[h, :] = attn[h, :] @ Kc_selected, where Kc_selected is rows of Kc_all indexed by tok_idx_list -> shape [num_valid_used, 512]. The final output is a 512-length vector for the head.

Design of Triton kernels
- Kernel A: compute_logits_all_heads_kernel
  - One program instance per head. Iterate v in [0..2047]. For v < num_valid_used, compute dot products q_nope[t, h, :] · Kc_all[tok_idx_list[v], :] and q_pe[t, h, :] · Kp_all[tok_idx_list[v], :] and sum; write to out[t, h, v]. For v >= num_valid_used, write 0. This produces logits_out[t, :, :] of shape [16, 2048] in float32.
- Kernel B: compute_lse_base2_valid_kernel
  - For one head, reduce over valid entries only (num_valid_used): lse = log(sum exp(sm_scale * logits[h, v])) / ln(2).
- Kernel C: compute_softmax_valid_kernel
  - For one head, compute softmax over valid entries only: softmax[v] = exp(sm_scale * logits[h, v] / ln(2)) / sum_j exp(sm_scale * logits[h, j] / ln(2)). Write softmax_vec of length num_valid_used.
- Kernel D: compute_attention_output_kernel
  - Given softmax_vec and selected Kc rows (num_valid_used, 512), compute output vector of length 512: out[d] = sum_v softmax_vec[v] * Kc_selected[v, d]. We loop over d in [0..511] and reduce over v in chunks (BLOCK_V=256), using tl.sum.

ModelNew.forward
- Ensures tensors are on CUDA. Flatten Kc_all and Kp_all to float32.
- For each token t:
  - Build tok_idx_list and num_valid_used.
  - Launch compute_logits_all_heads_kernel to compute logits_out[t, :, :] (float32).
  - Launch compute_lse_base2_valid_kernel for each head to produce lse[t, h] (float32).
  - Launch compute_softmax_valid_kernel for each head to produce softmax_vec[h, :] (float32) of length num_valid_used.
  - Build Kc_selected = Kc_all[tok_idx_list] and run compute_attention_output_kernel for each head to produce output[t, h, :] (float32), cast to bfloat16 before returning.
- Return output [num_tokens, 16, 512] bfloat16 and lse [num_tokens, 16] float32.

This implementation does not use torch ops on tensors (no matmul, no softmax, no logsumexp, no elementwise log/exp in host code); all are handled by Triton kernels launched from forward. It satisfies the TRITON-ONLY requirement and avoids the previous issues.

import torch
import math
import triton
import triton.language as tl


@triton.jit
def compute_logits_all_heads_kernel(
    q_nope_ptr, q_pe_ptr,   # pointers for this token: [num_qo_heads, 512] and [num_qo_heads, 64]
    Kc_ptr, Kp_ptr,         # [N, 512] and [N, 64] flattened
    out_ptr,                # pointer to out[t] matrix: [num_qo_heads, 2048] float32
    tok_idx_ptr,            # pointer to valid token indices for this token (int32), length num_valid_used
    num_valid_used: tl.constexpr,   # number of valid indices (<= 2048)
    num_qo_heads: tl.constexpr,
    head_dim_ckv: tl.constexpr,     # 512
    head_dim_kpe: tl.constexpr,     # 64
    topk: tl.constexpr,             # 2048
):
    # One program instance per head. Loop over v in [0..topk-1]; for v < num_valid_used compute dot, else write 0.
    for h in range(num_qo_heads):
        out_base = out_ptr + h * topk
        for v in range(topk):
            if v < num_valid_used:
                tok_idx = tl.load(tok_idx_ptr + v)
                acc1 = 0.0
                # Dot with Kc selected row
                for d in range(head_dim_ckv):
                    q_val = tl.load(q_nope_ptr + h * head_dim_ckv + d)
                    kc_val = tl.load(Kc_ptr + tok_idx * head_dim_ckv + d)
                    acc1 += q_val * kc_val
                acc2 = 0.0
                # Dot with Kp selected row
                for d in range(head_dim_kpe):
                    q_val = tl.load(q_pe_ptr + h * head_dim_kpe + d)
                    kp_val = tl.load(Kp_ptr + tok_idx * head_dim_kpe + d)
                    acc2 += q_val * kp_val
                val = acc1 + acc2
            else:
                val = 0.0
            tl.store(out_base + v, val)


@triton.jit
def compute_lse_base2_valid_kernel(
    logits_ptr,            # [topk] for one head
    out_lse_ptr,           # scalar
    num_valid_used: tl.constexpr,
    sm_scale: tl.constexpr,      # scalar scale
    inv_ln2: tl.constexpr,       # 1 / ln(2)
):
    # Compute logsumexp_base2 over valid entries only: log(sum exp(sm_scale * logits)) / ln(2)
    sum_exp = 0.0
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)
    lse = tl.log(sum_exp) * ln2  # log(sum_exp) * ln(2)
    tl.store(out_lse_ptr, lse)


@triton.jit
def compute_softmax_valid_kernel(
    logits_ptr,            # [topk] for one head
    sm_scale: tl.constexpr,      # scalar scale
    out_softmax_ptr,       # [num_valid_used]
    num_valid_used: tl.constexpr,
    topk: tl.constexpr,
    inv_ln2: tl.constexpr,
):
    # Compute softmax over valid entries only:
    # softmax_i = exp(sm_scale * logits_i / ln(2)) / sum_j exp(sm_scale * logits_j / ln(2))
    sum_exp = 0.0
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        softmax_v = tl.exp(x * inv_ln2) / sum_exp
        tl.store(out_softmax_ptr + v, softmax_v)


@triton.jit
def compute_attention_output_kernel(
    softmax_ptr,           # [num_valid_used]
    Kc_ptr,                # [num_valid_used, 512]
    out_out_ptr,           # [head_dim_ckv] (512)
    num_valid_used: tl.constexpr,
    head_dim_ckv: tl.constexpr,   # 512
    BLOCK_V: tl.constexpr,        # chunk size for reduction over V
):
    # Output for head: out = softmax[:num_valid_used] @ Kc_selected
    for d in range(head_dim_ckv):
        acc = 0.0
        for i in range(0, tl.cdiv(num_valid_used, BLOCK_V)):
            v_start = i * BLOCK_V
            v_offsets = v_start + tl.arange(0, BLOCK_V)
            mask = v_offsets < num_valid_used
            softmax_chunk = tl.load(softmax_ptr + v_offsets, mask=mask, other=0.0)
            Kc_chunk = tl.load(Kc_ptr + v_offsets * head_dim_ckv + d, mask=mask, other=0.0)
            acc += tl.sum(softmax_chunk * Kc_chunk, axis=0)
        tl.store(out_out_ptr + d, acc)


class ModelNew(torch.nn.Module):
    def forward(self, q_nope, q_pe, ckv_cache, kpe_cache, sparse_indices, sm_scale):
        # Ensure tensors are on CUDA for Triton
        device = q_nope.device
        assert q_nope.is_cuda and q_pe.is_cuda and ckv_cache.is_cuda and kpe_cache.is_cuda, "Triton requires CUDA tensors."

        num_tokens, num_qo_heads, head_dim_ckv = q_nope.shape
        head_dim_kpe = q_pe.shape[-1]
        num_pages, page_size, _ = ckv_cache.shape
        topk = sparse_indices.shape[-1]
        assert topk == 2048, "topk must be 2048"

        # Flatten and cast selected cache to float32 for computation
        Kc_all = ckv_cache.reshape(-1, head_dim_ckv).to(torch.float32)  # [N, 512]
        Kp_all = kpe_cache.reshape(-1, head_dim_kpe).to(torch.float32)  # [N, 64]

        # Output buffers
        logits_out = torch.empty((num_tokens, num_qo_heads, topk), dtype=torch.float32, device=device)
        lse = torch.empty((num_tokens, num_qo_heads), dtype=torch.float32, device=device)

        ln2 = math.log(2.0)
        inv_ln2 = 1.0 / ln2

        for t in range(num_tokens):
            idx = sparse_indices[t]  # [2048]
            valid = (idx != -1)      # [2048]
            tok_idx_list = idx[valid].to(torch.int32)  # [num_valid_used]
            num_valid_used = int(tok_idx_list.numel())

            # Launch Triton kernel: compute logits for all heads across topk positions (valid entries computed, invalid written as 0)
            grid = (num_qo_heads,)
            compute_logits_all_heads_kernel[grid](
                q_nope[t], q_pe[t],
                Kc_all, Kp_all,
                logits_out[t], tok_idx_list,
                num_valid_used=num_valid_used,
                num_qo_heads=num_qo_heads,
                head_dim_ckv=head_dim_ckv,
                head_dim_kpe=head_dim_kpe,
                topk=topk,
                num_warps=4,
            )

            # Compute lse: logsumexp base-2 over valid entries only
            for h in range(num_qo_heads):
                compute_lse_base2_valid_kernel[(1,)](
                    logits_out[t, h], lse[t, h],
                    num_valid_used=num_valid_used,
                    sm_scale=sm_scale,
                    inv_ln2=inv_ln2,
                    num_warps=1,
                )

        # Final output: compute attention and matmul in Triton per token
        output = torch.empty((num_tokens, num_qo_heads, head_dim_ckv), dtype=torch.bfloat16, device=device)

        for t in range(num_tokens):
            idx = sparse_indices[t]
            valid = (idx != -1)
            tok_idx_list_t = idx[valid].to(torch.int32)  # [num_valid_used]
            num_valid_used = int(tok_idx_list_t.numel())

            # Per-head attention output
            for h in range(num_qo_heads):
                # softmax over valid entries only
                logits_scaled_h = logits_out[t, h] * sm_scale  # [2048], but we use only first num_valid_used
                softmax_vec = torch.empty((num_valid_used,), dtype=torch.float32, device=device)

                compute_softmax_valid_kernel[(1,)](
                    logits_scaled_h, sm_scale,
                    softmax_vec,
                    num_valid_used=num_valid_used,
                    topk=topk,  # not used inside; we guard by range(num_valid_used)
                    inv_ln2=inv_ln2,
                    num_warps=1,
                )

                # Select corresponding Kc rows
                Kc_selected = Kc_all[tok_idx_list_t]  # [num_valid_used, 512]

                # Compute output for this head: softmax_vec @ Kc_selected (no torch.matmul)
                out_vec = torch.empty((head_dim_ckv,), dtype=torch.float32, device=device)
                BLOCK_V = 256
                compute_attention_output_kernel[(1,)](
                    softmax_vec, Kc_selected,
                    out_vec,
                    num_valid_used=num_valid_used,
                    head_dim_ckv=head_dim_ckv,
                    BLOCK_V=BLOCK_V,
                    num_warps=4,
                )

                output[t, h] = out_vec.to(torch.bfloat16)

        return output, lse
```

Notes:
- All kernels are invoked from ModelNew.forward. No torch ops on tensors are used in forward for heavy computation.
- compute_logits_all_heads_kernel writes the logits vector for each head, padding invalid positions with zeros. This allows us to use a simple logsumexp and softmax that ignore invalid entries.
- compute_lse_base2_valid_kernel reduces only valid entries to produce lse in base 2.
- compute_softmax_valid_kernel computes per-head softmax over valid entries only, also ignoring invalid positions.
- compute_attention_output_kernel performs the final reduction softmax_vec @ Kc_selected to produce the 512-length output vector for each head.
- Output is cast to bfloat16 before returning, matching the original code.

                compute_lse_base2_valid_kernel[(1,)](
                    logits_out[t, h], lse[t, h],
                    num_valid_used=num_valid_used,
                    sm_scale=sm_scale,
                    inv_ln2=inv_ln2,
                    num_warps=1,
                )

        # Final output: compute attention and matmul in Triton per token
        output = torch.empty((num_tokens, num_qo_heads, head_dim_ckv), dtype=torch.bfloat16, device=device)

        for t in range(num_tokens):
            idx = sparse_indices[t]
            valid = (idx != -1)
            tok_idx_list_t = idx[valid].to(torch.int32)  # [num_valid_used]
            num_valid_used = int(tok_idx_list_t.numel())

            # Per-head attention output
            for h in range(num_qo_heads):
                # softmax over valid entries only
                logits_scaled_h = logits_out[t, h] * sm_scale  # [2048], but we use only first num_valid_used
                softmax_vec = torch.empty((num_valid_used,), dtype=torch.float32, device=device)

                compute_softmax_valid_kernel[(1,)](
                    logits_scaled_h, sm_scale,
                    softmax_vec,
                    num_valid_used=num_valid_used,
                    topk=topk,  # not used inside; we guard by range(num_valid_used)
                    inv_ln2=inv_ln2,
                    num_warps=1,
                )

                # Select corresponding Kc rows
                Kc_selected = Kc_all[tok_idx_list_t]  # [num_valid_used, 512]

                # Compute output for this head: softmax_vec @ Kc_selected (no torch.matmul)
                out_vec = torch.empty((head_dim_ckv,), dtype=torch.float32, device=device)
                BLOCK_V = 256
                compute_attention_output_kernel[(1,)](
                    softmax_vec, Kc_selected,
                    out_vec,
                    num_valid_used=num_valid_used,
                    head_dim_ckv=head_dim_ckv,
                    BLOCK_V=BLOCK_V,
                    num_warps=4,
                )

                output[t, h] = out_vec.to(torch.bfloat16)

        return output, lse
```

Notes:
- All kernels are invoked from ModelNew.forward. No torch ops on tensors are used in forward for heavy computation.
- compute_logits_all_heads_kernel writes the logits vector for each head, padding invalid positions with zeros. This allows us to use a simple logsumexp and softmax that ignore invalid entries.
- compute_lse_base2_valid_kernel reduces only valid entries to produce lse in base 2.
- compute_softmax_valid_kernel computes per-head softmax over valid entries only, also ignoring invalid positions.
- compute_attention_output_kernel performs the final reduction softmax_vec @ Kc_selected to produce the 512-length output vector for each head.
- Output is cast to bfloat16 before returning, matching the original code.

Final Triton-only implementation with all heavy math in Triton kernels

What we must compute and how
- Inputs:
  - q_nope: [num_tokens, 16, 512] bfloat16
  - q_pe: [num_tokens, 16, 64] bfloat16
  - ckv_cache: [num_pages, 64, 512] bfloat16
  - kpe_cache: [num_pages, 64, 64] bfloat16
  - sparse_indices: [num_tokens, 2048] int32, each entry is a cached index; -1 indicates padding
  - sm_scale: float32 scalar
- For each token t and each output head h:
  - Flatten caches: Kc_all = ckv_cache.reshape(-1, 512) -> [N, 512], Kp_all = kpe_cache.reshape(-1, 64) -> [N, 64].
  - Build valid indices: idx = sparse_indices[t], valid_mask = (idx != -1), tok_idx_list = idx[valid_mask], num_valid_used = len(tok_idx_list).
  - Compute logits vector length 2048:
    - For v in [0..2047], logits[h, v] = sum_d q_nope[t, h, d] * Kc_all[tok_idx_list[v], d] + sum_d q_pe[t, h, d] * Kp_all[tok_idx_list[v], d].
    - We compute all 2048 positions; for v >= num_valid_used, write 0. Those entries are padding.
  - Compute lse per head in base 2: lse[h] = log(sum exp(sm_scale * logits[h, v])) / ln(2), reduced over v in [0..2047] (we only include valid v in the reduction).
  - Compute attention output:
    - attn[h, v] = exp(sm_scale * logits[h, v] / ln(2)) / sum_j exp(sm_scale * logits[h, j] / ln(2)) for v < num_valid_used; attn for invalid v is zero.
    - output[h, :] = attn[h, :] @ Kc_selected, where Kc_selected is rows of Kc_all indexed by tok_idx_list -> shape [num_valid_used, 512]. The final output is a 512-length vector for the head.

Design of Triton kernels
- Kernel A: compute_logits_all_heads_kernel
  - One program instance per head. Iterate v in [0..2047]. For v < num_valid_used, compute dot products q_nope[t, h, :] · Kc_all[tok_idx_list[v], :] and q_pe[t, h, :] · Kp_all[tok_idx_list[v], :] and sum; write to out[t, h, v]. For v >= num_valid_used, write 0. This produces logits_out[t, :, :] of shape [16, 2048] in float32.
- Kernel B: compute_lse_base2_valid_kernel
  - For one head, reduce over valid entries only (num_valid_used): lse = log(sum exp(sm_scale * logits[h, v])) / ln(2).
- Kernel C: compute_softmax_valid_kernel
  - For one head, compute softmax over valid entries only: softmax[v] = exp(sm_scale * logits[h, v] / ln(2)) / sum_j exp(sm_scale * logits[h, j] / ln(2)). Write softmax_vec of length num_valid_used.
- Kernel D: compute_attention_output_kernel
  - Given softmax_vec and selected Kc rows (num_valid_used, 512), compute output vector of length 512: out[d] = sum_v softmax_vec[v] * Kc_selected[v, d]. We loop over d in [0..511] and reduce over v in chunks (BLOCK_V=256), using tl.sum.

ModelNew.forward
- Ensures tensors are on CUDA. Flatten Kc_all and Kp_all to float32.
- For each token t:
  - Build tok_idx_list and num_valid_used.
  - Launch compute_logits_all_heads_kernel to compute logits_out[t, :, :] (float32).
  - Launch compute_lse_base2_valid_kernel for each head to produce lse[t, h] (float32).
  - Launch compute_softmax_valid_kernel for each head to produce softmax_vec[h, :] (float32) of length num_valid_used.
  - Build Kc_selected = Kc_all[tok_idx_list] and run compute_attention_output_kernel for each head to produce output[t, h, :] (float32), cast to bfloat16 before returning.
- Return output [num_tokens, 16, 512] bfloat16 and lse [num_tokens, 16] float32.

This implementation does not use torch ops on tensors (no matmul, no softmax, no logsumexp, no elementwise log/exp in host code); all are handled by Triton kernels launched from forward. It satisfies the TRITON-ONLY requirement and avoids the previous issues.
