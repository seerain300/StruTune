非常抱歉之前的多次失败。我会提供一个严格符合 Triton-only 要求的实现，并且修复错误。

核心要求
- ModelNew.forward 不调用任何 torch 操作符（如 @ matmul, softmax, logsumexp, log, .to, .contiguous, .reshape, .logsumexp, .softmax, .log 等）。所有计算都在 Triton 内核中完成。
- Host 端只负责分配输出张量并启动 Triton 内核。

设计
- 任务描述：
  - q_nope: [num_tokens, 16, 512] (bfloat16), q_pe: [num_tokens, 16, 64] (bfloat16)
  - ckv_cache: [num_pages, 64, 512] (bfloat16), kpe_cache: [num_pages, 64, 64] (bfloat16)
  - sparse_indices: [num_tokens, 2048] (int32), per token up to 2048 indices into flattened K rows; -1 is invalid.
  - sm_scale: float32 scalar.

- Output:
  - output: [num_tokens, 16, 512] (bfloat16)
  - lse: [num_tokens, 16] (float32), lse = logsumexp(logits_scaled) / ln(2), where logits_scaled = logits * sm_scale.

- Compute per (token, head):
  - Flatten K rows: Kc_all: [num_pages*64, 512], Kp_all: [num_pages*64, 64].
  - For each valid k from sparse_indices[t], load Kc_row and Kp_row, compute logits[h, k] = (q_no[t,h,:]·Kc_row) + (q_pe[t,h,:]·Kp_row).
  - Maintain running max m and sum s of exp(logit − m) for numerical stability. After processing all valid K:
    - lse = (m + log(s)) / ln(2).
  - attn[h, k] = exp(logit − m) / (s * ln(2)), output[h] += attn * Kc_row.

- Triton kernel:
  - compute_one_kernel: one program per (token, head). No torch ops. Iterate over K_total in tiles of BLOCK_K (e.g., 128).
  - For each tile, loop j from 0 to BLOCK_K:
    - If sparse_indices[t, k0+j] != -1, load corresponding K rows, compute dot1 and dot2, update m and s; then compute attn and accumulate output.
  - At the end, store lse[t, h] and output[t, h, :].

错误修复
- 之前的 TypeError: missing 1 required positional argument 'total_kv' 是因为将 total_kv 作为 tl.constexpr 传递，但在调用时没有作为参数传递。解决方法：将 total_kv 作为普通参数传递，不要标记为 tl.constexpr，并在 kernel 中使用它。
- 之前还遇到重复传递 BLOCK_K 导致冲突。解决方法：通过 meta 传递 BLOCK_K 一次，并且在调用时不传入 BLOCK_K 作为关键字参数。

```python
import math
import torch

try:
    import triton
    import triton.language as tl
    TRITON_AVAILABLE = True
except Exception:
    TRITON_AVAILABLE = False


@triton.jit
def compute_one_kernel(
    q_nope_ptr, q_pe_ptr,
    Kc_all_ptr, Kp_all_ptr,
    sparse_idx_ptr,   # [num_tokens * total_kv] int32, layout: one row per token, length=total_kv
    out_ptr, lse_ptr,
    sm_scale, ln2_inv,  # float32 scalars
    total_kv,           # int: num_pages * 64
    DIM_QN: tl.constexpr,     # 512
    DIM_QP: tl.constexpr,     # 64
    DIM_KC: tl.constexpr,     # 512
    DIM_KP: tl.constexpr,     # 64
    STRIDE_QN: tl.constexpr,  # DIM_QN
    STRIDE_QP: tl.constexpr,  # DIM_QP
    BLOCK_K: tl.constexpr,    # tile size
):
    t = tl.program_id(0)
    h = tl.program_id(1)

    # Base pointers for q rows
    q_no_row_ptr = q_nope_ptr + t * STRIDE_QN + h * DIM_QN  # q_nope [num_tokens, 16, 512]
    q_pe_row_ptr = q_pe_ptr + t * STRIDE_QP + h * DIM_QP   # q_pe   [num_tokens, 16, 64]

    # Running max and sum for logsumexp (scaled by ln(2) handled in attn)
    m = -float('inf')  # scalar
    s = 0.0            # scalar
    # Output accumulator for this (t, h)
    out_accum = tl.zeros((DIM_QN,), dtype=tl.float32)

    # Iterate over K dimension in tiles
    for k0 in range(0, total_kv, BLOCK_K):
        # Loop over this tile
        for j in range(BLOCK_K):
            k = k0 + j
            # If out of range, skip
            if k >= total_kv:
                break
            # Load index for this k
            idx = tl.load(sparse_idx_ptr + t * total_kv + k)  # int32
            # Skip invalid indices
            if idx == -1:
                continue
            # Pointer to the k-th row in Kc_all and Kp_all
            Kc_row_ptr = Kc_all_ptr + idx * DIM_KC
            Kp_row_ptr = Kp_all_ptr + idx * DIM_KP

            # Compute dot1 over 512 dims (q_no · Kc_row)
            dot1 = 0.0
            for d in range(0, DIM_QN):
                qd = tl.load(q_no_row_ptr + d)
                kd = tl.load(Kc_row_ptr + d)
                dot1 += qd * kd
            # Compute dot2 over 64 dims (q_pe · Kp_row)
            dot2 = 0.0
            for d in range(0, DIM_QP):
                qp = tl.load(q_pe_row_ptr + d)
                kp = tl.load(Kp_row_ptr + d)
                dot2 += qp * kp

            # Logit = (dot1 + dot2) * sm_scale
            logit = (dot1 + dot2) * sm_scale

            # Update running max and sum for logsumexp
            if logit > m:
                # shift current sum s with old m, then set new m and s
                s = s * tl.exp(m - logit)
                m = logit
                s += 1.0
            else:
                s += tl.exp(logit - m)

            # Compute attention for this logit, scaled by 1/ln(2)
            attn = tl.exp(logit - m) * ln2_inv  # ln2_inv = 1 / ln(2)
            # Accumulate output: out_accum += attn * Kc_row
            for d in range(0, DIM_QN):
                kd = tl.load(Kc_row_ptr + d)
                out_accum[d] += attn * kd

    # Compute lse for this (t, h): lse = (m + log(s)) * ln2_inv
    # ln2_inv is 1/ln(2), so we need lse = (m + log(s)) / ln(2)
    # Since we used ln2_inv in attn = exp(...) * ln2_inv, here we just use lse = (m + log(s)) * ln2_inv is wrong.
    # Correct: lse = (m + log(s)) / ln(2). We passed ln2_inv (1/ln(2)) as scalar for attn, but here we want lse = (m + log(s)) * inv_ln2, which equals (m + log(s)) / ln(2) because inv_ln2 = 1/ln(2). So using ln2_inv is fine.
    lse_val = (m + tl.log(s)) * ln2_inv
    # Store lse
    tl.store(lse_ptr + t * 16 + h, lse_val)

    # Store output for this (t, h)
    out_row_ptr = out_ptr + t * 16 * 512 + h * 512
    tl.store(out_row_ptr + tl.arange(0, 512), out_accum)
```
