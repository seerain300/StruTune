Final Triton-only implementation that invokes kernels for all heavy math

Overview of the original computation
- Inputs:
  - q_nope: [num_tokens, 16, 512], bfloat16
  - q_pe: [num_tokens, 16, 64], bfloat16
  - ckv_cache: [num_pages, 64, 512], bfloat16
  - kpe_cache: [num_pages, 64, 64], bfloat16
  - sparse_indices: [num_tokens, 2048], int32 (each entry is a cached token index; -1 means padding)
  - sm_scale: float32 scalar
- For each token t and output head h:
  - Flatten caches: Kc_all = ckv_cache.reshape(-1, 512) and Kp_all = kpe_cache.reshape(-1, 64). Total rows N = num_tokens * num_pages * 64.
  - Valid indices: idx = sparse_indices[t]; valid_mask = (idx != -1); tok_idx_list = idx[valid_mask]; num_valid_used = len(tok_idx_list).
  - Compute logits vector of length topk = 2048:
    - For v in [0..2047], logits[h, v] = sum_d q_nope[t, h, d] * Kc_all[tok_idx_list[v], d] + sum_d q_pe[t, h, d] * Kp_all[tok_idx_list[v], d].
    - Only entries v < num_valid_used contribute to the output; we write zeros for v >= num_valid_used (padding).
  - Logsumexp in base 2:
    - lse[h] = log(sum exp(sm_scale * logits[h, v])) / log(2), reduced over v in [0..2047]. The reference uses all 2048 entries, but invalid entries are zeros, so they don’t affect the sum.
  - Attention output:
    - attn[h, v] = exp(sm_scale * logits[h, v] / ln(2)) / sum_w exp(sm_scale * logits[h, w] / ln(2)) for v < num_valid_used (softmax over valid entries). Invalid entries are ignored in softmax.
    - output[h, :] = attn[h, :] @ Kc_selected, where Kc_selected is the rows of Kc_all indexed by tok_idx_list, shape [num_valid_used, 512]. Final vector is 512-dimensional.

Plan for Triton kernels
- Kernel 1: compute_logits_all_heads_kernel
  - Inputs: q_nope[t], q_pe[t], Kc_all, Kp_all, out_ptr for logits, tok_idx_ptr for valid indices, meta constants.
  - For each head h, loop over v in [0..topk-1]:
    - If v < num_valid_used: load tok_idx = tok_idx_ptr[v], compute acc1 = q_nope[t,h,:] · Kc_all[tok_idx,:] and acc2 = q_pe[t,h,:] · Kp_all[tok_idx,:], store acc1+acc2 into out[t,h,v].
    - Else: store 0.0. This writes a complete logits vector of length 2048 per head, with zeros for padding.
- Kernel 2: compute_lse_base2_valid_kernel
  - Inputs: logits vector for one head (length 2048), num_valid_used, sm_scale, inv_ln2 (1/ln(2)).
  - Compute sum_exp = sum_v exp(sm_scale * logits[v] * inv_ln2) over v in [0..2047]. Since invalid entries are zeros, they don’t contribute. Then lse = log(sum_exp) * ln(2). Store scalar lse.
- Kernel 3: compute_softmax_valid_kernel
  - Inputs: logits_scaled vector (length 2048), sm_scale, out_softmax buffer (length 2048), num_valid_used, topk, inv_ln2.
  - Compute sum_exp = sum_v exp(sm_scale * logits_scaled[v] * inv_ln2) over valid entries only. Then for v in [0..2047]: softmax_v = exp(sm_scale * logits_scaled[v] * inv_ln2) / sum_exp. For v >= num_valid_used, we leave out_softmax untouched (it was zero), but the kernel only writes up to num_valid_used. To be precise, we can set out_softmax[v] = 0 for v >= num_valid_used, but since we only use first num_valid_used later, it’s fine.
- Kernel 4: compute_attention_output_kernel
  - Inputs: softmax_vec (length num_valid_used), Kc_selected (num_valid_used x 512), out_out vector (length 512).
  - For each d in [0..511], accumulate acc += sum_v softmax_vec[v] * Kc_selected[v, d] over v in chunks of BLOCK_V (e.g., 256). Store acc into out_out[d].

ModelNew.forward
- Ensure tensors are on CUDA and Triton is available.
- Flatten Kc_all and Kp_all to float32 for computation.
- For each token t:
  - Build tok_idx_list and num_valid_used.
  - Launch compute_logits_all_heads_kernel to produce logits_out[t, h, v] for all h.
  - Launch compute_lse_base2_valid_kernel to produce lse[t, h] for all h.
  - Select Kc_selected = Kc_all[tok_idx_list] (float32).
  - For each head h:
    - Launch compute_softmax_valid_kernel on logits_out[t, h] * sm_scale to produce softmax over valid entries into a temporary vector.
    - Launch compute_attention_output_kernel with softmax_vec and Kc_selected to produce output vector of length 512 in float32; cast to bfloat16 for final output[t, h, :].
- Return output [num_tokens, 16, 512] bfloat16 and lse [num_tokens, 16] float32.

This implementation avoids any torch operations on tensors for heavy math; all computations (dot products, reductions, softmax, final matvec) are performed by Triton kernels.

Final code:

```python
import torch
import math
import triton
import triton.language as tl


@triton.jit
def compute_logits_all_heads_kernel(
    q_nope_ptr, q_pe_ptr,   # pointers for this token: [num_qo_heads, 512] and [num_qo_heads, 64]
    Kc_ptr, Kp_ptr,         # [N, 512] and [N, 64] flattened
    out_ptr,                # pointer to out[t] matrix: [num_qo_heads, 2048]
    tok_idx_ptr,            # pointer to valid token indices for this token (int32), length num_valid_used
    num_valid_used: tl.constexpr,   # number of valid indices (<= 2048)
    num_qo_heads: tl.constexpr,
    head_dim_ckv: tl.constexpr,     # 512
    head_dim_kpe: tl.constexpr,     # 64
    topk: tl.constexpr,             # 2048
):
    # One program instance per token; we loop over heads and v to fill the out matrix
    for h in range(num_qo_heads):
        out_base = out_ptr + h * topk
        for v in range(topk):
            if v < num_valid_used:
                tok_idx = tl.load(tok_idx_ptr + v)
                acc1 = 0.0
                # Dot with Kc: sum over d in [0, head_dim_ckv)
                for d in range(head_dim_ckv):
                    q_val = tl.load(q_nope_ptr + h * head_dim_ckv + d)
                    kc_val = tl.load(Kc_ptr + tok_idx * head_dim_ckv + d)
                    acc1 += q_val * kc_val
                acc2 = 0.0
                # Dot with Kp: sum over d in [0, head_dim_kpe)
                for d in range(head_dim_kpe):
                    q_val = tl.load(q_pe_ptr + h * head_dim_kpe + d)
                    kp_val = tl.load(Kp_ptr + tok_idx * head_dim_kpe + d)
                    acc2 += q_val * kp_val
                val = acc1 + acc2
            else:
                val = 0.0
            tl.store(out_base + v, val)


@triton.jit
def compute_lse_base2_valid_kernel(
    logits_ptr,            # pointer to logits vector [topk] for one head
    out_lse_ptr,           # pointer to scalar lse for that head
    num_valid_used: tl.constexpr,
    sm_scale: tl.constexpr,      # scalar scale
    inv_ln2: tl.constexpr,       # 1 / ln(2)
):
    # Compute logsumexp_base2 over valid entries only: log(sum exp(sm_scale * logits)) / ln(2)
    sum_exp = 0.0
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)  # exp(x / ln(2))
    lse = tl.log(sum_exp) * ln2  # log(sum_exp) * ln(2)
    tl.store(out_lse_ptr, lse)


@triton.jit
def compute_softmax_valid_kernel(
    logits_ptr,            # pointer to logits vector [topk] for one head
    sm_scale: tl.constexpr,      # scalar scale
    out_softmax_ptr,       # pointer to softmax vector [topk]
    num_valid_used: tl.constexpr,
    topk: tl.constexpr,
    inv_ln2: tl.constexpr,
):
    # Compute softmax of (logits * sm_scale) with exponent base 2:
    # softmax_v = exp(sm_scale * logits_v / ln(2)) / sum_w exp(sm_scale * logits_w / ln(2))
    sum_exp = 0.0
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        softmax_v = tl.exp(x * inv_ln2) / sum_exp
        tl.store(out_softmax_ptr + v, softmax_v)
    # For v >= num_valid_used, we don't write; attention kernel only uses first num_valid_used.


@triton.jit
def compute_attention_output_kernel(
    softmax_ptr,           # pointer to softmax vector [num_valid_used]
    Kc_ptr,                # pointer to selected Kc rows [num_valid_used, 512]
    out_out_ptr,           # pointer to output vector [head_dim_ckv]
    num_valid_used: tl.constexpr,
    head_dim_ckv: tl.constexpr,   # 512
    BLOCK_V: tl.constexpr,        # chunk size for V reduction (e.g., 256)
):
    # Output for head: out = softmax @ Kc_selected
    for d in range(head_dim_ckv):
        acc = 0.0
        for i in range(0, tl.cdiv(num_valid_used, BLOCK_V)):
            v_start = i * BLOCK_V
            v_offsets = v_start + tl.arange(0, BLOCK_V)
            mask = v_offsets < num_valid_used
            softmax_chunk = tl.load(softmax_ptr + v_offsets, mask=mask, other=0.0)
            Kc_chunk = tl.load(Kc_ptr + v_offsets * head_dim_ckv + d, mask=mask, other=0.0)
            acc += tl.sum(softmax_chunk * Kc_chunk, axis=0)
        tl.store(out_out_ptr + d, acc)


class ModelNew(torch.nn.Module):
    def forward(self, q_nope, q_pe, ckv_cache, kpe_cache, sparse_indices, sm_scale):
        # Ensure tensors are on CUDA for Triton
        device = q_nope.device
        assert q_nope.is_cuda and q_pe.is_cuda and ckv_cache.is_cuda and kpe_cache.is_cuda, "Triton requires CUDA tensors."

        num_tokens, num_qo_heads, head_dim_ckv = q_nope.shape
        head_dim_kpe = q_pe.shape[-1]
        num_pages, page_size, _ = ckv_cache.shape
        topk = sparse_indices.shape[-1]
        assert topk == 2048, "topk must be 2048"

        # Flatten and cast selected cache to float32 for computation
        Kc_all = ckv_cache.reshape(-1, head_dim_ckv).to(torch.float32)  # [N, 512]
        Kp_all = kpe_cache.reshape(-1, head_dim_kpe).to(torch.float32)  # [N, 64]

        # Output buffers
        logits_out = torch.empty((num_tokens, num_qo_heads, topk), dtype=torch.float32, device=device)
        lse = torch.empty((num_tokens, num_qo_heads), dtype=torch.float32, device=device)

        ln2 = math.log(2.0)
        inv_ln2 = 1.0 / ln2

        for t in range(num_tokens):
            idx = sparse_indices[t]  # [topk]
            valid = (idx != -1)      # [topk]
            tok_idx_list = idx[valid].to(torch.int32)  # [num_valid_used]
            num_valid_used = int(tok_idx_list.numel())

            # Prepare tok_idx_ptr for this token: int32 vector of length num_valid_used
            tok_idx_vec = tok_idx_list  # tensor-like; Triton will read from it

            # Launch Triton kernel: compute logits for all heads across topk positions (valid entries computed, invalid written as 0)
            compute_logits_all_heads_kernel[(num_qo_heads,)](
                q_nope[t], q_pe[t],
                Kc_all, Kp_all,
                logits_out[t], tok_idx_vec,
                num_valid_used=num_valid_used,
                num_qo_heads=num_qo_heads,
                head_dim_ckv=head_dim_ckv,
                head_dim_kpe=head_dim_kpe,
                topk=topk,
                num_warps=4,
            )

            # Compute lse: logsumexp base-2 over valid entries only (we consider all 2048 entries, but invalid are zeros)
            for h in range(num_qo_heads):
                compute_lse_base2_valid_kernel[(1,)](
                    logits_out[t, h], lse[t, h],
                    num_valid_used=num_valid_used,
                    sm_scale=sm_scale,
                    inv_ln2=inv_ln2,
                    num_warps=1,
                )

        # Final output: compute attention and matmul in Triton per token
        output = torch.empty((num_tokens, num_qo_heads, head_dim_ckv), dtype=torch.bfloat16, device=device)

        for t in range(num_tokens):
            idx = sparse_indices[t]
            valid = (idx != -1)
            tok_idx_list_t = idx[valid].to(torch.int32)  # [num_valid_used]
            num_valid_used = int(tok_idx_list_t.numel())

            # Per-head attention output
            for h in range(num_qo_heads):
                # softmax over valid entries only
                logits_scaled_h = logits_out[t, h] * sm_scale  # [2048]; we use first num_valid_used
                softmax_vec = torch.empty((num_valid_used,), dtype=torch.float32, device=device)

                compute_softmax_valid_kernel[(1,)](
                    logits_scaled_h, sm_scale,
                    softmax_vec,
                    num_valid_used=num_valid_used,
                    topk=topk,
                    inv_ln2=inv_ln2,
                    num_warps=1,
                )

                # Select corresponding Kc rows
                Kc_selected = Kc_all[tok_idx_list_t]  # [num_valid_used, 512]

                # Compute output for this head: softmax_vec @ Kc_selected (no torch.matmul)
                out_vec = torch.empty((head_dim_ckv,), dtype=torch.float32, device=device)
                compute_attention_output_kernel[(1,)](
                    softmax_vec, Kc_selected,
                    out_vec,
                    num_valid_used=num_valid_used,
                    head_dim_ckv=head_dim_ckv,
                    BLOCK_V=256,
                    num_warps=4,
                )

                output[t, h] = out_vec.to(torch.bfloat16)

        return output, lse

Notes
- All heavy computations are performed by Triton kernels; forward only orchestrates allocations, launches, and casts.
- The kernels:
  - compute_logits_all_heads_kernel writes the full logits vector per head (length 2048), with zeros for padding.
  - compute_lse_base2_valid_kernel computes logsumexp base-2 over valid entries (invalid zeros don’t change the sum).
  - compute_softmax_valid_kernel computes softmax over valid entries using exp and normalization in Triton (no torch ops).
  - compute_attention_output_kernel performs the final reduction to produce the 512-length output vector per head (no torch.matmul).
- This implementation matches the original model’s outputs in shape and dtype:
  - output: [num_tokens, 16, 512], bfloat16
  - lse: [num_tokens, 16], float32
- This satisfies the Triton-only requirement by invoking Triton kernels and not using torch operations on tensors for any of the heavy math steps.

                    num_valid_used=num_valid_used,
                    topk=topk,
                    inv_ln2=inv_ln2,
                    num_warps=1,
                )

                # Select corresponding Kc rows
                Kc_selected = Kc_all[tok_idx_list_t]  # [num_valid_used, 512]

                # Compute output for this head: softmax_vec @ Kc_selected (no torch.matmul)
                out_vec = torch.empty((head_dim_ckv,), dtype=torch.float32, device=device)
                compute_attention_output_kernel[(1,)](
                    softmax_vec, Kc_selected,
                    out_vec,
                    num_valid_used=num_valid_used,
                    head_dim_ckv=head_dim_ckv,
                    BLOCK_V=256,
                    num_warps=4,
                )

                output[t, h] = out_vec.to(torch.bfloat16)

        return output, lse
```

Notes
- The forward function only allocates tensors and launches Triton kernels. It does not perform any torch operations on tensors for heavy math, satisfying the Triton-only requirement.
- Kernels compute:
  - Per-token logits for all heads across topk positions (valid entries contribute; invalid entries are zeros).
  - Per-head logsumexp in base 2 over all 2048 entries (invalid zeros don’t affect the sum).
  - Per-head softmax over valid entries using base-2 exponent.
  - Per-head attention output by reducing softmax vector with selected Kc rows to produce a 512-length vector.
- Returned outputs match the original in shape and dtype: output [num_tokens, 16, 512] bfloat16 and lse [num_tokens, 16] float32.

@triton.jit
def compute_logits_all_heads_kernel(
    q_nope_ptr, q_pe_ptr,   # pointers for this token: [num_qo_heads, 512] and [num_qo_heads, 64]
    Kc_ptr, Kp_ptr,         # [N, 512] and [N, 64] flattened
    out_ptr,                # pointer to out[t] matrix: [num_qo_heads, 2048]
    tok_idx_ptr,            # pointer to valid token indices for this token (int32), length num_valid_used
    num_valid_used: tl.constexpr,   # number of valid indices (<= 2048)
    num_qo_heads: tl.constexpr,
    head_dim_ckv: tl.constexpr,     # 512
    head_dim_kpe: tl.constexpr,     # 64
    topk: tl.constexpr,             # 2048
):
    # One program instance per token; loop over heads and v to fill out[t, h, v]
    for h in range(num_qo_heads):
        out_base = out_ptr + h * topk
        for v in range(topk):
            if v < num_valid_used:
                tok_idx = tl.load(tok_idx_ptr + v)
                acc1 = 0.0
                # Dot with Kc: sum over d in [0, head_dim_ckv)
                for d in range(head_dim_ckv):
                    q_val = tl.load(q_nope_ptr + h * head_dim_ckv + d)
                    kc_val = tl.load(Kc_ptr + tok_idx * head_dim_ckv + d)
                    acc1 += q_val * kc_val
                acc2 = 0.0
                # Dot with Kp: sum over d in [0, head_dim_kpe)
                for d in range(head_dim_kpe):
                    q_val = tl.load(q_pe_ptr + h * head_dim_kpe + d)
                    kp_val = tl.load(Kp_ptr + tok_idx * head_dim_kpe + d)
                    acc2 += q_val * kp_val
                val = acc1 + acc2
            else:
                val = 0.0
            tl.store(out_base + v, val)

def compute_lse_base2_valid_kernel(
    logits_ptr,            # pointer to logits vector [topk] for one head
    out_lse_ptr,           # pointer to scalar lse for that head
    num_valid_used: tl.constexpr,
    sm_scale: tl.constexpr,      # scalar scale
    inv_ln2: tl.constexpr,       # 1 / ln(2)
):
    # Compute logsumexp_base2 over valid entries only: log(sum exp(sm_scale * logits)) / ln(2)
    sum_exp = 0.0
    for v in range(num_valid_used):
        x = tl.load(logits_ptr + v)
        x = x * sm_scale
        sum_exp += tl.exp(x * inv_ln2)  # exp(x / ln(2))
    lse = tl.log(sum_exp) * ln2  # log(sum_exp) * ln(2)
    tl.store(out_lse_ptr, lse)
