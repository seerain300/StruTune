- Online logsumexp is implemented to compute lse efficiently: m is the running max and sum_exp accumulates exp(y - m) with updates when a new larger y appears. lse is stored per (token, head).
- The second pass recomputes logits to obtain attention weights and accumulates the final output vector per head.
user
The previous Triton implementation did not write output for all 2048 sparse candidates in one go. It processed candidates in blocks and reloaded q vectors in the second pass, which increases memory traffic. We can optimize and fix this by processing all candidates for a given token and head at once using a single BLOCK that is at least topk (e.g., 2048), loading the indices and valid mask in one vector, then performing both passes without re-reading q vectors. This avoids Python-side loops over j and keeps the Triton kernel vectorized.

Key changes:
- Use a single 2D Triton kernel with grid=(N, H), each program handles one (token, head).
- Load the entire sparse_indices[t, :] vector (size topk=2048) in one shot using BLOCK = topk, and use masks for invalid entries (-1). This eliminates the loop over j in Python and re-loads of q vectors.
- First pass: compute y = logits_scaled for all valid candidates via tl.where on validity, then compute running max m and sum_exp for online logsumexp.
- Compute lse = m * inv_log2 and store.
- Second pass: compute attn per candidate (recompute logit only for valid ones) and accumulate output vector. We do not need to loop over j; just use tl.where to zero out contributions for invalid candidates.

This ensures we:
- Perform all math in Triton, including the log in logsumexp (via exp).
- Write to output and lse buffers.
- Return outputs and lse from forward without any torch ops in the kernel.

Final code:

```python
import math
import torch
import triton
import triton.language as tl


@triton.jit
def attention_token_head_kernel(
    q_nope_ptr, q_pe_ptr, Kc_all_ptr, Kp_all_ptr, sparse_idx_ptr,
    out_ptr, lse_ptr,
    N, H, Dk, Dp, topk,
    sm_scale, inv_log2,
    BLOCK: tl.constexpr,
):
    # 2D grid: (token, head)
    t = tl.program_id(0)
    h = tl.program_id(1)

    # Base offset for this token in sparse_indices
    base = t * topk

    # Load q vectors for this head (scalars or vectors reused across candidates)
    q_nope_flat = tl.load(q_nope_ptr + t * H * Dk + h * Dk + tl.arange(0, Dk))  # [Dk]
    q_pe_flat = tl.load(q_pe_ptr + t * H * Dp + h * Dp + tl.arange(0, Dp))      # [Dp]

    # Vector of candidate offsets
    j_offsets = tl.arange(0, BLOCK)  # BLOCK == topk
    mask_j = j_offsets < topk
    idx_vals = tl.load(sparse_idx_ptr + base + j_offsets, mask=mask_j, other=-1)  # int32
    valid_mask = idx_vals != -1  # [BLOCK], boolean

    # Prepare row offsets for Kc_all and Kp_all
    # We'll load Kc/Kp rows as vectors for all candidates at once, then reduce
    # Build a 2D grid: candidates x features, load with masks per candidate
    # We need to load Kc rows across BLOCK candidates: shape [BLOCK, Dk]
    # But Triton vectors are 1D; we'll loop over feature dimension to build contributions.

    # Online logsumexp state
    m = -float('inf')
    sum_exp = 0.0

    # First pass: compute y = sm_scale * logit for all valid candidates and update lse
    for jj in range(0, BLOCK):
        if (j_offsets[jj] >= topk) or (not valid_mask[jj]):
            continue
        row_kc = idx_vals[jj] * Dk
        row_kp = idx_vals[jj] * Dp

        # Load Kc and Kp rows (scalars for now, we'll use elementwise product below)
        # We actually compute dot products by multiplying and reducing over feature dims.
        # We'll do elementwise products then reduce.
        # Note: We cannot form [BLOCK, Dk] vector directly, so we recompute dot per jj using elementwise loop.
        # That's okay: BLOCK is small relative to Dk, and we avoid Python-side loops over N.
        # Compute dot products for this candidate
        dot1 = tl.sum(q_nope_flat * tl.load(Kc_all_ptr + row_kc + tl.arange(0, Dk), mask=valid_mask[jj], other=0.0), axis=0)
        dot2 = tl.sum(q_pe_flat * tl.load(Kp_all_ptr + row_kp + tl.arange(0, Dp), mask=valid_mask[jj], other=0.0), axis=0)
        logit = dot1 + dot2
        y = logit * sm_scale

        # Online logsumexp update
        if y > m:
            sum_exp = sum_exp * tl.exp(m - y) + 1.0
            m = y
        else:
            sum_exp += tl.exp(y - m)

    # lse = m / log(2) = m * inv_log2
    lse_h = m * inv_log2
    tl.store(lse_ptr + t * H + h, lse_h)

    # Second pass: compute attention and accumulate output
    out_row_ptr = out_ptr + t * H * Dk + h * Dk
    for jj in range(0, BLOCK):
        if (j_offsets[jj] >= topk) or (not valid_mask[jj]):
            continue
        row_kc = idx_vals[jj] * Dk
        row_kp = idx_vals[jj] * Dp

        Kc_row = tl.load(Kc_all_ptr + row_kc + tl.arange(0, Dk), mask=valid_mask[jj], other=0.0)  # [Dk]
        Kp_row = tl.load(Kp_all_ptr + row_kp + tl.arange(0, Dp), mask=valid_mask[jj], other=0.0)  # [Dp]

        # Recompute q vectors (same for this head)
        q_nope_flat = tl.load(q_nope_ptr + t * H * Dk + h * Dk + tl.arange(0, Dk))  # [Dk]
        q_pe_flat = tl.load(q_pe_ptr + t * H * Dp + h * Dp + tl.arange(0, Dp))      # [Dp]

        dot1 = tl.sum(q_nope_flat * Kc_row, axis=0)
        dot2 = tl.sum(q_pe_flat * Kp_row, axis=0)
        logit = dot1 + dot2
        y = logit
