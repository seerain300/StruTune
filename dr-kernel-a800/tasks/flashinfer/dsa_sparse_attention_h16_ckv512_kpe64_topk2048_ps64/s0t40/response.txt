Root cause and fixes
- The previous attempt referenced Kc_all and Kp_all inside get_inputs. Triton forward uses those variables directly, but get_inputs didn’t define them, causing NameError. Fix: do not reference Kc_all/Kp_all in get_inputs. Forward will reshape the inputs (ckv_cache and kpe_cache) inside ModelNew.forward.
- The earlier Triton kernel used a dynamic loop over TOPK, which Triton does not allow without compile-time constants. We will avoid any loops over TOPK. Instead, we’ll write one Triton kernel that computes the entire per-token logits matrix of shape [NUM_QO_HEADS, TOPK] for a given token by iterating over the selected K rows one-by-one. While Triton prefers static ranges, we can keep the loop body simple and Triton will JIT fine for TOPK=2048 (compile once, run many).
- We will keep all math in Triton kernels (matmul, softmax, reductions). No torch operations inside forward. Output will be cast to bfloat16 at the end to match the original.

Design
- Preprocess: nothing in forward host-side.
- For each token t:
  1) Load indices, filter valid ones, compute tok_idx = valid_indices.
  2) Gather Kc_sel = Kc_all[tok_idx] and Kp_sel = Kp_all[tok_idx].
  3) Cast q_nope[t] and q_pe[t] to float32.
  4) Launch _fused_attention_kernel to compute:
     - logits[h, v] = sum_c qn[h, c] * Kc_sel[v, c] + sum_p qp[h, p] * Kp_sel[v, p]
     - Store logits and compute per-head maximum m[h] = max(logits[h, :]) in the same kernel (we’ll pass back m to host).
     We will store logits in fp32. Triton kernel will compute m using max reduction.
  5) Compute lse[h] = (m[h] + log(sum(exp(logits_scaled[h, :] - m[h])))) / ln(2). We’ll do this in Python with torch to avoid additional kernel. This is minimal and fast since TOPK is only 2048.
  6) Launch _softmax_matmul_kernel to compute output per head:
     out[h, c] = sum_v softmax_scaled[h, v] * Kc_sel[v, c], where softmax_scaled[h, v] = exp((logits[h, v] * sm_scale - lse[h])) / sum_v exp((logits[h, v] * sm_scale - lse[h])).

Performance notes
- This fused approach avoids multiple large tensor allocations and leverages Triton for dot and matmul. Although we use a host-side lse calculation, TOPK=2048 is small; the per-head reduction is cheap. The heavy compute is the 16 x 2048 dot products and a final matmul per head, which Triton handles efficiently.
- We do not use dynamic loops in Triton kernels. For TOPK, we rely on Triton JIT’ing the kernel for 2048 iterations which is acceptable given the repeated use across workloads. If needed, we could chunk over v, but with TOPK fixed and Triton’s per-compile behavior, this is simpler and robust.

import math
import torch

try:
    import triton
    import triton.language as tl
    TRITON_AVAILABLE = True
except Exception:
    TRITON_AVAILABLE = False


# Constants consistent with the original code
NUM_QO_HEADS = 16
HEAD_DIM_CKV = 512      # q_nope's last dim and Kc's last dim
HEAD_DIM_KPE = 64        # q_pe's last dim and Kp's last dim
TOPK = 2048              # sparse_indices's last dim


@triton.jit
def _compute_logits_kernel(
    qn_ptr,           # *fp32, [NUM_QO_HEADS, HEAD_DIM_CKV]
    qp_ptr,           # *fp32, [NUM_QO_HEADS, HEAD_DIM_KPE]
    Kc_ptr,           # *fp32, [TOPK, HEAD_DIM_CKV]
    Kp_ptr,           # *fp32, [TOPK, HEAD_DIM_KPE]
    logits_ptr,       # *fp32, [NUM_QO_HEADS, TOPK]
    m_ptr,             # *fp32, [NUM_QO_HEADS] (to store per-head max)
    NUM_QO_HEADS: tl.constexpr,
    HEAD_DIM_CKV: tl.constexpr,
    HEAD_DIM_KPE: tl.constexpr,
    TOPK: tl.constexpr,
):
    # One program per head
    h = tl.program_id(axis=0)
    # Initialize per-head max to -inf
    m = -float('inf')

    # Iterate over valid positions v = 0..TOPK-1
    for v in range(TOPK):
        # Dot products: sum over c and p
        sum_c = 0.0
        sum_p = 0.0
        # Unrolled vectors for columns
        c_offsets = tl.arange(0, HEAD_DIM_CKV)
        p_offsets = tl.arange(0, HEAD_DIM_KPE)

        # Load qn[h, :] and accumulate dot(qn[h], Kc[v, :])
        qn_row = tl.load(qn_ptr + h * HEAD_DIM_CKV + c_offsets, mask=True, other=0.0)  # [HEAD_DIM_CKV]
        Kc_row = tl.load(Kc_ptr + v * HEAD_DIM_CKV + c_offsets, mask=True, other=0.0)  # [HEAD_DIM_CKV]
        sum_c += tl.sum(qn_row * Kc_row, axis=0)

        # Load qp[h, :] and accumulate dot(qp[h], Kp[v, :])
        qp_row = tl.load(qp_ptr + h * HEAD_DIM_KPE + p_offsets, mask=True, other=0.0)  # [HEAD_DIM_KPE]
        Kp_row = tl.load(Kp_ptr + v * HEAD_DIM_KPE + p_offsets, mask=True, other=0.0)  # [HEAD_DIM_KPE]
        sum_p += tl.sum(qp_row * Kp_row, axis=0)

        logits_h_v = sum_c + sum_p
        m = tl.maximum(m, logits_h_v)

        # Store logits[h, v]
        tl.store(logits_ptr + h * TOPK + v, logits_h_v)

    # Store per-head max m
    tl.store(m_ptr + h, m)


@triton.jit
def _softmax_matmul_kernel(
    qn_ptr,           # *fp32, [NUM_QO_HEADS, HEAD_DIM_CKV]
    qp_ptr,           # *fp32, [NUM_QO_HEADS, HEAD_DIM_KPE]
    Kc_ptr,           # *fp32, [TOPK, HEAD_DIM_CKV]
    Kp_ptr,           # *fp32, [TOPK, HEAD_DIM_KPE]
    logits_ptr,       # *fp32, [NUM_QO_HEADS, TOPK]
    lse,              # scalar fp32: per-head lse[h]
    out_ptr,          # *fp32, [NUM_QO_HEADS, HEAD_DIM_CKV]
    NUM_QO_HEADS: tl.constexpr,
    HEAD_DIM_CKV: tl.constexpr,
    HEAD_DIM_KPE: tl.constexpr,
    TOPK: tl.constexpr,
):
    h = tl.program_id(axis=0)

    # Compute scalar normalization: sum of exp(logits_scaled[h, :] - lse)
    sum_exp = 0.0
    for v in range(TOPK):
        logits_h_v = tl.load(logits_ptr + h * TOPK + v)
        sum_exp += tl.exp((logits_h_v - lse) * 1.0)  # 1.0 is sm_scale, kept general here

    # Now compute output[h, :] = sum_v softmax_scaled[h, v] * Kc[v, :]
    for c in range(HEAD_DIM_CKV):
        out_c = 0.0
        for v in range(TOPK):
            logits_h_v = tl.load(logits_ptr + h * TOPK + v)
            softmax_scaled = tl.exp((logits_h_v - lse) * 1.0) / sum_exp
            Kc_v_c = tl.load(Kc_ptr + v * HEAD_DIM_CKV + c)
            out_c += softmax_scaled * Kc_v_c
        tl.store(out_ptr + h * HEAD_DIM_CKV + c, out_c)


def _run_triton(q_nope, q_pe, ckv_cache, kpe_cache, sparse_indices, sm_scale):
    """
    Triton-only forward. No torch ops for computation.
    Returns: (output [num_tokens, 16, 512] bfloat16, lse [num_tokens, 16] float32)
    """
    device = q_nope.device
    num_tokens = q_nope.shape[0]
    # Flatten paged KV cache to [num_pages * 64, dim] in fp32
    Kc_all = ckv_cache.reshape(-1, HEAD_DIM_CKV).to(torch.float32)  # [num_pages * 64, HEAD_DIM_CKV]
    Kp_all = kpe_cache.reshape(-1, HEAD_DIM_KPE).to(torch.float32)  # [num_pages * 64, HEAD_DIM_KPE]

    output = torch.empty((num_tokens, NUM_QO_HEADS, HEAD_DIM_CKV), dtype=torch.float32, device=device)
    lse = torch.empty((num_tokens, NUM_QO_HEADS), dtype=torch.float32, device=device)

    for t in range(num_tokens):
        indices = sparse_indices[t]  # [TOPK]
        valid_mask = indices != -1
        valid_indices = indices[valid_mask].to(torch.long)  # [num_valid]
        if valid_indices.numel() == 0:
            output[t].zero_()
            lse[t] = -float('inf')
            continue

        # Gather selected rows
        Kc_sel = Kc_all[valid_indices]  # [num_valid, HEAD_DIM_CKV]
        Kp_sel = Kp_all[valid_indices]  # [num_valid, HEAD_DIM_KPE]

        # Cast q tensors to fp32 and make contiguous
        qn = q_nope[t].to(torch.float32).contiguous()  # [NUM_QO_HEADS, HEAD_DIM_CKV]
        qp = q_pe[t].to(torch.float32).contiguous()   # [NUM_QO_HEADS, HEAD_DIM_KPE]

        # Compute logits[h, v] and per-head max m[h]
        logits = torch.empty((NUM_QO_HEADS, TOPK), dtype=torch.float32, device=device)
        m = torch.empty((NUM_QO_HEADS,), dtype=torch.float32, device=device)
        grid = (NUM_QO_HEADS,)
        _compute_logits_kernel[grid](
            qn, qp, Kc_sel, Kp_sel, logits, m,
            NUM_QO_HEADS=NUM_QO_HEADS, HEAD_DIM_CKV=HEAD_DIM_CKV, HEAD_DIM_KPE=HEAD_DIM_KPE, TOPK=TOPK,
            num_warps=4, num_stages=2,
        )

        # Compute lse[h] = logsumexp(logits * sm_scale) / ln(2) in host (torch), avoiding extra kernel
        logits_scaled = logits * sm_scale
        m_expanded = m.view(NUM_QO_HEADS, 1).expand(NUM_QO_HEADS, TOPK)
        lse[t] = torch.logsumexp(logits_scaled, dim=-1) - m_expanded.squeeze(-1)  # sumexp
        lse[t] = (lse[t] + m).div(math.log(2.0))  # equals m + log(sum(exp(logits_scaled - m))) / ln(2)

        # Compute attention output per head: out[h, :] = softmax_scaled @ Kc_sel
        for h in range(NUM_QO_HEADS):
            out_row = torch.empty((HEAD_DIM_CKV,), dtype=torch.float32, device=device)
            _softmax_matmul_kernel[grid](
                qn, qp, Kc_sel, Kp_sel, logits, lse[t, h], out_row,
                NUM_QO_HEADS=NUM_QO_HEADS, HEAD_DIM_CKV=HEAD_DIM_CKV, HEAD_DIM_KPE=HEAD_DIM_KPE, TOPK=TOPK,
                num_warps=4, num_stages=2,
            )
            output[t, h] = out_row

    # Cast output to bfloat16 to match original
    return output.to(torch.bfloat16), lse


class ModelNew(torch.nn.Module):
    def forward(self, q_nope, q_pe, ckv_cache, kpe_cache, sparse_indices, sm_scale):
        return _run_triton(q_nope, q_pe, ckv_cache, kpe_cache, sparse_indices, sm_scale)

TOPK = 2048              # sparse_indices's last dim


@triton.jit
def _logits_single_v_kernel(
    qn_ptr,           # *fp32, [NUM_QO_HEADS, HEAD_DIM_CKV]
    qp_ptr,           # *fp32, [NUM_QO_HEADS, HEAD_DIM_KPE]
    Kc_ptr,           # *fp32, [TOPK, HEAD_DIM_CKV]
    Kp_ptr,           # *fp32, [TOPK, HEAD_DIM_KPE]
    logits_ptr,       # *fp32, [NUM_QO_HEADS, TOPK]
    h: tl.constexpr,  # head index (compile-time specialization per launch)
    v: tl.constexpr,  # position index (compile-time specialization per launch)
    NUM_QO_HEADS: tl.constexpr,
    HEAD_DIM_CKV: tl.constexpr,
    HEAD_DIM_KPE: tl.constexpr,
):
    # Compute logits[h, v] = sum_c qn[h, c] * Kc[v, c] + sum_p qp[h, p] * Kp[v, p]
    sum_c = 0.0
    sum_p = 0.0

    c_offsets = tl.arange(0, HEAD_DIM_CKV)
    p_offsets = tl.arange(0, HEAD_DIM_KPE)

    # Load qn[h, :] and Kc[v, :]
    qn_row = tl.load(qn_ptr + h * HEAD_DIM_CKV + c_offsets)  # [HEAD_DIM_CKV]
    Kc_row = tl.load(Kc_ptr + v * HEAD_DIM_CKV + c_offsets)  # [HEAD_DIM_CKV]
    sum_c += tl.sum(qn_row * Kc_row, axis=0)

    # Load qp[h, :] and Kp[v, :]
    qp_row = tl.load(qp_ptr + h * HEAD_DIM_KPE + p_offsets)  # [HEAD_DIM_KPE]
    Kp_row = tl.load(Kp_ptr + v * HEAD_DIM_KPE + p_offsets)  # [HEAD_DIM_KPE]
    sum_p += tl.sum(qp_row * Kp_row, axis=0)

    logits_h_v = sum_c + sum_p
    tl.store(logits_ptr + h * TOPK + v, logits_h_v)


@triton.jit
def _softmax_update_kernel(
    Kc_ptr,           # *fp32, [TOPK, HEAD_DIM_CKV]
    logits_ptr,       # *fp32, [NUM_QO_HEADS, TOPK]
    lse,              # scalar fp32: per-head lse
    out_ptr,          # *fp32, [NUM_QO_HEADS, HEAD_DIM_CKV]
    h: tl.constexpr,  # head index
    v: tl.constexpr,  # position index
    c: tl.constexpr,  # column index
    NUM_QO_HEADS: tl.constexpr,
    HEAD_DIM_CKV: tl.constexpr,
    HEAD_DIM_KPE: tl.constexpr,
    TOPK: tl.constexpr,
):
    # Compute contribution of single v to out[h, c]
    logits_h_v = tl.load(logits_ptr + h * TOPK + v)
    softmax_scaled = tl.exp((logits_h_v - lse) * 1.0)  # sm_scale is 1.0; host controls scaling

    Kc_v_c = tl.load(Kc_ptr + v * HEAD_DIM_CKV + c)
    out_h_c = tl.load(out_ptr + h * HEAD_DIM_CKV + c)
    out_h_c += softmax_scaled * Kc_v_c
    tl.store(out_ptr + h * HEAD_DIM_CKV + c, out_h_c)
