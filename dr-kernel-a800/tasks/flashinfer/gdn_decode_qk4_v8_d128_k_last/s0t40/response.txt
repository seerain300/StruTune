What went wrong in prior attempts:
- The “shape ‘[1, 4, 128, 128]’ is invalid for input of size 131072” error indicates a host-side allocation mismatch. We allocated a tensor with shape [B, H, V, K] but the number of elements didn’t match what the Triton kernel produced or the actual H/V/K for the given input. This happened because:
  - We used a fixed H when allocating the output, or
  - We computed H, V, K from our assumptions, not from the input tensors, and the evaluator’s dynamic axes caused a mismatch.
  - Additionally, one earlier attempt changed H, V, K via assertions, which prevented correct handling for different axes.
- Similarly, the error “shape ‘[1, 1, 128]’ is invalid for input of size 512” suggests we allocated an output vector of length 128 but the kernel produced 512 elements or the shape was not a true [B, 1, V] vector.
- A separate previous IndexError (“index 4 is out of bounds for dimension 1 with size 4”) came from Python-side indexing past the second dimension size, which we must avoid.

Fix strategy:
- Remove all Python-side indexing into input tensors that could be incorrect. Launch Triton kernels per (b, h) with grid = (B, H), where H is the actual number of heads (QH or KH as per the original implementation). Do not squeeze or unsqueeze dimension 1.
- Compute all reductions (dot products) inside Triton kernels. For output scalar per (b, h), compute q[b, h] · new_state[b, h] in the kernel and store a single value. We’ll allocate output as [B, H] on the host and then return [B, 1, H] on the host by unsqueezing dim=1.
- Ensure all host-side allocations use actual tensor sizes from the input:
  - new_state: [B, H, V, K]
  - output: [B, H], then cast to bfloat16 and return [B, 1, H]
- Keep all math in float32 inside Triton kernels for numerical stability; cast output as requested (bfloat16).
- Keep kernels simple and vectorize over V and K with masks; use strides to avoid shape mismatches. The kernels assume q, k, v have shape [B, 1, ...] and pass (b, h) to kernels implicitly via program_id(0)=b, program_id(1)=h. But to keep things simple and robust, we will launch kernels per (b, h) and pass b/h scalars, and operate directly on original shapes without squeezing.

Performance considerations:
- The current reference implementation does a per-batch loop over heads and performs several tensor ops: softplus, sigmoid, K×V dot, q·h_state. Triton can fuse g and beta computation, tmp_old_v, and update of new_state and output into kernels that run per (b, h). While the data sizes here are small (K=128, V=128, H in {4,8}), moving everything to Triton avoids Python overhead and can be faster, especially when B varies. We will:
  - Use a single Triton kernel to compute g[b,h] and beta[b,h].
  - Use a single Triton kernel to compute tmp_old_v[b,h] = k[b,h] · state[b,h] via a tile loop over K.
  - Use a single Triton kernel to update new_state[b,h] elementwise and output[b,h] scalar: new_state = g * old_state + k ⊺ ((1−beta) * (k ⊺ old_state) + beta * v) − k ⊺ (k ⊺ old_state), output = scale * (q ⊺ new_state).
- All heavy math and reductions are performed in Triton; host code just allocates, launches, and returns. No torch operations on data in host code.

    g_val = tl.exp(-tl.exp(A) * sp)
    beta_val = 1.0 / (1.0 + tl.exp(-bb))
    tl.store(g_ptr + b_idx * stride_g_b + h_idx * stride_g_h, g_val)
    tl.store(beta_ptr + b_idx * stride_beta_b + h_idx * stride_beta_h, beta_val)


@triton.jit
def kernel_tmp_old_v(
    k_ptr, state_ptr, tmp_ptr,
    B, H, V, K,
    stride_k_b, stride_k_h, stride_k_k,
    stride_state_b, stride_state_h, stride_state_v, stride_state_k,
    stride_tmp_b, stride_tmp_h,
    num_warps: tl.constexpr,
):
    # One program per (b, h)
    b_idx = tl.program_id(0)
    h_idx = tl.program_id(1)
    acc = 0.0
    # Dot over K in tiles
    for k_start in range(0, K, 64):
        k_offsets = k_start + tl.arange(0, 64)
        mask_k = k_offsets < K
        k_vec = tl.load(k_ptr + b_idx * stride_k_b + h_idx * stride_k_h + k_offsets * stride_k_k, mask=mask_k, other=0.0)
        # For each v, sum k_vec * state[b,h,v,k]
        for v_idx in range(0, V):
            s = tl.load(state_ptr + b_idx * stride_state_b + h_idx * stride_state_h + v_idx * stride_state_v + k_offsets * stride_state_k, mask=mask_k, other=0.0)
            acc += tl.sum(k_vec * s, axis=0)
    tl.store(tmp_ptr + b_idx * stride_tmp_b + h_idx * stride_tmp_h, acc)


@triton.jit
def kernel_update_and_output(
    q_ptr, k_ptr, v_ptr, state_ptr, g_ptr, beta_ptr, tmp_ptr, out_ptr,
    B, H, V, K,
    stride_q_b, stride_q_h, stride_q_k,
    stride_k_b, stride_k_h, stride_k_k,
    stride_v_b, stride_v_h, stride_v_v,
    stride_state_b, stride_state_h, stride_state_v, stride_state_k,
    stride_g_b, stride_g_h, stride_beta_b, stride_beta_h, stride_tmp_b, stride_tmp_h,
    stride_out_b, stride_out_h,
    scale,
    num_warps: tl.constexpr,
):
    # One program per (b, h)
    b_idx = tl.program_id(0)
    h_idx = tl.program_id(1)

    g_val = tl.load(g_ptr + b_idx * stride_g_b + h_idx * stride_g_h).to(tl.float32)
    beta_val = tl.load(beta_ptr + b_idx * stride_beta_b + h_idx * stride_beta_h).to(tl.float32)
    tmp_val = tl.load(tmp_ptr + b_idx * stride_tmp_b + h_idx * stride_tmp_h).to(tl.float32)

    # Compute q @ new_state for output scalar. We update state in-place for new_state:
    # new_state_v_k = g * state_v_k + beta * v_scalar
    for v_idx in range(0, V):
        for k_start in range(0, K, 64):
            k_offsets = k_start + tl.arange(0, 64)
            mask_k = k_offsets < K
            q_vec = tl.load(q_ptr + b_idx * stride_q_b + h_idx * stride_q_h + k_offsets * stride_q_k, mask=mask_k, other=0.0)
            state_row = tl.load(state_ptr + b_idx * stride_state_b + h_idx * stride_state_h + v_idx * stride_state_v + k_offsets * stride_state_k, mask=mask_k, other=0.0)
            v_scalar = tl.load(v_ptr + b_idx * stride_v_b + h_idx * stride_v_h).to(tl.float32)
            new_state_row = g_val * state_row + beta_val * v_scalar
            tl.store(state_ptr + b_idx * stride_state_b + h_idx * stride_state_h + v_idx * stride_state_v + k_offsets * stride_state_k, new_state_row, mask=mask_k)
            # Accumulate output scalar: scale * sum_k q_k * new_state_row
            acc_out = tl.sum(q_vec * new_state_row, axis=0)

    tl.store(out_ptr + b_idx * stride_out_b + h_idx * stride_out_h, acc_out)
