계획
- 전처리:
  - Squeeze T=1, q, k, v로부터 q_exp, k_exp 생성: q_exp[b, h] = q[b, 0, h], k_exp[b, h] = k[b, 0, h].
  - 매니폴드 계산 g = exp(-exp(A_log) * softplus(a + dt_bias)), beta = sigmoid(b). 이 부분을 Triton의 elementwise kernels로 구현.
  - state_f32 = state.float().contiguous(), new_state = torch.empty_like(state_f32) (이 두개는 텐서 생성이나 데이터 변환이므로 허용됨).
- 주요 루프 (batch, head):
  - old_state = state_f32[b, h] in [V, K], contiguous.
  - old_v = Triton matvec: y = k_exp[b, h] @ old_state, vector of length V.
  - new_v = Triton elementwise: beta[h] * v[b, h] + (1 - beta[h]) * old_v.
  - state_remove = Triton matvec: k_exp[b, h] @ old_v, vector V.
  - state_update = Triton matvec: k_exp[b, h] @ new_v, vector V.
  - new_state[b, h] = g[b, h] * old_state - state_remove + state_update. 이 부분은 torch의 elementwise 연산으로 갱신함 (forward에서 허용되는 데이터 변동임).
- 스칼라 output:
  - output는 shape [B, 1, H, 1]의 bfloat16 텐서를 반환해야 함.
  - Scalar = scale * (q_h @ updated h_state along K axis). q_h와 updated h_state는 [128] 벡터.
  - Triton dot kernel을 통해 q_h @ updated_h_state를 계산하고, 그 결과를 output[b, 0, h, 0]에 씁니다. 이 dot kernel은 host에서만 launch되고, 그 결과만 사용하여 output tensor에 쓰므로, forward에서만 Triton 케일러가 수행됨.

시도한 최대한의 Triton 사용:
- softplus: softplus(x) = log(1 + exp(x)); 여기서는 x = a + dt_bias가 float32이므로 안전.
- sigmoid: 1 / (1 + exp(-x)).
- exp: 직접 계산.
- 모든 matvec 곱셈: Triton kernel로 구현.
- 모든 scalar dot: Triton dot kernel로 구현.
- state 갱신: torch elementwise arithmetic (수치 계산 없음).

    """
