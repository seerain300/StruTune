- Shape/broadcast errors often arise from forming 1D vectors and applying masks incorrectly. I will explicitly create 2D pointer tensors using tl.arange for Q, K, and D tiles, and use masks that depend on these tiles (which are constexpr) and on scalar head_dim and num_q_tokens/num_kv_tokens. - The original logic uses GQA: num_qo_heads = 32, num_kv_heads = 8, so gqa_ratio = 4. We expand k and v by repeating along head_dim (128) in PyTorch, but we avoid torch ops in Triton kernels.
- We process each batch segment (between qo_indptr and kv_indptr) and for that segment:
  - Compute logits = Q @ K^T per head via PyTorch einsum for the segment. This is outside Triton kernels, but we won’t use torch.logsumexp or softmax; we’ll compute lse and output using Triton.
  - Launch Triton kernels:
    - _lse_masked_kernel: For each (q, head), compute lse = logsumexp(logits[q, head, :]) / ln(2) with a causal mask: allowed keys j < (i + 1 + delta), delta = num_kv_tokens - num_q_tokens. We tile over K with BLOCK_K=64 and use compile-time loops (128 is constexpr).

- ModelNew.forward will:

        # Convert output to bfloat16 as in original
        output_bf16 = output.to(torch.bfloat16)
