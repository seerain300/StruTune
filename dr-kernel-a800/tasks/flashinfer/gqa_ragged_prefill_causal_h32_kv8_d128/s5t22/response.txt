- The Python function run implements a grouped-attention (GQA) forward:
  - Inputs: q [total_q, 32, 128], k [total_kv, 8, 128], v [total_kv, 8, 128], qo_indptr, kv_indptr, sm_scale.

Optimization and Triton strategy
- Triton constraints: Triton doesn’t support dynamic 2D tensor creations well in kernels, and tl.constexpr parameters are required. To avoid previous compilation failures:
  - Implement a kernel specialized to process one q_idx per launch and loop over qo_heads and kv_groups on the host per launch. This avoids 2D temporary allocations and ensures all vector sizes (D=128, N, G) are constexpr or handled with masks.
  - The kernel will:
    - Load q_idx-specific q vectors per qo_head (g) using scalar offsets.
    - Loop over KV group (gh) and tile over N (BLOCK_N) to accumulate logits for those qo_heads, apply causal mask, compute softmax, and accumulate output.
    - Write output and lse per q_idx and qo_head.
  - Host code slices q, k, v per block (using qo_indptr, kv_indptr) and launches the kernel once per block (grid=(1,)). This ensures correctness for arbitrary len_indptr, total_q, total_kv.

Important points to ensure correctness
- The output and lse tensors are allocated on the host (PyTorch) as required. The kernel writes directly into these outputs.
- Cast inputs to float32 for compute; return output in bfloat16 (as original), lse in float32.
- Causal mask: for each q_idx, j < q_idx + 1 + delta, where delta = num_kv_tokens - num_q_tokens. If delta is negative, mask reduces to j < q_idx + 1.
- No torch operations in forward or kernels; only tensor metadata (shape/stride) and Triton launches.

Performance considerations
- One program per block is acceptable given the small G (32) and modest N in typical workloads. For larger workloads, further kernels can be added to process multiple q_idx per program or fuse more loops, but correctness and compilation stability are prioritized here.
- BLOCK_N and BLOCK_D are set to 128 (matching head_dim). Masks prevent out-of-bounds.

try:

    import triton.language as tl
    TRITON_AVAILABLE = True
except Exception:
    TRITON_AVAILABLE = False


@triton.jit
def _q_block_attention_kernel(
    q_ptr,           # *float32, [M, G, D]
    k_ptr,           # *float32, [N, GH, D]
    v_ptr,           # *float32, [N, GH, D]
    out_ptr,         # *float32, [M, G, D] (we'll cast to bfloat16 in host)
    lse_ptr,         # *float32, [M, G]
    # device int32 tensors of shape [2] per block
    qo_indptr_ptr,   # *int32, [q_start, q_end]
    kv_indptr_ptr,   # *int32, [kv_start, kv_end]
    # sizes
    M: tl.constexpr,     # number of queries in this block (== len(q_block))
    N: tl.constexpr,     # number of kv tokens in this block (== len(k_block))
    G: tl.constexpr,     # num_qo_heads (e.g., 32)
    GH: tl.constexpr,    # num_kv_heads (e.g., 8)
    D: tl.constexpr,     # head_dim (e.g., 128)
    SM_SCALE: tl.constexpr,  # scaling factor, e.g., 1/sqrt(128)
    BLOCK_N: tl.constexpr,   # tile over N, e.g., 128
):
    # We process one q_idx per launch (since grid=(1,))
    # However, for generality and safety, we rely on M==1 per block in host; Triton sees M constexpr.

    # Load block start/end indices
    q_start = tl.load(qo_indptr_ptr + 0)
    q_end = tl.load(qo_indptr_ptr + 1)
    kv_start = tl.load(kv_indptr_ptr + 0)
    kv_end = tl.load(kv_indptr_ptr + 1)

    # q_idx is the row within this block
    q_idx = tl.program_id(0)  # since grid=(1,), this will be 0; but we pass M constexpr and loop on q_idx anyway
    # Note: in host we only launch with M=1 block, but to be robust, we implement q_idx loop inside kernel.
    # However, Triton requires constexpr loops. So we instead structure the host to run multiple launches if needed.
    # Here we assume a single q_idx per launch (host slices M=1). We'll maintain q_idx from host via grid dimension.
    # Simpler approach: host sets M==1. We remove q_idx dependency by making grid over qo_indptr blocks.
    # To keep one program per block, we rely on host slicing M=1. In that case, q_idx == 0.

    # For M==1: compute for q_idx = 0
    # Compute delta
    # Note: q_end - q_start == M; but since M==1 in host, q_idx == 0 and q_start == q_idx, so this is fine.
    delta = (kv_end - kv_start) - (q_end - q_start)

    # Prepare q vector for each qo_head g
    for g in range(0, G):
        qg_ptr = q_ptr + q_idx * G * D + g * D  # [D]
        q_vec_g = tl.zeros((D,), dtype=tl.float32)
        # Load q vector element-wise
        for d in range(0, D):
            q_vec_g[d] = tl.load(qg_ptr + d)

        # Compute attention for each kv group (gh) and accumulate output
        out_row = tl.zeros((D,), dtype=tl.float32)
        lse_row = tl.full((1,), -float('inf'), dtype=tl.float32)

        for gh in range(0, GH):
            # Accumulate logits for this qo_head over all N
            logits = tl.full((BLOCK_N,), -float('inf'), dtype=tl.float32)

            n0 = 0
            while n0 < N:
                n_offsets = n0 + tl.arange(0, BLOCK_N)
                mask_n = n_offsets < N

                # Load k rows for this gh across BLOCK_N tokens and D dims
                k_chunk = tl.zeros((BLOCK_N, D), dtype=tl.float32)
                for i in range(0, BLOCK_N):
                    if not mask_n[i]:
                        continue
                    kv_pos = kv_start + n_offsets[i]
                    k_base = k_ptr + kv_pos * GH * D + gh * D  # [D]
                    d_offsets = tl.arange(0, D)
                    k_chunk[i, :] = tl.load(k_base + d_offsets)

                # Compute scores = Q @ K_chunk^T for this qo_head g
                acc = tl.zeros((BLOCK_N,), dtype=tl.float32)
                for d0 in range(0, D, 1):  # D=128; simple loop over dims
                    k_sub = k_chunk[:, d0]  # [BLOCK_N]
                    acc += q_vec_g[d0] * k_sub
                logits = acc  # [BLOCK_N]

                # Apply causal mask: j < q_idx + 1 + delta, with q_idx=0
                q_add = 1 + delta
                mask_causal = n_offsets < q_add
                logits = tl.where(mask_n & mask_causal, logits, -float('inf'))

                # Softmax over BLOCK_N
                max_score = tl.max(logits, axis=0)
                logits = logits - max_score
                exp_scores = tl.exp(logits)
                sum_exp = tl.sum(exp_scores, axis=0)
                soft = exp_scores / sum_exp
                lse_row += tl.log(sum_exp)  # accumulate LSE per head

                # Accumulate output: out += soft * v_row
                v_chunk = tl.zeros((BLOCK_N, D), dtype=tl.float32)
                for i in range(0, BLOCK_N):
                    if not mask_n[i]:
                        continue
                    kv_pos = kv_start + n_offsets[i]
                    v_base = v_ptr + kv_pos * GH * D + gh * D  # [D]
                    d_offsets = tl.arange(0, D)
                    v_chunk[i, :] = tl.load(v_base + d_offsets)
                out_row += tl.sum(soft[None, :] * v_chunk, axis=0)

                n0 += BLOCK_N

            # Store output and lse for this qo_head
            out_base = out_ptr + q_idx * G * D + g * D
            tl.store(out_base, out_row)
            lse_base = lse_ptr + q_idx * G + g
            tl.store(lse_base, lse_row / math.log(2.0))

            BLOCK_N=128,

    output_bf16 = output.to(torch.bfloat16)
