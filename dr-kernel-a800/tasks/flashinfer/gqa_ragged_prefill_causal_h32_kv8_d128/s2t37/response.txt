Understanding the original behavior and fixing correctness

- The original Model.run function computes per-batch attention:

  - It uses qo_indptr and kv_indptr to slice q, k, v into batches.
  - It expands k and v along the head dimension by GQA ratio gqa_ratio = num_qo_heads // num_kv_heads = 4, so k_expanded and v_expanded have shape [num_kv_tokens, 32, 128].
  - It computes logits = Q @ K^T per head h (Q per head: [num_q_tokens, 128], K per head: [num_kv_tokens, 128]), scaled by sm_scale = 1/sqrt(128).
  - It applies a causal mask: for each query i and KV j, only keep j < (i + 1 + delta), where delta = num_kv_tokens - num_q_tokens.
  - It computes lse per (query, head) as logsumexp(logits) / log(2) (2-base LSE). Even though the original doesn’t use lse elsewhere, we must compute it correctly to match the signature.

- Common pitfalls that can break correctness:
  - Indexing into [q_tokens, heads, kv_tokens] must be consistent for both storing logits and reading them later. Using different indexing logic can lead to wrong mapping and incorrect outputs.
  - Ensuring kernel launches cover all heads (since num_qo_heads=32 and we use BH=8, grid over heads must be 4).
  - Maintain that sm_scale is correctly applied and that causal mask is properly enforced.

Design for Triton implementation

- Kernel 1: compute_logits_masked_and_lse
  - Grid: (num_batches, ceil_div(num_qo_heads, BH), ceil_div(num_q_tokens, BLOCK_Q)).
  - Inside:
    - For each head h in tile:
      - For each KV tile:
        - Load Q block [BLOCK_Q, 128], K block [BLOCK_KV, 128].
        - Compute acc = Q @ K^T * sm_scale.
        - Load causal mask tile and set invalid entries to -inf.
        - Store acc into logits_out at logical indices [row, h, col], using lse_ptr tracking.
      - Track per-row maxima (lse_acc) across tiles and at the end store lse_row scaled by 1/log(2).

- Kernel 2: compute_output_from_logits_and_lse
  - Grid: same as kernel 1.
  - Inside:
    - For each head h in tile:
      - For each row i in tile:
        - Load lse_2base[i], compute softmax over KV tokens for that row using logits_out (subtract lse_2base[i]).
        - Loop over KV tiles:
          - Load exp_row (softmax), compute denom, load K and V tiles, accumulate weighted V into output row.
        - Store output row.

- ModelNew.forward:

try:
    import triton
    import triton.language as tl
    TRITON_AVAILABLE = True
except Exception:
    TRITON_AVAILABLE = False


@triton.jit
def compute_logits_masked_and_lse(
    q_ptr,  # *float32, [num_q_tokens, num_qo_heads, head_dim]
    k_ptr,  # *float32, [num_kv_tokens, num_qo_heads, head_dim] (K expanded to 32 heads)
    mask_ptr,  # *int8, [num_q_tokens, num_kv_tokens]
    logits_ptr,  # *float32, [num_q_tokens, num_qo_heads, num_kv_tokens]
    lse_row_ptr,  # *float32, [num_q_tokens, num_qo_heads]
    sm_scale,  # float32 scalar
    num_q_tokens: tl.constexpr,
    num_kv_tokens: tl.constexpr,
    num_qo_heads: tl.constexpr,
    head_dim: tl.constexpr,
    BLOCK_Q: tl.constexpr,
    BLOCK_KV: tl.constexpr,
    BH: tl.constexpr
):
    # Grid: (num_batches, ceil_div(num_qo_heads, BH), ceil_div(num_q_tokens, BLOCK_Q))
    pid_b = tl.program_id(0)
    pid_h = tl.program_id(1)
    pid_q = tl.program_id(2)

    qo_start = pid_b * num_q_tokens
    kv_start = pid_b * num_kv_tokens

    h_start = pid_h * BH
    qo_mask = pid_q * BLOCK_Q + tl.arange(0, BLOCK_Q)  # [BLOCK_Q]
    valid_q = qo_mask < num_q_tokens

    for hh in range(BH):
        h = h_start + hh
        if h >= num_qo_heads:
            break

        # Track row-wise maxima for lse
        lse_acc = tl.full((BLOCK_Q,), -float('inf'), dtype=tl.float32)

        # Loop over KV tiles to compute logits and update lse_acc (row-wise maxima)
        for kv_off in range(0, num_kv_tokens, BLOCK_KV):
            kv_mask = kv_off + tl.arange(0, BLOCK_KV)  # [BLOCK_KV]
            valid_k = kv_mask < num_kv_tokens  # [BLOCK_KV]

            # Load Q block: [BLOCK_Q, head_dim]
            q_block = tl.load(
                q_ptr + (qo_start + qo_mask[:, None]) * (num_qo_heads * head_dim) + h * head_dim,
                mask=valid_q[:, None],
                other=0.0
            )  # [BLOCK_Q, head_dim]

            # Load K block: [BLOCK_KV, head_dim]
            k_block = tl.load(
                k_ptr + (kv_start + kv_mask[:, None]) * (num_qo_heads * head_dim) + h * head_dim,
                mask=valid_k[:, None],
                other=0.0
            )  # [BLOCK_KV, head_dim]

            # Matmul: [BLOCK_Q, head_dim] @ [head_dim, BLOCK_KV] => [BLOCK_Q, BLOCK_KV]
            acc = tl.dot(q_block, tl.trans(k_block)) * sm_scale  # [BLOCK_Q, BLOCK_KV]

            # Load causal mask tile: [BLOCK_Q, BLOCK_KV], int8 (0/1), masked by valid_q & valid_k
            mask_tile = tl.load(
                mask_ptr + qo_mask[:, None] * num_kv_tokens + kv_mask[None, :],
                mask=valid_q[:, None] & valid_k[None, :],
                other=0
            )  # [BLOCK_Q, BLOCK_KV]

            # Apply mask: invalid entries -> -inf
            acc = tl.where(mask_tile != 0, acc, -float('inf'))

            # Store logits tile to logits_ptr: indexing [row, head, col]
            for i in range(BLOCK_Q):
                row = qo_start + qo_mask[i]
                for j in range(BLOCK_KV):
                    col = kv_start + kv_mask[j]
                    ptr = logits_ptr + row * (num_qo_heads * num_kv_tokens) + h * num_kv_tokens + col
                    val = acc[i, j]
                    tl.store(ptr, val)

            # Track row-wise maxima for lse
            for i in range(BLOCK_Q):
                row_acc = acc[i, :]  # [BLOCK_KV]
                row_max_i = tl.max(row_acc, axis=0)  # scalar
                lse_acc[i] = tl.maximum(lse_acc[i], row_max_i)

        # Store lse_row: scale by 1/log(2) to get 2-base LSE
        inv_log2 = 1.0 / math.log(2.0)
        for i in range(BLOCK_Q):
            tl.store(
                lse_row_ptr + (qo_start + qo_mask[i]) * num_qo_heads + h,
                lse_acc[i] * inv_log2
            )


@triton.jit
def compute_output_from_logits_and_lse(
    k_ptr,  # *float32, [num_kv_tokens, num_qo_heads, head_dim] (K expanded)
    v_ptr,  # *float32, [num_kv_tokens, num_qo_heads, head_dim] (V expanded)
    mask_ptr,  # *int8, [num_q_tokens, num_kv_tokens]
    logits_ptr,  # *float32, [num_q_tokens, num_qo_heads, num_kv_tokens]
    output_ptr,  # *float32, [num_q_tokens, num_qo_heads, head_dim]
    lse_row_ptr,  # *float32, [num_q_tokens, num_qo_heads]
    sm_scale,  # float32 scalar (unused here but kept for signature symmetry)
    num_q_tokens: tl.constexpr,
    num_kv_tokens: tl.constexpr,
    num_qo_heads: tl.constexpr,
    head_dim: tl.constexpr,
    BLOCK_Q: tl.constexpr,
    BLOCK_KV: tl.constexpr,
    BH: tl.constexpr
):
    # Grid: (num_batches, ceil_div(num_qo_heads, BH), ceil_div(num_q_tokens, BLOCK_Q))
    pid_b = tl.program_id(0)
    pid_h = tl.program_id(1)
    pid_q = tl.program_id(2)

    qo_start = pid_b * num_q_tokens
    kv_start = pid_b * num_kv_tokens

    h_start = pid_h * BH
    qo_mask = pid_q * BLOCK_Q + tl.arange(0, BLOCK_Q)  # [BLOCK_Q]
    valid_q = qo_mask < num_q_tokens

    for hh in range(BH):
        h = h_start + hh
        if h >= num_qo_heads:
            break

        # Load lse values per row (already stored as 2-base in kernel 1)
        lse_2base = tl.load(
            lse_row_ptr + (qo_start + qo_mask) * num_qo_heads + h,
            mask=valid_q,
            other=-float('inf')
        )  # [BLOCK_Q]

        # For each query row i in this tile, compute output row
        for i in range(BLOCK_Q):
            if not valid_q[i]:
                continue
            row = qo_start + qo_mask[i]
            # Initialize output accumulator for this row and head
            out_row = tl.zeros((head_dim,), dtype=tl.float32)

            # Compute softmax over KV tokens: logits[row, h, :]
            for kv_off in range(0, num_kv_tokens, BLOCK_KV):
                kv_mask = kv_off + tl.arange(0, BLOCK_KV)  # [BLOCK_KV]
                valid_k = kv_mask < num_kv_tokens

                # Load logits tile for this row and head: [BLOCK_KV]
                logits_row = tl.load(
                    logits_ptr + row * (num_qo_heads * num_kv_tokens) + h * num_kv_tokens + kv_start + kv_mask,
                    mask=valid_k,
                    other=-float('inf')
                )  # [BLOCK_KV]

                # Subtract lse_2base[i] to get logsumexp-based normalization
                exp_row = tl.exp(logits_row - lse_2base[i])  # [BLOCK_KV]

                # Compute denominator
                denom = tl.sum(exp_row, axis=0)  # scalar

                # Load K tile for matvec: [BLOCK_KV, head_dim]
                k_block = tl.load(
                    k_ptr + (kv_start + kv_mask[:, None]) * (num_qo_heads * head_dim) + h * head_dim,
                    mask=valid_k[:, None],
                    other=0.0
                )  # [BLOCK_KV, head_dim]

                # Load V tile: [BLOCK_KV, head_dim]
                v_block = tl.load(
                    v_ptr + (kv_start + kv_mask[:, None]) * (num_qo_heads * head_dim) + h * head_dim,
                    mask=valid_k[:, None],
                    other=0.0
                )  # [BLOCK_KV, head_dim]

                # Accumulate output contribution per column
                for j in range(BLOCK_KV):
                    if valid_k[j]:
                        weight = exp_row[j] / denom  # scalar
                        v_col = v_block[j, :]  # [head_dim]
                        out_row += weight * v_col

            # Store output row for this head
            out_ptr = output_ptr + row * (num_qo_heads * head_dim) + h * head_dim
            tl.store(out_ptr + tl.arange(0, head_dim), out_row)

            kv_end = int(kv_indptr[b + 1].item())

            num_kv_tokens = kv_end - kv_start

            # Track row-wise maxima for lse
            for i in range(BLOCK_Q):
                row_acc = acc[i, :]  # [BLOCK_KV]
                row_max_i = tl.max(row_acc, axis=0)  # scalar
                lse_acc[i] = tl.maximum(lse_acc[i], row_max_i)

        # Store lse_row: scale by 1/log(2) to get 2-base LSE
        inv_log2 = 1.0 / math.log(2.0)
        for i in range(BLOCK_Q):
            tl.store(
                lse_row_ptr + (qo_start + qo_mask[i]) * num_qo_heads + h,
                lse_acc[i] * inv_log2
            )


# Kernel to compute final output from stored logits and lse, also writing lse.
@triton.jit
def compute_output_from_logits_and_lse(
    k_ptr,  # *float32, [num_kv_tokens, num_qo_heads, head_dim] (K expanded)
    v_ptr,  # *float32, [num_kv_tokens, num_qo_heads, head_dim] (V expanded)
    mask_ptr,  # *int8, [num_q_tokens, num_kv_tokens]
    logits_ptr,  # *float32, [num_q_tokens, num_qo_heads, num_kv_tokens]
    output_ptr,  # *float32, [num_q_tokens, num_qo_heads, head_dim]
    lse_row_ptr,  # *float32, [num_q_tokens, num_qo_heads]
    sm_scale,  # float32 scalar (kept for signature symmetry)
    num_q_tokens: tl.constexpr,
    num_kv_tokens: tl.constexpr,
    num_qo_heads: tl.constexpr,
    head_dim: tl.constexpr,
    BLOCK_Q: tl.constexpr,
    BLOCK_KV: tl.constexpr,
    BH: tl.constexpr
):
    # Grid: (num_batches, ceil_div(num_qo_heads, BH), ceil_div(num_q_tokens, BLOCK_Q))
    pid_b = tl.program_id(0)
    pid_h = tl.program_id(1)
    pid_q = tl.program_id(2)

    qo_start = pid_b * num_q_tokens
    kv_start = pid_b * num_kv_tokens

    h_start = pid_h * BH
    qo_mask = pid_q * BLOCK_Q + tl.arange(0, BLOCK_Q)  # [BLOCK_Q]
    valid_q = qo_mask < num_q_tokens

    for hh in range(BH):
        h = h_start + hh
        if h >= num_qo_heads:
            break

        # Load lse values per row (already stored as 2-base in compute_store_logits_tile)
        lse_2base = tl.load(
            lse_row_ptr + (qo_start + qo_mask) * num_qo_heads + h,
            mask=valid_q,
            other=-float('inf')
        )  # [BLOCK_Q]

        # For each query row i in this tile, compute output row
        for i in range(BLOCK_Q):
            if not valid_q[i]:
                continue
            row = qo_start + qo_mask[i]
            # Initialize output accumulator for this row and head
            out_row = tl.zeros((head_dim,), dtype=tl.float32)

            # Compute softmax over KV tokens: logits[row, h, :]
            for kv_off in range(0, num_kv_tokens, BLOCK_KV):
                kv_mask = kv_off + tl.arange(0, BLOCK_KV)  # [BLOCK_KV]
                valid_k = kv_mask < num_kv_tokens

                # Load logits tile for this row and head: [BLOCK_KV]
                logits_row = tl.load(
                    logits_ptr + row * (num_qo_heads * num_kv_tokens) + h * num_kv_tokens + kv_start + kv_mask,
                    mask=valid_k,
                    other=-float('inf')
                )  # [BLOCK_KV]

                # Subtract lse_2base[i] to get logsumexp-based normalization
                exp_row = tl.exp(logits_row - lse_2base[i])  # [BLOCK_KV]

                # Compute denominator
                denom = tl.sum(exp_row, axis=0)  # scalar

                # Load K tile for matvec: [BLOCK_KV, head_dim]
                k_block = tl.load(
                    k_ptr + (kv_start + kv_mask[:, None]) * (num_qo_heads * head_dim) + h * head_dim,
                    mask=valid_k[:, None],
                    other=0.0
                )  # [BLOCK_KV, head_dim]

                # Load V tile: [BLOCK_KV, head_dim]
                v_block = tl.load(
                    v_ptr + (kv_start + kv_mask[:, None]) * (num_qo_heads * head_dim) + h * head_dim,
                    mask=valid_k[:, None],
                    other=0.0
                )  # [BLOCK_KV, head_dim]

                # Accumulate output contribution per column
                for j in range(BLOCK_KV):
                    if valid_k[j]:
                        weight = exp_row[j] / denom  # scalar
                        v_col = v_block[j, :]  # [head_dim]
                        out_row += weight * v_col

            # Store output row for this head
            out_ptr = output_ptr + row * (num_qo_heads * head_dim) + h * head_dim
            tl.store(out_ptr + tl.arange(0, head_dim), out_row)
