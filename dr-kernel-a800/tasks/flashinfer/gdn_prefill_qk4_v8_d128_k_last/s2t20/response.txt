  - Compute new_v = beta * v[t] + (1 - beta) * old_v, where v[t] is [H, V].
  - Compute state_remove = k[t] @ old_v, state_update = k[t] @ new_v.
  - Update state_HKV = g * state_HKV - state_remove + state_update.
  - Output[t] = scale * q[t] @ state_HKV.
- Triton kernels used:
  - softplus_a_dt_kernel: computes softplus(a + dt_bias) per (t, hv) using a 2D grid.
  - sigmoid_b_kernel: computes sigmoid(b) per (t, hv) using a 2D grid.
  - exp_minus_expA_times_softplus_kernel: computes g = exp(-exp(A_log[hv]) * softplus) per (t, hv).
