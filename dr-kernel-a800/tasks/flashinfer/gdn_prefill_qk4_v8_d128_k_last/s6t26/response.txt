High-level analysis and plan
- The original run does per-step updates across sequence length T and per-head H, with head_size N=128. It computes:
  - g = exp(-exp(A_log) * softplus(a + dt_bias))
  - beta = sigmoid(b)
  - For each t and each head h:
    - old_v = k[t, h] @ state_old[t, h] -> vector [N]
    - new_v = beta[t, h] * v[t, h] + (1 - beta[t, h]) * old_v
    - state_remove_kk = k[t, h]^T @ old_v -> scalar per kk
    - state_update_kk = k[t, h]^T @ new_v -> scalar per kk
    - state_new[t, h, kk, :] = g[t, h] * state_old[t, h, kk, :] + state_update_kk - state_remove_kk
    - output[t, h, :] = scale * q_exp[t, h] @ state_new[t, h]
- Triton constraints:
  - Triton kernels are launched with a grid and operate on tensors of known shapes. Per-head indexing of 2D tensors must be handled by launching one program per (t, h) and passing the relevant 1D vectors. We will:
    - Launch compute_g_kernel to compute g for all (t, h) pairs.
    - Launch sigmoid_kernel to compute beta for all (t, h) pairs.
    - Launch mm_k_state_kernel per (t, h) to compute old_v = k[t, h] @ state_old[t, h] and store as a vector.
    - Launch mm_kT_vec_kernel per (t, h) to compute state_remove and state_update scalars (one program per kk, but we’ll structure it to compute both scalars per kk across kk loop; alternatively, compute per-kk contributions by looping kk inside the program, but Triton doesn’t support dynamic loops; we will compute both per-kk in a single kernel by reusing scalar results).
    - Launch matmul_row_kernel per (t, h) to compute output[t, h] as a vector using q_exp[t, h] @ state_new[t, h].
    - Launch update_state_kernel per (t, h) to update the state tensor S_new for that (t, h). This kernel takes S_old, q, v, and computed old_v, state_remove/state_update, and g, and writes S_new. This can be done per (t, h) since it operates on S_new which is a 2D matrix, but Triton doesn’t support per-element indexing across 2D without Python-side loops. Given the requirement, we’ll implement update_state per (t, h) by launching a single kernel that updates the entire [N, N] matrix for that (t, h) by computing contributions and assigning, relying on Triton pointer arithmetic for rows and columns. This is the most robust way to ensure Triton-only and actual kernel usage.
