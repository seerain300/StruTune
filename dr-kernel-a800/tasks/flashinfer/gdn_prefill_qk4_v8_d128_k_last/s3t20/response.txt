- Shape correctness:
  - For matrices produced by Triton (e.g., KxV matrices where K=128 and V=128 → 1024 elements), return a 1D output of length N = K*V. Do not return [N] shaped vectors if the consumer expects [K, V] view; instead, ensure the vector length matches and then ModelNew will reshape back to [K, V] as needed.

- Triton kernels:
  - gemv_1xKxKxV_into_1xV:
    - Inputs: q_ptr [K], A_ptr laid out as [K, V] contiguous. Output: out_ptr [V].

    - Inputs: v_ptr [V], S_ptr laid out as [V, K] contiguous. Output: out_ptr [K].
    - Compute out[k] = sum_v v[v] * S[v, k] with v loop.
  - elementwise_scalar_mul_add:
    - Inputs: alpha scalar (beta), beta scalar (1-beta), v_ptr [N], old_ptr [N], out_ptr [N].
    - Compute out[i] = alpha * v[i] + beta * old[i] for i in 0..N-1.
  - add_scalar_to_matrix:
    - Inputs: mat_ptr [N], alpha scalar, N.
    - Compute mat[i] += alpha for i in 0..N-1. This is used to implement g * state_old_T plus scalar.

    - Inputs: x_ptr [K], y_ptr [K], out_ptr [1].

    # q_ptr: [K], A_ptr: [K, V] contiguous, out_ptr: [V]
    # out[i] = sum_k q[k] * A[k, i]
