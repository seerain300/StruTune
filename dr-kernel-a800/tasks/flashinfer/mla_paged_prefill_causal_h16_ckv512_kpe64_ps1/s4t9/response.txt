Given the original code’s logic:

  - q_pe: [total_q, 16, 64]

  - kpe_cache: [num_pages, 1, 64] squeezed to [num_pages, 64]

- For each batch b:

  - tok_idx = kv_indices[kv_indptr[b]: kv_indptr[b+1]] -> length L

  - Kp = kpe_cache[tok_idx] -> [L, 64]

    - attn = softmax(logits_scaled - lse) per head
    - out[h, :] = attn[h, :] @ Kc
- Output:
  - output: [total_q, 16, 512] bfloat16
  - lse: [total_q, 16] float32

Implementation plan:
1) Triton kernel compute_logits_ih: grid=(q_len, H), for each (i, h), loop over L tokens and D and Kp dims to compute logits[h, l] = sum_d qn[h, d] * Kc[d, l] + sum_k qp[h, k] * Kp[k, l]. We store logits into a 1D buffer for later use.
2) Triton kernel lse_and_mask_ih: grid=(q_len, H), reads logits and computes lse with causal mask: for each k, if k <= query_abs_pos, set to -inf; else use logits[k]. We do this with elementwise operations and a reduction to max and sum. We store lse in float32.
3) Triton kernel softmax_ih: grid=(q_len, H), reads logits_scaled and lse, computes attn = exp(logits_scaled - lse) normalized by sum(exp(...)). We store attn to a 1D buffer (flattened over i,h).
4) Triton kernel matvec_per_head: grid=(H, tiles), for each head h, loops over output columns in tiles and over L to compute out[h, d_tile] = sum_l attn[h, l] * Kc[l, d_tile]. We write out in bfloat16. Host will copy into the final output tensor at the appropriate query row.

The forward:
- Computes shapes, allocates outputs, ensures inputs are on CUDA, and launches the Triton kernels. It avoids any torch matmul, softmax, or reductions on tensors.
