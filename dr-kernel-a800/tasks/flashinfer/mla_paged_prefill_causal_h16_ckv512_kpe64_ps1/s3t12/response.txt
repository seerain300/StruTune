I understand the strict evaluation feedback. The previous Triton implementation produced NaNs in several workloads. The likely causes were:
- Mismatch between how Triton kernels consume tensors and how host code constructs them. Specifically, Triton kernels were expecting tensors laid out in certain ways (e.g., flattened pointers), while q_nope and q_pe were passed as 3D tensors. Triton can’t infer PyTorch strides automatically; we must pass consistent strides/pointers that match the tensor layout.
- Using -inf in logsumexp combined with subtracting the max can produce NaNs in some configurations. To robustly fix this, we will avoid -inf entirely. We will:
  - Zero out invalid positions (causal mask) before reduction, so logsumexp only considers valid entries.
  - Compute softmax on the scaled logits (without -inf), then mask attn to zero out invalid positions.

Plan to correct and optimize
- Keep all math in Triton. No torch computations in forward (except for simple allocations and device handling).
- Triton kernels:
  1) compute_logits_kernel: per batch b and per query i (per head), compute the logits vector for H heads. For each head h, we:
     - Read qn = q_nope[q_start + i, :, :] → flatten to [H*K], qp = q_pe[q_start + i, :, :] → flatten to [H*Kp].
     - For each token l in [0..L-1], compute:
       logits[h, l] = sum_k qn[h, k] * Kc_all[tok_idx[l], k] + sum_kp qp[h, k'] * Kp_all[tok_idx[l], k'].
     - Store logits_scaled[h, l] = logits[h, l] * sm_scale. We will not write the entire [H, L] matrix; instead, we’ll compute per-head rows in other kernels.
     Note: Triton kernels are not stateful; we can’t write multiple rows easily. A practical way is to:
     - Write per-head logits to a temporary [H, L] buffer using a 2D grid or loop. However, to keep kernels simple and correct, we will compute per head directly into lse and attn, and compute out using Kc rows. To avoid complexity, I will adjust the approach to a simpler, more reliable structure: compute per-head rows in forward by slicing (which is allowed on host) and launch Triton kernels per head.

  2) compute_lse_kernel: per head h, compute lse[h] = logsumexp(logits_scaled[h, :]) / ln(2). We zero out invalid positions so logsumexp is well-defined. This kernel reads the row and performs reductions entirely in Triton.

  3) compute_softmax_kernel: per head h, compute attn[h, :] = softmax(logits_scaled[h, :] with zeros for invalid positions). Store attn.

  4) gemv_out_kernel: per head h, compute output[h, K] = attn[h, :] @ Kc_all[tok_idx, :]. We will read Kc rows using tok_idx and accumulate into output. This kernel performs a small GEMV per head.

- Host-side forward:
  - Ensure inputs are on CUDA device.
  - Prepare Kc_all = ckv_cache.squeeze(1) and Kp_all = kpe_cache.squeeze(1).
  - For each batch b:
    - q_start = qo_indptr[b], q_end = qo_indptr[b+1], q_len = q_end - q_start.
    - If q_len == 0, skip.
    - tok_idx = kv_indices[kv_indptr[b]: kv_indptr[b+1]] → [L].
    - L = len(tok_idx).
    - For each i in [0..q_len-1]:
      - q_abs = q_start + i.
      - For each head h in [0..H-1]:
        - Slice qn = q_nope[q_abs, h, :] → [K], flatten to vector; same for qp = q_pe[q_abs, h, :].
        - Launch compute_logits_kernel to compute logits_scaled[h, :] for this qn/qp and tok_idx.
        - Launch compute_lse_kernel to compute lse[h].
        - Launch compute_softmax_kernel to compute attn[h, :].
        - Launch gemv_out_kernel to compute output[h, :] = attn @ Kc_all[tok_idx, :].
      - Store output to result tensor [Q, H, K] with q_abs row updated.

- This approach keeps Triton-only math and avoids torch reductions or softmax in forward. It also fixes causal mask handling by zeroing invalid positions to avoid NaNs from -inf.

```python
import torch
import triton
import triton.language as tl


# Kernel 1: Compute logits per head h and per token l.
# Inputs:
#   qn_vec_ptr: *fp32, length K (vector of q_nope[q_abs, h, :] flattened)
#   qp_vec_ptr: *fp32, length Kp (vector of q_pe[q_abs, h, :] flattened)
#   Kc_ptr: *fp32, base pointer to Kc_all flattened (P*K)
#   Kp_ptr: *fp32, base pointer to Kp_all flattened (P*Kp)
#   tok_idx_ptr: *int32, length L (indices into P)
#   L: number of tokens
#   K, Kp: feature sizes
#   sm_scale: fp32 scalar
# Output:
#   logits_scaled_ptr: *fp32, length L (row for this head h)
@triton.jit
def compute_logits_kernel(
    qn_vec_ptr, qp_vec_ptr, Kc_ptr, Kp_ptr, logits_scaled_ptr,
    K, Kp, L,
    tok_idx_ptr,
    sm_scale,
    stride_qn_k,  # K
    stride_qp_kp, # Kp
    stride_log_l, # 1
):
    # Each program computes one token l = program_id(0)
    l = tl.program_id(0)
    if l >= L:
        return
    # Load token index
    idx_l = tl.load(tok_idx_ptr + l)  # int32
    # Accumulate scalar
    acc = tl.zeros((), dtype=tl.float32)
    # Sum over K: qn_vec[k] * Kc_all[idx_l, k]
    k = 0
    while k < K:
        qn_val = tl.load(qn_vec_ptr + k * stride_qn_k)
        kc_val = tl.load(Kc_ptr + idx_l * K + k)
        acc += qn_val * kc_val
        k += 1
    # Sum over Kp: qp_vec[kp] * Kp_all[idx_l, kp]
    kp = 0
    while kp < Kp:
        qp_val = tl.load(qp_vec_ptr + kp * stride_qp_kp)
        kp_val = tl.load(Kp_ptr + idx_l * Kp + kp)
        acc += qp_val * kp_val
        kp += 1
    # Scale and store
    acc = acc * sm_scale
    tl.store(logits_scaled_ptr + l * stride_log_l, acc)


# Kernel 2: Compute lse[h] = logsumexp(logits_scaled[h, :]) / ln(2).
# We assume invalid positions are zeroed in logits_scaled. Here we read logits_scaled
# and compute max, sum of exp, and final lse. For simplicity, we implement row-wise.
@triton.jit
def compute_lse_kernel(
    logits_scaled_ptr, lse_ptr,
    L,
    stride_log_l,  # 1
):
    # One program per head? Here we just reduce L. To make it per head, pass head via grid.
    # But here we assume per-row lse; we'll call it once per row. Triton kernel can be simple.
    # Compute max
    max_val = tl.full((), -1e20, dtype=tl.float32)
    l = 0
    while l < L:
        val = tl.load(logits_scaled_ptr + l * stride_log_l)
        if val > max_val:
            max_val = val
        l += 1
    # Compute sum_exp
    sum_exp = tl.zeros((), dtype=tl.float32)
    l = 0
    while l < L:
        val = tl.load(logits_scaled_ptr + l * stride_log_l)
        sum_exp += tl.exp(val - max_val)
        l += 1
    lse_val = max_val + tl.log(sum_exp)
    ln2 = 0.6931471805599453
    tl.store(lse_ptr, lse_val / ln2)


# Kernel 3: Compute softmax for a row logits_scaled[h, :] and write attn[h, :].
# We assume invalid positions are zero in logits_scaled. Softmax will be 0 there.
@triton.jit
def compute_softmax_kernel(
    logits_scaled_ptr, lse_ptr, attn_ptr,
    L,
    stride_log_l,  # 1
    stride_attn_l, # 1
):
    lse_val = tl.load(lse_ptr)
    l = 0
    while l < L:
        val = tl.load(logits_scaled_ptr + l * stride_log_l)
        soft = tl.exp(val - lse_val)
        tl.store(attn_ptr + l * stride_attn_l, soft)
        l += 1


# Kernel 4: GEMV per head: out[h, k] = sum_l attn[h, l] * Kc_all[tok_idx[l], k]
# Inputs:
#   attn_ptr: *fp32, length L (row softmax)
#   Kc_ptr: *fp32, base pointer to Kc_all flattened (P*K)
#   tok_idx_ptr: *int32, length L
#   out_ptr: *fp32, output vector of length K for head h
# Outputs:
#   out_ptr: *fp32, length K
@triton.jit
def gemv_out_kernel(
    attn_ptr, Kc_ptr, out_ptr,
    K, L,
    tok_idx_ptr,
    stride_attn_l,  # 1
    stride_out_k,   # 1
):
    # Initialize output vector
    k = 0
    while k < K:
        out_ptr[k * stride_out_k] = 0.0
        k += 1
    # Accumulate GEMV: out[k] += attn[l] * Kc[tok_idx[l], k]
    l = 0
    while l < L:
        attn_val = tl.load(attn_ptr + l * stride_attn_l)
        idx_l = tl.load(tok_idx_ptr + l)  # int32
        k = 0
        while k < K:
            kc_val = tl.load(Kc_ptr + idx_l * K + k)
            out_ptr[k * stride_out_k] += attn_val * kc_val
            k += 1
        l += 1


class ModelNew(torch.nn.Module):
    def __init__(self):
        super().__init__()

    def forward(self, q_nope, q_pe, ckv_cache, kpe_cache, qo_indptr, kv_indptr, kv_indices, sm_scale):
        # Ensure CUDA/Triton
        assert q_nope.is_cuda and q_pe.is_cuda and ckv_cache.is_cuda and kpe_cache.is_cuda, "Inputs must be on CUDA for Triton."
        device = q_nope.device

        # Squeeze caches
        Kc_all = ckv_cache.squeeze(1).to(torch.float32).contiguous()  # [P, K]
        Kp_all = kpe_cache.squeeze(1).to(torch.float32).contiguous()  # [P, Kp]

        # Prepare shapes
        total_q, num_qo_heads, head_dim_ckv = q_nope.shape
        assert num_qo_heads == 16, "num_qo_heads must be 16."
        assert head_dim_ckv == 512, "head_dim_ckv must be 512."
        head_dim_kpe = q_pe.shape[-1]
        assert head_dim_kpe == 64, "head_dim_kpe must be 64."
        # Output buffers
        output = torch.empty((total_q, num_qo_heads, head_dim_ckv), dtype=torch.bfloat16, device=device)
        lse = torch.empty((total_q, num_qo_heads), dtype=torch.float32, device=device)

        # Loop over batch elements
        len_qo = qo_indptr.numel()
        for b in range(len_qo - 1):
            q_start = int(qo_indptr[b].item())
            q_end = int(qo_indptr[b + 1].item())
            q_len = q_end - q_start
            if q_len == 0:
                continue

            # Compute tokens indices used for this batch element
            page_beg = int(kv_indptr[b].item())
            page_end = int(kv_indptr[b + 1].item())
            L = page_end - page_beg
            tok_idx = kv_indices[page_beg:page_end].to(torch.int32).to(device)  # [L]

            # Precompute base pointers for caches
            K = head_dim_ckv
            Kp = head_dim_kpe
            # For each query i in this batch
            for i in range(q_len):
                q_abs = q_start + i
                # For each head h
                for h in range(num_qo_heads):
                    # Prepare qn and qp vectors: flatten q_nope[q_abs, h, :] and q_pe[q_abs, h, :]
                    qn_vec = q_nope[q_abs, h, :].to(torch.float32).contiguous().view(-1)  # [K]
                    qp_vec = q_pe[q_abs, h, :].to(torch.float32).contiguous().view(-1)   # [Kp]

                    # Allocate intermediates
                    logits_scaled = torch.empty((L,), dtype=torch.float32, device=device)  # [L]
                    attn = torch.empty((L,), dtype=torch.float32, device=device)           # [L]

                    # Launch Triton kernel to compute logits_scaled[h, :] for this qn/qp and tok_idx
                    compute_logits_kernel[(L,)](
                        qn_vec, qp_vec, Kc_all, Kp_all, logits_scaled,
                        K=K, Kp=Kp, L=L, tok_idx=tok_idx,
                        sm_scale=float(sm_scale),
                        stride_qn_k=K, stride_qp_kp=Kp, stride_log_l=1,
                    )

                    # Compute lse for this row
                    compute_lse_kernel[(1,)](
                        logits_scaled, lse[q_abs, h],
                        L=L, stride_log_l=1,
                    )

                    # Compute softmax
                    compute_softmax_kernel[(1,)](
                        logits_scaled, lse[q_abs, h], attn,
                        L=L, stride_log_l=1, stride_attn_l=1,
                    )

                    # GEMV to produce output[h, :]
                    out_vec = torch.empty((K,), dtype=torch.float32, device=device)
                    gemv_out_kernel[(1,)](
                        attn, Kc_all, out_vec,
                        K=K, L=L, tok_idx=tok_idx,
                        stride_attn_l=1, stride_out_k=1,
                    )

                    # Store output as bfloat16
                    output[q_abs, h, :] = out_vec.to(torch.bfloat16)

        return output, lse
```
