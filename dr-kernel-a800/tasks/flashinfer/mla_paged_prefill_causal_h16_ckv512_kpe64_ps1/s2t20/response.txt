High-level analysis and plan
- The original PyTorch code processes multiple queries per batch element:
  - For each batch b and each query i:
    - Compute logits per head: logits[h, j] = (qn[h] · Kc[j]) + (qp[h] · Kp[j]) where qn/qp come from q_nope/q_pe and Kc/Kp are selected from ckv_cache/kpe_cache using kv_indices. Kc/Kp are gathered for all kv positions in the current batch element.
    - Scale logits by sm_scale, apply a causal mask based on absolute position (query_abs_pos = prefix_len + i, prefix_len = kv_len - q_len).
    - Compute logsumexp of logits per head (converted to log2), then softmax over j and multiply by Kc[j] to produce output vector per head. Store output as bfloat16 and lse as float32.
- Triton strategy:
  - Launch a Triton kernel per query. The grid will be (len_indptr - 1, q_len), i.e., one Triton program for each batch element b and query i. This avoids dynamic loops inside the kernel and allows specialization per workload.
  - Inside the kernel:
    - Compute q_abs = q_start + i where q_start = qo_indptr[b].
    - Load qn[h, :] and qp[h, :] from q_nope and q_pe for all heads, cast to float32.
    - Gather Kc_sel = ckv_cache[tok_idx] and Kp_sel = kpe_cache[tok_idx] where tok_idx = kv_indices[page_beg:page_end] and for batch b, page_beg = kv_indptr[b], page_end = kv_indptr[b+1]. We will host-side gather these into temporary tensors and pass them to the kernel as [kv_len, 512] and [kv_len, 64] bfloat16.
    - Compute logits per head by looping j in [0, kv_len): logits[h, j] = sum_k qn[h, k] * Kc_sel[j, k] + sum_k qp[h, k] * Kp_sel[j, k].
    - Scale logits by sm_scale, apply causal mask (set logits[j] = -inf if j < query_abs_pos).
    - Compute logsumexp in log2: lse = log(sum(exp(logits))) * (1/ln(2)) + max(logits). For numerical stability, compute m = max(logits) and then lse = m + log(sum(exp(logits - m))) * ln2_inv. Implement log via tl.log. This is essential because the original uses torch.logsumexp; we ensure it’s Triton-only via tl.log.
    - Compute softmax: exp_logits = exp(logits - lse); softmax = exp_logits / sum(exp_logits).
    - Compute output vector: out[h, :] = sum_j softmax[j] * Kc_sel[j, :], store as bfloat16.
    - Store lse per head to lse[q_abs, h] as float32.
  - ModelNew.forward will:
    - Assert shapes and constants (num_heads=16, head_dim_ckv=512, head_dim_kpe=64).
    - For each batch element b, compute tok_idx, host-side gather Kc_sel and Kp_sel (torch ops only for selection, no computation), cast to bfloat16 and contiguous.
    - Launch the Triton kernel once per query with grid=(1, q_len), passing all pointers and meta-parameters. No torch math is performed in host code beyond allocation and gathering.
