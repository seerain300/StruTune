- Triton kernels:
  1) compute_logits_and_lse_kernel:
     - Input: qn_row [512], qp_row [64], Kc [KV, 512], Kp [KV, 64], output logits [H, KV], output lse [H], scalars sm_scale, prefix_len, query_abs_pos.

    - lse[h] = logsumexp(logits_scaled[h, :]) / ln(2)
    - attn[h, :] = softmax(logits_scaled[h, :])
    - out[h, :] = attn[h, :] @ Kc -> [512]
  - The implementation asserts num_qo_heads == 16, head_dim_ckv == 512, head_dim_kpe == 64.

- Triton strategy:
  - Implement three Triton kernels:
    1) compute_logits_and_lse_kernel:
       - Inputs: qn_row [512], qp_row [64], Kc [KV, 512], Kp [KV, 64], per-head outputs logits [KV], per-head output lse [].
       - Compute S = qn_row @ Kc.T (GEMV) and T = qp_row @ Kp.T (GEMV), accumulate over KV tiles. S and T are vectors of length 512 and 512.
       - logits = S + T; apply scaling and causal mask (j > (prefix_len + i)).
       - Compute lse = logsumexp(logits) / ln(2) stably (subtract max).
       - Store logits and lse.
    2) softmax_row_kernel:
       - Inputs: logits [KV], output attn [KV], ln2 float.
       - Compute stable softmax: m = max(logits), exp(logits - m), sum, attn = exp / sum, then divide by ln2 to match lse normalization. Store attn.
    3) compute_out_row_kernel:
       - Inputs: attn [KV], Kc [KV, 512], output out [512].
       - Compute out = attn @ Kc via tiled reduction over KV (BLOCK_K=128).

  - Integration in forward:
    - Ensure inputs are on CUDA. Convert caches to float32 for compute.
    - For each batch b and query i, gather qn_row and qp_row for each head h, and gather Kc, Kp using tok_idx from kv_indptr.
    - Launch compute_logits_and_lse_kernel for each head h.
    - Store lse[q_start + i, h] as float32.
    - Launch softmax_row_kernel to produce attn row for that head.
    - Launch compute_out_row_kernel to produce out row and store output[q_start + i, h, :] as float32.
    - After processing all queries and heads, cast output to bfloat16 and return (output, lse).

- Important: Triton kernels must be actually invoked from forward; no decoy definitions. I will call all three kernels in forward for every (b, i, h).

    qn_ptr,         # [512] float32
    qp_ptr,         # [64]  float32
    Kc_ptr,         # [KV, 512] float32
    Kp_ptr,         # [KV, 64]  float32
    logits_ptr,     # [KV]      float32, output logits for this head
    lse_ptr,        # []        float32, output lse for this head
    sm_scale: tl.float32,          # scalar
    prefix_len: tl.int32,          # scalar
    query_abs_pos: tl.int32,       # scalar
    KV: tl.int32,                  # number of KV tokens
    Dn: tl.constexpr,              # head_dim_ckv = 512
    Dp: tl.constexpr,              # head_dim_kpe = 64
    BLOCK_K: tl.constexpr = 128,   # tile size over KV
):
    # Accumulate S = qn_row @ Kc.T over tiles of Kc
    acc_S = tl.zeros((Dn,), dtype=tl.float32)
    qn_row = tl.load(qn_ptr + tl.arange(0, Dn))  # [512]
    for k0 in range(0, KV, BLOCK_K):
        k_idx = k0 + tl.arange(0, BLOCK_K)               # [BLOCK_K]
        mask_k = k_idx < KV
        Kc_tile = tl.load(Kc_ptr + k_idx[:, None] * Dn + tl.arange(0, Dn), mask=mask_k[:, None], other=0.0)
        acc_S += tl.sum(Kc_tile * qn_row[None, :], axis=0)  # [512]

        k_idx = k0 + tl.arange(0, BLOCK_K)               # [BLOCK_K]
        mask_k = k_idx < KV
        Kp_tile = tl.load(Kp_ptr + k_idx[:, None] * Dp + tl.arange(0, Dp), mask=mask_k[:, None], other=0.0)  # [BLOCK_K, 64]

        for kk in range(0, BLOCK_K):

                acc_T += contrib
