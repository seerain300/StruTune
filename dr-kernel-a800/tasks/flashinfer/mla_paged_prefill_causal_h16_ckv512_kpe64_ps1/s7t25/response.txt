Understanding the failures and constraints

- The evaluator reports:
  - Multiple workloads failed with “IndexError: index 2 is out of bounds for dimension 0 with size 2.” This strongly indicates a shape/dimension mismatch in Triton tensor indexing and suggests some tensors were being treated as 3D (Triton complained about dimension 2) when the code was writing 2D-only logic.
  - Another reported failure: “INCORRECT_NUMERICAL output,” meaning the numerical result didn’t match the PyTorch reference even when the run didn’t crash. Given the observed mismatch, it’s likely our Triton kernels were either not handling the causal mask or not computing matmuls/softmax precisely like PyTorch.

- Original PyTorch logic:
  - For each batch element b and each query i in that batch:
    - qn = q_nope[b, i] → shape [16, 512], q_pe[b, i] → [16, 64].
    - From caches, gather keys for tokens in kv_indices[b, :] into Kc = ckv_cache[:, tok_idx, :] → [L, 512], Kp = kpe_cache[:, tok_idx, :] → [L, 64], where L = len(kv_indices[b, :]).
    - Compute logits = (qn @ Kc.T) + (qp @ Kp.T) → [16, L].
    - Scale logits by sm_scale, apply causal mask: j >= (L - q_len + i).
    - lse = logsumexp(logits_scaled) per head (base 2).
    - attn = softmax(logits_scaled).
    - output = attn @ Kc → [16, 512].
  - In provided get_inputs(), batch_size=1, q_len=1, L=34. But the evaluator will test many configurations.

Design to ensure correctness and actual Triton usage

- Avoid torch ops on device tensors: no torch.tensor(...) on GPU, no torch.cat in forward. Only allocate torch tensors for outputs and launch Triton kernels for all compute.
- Implement Triton kernels:
  1) Row copy: copy_row_to_fp32_kernel — copies a row of a 3D tensor A[T, M, K] into a 2D fp32 buffer B[T, M*K]. This avoids handling 3D indexing in Triton (which can be finicky). We flatten the [M,K] plane for Triton, since Triton prefers 1D/2D. We reconstruct m and k by integer division/modulo in-kernel.
  2) Transpose per-row: transpose_single_row_kernel — reads a row from 2D src[K, N] and writes a row into 2D dst[N, K] transposed. Useful to produce Kc.T for matmul. We’ll use this to transpose gathered cached keys and query rows (qp for Kp.T).
  3) Left-multiply matmul kernel: matmul_left_kernel — computes A[M, N] @ B[K, N]^T → C[M, K], with BLOCK tiling. We’ll use this twice:
     - First for logits = qn @ Kc.T + qp @ Kp.T. We’ll compute both qn @ Kc.T and qp @ Kp.T and add. Here M=16, N=L, K=512 (and 64 for Kp).
     - Second for out = attn @ Kc. Here M=16, N=L, K=512.
  4) Softmax with causal mask: softmax_mask_row_kernel — row-wise softmax with a causal mask on the last dimension. We’ll use this on logits_scaled.
  5) LSE base-2 row-wise: lse_mask_base2_row_kernel — row-wise logsumexp with causal mask and divide by ln(2). This matches the original’s lse computation.

- Host-side code:
  - For each batch b and each query i:
    - Copy q_nope[b, i] and q_pe[b, i] into fp32 buffers using copy_row_to_fp32_kernel (producing 2D buffers).
    - For each token in kv_indices[b, :]:
      - Copy the corresponding rows of ckv_cache and kpe_cache into fp32 buffers, then transpose to 2D for matmul.
    - Compute qn @ Kc.T and qp @ Kp.T via matmul_left_kernel, add, scale, apply causal mask, compute lse, then softmax.
    - Multiply softmax by Kc.T (transposed cached keys) via matmul_left_kernel to produce output row, store.
  - We allocate output and lse as torch tensors on device, fill, and return.

This approach minimizes Triton complexity (uses only 2D transposes and left-matmul) and avoids problematic 3D indexing. It also ensures we actually launch Triton kernels (no decoy), which is critical per feedback.

import torch
import triton
import triton.language as tl


# Triton kernel: copy one row of a 3D tensor A[T, M, K] into a 2D buffer B[T, M*K] (row-major).
# We flatten the [M,K] plane to a single dimension of size S=M*K. Within the kernel, we reconstruct
# (m, k) via integer division and modulo: m = idx // K, k = idx % K.
@triton.jit
def copy_row_to_fp32_kernel(A_ptr, B_ptr,
                            T, M, K, S,
                            stride_at, stride_am, stride_ak,
                            stride_bt, stride_bk,
                            BLOCK_S: tl.constexpr):
    pid_t = tl.program_id(0)  # index along T (rows)
    # We launch with grid = (T,), so only one row per program instance. BLOCK_S iterates over S in tiles.
    for start in range(0, S, BLOCK_S):
        offs = start + tl.arange(0, BLOCK_S)
        mask = offs < S
        m = offs // K            # shape [BLOCK_S], int
        k = offs % K             # shape [BLOCK_S], int
        # Compute source pointers for A row
        A_block_ptr = A_ptr + pid_t * stride_at + m[:, None] * stride_am + k[:, None] * stride_ak
        a_vals = tl.load(A_block_ptr, mask=mask[:, None], other=0.0)
        # Store to B row at position pid_t
        B_block_ptr = B_ptr + pid_t * stride_bt + offs * stride_bk
        tl.store(B_block_ptr, a_vals, mask=mask)


# Triton kernel: transpose a single row of a 2D tensor src[K, N] into dst[N, K].
# Each program instance handles one row, writing transposed values.
@triton.jit
def transpose_single_row_kernel(src_ptr, dst_ptr,
                                row_idx, K, N,
                                stride_s0, stride_s1,
                                stride_d0, stride_d1):
    k = tl.arange(0, K)
    n = tl.arange(0, N)
    # Load row from src: shape [K, N]
    src_row_ptr = src_ptr + row_idx * stride_s0 + n * stride_s1
    vals = tl.load(src_row_ptr)
    # Store to dst: dst[n, k] = src[row_idx, k]
    dst_row_ptr = dst_ptr + n * stride_d0 + k * stride_d1
    tl.store(dst_row_ptr, vals)


# Triton kernel: left-multiply matmul. Computes C[M, K] = A[M, N] @ B[K, N]^T, where B is provided as a 2D matrix.
# We assume A and B are fp32. This kernel uses simple tiling with BLOCK_M/BLOCK_K/BLOCK_N.
@triton.jit
def matmul_left_kernel(A_ptr, B_ptr, C_ptr,
                       M, N, K,
                       stride_am, stride_an,            # A strides (for M,N) in a 2D view
                       stride_bk, stride_bn,           # B strides (for K,N) in 2D view (B^T has dims (N,K))
                       stride_cm, stride_ck,           # C strides (for M,K)
                       BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr):
    pid_m = tl.program_id(0)  # tile along M
    pid_k = tl.program_id(1)  # tile along K

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_k = pid_k * BLOCK_K + tl.arange(0, BLOCK_K)
    offs_n = tl.arange(0, BLOCK_N)

    # Initialize accumulator
    acc = tl.zeros((BLOCK_M, BLOCK_K), dtype=tl.float32)

    # Loop over N dimension
    for n_start in range(0, N, BLOCK_N):
        n_idx = n_start + offs_n
        # Load A tile: [BLOCK_M, BLOCK_N]
        A_tile_ptr = A_ptr + offs_m[:, None] * stride_am + n_idx[None, :] * stride_an
        A_mask = (offs_m[:, None] < M) & (n_idx[None, :] < N)
        A_tile = tl.load(A_tile_ptr, mask=A_mask, other=0.0)

        # Load B^T tile: [BLOCK_N, BLOCK_K]
        # B^T has shape (N, K). Pointer offset: n_idx along rows of B^T, offs_k along cols.
        BT_tile_ptr = B_ptr + n_idx[:, None] * stride_bk + offs_k[None, :] * stride_bn
        BT_mask = (n_idx[:, None] < N) & (offs_k[None, :] < K)
        BT_tile = tl.load(BT_tile_ptr, mask=BT_mask, other=0.0)

        # Accumulate
        acc += tl.dot(A_tile, BT_tile)

    # Write back to C
    C_tile_ptr = C_ptr + offs_m[:, None] * stride_cm + offs_k[None, :] * stride_ck
    C_mask = (offs_m[:, None] < M) & (offs_k[None, :] < K)
    tl.store(C_tile_ptr, acc, mask=C_mask)


# Triton kernel: row-wise softmax with causal mask (j >= position) along last dimension.
# Input logits_row is 1D length L. Output stores softmax back to logits_row. We use mask: j > position means set to -inf.
@triton.jit
def softmax_mask_row_kernel(logits_row_ptr, L, position,
                            BLOCK_N: tl.constexpr):
    n = tl.arange(0, BLOCK_N)
    # Load logits
    logits = tl.load(logits_row_ptr + n, mask=n < L, other=-float("inf"))
    # Apply causal mask: positions after 'position' get -inf
    causal = n > position
    logits = tl.where(causal & (n < L), -float("inf"), logits)
    # Numerically stable softmax
    max_val = tl.max(logits, axis=0)
    logits = logits - max_val
    exp_logits = tl.exp(logits)
    exp_logits = tl.where(causal & (n < L), 0.0, exp_logits)  # zero out masked positions for sum
    sum_exp = tl.sum(exp_logits, axis=0)
    softmax = exp_logits / sum_exp
    # Store back
    tl.store(logits_row_ptr + n, softmax, mask=n < L)


# Triton kernel: row-wise logsumexp with causal mask and base-2 conversion.
# Input logits_row is 1D length L. Output lse_row[i] = logsumexp(logits with mask) / ln(2).
@triton.jit
def lse_mask_base2_row_kernel(logits_row_ptr, lse_row_ptr, L, position,
                              BLOCK_N: tl.constexpr):
    n = tl.arange(0, BLOCK_N)
    logits = tl.load(logits_row_ptr + n, mask=n < L, other=-float("inf"))
    causal = n > position
    logits = tl.where(causal & (n < L), -float("inf"), logits)
    max_val = tl.max(logits, axis=0)
    logits = logits - max_val
    exp_sum = tl.sum(tl.exp(logits), axis=0)
    lse = max_val + tl.log(exp_sum)  # natural log
    lse = lse / 0.6931471805599453   # 1/ln(2)
    tl.store(lse_row_ptr, lse)

                               T, M, K,
                               stride_at, stride_am, stride_ak,
                               stride_bt, stride_bm, stride_bk,
                               BLOCK_M: tl.constexpr, BLOCK_K: tl.constexpr):
    pid_t = tl.program_id(0)  # row index in T
    for m_start in range(0, M, BLOCK_M):
        for k_start in range(0, K, BLOCK_K):
            offs_m = m_start + tl.arange(0, BLOCK_M)
            offs_k = k_start + tl.arange(0, BLOCK_K)
            mask_m = offs_m < M
            mask_k = offs_k < K
            # Pointer for A row: [M_tile, K_tile]
            A_block_ptr = A_ptr + pid_t * stride_at + offs_m[:, None] * stride_am + offs_k[None, :] * stride_ak
            a = tl.load(A_block_ptr, mask=mask_m[:, None] & mask_k[None, :], other=0.0)
            # Store into B row at time index pid_t
            B_block_ptr = B_ptr + pid_t * stride_bt + offs_m[:, None] * stride_bm + offs_k[None, :] * stride_bk
            tl.store(B_block_ptr, a, mask=mask_m[:, None] & mask_k[None, :])


# Triton kernel: transpose a single row of a 2D tensor src[N, K] into dst[K, N].
# Each program instance handles one row, writing transposed values.
@triton.jit
def transpose_single_row_kernel(src_ptr, dst_ptr,
                                row_idx, N, K,
                                stride_sn, stride_sk,
                                stride_dk, stride_dn):
    n = tl.arange(0, N)
    k = tl.arange(0, K)
    # Load row from src: shape [N, K]
    src_row_ptr = src_ptr + row_idx * stride_sn + n * stride_sk
    vals = tl.load(src_row_ptr)
    # Store to dst: dst[k, n] = src[row_idx, n]
    dst_row_ptr = dst_ptr + k * stride_dk + n * stride_dn
    tl.store(dst_row_ptr, vals)


# Triton kernel: left-multiply matmul. Computes C[M, K] = A[M, N] @ B[N, K], where A is provided as [M, N],
# and B is provided as [N, K] (B^T). We assume fp32 tensors and 2D shapes. Strides provided for A and B^T.
@triton.jit
def matmul_left_kernel(A_ptr, BT_ptr, C_ptr,
                       M, N, K,
                       stride_am, stride_an,
                       stride_bk, stride_bn,  # BT has shape (N, K): stride_bk = stride along K, stride_bn = stride along N
                       stride_cm, stride_ck,
                       BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr):
    pid_m = tl.program_id(0)  # tile along M
    pid_k = tl.program_id(1)  # tile along K

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_k = pid_k * BLOCK_K + tl.arange(0, BLOCK_K)
    offs_n = tl.arange(0, BLOCK_N)

    acc = tl.zeros((BLOCK_M, BLOCK_K), dtype=tl.float32)

    for n_start in range(0, N, BLOCK_N):
        n_idx = n_start + offs_n
        # Load A tile: [BLOCK_M, BLOCK_N]
        A_tile_ptr = A_ptr + offs_m[:, None] * stride_am + n_idx[None, :] * stride_an
        A_mask = (offs_m[:, None] < M) & (n_idx[None, :] < N)
        A_tile = tl.load(A_tile_ptr, mask=A_mask, other=0.0)

        # Load BT tile: [BLOCK_N, BLOCK_K]
        BT_tile_ptr = BT_ptr + n_idx[:, None] * stride_bk + offs_k[None, :] * stride_bn
        BT_mask = (n_idx[:, None] < N) & (offs_k[None, :] < K)
        BT_tile = tl.load(BT_tile_ptr, mask=BT_mask, other=0.0)

        acc += tl.dot(A_tile, BT_tile)

    # Write back to C
    C_tile_ptr = C_ptr + offs_m[:, None] * stride_cm + offs_k[None, :] * stride_ck
    C_mask = (offs_m[:, None] < M) & (offs_k[None, :] < K)
    tl.store(C_tile_ptr, acc, mask=C_mask)
