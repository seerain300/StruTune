- The original per-batch per-head computation:
  - For batch b and head h:
    - Tokens = kv_indices[kv_indptr[b]:kv_indptr[b+1]] → M tokens.
    - If M <= 0: output zeros for that batch, lse initialized as in PyTorch, but forward in the provided code zeros output for that b anyway. We will mirror that.
    - Gather rows:
      - Kc = ckv_cache[tokens, 0, :] → [M, 512]
      - Kp = kpe_cache[tokens, 0, :] → [M, 64]
    - qn = q_nope[b, h, :] → [512], qp = q_pe[b, h, :] → [64]
    - logits[i] = sum_k qn[k] * Kc[i, k] + sum_k qp[k] * Kp[i, k], i in 0..M-1
    - logits_scaled = logits * sm_scale
    - lse[h] = logsumexp(logits_scaled) / ln(2)
    - attn[i] = exp(logits_scaled[i]) / sum_j exp(logits_scaled[j])
    - out[h, :] = sum_i attn[i] * Kc[i, :] → [512], cast to bfloat16

- Constraints and Triton limitations:
  - Triton requires tl.arange and static loops via tl.constexpr. We cannot use dynamic ranges. We will compute everything in kernels with compile-time M_CONST and K_CONST.
  - To avoid decoy kernels, all defined Triton kernels must be invoked from ModelNew.forward.

- Strategy:
  - Heavy computation: matvec to produce logits_qn = qn @ Kc.T and logits_qp = qp @ Kp.T using a Triton matvec_row_kernel with grid=(M_CONST,) and loop over K_CONST. Store both vectors.
  - Combine: logits = logits_qn + sm_scale * logits_qp.
  - Compute lse and attn fully in Triton:
    - max_val = -inf, sum_exp = 0.0. Use Triton kernel to loop over M_CONST (static) and update max and sum (two passes). Then compute lse = log(sum_exp) / ln(2).

  - Output casting: Triton will compute in float32; we cast to bfloat16 on host for the final output tensor to match the original code.

@triton.jit
def matvec_row_kernel(
    q_ptr,            # *float32, q vector of length K_CONST
    B_ptr,            # *float32, matrix B of shape [M_CONST, K_CONST], contiguous
    C_ptr,            # *float32, output vector of shape [M_CONST], contiguous
    K_CONST: tl.constexpr,
    M_CONST: tl.constexpr,
    BLOCK_K: tl.constexpr = 64
):
    # One program computes a single output element: C[i] = q @ B[i, :]
    i = tl.program_id(0)  # 0..M_CONST-1
    acc = 0.0
    for k0 in range(0, K_CONST, BLOCK_K):
        offs_k = k0 + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K_CONST
        a = tl.load(q_ptr + offs_k, mask=mask_k, other=0.0)
        b = tl.load(B_ptr + i * K_CONST + offs_k, mask=mask_k, other=0.0)
        acc += tl.sum(a * b, axis=0)
    tl.store(C_ptr + i, acc)


@triton.jit
