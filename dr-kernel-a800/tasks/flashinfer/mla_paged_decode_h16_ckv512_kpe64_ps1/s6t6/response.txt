1) Recap of original PyTorch logic
- Inputs:

  - kv_indices: [L_tokens] per batch element (varies by batch)
  - sm_scale: float scalar (1.0)

- Per batch b:
  - Determine the KV token range: start = kv_indptr[b], end = kv_indptr[b+1], L_tokens = end - start.
  - Gather embeddings for those token indices:
    - Kc_all[tok_idx] -> Kc[t, :] shape [L_tokens, D]
    - Kp_all[tok_idx] -> Kp[t, :] shape [L_tokens, Dp]
  - For each head h in 0..H-1:
    - Compute logits[h, t] = dot(qn[h, :], Kc[t, :]) + dot(qp[h, :], Kp[t, :]) for t in 0..L_tokens-1.
    - logits_scaled = logits * sm_scale
    - lse[h] = logsumexp(logits_scaled[h, :]) / log(2)
    - attn[h, :] = softmax(logits_scaled[h, :], dim=-1)
    - output[h, :] = attn[h, :] @ Kc[:, :]  -> shape [D]
  - Returns: output [B, H, D] bfloat16, lse [B, H] float32.

2) Previous issues and fixes
- Earlier Triton compilation errors came from using tl.arange with runtime sizes (D, Dp, L_tokens) and marking b/L_tokens as tl.constexpr. Triton requires tl.arange arguments to be compile-time constants. We’ll avoid tl.arange entirely and use scalar loops (which Triton supports with runtime integers), fixing compilation.
- We must ensure all reductions (max, exp-sum, log, softmax) are in Triton, and not in PyTorch. The forward will only launch Triton kernels. No .max(), .logsumexp(), or torch reductions on tensors in host code.

3) Triton kernel design
- Kernel 1 (compute_logits_per_batch): 2D grid over (heads, tokens) per batch. For each (b, h, t), compute:
  - qn_row[h, :] and qp_row[h, :] by loading contiguous rows (we’ll ensure q tensors are contiguous and compute offsets with scalar loops).
  - Kc_row[t, :] and Kp_row[t, :] similarly (K tensors are [N_total, D] and [N_total, Dp], so Kc_row at token t uses tok_idx[t] as index).
  - acc1 = sum over d of qn[h,d] * Kc[t,d], acc2 = sum over dp of qp[h,dp] * Kp[t,dp], logits[b, h, t] = acc1 + acc2. Store to a flat logits buffer at index ((b*H + h)*L_tokens + t).

- Kernel 2 (lse_per_batch): 1D grid over H. For each (b, h), compute:
  - scaled = logits_scaled[b, h, :] = logits[b, h, :] * sm_scale.
  - m = max(scaled).
  - sumexp = sum(exp(scaled - m)) for t in 0..L_tokens-1.
  - lse[b, h] = log(sumexp) / log(2). Store to lse buffer at (b*H + h).

- Kernel 3 (output_per_batch): 1D grid over H. For each (b, h), compute:
  - scaled = logits_scaled[b, h, :].
  - m = max(scaled).
  - attn[t] = exp(scaled[t] - m) for t in 0..L_tokens-1. Normalize: denom = sum(attn), attn /= denom.
  - output[h, d] = sum over t of attn[t] * Kc[t, d] for d in 0..D-1. Store output to output buffer at (b*H + h, d).

4) Host code
- Ensure all inputs are on CUDA and cast q_nope, q_pe to float32; Kc_all, Kp_all to float32; make contiguous.
- For each batch b: compute L_tokens = int(kv_indptr[b+1].item()) - int(kv_indptr[b].item()).
- tok_idx = kv_indices[int(kv_indptr[b].item()):int(kv_indptr[b+1].item())] as int32 tensor on device.
- Allocate buffers:
  - logits_buf[B*H*L_tokens] float32
  - lse_buf[B*H] float32
  - output_buf[B*H*D] float32
- Launch kernels per batch:
  - compute_logits_per_batch_kernel for b
  - lse_per_batch_kernel for b
  - output_per_batch_kernel for b
- Reshape and return output (cast to bfloat16) and lse.

This guarantees all computation happens inside Triton, and no PyTorch reductions or elementwise ops are used in host code. It should fix the compilation issues (no tl.arange, all loops/runtime) and satisfy the Triton-only requirement.

def compute_logits_per_batch_kernel(
    qn_ptr,         # *fp32, [H, D], contiguous
    qp_ptr,         # *fp32, [H, Dp], contiguous
    Kc_ptr,         # *fp32, [N_total, D], contiguous
    Kp_ptr,         # *fp32, [N_total, Dp], contiguous

    logits_ptr,     # *fp32, flattened [B*H*L_tokens]
    H: tl.int32,
    D: tl.int32,
    Dp: tl.int32,
    L_tokens: tl.int32,
    b: tl.int32,
    sm_scale: tl.float32,
):
    # 2D grid over (head, token)
    h = tl.program_id(0)
    t = tl.program_id(1)
    if (h >= H) or (t >= L_tokens):
        return

    # Compute flat index for logits[b, h, t]
    idx = (b * H + h) * L_tokens + t

    # Load qn row for head h: [D]
    qn_row = tl.zeros((D,), dtype=tl.float32)
    for kk in range(0, D):
        qn_row[kk] = tl.load(qn_ptr + h * D + kk)

    # Load qp row for head h: [Dp]
    qp_row = tl.zeros((Dp,), dtype=tl.float32)
    for kk in range(0, Dp):
        qp_row[kk] = tl.load(qp_ptr + h * Dp + kk)

    Kc_row = tl.zeros((D,), dtype=tl.float32)
    for kk in range(0, D):
        Kc_row[kk] = tl.load(Kc_ptr + tok_idx_t * D + kk)

    # Load Kp row for token t: [Dp]
    Kp_row = tl.zeros((Dp,), dtype=tl.float32)
    for kk in range(0, Dp):
        Kp_row[kk] = tl.load(Kp_ptr + tok_idx_t * Dp + kk)

    # Compute dot products
    acc1 = 0.0
    for kk in range(0, D):

    acc2 = 0.0

@triton.jit
def lse_per_batch_kernel(
    logits_ptr,     # *fp32, [B*H*L_tokens]
    lse_ptr,        # *fp32, [B*H]
    H: tl.int32,
    D: tl.int32,    # not used here, but kept for signature consistency
    L_tokens: tl.int32,
    b: tl.int32,
    sm_scale: tl.float32,
):

    if h >= H:
        return
    # compute index offset for this batch
    base = (b * H + h) * L_tokens
    # max over logits_scaled
    m = -float('inf')
    for t in range(0, L_tokens):
        val = tl.load(logits_ptr + base + t) * sm_scale
        m = tl.maximum(m, val)

    sumexp = 0.0
    for t in range(0, L_tokens):
        val = tl.load(logits_ptr + base + t) * sm_scale
        sumexp += tl.exp(val - m)

    lse_val = tl.log(sumexp) / 1.4426950408889634  # 1 / log(2)

@triton.jit
def output_per_batch_kernel(
    logits_ptr,     # *fp32, [B*H*L_tokens]
    Kc_ptr,         # *fp32, [N_total, D], contiguous
    tok_idx_ptr,    # *int32, [L_tokens]
    output_ptr,     # *fp32, [B*H*D]
    H: tl.int32,
    D: tl.int32,
    L_tokens: tl.int32,
    b: tl.int32,
    sm_scale: tl.float32,
):
    h = tl.program_id(0)
    if h >= H:
        return
    base_logits = (b * H + h) * L_tokens
    # Compute attn per token
    # First pass: compute m and denom
    m = -float('inf')
    for t in range(0, L_tokens):
        val = tl.load(logits_ptr + base_logits + t) * sm_scale
        m = tl.maximum(m, val)
    denom = 0.0
    for t in range(0, L_tokens):
        val = tl.load(logits_ptr + base_logits + t) * sm_scale
        attn_t = tl.exp(val - m)
        denom += attn_t
    # Second pass: accumulate output
    for d in range(0, D):
        acc = 0.0
        for t in range(0, L_tokens):
            val = tl.load(logits_ptr + base_logits + t) * sm_scale
            attn_t = tl.exp(val - m) / denom
            tok_idx_t = tl.load(tok_idx_ptr + t)
            Kc_val = tl.load(Kc_ptr + tok_idx_t * D + d)
            acc += attn_t * Kc_val
        tl.store(output_ptr + (b * H + h) * D + d, acc)
