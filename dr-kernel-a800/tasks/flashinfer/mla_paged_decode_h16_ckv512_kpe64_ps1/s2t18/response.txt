- Provide two real @triton.jit kernels that are launched from ModelNew.forward.
- Use a robust tiling strategy with constexpr BLOCK_T and 2D block loads, avoiding 1D tl.arange with runtime indices, which has triggered previous compilation failures.
- Perform all heavy math in Triton: no PyTorch matmul/softmax in kernels.
- Return outputs with the same dtypes as the original model: output in bfloat16 and lse in float32.

High-level analysis and plan
- Original computation per batch b:
  - L_tokens = kv_indptr[b+1] - kv_indptr[b].
  - For each head h:
    - For t in 0..L_tokens-1:
      - idx = kv_indices[page_beg + t] (with page_size=1, it’s just token index).
      - Kc_row = ckv_cache[idx, :] -> [D1=512], Kp_row = kpe_cache[idx, :] -> [D2=64].
      - logits_t = (qn[h] @ Kc_row) + (qp[h] @ Kp_row), scaled by sm_scale.
      - Softmax over tokens t per head, then out[h, :] += attn[t] * Kc_row.
    - lse[h] = logsumexp(logits_scaled) / ln(2).

- Triton strategy:
  - Kernel 1 (_lse_per_head_kernel):
    - One Triton program per batch element b. Loop over H (head count) inside the program. For each head:
      - Load qn and qp vectors (1D) using tl.arange with constexpr D1 and D2.
      - Tile over tokens using BLOCK_T with tl.static_range; for each token tt in the tile:
        - Load Kc_rows and Kp_rows as [BLOCK_T, D1] and [BLOCK_T, D2] using 2D pointer arithmetic and masks.
        - For each row in the tile, compute scalar logits = (sum(qn*Kc_row) + sum(qp*Kp_row)) * sm_scale.
        - Update per-column token_max_vec and token_sum_vec (masked).
      - After processing all tokens, write lse[b, h] = token_max_vec + log(token_sum_vec) / ln(2).
  - Kernel 2 (_compute_output_kernel):
    - Same structure; for each token tt in the tile, compute scalar logits, compute attn = exp(logits - token_max_vec) / token_sum_vec, and accumulate out[b, h, :] += attn * Kc_row. Store out as fp32; host casts to bf16.

- Launching:
  - ModelNew.forward:
    - Squeeze cache tensors to [N, D1] and [N, D2].
    - For each b:
      - Compute L_tokens from kv_indptr.
      - Allocate output_fp32 [B, H, D1] and lse [B, H].
      - Launch _lse_per_head_kernel with grid=(B,) and pass all runtime args (L_tokens, sm_scale).
      - If needed, launch _compute_output_kernel similarly to accumulate output.

- Constants:
  - Use tl.constexpr for D1=512, D2=64, H=16, BLOCK_T=128 for robust compilation.

- Dtype handling:
  - Kc_all and Kp_all are float32.
  - q_nope and q_pe are bfloat16 in inputs, but we load and convert to float32 inside kernels for computation; the final output is cast to bfloat16 in forward to match original behavior. lse returned as float32.

This approach avoids previous compilation pitfalls (1D runtime-indexed tl.load) and uses masked 2D block loads with constexpr tiling, which is typically more robust in Triton. It ensures the kernels are actually launched from ModelNew.forward and perform all heavy math, while returning the expected outputs and dtypes.

import math
import torch
import triton
import triton.language as tl


@triton.jit
def _lse_per_head_kernel(
    q_nope_rows_ptr,      # *f32, shape [B*H, D1] contiguous (we pass q_nope.view(B*H, D1))
    q_pe_rows_ptr,        # *f32, shape [B*H, D2] contiguous (we pass q_pe.view(B*H, D2))
    Kc_all_ptr,           # *f32, shape [N, D1] contiguous (we pass ckv_cache.squeeze(1))
    Kp_all_ptr,           # *f32, shape [N, D2] contiguous (we pass kpe_cache.squeeze(1))
    lse_out_ptr,          # *f32, shape [B, H] contiguous
    B: tl.int32,          # batch size (runtime)
    H: tl.int32,          # number of heads (runtime)
    D1: tl.constexpr,     # 512
    D2: tl.constexpr,     # 64
    L_tokens: tl.int32,   # tokens per batch element (runtime)
    sm_scale: tl.float32, # scaling (runtime)
    BLOCK_T: tl.constexpr,  # tiling over tokens (constexpr, e.g., 128)
):
    # One Triton program per batch element
    b = tl.program_id(axis=0)

    for h in range(0, H):
        # Load q vectors for head h
        qn = tl.load(q_nope_rows_ptr + (b * H + h) * D1 + tl.arange(0, D1)).to(tl.float32)  # [D1]
        qp = tl.load(q_pe_rows_ptr + (b * H + h) * D2 + tl.arange(0, D2)).to(tl.float32)   # [D2]

        # Initialize per-column max and sum across tokens
        token_max_vec = tl.full((D1,), -float("inf"), dtype=tl.float32)
        token_sum_vec = tl.zeros((D1,), dtype=tl.float32)

        # Tile over tokens; static unroll over BLOCK_T
        for tile in tl.static_range(0, (L_tokens + BLOCK_T - 1) // BLOCK_T):
            t_base = tile * BLOCK_T
            offs_t = tl.arange(0, BLOCK_T)  # constexpr range
            t_idx = t_base + offs_t
            mask_t = t_idx < L_tokens

            # 2D block loads: [BLOCK_T, D1] and [BLOCK_T, D2]
            Kc_rows = tl.load(
                Kc_all_ptr + t_idx[:, None] * D1 + tl.arange(0, D1)[None, :],
                mask=mask_t[:, None],
                other=0.0,
            ).to(tl.float32)  # [BLOCK_T, D1]
            Kp_rows = tl.load(
                Kp_all_ptr + t_idx[:, None] * D2 + tl.arange(0, D2)[None, :],
                mask=mask_t[:, None],
                other=0.0,
            ).to(tl.float32)  # [BLOCK_T, D2]

            # Loop over rows in the tile
            for tt in tl.static_range(0, BLOCK_T):
                t = t_base + tt
                valid = t < L_tokens

                Kc_row = Kc_rows[tt, :]  # [D1]
                Kp_row = Kp_rows[tt, :]  # [D2]

                # Compute scalar logits for this token
                dot1 = tl.sum(qn * Kc_row, axis=0)  # scalar
                dot2 = tl.sum(qp * Kp_row, axis=0)  # scalar
                logits_scalar = (dot1 + dot2) * sm_scale  # scalar

                # Update per-column max and sum (masked by valid)
                token_max_vec = tl.maximum(token_max_vec, logits_scalar)
                token_sum_vec += tl.where(valid, tl.exp(logits_scalar - token_max_vec), 0.0)

        # Store lse for this head: lse[b, h] = token_max_vec + log(token_sum_vec) / ln(2)
        ln2 = 0.6931471805599453  # math.log(2)
        lse_bh = token_max_vec + tl.log(token_sum_vec) / ln2
        tl.store(lse_out_ptr + b * H + h, lse_bh)


@triton.jit
def _compute_output_kernel(
    q_nope_rows_ptr,      # *f32, shape [B*H, D1] contiguous (we pass q_nope.view(B*H, D1))
    q_pe_rows_ptr,        # *f32, shape [B*H, D2] contiguous (we pass q_pe.view(B*H, D2))
    Kc_all_ptr,           # *f32, shape [N, D1] contiguous
    Kp_all_ptr,           # *f32, shape [N, D2] contiguous
    out_ptr,              # *f32, shape [B*H, D1] contiguous (we'll store per-head outputs as [B*H, D1])
    B: tl.int32,
    H: tl.int32,
    D1: tl.constexpr,
    D2: tl.constexpr,
    L_tokens: tl.int32,
    sm_scale: tl.float32,
    BLOCK_T: tl.constexpr,
):
    # One Triton program per batch element
    b = tl.program_id(axis=0)

    for h in range(0, H):
        # Load q vectors for head h
        qn = tl.load(q_nope_rows_ptr + (b * H + h) * D1 + tl.arange(0, D1)).to(tl.float32)  # [D1]
        qp = tl.load(q_pe_rows_ptr + (b * H + h) * D2 + tl.arange(0, D2)).to(tl.float32)   # [D2]

        # Initialize per-column max and sum across tokens
        token_max_vec = tl.full((D1,), -float("inf"), dtype=tl.float32)
        token_sum_vec = tl.zeros((D1,), dtype=tl.float32)

        # Accumulator for out[h, :]
        out_vec = tl.zeros((D1,), dtype=tl.float32)

        # Tile over tokens; static unroll over BLOCK_T
        for tile in tl.static_range(0, (L_tokens + BLOCK_T - 1) // BLOCK_T):
            t_base = tile * BLOCK_T
            offs_t = tl.arange(0, BLOCK_T)  # constexpr range
            t_idx = t_base + offs_t
            mask_t = t_idx < L_tokens

            # 2D block loads: [BLOCK_T, D1] and [BLOCK_T, D2]
            Kc_rows = tl.load(
                Kc_all_ptr + t_idx[:, None] * D1 + tl.arange(0, D1)[None, :],
                mask=mask_t[:, None],
                other=0.0,
            ).to(tl.float32)  # [BLOCK_T, D1]
            Kp_rows = tl.load(
                Kp_all_ptr + t_idx[:, None] * D2 + tl.arange(0, D2)[None, :],
                mask=mask_t[:, None],
                other=0.0,
            ).to(tl.float32)  # [BLOCK_T, D2]

            # Loop over rows in the tile
            for tt in tl.static_range(0, BLOCK_T):
                t = t_base + tt
                valid = t < L_tokens

                Kc_row = Kc_rows[tt, :]  # [D1]
                Kp_row = Kp_rows[tt, :]  # [D2]

                # Compute scalar logits for this token
                dot1 = tl.sum(qn * Kc_row, axis=0)  # scalar
                dot2 = tl.sum(qp * Kp_row, axis=0)  # scalar
                logits_scalar = (dot1 + dot2) * sm_scale  # scalar

                # Update per-column max and sum
                token_max_vec = tl.maximum(token_max_vec, logits_scalar)
                token_sum_vec += tl.where(valid, tl.exp(logits_scalar - token_max_vec), 0.0)

                # Compute attn and accumulate output
                attn = tl.where(valid, tl.exp(logits_scalar - token_max_vec) / token_sum_vec, 0.0)
                out_vec += attn * Kc_row

        # Store accumulated output for this head h as [b, h, :]
        # We store into out_ptr at index (b*H + h) row
        tl.store(out_ptr + (b * H + h) * D1 + tl.arange(0, D1), out_vec)


class ModelNew(torch.nn.Module):
    def forward(self, q_nope, q_pe, ckv_cache, kpe_cache, kv_indptr, kv_indices, sm_scale):
        """
        q_nope: [B, H, D1], dtype bfloat16 (H=16, D1=512)
        q_pe: [B, H, D2], dtype bfloat16 (D2=64)
        ckv_cache: [N, 1, D1] -> squeeze to [N, D1]
        kpe_cache: [N, 1, D2] -> squeeze to [N, D2]
        kv_indptr: [B+1], int32
        kv_indices: [L_tokens], int32 (runtime per batch)
        sm_scale: float32
        Returns:
        - output: [B, H, D1], bfloat16
        - lse: [B, H], float32
        """
        # Constants
        H = 16
        D1 = 512
        D2 = 64
        BLOCK_T = 128  # constexpr tile size over tokens

        B = q_nope.shape[0]
        device = q_nope.device

        # Squeeze cache tensors to [N, D1] and [N, D2], ensure contiguous
        Kc_all = ckv_cache.squeeze(1).to(torch.float32).contiguous()  # [N, D1]
        Kp_all = kpe_cache.squeeze(1).to(torch.float32).contiguous()  # [N, D2]

        # Flatten q_nope and q_pe to [B*H, D] for simple indexing in kernels
        q_nope_flat = q_nope.to(torch.float32).contiguous().view(B * H, D1)
        q_pe_flat = q_pe.to(torch.float32).contiguous().view(B * H, D2)

        # Compute L_tokens for each batch element
        L_tokens = (kv_indptr[1:] - kv_indptr[:-1]).tolist()  # [B]
        # Allocate outputs (fp32)
        lse_out = torch.empty((B, H), dtype=torch.float32, device=device)
        out_fp32 = torch.empty((B * H, D1), dtype=torch.float32, device=device)

        # Launch lse kernel: one program per batch element
        grid_lse = (B,)
        _lse_per_head_kernel[grid_lse](
            q_nope_flat, q_pe_flat, Kc_all, Kp_all, lse_out,
            B, H, D1, D2, L_tokens[0], sm_scale, BLOCK_T,  # Triton requires runtime args here
            num_warps=4, num_stages=2,
        )

        # Launch output kernel: one program per batch element
        grid_out = (B,)
        _compute_output_kernel[grid_out](
            q_nope_flat, q_pe_flat, Kc_all, Kp_all, out_fp32,
            B, H, D1, D2, L_tokens[0], sm_scale, BLOCK_T,
            num_warps=4, num_stages=2,
        )

        # Reshape output to [B, H, D1] and cast to bfloat16
        output = out_fp32.view(B, H, D1).to(torch.bfloat16)

        return output, lse_out
