Thanks for the detailed feedback. I’ll address the compilation errors and ensure all heavy computation is done by Triton kernels. The previous failures stem from Triton constraints: tl.arange requires a compile-time constant, and dynamic loops must be implemented carefully. I’ll fix kernels to use static tiling and masks, and avoid problematic patterns.

Analysis and plan

What the original PyTorch code does per batch b and head h:
- Compute logits vector of length M from gathered cache rows:
  - Kc: [M, 512], qn: [512] → qn @ Kc.T → logits part1
  - Kp: [M, 64], qp: [64] → qp @ Kp.T → logits part2
  - logits = part1 + part2
- Compute lse = logsumexp(logits * sm_scale) / ln(2) per head
- Compute attention vector attn = softmax(logits * sm_scale)
- Output vector out = attn @ Kc → [512], cast to bfloat16

Triton kernels design:
- matvec_row_kernel: computes C[i] = sum_k A[k] * B[i, k] for i in 0..M-1, where A is a row vector of length K (we pass A as a 1D contiguous vector of length K), B is [M, K], and output C is [M]. We tile along K with BLOCK_K (e.g., 64 or 128) and along M with BLOCK_M (e.g., 64). We use nested loops with tl.static_range over K and M tiles, and masks for boundary handling. This avoids tl.arange with runtime sizes and compiles robustly.
- softmax_lse_kernel: loads the logits_scaled vector (length M), computes:
  - max over the vector
  - sum of exp(logits_scaled - max)
  - lse = (max + log(sum_exp)) / ln(2)
  - attn = exp(logits_scaled - max) / sum_exp
  Writes lse and attn out. We also avoid tl.arange with runtime M by using static tiling loops for max/sum and vectorized stores.
- matvec_out_kernel: identical to matvec_row_kernel, used to compute out = attn @ Kc, producing [M] which we then reduce to a [512] vector per head.

ModelNew.forward flow:
- For each batch b:
  - If M <= 0: skip, output zeros for that batch
  - Allocate logits_f32 [M] and compute it via matvec_row_kernel for qn @ Kc.T, then via matvec_row_kernel for qp @ Kp.T, add them, and scale by sm_scale. Then call softmax_lse_kernel to get lse per head and attn vector.
  - Allocate output_f32 [16, 512], and for each head h, compute out[h, :] using matvec_out_kernel (attn @ Kc), and write to output. Finally cast output to bfloat16 and return.

This ensures all torch matmul/softmax in the host code are replaced by Triton kernels, and avoids prior compilation issues by using static tiling and masks.

```python
import math
import torch

try:
    import triton
    import triton.language as tl
    TRITON_AVAILABLE = True
except Exception:
    TRITON_AVAILABLE = False


# Triton kernel: compute C[i] = sum_k A[k] * B[i, k] for i in [0, M), A: [K], B: [M, K], C: [M]
if TRITON_AVAILABLE:
    @triton.jit
    def matvec_row_kernel(
        A_ptr,        # *float32, 1D vector of length K (we pass A as 1D contiguous)
        B_ptr,        # *float32, 2D matrix [M, K], row-major
        C_ptr,        # *float32, 1D vector [M]
        M,            # int32, number of rows in B
        K,            # int32, length of A / number of columns in B
        BLOCK_M: tl.constexpr,   # tile size along M
        BLOCK_K: tl.constexpr    # tile size along K
    ):
        # One program handles a block of M rows
        pid = tl.program_id(0)
        m0 = pid * BLOCK_M
        # Vector of output indices this program handles
        dm = tl.arange(0, BLOCK_M)
        i = m0 + dm  # [BLOCK_M]
        mask_m = i < M

        # Accumulator for this block
        acc = tl.zeros([BLOCK_M], dtype=tl.float32)

        # Loop over K in tiles
        for k0 in tl.static_range(0, K, BLOCK_K):
            offs_k = k0 + tl.arange(0, BLOCK_K)          # [BLOCK_K]
            mask_k = offs_k < K
            # Load A chunk
            A_chunk = tl.load(A_ptr + offs_k, mask=mask_k, other=0.0)  # [BLOCK_K]
            # For each row i in this block, load B[i, offs_k] and accumulate
            # Pointer to row i: B_ptr + i * K
            # Load vector for each i: mask with mask_m and offs_k
            # We create a [BLOCK_M, BLOCK_K] pointer matrix and load it
            # Build pointer matrix for B rows: b_ptrs = B_ptr + i[:, None] * K + offs_k[None, :]
            # Note: Triton allows this pointer arithmetic; mask_m[:, None] & mask_k[None, :] handles boundaries
            b_ptrs = B_ptr + (i[:, None] * K) + offs_k[None, :]
            B_chunk = tl.load(b_ptrs, mask=mask_m[:, None] & mask_k[None, :], other=0.0)  # [BLOCK_M, BLOCK_K]
            # Accumulate: acc += sum over K tile of (B_chunk * A_chunk[None, :])
            # Multiply and reduce along axis=1
            acc += tl.sum(B_chunk * A_chunk[None, :], axis=1)

        # Store results for valid i
        tl.store(C_ptr + i, acc, mask=mask_m)


    # Triton kernel: compute lse and attn for a given logits_scaled vector (length M)
    # Inputs: logits_scaled_ptr [M], outputs: lse_out_ptr [1], attn_ptr [M]
    @triton.jit
    def softmax_lse_kernel(
        logits_scaled_ptr,    # *float32, 1D vector [M]
        lse_out_ptr,          # *float32, 1D vector [1]
        attn_ptr,             # *float32, 1D vector [M]
        M,                    # int32
        inv_ln2,              # float32, 1 / ln(2)
        BLOCK_M: tl.constexpr
    ):
        # We process the whole vector in tiles. Compute max and sum_exp in tiles.
        # Initialize max and sum_exp
        max_val = tl.full((), -float("inf"), tl.float32)
        sum_exp = tl.zeros((), dtype=tl.float32)

        # Pass 1: compute max over tiles
        for m0 in tl.static_range(0, M, BLOCK_M):
            i = m0 + tl.arange(0, BLOCK_M)        # [BLOCK_M]
            mask = i < M
            x = tl.load(logits_scaled_ptr + i, mask=mask, other=-float("inf"))
            tile_max = tl.max(x, axis=0)
            max_val = tl.maximum(max_val, tile_max)

        # Pass 2: compute sum of exp(x - max)
        for m0 in tl.static_range(0, M, BLOCK_M):
            i = m0 + tl.arange(0, BLOCK_M)
            mask = i < M
            x = tl.load(logits_scaled_ptr + i, mask=mask, other=-float("inf"))
            exp_x = tl.exp(x - max_val)
            # sum over tile
            tile_sum = tl.sum(exp_x, axis=0)
            sum_exp += tile_sum

        # Compute lse
        lse = (max_val + tl.log(sum_exp)) * inv_ln2
        tl.store(lse_out_ptr, lse)

        # Pass 3: compute attn vector and store
        for m0 in tl.static_range(0, M, BLOCK_M):
            i = m0 + tl.arange(0, BLOCK_M)
            mask = i < M
            x = tl.load(logits_scaled_ptr + i, mask=mask, other=-float("inf"))
            attn_vec = tl.exp(x - max_val) / sum_exp
            tl.store(attn_ptr + i, attn_vec, mask=mask)


    # Triton kernel: compute out = attn @ Kc, where attn: [M], Kc: [M, 512], out: [512]
    # We implement this as a matvec: out[d] = sum_i attn[i] * Kc[i, d]
    @triton.jit
    def matvec_out_kernel(
        attn_ptr,        # *float32, 1D vector [M]
        Kc_ptr,          # *float32, 2D matrix [M, 512]
        out_ptr,         # *float32, 1D vector [512]
        M,               # int32
        Kc_dim,          # int32 (512 here)
        BLOCK_M: tl.constexpr,
        BLOCK_K: tl.constexpr
    ):
        # One program handles a block of output columns
        pid = tl.program_id(0)
        d0 = pid * BLOCK_K
        offs_d = d0 + tl.arange(0, BLOCK_K)         # [BLOCK_K]
        mask_d = offs_d < Kc_dim

        acc = tl.zeros([BLOCK_K], dtype=tl.float32)

        # Loop over M in tiles
        for m0 in tl.static_range(0, M, BLOCK_M):
            i = m0 + tl.arange(0, BLOCK_M)          # [BLOCK_M]
            mask_m = i < M
            # Load attn chunk
            attn_chunk = tl.load(attn_ptr + i, mask=mask_m, other=0.0)  # [BLOCK_M]
            # Load Kc rows chunk: [BLOCK_M, BLOCK_K]
            k_ptrs = Kc_ptr + (i[:, None] * Kc_dim) + offs_d[None, :]
            Kc_chunk = tl.load(k_ptrs, mask=mask_m[:, None] & mask_d[None, :], other=0.0)  # [BLOCK_M, BLOCK_K]
            acc += tl.sum(Kc_chunk * attn_chunk[:, None], axis=0)

        tl.store(out_ptr + offs_d, acc, mask=mask_d)


class ModelNew(torch.nn.Module):
    def __init__(self):
        super().__init__()
        # precompute 1/ln(2)
        self.inv_ln2 = 1.0 / math.log(2.0)

    def forward(self, q_nope, q_pe, ckv_cache, kpe_cache, kv_indptr, kv_indices, sm_scale):
        # Ensure everything is on the same device
        device = q_nope.device
        # Gather Kc_all and Kp_all as [N, head_dim], squeeze the batch dim
        Kc_all = ckv_cache.squeeze(1).to(torch.float32)  # [N, 512]
        Kp_all = kpe_cache.squeeze(1).to(torch.float32)  # [N, 64]

        batch_size = q_nope.shape[0]
        num_qo_heads = q_nope.shape[1]
        head_dim_ckv = q_nope.shape[2]
        head_dim_kpe = q_pe.shape[2]

        # Constants as per original assertions
        assert num_qo_heads == 16, "num_qo_heads must be 16"
        assert head_dim_ckv == 512, "head_dim_ckv must be 512"
        assert head_dim_kpe == 64, "head_dim_kpe must be 64"
        assert kv_indptr.shape[0] == batch_size + 1, "len(kv_indptr) must be batch_size + 1"
        # num_pages is not explicitly used, but shape checks rely on cached sizes

        output = torch.zeros(
            (batch_size, num_qo_heads, head_dim_ckv),
            dtype=torch.bfloat16,
            device=device
        )
        lse = torch.empty((batch_size, num_qo_heads), dtype=torch.float32, device=device)

        for b in range(batch_size):
            # Determine valid tokens for this batch
            start = int(kv_indptr[b].item())
            end = int(kv_indptr[b + 1].item())
            if start >= end:
                # No KV cache for this batch element: output zeros and skip
                output[b].zero_()
                lse[b] = 0.0
                continue

            # Gather token indices
            tokens = kv_indices[start:end]  # [M]
            M = tokens.numel()

            # Gather Kc and Kp for these tokens
            Kc = Kc_all[tokens]  # [M, 512]
            Kp = Kp_all[tokens]  # [M, 64]

            # Prepare outputs/intermediates
            # Allocate logits_f32 [M]
            logits_f32 = torch.empty(M, dtype=torch.float32, device=device)

            # Compute qn @ Kc.T -> logits part1
            qn = q_nope[b].to(torch.float32)  # [16, 512]
            # Select head h: we need per-head, but the original code loops over heads. Here, q_nope is [B, 16, 512], so we pass the whole q_nope[b] vector and reduce. However, in original logic, it computes per head. To match, we should use q_nope[b, h, :].
            # Since forward passes [B, 16, 512], we need to access per head. We'll compute per head by reshaping q_nope[b] into heads.
            # But to keep Triton kernel simple, we pass the vector A as qn for head 0. We need per head; we can do it in Python loop over heads:
            # Compute per-head output. We'll implement head loop explicitly.
            for h in range(num_qo_heads):
                qn_vec = q_nope[b, h].contiguous().to(torch.float32)  # [512]
                # Kernel launch: matvec_row_kernel for qn_vec @ Kc.T
                # We need to pass A as 1D of length K and B as [M, K]
                # qn_vec is already 1D contiguous
                # Allocate C for logits part1
                logits_part1 = torch.empty(M, dtype=torch.float32, device=device)

                # Kernel launch parameters
                BLOCK_M = 64
                BLOCK_K = 128 if head_dim_ckv >= 128 else 64
                grid_m = (M + BLOCK_M - 1) // BLOCK_M

                matvec_row_kernel[(grid_m,)](
                    qn_vec,                   # A_ptr: [K]
                    Kc,                       # B_ptr: [M, K]
                    logits_part1,             # C_ptr: [M]
                    M, K,
                    BLOCK_M=BLOCK_M,
                    BLOCK_K=BLOCK_K
                )

                # Compute qn @ Kp.T for Kp: similarly, but head_dim_kpe is 64, and qn_vec is [512], which is not compatible. The original code uses q_pe[b, h, :] of length 64. We need to compute part2 using q_pe[b, h].
                # We'll load q_pe for this head:
                qp_vec = q_pe[b, h].contiguous().to(torch.float32)  # [64]

                logits_part2 = torch.empty(M, dtype=torch.float32, device=device)
                BLOCK_M2 = 64
                BLOCK_K2 = 128 if head_dim_kpe >= 128 else 64
                grid_m2 = (M + BLOCK_M2 - 1) // BLOCK_M2

                matvec_row_kernel[(grid_m2,)](
                    qp_vec,                   # A_ptr: [K'] with K' = 64
                    Kp,                       # B_ptr: [M, 64]
                    logits_part2,             # C_ptr: [M]
                    M, 64,
                    BLOCK_M=BLOCK_M2,
                    BLOCK_K=BLOCK_K2
                )

                # Total logits_scaled
                logits_scaled = (logits_part1 + logits_part2) * sm_scale

                # Compute lse and attn in Triton
                attn = torch.empty(M, dtype=torch.float32, device=device)
                lse_val = torch.empty(1, dtype=torch.float32, device=device)
                BLOCK_M_soft = 256 if M >= 256 else (128 if M >= 128 else 64)
                softmax_lse_kernel[(1,)](
                    logits_scaled,            # [M]
                    lse_val,                  # [1]
                    attn,                     # [M]
                    M,
                    self.inv_ln2,
                    BLOCK_M=BLOCK_M_soft
                )
                lse[b] = lse_val[0]

                # Compute out[h, :] = attn @ Kc
                out_vec = torch.empty(head_dim_ckv, dtype=torch.float32, device=device)
                BLOCK_M_out = 256 if M >= 256 else (128 if M >= 128 else 64)
                BLOCK_K_out = 128 if head_dim_ckv >= 128 else 64
                grid_out = (head_dim_ckv + BLOCK_K_out - 1) // BLOCK_K_out

                matvec_out_kernel[(grid_out,)](
                    attn,                     # [M]
                    Kc,                       # [M, 512]
                    out_vec,                  # [512]
                    M,
                    head_dim_ckv,
                    BLOCK_M=BLOCK_M_out,
                    BLOCK_K=BLOCK_K_out
                )
                # Write to output
                output[b, h, :] = out_vec

        # Cast output to bfloat16 as original code returns bfloat16
        output = output.to(torch.bfloat16)
        return output, lse
```

- The Triton kernels use static tiling and masks to avoid tl.arange with runtime sizes, which caused previous compilation errors. All heavy math is done in Triton; no torch matmul/softmax in host code.
- For per-head computation, we loop over h=0..15 explicitly in forward. This maintains correctness and adheres to Triton-only requirement.
- Output is cast to bfloat16 at the end to match the original Model’s return type. LSE remains float32 as in the original.
