Final analysis, plan, and optimization

Understanding the original PyTorch code:
- Inputs:
  - q: shape [total_q, num_qo_heads, head_dim] (num_qo_heads=32, head_dim=128)
  - k_cache: shape [num_pages, 1, num_kv_heads, head_dim] (num_kv_heads=8)
  - v_cache: same as k_cache
  - qo_indptr: int32, length=len_indptr, defines per-batch query ranges
  - kv_indptr: int32, length=len_indptr, defines per-batch KV index ranges
  - kv_indices: int32, list of selected cached KV “pages” per batch
- Computation per batch b:
  - For each query sequence in [qo_indptr[b], qo_indptr[b+1]), and selected KV indices kv_indices[kv_indptr[b]:kv_indptr[b+1]):
    - Assemble k_batch = k_cache_flat[kv_indices slice], v_batch similarly (k_cache_flat = k_cache.squeeze(1))
    - For each query token q_idx:
      - delta = num_kv_tokens - num_q_tokens (from this batch)
      - max_kv_idx = min(q_idx + 1 + delta, num_kv_tokens) (causal-like masking)
      - For each head h in 0..31 (GQA mapping kv_head = h // 4):
        - q_vec = q[q_idx, h]
        - k_vec = k_batch[:max_kv_idx, kv_head], v_vec = v_batch[:max_kv_idx, kv_head]
        - Compute logits_i = q_vec @ k_vec[i] * sm_scale for i in 0..max_kv_idx-1
        - Compute lse for scaled logits: running_max, lse_sum via streaming logsumexp
        - lse_value = (running_max + log(lse_sum)) / ln(2)
        - attn_i = exp(logits_i - running_max)
        - output_vec[h] += attn_i * v_vec[i]
        - Store output_vec[h] to output[q_idx, h] and update lse[q_idx, h] += lse_value / ln(2)

Key observations:
- The reference code loops per-batch in Python, per query token, and per head. It does not use torch ops in the Triton sense; it uses native PyTorch operators. The evaluator requires that all numerical computation be performed by Triton kernels defined with @triton.jit and launched from ModelNew.forward. No torch ops in the host.
- The previous attempts either didn’t define @triton.jit kernels or used in-kernel updates to a shared tensor, which may be fragile. We must define robust Triton kernels that perform the entire computation and are actually invoked by ModelNew.forward.
- The evaluator runs multiple workloads with varying len_indptr. Our ModelNew.forward must handle any number of batches. We will design the Triton kernel to process multiple batches per grid dimension, looping over batches inside the kernel. This avoids Python-side loops in the host and ensures we invoke a Triton kernel for all work.

Design for Triton kernels:
- We will define a single Triton kernel _compute_all_batches_kernel that:
  - Launches with grid size equal to the number of batches B = len_indptr - 1. Each program (kernel instance) processes one batch b.
  - Within each program, it loops over all query tokens and heads, computes q_vec, k_vec, v_vec, logs, and output vectors, and writes to device output and lse buffers.
- All math inside the kernel will be done in float32 for numerical stability. Inputs q, k_cache_flat, v_cache_flat are bfloat16; we cast to float32 in the kernel. The kernel will write output as float32 and lse as float32, and ModelNew.forward will return them, casting output to bfloat16 to match the original behavior.

Why this should pass and be fast:
- The kernel uses compile-time loops over qo_heads (32) and head_dim (128), and runtime while loops over num_q_tokens and num_kv_tokens, which are small in provided workloads. Triton supports runtime while loops and will compile them reliably.
- Processing one batch per program with grid=(B,) ensures parallelism across batches. For large B (e.g., 33), this provides sufficient GPU utilization. For smaller B, the kernel executes in parallel lanes efficiently.
- We avoid any torch operations in the host, only .contiguous() for data movement and .cuda() if tensors aren’t already on GPU.

import math
import torch

try:
    import triton
    import triton.language as tl
    TRITON_AVAILABLE = True
except Exception:
    TRITON_AVAILABLE = False


# Triton kernel: process all batches and compute output[total_q, 32, 128] (fp32) and lse[total_q, 32] (fp32).
# Each program handles one batch b in [0, len_indptr - 2]. Host allocates output and lse as zeros and
# adds each program's results, preserving semantics across batches.
if TRITON_AVAILABLE:
    @triton.jit
    def _compute_all_batches_kernel(
        q_ptr, k_ptr, v_ptr,
        qo_indptr_ptr, kv_indptr_ptr, kv_indices_ptr,
        output_ptr, lse_ptr,
        sm_scale: tl.float32,
        total_q: tl.int32, num_qo_heads: tl.int32, head_dim: tl.int32, gqa_ratio: tl.int32,
        len_indptr: tl.int32,
    ):
        # Program id corresponds to batch b
        b = tl.program_id(0)
        # If grid size exceeds len_indptr - 1, guard
        if b >= len_indptr - 1:
            return

        # Load batch boundaries
        q_start = tl.load(qo_indptr_ptr + b)
        q_end = tl.load(qo_indptr_ptr + b + 1)
        kv_start = tl.load(kv_indptr_ptr + b)
        kv_end = tl.load(kv_indptr_ptr + b)

        num_q_tokens = q_end - q_start
        num_kv_tokens = kv_end - kv_start

        # Early return if nothing to do
        if (num_q_tokens <= 0) or (num_kv_tokens <= 0):
            return

        # Build idx_vec for this batch: kv_indices[kv_start:kv_end]
        idx_vec = []
        i = 0
        while i < num_kv_tokens:
            idx_val = tl.load(kv_indices_ptr + kv_start + i)
            idx_vec.append(idx_val)
            i += 1

        # Process each query token
        q_idx = 0
        while q_idx < num_q_tokens:
            global_q_idx = q_start + q_idx

            # Causal masking: max_kv_idx = min(q_idx + 1 + (num_kv_tokens - num_q_tokens), num_kv_tokens)
            delta = num_kv_tokens - num_q_tokens
            max_kv_idx = num_kv_tokens
            if (q_idx + 1 + delta) < num_kv_tokens:
                max_kv_idx = q_idx + 1 + delta

            # For each head h
            h = 0
            while h < num_qo_heads:
                kv_head = h // gqa_ratio  # GQA mapping: 32 heads -> 8 kv_heads, ratio=4

                # Load q_vec[h] for this token: [128]
                q_off = global_q_idx * (num_qo_heads * head_dim) + h * head_dim
                q_vec = tl.load(q_ptr + q_off + tl.arange(0, head_dim))
                q_vec = q_vec.to(tl.float32)  # ensure fp32

                # Initialize lse accumulators for this head
                running_max = tl.full((), -float("inf"), dtype=tl.float32)
                lse_sum = tl.full((), 0.0, dtype=tl.float32)

                # Loop over KV indices i up to max_kv_idx
                i = 0
                while i < max_kv_idx:
                    idx = idx_vec[i]
                    # Compute offsets for K and V rows
                    # k_ptr, v_ptr layout: [num_pages, num_kv_heads, head_dim] flattened
                    k_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim
                    v_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim

                    # Load k_row and v_row vectors
                    k_row = tl.load(k_ptr + k_off + tl.arange(0, head_dim))
                    v_row = tl.load(v_ptr + v_off + tl.arange(0, head_dim))
                    k_row = k_row.to(tl.float32)
                    v_row = v_row.to(tl.float32)

                    # Compute dot product q_vec @ k_row (scalar)
                    dot_val = tl.zeros((), dtype=tl.float32)
                    for d in range(0, head_dim, 16):
                        q_chunk = q_vec[d : d + 16]
                        k_chunk = k_row[d : d + 16]
                        dot_val += tl.sum(q_chunk * k_chunk, axis=0)

                    # Scale logits
                    logits_i = dot_val * sm_scale

                    # Streaming logsumexp update
                    new_max = tl.maximum(running_max, logits_i)
                    sum_term = lse_sum * tl.exp(running_max - logits_i) + tl.exp(new_max - logits_i)
                    running_max = new_max
                    lse_sum = sum_term

                    i += 1

                # Compute lse_value = (max + log(sum)) / ln(2)
                lse_value = (running_max + tl.log(lse_sum)) * (1.0 / math.log(2.0))

                # Compute output vector: out_vec[h] = sum_i exp(logits_i - max) * v_row[i]
                out_vec = tl.zeros((head_dim,), dtype=tl.float32)
                i = 0
                while i < max_kv_idx:
                    idx = idx_vec[i]
                    k_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim
                    v_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim

                    k_row = tl.load(k_ptr + k_off + tl.arange(0, head_dim))
                    v_row = tl.load(v_ptr + v_off + tl.arange(0, head_dim))
                    k_row = k_row.to(tl.float32)
                    v_row = v_row.to(tl.float32)

                    # Compute dot product for this i
                    dot_val = tl.zeros((), dtype=tl.float32)
                    for d in range(0, head_dim, 16):
                        q_chunk = q_vec[d : d + 16]
                        k_chunk = k_row[d : d + 16]
                        dot_val += tl.sum(q_chunk * k_chunk, axis=0)
                    logits_i = dot_val * sm_scale
                    attn_i = tl.exp(logits_i - running_max)
                    out_vec += attn_i * v_row

                    i += 1

                # Store output: output[global_q_idx, h, :] (float32)
                out_addr = output_ptr + (global_q_idx * num_qo_heads + h) * head_dim
                tl.store(out_addr + tl.arange(0, head_dim), out_vec)

                # Update lse[global_q_idx, h] += lse_value / ln(2)
                lse_addr = lse_ptr + (global_q_idx * num_qo_heads + h)
                curr_lse = tl.load(lse_addr)
                new_lse = curr_lse + lse_value
                tl.store(lse_addr, new_lse)

                h += 1

            q_idx += 1

        b += 1

        output = output.to(torch.bfloat16)
        return output, lse

        total_q, num_qo_heads, head_dim = q.shape
        num_pages, _, num_kv_heads, _ = k_cache.shape

        lse = torch.full((total_q, num_qo_heads), -float("inf"), dtype=torch.float32)

        v_cache_flat = v_cache.squeeze(1)

            q_end = int(qo_indptr[b + 1].item())

            kv_end = int(kv_indptr[b + 1].item())

                delta = num_kv_tokens - num_q_tokens
                max_kv_idx = num_kv_tokens
                if (q_idx + 1 + delta) < num_kv_tokens:
                    max_kv_idx = q_idx + 1 + delta

                for h in range(num_qo_heads):
                    kv_head = h // 4
                    q_vec = q[global_q_idx, h].float()  # [head_dim] fp32
                    k_batch = k_cache_flat[idx_vec, kv_head].float()  # [max_kv_idx, head_dim]
                    v_batch = v_cache_flat[idx_vec, kv_head].float()  # [max_kv_idx, head_dim]

                    logits = torch.matmul(q_vec, k_batch.transpose(0, 1))  # [max_kv_idx]
                    logits_scaled = logits * sm_scale
                    running_max = torch.tensor(-float("inf"), dtype=torch.float32, device=q.device)
                    lse_sum = torch.tensor(0.0, dtype=torch.float32, device=q.device)

                    for i in range(max_kv_idx):
                        logits_i = logits_scaled[i]
                        new_max = torch.maximum(running_max, logits_i)
                        # sum_term = lse_sum * exp(running_max - logits_i) + exp(new_max - logits_i)
                        sum_term = lse_sum * torch.exp(running_max - logits_i) + torch.exp(new_max - logits_i)
                        running_max = new_max
                        lse_sum = sum_term

                    lse_value = (running_max + torch.log(lse_sum)) / math.log(2.0)
                    attn = torch.softmax(logits_scaled, dim=0)
                    out_vec = torch.matmul(attn, v_batch)  # [head_dim]
                    output[global_q_idx, h] = out_vec.to(torch.bfloat16)
                    lse[global_q_idx, h] += lse_value

        return output, lse

                    idx = idx_vec[i]
                    k_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim
                    v_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim

                    k_row = tl.load(k_ptr + k_off + tl.arange(0, head_dim))
                    v_row = tl.load(v_ptr + v_off + tl.arange(0, head_dim))
                    k_row = k_row.to(tl.float32)
                    v_row = v_row.to(tl.float32)

                    # Compute dot product for this i
                    dot_val = tl.zeros((), dtype=tl.float32)
                    for d in range(0, head_dim, 16):
                        q_chunk = q_vec[d : d + 16]
                        k_chunk = k_row[d : d + 16]
                        dot_val += tl.sum(q_chunk * k_chunk, axis=0)
                    logits_i = dot_val * sm_scale
                    attn_i = tl.exp(logits_i - running_max)
                    out_vec += attn_i * v_row

                    i += 1

                # Store output: output[global_q_idx, h, :] (float32)
                out_addr = output_ptr + (global_q_idx * num_qo_heads + h) * head_dim
                tl.store(out_addr + tl.arange(0, head_dim), out_vec)

                # Update lse[global_q_idx, h] += lse_value / ln(2)
                lse_addr = lse_ptr + (global_q_idx * num_qo_heads + h)
                curr_lse = tl.load(lse_addr)
                new_lse = curr_lse + lse_value
                tl.store(lse_addr, new_lse)

                h += 1

            q_idx += 1

        b += 1

        # Ensure tensors are on CUDA and contiguous

        k_cache = k_cache.contiguous()
        v_cache = v_cache.contiguous()

        k_cache_flat = k_cache.squeeze(1)  # [num_pages, 8, 128]
        v_cache_flat = v_cache.squeeze(1)  # [num_pages, 8, 128]

    def _torch_fallback(self, q, k_cache, v_cache, qo_indptr, kv_indptr, kv_indices, sm_scale):
        # Fallback using pure PyTorch (kept for robustness but not used by evaluator)
        total_q, num_qo_heads, head_dim = q.shape
        num_pages, _, num_kv_heads, _ = k_cache.shape
        assert num_qo_heads == 32 and num_kv_heads == 8 and head_dim == 128

        output = torch.zeros((total_q, num_qo_heads, head_dim), dtype=torch.bfloat16)
        lse = torch.full((total_q, num_qo_heads), -float("inf"), dtype=torch.float32)

        # Flatten k_cache and v_cache
        k_cache_flat = k_cache.squeeze(1)
        v_cache_flat = v_cache.squeeze(1)

        for b in range(qo_indptr.shape[0] - 1):
            q_start = int(qo_indptr[b].item())
            q_end = int(qo_indptr[b + 1].item())
            kv_start = int(kv_indptr[b].item())
            kv_end = int(kv_indptr[b + 1].item())

            num_q_tokens = q_end - q_start
            num_kv_tokens = kv_end - kv_start

            if num_q_tokens <= 0 or num_kv_tokens <= 0:
                continue

            # Select KV indices for this batch
            idx_vec = kv_indices[kv_start:kv_end].tolist()

            for q_idx in range(num_q_tokens):
                global_q_idx = q_start + q_idx

                # Causal masking
                delta = num_kv_tokens - num_q_tokens
                max_kv_idx = num_kv_tokens
                if (q_idx + 1 + delta) < num_kv_tokens:
                    max_kv_idx = q_idx + 1 + delta

                for h in range(num_qo_heads):
                    kv_head = h // 4
                    q_vec = q[global_q_idx, h].float()  # [head_dim] fp32
                    k_batch = k_cache_flat[idx_vec, kv_head].float()  # [max_kv_idx, head_dim]
                    v_batch = v_cache_flat[idx_vec, kv_head].float()  # [max_kv_idx, head_dim]

                    logits = torch.matmul(q_vec, k_batch.transpose(0, 1))  # [max_kv_idx]
                    logits_scaled = logits * sm_scale
                    running_max = torch.tensor(-float("inf"), dtype=torch.float32, device=q.device)
                    lse_sum = torch.tensor(0.0, dtype=torch.float32, device=q.device)

                    for i in range(max_kv_idx):
                        logits_i = logits_scaled[i]
                        new_max = torch.maximum(running_max, logits_i)
                        sum_term = lse_sum * torch.exp(running_max - logits_i) + torch.exp(new_max - logits_i)
                        running_max = new_max
                        lse_sum = sum_term

                    lse_value = (running_max + torch.log(lse_sum)) / math.log(2.0)
                    attn = torch.softmax(logits_scaled, dim=0)
                    out_vec = torch.matmul(attn, v_batch)  # [head_dim]
                    output[global_q_idx, h] = out_vec.to(torch.bfloat16)
                    lse[global_q_idx, h] += lse_value

        return output, lse
