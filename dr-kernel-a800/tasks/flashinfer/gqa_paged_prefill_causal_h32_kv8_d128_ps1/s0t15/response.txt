Final analysis, plan, and optimization strategy

What the original PyTorch code computes:
- Inputs:
  - q: shape [total_q, num_qo_heads, head_dim] (num_qo_heads=32, head_dim=128).
  - k_cache: shape [num_pages, 1, num_kv_heads, head_dim] (num_kv_heads=8).
  - v_cache: same shape as k_cache.
  - qo_indptr: int32 of length len_indptr; qo_indptr[b:b+1] gives [q_start, q_end) for batch b.
  - kv_indptr: same as qo_indptr, gives KV slice for each batch.
  - kv_indices: int32 of length num_kv_indices; for batch b, the relevant cached KV rows are k_cache[v, kv_head, :] for v in kv_indices[kv_start:kv_end].
  - sm_scale: scalar (1/sqrt(head_dim) = 1/11.3137).
- Per batch b:
  - Determine q_start, q_end and num_q_tokens = q_end - q_start.
  - Determine kv_start, kv_end and num_kv_tokens = kv_end - kv_start.
  - Select idx_vec = kv_indices[kv_start:kv_end].
  - For each query token q_idx in [0..num_q_tokens-1], and each head h in [0..31]:
    - kv_head = h // 4 (GQA mapping).
    - q_vec[h] = q[q_start + q_idx, h, :].
    - k_batch = k_cache_flat[idx_vec[:], kv_head, :], shape [num_kv_tokens, 128].
    - v_batch = v_cache_flat[idx_vec[:], kv_head, :].
    - Apply causal masking: define delta = num_kv_tokens - num_q_tokens, and max_kv_idx = min(q_idx + 1 + delta, num_kv_tokens). For i >= max_kv_idx, contributions are ignored.
    - Compute logits_scaled for i in 0..max_kv_idx-1: logits_scaled[i] = (q_vec[h] · k_batch[i, :]) * sm_scale.
    - Accumulate logsumexp over these scaled logits in a streaming manner:
      - running_max, lse_sum updated as new_max = max(running_max, logits_scaled[i]); lse_sum = lse_sum * exp(running_max - logits_scaled[i]) + exp(new_max - logits_scaled[i]); running_max = new_max.
      - After the loop, lse_value = (running_max + log(lse_sum)) / ln(2).
    - Compute attention attn[i] = exp(logits_scaled[i] - running_max) for i < max_kv_idx; else 0.
    - Output vector out_vec[h] = sum_i attn[i] * v_batch[i, :].
    - Write out_vec[h] to output[q_start + q_idx, h, :].
    - Update lse[q_start + q_idx, h] += lse_value / ln(2).

Key observation:
- There is no conventional softmax over all tokens; each query token computes a scalar lse across a subset of KV entries determined by the causal mask and GQA head mapping. The final output is a per-head vector for each token, not a probability distribution.

Why Triton is appropriate:
- Triton excels at writing custom kernels that perform vectorized loads, reductions, and elementwise operations on GPUs. The per-batch computation is small (head_dim=128, num_qo_heads=32, typical num_q_tokens and num_kv_tokens are modest). A kernel that processes one batch per program can load q, k, v slices, compute the per-head reductions and outputs, and write to device buffers. This avoids host-side torch ops and keeps all computation in Triton.

Design for correctness and performance:
- Implement a Triton kernel that handles one batch per program. Launch it with grid=(B,) where B=len_indptr-1. Each program:
  - Reads qo_indptr[b], qo_indptr[b+1], kv_indptr[b], kv_indptr[b+1] to determine slices.
  - Constructs idx_vec = kv_indices[kv_start:kv_end].
  - Loops over each q token and each head h:
    - Loads q_vec[h], k_batch rows, v_batch rows, computes scaled logits, lse, attention, and output vector, and writes to output and lse buffers.
  - All math is in fp32; output returned as bfloat16; lse as float32. This matches the original signature.

- ModelNew.forward:
  - Ensure tensors are on CUDA and contiguous.
  - Flatten k_cache and v_cache by squeezing time dim (1).
  - Allocate output and lse buffers as zeros (fp32).
  - Launch the Triton kernel (one program per batch).
  - Return output cast to bfloat16 and lse (fp32). This preserves semantics: lse accumulates contributions across workloads, and output is produced without torch operations in the host.

This approach satisfies the requirement that all numerical computation is performed by Triton kernels and defines ModelNew as the entry point. It avoids Python-side loops over batches in the host and uses one Triton program per batch for robustness.

import math
import torch

try:
    import triton
    import triton.language as tl
    TRITON_AVAILABLE = True
except Exception:
    TRITON_AVAILABLE = False


# Triton kernel: compute output and lse for a single batch b.
# Each program handles one batch, reads q, k, v slices, and writes results to output and lse.
if TRITON_AVAILABLE:
    @triton.jit
    def _batch_compute_kernel(
        q_ptr, k_ptr, v_ptr,
        qo_indptr_ptr, kv_indptr_ptr, kv_indices_ptr,
        output_ptr, lse_ptr,
        sm_scale: tl.float32,
        total_q: tl.int32, num_qo_heads: tl.int32, head_dim: tl.int32, gqa_ratio: tl.int32,
        b: tl.int32,  # batch index in [0, len_indptr - 2]
        len_indptr: tl.int32,
    ):
        # Load boundaries for this batch
        q_start = tl.load(qo_indptr_ptr + b)
        q_end = tl.load(qo_indptr_ptr + b + 1)
        kv_start = tl.load(kv_indptr_ptr + b)
        kv_end = tl.load(kv_indptr_ptr + b)

        num_q_tokens = q_end - q_start
        num_kv_tokens = kv_end - kv_start

        # Early return if nothing to do
        if (num_q_tokens <= 0) or (num_kv_tokens <= 0):
            return

        # Build idx_vec for this batch: kv_indices[kv_start:kv_end]
        idx_vec = []
        i = 0
        while i < num_kv_tokens:
            idx_val = tl.load(kv_indices_ptr + kv_start + i)
            idx_vec.append(idx_val)
            i += 1

        # Process each query token
        q_idx = 0
        while q_idx < num_q_tokens:
            global_q_idx = q_start + q_idx

            # Causal masking: max_kv_idx = min(q_idx + 1 + (num_kv_tokens - num_q_tokens), num_kv_tokens)
            delta = num_kv_tokens - num_q_tokens
            max_kv_idx = num_kv_tokens
            if (q_idx + 1 + delta) < num_kv_tokens:
                max_kv_idx = q_idx + 1 + delta

            # For each head h
            h = 0
            while h < num_qo_heads:
                kv_head = h // gqa_ratio  # GQA mapping: 32 -> 8, ratio=4

                # Load q_vec[h] for this token: [128]
                q_off = global_q_idx * (num_qo_heads * head_dim) + h * head_dim
                q_vec = tl.load(q_ptr + q_off + tl.arange(0, head_dim))
                q_vec = q_vec.to(tl.float32)  # ensure fp32

                # Initialize lse accumulators for this head
                running_max = tl.full((), -float("inf"), dtype=tl.float32)
                lse_sum = tl.full((), 0.0, dtype=tl.float32)

                # Loop over KV indices i up to max_kv_idx
                i = 0
                while i < max_kv_idx:
                    idx = idx_vec[i]
                    # Compute offsets for K and V rows (flattened layout [num_pages, num_kv_heads, head_dim])
                    k_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim
                    v_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim

                    # Load k_row and v_row vectors
                    k_row = tl.load(k_ptr + k_off + tl.arange(0, head_dim))
                    v_row = tl.load(v_ptr + v_off + tl.arange(0, head_dim))
                    k_row = k_row.to(tl.float32)
                    v_row = v_row.to(tl.float32)

                    # Compute dot product q_vec @ k_row (scalar)
                    dot_val = tl.zeros((), dtype=tl.float32)
                    # Unroll across head_dim in chunks of 16 for efficiency
                    for d in range(0, head_dim, 16):
                        q_chunk = q_vec[d : d + 16]
                        k_chunk = k_row[d : d + 16]
                        dot_val += tl.sum(q_chunk * k_chunk, axis=0)

                    # Scale logits
                    logits_i = dot_val * sm_scale

                    # Streaming logsumexp update
                    new_max = tl.maximum(running_max, logits_i)
                    sum_term = lse_sum * tl.exp(running_max - logits_i) + tl.exp(new_max - logits_i)
                    running_max = new_max
                    lse_sum = sum_term

                    i += 1

                # Compute lse_value = (max + log(sum)) / ln(2)
                lse_value = (running_max + tl.log(lse_sum)) * (1.0 / math.log(2.0))

                # Compute output vector: out_vec[h] = sum_i exp(logits_i - max) * v_row[i]
                out_vec = tl.zeros((head_dim,), dtype=tl.float32)
                i = 0
                while i < max_kv_idx:
                    idx = idx_vec[i]
                    k_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim
                    v_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim

                    k_row = tl.load(k_ptr + k_off + tl.arange(0, head_dim))
                    k_row = k_row.to(tl.float32)
                    v_row = tl.load(v_ptr + v_off + tl.arange(0, head_dim))
                    v_row = v_row.to(tl.float32)

                    dot_val = tl.zeros((), dtype=tl.float32)
                    for d in range(0, head_dim, 16):
                        q_chunk = q_vec[d : d + 16]
                        k_chunk = k_row[d : d + 16]
                        dot_val += tl.sum(q_chunk * k_chunk, axis=0)

                    logits_i = dot_val * sm_scale
                    attn = tl.exp(logits_i - running_max)
                    out_vec += attn * v_row

                    i += 1

                # Store output: output[global_q_idx, h, :] in float32 (host will cast to bfloat16)
                out_addr = output_ptr + (global_q_idx * num_qo_heads + h) * head_dim
                tl.store(out_addr + tl.arange(0, head_dim), out_vec)

                # Update lse[global_q_idx, h] += lse_value / ln(2)
                lse_addr = lse_ptr + (global_q_idx * num_qo_heads + h)
                curr_lse = tl.load(lse_addr)
                new_lse = curr_lse + lse_value
                tl.store(lse_addr, new_lse)

                h += 1
            q_idx += 1
        b += 1

            if v_cache.device.type != "cuda":
                v_cache = v_cache.cuda(non_blocking=True)
            if qo_indptr.device.type != "cuda":

            if kv_indptr.device.type != "cuda":

            if kv_indices.device.type != "cuda":

            # Make inputs contiguous
            q = q.contiguous()
            k_cache = k_cache.contiguous()

            # Flatten k_cache and v_cache by squeezing time dim (always 1 in provided inputs)
            k_cache_flat = k_cache.squeeze(1)  # [num_pages, 8, 128]
