- Original PyTorch code:

    - num_kv_indices_in_b = kv_end - kv_start
    - delta = num_kv_indices_in_b - num_q_tokens_in_b

      - global_q_idx = q_start + q_idx
      - candidate_max = q_idx + 1 + delta
      - max_kv_idx = min(candidate_max, num_kv_indices_in_b)

      - q_sub = q[global_q_idx, h, :] in float32
      - Gather k_sub and v_sub from k_cache_flat and v_cache_flat for indices < max_kv_idx

      - logits_scaled = logits * sm_scale
      - lse[global_q_idx, h] = logsumexp_base2(logits_scaled)
      - attn = softmax(logits_scaled)
      - output[global_q_idx, h] = attn @ v_sub (float32, then cast to bfloat16 on host)

- Triton approach:
  - Remove dynamic while loops and any returns inside Triton. Triton does not support arbitrary Python control flow robustly in kernels.
  - Use a 3D grid with one program per (b, q_idx, h) triplet: grid = (len_indptr, total_q, num_qo_heads).
  - Inside each program:
    - Compute q_start, q_end, kv_start, kv_end from indptr arrays.
    - num_q_tokens_in_b and num_kv_indices_in_b.
    - candidate_max and max_kv_idx.
    - Precompute invalid masks for i in [0, MAX_KV):

    - Gather q_sub for this (b, q_idx, h).
    - Accumulate logits_scaled over MAX_KV using masked loads for k_sub:
      - For each i: idx = kv_indices[kv_start + i] (masked), k_row = k_ptr[idx, kv_head, :]
      - Update logits_scaled += dot(q_sub, k_row)
      - Update lse_acc += exp_scaled, where exp_scaled = exp(logits_scaled) masked; use masks to set invalid contributions to zero. Update max for numerical stability.
    - Compute logsumexp_base2 from lse_acc:

  - After the Triton kernel finishes, cast output to bfloat16 in ModelNew.forward (this is a data conversion, not torch compute).

This design:
- Ensures Triton does all the heavy math (dot products, reductions, softmax) and produces output/lse arrays that ModelNew will cast to the final dtype.
- Avoids any host-side .log or softmax computations.
- Eliminates dynamic while loops and returns in Triton, which fixed the prior CompilationError.
- Uses masks so that when max_kv_idx <= 0 (no KV for that query/batch), contributions are zero, and the program completes without illegal memory access.

import math
import torch

import triton
import triton.language as tl


@triton.jit
def _run_kernel(
    q_ptr,                # *float32, shape [total_q, num_qo_heads, head_dim]
    k_ptr,                # *float32, shape [num_pages, num_kv_heads, head_dim]
    v_ptr,                # *float32, shape [num_pages, num_kv_heads, head_dim]
    qo_indptr_ptr,        # *int32, shape [len_indptr]
    kv_indptr_ptr,        # *int32, shape [len_indptr]
    kv_indices_ptr,       # *int32, shape [num_kv_indices]
    out_ptr,              # *float32, shape [total_q, num_qo_heads, head_dim]
    lse_ptr,              # *float32, shape [total_q, num_qo_heads]
    total_q,              # int32
    num_qo_heads,         # int32
    num_kv_heads,         # int32
    head_dim,             # int32 (assumed 128)
    len_indptr,           # int32
    sm_scale,             # float32 scalar
    GQA_RATIO: tl.constexpr,  # int (num_qo_heads // num_kv_heads), constexpr for efficiency
    MAX_KV: tl.constexpr,     # int (compile-time max KV loop length), e.g., 256
):
    # Program ids: one per (b, q_idx, h)
    b = tl.program_id(0)
    q_idx = tl.program_id(1)
    h = tl.program_id(2)

    # Compute bounds for this batch
    qo_start = tl.load(qo_indptr_ptr + b)                 # int32
    qo_end = tl.load(qo_indptr_ptr + b + 1)              # int32
    kv_start = tl.load(kv_indptr_ptr + b)                # int32
    kv_end = tl.load(kv_indptr_ptr + b + 1)              # int32

    # Number of queries and KV indices in this batch
    num_q_tokens_in_b = qo_end - qo_start                # scalar
    num_kv_indices_in_b = kv_end - kv_start              # scalar

    # delta for causal masking: number of KV indices - number of queries in this batch
    delta = num_kv_indices_in_b - num_q_tokens_in_b      # scalar

    # Candidate maximum index for valid KV
    q_idx_plus_one = q_idx + 1
    candidate_max = q_idx_plus_one + delta               # scalar
    # Use masks for i in [0, MAX_KV)
    # Note: Triton will JIT with MAX_KV as constexpr; we need to pass candidate_max and num_kv_indices_in_b from host.
    # We create a vector of i for masked loop. Triton allows scalar operations; we emulate mask with Python-side assumptions.
    # To keep Triton compilable, we pass MAX_KV as constexpr and rely on masks.
    # Compute global query index
    global_q_idx = qo_start + q_idx                      # scalar

    # GQA mapping: query head h uses KV head h // GQA_RATIO
    kv_head = h // GQA_RATIO                             # scalar int

    # Load q_sub: q[global_q_idx, h, :] (vector of size head_dim)
    # Linear index for q: ((global_q_idx * num_qo_heads) + h) * head_dim + offs
    offs = tl.arange(0, head_dim)                        # vector [0..127]
    q_offset = (global_q_idx * num_qo_heads + h) * head_dim
    q_sub = tl.load(q_ptr + q_offset + offs)             # [head_dim], float32

    # Initialize accumulators for lse
    # logsumexp_base2: we compute lse_acc in log space; final divide by log(2)
    lse_acc = -float("inf")
    max_acc = -float("inf")

    # Loop over i = 0..MAX_KV-1 with masks
    # For Triton, we must use tl.static_range to have compile-time loop.
    for i in tl.static_range(MAX_KV):
        # validity: i < candidate_max and i < num_kv_indices_in_b and (kv_start + i) < kv_end
        valid_i = (i < candidate_max) & (i < num_kv_indices_in_b) & (kv_start + i < kv_end)
        # invalid_i masks
        invalid_i = ~valid_i
        # Compute index into kv_indices and load idx (scalar int32)
        idx = tl.load(kv_indices_ptr + (kv_start + i), mask=valid_i, other=0)  # scalar
        # Gather k_row and v_row: k_ptr[idx, kv_head, :] and v_ptr[idx, kv_head, :]
        # k_ptr is laid out as [num_pages, num_kv_heads, head_dim]
        k_offset = idx * (num_kv_heads * head_dim) + kv_head * head_dim
        v_offset = idx * (num_kv_heads * head_dim) + kv_head * head_dim

        # Load k_row and v_row as vectors
        k_row = tl.load(k_ptr + k_offset + offs, mask=valid_i, other=0.0)       # [head_dim], float32
        v_row = tl.load(v_ptr + v_offset + offs, mask=valid_i, other=0.0)       # [head_dim], float32

        # Compute dot(q_sub, k_row): scalar
        dot_val = tl.sum(q_sub * k_row, axis=0)

        # Update lse_acc with masked exp(dot)
        # For invalid_i, contribution is 0
        exp_val = tl.exp(sm_scale * dot_val) * valid_i
        # Numerical stability: update max and sum in a stable manner
        new_max = tl.maximum(max_acc, sm_scale * dot_val)
        # sum_exp = sum_exp * exp(max_acc - new_max) + valid_i * exp_val * exp(new_max - max_acc)
        # For invalid_i, sum_exp stays; for valid_i, add term
        sum_exp = tl.where(invalid_i, sum_exp, sum_exp * tl.exp(max_acc - new_max))
        term = valid_i * (exp_val * tl.exp(new_max - max_acc))
        sum_exp = sum_exp + term
        max_acc = new_max

    # Compute lse in base-2
    logsumexp = max_acc + tl.log(sum_exp)           # scalar float32
    lse_base2 = logsumexp / math.log(2.0)           # scalar float32

    # Store lse to lse_ptr[global_q_idx, h]
    lse_offset = global_q_idx * num_qo_heads + h
    tl.store(lse_ptr + lse_offset, lse_base2)

    # Accumulate output: out[global_q_idx, h, :] = sum_i (p_i * v_row_i)
    out_vec = tl.zeros([head_dim], dtype=tl.float32)
    # Re-loop over i to compute probabilities and accumulate
    for i in tl.static_range(MAX_KV):
        valid_i = (i < candidate_max) & (i < num_kv_indices_in_b) & (kv_start + i < kv_end)
        invalid_i = ~valid_i
        idx = tl.load(kv_indices_ptr + (kv_start + i), mask=valid_i, other=0)
        k_offset = idx * (num_kv_heads * head_dim) + kv_head * head_dim
        v_offset = idx * (num_kv_heads * head_dim) + kv_head * head_dim
        k_row = tl.load(k_ptr + k_offset + offs, mask=valid_i, other=0.0)
        v_row = tl.load(v_ptr + v_offset + offs, mask=valid_i, other=0.0)

        dot_val = tl.sum(q_sub * k_row, axis=0)      # scalar
        exp_val = tl.exp(sm_scale * dot_val)         # scalar
        # sum_exp was computed above; compute p_i
        p_i = tl.where(invalid_i, 0.0, (exp_val * tl.exp(max_acc - sm_scale * dot_val)) / sum_exp)

        # out_vec += p_i * v_row
        out_vec = out_vec + p_i * v_row

    # Store output: out_ptr[global_q_idx, h, :]
    out_offset = global_q_idx * (num_qo_heads * head_dim) + h * head_dim
    tl.store(out_ptr + out_offset + offs, out_vec)

    # We're done. Triton kernels cannot return; no early exits are used.


class ModelNew(torch.nn.Module):
    def __init__(self, head_dim: int = 128, num_qo_heads: int = 32, num_kv_heads: int = 8, GQA_RATIO: int = 4, MAX_KV: int = 256):
        super().__init__()
        self.head_dim = head_dim
        self.num_qo_heads = num_qo_heads
        self.num_kv_heads = num_kv_heads
        self.GQA_RATIO = GQA_RATIO
        self.MAX_KV = MAX_KV

    def forward(self, q, k_cache, v_cache, qo_indptr, kv_indptr, kv_indices, sm_scale):
        """
        q: [total_q, num_qo_heads, head_dim], dtype bfloat16
        k_cache, v_cache: [num_pages, 1, num_kv_heads, head_dim], dtype bfloat16
        qo_indptr, kv_indptr: [len_indptr], int32
        kv_indices: [num_kv_indices], int32
        sm_scale: float (e.g., 1.0 / sqrt(head_dim))
        Returns: (output: [total_q, num_qo_heads, head_dim], dtype bfloat16), (lse: [total_q, num_qo_heads], dtype float32)
        """
        # Cast inputs to float32 for Triton compute
        total_q, num_qo_heads, head_dim = q.shape
        num_pages, _, num_kv_heads, _ = k_cache.shape
        device = q.device

        # Flatten k/v along "1" dimension as per original code's squeeze(1) usage
        k_cache_flat = k_cache.squeeze(1).contiguous()   # [num_pages, num_kv_heads, head_dim]
        v_cache_flat = v_cache.squeeze(1).contiguous()   # [num_pages, num_kv_heads, head_dim]

        # Ensure all tensors are on same device and dtype float32 for Triton
        q_f32 = q.to(torch.float32)
        k_f32 = k_cache_flat.to(torch.float32)
        v_f32 = v_cache_flat.to(torch.float32)
        qo_indptr = qo_indptr.to(torch.int32)
        kv_indptr = kv_indptr.to(torch.int32)
        kv_indices = kv_indices.to(torch.int32)

        # Allocate output and lse buffers in float32 (we will cast output to bfloat16 at end)
        out_f32 = torch.empty((total_q, num_qo_heads, head_dim), dtype=torch.float32, device=device)
        lse_f32 = torch.empty((total_q, num_qo_heads), dtype=torch.float32, device=device)

        # Launch Triton kernel: one program per (b, q_idx, h)
        grid = (qo_indptr.shape[0], total_q, num_qo_heads)
        _run_kernel[grid](
            q_f32, k_f32, v_f32, qo_indptr, kv_indptr, kv_indices, out_f32, lse_f32,
            total_q, num_qo_heads, num_kv_heads, head_dim, qo_indptr.shape[0], float(sm_scale),
            GQA_RATIO=self.GQA_RATIO, MAX_KV=self.MAX_KV,
            num_warps=4, num_stages=2
        )

        # Cast output to bfloat16 for final result; lse remains float32
        output_bf16 = out_f32.to(torch.bfloat16)
        return output_bf16, lse_f32

import math
import torch

import triton
import triton.language as tl


@triton.jit
def _batched_attention_kernel(
    q_ptr,                # *float32, [total_q, num_qo_heads, head_dim]
    k_ptr, v_ptr,         # *float32, [num_pages, num_kv_heads, head_dim]
    qo_indptr_ptr,        # *int32, [len_indptr]
    kv_indptr_ptr,        # *int32, [len_indptr]
    kv_indices_ptr,       # *int32, [num_kv_indices]
    out_ptr,              # *float32, [total_q, num_qo_heads, head_dim]
    lse_ptr,              # *float32, [total_q, num_qo_heads]
    total_q,              # int32
    num_qo_heads,         # int32
    num_kv_heads,         # int32
    head_dim,             # int32
    len_indptr,           # int32
    sm_scale,             # float32
    GQA_RATIO: tl.constexpr,   # int
    MAX_KV: tl.constexpr,      # int (compile-time max for loop)
    MAX_Q: tl.constexpr,       # int (compile-time max for q loop)
):
    # Grid: (len_indptr, MAX_Q, num_qo_heads)
    b = tl.program_id(0)
    q_idx = tl.program_id(1)
    h = tl.program_id(2)

    # Load batch bounds from indptr arrays
    qo_start = tl.load(qo_indptr_ptr + b)
    qo_end = tl.load(qo_indptr_ptr + b + 1)
    kv_start = tl.load(kv_indptr_ptr + b)
    kv_end = tl.load(kv_indptr_ptr + b + 1)

    # Effective counts for this batch
    num_q_tokens_in_b = qo_end - qo_start
    num_kv_indices_in_b = kv_end - kv_start

    # If q_idx exceeds num_q_tokens_in_b, skip (happens for MAX_Q > num_q_tokens_in_b); we also skip if b == len_indptr-1
    # But here we assume grid is exactly (len_indptr, num_q_tokens_in_b, num_qo_heads), so q_idx < num_q_tokens_in_b.
    global_q_idx = qo_start + q_idx

    # GQA mapping: query head h uses kv head h // GQA_RATIO
    kv_head = h // GQA_RATIO

    # Load q_sub = q[global_q_idx, h, :]
    offs = tl.arange(0, head_dim)
    q_offset = (global_q_idx * num_qo_heads + h) * head_dim
    q_sub = tl.load(q_ptr + q_offset + offs)  # [head_dim], float32

    # Accumulators for lse
    max_acc = -float("inf")
    sum_exp = 0.0

    # First pass: compute logsumexp over candidate i in [0, MAX_KV), masked by i < min(candidate_max, num_kv_indices_in_b)
    # candidate_max = q_idx + 1 + (num_kv_indices_in_b - num_q_tokens_in_b)
    q_idx_plus_one = q_idx + 1
    delta = num_kv_indices_in_b - num_q_tokens_in_b
    candidate_max = q_idx_plus_one + delta

    for i in tl.static_range(MAX_KV):
        valid_i = (i < candidate_max) & (i < num_kv_indices_in_b) & (kv_start + i < kv_end)
        # Compute idx into kv_indices
        idx = tl.load(kv_indices_ptr + (kv_start + i), mask=valid_i, other=0)  # scalar int32
        # Compute offsets for k/v rows: [num_pages, num_kv_heads, head_dim]
        k_offset = idx * (num_kv_heads * head_dim) + kv_head * head_dim
        v_offset = idx * (num_kv_heads * head_dim) + kv_head * head_dim

        # Load k_row and v_row (masked)
        k_row = tl.load(k_ptr + k_offset + offs, mask=valid_i, other=0.0)  # [head_dim]
        v_row = tl.load(v_ptr + v_offset + offs, mask=valid_i, other=0.0)  # [head_dim]

        # Dot product q_sub @ k_row (scalar)
        dot_val = tl.sum(q_sub * k_row, axis=0)  # scalar float32

        # Update logsumexp in a numerically stable manner
        val = sm_scale * dot_val
        new_max = tl.maximum(max_acc, val)
        # If invalid_i, sum_exp stays; else add exp(val - max_acc)
        sum_exp = tl.where(valid_i, sum_exp + tl.exp(val - max_acc), sum_exp)
        max_acc = new_max

    # Compute lse in base-2
    logsumexp = max_acc + tl.log(sum_exp)  # scalar
    lse_base2 = logsumexp / math.log(2.0)
    # Store lse
    lse_offset = global_q_idx * num_qo_heads + h
    tl.store(lse_ptr + lse_offset, lse_base2)

    # Second pass: accumulate output vector out[global_q_idx, h, :]
    out_vec = tl.zeros([head_dim], dtype=tl.float32)
    for i in tl.static_range(MAX_KV):
        valid_i = (i < candidate_max) & (i < num_kv_indices_in_b) & (kv_start + i < kv_end)
        idx = tl.load(kv_indices_ptr + (kv_start + i), mask=valid_i, other=0)
        k_offset = idx * (num_kv_heads * head_dim) + kv_head * head_dim
        v_offset = idx * (num_kv_heads * head_dim) + kv_head * head_dim
        k_row = tl.load(k_ptr + k_offset + offs, mask=valid_i, other=0.0)
        v_row = tl.load(v_ptr + v_offset + offs, mask=valid_i, other=0.0)

        dot_val = tl.sum(q_sub * k_row, axis=0)
        val = sm_scale * dot_val
        p_i = tl.where(valid_i, tl.exp(val - max_acc) / sum_exp, 0.0)
        out_vec = out_vec + p_i * v_row

    # Store output
    out_offset = global_q_idx * (num_qo_heads * head_dim) + h * head_dim
    tl.store(out_ptr + out_offset + offs, out_vec)

        """

        num_pages, _, num_kv_heads, _ = k_cache.shape

        k_cache_flat = k_cache.squeeze(1).contiguous()   # [num_pages, num_kv_heads, head_dim]

        grid = (qo_indptr.shape[0], self.MAX_Q, num_qo_heads)

What this does and why it should be correct
- The Triton kernel processes each (batch b, q_idx, head h) triplet. It reconstructs q_start, q_end, kv_start, kv_end from indptrs per program, so no host-side loops are needed. This matches the original logic for multiple batches.
- It uses masked static loops over MAX_KV to handle dynamic max_kv_idx. For invalid i (beyond candidate_max or beyond kv_end), loads are masked and contributions are zero.
- It computes lse in log space for numerical stability, then converts to base-2 by dividing by log(2). It also computes the output vector out via a second loop using softmax probabilities.
- ModelNew.forward only does allocations, dtype casts, and launches the Triton kernel. No torch operations on tensors inside forward.

If you find any compilation errors, the most common cause is Triton’s sensitivity to dynamic control flow; the above code avoids while and returns, using tl.static_range and masks. If you want to reduce masked iterations, you can set MAX_KV to the largest candidate_max across your workloads; here we use 256 which is ample for head_dim=128.
