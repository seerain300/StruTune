What the original PyTorch code does
- It computes a batch of attention queries q over a KV cache k_cache and v_cache, using grouped-query attention (GQA).
- Inputs:
  - q: [total_q, num_qo_heads, head_dim]
  - k_cache: [num_pages, 1, num_kv_heads, head_dim] with assumed fixed 1 for “page_size”
  - v_cache: [num_pages, 1, num_kv_heads, head_dim]
  - qo_indptr: length len_indptr; q_start = qo_indptr[b], q_end = qo_indptr[b+1] for b in range(len_indptr-1)
  - kv_indptr: length len_indptr; similarly defines per-batch KV ranges
  - kv_indices: [num_kv_indices], each is a “page id” in [0, num_pages)
  - sm_scale: scalar scaling for logits (typically 1/sqrt(head_dim))
- Assertions: num_qo_heads == 32, num_kv_heads == 8, head_dim == 128, and total_q == qo_indptr[-1].item()
- For each batch element b:
  - Compute q_start, q_end, kv_start, kv_end. If invalid ranges, skip.
  - Compute num_kv_tokens = kv_end - kv_start.
  - Compute delta = num_kv_tokens - (q_end - q_start).
  - For each query position q_idx in [q_start, q_end), and each qo head h in [0, num_qo_heads):
    - GQA mapping: kv_head = h // (num_qo_heads // num_kv_heads) = h // 4.
    - max_kv_idx = min(q_idx + 1 + delta, num_kv_tokens).
    - For j in [0, max_kv_idx):
      - k_id = kv_indices[kv_start + j].
      - Load k_row = k_cache_flat[k_id, kv_head, :], v_row = v_cache_flat[k_id, kv_head, :].
      - Accumulate lse = logsumexp over j of scaled dot(q_vec[h], k_row), where q_vec[h] is the query vector segment for head h.
      - Then compute attention for each j: attn = exp(scaled - lse) and out[h] += attn * v_row.
    - Store out[h] to output and lse to lse buffer.

Design for a robust Triton-based implementation
- Keep the Python/host-side loops that drive the algorithm. Triton doesn’t support complex control flow and Python for/while loops in the host code are fine for iterating over b, q_idx, and head h.
- Implement two Triton kernels:
  1) lse_row_kernel: Computes lse (logsumexp of scaled dot products) for a single (b, q_idx, h). It iterates j from 0 to max_kv_idx-1, loads k_row and q_vec, computes scaled dot, updates a running max and sumexp, then writes one scalar lse to the lse buffer.
  2) output_row_kernel: Same as above, but also computes the output vector by iterating j again, computing attn = exp(scaled - lse) and out[h] += attn * v_row. We pass the computed lse from lse_row_kernel. We do not compute lse in this kernel to avoid recomputation; instead we pass lse as an argument.
- We pass the query vector q_vec as a contiguous 1D tensor pointer (length head_dim) for the current q_idx and head h. We also pass kv_indices_ptr to the kernel and do scalar loads for k_id and vector loads for k_row/v_row of length head_dim.
- Important type and shape handling:
  - Ensure q, k_cache, v_cache are moved to CUDA and cast to float32 for computation.
  - Flatten k_cache and v_cache to k_cache_flat and v_cache_flat with shape [num_pages * num_kv_heads, head_dim]. Since in the provided setup “page_size == 1” this is straightforward. If in future “page_size” != 1, flattening can be done as k_cache[:, 0, :, :].reshape(-1, head_dim), but for the current eval this is valid.
  - For q, compute q_vec via q[q_start + q_idx, h, :] as a contiguous 1D tensor and pass its pointer to Triton.
  - Triton vector operations: use tl.arange(0, head_dim) to build 1D index vectors and tl.load(... + tl.arange(0, head_dim)) to load contiguous segments. Avoid .to(tl.float32) or any expand that can trip Triton. All scalars should be tl.int32 or tl.float32; no Python-side dynamic list construction inside Triton.
- Avoid “continue” and overly complex control flow in kernels. Use while loops with scalar j and fixed head_dim (128).
- Host-side forward:
  - Allocate output and lse tensors on device with dtype float32.
  - For each b, q_idx, h:
    - Compute delta and max_kv_idx.
    - Launch lse_row_kernel to get lse for this (b, q_idx, h).
    - Launch output_row_kernel to fill the output vector for this (b, q_idx, h) using the computed lse.
  - Return output (cast to bfloat16 to match original) and lse. For benchmarks, we only need output.

Performance notes
- This replaces the per-(q_idx, head) inner loop over KV rows with Triton kernels. It avoids torch ops in the hot path, doing dot products and reductions in Triton. For small to moderate head_dim (128) and small number of K rows, per-row Triton loads and sums are efficient.
- Although we use host-side loops over b, q_idx, and h, those are modest in this benchmark (hundreds of calls), and Triton kernels will handle the per-row math efficiently. This should be competitive and avoid the previous Triton compilation/runtime issues.

import math
import torch
import triton
import triton.language as tl


# Kernel to compute LSE (logsumexp) over j in [0, max_kv_idx) for a single (b, q_idx, h).
@triton.jit
def _lse_row_kernel(
    kv_indices_ptr,         # *int32
    q_vec_ptr,              # *float32, length head_dim
    k_cache_flat_ptr,       # *float32, shape [num_pages*num_kv_heads, head_dim], contiguous
    lse_out_ptr,            # *float32, scalar (1-element tensor) for this (b, q_idx, h)
    num_kv_tokens: tl.int32,
    kv_start: tl.int32,
    q_idx: tl.int32,        # not used directly, kept for completeness
    num_q_tokens: tl.int32, # not used directly
    delta: tl.int32,
    max_kv_idx: tl.int32,
    head_dim: tl.constexpr, # e.g., 128
    num_kv_heads: tl.int32, # e.g., 8
    gqa_ratio: tl.int32,    # e.g., 4
    sm_scale: tl.float32,   # scaling for logits
):
    h = 0  # this kernel handles a single h implicitly; h is fixed from host launch
    # Running max and sum for LSE
    m = -float('inf')
    sumexp = 0.0  # float32

    # First pass: compute LSE
    j = 0
    while j < max_kv_idx:
        k_id = tl.load(kv_indices_ptr + kv_start + j)  # int32
        kv_head = h // gqa_ratio  # GQA mapping: 32 qo heads -> 8 kv heads
        # Row id in flattened cache: (k_id, kv_head)
        row_id = k_id * (num_kv_heads * head_dim) + kv_head * head_dim
        # Load k_row and q_vec (both length head_dim)
        k_row = tl.load(k_cache_flat_ptr + row_id + tl.arange(0, head_dim))  # [head_dim] float32
        q_vec = tl.load(q_vec_ptr + tl.arange(0, head_dim))                 # [head_dim] float32
        # Dot product
        dot = tl.sum(q_vec * k_row)
        scaled = dot * sm_scale
        m_new = tl.maximum(m, scaled)
        # Rescale sumexp
        sumexp = sumexp * tl.exp(m - m_new) + tl.exp(scaled - m_new)
        m = m_new
        j += 1

    # LSE per original: logsumexp(scaled) / ln(2)
    # Triton math constants
    ln2 = 0.6931471805599453  # math.log(2.0)
    lse_val = (m + tl.log(sumexp)) / ln2
    # Store scalar lse
    tl.store(lse_out_ptr, lse_val)


# Kernel to compute output vector for a single (b, q_idx, h) using the precomputed LSE.
@triton.jit
def _output_row_kernel(
    kv_indices_ptr,         # *int32
    q_vec_ptr,              # *float32, length head_dim
    k_cache_flat_ptr,       # *float32, shape [num_pages*num_kv_heads, head_dim], contiguous
    v_cache_flat_ptr,       # *float32, shape [num_pages*num_kv_heads, head_dim], contiguous
    out_ptr,                # *float32, output vector [head_dim] for this (b, q_idx, h)
    lse_val,                # scalar float32 (same for all j for this q_idx,h)
    num_kv_tokens: tl.int32,
    kv_start: tl.int32,
    q_idx: tl.int32,        # not used directly
    num_q_tokens: tl.int32, # not used directly
    delta: tl.int32,
    max_kv_idx: tl.int32,
    head_dim: tl.constexpr, # e.g., 128
    num_kv_heads: tl.int32, # e.g., 8
    gqa_ratio: tl.int32,    # e.g., 4
    sm_scale: tl.float32,
):
    h = 0  # single h
    # Initialize output vector to zeros
    d = 0
    while d < head_dim:
        tl.store(out_ptr + d, 0.0)
        d += 1

    j = 0
    while j < max_kv_idx:
        k_id = tl.load(kv_indices_ptr + kv_start + j)
        kv_head = h // gqa_ratio
        row_id = k_id * (num_kv_heads * head_dim) + kv_head * head_dim
        k_row = tl.load(k_cache_flat_ptr + row_id + tl.arange(0, head_dim))  # [head_dim]
        q_vec = tl.load(q_vec_ptr + tl.arange(0, head_dim))                 # [head_dim]
        dot = tl.sum(q_vec * k_row)
        scaled = dot * sm_scale
        attn = tl.exp(scaled - lse_val)  # softmax normalized
        v_row = tl.load(v_cache_flat_ptr + row_id + tl.arange(0, head_dim))  # [head_dim]
        # out += attn * v_row
        d = 0
        while d < head_dim:
            out_ptr[d] += attn * v_row[d]
            d += 1
        j += 1


class ModelNew(torch.nn.Module):
    def forward(self, q, k_cache, v_cache, qo_indptr, kv_indptr, kv_indices, sm_scale):
        # Ensure CUDA and dtype
        device = q.device
        if device.type != "cuda":
            raise RuntimeError("ModelNew requires CUDA tensors. Move inputs to CUDA.")
        q_f32 = q.to(torch.float32).contiguous()
        # Flatten k_cache and v_cache since 'page_size' is 1 in the provided setup.
        # Shape assumptions: k_cache: [num_pages, 1, num_kv_heads, head_dim]
        k_flat = k_cache.squeeze(1).to(torch.float32).contiguous()  # [num_pages, num_kv_heads, head_dim] -> flatten below
        v_flat = v_cache.squeeze(1).to(torch.float32).contiguous()

        # We will flatten to [num_pages * num_kv_heads, head_dim]
        num_pages, _, num_kv_heads, head_dim = k_cache.shape
        k_flat = k_flat.reshape(num_pages * num_kv_heads, head_dim)
        v_flat = v_flat.reshape(num_pages * num_kv_heads, head_dim)

        len_indptr = qo_indptr.shape[0]
        total_q = int(qo_indptr[-1].item())
        # Allocate outputs
        output = torch.zeros((total_q, 32, head_dim), dtype=torch.float32, device=device)
        lse = torch.full((total_q, 32), -float("inf"), dtype=torch.float32, device=device)

        # Constants
        gqa_ratio = 4  # 32 qo heads -> 8 kv heads, each qo head maps to 8*4=32 kv heads
        sm_scale = float(sm_scale)

        # Iterate over batches defined by qo_indptr
        for b in range(len_indptr - 1):
            q_start = int(qo_indptr[b].item())
            q_end = int(qo_indptr[b + 1].item())
            if q_start >= q_end:
                continue
            kv_start = int(kv_indptr[b].item())
            kv_end = int(kv_indptr[b + 1].item())
            if kv_start >= kv_end:
                continue

            num_q_tokens = q_end - q_start
            num_kv_tokens = kv_end - kv_start
            delta = num_kv_tokens - num_q_tokens
            max_kv_idx = min(q_start + 1 + delta, num_kv_tokens)

            # Loop over each query token and each qo head
            for q_idx in range(num_q_tokens):
                global_q_idx = q_start + q_idx
                # Prepare q vector for this head
                for h in range(32):
                    # q_vec is contiguous segment of length head_dim
                    q_vec = q_f32[global_q_idx, h]  # [head_dim], already contiguous
                    # Allocate output buffer and lse scalar
                    out_buf = torch.empty(head_dim, dtype=torch.float32, device=device)
                    lse_buf = torch.empty(1, dtype=torch.float32, device=device)

                    # Launch LSE kernel
                    _lse_row_kernel[(1,)](
                        kv_indices,                      # *int32
                        q_vec,                           # *float32, 1D tensor
                        k_flat,                          # *float32
                        lse_buf,                         # *float32, scalar
                        num_kv_tokens,
                        kv_start,
                        q_idx,
                        num_q_tokens,
                        delta,
                        max_kv_idx,
                        head_dim=128,
                        num_kv_heads=8,
                        gqa_ratio=4,
                        sm_scale=sm_scale,
                    )
                    lse_val = lse_buf[0]  # scalar float32

                    # Launch output kernel
                    _output_row_kernel[(1,)](
                        kv_indices,
                        q_vec,
                        k_flat,
                        v_flat,                          # *float32
                        out_buf,                         # *float32
                        lse_val,
                        num_kv_tokens,
                        kv_start,
                        q_idx,
                        num_q_tokens,
                        delta,
                        max_kv_idx,
                        head_dim=128,
                        num_kv_heads=8,
                        gqa_ratio=4,
                        sm_scale=sm_scale,
                    )

                    # Store result
                    output[global_q_idx, h] = out_buf

        # Cast output to bfloat16 to match original signature expectations
        output_bf16 = output.to(torch.bfloat16)
        return output_bf16, lse

        k_id = tl.load(kv_indices_ptr + kv_start + j)  # int32
        kv_head = h // 4  # GQA mapping: 32 qo heads -> 8 kv heads
        row_id = k_id * (num_kv_heads * head_dim) + kv_head * head_dim
        k_row = tl.load(k_cache_flat_ptr + row_id + tl.arange(0, head_dim))  # [head_dim] float32
        q_vec = tl.load(q_vec_ptr + tl.arange(0, head_dim))                 # [head_dim] float32
        dot = tl.sum(q_vec * k_row)
        scaled = dot * sm_scale
        m_new = tl.maximum(m, scaled)
        sumexp = sumexp * tl.exp(m - m_new) + tl.exp(scaled - m_new)
        m = m_new
        j += 1

    # LSE: logsumexp(scaled) / ln(2)
    ln2 = 0.6931471805599453  # math.log(2.0)
    lse_val = (m + tl.log(sumexp)) / ln2
    tl.store(lse_out_ptr, lse_val)


@triton.jit
def _output_row_kernel_h(
    kv_indices_ptr,         # *int32
    q_vec_ptr,              # *float32, length head_dim
    k_cache_flat_ptr,       # *float32, [num_pages*num_kv_heads, head_dim], contiguous
    v_cache_flat_ptr,       # *float32, [num_pages*num_kv_heads, head_dim], contiguous
    out_ptr,                # *float32, output vector [head_dim]
    lse_val,                # scalar float32
    h: tl.int32,            # qo head index
    num_kv_tokens: tl.int32,
    kv_start: tl.int32,
    q_idx: tl.int32,        # not used directly
    num_q_tokens: tl.int32, # not used directly
    delta: tl.int32,
    max_kv_idx: tl.int32,
    head_dim: tl.constexpr, # e.g., 128
    num_kv_heads: tl.int32, # e.g., 8
    sm_scale: tl.float32,   # scaling for logits (not used here, but kept for signature symmetry)
):
    # Initialize output vector to zeros
    d = 0
    while d < head_dim:
        tl.store(out_ptr + d, 0.0)
        d += 1

    j = 0
    while j < max_kv_idx:
        k_id = tl.load(kv_indices_ptr + kv_start + j)
        kv_head = h // 4
        row_id = k_id * (num_kv_heads * head_dim) + kv_head * head_dim
        k_row = tl.load(k_cache_flat_ptr + row_id + tl.arange(0, head_dim))  # [head_dim]
        q_vec = tl.load(q_vec_ptr + tl.arange(0, head_dim))                 # [head_dim]
        dot = tl.sum(q_vec * k_row)
        scaled = dot * sm_scale
        attn = tl.exp(scaled - lse_val)  # softmax normalized per j
        v_row = tl.load(v_cache_flat_ptr + row_id + tl.arange(0, head_dim))  # [head_dim]
        # out += attn * v_row
        d = 0
        while d < head_dim:
            out_ptr[d] += attn * v_row[d]
            d += 1
        j += 1
