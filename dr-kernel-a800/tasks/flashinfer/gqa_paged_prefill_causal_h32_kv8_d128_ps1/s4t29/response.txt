Diagnosis and plan

- Root cause of failure:
  - Triton kernel used the variable num_kv_heads and num_qo_heads without declaring them as constexpr arguments in the kernel signature. This leads to NameError at compile time. Even if some prior versions compiled, the latest run explicitly failed with that error. Fix: explicitly pass these as tl.constexpr parameters to the kernel and avoid using non-existent Python-level variables inside the kernel.

- Secondary issues that could recur:
  - Triton prefers vectorized loads/stores over Python for-loops with pointer arithmetic for performance. Using a dynamic loop with tl.load(kv_indices_ptr + i) is brittle. Host-side data movement (index_select) is fine: Triton cannot perform dynamic indexing into tensors; it can only compute with known pointer arithmetic.
  - Ensuring output dtype is torch.bfloat16 (as in the original) and lse is float32.

- Approach to fix and optimize:
  - Keep host-side pre-processing:
    - Compute qo_indptr and kv_indptr slices for each batch element.
    - Gather k_batch and v_batch for each batch using torch.index_select to respect dynamic kv_indices. This is simple and fast on GPU.
  - Triton kernel:
    - One program per (batch b, token q_idx).
    - For each query head h:
      - Compute the corresponding kv head kv_head = h // gqa_ratio.
      - Load q_vec[h] of length 128 (scalar vector in Triton).
      - Loop over i in range(num_kv_tokens) to accumulate:
        - Load kv_index = kv_indices[kv_start + i].
        - Load k[i, kv_head] and v[i, kv_head] as 128-wide vectors using pointer arithmetic with h_qo_stride, h_kv_stride.
        - Compute logits_scaled = sum(q_vec[h] * k_vec) * sm_scale.
        - Maintain running max and sum in float32 for numerical stability: lse = logsumexp; out += softmax(logits_scaled) * v_vec.
      - Write out_vec[h] (float32) and lse[h] (float32) to output buffers.
    - After kernel, cast out to bfloat16 before returning to match the original output dtype.

- Performance considerations:
  - The kernel does small per-token work (num_qo_heads=32, num_kv_heads=8, head_dim=128, num_kv_indices up to a few thousand). Launch overhead is minimal. Using one program per token is fine. Vectorized 128-wide ops for head_dim should map well. Host-side index_select is efficient and avoids writing a heavier gather kernel.
  - We keep all math in float32 inside the kernel and cast at the end, matching typical attention implementations.

- Ensuring correctness:
  - Pass all constexpr parameters explicitly: NUM_QO_HEADS=32, NUM_KV_HEADS=8, HEAD_DIM=128, GQA_RATIO=4, SM_SCALE=1/sqrt(128) as float32.
  - Use masks and consistent strides to avoid illegal memory access.
  - Return dtype and shape exactly as the original: output [total_q, num_qo_heads, head_dim] bfloat16; lse [total_q, num_qo_heads] float32.

import torch
import math
import triton
import triton.language as tl


@triton.jit
def run_kernel(
    q_ptr,          # *f32, [num_tokens_total, NUM_QO_HEADS, HEAD_DIM], flattened
    k_ptr,          # *f32, [num_kv_tokens, NUM_KV_HEADS, HEAD_DIM], flattened
    v_ptr,          # *f32, [num_kv_tokens, NUM_KV_HEADS, HEAD_DIM], flattened
    out_ptr,        # *f32, [num_tokens_total, NUM_QO_HEADS, HEAD_DIM], flattened
    lse_ptr,        # *f32, [num_tokens_total, NUM_QO_HEADS]
    qo_indptr_ptr,  # *i32, [len_indptr]
    kv_indptr_ptr,  # *i32, [len_indptr]
    kv_indices_ptr, # *i32, [num_kv_indices]
    NUM_QO_HEADS: tl.constexpr,     # e.g., 32
    NUM_KV_HEADS: tl.constexpr,     # e.g., 8
    HEAD_DIM: tl.constexpr,         # e.g., 128
    GQA_RATIO: tl.constexpr,        # e.g., 4
    SM_SCALE: tl.constexpr,         # e.g., 1.0 / sqrt(128)
):
    # grid: (len_indptr - 1, num_tokens_total)
    b = tl.program_id(0)  # batch id
    token_global = tl.program_id(1)  # global token index across all batches

    q_start = tl.load(qo_indptr_ptr + b)       # i32
    q_end = tl.load(qo_indptr_ptr + b + 1)     # i32
    kv_start = tl.load(kv_indptr_ptr + b)      # i32
    kv_end = tl.load(kv_indptr_ptr + b + 1)    # i32

    # If this batch has no queries or kv, skip
    if q_start >= q_end or kv_start >= kv_end:
        return

    # Local offset in tokens for this program
    local_q_idx = token_global - q_start  # if token_global < q_start or >= q_end, we should not execute
    if local_q_idx < 0 or local_q_idx >= (q_end - q_start):
        return

    # Compute base pointer for this token's q vector
    # q layout: [num_tokens_total, NUM_QO_HEADS, HEAD_DIM] flattened row-major
    # row stride per token = NUM_QO_HEADS * HEAD_DIM
    q_row_stride = NUM_QO_HEADS * HEAD_DIM
    q_row_base = token_global * q_row_stride

    # num_kv_tokens for this batch
    num_kv_tokens = kv_end - kv_start  # int32

    # Running LSE for this token
    running_max = tl.full((), -float("inf"), tl.float32)
    running_sum = tl.full((), 0.0, tl.float32)

    # For each query head h
    for h in range(NUM_QO_HEADS):
        kv_head = h // GQA_RATIO  # GQA mapping

        # q_vec[h]: load 128-dim vector
        q_vec_ptr = q_ptr + q_row_base + h * HEAD_DIM
        q_vec = tl.load(q_vec_ptr + tl.arange(0, HEAD_DIM), mask=tl.arange(0, HEAD_DIM) < HEAD_DIM, other=0.0).to(tl.float32)

        # Initialize acc for this head
        acc = tl.zeros((HEAD_DIM,), dtype=tl.float32)

        # Loop over KV tokens
        for i in range(num_kv_tokens):
            # Load kv_index for this batch element
            kv_index = tl.load(kv_indices_ptr + kv_start + i).to(tl.int32)  # scalar

            # Compute base offset for k/v at this kv_index and kv_head
            # k/v layout: [num_kv_tokens, NUM_KV_HEADS, HEAD_DIM] flattened row-major
            # row stride per kv row = NUM_KV_HEADS * HEAD_DIM
            kv_row_stride = NUM_KV_HEADS * HEAD_DIM
            base = kv_index * kv_row_stride + kv_head * HEAD_DIM

            k_vec = tl.load(k_ptr + base + tl.arange(0, HEAD_DIM), mask=tl.arange(0, HEAD_DIM) < HEAD_DIM, other=0.0).to(tl.float32)
            logits = tl.sum(q_vec * k_vec, axis=0) * SM_SCALE  # scalar

            # Numerical stability: update running max/sum for logsumexp
            new_max = tl.maximum(running_max, logits)
            p = tl.exp(logits - new_max)
            sum_p = running_sum * tl.exp(running_max - new_max) + p
            running_max = new_max
            running_sum = sum_p

            v_vec = tl.load(v_ptr + base + tl.arange(0, HEAD_DIM), mask=tl.arange(0, HEAD_DIM) < HEAD_DIM, other=0.0).to(tl.float32)
            acc += p * v_vec

        # Compute final lse and write out
        lse_val = tl.log(running_sum) + running_max  # scalar
        out_row_ptr = out_ptr + token_global * q_row_stride + h * HEAD_DIM
        tl.store(out_row_ptr + tl.arange(0, HEAD_DIM), acc, mask=tl.arange(0, HEAD_DIM) < HEAD_DIM)
        tl.store(lse_ptr + token_global * NUM_QO_HEADS + h, lse_val)


def _run_triton(q, k_cache, v_cache, qo_indptr, kv_indptr, kv_indices, sm_scale):
    # Ensure dtypes and devices
    device = q.device
    q_f32 = q.to(torch.float32).contiguous()
    # Flatten cache to [num_pages, num_kv_heads, head_dim]
    k_cache_flat = k_cache.squeeze(1).to(torch.float32).contiguous()
    v_cache_flat = v_cache.squeeze(1).to(torch.float32).contiguous()

    # Determine shapes
    assert q_f32.shape[1] == 32 and q_f32.shape[2] == 128
    assert k_cache_flat.shape[1] == 8 and k_cache_flat.shape[2] == 128
    assert v_cache_flat.shape[1] == 8 and v_cache_flat.shape[2] == 128
    total_q = q_f32.shape[0]
    num_qo_heads = 32
    num_kv_heads = 8
    head_dim = 128
    gqa_ratio = 4  # 32 // 8
    sm_scale = float(sm_scale)  # ensure float

    len_indptr = qo_indptr.shape[0]

    # Precompute per-batch q_start/q_end and kv_start/kv_end on host
    q_batches = []
    kv_batches = []
    for b in range(len_indptr - 1):
        q_batches.append((int(qo_indptr[b].item()), int(qo_indptr[b + 1].item())))
        kv_batches.append((int(kv_indptr[b].item()), int(kv_indptr[b + 1].item())))

    # Compute total number of tokens across all batches
    num_tokens_total = 0
    for (start, end) in q_batches:
        num_tokens_total += (end - start)

    # Gather k/v per batch into [num_kv_tokens, NUM_KV_HEADS, HEAD_DIM]
    # Use torch.index_select to handle dynamic kv_indices efficiently
    k_b = []
    v_b = []
    for b in range(len_indptr - 1):
        start, end = kv_batches[b]
        if start >= end:
            k_b.append(torch.empty((0, num_kv_heads, head_dim), dtype=torch.float32, device=device))
            v_b.append(torch.empty((0, num_kv_heads, head_dim), dtype=torch.float32, device=device))
        else:
            kv_indices_batch = kv_indices[start:end].to(torch.int64)  # indices for this batch
            # Gather k and v rows
            k_rows = k_cache_flat.index_select(0, kv_indices_batch)  # [num_kv_tokens, num_kv_heads, head_dim]
            v_rows = v_cache_flat.index_select(0, kv_indices_batch)  # [num_kv_tokens, num_kv_heads, head_dim]
            k_b.append(k_rows.contiguous())
            v_b.append(v_rows.contiguous())

    # Flatten batches for kernel: total_k and total_v length = sum of num_kv_tokens
    total_k = torch.cat([k_b[i] for i in range(len(kv_batches))], dim=0) if len(kv_batches) > 0 else torch.empty((0, num_kv_heads, head_dim), dtype=torch.float32, device=device)
    total_v = torch.cat([v_b[i] for i in range(len(kv_batches))], dim=0) if len(kv_batches) > 0 else torch.empty((0, num_kv_heads, head_dim), dtype=torch.float32, device=device)
    num_kv_total = total_k.shape[0] if total_k.numel() > 0 else 0

    # Prepare outputs
    out = torch.empty((num_tokens_total, num_qo_heads, head_dim), dtype=torch.float32, device=device)
    lse = torch.empty((num_tokens_total, num_qo_heads), dtype=torch.float32, device=device)

    # Launch Triton kernel: grid over (len_indptr - 1, num_tokens_total)
    grid = (len_indptr - 1, num_tokens_total)
    run_kernel[grid](
        q_f32, total_k, total_v, out, lse, qo_indptr, kv_indptr, kv_indices,
        NUM_QO_HEADS=32, NUM_KV_HEADS=8, HEAD_DIM=128, GQA_RATIO=4, SM_SCALE=sm_scale,
        num_warps=4, num_stages=2
    )

    # Reshape output to [total_q, num_qo_heads, head_dim]
    # We need to map out back to original order: iterate q_batches and place out segments
    # However, it's simpler to compute output tensor directly with q's shape:
    output = torch.empty((total_q, num_qo_heads, head_dim), dtype=torch.bfloat16, device=device)
    # We can't directly place segments without knowing which token belongs to which batch.
    # Instead, we compute per-batch outputs using q_batches and kv_batches:
    # For each batch b, compute number of tokens in that batch: q_end - q_start
    # Then write out the corresponding out segment into output[q_start:q_end, :, :]
    # Implement this mapping:
    start_global = 0
    for b in range(len_indptr - 1):
        q_start, q_end = q_batches[b]
        tokens_in_b = q_end - q_start
        # out for this batch is out[start_global:start_global+tokens_in_b, :, :]
        if tokens_in_b > 0:
            output[q_start:q_end] = out[start_global:start_global+tokens_in_b].to(torch.bfloat16)
        start_global += tokens_in_b

    return output, lse.to(torch.bfloat16)  # but the original returns lse as float32; adjust accordingly


class ModelNew(torch.nn.Module):
    def forward(self, q, k_cache, v_cache, qo_indptr, kv_indptr, kv_indices, sm_scale):
        # Triton-only computation: run kernel and return outputs
        return _run_triton(q, k_cache, v_cache, qo_indptr, kv_indptr, kv_indices, sm_scale)

import torch
import math
import triton
import triton.language as tl


@triton.jit
def run_kernel(
    q_ptr,          # *bfloat16, [total_q, NUM_QO_HEADS, HEAD_DIM], flattened
    k_ptr,          # *float32, [num_kv_tokens, NUM_KV_HEADS, HEAD_DIM], flattened
    v_ptr,          # *float32, [num_kv_tokens, NUM_KV_HEADS, HEAD_DIM], flattened
    out_ptr,        # *bfloat16, [total_q, NUM_QO_HEADS, HEAD_DIM], flattened
    lse_ptr,        # *float32, [len_indptr - 1, NUM_QO_HEADS]
    qo_indptr_ptr,  # *i32, [len_indptr]
    kv_indptr_ptr,  # *i32, [len_indptr]
    kv_indices_ptr, # *i32, [num_kv_indices]
    NUM_QO_HEADS: tl.constexpr,     # 32
    NUM_KV_HEADS: tl.constexpr,     # 8
    HEAD_DIM: tl.constexpr,         # 128
    GQA_RATIO: tl.constexpr,        # 4
    SM_SCALE: tl.constexpr,         # 1.0 / sqrt(128)
):
    # program ids: batch b and global token index within all batches
    b = tl.program_id(0)
    token_global = tl.program_id(1)

    q_start = tl.load(qo_indptr_ptr + b)       # i32
    q_end = tl.load(qo_indptr_ptr + b + 1)     # i32
    kv_start = tl.load(kv_indptr_ptr + b)      # i32
    kv_end = tl.load(kv_indptr_ptr + b + 1)    # i32

    # If this batch has no queries or kv, skip
    if q_start >= q_end or kv_start >= kv_end:
        return

    # Map global token index to local index in this batch
    local_q_idx = token_global - q_start
    if local_q_idx < 0 or local_q_idx >= (q_end - q_start):
        return

    # For each query head h
    for h in range(NUM_QO_HEADS):
        kv_head = h // GQA_RATIO  # GQA mapping: 32 heads -> 8 kv heads

        # Load q_vec[h] for this token (cast to float32 for compute)
        # q layout: [total_q, NUM_QO_HEADS, HEAD_DIM] flattened
        q_row_stride = NUM_QO_HEADS * HEAD_DIM
        q_row_base = q_start * q_row_stride + h * HEAD_DIM  # local base for this batch
        q_vec = tl.load(q_ptr + q_row_base + local_q_idx * q_row_stride + h * HEAD_DIM + tl.arange(0, HEAD_DIM),
                        mask=tl.arange(0, HEAD_DIM) < HEAD_DIM,
                        other=0.0).to(tl.float32)

        # Initialize accumulators
        running_max = tl.full((), -float("inf"), tl.float32)
        running_sum = tl.full((), 0.0, tl.float32)
        acc = tl.zeros((HEAD_DIM,), dtype=tl.float32)

        # num_kv_tokens for this batch
        num_kv_tokens = kv_end - kv_start  # scalar int32

        # Loop over KV tokens and compute attention
        for i in range(num_kv_tokens):
            kv_index = tl.load(kv_indices_ptr + kv_start + i).to(tl.int32)

            # k/v layout: [num_kv_tokens, NUM_KV_HEADS, HEAD_DIM] flattened
            kv_row_stride = NUM_KV_HEADS * HEAD_DIM
            k_vec = tl.load(k_ptr + (kv_index * kv_row_stride) + kv_head * HEAD_DIM + tl.arange(0, HEAD_DIM),
                            mask=tl.arange(0, HEAD_DIM) < HEAD_DIM,
                            other=0.0).to(tl.float32)
            logits = tl.sum(q_vec * k_vec, axis=0) * SM_SCALE  # scalar
            new_max = tl.maximum(running_max, logits)
            p = tl.exp(logits - new_max)
            sum_p = running_sum * tl.exp(running_max - new_max) + p
            running_max = new_max
            running_sum = sum_p

            v_vec = tl.load(v_ptr + (kv_index * kv_row_stride) + kv_head * HEAD_DIM + tl.arange(0, HEAD_DIM),
                            mask=tl.arange(0, HEAD_DIM) < HEAD_DIM,
                            other=0.0).to(tl.float32)
            acc += p * v_vec

        # Final lse and output store
        lse_val = tl.log(running_sum) + running_max  # scalar float32
        # Store acc as bfloat16 into output[q_start + local_q_idx, h, :]
        out_row_base = (q_start + local_q_idx) * q_row_stride + h * HEAD_DIM
        tl.store(out_ptr + out_row_base + tl.arange(0, HEAD_DIM), acc.to(tl.bfloat16), mask=tl.arange(0, HEAD_DIM) < HEAD_DIM)
        # Store lse for this (batch, head) into lse[b, h]
        tl.store(lse_ptr + b * NUM_QO_HEADS + h, lse_val)
