  - Determine max_kv_idx as described. j iterates 0..max_kv_idx-1 (compile-time loop size using constexpr MAX_K = 128, but we mask j >= max_kv_idx).

- “continue” in Triton (use mask and grid to skip invalid cases).
- Dynamic while loops in Triton (use constexpr and for loops).
