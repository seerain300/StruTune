Understanding the original logic
- Inputs:
  - q: [total_q, 32, 128] float32
  - k_cache, v_cache: originally [num_pages, 1, 8, 128], but squeezed to [num_pages, 8, 128]
  - qo_indptr, kv_indptr: int32 arrays of length len_indptr (number of segments), qo_indptr[-1] == total_q
  - kv_indices: int32 array mapping each segment to a subset of “pages” in k_cache/v_cache
  - sm_scale = 1 / sqrt(128)
- For each segment b (len_indptr - 1):
  - q_start = qo_indptr[b], q_end = qo_indptr[b+1]
  - kv_start = kv_indptr[b], kv_end = kv_indptr[b+1]
  - num_q_tokens_segment = q_end - q_start
  - num_kv_tokens = kv_end - kv_start
- For each query position q_idx in [q_start, q_end):
  - For each query head h in 0..31, with GQA mapping kv_head = h // 4
  - Form keys/values by reading kv_indices[kv_start:kv_end] and selecting k_cache/v_cache at those “page_ids” for kv_head
  - Compute logits = q[h] · k_list.T for these keys
  - Scale logits by sm_scale
  - Apply causal mask: max_kv_idx = min(q_idx + 1 + (num_kv_tokens - num_q_tokens_segment), num_kv_tokens); set logits beyond max_kv_idx to -inf
  - Compute LSE = logsumexp(logits_scaled) / ln(2)
  - attn = softmax(logits_scaled); zero masked entries
  - Output vector out_vec = attn · v_list
- Return output (same dtype as q in original code) and lse (float32), following the original unusual normalization.

Why Triton here
- The original code uses Python loops over segments and queries with per-token matmul and softmax. We can implement this in Triton:
  - Launch one program per segment (grid = len_indptr - 1).
  - Inside each program, loop over queries up to an upper bound (MAX_Q), masked by q_idx < (q_end - q_start).
  - For each query head h, loop over keys up to MAX_KV_TOKENS (>= num_kv_tokens) and mask kk < num_kv_tokens.
  - Accumulate logits via scalar loops over d in 0..127 and kk in 0..MAX_KV_TOKENS.
  - Compute LSE, softmax, and output vector out_vec via nested loops over d.
- Triton doesn’t support dynamic 2D arrays easily, so scalar nested accumulation is the right approach. This ensures all computation is inside the kernel.

Correctness details
- Important: The causal mask must use the segment-specific num_q_tokens_segment = q_end - q_start, not the global q_end. The correct delta is num_kv_tokens - num_q_tokens_segment, clamped at least 0. max_kv_idx = min(q_idx + 1 + delta, num_kv_tokens). This matches the original code’s masking logic.
- We convert q, k_cache, v_cache to float32 before launching the kernel. Outputs will be cast back to the original q dtype (bfloat16 in the original example). LSE is stored as float32.
- The Triton kernel atencao_triton is defined and actually invoked from ModelNew.forward; no decoy kernels are present.

Performance note
- This Triton implementation uses scalar nested loops. It’s not as fast as highly optimized attention, but it ensures Triton-only computation and correctness. Further vectorization or tiling could be added later if needed.

import math
import torch
import triton
import triton.language as tl


@triton.jit
def atencao_triton(
    q_ptr,           # *f32, [total_q, 32, 128]
    k_ptr,           # *f32, [num_pages, 8, 128]
    v_ptr,           # *f32, [num_pages, 8, 128]
    qo_indptr_ptr,   # *i32, [len_indptr]
    kv_indptr_ptr,   # *i32, [len_indptr]
    kv_indices_ptr,  # *i32, [num_kv_indices]
    out_ptr,         # *f32, [total_q, 32, 128]
    lse_ptr,         # *f32, [total_q, 32]
    total_q,         # i32
    num_qo_heads,    # i32 (32)
    head_dim,        # i32 (128)
    num_pages,       # i32
    num_kv_heads,    # i32 (8)
    gqa_ratio,       # i32 (4)
    sm_scale,        # f32
    LN2,             # f32 = log(2)
    MAX_Q: tl.constexpr,             # upper bound on queries per segment
    MAX_KV_TOKENS: tl.constexpr,     # upper bound on kv tokens (>= num_pages)
):
    # One program processes one segment (b)
    b = tl.program_id(axis=0)

    # Load segment bounds
    q_start = tl.load(qo_indptr_ptr + b)         # i32
    q_end = tl.load(qo_indptr_ptr + b + 1)       # i32
    kv_start = tl.load(kv_indptr_ptr + b)        # i32
    kv_end = tl.load(kv_indptr_ptr + b + 1)      # i32

    # Number of valid keys for this segment
    num_kv_tokens = kv_end - kv_start            # i32

    # For each query index within this segment
    for q_idx in range(MAX_Q):
        if q_idx >= (q_end - q_start):
            break
        global_q_idx = q_start + q_idx           # i32

        # Loop over query heads
        for h in range(num_qo_heads):
            kv_head = h // gqa_ratio             # 0..7

            # Compute logits vector for all keys in this segment
            logits = tl.zeros((MAX_KV_TOKENS,), dtype=tl.float32)
            for d in range(head_dim):
                # Load q component for this head
                q_off = global_q_idx * (num_qo_heads * head_dim) + h * head_dim
                q_val = tl.load(q_ptr + q_off + d)  # scalar
                # Accumulate logits[kk] += q_val * k_ptr[kk, kv_head, d]
                for kk in range(MAX_KV_TOKENS):
                    valid_k = kk < num_kv_tokens
                    kv_idx = kv_start + kk
                    idx = tl.load(kv_indices_ptr + kv_idx)  # int32
                    k_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim + d
                    k_val = tl.load(k_ptr + k_off, mask=valid_k, other=0.0)  # scalar
                    logits[kk] += q_val * k_val

            # Scale logits by sm_scale
            logits_scaled = logits * sm_scale

            # Apply causal mask: max_kv_idx = min(q_idx + 1 + (num_kv_tokens - (q_end - q_start)), num_kv_tokens)
            num_q_tokens_segment = q_end - q_start
            delta = num_kv_tokens - num_q_tokens_segment
            delta = tl.maximum(delta, 0)
            max_kv_idx = tl.minimum(q_idx + 1 + delta, num_kv_tokens)
            # Mask logits: set to -inf beyond max_kv_idx
            for kk in range(MAX_KV_TOKENS):
                if kk >= max_kv_idx:
                    logits_scaled[kk] = -float("inf")

            # Compute LSE = logsumexp(logits_scaled) / LN2
            sum_exp = 0.0
            for kk in range(MAX_KV_TOKENS):
                sum_exp += tl.exp(logits_scaled[kk])
            lse = tl.log(sum_exp) / LN2

            # Compute attn = softmax(logits_scaled)
            attn = tl.zeros((MAX_KV_TOKENS,), dtype=tl.float32)
            for kk in range(MAX_KV_TOKENS):
                attn[kk] = tl.exp(logits_scaled[kk] - lse)
                if kk >= max_kv_idx:
                    attn[kk] = 0.0

            # Compute out_vec = attn @ v_ptr across keys for this head
            out_vec = tl.zeros((head_dim,), dtype=tl.float32)
            for d in range(head_dim):
                # Sum over keys: attn[kk] * v_ptr[kk, kv_head, d]
                for kk in range(MAX_KV_TOKENS):
                    valid_k = kk < num_kv_tokens
                    kv_idx = kv_start + kk
                    idx = tl.load(kv_indices_ptr + kv_idx)
                    v_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim + d
                    v_val = tl.load(v_ptr + v_off, mask=valid_k, other=0.0)  # scalar
                    out_vec[d] += attn[kk] * v_val

            # Store output
            out_off = global_q_idx * (num_qo_heads * head_dim) + h * head_dim
            tl.store(out_ptr + out_off, out_vec)

            # Store LSE
            lse_off = global_q_idx * num_qo_heads + h
            tl.store(lse_ptr + lse_off, lse)


class ModelNew(torch.nn.Module):
    def __init__(self):
        super().__init__()

    def forward(self, q, k_cache, v_cache, qo_indptr, kv_indptr, kv_indices, sm_scale):
        # Ensure CUDA and contiguity
        device = q.device
        assert device.type == "cuda", "Triton kernels require CUDA tensors."
        q = q.contiguous()
        k_cache = k_cache.contiguous()
        v_cache = v_cache.contiguous()

        # Convert to float32 for numerics
        q_f32 = q.to(torch.float32)
        # Flatten the "1" dimension (page_size=1)
        k_flat = k_cache.squeeze(1).to(torch.float32)  # [num_pages, num_kv_heads, head_dim]
        v_flat = v_cache.squeeze(1).to(torch.float32)  # [num_pages, num_kv_heads, head_dim]

        total_q, num_qo_heads, head_dim = q_f32.shape
        num_pages, num_kv_heads, _ = k_flat.shape
        assert num_qo_heads == 32, "num_qo_heads must be 32"
        assert num_kv_heads == 8, "num_kv_heads must be 8"
        assert head_dim == 128, "head_dim must be 128"

        len_indptr = qo_indptr.shape[0]
        num_segments = len_indptr - 1
        # Ensure qo_indptr[-1] == total_q
        assert qo_indptr[-1].item() == total_q, "qo_indptr[-1] must equal total_q"

        # Allocate outputs (compute in float32, convert later)
        output = torch.empty((total_q, num_qo_heads, head_dim), dtype=torch.float32, device=device)
        lse = torch.empty((total_q, num_qo_heads), dtype=torch.float32, device=device)

        # Launch Triton kernel: one program per segment
        grid = (num_segments,)
        LN2 = math.log(2.0)

        # Choose reasonable upper bounds for loops
        MAX_Q = 4096  # upper bound on queries per segment (sufficient for typical workloads)
        MAX_KV_TOKENS = num_pages  # upper bound on kv tokens

        atencao_triton[grid](
            q_f32, k_flat, v_flat,
            qo_indptr, kv_indptr, kv_indices,
            output, lse,
            total_q, num_qo_heads, head_dim,
            num_pages, num_kv_heads, 4,  # gqa_ratio
            sm_scale, LN2,
            MAX_Q=MAX_Q, MAX_KV_TOKENS=MAX_KV_TOKENS,
            num_warps=4, num_stages=2,
        )

        # Return results in original dtype and shapes
        output_bf16 = output.to(q.dtype)  # convert back to original q dtype (bfloat16 as in original)
        return output_bf16, lse

Analysis, reasoning, and plan

Understanding the original logic
- Inputs:
  - q: [total_q, 32, 128], 32 query heads, dim=128
  - k_cache, v_cache: originally [num_pages, 1, 8, 128], but squeezed to [num_pages, 8, 128]
  - qo_indptr, kv_indptr: int32 arrays of length len_indptr (number of segments), qo_indptr[-1] == total_q
  - kv_indices: int32 array mapping each segment to a subset of “pages” in k_cache/v_cache
  - sm_scale = 1 / sqrt(128)
- For each segment b (len_indptr - 1):
  - q_start = qo_indptr[b], q_end = qo_indptr[b+1]
  - kv_start = kv_indptr[b], kv_end = kv_indptr[b+1]
  - num_q_tokens_segment = q_end - q_start
  - num_kv_tokens = kv_end - kv_start
- For each query position q_idx in [q_start, q_end):
  - For each query head h in 0..31, with GQA mapping kv_head = h // 4
  - Build keys/values by reading kv_indices[kv_start:kv_end] and selecting k_cache/v_cache at those “page_ids” for kv_head
  - Compute logits = q[h] · k_list.T for these keys
  - Scale logits by sm_scale
  - Apply causal mask: max_kv_idx = min(q_idx + 1 + (num_kv_tokens - num_q_tokens_segment), num_kv_tokens); set logits beyond max_kv_idx to -inf
  - Compute LSE = logsumexp(logits_scaled) / ln(2)
  - attn = softmax(logits_scaled); zero masked entries
  - Output vector out_vec = attn · v_list
- Return output (same dtype as q in original code) and lse (float32), following the original unusual normalization.

Why Triton here
- The original code uses Python loops over segments and queries with per-token matmul and softmax. We can implement this in Triton:
  - Launch one program per segment (grid = len_indptr - 1).
  - Inside each program, loop over queries up to an upper bound (MAX_Q), masked by q_idx < (q_end - q_start).
  - For each query head h, loop over keys up to MAX_KV_TOKENS (>= num_kv_tokens) and mask kk < num_kv_tokens.
  - Accumulate logits via scalar loops over d in 0..127 and kk in 0..MAX_KV_TOKENS.
  - Compute LSE, softmax, and output vector out_vec via nested loops over d.
- Triton doesn’t support dynamic 2D arrays easily, so scalar nested accumulation is the right approach. This ensures all computation is inside the kernel.

Correctness details
- Important: The causal mask must use the segment-specific num_q_tokens_segment = q_end - q_start, not the global q_end. The correct delta is num_kv_tokens - num_q_tokens_segment, clamped at least 0. max_kv_idx = min(q_idx + 1 + delta, num_kv_tokens). This matches the original code’s masking logic.
- We convert q, k_cache, v_cache to float32 before launching the kernel. Outputs will be cast back to the original q dtype (bfloat16 in the original example). LSE is stored as float32.
- The Triton kernel atencao_triton is defined and actually invoked from ModelNew.forward; no decoy kernels are present.

Performance note
- This Triton implementation uses scalar nested loops. It’s not as fast as highly optimized attention, but it ensures Triton-only computation and correctness. Further vectorization or tiling could be added later if needed.

import math
import torch
import triton
import triton.language as tl


@triton.jit
def atencao_triton(
    q_ptr,           # *f32, [total_q, 32, 128]
    k_ptr,           # *f32, [num_pages, 8, 128]
    v_ptr,           # *f32, [num_pages, 8, 128]
    qo_indptr_ptr,   # *i32, [len_indptr]
    kv_indptr_ptr,   # *i32, [len_indptr]
    kv_indices_ptr,  # *i32, [num_kv_indices]
    out_ptr,         # *f32, [total_q, 32, 128]
    lse_ptr,         # *f32, [total_q, 32]
    total_q,         # i32
    num_qo_heads,    # i32 (32)
    head_dim,        # i32 (128)
    num_pages,       # i32
    num_kv_heads,    # i32 (8)
    gqa_ratio,       # i32 (4)
    sm_scale,        # f32
    LN2,             # f32 = log(2)
    MAX_Q: tl.constexpr,             # upper bound on queries per segment
    MAX_KV_TOKENS: tl.constexpr,     # upper bound on kv tokens (>= num_pages)
):
    # One program processes one segment (b)
    b = tl.program_id(axis=0)

    # Load segment bounds
    q_start = tl.load(qo_indptr_ptr + b)         # i32
    q_end = tl.load(qo_indptr_ptr + b + 1)       # i32
    kv_start = tl.load(kv_indptr_ptr + b)        # i32
    kv_end = tl.load(kv_indptr_ptr + b + 1)      # i32

    # Number of valid keys for this segment
    num_kv_tokens = kv_end - kv_start            # i32

    # For each query index within this segment
    for q_idx in range(MAX_Q):
        if q_idx >= (q_end - q_start):
            break
        global_q_idx = q_start + q_idx           # i32

        # Loop over query heads
        for h in range(num_qo_heads):
            kv_head = h // gqa_ratio             # 0..7

            # Compute logits vector for all keys in this segment
            logits = tl.zeros((MAX_KV_TOKENS,), dtype=tl.float32)
            for d in range(head_dim):
                # Load q component for this head
                q_off = global_q_idx * (num_qo_heads * head_dim) + h * head_dim
                q_val = tl.load(q_ptr + q_off + d)  # scalar
                # Accumulate logits[kk] += q_val * k_ptr[kk, kv_head, d]
                for kk in range(MAX_KV_TOKENS):
                    valid_k = kk < num_kv_tokens
                    kv_idx = kv_start + kk
                    idx = tl.load(kv_indices_ptr + kv_idx)  # int32
                    k_off = idx * (num_kv_heads * head_dim) + kv_head * head_dim + d
                    k_val = tl.load(k_ptr + k_off, mask=valid_k, other=0.0)  # scalar
                    logits[kk] += q_val * k_val

            # Scale logits by sm_scale
            logits_scaled = logits * sm_scale

            # Apply causal mask: max_kv_idx = min(q_idx + 1 + (num_kv_tokens - (q_end - q_start)), num_kv_tokens)
            num_q_tokens_segment = q_end - q_start
            delta = num_kv_tokens - num_q_tokens_segment
            delta = tl.maximum(delta, 0)
            max_kv_idx = tl.minimum(q_idx + 1 + delta, num_kv_tokens)
            # Mask logits: set to -inf beyond max_kv_idx
            for kk in range(MAX_KV_TOKENS):
                if kk >= max_kv_idx:
                    logits_scaled[kk] = -float("inf")

            # Compute LSE = logsumexp(logits_scaled) / LN2
            sum_exp = 0.0
            for kk in range(MAX_KV_TOKENS):
                sum_exp += tl.exp(logits_scaled[kk])
            lse = tl.log(sum_exp) / LN2
