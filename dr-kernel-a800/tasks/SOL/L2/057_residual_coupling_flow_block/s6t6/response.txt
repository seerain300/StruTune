Analysis and plan

Behavior to replicate:
- Input x has shape [B, C=192, T].
- Each of the 4 transforms applies 3 conv1d layers with kernel_size=5, padding=2:
  1) conv0: in_channels=96, out_channels=192
  2) conv1: in_channels=192, out_channels=192
  3) conv2: in_channels=192, out_channels=96
- Output time lengths:
  - conv0: T0_out = T - 1
  - conv1: T1_out = (T - 1) - 1 = T - 2
  - conv2: T2_out = (T - 2) - 1 = T - 3
- After each conv + bias, ReLU is applied. Then the transform output (second half of channels) is multiplied by the mask x_mask (shape [B, 1, T], broadcast over channels).
- Forward coupling: x1 = x1 + h; Reverse: x1 = x1 - h. Then concatenate x0 and x1.
- In this submission, I will implement only forward (4 transforms), as required by the provided evaluation.

Key changes:
- Implement Triton conv1d for K=5, padding=2, valid conv. For each (b, output channel, time tile), loop over input channels and kernel taps, masked load for padding, accumulate into acc.
- Implement Triton kernels for:
  - add_bias
  - relu
  - mul_mask (elementwise multiply with x_mask, broadcasting across channels)
  - add_or_sub (either add or subtract the transform output h to/from x1)
  - copy_to (copy two halves into final output along channel dimension)
- Ensure all Triton kernels are launched from forward. No torch.conv1d or torch elementwise ops are used in forward.

Shape handling and correctness:
- For each transform, we:
  - Run conv0 → ReLU → add_bias → mul_mask to produce h0. Then split x into x0 (first 96 channels) and x1 (second 96 channels). We won’t modify x1 yet; we’ll perform coupling after all 4 transforms. The output from each transform is only used for coupling at the end.
  - After all transforms, we compute x1_coupled = x1 + sum_i h_i (since forward is x1 = x1 + transform(x0)). Then concatenate x0 and x1_coupled, and finally multiply by x_mask. We perform concatenation via Triton copy kernels.

Performance notes:
- The heavy work is conv; Triton conv is simple and effective for K=5. We tile over time with BLOCK_T=128, which gives good occupancy across typical T sizes.
- ReLU and mask kernels are lightweight but essential, and they are launched.
- While not necessarily faster than PyTorch’s conv for large K, the requirement is to use Triton and ensure correctness and kernel launches. We can tune BLOCK_T if needed, but 128 is a safe default.

import torch

@triton.jit
def conv1d_k5_p2(x_ptr, w_ptr, bias_ptr, y_ptr,
                 B: tl.constexpr, Cin: tl.constexpr, Cout: tl.constexpr,
                 T_in, T_out,
                 x_bs, x_cs, x_ts,
                 w_os, w_cs, w_ks,
                 y_bs, y_cs, y_ts):
    # grid: (B * Cout, ceil_div(T_out, 128))
    pid0 = tl.program_id(0)  # over B * Cout
    pid1 = tl.program_id(1)  # over time tiles
    b = pid0 // Cout
    co = pid0 % Cout
    t_offsets = pid1 * 128 + tl.arange(0, 128)
    t_mask = t_offsets < T_out

    acc = tl.zeros([128], dtype=tl.float32)

    # For each input channel and each kernel tap k in [0..4], accumulate
    for ci in range(Cin):
        # acc += sum over k of x[b, ci, t_out - 2 + k] * w[co, ci, k]
        for k in range(5):
            t_src = t_offsets - 2 + k  # padding=2 means shift by -2
            t_src_mask = (t_src >= 0) & (t_src < T_in) & t_mask
            x_off = b * x_bs + ci * x_cs + t_src * x_ts
            w_off = co * w_os + ci * w_cs + k * w_ks
            x_val = tl.load(x_ptr + x_off, mask=t_src_mask, other=0.0)
            w_val = tl.load(w_ptr + w_off)  # scalar
            acc += x_val * w_val

    # add bias
    b_val = tl.load(bias_ptr + co)
    acc = acc + b_val

    # store to output
    y_off = b * y_bs + co * y_cs + t_offsets * y_ts
    tl.store(y_ptr + y_off, acc, mask=t_mask)


@triton.jit
def add_bias(y_ptr, bias_ptr, B, C, T, y_bs, y_cs, y_ts):
    # grid: (B * C, ceil_div(T, 128))
    pid_bc = tl.program_id(0)
    pid_t = tl.program_id(1)

    c = pid_bc % C

    b_val = tl.load(bias_ptr + c)  # bias per output channel
    y_val = y_val + b_val
    tl.store(y_ptr + y_off, y_val, mask=t_mask)


@triton.jit
def relu_kernel(y_ptr, B, C, T, y_bs, y_cs, y_ts):
    # grid: (B * C, ceil_div(T, 128))
    pid_bc = tl.program_id(0)
    pid_t = tl.program_id(1)
    b = pid_bc // C
    c = pid_bc % C
    t_offsets = pid_t * 128 + tl.arange(0, 128)
    t_mask = t_offsets < T
    y_off = b * y_bs + c * y_cs + t_offsets * y_ts
    y_val = tl.load(y_ptr + y_off, mask=t_mask, other=0.0)
    y_val = tl.maximum(y_val, 0.0)
    tl.store(y_ptr + y_off, y_val, mask=t_mask)


@triton.jit
def mul_mask(y_ptr, mask_ptr, B, C, T, y_bs, y_cs, y_ts, mask_bs, mask_cs, mask_ts):
    # grid: (B * C, ceil_div(T, 128))
    pid_bc = tl.program_id(0)
    pid_t = tl.program_id(1)
    b = pid_bc // C
    c = pid_bc % C
    t_offsets = pid_t * 128 + tl.arange(0, 128)
    t_mask = t_offsets < T
    y_off = b * y_bs + c * y_cs + t_offsets * y_ts
    y_val = tl.load(y_ptr + y_off, mask=t_mask, other=0.0)
    # mask has shape [B, 1, T], so mask index c=0
    m_off = b * mask_bs + 0 * mask_cs + t_offsets * mask_ts
    m_val = tl.load(mask_ptr + m_off, mask=t_mask, other=1.0)
    y_val = y_val * m_val
    tl.store(y_ptr + y_off, y_val, mask=t_mask)


@triton.jit
def add_or_sub(y_ptr, addend_ptr, B, C, T, op_add: tl.constexpr, y_bs, y_cs, y_ts):
    # grid: (B * C, ceil_div(T, 128))

    pid_t = tl.program_id(1)
    b = pid_bc // C
    c = pid_bc % C
    t_offsets = pid_t * 128 + tl.arange(0, 128)

    add_val = tl.load(addend_ptr + add_off, mask=t_mask, other=0.0)
    if op_add:

    else:
        y_val = y_val - add_val
    tl.store(y_ptr + y_off, y_val, mask=t_mask)

    # grid: (B * C, ceil_div(T, 128))
    pid_bc = tl.program_id(0)

    t_offsets = pid_t * 128 + tl.arange(0, 128)

    dst_off = b * dst_bs + c * dst_cs + t_offsets * dst_ts
    src_off = b * src_bs + c * src_cs + t_offsets * src_ts
    val = tl.load(src_ptr + src_off, mask=t_mask, other=0.0)
    tl.store(dst_ptr + dst_off, val, mask=t_mask)

        expanded_mask = x_mask.expand(B, 192, T - 3).contiguous()
        grid_mask_final = (B * 192, triton.cdiv(T - 3, 128))
        mul_mask[grid_mask_final](
            output, expanded_mask, B, 192, T - 3, output.stride(0), output.stride(1), output.stride(2),
            expanded_mask.stride(0), expanded_mask.stride(1), expanded_mask.stride(2)
        )

        return output
