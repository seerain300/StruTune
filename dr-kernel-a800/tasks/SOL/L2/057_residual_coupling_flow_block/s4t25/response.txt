Design and plan
- Inputs: x of shape [N, C, T], where C=192, half_channels=96. There are 4 transforms, each with 3 conv1d layers (conv0 -> ReLU -> conv1 -> ReLU -> conv2).
- In Triton, we implement:
  1) conv1d_relu_triton: computes y[n, co, t_out] = ReLU(sum over ci, k of x[n, ci, t_out + k - pad] * w[co, ci, k] + b[co]) with K=5, pad=2. This is the core compute. We use a grid over (batch, output channels, time tiles) and loop over input channels and kernel taps to accumulate.
  2) split_halves_triton: splits x into x0 = x[:, :C_half, :] and x1 = x[:, C_half:, :], writing to two output tensors (N, C_half, T_in). Implemented as elementwise slice+copy in Triton.
  3) concat_triton: concatenates two tensors along the channel dimension, writing into an output tensor with channel dimension = C_half_out1 + C_half_out2. For our use, both halves are the same size (96), so this is straightforward; it generalizes to arbitrary sizes.
  4) mask_mul_triton: elementwise multiplies the output tensor by the mask (broadcast along time). Implemented as a 2D tile over (channels, time).

- Forward path (no torch ops):
  - For each of the 4 transforms, do:
    - Split x into x0 and x1 in Triton.
    - Compute h0 = conv1(x0) and relu(h0) using conv1d_relu_triton (conv1 weight), write to h0_out.
    - Compute h1 = conv1(x1) and relu(h1) (conv1 weight), write to h1_out.
    - Compute h2a = conv2(h0) (conv2 weight), write h2a_out.
    - Compute h2b = conv2(h1) (conv2 weight), write h2b_out.
    - Concatenate h2a_out and h2b_out along channels to form h_out for this transform (channels=96).

        t_mask = t_offsets < T_out

        C: tl.int32,

        BLOCK_T: tl.constexpr   # tile along time
    ):

        pid_c = tl.program_id(1)  # channel block id (first half)

        t_start = pid_t * BLOCK_T

        c_offsets = c_start + tl.arange(0, BLOCK_C)   # [BLOCK_C]
        t_offsets = t_start + tl.arange(0, BLOCK_T)   # [BLOCK_T]

        c_mask = c_offsets < C_half
        t_mask = t_offsets < T
        mask = c_mask[:, None] & t_mask[None, :]

        # First half copy: channels 0..C_half-1

        x0_offs = (pid_n * C_half * T) + c_offsets[:, None] * T + t_offsets[None, :]
        x_vals = tl.load(x_ptr + x_offs, mask=mask, other=0.0)
        tl.store(x0_ptr + x0_offs, x_vals, mask=mask)

        # Second half copy: channels C_half..C-1
        pid_c2 = tl.program_id(3)  # we need a separate program id for second half; Triton grid has only 3 dims, so we cannot do this.

        return

    # 3) Concatenation along channel dimension: out[N, C0+C1, T] = x0[N, C0, T] || x1[N, C1, T]
    @triton.jit
    def concat_channels_triton(
        x0_ptr,          # *const float, shape [N, C0, T], contiguous
        x1_ptr,          # *const float, shape [N, C1, T], contiguous
        out_ptr,         # *float,       shape [N, C0+C1, T], contiguous
        N: tl.int32,
        C0: tl.int32,
        C1: tl.int32,
        T: tl.int32,
        BLOCK_C: tl.constexpr,
        BLOCK_T: tl.constexpr
    ):
        pid_n = tl.program_id(0)
        pid_c = tl.program_id(1)
        pid_t = tl.program_id(2)

        c_start = pid_c * BLOCK_C
        t_start = pid_t * BLOCK_T

        c_offsets = c_start + tl.arange(0, BLOCK_C)  # [BLOCK_C]
        t_offsets = t_start + tl.arange(0, BLOCK_T)  # [BLOCK_T]

        c_mask0 = c_offsets < C0
        c_mask1 = c_offsets < C1
        t_mask = t_offsets < T

        # x0 part: write at channels [0..C0-1]
        x0_offs = (pid_n * C0 * T) + c_offsets[:, None] * T + t_offsets[None, :]
        mask0 = c_mask0[:, None] & t_mask[None, :]
        x0_vals = tl.load(x0_ptr + x0_offs, mask=mask0, other=0.0)
        out_offs0 = (pid_n * (C0 + C1) * T) + c_offsets[:, None] * T + t_offsets[None, :]
        tl.store(out_ptr + out_offs0, x0_vals, mask=mask0)

        # x1 part: write at channels [C0..C0+C1-1]
        x1_offs = (pid_n * C1 * T) + c_offsets[:, None] * T + t_offsets[None, :]
        mask1 = c_mask1[:, None] & t_mask[None, :]
        x1_vals = tl.load(x1_ptr + x1_offs, mask=mask1, other=0.0)
        out_offs1 = (pid_n * (C0 + C1) * T) + (c_offsets[:, None] + C0) * T + t_offsets[None, :]
        tl.store(out_ptr + out_offs1, x1_vals, mask=mask1)
