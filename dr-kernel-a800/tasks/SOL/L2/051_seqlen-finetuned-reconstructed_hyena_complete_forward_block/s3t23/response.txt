  - Triton kernels assumed a simple contiguous indexing scheme or used masked loads incorrectly, leading to out-of-bounds or partial writes/reads.
  - Not launching Triton kernels (decoy kernels) would be invalid; the evaluation requires that Triton kernels are invoked. We must ensure layernorm_3d_affine and linear_3d_constK are both defined and launched in ModelNew.forward.
  - To minimize indexing complexity and mismatches, we use block-pointer-based Triton kernels with explicit strides. Block pointers ensure correct tiling and boundary checks via masks, and reduce the risk of incorrect pointer arithmetic.

Plan
- Implement two Triton kernels using tl.make_block_ptr:
  1) layernorm_3d_affine: LayerNorm over the last dimension D for each (b, l) row of a 3D tensor [B, L, D], with affine weight and bias. Grid is (B, L). Each program:
     - Uses a block pointer to read the entire row across D, compute sum and sum of squares, then mean and variance.
     - Normalizes and applies affine, writing results via a block pointer to Y.
     - Assumes X and Y are contiguous along the last dimension. We call .contiguous() on inputs and outputs before launching.
  2) linear_3d_constK: Computes y[b, l, o] = sum_d x[b, l, d] * w[o, d] + bias[o] for x[B, L, D], w[K, D], y[B, L, K]. Grid is (B, L, K). Each program:
     - Uses a block pointer over the output vector for that (b, l, o), and iterates over D in tiles using block pointers to read X and W. Accumulates into y and stores.
     - Operates in float32; we pass tensors as float32.

- In ModelNew.forward:
  - Use get_inputs to produce tensors, cast to float32.
  - Ensure hidden_states is contiguous and launch layernorm_3d_affine on it with norm1_weight and norm1_bias (first residual + LayerNorm).
  - Launch linear_3d_constK for:
    - In-projection: in_proj_weight [inner_width, D], in_proj_bias [inner_width]
    - Out-projection: out_proj_weight [D, D], out_proj_bias [D]
    - MLP layers: mlp_fc1_weight [D, D], mlp_fc1_bias [D], then mlp_fc2_weight [D, D], mlp_fc2_bias [D]
  - Return the final output. All tensor math stays in Triton; no torch ops on tensors in forward.

This ensures Triton kernels are invoked, correctness is prioritized via block-pointer masked loads/stores, and shapes are handled explicitly with strides. We avoid any torch operations on tensors in forward, except for allocations and launches.

import math
import torch
import triton
import triton.language as tl


@triton.jit
def layernorm_3d_affine_block(X, Y, W, BIAS, EPS,
                               B, L, D,
                               BLOCK_D: tl.constexpr):
    """
    LayerNorm over last dimension for 3D tensor [B, L, D], with affine weight and bias.
    Grid: (B, L). Each program handles one (b, l) row across D.
    Assumes X, Y are laid out as [B, L, D] and contiguous along the last dim.
    """
    b = tl.program_id(0)
    l = tl.program_id(1)

    # Base offset for this (b, l) row
    base = b * L * D + l * D

    # Use block pointer to read the entire row across D
    x_ptr = tl.make_block_ptr(X, (L, D), (1, 0), (l, 0), (1, 1), (BLOCK_D, 1), 0)
    # Load X[b, l, :] and compute sum and sum of squares
    x = tl.load(x_ptr, boundary_check=(1))
    x_f32 = x.to(tl.float32)
    sum_x = tl.sum(x_f32, axis=0)
    sum_x2 = tl.sum(x_f32 * x_f32, axis=0)

    D_f = tl.float32(D)
    mean = sum_x / D_f
    var = sum_x2 / D_f - mean * mean
    inv_std = 1.0 / tl.sqrt(var + EPS)

    # Affine parameters
    w_ptr = tl.make_block_ptr(W, (D,), (0,), (0,), (1,), (BLOCK_D,), 0)
    b_ptr = tl.make_block_ptr(BIAS, (D,), (0,), (0,), (1,), (BLOCK_D,), 0)
    w = tl.load(w_ptr, boundary_check=(1)).to(tl.float32)
    bias = tl.load(b_ptr, boundary_check=(1)).to(tl.float32)

    # Write normalized + affine result to Y
    y_ptr = tl.make_block_ptr(Y, (L, D), (1, 0), (l, 0), (1, 1), (BLOCK_D, 1), 0)
    y = (x_f32 - mean) * inv_std
    y = y * w + bias  # broadcast over D
    tl.store(y_ptr, y, boundary_check=(1))


@triton.jit
def linear_3d_constK_block(X, W, BIAS, Y,
                            B, L, D, K,
                            BLOCK_D: tl.constexpr):
    """
    y[b, l, o] = sum_d x[b, l, d] * w[o, d] + bias[o]
    Grid: (B, L, K). Each program computes one output channel o for a given (b, l).
    Assumes X: [B, L, D], W: [K, D], Y: [B, L, K], all contiguous along last dim.
    """
    b = tl.program_id(0)
    l = tl.program_id(1)
    o = tl.program_id(2)

    base_x = b * L * D + l * D
    base_w = o * D  # W is [K, D], contiguous along D

    # Accumulator
    acc = 0.0

    # Iterate over D in tiles
    for d0 in range(0, D, BLOCK_D):
        d = d0 + tl.arange(0, BLOCK_D)
        mask = d < D

        x_ptr = tl.make_block_ptr(X, (L, D), (1, 0), (l, d0), (1, 1), (BLOCK_D, 1), 0)
        w_ptr = tl.make_block_ptr(W, (D,), (0,), (d0,), (1,), (BLOCK_D,), 0)

        x = tl.load(x_ptr, boundary_check=(1))
        w = tl.load(w_ptr, boundary_check=(1))
        x = x.to(tl.float32)
        w = w.to(tl.float32)

        # Masked multiply-accumulate: masked elements contribute 0
        prod = x * w
        acc += tl.sum(prod, axis=0)

    # Add bias[o]
    bias_val = tl.load(BIAS + o)
    acc = acc + bias_val.to(tl.float32)

    # Store result
    y_ptr = tl.make_block_ptr(Y, (L, K), (1, 0), (l, o), (1, 1), (1, 1), 0)
    tl.store(y_ptr, acc, boundary_check=(0))
