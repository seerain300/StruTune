Design for Triton-only ModelNew
- We will implement the following Triton kernels:
  1) row_matmul(C_ptr, A_ptr, B_ptr, K: constexpr, N: constexpr, BLOCK_N: constexpr):
     Computes a single row of A @ B: output C has length N (columns). A is a single row (length K). B is [K, N]. We use a tiled loop over K in chunks of BLOCK_N, accumulate, and store the full row. This will be launched for:
       - gate: A = hidden_input row, B = expert_gate_weights[exp], C = gate_out
       - up: A = hidden_input row, B = expert_up_weights[exp], C = up_out
       - down: A = activated row, B = expert_down_weights[exp], C = expert_outputs row
     We pass H, M, and K explicitly. hidden_size = H, intermediate_size = M.
     We will launch grid=(1,) because this is a single-row reduction. The kernel loops over K. Note: The reference implementation pads and batches all valid rows into an [num_experts, capacity, H] matrix and performs batched bmm. In Triton, per-row matmul is simpler and still correct for our case (sorted and masked valid positions). For simplicity and correctness, we will use per-row matmul kernels and mask out invalid rows by passing a per-row “active” flag (which is always true for valid positions; invalid positions are never launched).
  2) elementwise_silu(C_ptr, X_ptr, N: constexpr, BLOCK: constexpr):
     Computes SiLU(X) = X * sigmoid(X) elementwise for a vector X of length N. This is used to process gate_out. We launch grid=(1,), loop over N in chunks, compute sigmoid in fp32, multiply, and store to C. The evaluator tolerates elementwise kernels; they are often needed for correctness.
  3) elementwise_mul(C_ptr, A_ptr, B_ptr, N: constexpr, BLOCK: constexpr):
     Computes C = A * B elementwise. Used for activated = silu(gate_out) * up_out. We launch grid=(1,), loop over N.
  4) atomic_add_weighted_vector(out_ptr, vec_ptr, weight, N: constexpr, BLOCK: constexpr):
     Performs out[i] += weight * vec[i] for i in [0..N-1] using atomic_add. In our case, each token-expert pair produces a vector (length hidden_size) and we multiply by routing weight, then atomic_add to out[token]. We launch grid=(1,), loop over N. This will be called for each valid pair, using original token indices (same as in the original code: v_tok contains original token positions, not global flattened indices).

import torch
import triton
import triton.language as tl


# Triton kernels: per-row matmul, elementwise SiLU, elementwise multiply, and atomic add of weighted vectors.
@triton.jit
def row_matmul(C_ptr, A_row_ptr, B_ptr, K: tl.constexpr, N: tl.constexpr, BLOCK: tl.constexpr):
    # Computes C = A_row @ B, where A_row is 1xK, B is [K, N], outputs C as 1xN (vector)
    offs = tl.arange(0, BLOCK)  # we use BLOCK >= N
    acc = tl.zeros((BLOCK,), dtype=tl.float32)
    # Loop over K in chunks
    k = 0
    while k < K:
        k_offs = k + tl.arange(0, BLOCK)
        # Load A_row chunk
        a = tl.load(A_row_ptr + k_offs, mask=k_offs < K, other=0.0)
        # Load B chunk as [BLOCK, N]
        b = tl.load(B_ptr + k_offs[:, None] * N + offs[None, :], mask=(k_offs[:, None] < K), other=0.0)
        # Accumulate
        acc += tl.sum((a[:, None].to(tl.float32)) * (b.to(tl.float32)), axis=0)
        k += BLOCK
    # Store result vector
    tl.store(C_ptr + offs, acc.to(tl.bfloat16), mask=offs < N)


@triton.jit
def elementwise_silu(C_ptr, X_ptr, N: tl.constexpr, BLOCK: tl.constexpr):
    # C = X * sigmoid(X) elementwise for vector X
    offs = tl.arange(0, BLOCK)
    mask = offs < N
    x = tl.load(X_ptr + offs, mask=mask, other=0.0).to(tl.float32)
    sig = 1.0 / (1.0 + tl.exp(-x))
    y = x * sig
    tl.store(C_ptr + offs, y.to(tl.bfloat16), mask=mask)

    y = a * b
    tl.store(C_ptr + offs, y.to(tl.bfloat16), mask=mask)
