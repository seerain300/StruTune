为了通过评测并消除歧义，我将提供一个明确的 ModelNew.forward，它定义并 launch 三个 Triton kernel：
1) compute_mean_var_w_kernel: 用于计算 x_dwconv (B, C, H, W) 的每行 (B, C, H) 的均值和方差，沿着宽度 W 进行 reduction。这是模仿原始 forward 中的 LayerNorm 前的步骤：x_nhwc = x_dwconv.permute(0, 2, 3, 1) 并计算 mean/var over last dim (W) for each row.

2) linear_matmul_kernel: 实现 x_expanded = x_ln @ pwconv1_weight.T. 我们把 x_ln.view(-1) 作为 A (M=B*C*H*W), pwconv1_weight.T.view(K, N) 作为 B (K=C, N=C4), 输出 C(M,) 然后 reshape 到 (B, C, H, W). 由于 B*C*H*W 通常是很大的，为了可靠性我用 grid=(M,)，每个 program 处理一个 m，并在内核中简单循环 K=C 来计算 C[m]. 这样可以避免复杂的 2D tiling 和 stride 逻辑，降低出错概率。

3) elementwise_gelu_tanh_kernel: 用于应用 GELU (tanh approximation) 到 x_expanded, 生成 x_gelu. 这是一个简单的逐元素 kernel.

我将确保：
- 所有 tensors 传入 forward 时都是 float32 类型，并且 contiguous. Triton kernels 将使用明确的 offsets 和 masks 来防止越界.
- forward 不会执行任何 torch computation; 只进行 allocations 和 kernel launches.
- 每个 kernel 都被调用.

为了最小化风险并防止之前的 crash：
- compute_mean_var_w_kernel 使用 grid=(B*C*H,)，每个 program 计算一行 (b, c, h) 的 sum 和 sum of squares over W, 用 masks 来限制 idx < W.
- linear_matmul_kernel 使用 grid=(M,)，每个 program 计算一个 m 项 C[m]，循环 k from 0 to C-1, loads A[m] and B[k, n] across N tiles, accumulates. Because C is small (128), this is fine.
- elementwise_gelu_tanh_kernel 使用 grid=(M,) for 1D inputs or grid=(B, C, H, W) for 4D, whichever you prefer. I’ll use 1D for simplicity, assuming inputs are flattened 1D.

import torch

import triton.language as tl


# -------- Triton kernels --------

@triton.jit
def compute_mean_var_w_kernel(
    X_ptr,             # *const float32, input tensor (B, C, H, W) flattened as 1D
    mean_out_ptr,      # *float32, output means (B*C*H,)
    var_out_ptr,       # *float32, output vars (B*C*H,)
    B: tl.int32,       # batch size
    C: tl.int32,       # channels
    H: tl.int32,       # height
    W: tl.int32,       # width
    M: tl.int32,       # total number of rows = B*C*H
    BLOCK_W: tl.constexpr,  # tile along width for reduction
):
    row_id = tl.program_id(axis=0)  # 0..(B*C*H - 1)
    # Compute (b, c, h) for this row
    # b = row_id // (C*H), rem = row_id % (C*H); c = rem // H; h = rem % H
    b = row_id // (C * H)
    rem = row_id - b * (C * H)
    c = rem // H
    h = rem - c * H  # rem % H

    # Accumulate sum and sum of squares over W
    sum_val = 0.0
    sumsq_val = 0.0
    # Loop over width in chunks
    for w_start in range(0, W, BLOCK_W):
        w_idx = w_start + tl.arange(0, BLOCK_W)
        mask = w_idx < W
        # offset = ((b*C + c)*H + h)*W + w_idx
        offset = ((b * C + c) * H + h) * W + w_idx
        vals = tl.load(X_ptr + offset, mask=mask, other=0.0)
        vals = vals.to(tl.float32)
        # reduce this chunk
        sum_val += tl.sum(vals, axis=0)
        sumsq_val += tl.sum(vals * vals, axis=0)

    mean = sum_val / W
    var = sumsq_val / W - mean * mean  # biased variance
    # Store results
    tl.store(mean_out_ptr + row_id, mean)
    tl.store(var_out_ptr + row_id, var)

@triton.jit
def elementwise_gelu_tanh_kernel(
    X_ptr,             # *const float32, input flattened 1D
    Y_ptr,             # *float32, output flattened 1D
    M: tl.int32,       # length
    BLOCK: tl.constexpr,
):
    pid = tl.program_id(axis=0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < M
    x = tl.load(X_ptr + offs, mask=mask, other=0.0)
    # GELU tanh approximation
    c = 0.7978845608028654  # sqrt(2/pi)
    x3 = x * x * x
    inner = c * (x + 0.044715 * x3)
    y = 0.5 * x * (1.0 + tl.tanh(inner))
    tl.store(Y_ptr + offs, y, mask=mask)
