Design and plan
- We must compute the entire pipeline in Triton:
  1) Depthwise Conv2d with groups=C: y[b, c, oh, ow] = sum_{kh,kw} x[b, c, oh+kh-3, ow+kw-3] * w[c, 0, kh, kw], with padding=3.
     - Triton kernel: one program per output element (b, c, oh, ow). Explicit stride-based addressing and proper masks for padding. Accumulate in float32.
  2) Permute from NCHW to NHWC: x_nhwc[b, h, w, c] = x_dwconv[b, c, h, w]
     - Triton kernel: one program per destination element, computes source indices and copies value.
  3) LayerNorm across last dim (C) per (b, h, w): compute mean and var over C for each (b, h, w), then x_ln = (x_nhwc - mean) / sqrt(var + eps) * layernorm_weight
     - Two Triton kernels:
       - Reduction kernel: per (b, h, w), loop over C to accumulate sum and sum of squares. Store sums in separate buffers.
       - Normalization kernel: per (b, h, w), loop over C to compute mean, var, normalize, scale with layernorm_weight, and store.
  4) Linear projection (GEMV) to 4C: x_expanded = x_ln @ pwconv1_weight.T, i.e., for each (b, c_out), x_expanded[b, c_out] = sum_{c_in} x_ln[b, c_in] * pwconv1_weight[c_out, c_in]
     - Triton kernel: one program per (b, c_out). Loop over C_in (128) and accumulate dot product. Store result.
  5) GELU (tanh approximation) elementwise: y = 0.5 * x * (1 + tanh(sqrt(2/pi)*(x + 0.044715*x^3)))
     - Triton elementwise kernel: one program per output element in x_expanded. Compute GELU and store to new tensor.
  6) GRN:
     - Compute global_features per (b, c_out) as L2 norm over spatial dims H and W: global_features[b, c_out] = sqrt(sum_{h,w} x_gelu[b, c_out, h, w]^2)
       - Triton reduction kernel: per (b, c_out), loop over H*W and accumulate sum of squares.
     - Compute gf_mean per (b): mean of global_features over c_out
       - Triton reduction kernel: per b, loop over 4C to compute sum and divide by 4C.
     - Compute norm_features = global_features / (gf_mean + eps), then update x_gelu = x_gelu + x_gelu * norm_features (broadcast along spatial)
       - Triton elementwise kernel: per (b, c_out, h, w), read x_gelu, compute scale = norm_features[b, c_out], update value.

Important notes
- All kernels are launched from ModelNew.forward. No torch compute in host code.
- Tensors are made contiguous before kernel launches to simplify stride usage; explicit strides are used in address computations.

@triton.jit
def depthwise_conv2d_groupsC_per_output_kernel(
    x_ptr, w_ptr, y_ptr,
    B, C, H, W, H_out, W_out,
    pad_h, pad_w,
    stride_xB, stride_xC, stride_xH, stride_xW,
    stride_wC, stride_wKH, stride_wKW,
    stride_yB, stride_yC, stride_yH, stride_yW,
):
    # One program per output element: y[b, c, oh, ow]
    b = tl.program_id(0)
    c = tl.program_id(1)
    oh = tl.program_id(2)
    ow = tl.program_id(3)

    # Accumulator in float32
    acc = tl.zeros((), dtype=tl.float32)

    # Loop over 7x7 kernel
    for kh in range(7):
        for kw in range(7):
            ih = oh + kh - pad_h
            iw = ow + kw - pad_w
            in_bounds = (ih >= 0) & (ih < H) & (iw >= 0) & (iw < W)
            # Load input with mask; if out-of-bounds, use 0
            x_val = tl.load(x_ptr + b * stride_xB + c * stride_xC + ih * stride_xH + iw * stride_xW, mask=in_bounds, other=0.0)
            # Load per-channel weight (no bias)
            w_val = tl.load(w_ptr + c * stride_wC + 0 * stride_wKH + kh * stride_wKW)
            # Accumulate
            acc += x_val * w_val

    # Store result
    tl.store(y_ptr + b * stride_yB + c * stride_yC + oh * stride_yH + ow * stride_yW, acc)

@triton.jit
def layer_norm_normalize_kernel(
    x_ptr, lnw_ptr, y_ptr,
    sum_ptr, sumsq_ptr,
    B, C, H, W, Cdim,

    stride_yB, stride_yC, stride_yH, stride_yW,
    eps,
):

    b = tl.program_id(0)
    h = tl.program_id(1)
    w = tl.program_id(2)

    idx = b * H * W + h * W + w
    total_sum = tl.load(sum_ptr + idx)
    total_sumsq = tl.load(sumsq_ptr + idx)

@triton.jit
def gelu_tanh_elementwise_kernel(
    x_ptr, y_ptr,
    N,                      # number of elements
    stride_x, stride_y,
):
    idx = tl.program_id(0)
    val = tl.load(x_ptr + idx * stride_x)
    sqrt_2_over_pi = 0.7978845608028654
    inner = sqrt_2_over_pi * (val + 0.044715 * val * val * val)
    tanh_val = tl.tanh(inner)
    y_val = 0.5 * val * (1.0 + tanh_val)
    tl.store(y_ptr + idx * stride_y, y_val)
