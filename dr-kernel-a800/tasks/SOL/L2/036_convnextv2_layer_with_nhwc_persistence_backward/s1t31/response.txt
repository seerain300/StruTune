Final analysis and plan

The original forward performs a specific pipeline on provided inputs:
- residual: (B, C, H, W) is given by get_inputs, not to be generated by ModelNew (we avoid any torch.randn/torch.ones in forward).
- Depthwise conv2d: x_dwconv = F.conv2d(residual, dwconv_weight, padding=3, groups=C) producing (B, C, H_out, W_out) with H_out = H + 2*pad, W_out = W + 2*pad.
- Permute to NHWC: x_nhwc = x_dwconv.permute(0, 2, 3, 1) -> (B, H_out, W_out, C).
- LayerNorm across channels C at each (b, h, w):
  - mean = x_nhwc.mean(dim=-1, keepdim=True) -> per (b,h,w) mean over C
  - var = ((x_nhwc - mean) ** 2).mean(dim=-1, keepdim=True) -> per (b,h,w) var over C
  - x_normalized = (x_nhwc - mean) / sqrt(var + eps)
  - x_ln = x_normalized * layernorm_weight (layernorm_weight per channel C).
- Linear projection: x_expanded = x_ln @ pwconv1_weight.T, where x_ln reshaped as (M=B*H_out*W_out, K=C), pwconv1_weight (C4, C) -> output (M, C4).
- GELU (tanh approximation): gelu(x) = 0.5 * x * (1 + tanh(sqrt(2/pi) * (x + 0.044715 * x^3))).
- Global Response Norm (GRN): per (b,h,w) across channels C4
  - global_features = L2 norm over channels of x_gelu: sqrt(sum_c x_gelu^2)
  - gf_mean = global_features.mean over channels -> (B,H,W,1)
  - norm_features = global_features / (gf_mean + eps)
  - x_grn = grn_weight * (x_gelu * norm_features) + x_gelu, where grn_weight has shape (1,1,1,C4) and is broadcast.

TRITON-ONLY requirements:
- ModelNew.forward must not invoke any torch operations (no torch.randn, torch.ones, torch.mean, torch.rsqrt, etc.). It must only allocate tensors and launch Triton kernels.
- Implement:
  - conv2d depthwise (groups=C, 1x7x7, padding=3) forward in Triton.
  - LayerNorm mean/var per (b,h,w) across channels C in Triton (two kernels).
  - Batched matmul (M=B*H_out*W_out, K=C) @ (K, N=C4) in Triton to produce x_expanded.
  - GELU elementwise in Triton.
  - GRN elementwise combining in Triton.

Design details:
- conv2d depthwise forward Triton:
  - Grid: (B*C, H_out, W_out). Each program computes one output element (b, c, oh, ow).
  - Loop over 7x7 filter, compute input indices ih = oh - pad + kh, iw = ow - pad + kw, load with mask, multiply by per-channel weight[c, 0, kh, kw], accumulate, store.
- LayerNorm mean Triton:
  - Grid: (B, H_out, W_out). For each (b,h,w), loop over channels C in blocks, load NHWC row, compute mean, store (mean_ptr[b,h,w,0]).
- LayerNorm var Triton:
  - Same grid, load mean, loop over channels C in blocks, compute sum((x - mean)^2), divide by C, store var.
- Batched matmul Triton:
  - Inputs: X (B*H_out*W_out, C), W (C4, C). Output Y (B*H_out*W_out, C4, 1). We implement a tiled matmul over K=C, with BLOCK_M, BLOCK_N, BLOCK_K. The output pointer uses an extra stride for the trailing 1 dimension (we can pass Y_stride_l=1 and treat Y as (M, N) but keep 3D pointer).
  - This replaces torch.nn.functional.linear; no torch ops.
- GELU Triton:
  - Elementwise kernel over vector of length N; use tanh approximation.
- GRN Triton:
  - Compute global_features per (b,h,w) across channels C4: sum of squares, sqrt. Compute gf_mean = global_features / C4. Compute norm_features = global_features / (gf_mean + eps). Then compute x_grn for all channels C4: x_grn = grn_weight * (x_gelu * norm_features) + x_gelu. This is broadcast over channels, done in two loops (first to compute norm_features, then to write x_grn).

Correctness fixes:
- Avoid any host-side torch computations; everything is Triton.
- Ensure proper strides and indexing for NCHW/NHWC and matmul (K is channels C).
- Use masks in loads/stores for out-of-bounds padding.
- Keep eps and constants as Python floats passed to kernels.

Performance considerations:
- conv2d depthwise is small per output element (7x7 multiply-adds).
- Batched matmul with K=C=128, M=B*H_out*W_out, N=C4=512 is moderate. Using BLOCK_K=32, BLOCK_M=64, BLOCK_N=64 gives good utilization; grid = (ceil_div(M, BM), ceil_div(N, BN)).
- GELU and GRN are simple elementwise ops; single-pass kernels over flattened tensors.

# 1) Triton: conv2d depthwise forward (groups=C), 1x7x7, padding=3, NCHW input/output
@triton.jit
def conv2d_depthwise_forward_triton(
    input_ptr,       # *float32, (B, C, H, W)
    weight_ptr,      # *float32, (C, 1, 7, 7)
    output_ptr,      # *float32, (B, C, H_out, W_out)
    B, C, H, W, H_out, W_out,
    input_stride_b, input_stride_c, input_stride_h, input_stride_w,
    weight_stride_c, weight_stride_kh, weight_stride_kw,
    output_stride_b, output_stride_c, output_stride_h, output_stride_w,
):
    b = tl.program_id(0)
    c_out = tl.program_id(1)
    oh = tl.program_id(2)
    ow = tl.program_id(3)

    acc = tl.zeros((), dtype=tl.float32)

    # 1x7x7 depthwise conv: loop over 7x7
    for kh in range(7):
        for kw in range(7):
            ih = oh - 3 + kh
            iw = ow - 3 + kw
            in_bounds = (ih >= 0) & (ih < H) & (iw >= 0) & (iw < W)
            in_off = b * input_stride_b + c_out * input_stride_c + ih * input_stride_h + iw * input_stride_w
            x = tl.load(input_ptr + in_off, mask=in_bounds, other=0.0)
            w_off = c_out * weight_stride_c + kh * weight_stride_kh + kw * weight_stride_kw
            w = tl.load(weight_ptr + w_off)
            acc += x * w

    out_off = b * output_stride_b + c_out * output_stride_c + oh * output_stride_h + ow * output_stride_w
    tl.store(output_ptr + out_off, acc)

@triton.jit
def batched_matmul_triton(

    M, N, K,
    X_stride_m, X_stride_k,
    W_stride_k, W_stride_n,
