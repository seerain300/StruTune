Analysis, diagnosis, and optimization plan

- Original behavior:
  - Inputs: encoder_hidden_states [B, T, H], hidden_states [B, I, H], process_weight [H, H] (no bias).
  - Concatenate along sequence: A_cat = cat([encoder, hidden], dim=1) -> [B, L, H], L = T + I.
  - Linear projection: processed = A_cat @ process_weight.T -> [B, L, H].
  - Split: processed_encoder = processed[:, :T, :], processed_hidden = processed[:, T:, :].

- Previous results:
  - We achieved 14/16 correct runs, with two “INCORRECT_NUMERICAL” failures. This suggests the heavy matmul produces slightly different results for a couple of configurations (likely due to FP32 vs FP16 behavior, or subtle masking issues). One other submission had “INCORRECT_SHAPE,” which we will address.

- Root cause hypotheses and fixes:
  1) Numerical mismatch:
     - PyTorch’s torch.matmul uses highly tuned kernels and may cast to FP32 internally for performance (especially if inputs are FP16). Our Triton GEMM accumulates in FP32 and stores back to FP16, which can produce small differences. Evaluators sometimes enforce strict equality on FP16 outputs. To reduce deviation:
       - Accumulate in FP32 but try to mimic PyTorch’s behavior by controlling dtype at the host side. Ensuring inputs to the kernel are consistent and not unexpectedly upcast can help. We will keep the kernel strict and improve tile sizes and masking.
       - Add Triton autotune configs with a range of BLOCK_M/BLOCK_N/BLOCK_K, num_warps, num_stages to better match various shapes, improving performance while maintaining correctness.
  2) Shape mismatches:
     - Ensure all allocations and kernels strictly produce [B, L, H], and the split returns [B, T, H] and [B, I, H]. We will double-check stride usage and avoid any host-side torch operations on the output beyond split.

- Implementation plan:
  - Triton kernel for concatenation:
    - Allocate out_cat [B, L, H] contiguous. 3D grid over (B, L, H). For each (b, m, k): if m < T, load encoder[b, m, k]; else load hidden[b, m - T, k]; store to out_cat[b, m, k].
    - This is simple and robust; avoids tricky batched indexing.
  - Triton batched GEMM for linear projection:
    - Inputs: A_cat [B, L, H], W_T [H, H].
    - Output: C [B, L, H].
    - 3D grid over (B, sequence tiles M, output tiles N). Iterate K in blocks (BLOCK_K).
    - Use masks to guard out-of-bounds. Use strides from tensors, not hard-coded, to support any contiguous layout.
    - Add @triton.autotune with several configs to adapt to different sizes.
    - Keep accumulation in FP32 for stability; Triton will cast on store depending on output dtype.

- Performance:
  - The GEMM is the heavy compute. Using a 3D tiled GEMM with autotune should give a solid speedup over a naive PyTorch matmul for many shapes while maintaining correctness.
  - The concatenation is a data movement step; using a straightforward Triton copy is fine and avoids additional cat or slice costs.

import torch
import triton
import triton.language as tl


@triton.jit
def triton_concatenation(
    encoder_ptr, hidden_ptr, out_ptr,
    B, T, I, H,
    stride_e_b, stride_e_t, stride_e_h,
    stride_h_b, stride_h_i, stride_h_h,
    stride_o_b, stride_o_l, stride_o_h,
    BLOCK_H: tl.constexpr,
):
    # program ids
    pid_b = tl.program_id(0)
    pid_l = tl.program_id(1)  # sequence position in [0, T + I)
    pid_k = tl.program_id(2)  # H tile

    k = pid_k * BLOCK_H + tl.arange(0, BLOCK_H)
    mask_k = k < H

    # Determine source: first T rows from encoder, remaining from hidden
    use_encoder = pid_l < T

    # Compute offsets
    if use_encoder:
        e_off = pid_b * stride_e_b + pid_l * stride_e_t + k * stride_e_h
        o_off = pid_b * stride_o_b + pid_l * stride_o_l + k * stride_o_h
        val = tl.load(encoder_ptr + e_off, mask=mask_k, other=0.0)
    else:
        h_off = pid_b * stride_h_b + (pid_l - T) * stride_h_i + k * stride_h_h
        o_off = pid_b * stride_o_b + pid_l * stride_o_l + k * stride_o_h
        val = tl.load(hidden_ptr + h_off, mask=mask_k, other=0.0)

    # Store
    tl.store(out_ptr + o_off, val, mask=mask_k)


@triton.autotune(
    configs=[
        triton.Config({'BLOCK_M': 32,  'BLOCK_N': 32,  'BLOCK_K': 32},  num_warps=4, num_stages=2),
        triton.Config({'BLOCK_M': 64,  'BLOCK_N': 64,  'BLOCK_K': 32},  num_warps=8, num_stages=3),
        triton.Config({'BLOCK_M': 64,  'BLOCK_N': 128, 'BLOCK_K': 32},  num_warps=8, num_stages=3),
        triton.Config({'BLOCK_M': 128, 'BLOCK_N': 64,  'BLOCK_K': 32},  num_warps=8, num_stages=3),
        triton.Config({'BLOCK_M': 128, 'BLOCK_N': 128, 'BLOCK_K': 32},  num_warps=8, num_stages=4),
        triton.Config({'BLOCK_M': 64,  'BLOCK_N': 256, 'BLOCK_K': 64},  num_warps=8, num_stages=4),
        triton.Config({'BLOCK_M': 256, 'BLOCK_N': 64,  'BLOCK_K': 64},  num_warps=8, num_stages=4),
        triton.Config({'BLOCK_M': 128, 'BLOCK_N': 256, 'BLOCK_K': 64},  num_warps=8, num_stages=4),
    ],
    key=['M', 'N', 'K'],
)
@triton.jit
def triton_bmm_kernel(
    A_ptr, B_ptr, C_ptr,
    B, M, N, K,
    stride_a_b, stride_a_m, stride_a_k,
    stride_b_k, stride_b_n,
    stride_c_b, stride_c_m, stride_c_n,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    # 3D grid: (B, tiles along M, tiles along N)
    pid_b = tl.program_id(0)
    pid_m = tl.program_id(1)
    pid_n = tl.program_id(2)

    # compute row/col offsets
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)  # [BLOCK_M]
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)  # [BLOCK_N]

    # mask for valid M,N range
    mask_m = offs_m < M
    mask_n = offs_n < N

    # accumulator in fp32
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # loop over K
    for k0 in range(0, K, BLOCK_K):
        offs_k = k0 + tl.arange(0, BLOCK_K)  # [BLOCK_K]
        mask_k = offs_k < K

        # load A tile: [BLOCK_M, BLOCK_K]
        a_ptrs = A_ptr + pid_b * stride_a_b + offs_m[:, None] * stride_a_m + offs_k[None, :] * stride_a_k
        a_mask = mask_m[:, None] & mask_k[None, :]
        a = tl.load(a_ptrs, mask=a_mask, other=0.0)

        # load B tile: [BLOCK_K, BLOCK_N] (B is process_weight.T with shape [K, N])
        b_ptrs = B_ptr + offs_k[:, None] * stride_b_k + offs_n[None, :] * stride_b_n
        b_mask = mask_k[:, None] & mask_n[None, :]
        b = tl.load(b_ptrs, mask=b_mask, other=0.0)

        # accumulate
        acc += tl.dot(a, b)

    # store result
    c_ptrs = C_ptr + pid_b * stride_c_b + offs_m[:, None] * stride_c_m + offs_n[None, :] * stride_c_n
    c_mask = mask_m[:, None] & mask_n[None, :]
    # Note: acc is fp32; Triton will cast on store depending on C_ptr dtype
    tl.store(c_ptrs, acc, mask=c_mask)


class ModelNew(torch.nn.Module):
    def forward(self, hidden_states: torch.Tensor, encoder_hidden_states: torch.Tensor, process_weight: torch.Tensor):
        """
        hidden_states: [B, I, H]
        encoder_hidden_states: [B, T, H]
        process_weight: [H, H]
        Returns: (processed_encoder: [B, T, H], processed_hidden: [B, I, H])
        """
        assert hidden_states.dim() == 3 and encoder_hidden_states.dim() == 3, "Inputs must be 3D [B, dim, H]"
        B = hidden_states.shape[0]
        T = encoder_hidden_states.shape[1]
        I = hidden_states.shape[1]
        H = hidden_states.shape[2]
        # Ensure process_weight is [H, H]
        assert process_weight.shape[0] == H and process_weight.shape[1] == H, "process_weight must be [H, H]"
        # Ensure dtype consistency
        assert hidden_states.dtype == encoder_hidden_states.dtype == process_weight.dtype, "All tensors must have same dtype"

        # Compute total sequence length
        L = T + I

        # Allocate concatenated tensor [B, L, H]
        out_cat = torch.empty((B, L, H), dtype=hidden_states.dtype, device=hidden_states.device)

        # Launch Triton concatenation kernel
        # Grid: (B, L, H tiles). Choose BLOCK_H=64 for good throughput
        BLOCK_H = 64
        grid = (B, L, triton.cdiv(H, BLOCK_H))
        triton_concatenation[grid](
            encoder_hidden_states, hidden_states, out_cat,
            B, T, I, H,
            *encoder_hidden_states.stride(), *hidden_states.stride(),
            *out_cat.stride(),
            BLOCK_H=BLOCK_H,
            num_warps=4,
        )

        # Prepare weight^T: [H, H]
        # We can use process_weight.t() directly; ensure it's on same device and dtype
        W_T = process_weight.t()  # [H, H]

        # Allocate output of GEMM: [B, L, H], keep fp32 for accumulation
        # Triton will store acc (fp32) to the tensor dtype. We'll keep out same dtype as inputs.
        out = torch.empty((B, L, H), dtype=hidden_states.dtype, device=hidden_states.device)

        # Launch Triton batched GEMM: A = out_cat [B, L, H], B = W_T [H, H], C = out [B, L, H]
        # Grid: (B, tiles along M=L, tiles along N=H)
        # We can let autotune pick BLOCK_M/N/K and num_warps/stages
        grid_bmm = (B, triton.cdiv(L, 64), triton.cdiv(H, 64))  # initial grid; autotune will adjust internally
        triton_bmm_kernel[grid_bmm](
            out_cat, W_T, out,
            B, L, H, H,  # M=L, N=H, K=H (process_weight.T is [H, H])
            *out_cat.stride(), *W_T.stride(), *out.stride(),
        )

        # Split streams
        processed_encoder = out[:, :T, :]
        processed_hidden = out[:, T:, :]
        return processed_encoder, processed_hidden

- Concatenation kernel is straightforward and robust: it writes directly into out_cat with correct indexing using strides, avoiding any host-side torch.cat.
- The batched GEMM kernel uses a 3D grid over (B, tiles along sequence, tiles along output features) and iterates over K in BLOCK_K chunks with masks. It accumulates in FP32 for numerical stability and stores to the output dtype.
- Triton autotune is added for the GEMM kernel to improve performance across varying shapes. The key is ['M', 'N', 'K'], allowing Triton to pick the best configuration per shape. Grid for autotune is provided as a function of meta parameters; here we use a conservative grid based on 64, but Triton will internally select the best BLOCK_M/N/K and use the provided grid accordingly.

    encoder_ptr, hidden_ptr, out_ptr,
    B, T, I, H,
    stride_e_b, stride_e_t, stride_e_h,
    stride_h_b, stride_h_i, stride_h_h,
    stride_o_b, stride_o_l, stride_o_h,
    BLOCK_H: tl.constexpr,
):
    # Grid: (B, L, H tiles) where L = T + I
    pid_b = tl.program_id(0)
    pid_l = tl.program_id(1)  # position in [0, L)
    pid_k = tl.program_id(2)  # tile along H

    k = pid_k * BLOCK_H + tl.arange(0, BLOCK_H)
    mask_k = k < H

    use_encoder = pid_l < T

    if use_encoder:
        e_off = pid_b * stride_e_b + pid_l * stride_e_t + k * stride_e_h
        o_off = pid_b * stride_o_b + pid_l * stride_o_l + k * stride_o_h
        val = tl.load(encoder_ptr + e_off, mask=mask_k, other=0.0)
    else:
        h_off = pid_b * stride_h_b + (pid_l - T) * stride_h_i + k * stride_h_h
        o_off = pid_b * stride_o_b + pid_l * stride_o_l + k * stride_o_h
        val = tl.load(hidden_ptr + h_off, mask=mask_k, other=0.0)

    tl.store(out_ptr + o_off, val, mask=mask_k)


@triton.autotune(
    configs=[
        triton.Config({'BLOCK_M': 64,  'BLOCK_N': 64,  'BLOCK_K': 32},  num_warps=4, num_stages=2),
        triton.Config({'BLOCK_M': 64,  'BLOCK_N': 128, 'BLOCK_K': 32},  num_warps=8, num_stages=3),
        triton.Config({'BLOCK_M': 128, 'BLOCK_N': 64,  'BLOCK_K': 32},  num_warps=8, num_stages=3),
        triton.Config({'BLOCK_M': 128, 'BLOCK_N': 128, 'BLOCK_K': 32},  num_warps=8, num_stages=4),
        triton.Config({'BLOCK_M': 128, 'BLOCK_N': 256, 'BLOCK_K': 64},  num_warps=8, num_stages=4),
        triton.Config({'BLOCK_M': 256, 'BLOCK_N': 128, 'BLOCK_K': 64},  num_warps=8, num_stages=4),
        triton.Config({'BLOCK_M': 256, 'BLOCK_N': 256, 'BLOCK_K': 64},  num_warps=8, num_stages=4),
    ],
    key=['M', 'N', 'K'],
)
@triton.jit
def triton_bmm_kernel(
    A_ptr, B_ptr, C_ptr,
    B, M, N, K,
    stride_a_b, stride_a_m, stride_a_k,
    stride_b_k, stride_b_n,
    stride_c_b, stride_c_m, stride_c_n,
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    # Grid: (B, tiles along M, tiles along N)
    pid_b = tl.program_id(0)
    pid_m = tl.program_id(1)
    pid_n = tl.program_id(2)

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)  # [BLOCK_M]
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)  # [BLOCK_N]
    mask_m = offs_m < M
    mask_n = offs_n < N

    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    for k0 in range(0, K, BLOCK_K):
        offs_k = k0 + tl.arange(0, BLOCK_K)
        mask_k = offs_k < K

        a_ptrs = A_ptr + pid_b * stride_a_b + offs_m[:, None] * stride_a_m + offs_k[None, :] * stride_a_k
        a_mask = mask_m[:, None] & mask_k[None, :]
        a = tl.load(a_ptrs, mask=a_mask, other=0.0)  # loads as tensor dtype; we cast to fp32

        b_ptrs = B_ptr + offs_k[:, None] * stride_b_k + offs_n[None, :] * stride_b_n
        b_mask = mask_k[:, None] & mask_n[None, :]
        b = tl.load(b_ptrs, mask=b_mask, other=0.0)

        # Cast to fp32 for stable accumulation
        a = a.to(tl.float32)
        b = b.to(tl.float32)

        acc += tl.dot(a, b)

    c_ptrs = C_ptr + pid_b * stride_c_b + offs_m[:, None] * stride_c_m + offs_n[None, :] * stride_c_n
    c_mask = mask_m[:, None] & mask_n[None, :]
    tl.store(c_ptrs, acc, mask=c_mask)
