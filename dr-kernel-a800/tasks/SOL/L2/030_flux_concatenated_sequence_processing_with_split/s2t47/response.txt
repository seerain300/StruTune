What the original PyTorch code computes
- Inputs:
  - encoder_hidden_states: [B, T, H]
  - hidden_states: [B, I, H]
  - process_weight: [H, H], no bias
- Steps:
  - Concatenate along sequence dimension: A_cat = torch.cat([encoder_hidden_states, hidden_states], dim=1) -> [B, L, H], where L = T + I
  - Linear projection: processed = A_cat @ process_weight.T -> [B, L, H]
  - Split: processed_encoder = processed[:, :T, :], processed_hidden = processed[:, T:, :]

Evaluators constraints and prior issues
- All numerical computation must be done by Triton kernels. No torch.cat or torch.matmul for the heavy work in forward. Only host code can:
  - compute shapes/strides,
  - allocate output tensors,
  - make tensors contiguous,
  - launch Triton kernels,
  - return the results.
- A previous submission was rejected for defining a decoy Triton kernel that wasn’t launched. We must ensure the Triton kernels we define are actually invoked from ModelNew.forward.
- Earlier submissions showed intermittent shape mismatches and runtime errors. The most common causes:
  - Grid sizes not matching tile sizes, leading to incomplete output writes.
  - Autotune configs causing under-coverage when grid is not computed as a function of meta parameters (BLOCK sizes).
  - Dtype mismatches or casts leading to numerical discrepancies.

Fix and optimization strategy
- Implement all steps in Triton:
  1) Triton kernel for concatenation: directly write into the output tensor out_cat of shape [B, L, H]. For each (b, m, k):
     - If m < T: out_cat[b, m, k] = encoder_hidden_states[b, m, k]
     - Else: out_cat[b, m, T, k] = hidden_states[b, m - T, k]
     This avoids host-side torch.cat and guarantees shape [B, L, H].
  2) Triton batched GEMM kernel: compute processed[b, m, n] = sum_k out_cat[b, m, k] * process_weight.T[k, n], where process_weight.T has shape [H, H]. Use a 3D grid over (batch, tiles of sequence M=L, tiles of output N=H), and iterate the reduction dimension K=H in blocks (BLOCK_K). Accumulate in fp32, then store to output.
- To avoid grid/tile mismatches, use Triton’s autotune with a grid lambda that depends on meta-parameters (BLOCK_M, BLOCK_N). This ensures the launch grid covers all tiles for each config.
- Dtype handling: perform computation in fp32 for numeric stability, then cast outputs back to the original dtype if necessary. The original code returns tensors with the same dtype as inputs (typically float32); we’ll keep outputs in fp32.

Edge cases
- Ensure all loads/stores are masked for boundary tiles when dimensions are not multiples of tile sizes.
- Use contiguous inputs for straightforward stride calculations and coalesced memory access.

Performance
- The heavy computation is the GEMM; the concatenation is trivial. Autotuning multiple block configurations should provide decent performance across the varied axes. While torch.matmul is very fast, the requirement is to use Triton for numerical computation. We will ensure correctness and robustness, then optimize tile choices.

import torch
import triton
import triton.language as tl

# --------------------------
# Triton kernel: concatenate encoder and hidden sequences along sequence dim into out_cat [B, L, H]
# out_cat[b, m, k] = encoder[b, m, k] if m < T else hidden[b, m - T, k]
# --------------------------
@triton.jit
def concat_encoder_hidden_kernel(
    out_ptr,  # *float32 [B, L, H]
    encoder_ptr,  # *float32 [B, T, H]
    hidden_ptr,  # *float32 [B, I, H]
    B: tl.constexpr, T: tl.constexpr, I: tl.constexpr, H: tl.constexpr,
    stride_ob, stride_ol, stride_oh,
    stride_eb, stride_et, stride_eh,
    stride_hb, stride_hi, stride_hh,
    BLOCK_M: tl.constexpr, BLOCK_K: tl.constexpr,
):
    # 3D grid: (batch, tiles over L, tiles over H)
    pid_b = tl.program_id(0)
    pid_m = tl.program_id(1)
    pid_k = tl.program_id(2)

    L = T + I

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)  # along sequence dim
    offs_k = pid_k * BLOCK_K + tl.arange(0, BLOCK_K)  # along hidden dim

    # Masks for valid m and k
    mask_m = offs_m < L
    mask_k = offs_k < H

    # We need to decide source tensor based on offs_m (whether m < T or m in [T, T+I-1])
    # For each (m, k), write to out_ptr[pid_b, m, k]
    # Initialize zero tile; fill based on condition
    # Triton doesn't support dynamic control flow branching across tiles easily,
    # so we compute per-tile and store separately.
    # First, initialize out with zeros (handled by host if needed).
    # Then, write encoder part and hidden part into out where applicable.

    # We'll compute loads and stores via masks. For each element (m, k):
    # if m < T: out[b, m, k] = encoder[b, m, k]
    # else:      out[b, m, k] = hidden[b, m - T, k]

    # Build pointers for encoder and hidden. Note: we cannot branch per element,
    # but we can construct masks for encoder-only and hidden-only regions and store.
    # However, to simplify, we'll recompute pointers for the two regions and store.

    # Prepare a placeholder tile with zeros; then overwrite where applicable.
    # To avoid undefined values, we compute out tile via combined logic.
    # Create broadcasted pointers for encoder and hidden:
    # encoder load pointers: encoder_ptr + pid_b*stride_eb + offs_m[:, None]*stride_et + offs_k[None, :]*stride_eh
    # hidden load pointers: hidden_ptr + pid_b*stride_hb + (offs_m[:, None] - T)*stride_hi + offs_k[None, :]*stride_hh

    enc_ptrs = encoder_ptr + pid_b * stride_eb + offs_m[:, None] * stride_et + offs_k[None, :] * stride_eh
    hid_ptrs = hidden_ptr + pid_b * stride_hb + (offs_m[:, None] - T) * stride_hi + offs_k[None, :] * stride_hh

    # Masks for encoder-only and hidden-only
    mask_m_encoder = (offs_m[:, None] < T)
    mask_m_hidden = (offs_m[:, None] >= T) & (offs_m[:, None] < L)

    # Combine with k-mask
    mask_encoder = mask_m_encoder & mask_k[None, :]
    mask_hidden = mask_m_hidden & mask_k[None, :]

    # Load values with masks; other will be ignored by store masking
    enc_vals = tl.load(enc_ptrs, mask=mask_encoder, other=0.0)
    hid_vals = tl.load(hid_ptrs, mask=mask_hidden, other=0.0)

    # Decide output pointers based on region
    out_ptrs = out_ptr + pid_b * stride_ob + offs_m[:, None] * stride_ol + offs_k[None, :] * stride_oh

    # Store encoder part
    tl.store(out_ptrs, enc_vals, mask=mask_encoder)
    # Store hidden part
    tl.store(out_ptrs, hid_vals, mask=mask_hidden)

# --------------------------
# Triton kernel: batched GEMM on out_cat [B, M=L, K=H] and W_T [K=H, N=H] -> out [B, M=L, N=H]
# --------------------------
@triton.autotune(
    configs=[
        triton.Config({'BLOCK_M': 64,  'BLOCK_N': 64,  'BLOCK_K': 32}, num_warps=4, num_stages=3),
        triton.Config({'BLOCK_M': 128, 'BLOCK_N': 64,  'BLOCK_K': 32}, num_warps=4, num_stages=3),
        triton.Config({'BLOCK_M': 64,  'BLOCK_N': 128, 'BLOCK_K': 32}, num_warps=4, num_stages=3),
        triton.Config({'BLOCK_M': 128, 'BLOCK_N': 128, 'BLOCK_K': 32}, num_warps=8, num_stages=3),
        triton.Config({'BLOCK_M': 128, 'BLOCK_N': 64,  'BLOCK_K': 64}, num_warps=8, num_stages=4),
        triton.Config({'BLOCK_M': 64,  'BLOCK_N': 128, 'BLOCK_K': 64}, num_warps=8, num_stages=4),
        triton.Config({'BLOCK_M': 128, 'BLOCK_N': 128, 'BLOCK_K': 64}, num_warps=8, num_stages=4),
    ],
    key=['M', 'N', 'K'],
)
@triton.jit
def batched_gemm_kernel(
    A_ptr, B_ptr, C_ptr,
    BATCH: tl.constexpr, M: tl.constexpr, N: tl.constexpr, K: tl.constexpr,
    stride_ab, stride_am, stride_ak,   # A: [B, M, K]
    stride_bb, stride_bk, stride_bn,   # B: [K, N] (W_T)
    stride_cb, stride_cm, stride_cn,   # C: [B, M, N]
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    # 3D launch: (batch, tiles along M, tiles along N)
    pid_b = tl.program_id(0)
    pid_m = tl.program_id(1)
    pid_n = tl.program_id(2)

    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)
    offs_n = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)

    # Accumulator
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    # Loop over K dimension
    for k in range(0, K, BLOCK_K):
        offs_k = k + tl.arange(0, BLOCK_K)

        # A tile: A[pid_b, offs_m, offs_k]
        a_ptrs = A_ptr + pid_b * stride_ab + offs_m[:, None] * stride_am + offs_k[None, :] * stride_ak
        a_mask = (offs_m[:, None] < M) & (offs_k[None, :] < K)
        a = tl.load(a_ptrs, mask=a_mask, other=0.0)

        # B tile: B[offs_k, offs_n]
        b_ptrs = B_ptr + offs_k[:, None] * stride_bk + offs_n[None, :] * stride_bn
        b_mask = (offs_k[:, None] < K) & (offs_n[None, :] < N)
        b = tl.load(b_ptrs, mask=b_mask, other=0.0)

        # Accumulate
        acc += tl.dot(a, b)

    # Write back to C
    c_ptrs = C_ptr + pid_b * stride_cb + offs_m[:, None] * stride_cm + offs_n[None, :] * stride_cn
    c_mask = (offs_m[:, None] < M) & (offs_n[None, :] < N)
    tl.store(c_ptrs, acc, mask=c_mask)

# --------------------------
# ModelNew: forward must invoke Triton kernels
# --------------------------
class ModelNew(torch.nn.Module):
    def forward(
        self,
        hidden_states: torch.Tensor,
        encoder_hidden_states: torch.Tensor,
        process_weight: torch.Tensor,
    ) -> tuple[torch.Tensor, torch.Tensor]:
        """
        Triton-optimized version:
          - Concatenate sequences in Triton into [B, L, H]
          - Apply linear projection via Triton GEMM
          - Split back into [B, T, H] and [B, I, H]
        """
        # Ensure inputs are contiguous
        B = hidden_states.shape[0]
        T = encoder_hidden_states.shape[1]
        I = hidden_states.shape[1]
        H = hidden_states.shape[2]
        L = T + I

        enc = encoder_hidden_states.contiguous()
        hid = hidden_states.contiguous()
        # process_weight: [H, H] (no bias); transpose to [K=H, N=H]
        W_T = process_weight.t().contiguous()

        # Output tensors (float32 for computation)
        out_cat = torch.empty((B, L, H), device=hidden_states.device, dtype=torch.float32)
        processed = torch.empty((B, L, H), device=hidden_states.device, dtype=torch.float32)

        # Strides
        stride_ob = out_cat.stride(0); stride_ol = out_cat.stride(1); stride_oh = out_cat.stride(2)
        stride_eb = enc.stride(0); stride_et = enc.stride(1); stride_eh = enc.stride(2)
        stride_hb = hid.stride(0); stride_hi = hid.stride(1); stride_hh = hid.stride(2)

        # Launch Triton concat kernel
        # Grid over (batch, tiles over L, tiles over H). Use BLOCK_M=128, BLOCK_K=128 for grid.
        grid_cat = (B, triton.cdiv(L, 128), triton.cdiv(H, 128))
        concat_encoder_hidden_kernel[grid_cat](
            out_cat, enc, hid,
            B, T, I, H,
            stride_ob, stride_ol, stride_oh,
            stride_eb, stride_et, stride_eh,
            stride_hb, stride_hi, stride_hh,
            BLOCK_M=128, BLOCK_K=128,
        )

        # Strides for GEMM
        stride_ab = out_cat.stride(0)  # [B, M=L, K=H]
        stride_am = out_cat.stride(1)
        stride_ak = out_cat.stride(2)
        stride_bb = W_T.stride(0)      # [K=H, N=H]
        stride_bk = W_T.stride(1)
        stride_bn = W_T.stride(2)
        stride_cb = processed.stride(0)
        stride_cm = processed.stride(1)
        stride_cn = processed.stride(2)

        # Launch Triton GEMM kernel with autotuned configs; grid depends on meta params
        grid_gemm = lambda META: (
            B,
            triton.cdiv(L, META['BLOCK_M']),
            triton.cdiv(H, META['BLOCK_N']),
        )
        batched_gemm_kernel[grid_gemm](
            out_cat, W_T, processed,
            BATCH=B, M=L, N=H, K=H,
        )

        # Split outputs
        processed_encoder = processed[:, :T, :]
        processed_hidden = processed[:, T:, :]

        # Return results (same dtype as inputs if desired; original code returns float tensors)
        # If inputs are not float32, you may cast here, but keep it simple:
        return processed_encoder, processed_hidden

import torch
import triton
import triton.language as tl

# --------------------------
# Triton kernel: concatenate encoder and hidden sequences along sequence dim into out_cat [B, L, H]
# out_cat[b, m, k] = encoder[b, m, k] if m < T else hidden[b, m - T, k]
# 3D tiling over (batch, sequence M=L, hidden K=H)
# --------------------------
@triton.jit
def concat_encoder_hidden_kernel(
    out_ptr,  # *float32 [B, L, H]
    encoder_ptr,  # *float32 [B, T, H]
    hidden_ptr,  # *float32 [B, I, H]
    B: tl.constexpr, T: tl.constexpr, I: tl.constexpr, H: tl.constexpr,
    stride_ob, stride_ol, stride_oh,
    stride_eb, stride_et, stride_eh,
    stride_hb, stride_hi, stride_hh,
    BLOCK_M: tl.constexpr, BLOCK_K: tl.constexpr,
):
    # Program IDs
    pid_b = tl.program_id(0)
    pid_m = tl.program_id(1)  # tiles along sequence dim (L)
    pid_k = tl.program_id(2)  # tiles along hidden dim (H)

    L = T + I

    # Tile offsets
    offs_m = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)  # along sequence
    offs_k = pid_k * BLOCK_K + tl.arange(0, BLOCK_K)  # along hidden

    # Masks for bounds
    mask_m = offs_m < L
    mask_k = offs_k < H

    # Output pointers for this tile
    out_ptrs = out_ptr + pid_b * stride_ob + offs_m[:, None] * stride_ol + offs_k[None, :] * stride_oh

    # Region masks: encoder vs hidden
    mask_encoder = mask_m[:, None] & mask_k[None, :]
    mask_hidden = (offs_m[:, None] >= T) & (offs_m[:, None] < L) & mask_k[None, :]

    # Load encoder values where m < T
    enc_ptrs = encoder_ptr + pid_b * stride_eb + offs_m[:, None] * stride_et + offs_k[None, :] * stride_eh
    enc_vals = tl.load(enc_ptrs, mask=mask_encoder, other=0.0)

    # Load hidden values where m >= T
    hid_ptrs = hidden_ptr + pid_b * stride_hb + (offs_m[:, None] - T) * stride_hi + offs_k[None, :] * stride_hh
    hid_vals = tl.load(hid_ptrs, mask=mask_hidden, other=0.0)

    # Store results
    tl.store(out_ptrs, enc_vals, mask=mask_encoder)
    tl.store(out_ptrs, hid_vals, mask=mask_hidden)
