- The computation is:

  2) GEMM: Acat @ process_weight.T -> [B, T+P, K], where process_weight.T has shape [K, K].
  3) Split back to [B, T, K] and [B, P, K].

- To meet the strict requirement, we will implement all steps in Triton:

  - Triton kernels to perform splitting into the two output streams (no torch slicing).

Key fixes
- Use proper 3D grid for the GEMM kernel: grid = (B, cdiv(M, BLOCK_M), cdiv(N, BLOCK_N)) with M = B*(T+P), N=K.
- Use masked loads/stores across M, N, and K dimensions to avoid OOB accesses for non-multiple tile sizes.
- Ensure dtype is float32 and inputs are contiguous for safe pointer arithmetic.
- Launch all Triton kernels from ModelNew.forward.

Implementation details
- Concatenation kernel _concat_seq_kernel:
  - Grid: (B, T+P), loop over K in tiles. For each l, if l < T, read encoder[b, l, :] and write to Acat[b, l, :]; else read hidden[b, l-T, :] and write to Acat[b, l, :]. Masks on K dimension.

- GEMM kernel _gemm_bmn_kernel:
  - Inputs: A (concatenated) flattened as [M, K], W (process_weight.T) as [K, K], output C as [M, K].
  - Grid: (B, cdiv(M, BLOCK_M), cdiv(N, BLOCK_N)).
  - Each program computes a BLOCK_M x BLOCK_N tile of C, accumulating over K in chunks of BLOCK_K with masked loads/stores.

- Split kernels:
  - _split_encoder_kernel: Copy C[:, :T, :] into processed_encoder [B, T, K] using a 3D grid over (B, T, K).
  - _split_hidden_kernel: Copy C[:, T:, :] into processed_hidden [B, P, K] using a 3D grid over (B, P, K).

This setup ensures all computation happens in Triton kernels, avoids torch operations in forward, and should resolve previous runtime errors by using robust 3D grids and comprehensive masks.

import torch
import triton
import triton.language as tl


@triton.jit
def _concat_seq_kernel(
    enc_ptr,  # *float32
    hid_ptr,  # *float32
    out_ptr,  # *float32
    B: tl.constexpr, T: tl.constexpr, P: tl.constexpr, K: tl.constexpr,
    enc_stride_b, enc_stride_t, enc_stride_k,
    hid_stride_b, hid_stride_p, hid_stride_k,
    out_stride_b, out_stride_t, out_stride_k,
    BLOCK_K: tl.constexpr,
):
    # Each program handles one batch b and one sequence position l in [0, T+P)
    pid_b = tl.program_id(0)
    pid_l = tl.program_id(1)

    # Compute l relative to total length
    total = T + P
    l = pid_l  # 0 <= l < total

    # K loop in tiles
    k0 = 0
    while k0 < K:
        k_offsets = k0 + tl.arange(0, BLOCK_K)  # [BLOCK_K]
        mask_k = k_offsets < K

        # Determine source: encoder if l < T, else hidden at l - T
        use_enc = l < T  # scalar boolean
        l_src_t = l  # if use_enc
        l_src_p = l - T  # if not use_enc

        # Compute base addresses
        # enc: [B, T, K] -> b, l, k
        enc_addrs = enc_ptr + pid_b * enc_stride_b + l_src_t * enc_stride_t + k_offsets * enc_stride_k
        # hid: [B, P, K] -> b, l - T, k
        hid_addrs = hid_ptr + pid_b * hid_stride_b + l_src_p * hid_stride_p + k_offsets * hid_stride_k
        out_addrs = out_ptr + pid_b * out_stride_b + l * out_stride_t + k_offsets * out_stride_k

        # Load with masks
        vals = tl.load(enc_addrs, mask=mask_k & use_enc, other=0.0)
        vals = tl.where(use_enc, vals, tl.load(hid_addrs, mask=mask_k & (~use_enc), other=0.0))

        # Store
        tl.store(out_addrs, vals, mask=mask_k)
        k0 += BLOCK_K


@triton.jit
def _gemm_bmn_kernel(
    A_ptr,  # *float32, shape [M, K], M = B * (T + P)
    W_ptr,  # *float32, shape [K, K]
    C_ptr,  # *float32, shape [M, K]
    B: tl.constexpr, T: tl.constexpr, P: tl.constexpr, K: tl.constexpr, N: tl.constexpr,  # N == K
    A_stride_m, A_stride_k,  # A: [M, K], strides for m and k
    W_stride_k, W_stride_n,  # W: [K, N], here N == K
    C_stride_m, C_stride_n,  # C: [M, N], here N == K
    BLOCK_M: tl.constexpr, BLOCK_N: tl.constexpr, BLOCK_K: tl.constexpr,
):
    # 3D grid: (B, tiles over M, tiles over N)
    pid_b = tl.program_id(0)
    pid_m = tl.program_id(1)
    pid_n = tl.program_id(2)

    M_total = B * (T + P)

    m_offsets = pid_m * BLOCK_M + tl.arange(0, BLOCK_M)  # [BLOCK_M]
    n_offsets = pid_n * BLOCK_N + tl.arange(0, BLOCK_N)  # [BLOCK_N]

    # Initialize accumulator
    acc = tl.zeros((BLOCK_M, BLOCK_N), dtype=tl.float32)

    k0 = 0
    while k0 < K:
        k_offsets = k0 + tl.arange(0, BLOCK_K)  # [BLOCK_K]
        mask_k = k_offsets < K

        # Load A tile: A[m, k]
        A_addrs = A_ptr + m_offsets[:, None] * A_stride_m + k_offsets[None, :] * A_stride_k
        mask_am = m_offsets[:, None] < M_total
        mask_ak = mask_k[None, :]
        A_tile = tl.load(A_addrs, mask=mask_am & mask_ak, other=0.0)

        # Load W tile: W[k, n]
        W_addrs = W_ptr + k_offsets[:, None] * W_stride_k + n_offsets[None, :] * W_stride_n
        mask_wk = k_offsets[:, None] < K
        mask_wn = n_offsets[None, :] < N
        W_tile = tl.load(W_addrs, mask=mask_wk & mask_wn, other=0.0)

        # Accumulate
        acc += tl.dot(A_tile, W_tile)

        k0 += BLOCK_K

    # Store result to C[m, n]
    C_addrs = C_ptr + m_offsets[:, None] * C_stride_m + n_offsets[None, :] * C_stride_n
    mask_m = m_offsets[:, None] < M_total
    mask_n = n_offsets[None, :] < N
    tl.store(C_addrs, acc, mask=mask_m & mask_n)


@triton.jit
def _split_encoder_kernel(
    C_ptr,  # *float32, shape [B, T+P, K]
    out_ptr,  # *float32, shape [B, T, K]
    B: tl.constexpr, T: tl.constexpr, P: tl.constexpr, K: tl.constexpr,
    C_stride_b, C_stride_t, C_stride_k,
    out_stride_b, out_stride_t, out_stride_k,
    BLOCK_K: tl.constexpr,
):
    # 3D grid: (B, T, tiles over K)
    pid_b = tl.program_id(0)
    pid_t = tl.program_id(1)
    pid_k = tl.program_id(2)

    k0 = pid_k * BLOCK_K
    k_offsets = k0 + tl.arange(0, BLOCK_K)
    mask_k = k_offsets < K

    C_addrs = C_ptr + pid_b * C_stride_b + pid_t * C_stride_t + k_offsets * C_stride_k
    out_addrs = out_ptr + pid_b * out_stride_b + pid_t * out_stride_t + k_offsets * out_stride_k

    vals = tl.load(C_addrs, mask=mask_k, other=0.0)
    tl.store(out_addrs, vals, mask=mask_k)


@triton.jit
def _split_hidden_kernel(
    C_ptr,  # *float32, shape [B, T+P, K]
    out_ptr,  # *float32, shape [B, P, K]
    B: tl.constexpr, T: tl.constexpr, P: tl.constexpr, K: tl.constexpr,
    C_stride_b, C_stride_t, C_stride_k,
    out_stride_b, out_stride_p, out_stride_k,
    BLOCK_K: tl.constexpr,
):
    # 3D grid: (B, P, tiles over K)
    pid_b = tl.program_id(0)
    pid_p = tl.program_id(1)
    pid_k = tl.program_id(2)

    k0 = pid_k * BLOCK_K
    k_offsets = k0 + tl.arange(0, BLOCK_K)
    mask_k = k_offsets < K

    # For C, source index is t = T + pid_p
    C_addrs = C_ptr + pid_b * C_stride_b + (T + pid_p) * C_stride_t + k_offsets * C_stride_k
    out_addrs = out_ptr + pid_b * out_stride_b + pid_p * out_stride_p + k_offsets * out_stride_k

    vals = tl.load(C_addrs, mask=mask_k, other=0.0)
    tl.store(out_addrs, vals, mask=mask_k)


class ModelNew(torch.nn.Module):
    def forward(self, hidden_states: torch.Tensor, encoder_hidden_states: torch.Tensor, process_weight: torch.Tensor):
        """
        hidden_states: [B, P, K]
        encoder_hidden_states: [B, T, K]
        process_weight: [K, K]
        returns: (processed_encoder: [B, T, K], processed_hidden: [B, P, K])
        """
        assert hidden_states.is_cuda and encoder_hidden_states.is_cuda and process_weight.is_cuda, "Tensors must be on CUDA"
        assert hidden_states.dtype == torch.float32 and encoder_hidden_states.dtype == torch.float32 and process_weight.dtype == torch.float32, "Use float32"

        B = hidden_states.shape[0]
        T = encoder_hidden_states.shape[1]
        P = hidden_states.shape[1]
        K = hidden_states.shape[2]
        assert encoder_hidden_states.shape == (B, T, K)
        assert process_weight.shape == (K, K)

        # 1) Concatenate along sequence using Triton
        total = T + P
        Acat = torch.empty((B, total, K), device=hidden_states.device, dtype=torch.float32)

        BLOCK_K = 128  # tile over K
        grid_concat = (B, total)
        _concat_seq_kernel[grid_concat](
            encoder_hidden_states, hidden_states, Acat,
            B, T, P, K,
            encoder_hidden_states.stride(0), encoder_hidden_states.stride(1), encoder_hidden_states.stride(2),
            hidden_states.stride(0), hidden_states.stride(1), hidden_states.stride(2),
            Acat.stride(0), Acat.stride(1), Acat.stride(2),
            BLOCK_K=BLOCK_K,
            num_warps=4, num_stages=2,
        )

        # 2) GEMM in Triton: Acat [B*(T+P), K] @ process_weight.T [K, K] -> C_flat [B*(T+P), K]
        M = B * total
        C_flat = torch.empty((M, K), device=hidden_states.device, dtype=torch.float32)

        # We can pass process_weight.T as-is (it's [K, K]); no need to transpose since kernel uses W[k, n]
        W = process_weight  # [K, K], no transpose

        BLOCK_M = 64
        BLOCK_N = 64
        BLOCK_K = 32
        grid_gemm = (B, triton.cdiv(M, BLOCK_M), triton.cdiv(K, BLOCK_N))
        _gemm_bmn_kernel[grid_gemm](
            Acat, W, C_flat,
            B, T, P, K, K,
            Acat.stride(0), Acat.stride(2),
            W.stride(0), W.stride(1),
            C_flat.stride(0), C_flat.stride(1),
            BLOCK_M=BLOCK_M, BLOCK_N=BLOCK_N, BLOCK_K=BLOCK_K,
            num_warps=4, num_stages=2,
        )

        # Reshape C_flat to [B, T+P, K]
        C = C_flat.view(B, total, K)

        # 3) Split outputs using Triton
        processed_encoder = torch.empty((B, T, K), device=hidden_states.device, dtype=torch.float32)
        processed_hidden = torch.empty((B, P, K), device=hidden_states.device, dtype=torch.float32)

        BLOCK_K_split = 128
        grid_e = (B, T, triton.cdiv(K, BLOCK_K_split))
        _split_encoder_kernel[grid_e](
            C, processed_encoder,
            B, T, P, K,
            C.stride(0), C.stride(1), C.stride(2),
            processed_encoder.stride(0), processed_encoder.stride(1), processed_encoder.stride(2),
            BLOCK_K=BLOCK_K_split,
            num_warps=4, num_stages=2,
        )

        grid_h = (B, P, triton.cdiv(K, BLOCK_K_split))
        _split_hidden_kernel[grid_h](
            C, processed_hidden,
            B, T, P, K,
            C.stride(0), C.stride(1), C.stride(2),
            processed_hidden.stride(0), processed_hidden.stride(1), processed_hidden.stride(2),
            BLOCK_K=BLOCK_K_split,
            num_warps=4, num_stages=2,
        )

        return processed_encoder, processed_hidden

Notes on performance and correctness
- All compute is in Triton kernels: concatenation, GEMM, splitting. No torch.cat, no slicing, no matmul.
- GEMM uses a 3D grid to cover all tiles across M=B*(T+P), N=K, and reduction K in chunks. Masks ensure boundary safety for non-multiple tile sizes.
- Concatenation kernel writes per (b, l) vector across K with masking for both encoder and hidden contributions; it handles arbitrary T and P.
- Split kernels read from C and write into outputs in tiles across K. They avoid any host-side slicing.
- Dtypes are float32; tensors are contiguous; masks avoid illegal memory accesses. This should prevent the prior runtime errors and ensure correctness across provided axes. Further tuning of block sizes can be done once correctness is validated.
