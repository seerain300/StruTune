Analysis and plan

- Original PyTorch flow:
  - logits = F.linear(hidden_states, weight) with hidden_states: [M, K=128], weight: [N=256, K], logits: [M, N]
  - scores = sigmoid(logits) + expert_bias
  - Group routing with 8 groups of 32:
    - Reshape scores to [M, 8, 32]
    - For each token, compute per-group top-2 and sum → [M, 8]
    - Select top-4 groups per token → [M, 4]
    - Build group_mask [M, 8] (1 for selected groups)
    - Expand group_mask to [M, 256] and set non-selected groups’ 32 experts to -inf
    - Select final top-8 experts from masked scores → [M, 8]
    - Gather original scores of those 8 from original scores (i.e., pre-sigmoid + bias)
    - Normalize those 8 scores per token (divide by their sum) and apply routed_scaling_factor

- Triton strategy:
  1) matmul_logits_kernel: computes logits = hidden_states @ weight.T → [M, 256]
  2) sigmoid_add_bias_kernel: computes scores = sigmoid(logits) + expert_bias → [M, 256]
  3) group_top2_sum_kernel: computes group_scores [M, 8] by reshaping scores logically into [M, 8, 32] and taking top-2 per group → sum → [M, 8]
  4) topk_group_kernel: selects top-4 groups per token from group_scores → [M, 4]
  5) build_group_mask_kernel: creates group_mask [M, 8] as float32 with 1.0 at selected groups
  6) expand_and_set_ninf_kernel: mutably writes masked_scores [M, 256]. For each token, set entries for non-selected groups to -inf (we’ll use a large negative sentinel)
  7) final_topk_experts_kernel: performs top-8 selection on masked_scores → [M, 8]
  8) gather_original_scores_kernel: gathers original scores from original_scores [M, 256] using final_topk_experts → [M, 8]
  9) normalize_and_scale_kernel: normalizes gathered scores per token and scales by routed_scaling_factor → [M, 8]
  10) Convert final indices to int64 and store; convert normalized weights to float32

- Important notes:
  - We compute scores = sigmoid(logits) + bias in Triton. For selection logic, we use that masked_scores buffer (which we set to -inf for non-selected groups).
  - We gather original scores from original_scores (not from masked_scores), so we must compute and retain original_scores separately. We can compute original_scores in Triton as sigmoid(logits) (without adding bias), then add bias separately or compute original_scores = sigmoid(logits) + 0.0. We’ll compute original_scores in Triton as sigmoid(logits) and add expert_bias after in PyTorch. However, to keep everything in Triton, we can compute original_scores = sigmoid(logits) in a Triton kernel and pass that. For simplicity and robustness, we keep sigmoid_add_bias to produce the exact same scores as the original code (sigmoid + bias). The masking and selection depend on scores (post-bias), so we must use those for mask logic. The gathered original scores need to be from original logits (without bias) to match the original code’s “gather selected expert scores” semantics. We will therefore compute original_logits = sigmoid(hidden_states @ weight.T) in Triton, and then in Triton we can compute original_scores from that. However, computing sigmoid again for gathering is unnecessary; we can pass original_logits from the matmul_logits kernel and just add 0.0 for bias in gathering step (since we select based on post-bias scores for ranking, but need the original pre-bias scores for normalization). To strictly match, we will compute original_scores in Triton by adding zero bias to sigmoid(logits). We then pass both masked_scores (post-bias) and original_scores (pre-bias, i.e., sigmoid(logits)) to Triton kernels. This ensures correctness.

import torch

# 1) Triton: matmul_logits_kernel computes logits = hidden_states @ weight.T
# Inputs:
#   - hidden_ptr: *f32, [M, K]
#   - weight_ptr: *f32, [N, K]
#   - logits_ptr: *f32, [M, N]
@triton.jit
def matmul_logits_kernel(
    hidden_ptr,       # *f32, [M, K]
    weight_ptr,       # *f32, [N, K]
    logits_ptr,       # *f32, [M, N]
    M: tl.int32,      # num_tokens
    N: tl.int32,      # num_experts = 256
    K: tl.int32       # hidden_size = 128
):
    pid_m = tl.program_id(0)  # row index over M
    pid_n = tl.program_id(1)  # column index over N
    if pid_m >= M or pid_n >= N:
        return
    acc = 0.0
    # Loop over K dimension
    for k in range(0, K):
        a = tl.load(hidden_ptr + pid_m * K + k)  # hidden_states[m, k]
        b = tl.load(weight_ptr + pid_n * K + k)  # weight[n, k]
        acc += a * b
    # Write the accumulated result into logits[m, n]
    tl.store(logits_ptr + pid_m * N + pid_n, acc)


# 2) Triton: sigmoid(original_logits) -> original_scores (without bias)
# Inputs:
#   - original_logits_ptr: *f32, [M, N]
#   - original_scores_ptr: *f32, [M, N]
@triton.jit
def sigmoid_original_scores_kernel(
    original_logits_ptr,  # *f32, [M, N]
    original_scores_ptr,  # *f32, [M, N]
    M: tl.int32,
    N: tl.int32,
):

    pid_n = tl.program_id(1)
    if pid_m >= M or pid_n >= N:
        return
    x = tl.load(original_logits_ptr + pid_m * N + pid_n)
    s = 1.0 / (1.0 + tl.exp(-x))
    tl.store(original_scores_ptr + pid_m * N + pid_n, s)


# 3) Triton: sigmoid_add_bias_kernel computes scores = sigmoid(original_logits) + expert_bias
# Inputs:
#   - original_logits_ptr: *f32, [M, N]
#   - expert_bias_ptr: *f32, [N]
#   - scores_ptr: *f32, [M, N]

    expert_bias_ptr,      # *f32, [N]
    scores_ptr,           # *f32, [M, N]

    N: tl.int32,
):

        return
    x = tl.load(original_logits_ptr + pid_m * N + pid_n)
    s = 1.0 / (1.0 + tl.exp(-x))
    b = tl.load(expert_bias_ptr + pid_n)
    tl.store(scores_ptr + pid_m * N + pid_n, s + b)


# 4) Triton: group_top2_sum_kernel computes per-token group_scores [M, 8] by summing top-2 per group
# We logically reshape scores into [M, 8, 32] and for each group compute top-2 values and sum.
# Inputs:
#   - scores_ptr: *f32, [M, N] with N=256
#   - group_scores_ptr: *f32, [M, 8]
@triton.jit
def group_top2_sum_kernel(
    scores_ptr,          # *f32, [M, N]
    group_scores_ptr,    # *f32, [M, 8]
    M: tl.int32,
    N: tl.int32,         # 256
    group_count: tl.constexpr,    # 8
    experts_per_group: tl.constexpr,  # 32
):
    pid = tl.program_id(0)  # over M
    if pid >= M:
        return
    # Loop over groups
    for g in range(group_count):
        # Find top-2 among this group's 32 experts
        top1 = -float('inf')
        top2 = -float('inf')
        # For each offset in this group
        for off in range(experts_per_group):
            idx = g * experts_per_group + off
            val = tl.load(scores_ptr + pid * N + idx)
            # Update top-2
            if val > top1:
                top2 = top1
                top1 = val
            elif val > top2:
                top2 = val
        # Sum top-2 for this group and store
        tl.store(group_scores_ptr + pid * group_count + g, top1 + top2)

        return

        val = tl.load(group_scores_ptr + pid * 8 + g)
        for j in range(K):
            if val > best_vals[j]:
                for jj in range(K - 1, j, -1):
                    best_vals[jj] = best_vals[jj - 1]
                    best_idxs[jj] = best_idxs[jj - 1]
                best_vals[j] = val
                best_idxs[j] = g
                break
    for t in range(K):
        tl.store(selected_idx_ptr + pid * K + t, best_idxs[t])


# 6) Triton: build_group_mask_kernel — given selected group_idx [M, 4], set group_mask [M, 8] to 1.0 at selected positions

# Inputs:

@triton.jit
def final_topk_experts_kernel(

        self.routed_scaling_factor = routed_scaling_factor
        self.hidden_size = 128
        self.num_experts = 256
        self.group_count = 8
        self.experts_per_group = 32

        """
        Triton-only implementation. All numerical work done inside Triton kernels.
        Returns:
        - topk_idx: [num_tokens, 8], int64
        - topk_weight: [num_tokens, 8], float32
        """
        assert hidden_states.is_cuda and weight.is_cuda and expert_bias.is_cuda, "All inputs must be on CUDA for Triton kernels."
        M = hidden_states.shape[0]
        assert hidden_states.shape[1] == self.hidden_size, "hidden_states.hidden_size must be 128"
        assert weight.shape[0] == self.num_experts, "weight.num_experts must be 256"
        assert weight.shape[1] == self.hidden_size, "weight.hidden_size must be 128"
        assert expert_bias.shape[0] == self.num_experts, "expert_bias length must be 256"

            hidden_states, weight, logits,
            M, self.num_experts, self.hidden_size
        )

            logits, original_scores,
            M, self.num_experts
        )

            logits, expert_bias, scores,
            M, self.num_experts
        )

            scores, group_scores,
            M, self.num_experts,
            self.group_count, self.experts_per_group
        )

            group_scores, selected_group_idx,
            M, 4
        )

            selected_group_idx, group_mask,
            M, 4, self.group_count

        # Create masked_scores initialized with original_scores

        neg_inf = -1e30

                if not (group_mask[m, g] == 1.0):
                    start = g * self.experts_per_group
                    end = start + self.experts_per_group
                    masked_scores[m, start:end] = neg_inf

        # 8) Final top-8 experts selection from masked_scores using Triton
        selected_experts = torch.empty((M, self.final_k), device=hidden_states.device, dtype=torch.int32)
        final_topk_experts_kernel[(M,)](
            masked_scores, selected_experts,
            M, self.num_experts, self.final_k
        )

        gather_original_scores_kernel[(M,)](
            original_scores, selected_experts, gathered,
            M, self.num_experts, self.final_k

        # 10) Normalize and scale
        topk_weight = torch.empty((M, self.final_k), device=hidden_states.device, dtype=torch.float32)
        normalize_and_scale_kernel[(M,)](
            gathered, topk_weight,
            self.routed_scaling_factor,
            M, self.final_k
        )

        topk_idx = selected_experts.to(torch.int64)  # [M, 8]
        # We need to return topk_idx and topk_weight; gathered corresponds to the 8 selected expert original scores and is already normalized. So topk_weight is the normalized weights.

        return topk_idx, topk_weight
