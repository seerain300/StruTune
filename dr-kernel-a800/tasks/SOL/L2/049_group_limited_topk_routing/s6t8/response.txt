Implementation details

- Triton matmul for logits:
  - Inputs: a [M, 128] float32, b [256, 128] float32. Output [M, 256] float32.
  - Grid: (M, 256). Loop over K=128: a_row[k] * b_col[k] and accumulate. Store to out[row, col].

- Triton sigmoid + bias:
  - Inputs: logits [M, 256], bias [256]. Output scores [M, 256].
  - Grid: (M, 256). Compute sigmoid = 1 / (1 + exp(-x)), add bias.

- Triton group_top2_sum:
  - Input: scores [M, 8, 32] stored as a flat pointer of length M*8*32. Output group_scores [M, 8].
  - For each row r in 0..M-1 and each group g in 0..7:
    - Iterate j in 0..31: decode idx = g*32 + j, load score at flat index r*(8*32) + idx, track top1 and top2.
    - sum = top1 + top2.
    - store to out[r, g].

- Triton top-k group selection (k=4):
  - Input: group_scores [M, 8], Output group_idx [M, 4] int32.
  - For t in 0..3:
    - compute max over 8 for row r, store idx to out[r, t], and mark that position as -inf in input for next iteration.

- Triton build group mask:
  - Input: group_idx [M, 4], Output group_mask [M, 8] int32 (0/1).
  - For each r, set group_mask[r, group_idx[r, t]] = 1 for t in 0..3, others 0.

- Triton expand mask and set -inf:
  - Input: group_mask [M, 8], scores [M, 256], Output masked_scores [M, 256].
  - For each r, for each group g: if group_mask[r, g] == 0, set masked_scores[r, g*32 + j] = -inf for j in 0..31. Else keep original.

- Triton final top-k (k=8):
  - Input: masked_scores [M, 256], Output final_idx [M, 8] int32.
  - Implement iterative top-8 argmax: for t in 0..7, find max over 256 for row r, store idx, and set that position to -inf.

- Triton gather selected original scores:
  - Input: scores [M, 256], final_idx [M, 8], Output gathered [M, 8] float32.
  - For each r, load scores[r, final_idx[r, t]].

- Triton normalize and scale:
  - Input: gathered [M, 8], scale=float, Output final_weight [M, 8] float32.
  - For each r, sum over 8, divide each by sum, multiply by scale.

@triton.jit

    K: tl.constexpr,           # 128
