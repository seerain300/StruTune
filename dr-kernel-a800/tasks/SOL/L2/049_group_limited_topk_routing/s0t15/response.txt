Deep analysis and plan

1) GEMM in Triton (F.linear)
   - We need logits = hidden_states @ weight.T where:
     - hidden_states: [M, K] with M=num_tokens, K=hidden_dim=256
     - weight: [N, K] with N=num_experts=256
     - logits: [M, N]
   - Implement a tiled matmul kernel: for each program instance, compute a TILE_M x TILE_N output tile:
     acc = 0
     for k in range(0, K, TILE_K):
       a = hidden_states_tile [TILE_M x TILE_K]
       b = weight_tile         [TILE_K x TILE_N]
       acc += tl.dot(a, b)
   - We will:
     - Use grid = (ceil_div(M, TILE_M), ceil_div(N, TILE_N)). If we tile N, this means we will not have a grid with 0 programs when N is not divisible by TILE_N. Triton requires grid to cover all output tiles. The correct approach is to tile along M and K with loops inside the kernel, and along N with a grid on N. But to avoid any partial-coverage pitfalls, we’ll ensure our tiling covers all rows. Since M can vary across workloads, we keep a generic grid based on ceil_div(M, TILE_M), and loop over N inside the kernel up to N using masks. This avoids shape-dependent grid adjustments.
   - We accumulate in float32 and store to logits.

2) Sigmoid + bias (elementwise)
   - scores = sigmoid(logits) + expert_bias
   - We load logits and bias, compute sigmoid (1 / (1 + exp(-x))), add bias, store to scores.

3) Group top-2 sum per token
   - Group 256 experts into 8 groups of 32:
     - For each token t:
       - For each group g in 0..7:
         - Consider scores[t, g*32 : g*32 + 32]
         - Find top-2 unsorted, sum to group_score[t, g]
   - Implement a Triton kernel that for each token:
     - Initializes group_score as -inf
     - Iterates over group index (0..7), loads 32 values, finds max and second max by repeated comparisons (linear scan), sums them, stores to group_score.

4) Top-4 group selection per token
   - From group_scores [M, 8], pick top-4 indices per token (sorted=False).
   - Implement a Triton kernel for each token:
     - Keep 4 arrays max1..max4 = -inf, and idx1..idx4.
     - For i in 0..7:
       - If group_scores[t, i] > max1, insert at position 1 (shift max1..max3), and set idx1.. accordingly.
       - Repeat for second, third, fourth slots.
     - Write out top4_groups[t, :] = idx1..idx4.

5) Masking non-selected groups in scores
   - For each token t, keep only the 4 selected groups (indices in top4_groups[t, :]) and set scores[t, others] = -inf.
   - Implement a Triton kernel that:
     - For each token t:
       - Loops over 8 groups, checks if index in top4_groups[t, :], leaves as is; else sets to -inf.

6) Final top-8 selection from masked scores
   - From masked_scores [M, 256], select top-8 per token (largest=True, sorted=False).
   - Implement a Triton kernel for each token:
     - Repeatedly find the max value among remaining entries and its index, mark it as used (e.g., set to -inf), and record its index. Do this 8 times.
     - Store top8_indices.

7) Normalization and scaling
   - Gather selected scores from masked_scores using top8_indices: selected = masked_scores.gather(1, top8_indices).
   - Normalize: denom = sum(selected, dim=1) + 1e-20; weights = selected / denom[:, None].
   - Multiply by routed_scaling_factor.
   - Implement a Triton kernel that:
     - For each token t:
       - Loops i in 0..7, loads selected_score[t, i], divides by denom[t], multiplies by scaling_factor, writes to output.

import torch
import triton
import triton.language as tl

# ---------------------------
# Triton kernel 1: GEMM logits = hidden @ weight.T
# hidden: [M, K], weight: [N, K], logits: [M, N]
# ---------------------------
@triton.jit
def _linear_proj_kernel(
    hidden_ptr, weight_ptr, logits_ptr,
    M, K, N,
    stride_hm, stride_hk,
    stride_wn, stride_wk,
    stride_lm, stride_ln,
    TILE_M: tl.constexpr, TILE_N: tl.constexpr, TILE_K: tl.constexpr,
):
    pid_m = tl.program_id(0)
    offs_m = pid_m * TILE_M + tl.arange(0, TILE_M)
    offs_n = tl.arange(0, TILE_N)
    acc = tl.zeros((TILE_M, TILE_N), dtype=tl.float32)

    # Loop over K in chunks
    for k0 in range(0, K, TILE_K):
        offs_k = k0 + tl.arange(0, TILE_K)
        # A tile: [TILE_M, TILE_K]
        a_ptrs = hidden_ptr + (offs_m[:, None] * stride_hm + offs_k[None, :] * stride_hk)
        a_mask = (offs_m[:, None] < M) & (offs_k[None, :] < K)
        a = tl.load(a_ptrs, mask=a_mask, other=0.0)

        # B tile: we want [TILE_K, TILE_N] = weight[n, k], where n in [offs_n], k in [offs_k]
        b_ptrs = weight_ptr + (offs_n[None, :] * stride_wn + offs_k[:, None] * stride_wk)
        b_mask = (offs_k[:, None] < K) & (offs_n[None, :] < N)
        b = tl.load(b_ptrs, mask=b_mask, other=0.0)

        acc += tl.dot(a, b)

    # Store acc into logits
    l_ptrs = logits_ptr + (offs_m[:, None] * stride_lm + offs_n[None, :] * stride_ln)
    l_mask = (offs_m[:, None] < M) & (offs_n[None, :] < N)
    tl.store(l_ptrs, acc, mask=l_mask)


# ---------------------------
# Triton kernel 2: scores = sigmoid(logits) + expert_bias
# scores: [M, N], logits: [M, N], bias: [N]
# ---------------------------
@triton.jit
def _sigmoid_add_bias_kernel(
    logits_ptr, bias_ptr, scores_ptr,
    M, N,
    stride_sm, stride_sn,
    stride_bn,
    stride_om, stride_on,
):
    # 1D grid over elements
    pid = tl.program_id(0)
    total = M * N
    idx = pid
    # Compute row and col from linear index
    row = idx // N
    col = idx % N

    # Bounds check
    if (row >= M) or (col >= N):
        return

    x = tl.load(logits_ptr + row * stride_sm + col * stride_sn)
    b = tl.load(bias_ptr + col * stride_bn)
    y = 1.0 / (1.0 + tl.exp(-x))
    y = y + b
    tl.store(scores_ptr + row * stride_om + col * stride_on, y)


# ---------------------------
# Triton kernel 3: group_top2_sum -> group_scores [M, 8]
# scores: [M, N], group_scores: [M, 8]
# Each group has 32 experts. For token t: sum of top-2 in each group.
# ---------------------------
@triton.jit
def _group_top2_sum_kernel(
    scores_ptr, group_scores_ptr,
    M, N,
    EXP_PER_GROUP: tl.constexpr,  # 32
    stride_sm, stride_sn,
    stride_gm, stride_gn,
):
    t = tl.program_id(0)  # one program per token
    if t >= M:
        return

    sum2 = tl.full((), -float('inf'), tl.float32)
    # Loop over 8 groups
    for g in range(8):
        base = g * EXP_PER_GROUP
        # Find max
        max1 = tl.full((), -float('inf'), tl.float32)
        max2 = tl.full((), -float('inf'), tl.float32)
        # Scan 32 elements
        for j in range(EXP_PER_GROUP):
            val = tl.load(scores_ptr + t * stride_sm + (base + j) * stride_sn)
            # Update max1 and max2
            if val > max1:
                max2 = max1
                max1 = val
            elif val > max2:
                max2 = val
        sum2 += max1 + max2

    tl.store(group_scores_ptr + t * stride_gm + 0 * stride_gn, sum2)


# ---------------------------

# group_scores: [M, 8], top4_groups: [M, 4] (int32)

    max4 = tl.full((), -float('inf'), tl.float32)
    idx1 = tl.full((), -1, tl.int32)
    idx2 = tl.full((), -1, tl.int32)
    idx3 = tl.full((), -1, tl.int32)
    idx4 = tl.full((), -1, tl.int32)

    for i in range(8):
        val = tl.load(group_scores_ptr + t * stride_gm + i * stride_gn)
        inserted = tl.full((), 0, tl.int1)
        # Insert into 1

            inserted = 1
            max4 = max3
            idx4 = idx3
            max3 = max2
            idx3 = idx2
            max2 = max1
            idx2 = idx1
            max1 = val
            idx1 = i
        elif val > max2:
            inserted = 1
            max4 = max3
            idx4 = idx3
            max3 = max2
            idx3 = idx2
            max2 = val
            idx2 = i
        elif val > max3:

            max4 = max3
            idx4 = idx3
            max3 = val
            idx3 = i
        elif val > max4:

            max4 = val
            idx4 = i

    # Write results
    tl.store(top4_groups_ptr + t * stride_tm + 0 * stride_tn, idx1)
    tl.store(top4_groups_ptr + t * stride_tm + 1 * stride_tn, idx2)
    tl.store(top4_groups_ptr + t * stride_tm + 2 * stride_tn, idx3)
    tl.store(top4_groups_ptr + t * stride_tm + 3 * stride_tn, idx4)

@triton.jit
def _mask_selected_groups_kernel(
    scores_ptr, masked_scores_ptr,
    M, N,
    idx0, idx1, idx2, idx3,
    stride_sm, stride_sn,
    stride_mm, stride_mn,
):
    t = tl.program_id(0)
    if t >= M:
        return
    # Loop over all groups (8) and for each group, set to -inf if group id not in {idx0, idx1, idx2, idx3}
    for g in range(8):
        base = g * 32
        set_neg = 1  # default to set to -inf
        # Compare g with idx0..idx3
        # Note: Triton compares scalar values fine. idx0..idx3 are scalars known at launch.
        if g == idx0:
            set_neg = 0
        if g == idx1:
            set_neg = 0
        if g == idx2:
            set_neg = 0
        if g == idx3:
            set_neg = 0
        # If set_neg == 1, set -inf for all 32 in this group
        for j in range(32):
            val = tl.load(scores_ptr + t * stride_sm + (base + j) * stride_sn)
            neg = -float('inf')
            out_val = tl.where(set_neg == 1, neg, val)
            tl.store(masked_scores_ptr + t * stride_mm + (base + j) * stride_mn, out_val)

    best_val = tl.full((), -float('inf'), tl.float32)

        found = 0
        # Iterate over all N to find current max

        # Reset best for next iteration
