ฉันเข้าใจว่ากรอบการทำงานคือ:

- ModelNew.forward จะเรียกใช้ Triton kernels ทุกตัว และไม่ใช้ PyTorch ops ในการ compute จริงๆ
- โค้ดต้องทำงานถูกต้องในหลากหลาย workload โดยเฉพาะ num_tokens ที่หลากหลาย (2048, 2080, 3557 ฯลฯ)
- สาเหตุที่งานที่แล้ว fail น่าจะเป็น:
  - โค้ดไม่สมบูรณ์ (kernel ตัวไหนบางตัว code หาย) แม้ forward มี calls แต่ไม่ได้คอมไพล์/run จริง
  - อาจเป็นชนิดข้อมูลไม่ถูกต้องใน Triton (ใช้ tl.constexpr กับตัวแปรที่ไม่ใช่ compile-time constants, หรือ addressing ผิดพลาด)
  - iterative elimination logic ใน Triton อาจจะผิดพลาด (ไม่ได้ใช้ Triton operators ที่รองรับดีพอ)

แผนการแก้ไข:

1) ให้โค้ด compact, มี kernel ที่ define ครบ 5 ตัว (linear + bias, scores + bias, select top-4 groups, mask scores, select top-8 with normalization) และ forward เรียกใช้ kernel ทุกตัวจริงๆ
2) ลดความยุ่งยาก: ใน Triton เราไม่ควรใช้ operators ที่ซับซ้อนมาก (เช่น มาร์กซ์ตาราง 2D), ดังนั้นเราใช้ strategy ที่ flat โดยจัดการ 2D tensors ด้วย 1D addressing: logits ได้มาแล้ว, scores ก็ได้มาแล้ว, จัดกลุ่มโดยใช้ index mapping ใน CPU แล้ว compute group_scores ด้วย Triton โดยใช้ indices (หมายเหตุ: ตรงนี้เราเลือกให้ Triton คำนวณ top-2 per group โดยการโหลดเฉพาะสมาชิกที่ต้องการ ซึ่งทำได้ด้วย 1D indexing, ไม่ใช้ reshape ใน kernel ซับซ้อน)
3) ไม่ใช้ torch.topk ใน host: ใช้ iterative elimination โดยทำ loop ใน Triton (ใช้ for) และอ่านค่าจาก memory ตามตำแหน่งที่เราทำการใส่ -inf ในคราวเดียวกันเพื่อป้องกันการเลือกซ้ำ
4) ตรวจสอบ dtype และ stride: เราจะ cast inputs ไปเป็น float32 (compute ทั้งหมด) ไม่เปลี่ยนขนาด, ใช้ strides ที่ถูกต้องในการ addressing 2D, ไม่ใช้ view ที่ทำให้ compute ผิดพลาด

Note: ปัญหาเดิมเกิดจากการโพสต์โค้ดไม่สมบูรณ์และอาจไม่ได้เรียกใช้ kernel บางตัวจริงๆ; คราวนี้ผมจะโพสต์โค้ดครบถ้วน รวม kernel ที่ define ทั้งหมดและ forward เรียกใช้ทุกตัว. ภาษาตริตันใช้ทัวโทปในการ comput จริงๆ (ไม่ใช้ PyTorch ops) ยกเว้นแค่ allocation, casting, and creation of tensors.

```python
            group_scores.stride(0), group_scores.stride(1),
```

- 3) compute_group_scores_kernel: For each token i, for each group g in 0..7, compute top2 = max(scores[i, g*32:(g+1)*32]) and second = second_max of that slice, and OUT[i, g] = top2 + second. Do not use torch.topk.
- 4) select_top4_groups_kernel: For each token i, repeated elimination:
  - maxv = max(group_scores[i, :]), idx = argmax, store to selected_groups[i, 0], set group_scores[i, idx] = -inf
  - repeat 3 more times
- 5) mask_scores_with_groups_kernel: For each token i, for each selected_group index sg in selected_groups[i, :], zero scores[i, sg*32:(sg+1)*32] to -inf in OUT_MASKED (use 1D addressing: idx = row*N + col).

  - repeat 7 times
  - Then weight[i, j] = numerator / (numerator + 1e-20)

Understanding and plan:
- Original algorithm summary:
  1) logits = hidden_states @ weight^T + expert_bias
  2) scores = sigmoid(logits) + expert_bias
  3) For each token, for 8 groups of 32 experts each, compute sum of top-2 scores per group => 8 group scores
  4) Select top-4 groups based on group scores (sorted=False)
  5) Mask out non-selected groups (set their scores to -inf)
  6) Select top-8 experts from the masked scores (sorted=False), and normalize weights using original logits: weight_i = routed_scaling_factor * (sum(selected_logits)) / (sum(selected_logits) + 1e-20)

- Triton approach:
  - Kernel 1: linear_bias_kernel computes logits = A @ W^T + bias (GEMV-like per row + bias).
  - Kernel 2: sigmoid_bias_kernel computes scores = sigmoid(logits) + bias.
  - Kernel 3: compute_group_scores_kernel computes group_scores per token via iterative top-2 selection within each group using 1D addressing. No torch.topk.
  - Kernel 4: select_top4_groups_kernel selects 4 groups per token via iterative elimination (find max, set it to -inf, store index).
  - Kernel 5: mask_scores_with_groups_kernel sets to -inf all experts in non-selected groups for each token.
  - Kernel 6: select_top8_with_weight_and_normalize_kernel selects 8 experts from masked scores per token via iterative elimination; accumulates numerator = routed_scaling_factor * sum(original logits at selected indices); then divides numerator by (numerator + 1e-20).

- Important: All compute is done by Triton kernels. Host code does only allocation, casting, and launching kernels. No torch operations in the compute path.

```python
import torch
import torch.nn as nn
import triton
import triton.language as tl


# Kernel 1: logits = hidden_states @ weight^T + expert_bias
# A: [M, K] (row-major), W: [N, K] (row-major), bias: [N]
@triton.jit
def linear_bias_kernel(A_ptr, W_ptr, BIAS_ptr, OUT_ptr, M, N, K):
    # Each program handles one row i (token)
    i = tl.program_id(0)
    if i >= M:
        return
    acc = tl.zeros((N,), dtype=tl.float32)
    # Loop over K in chunks
    for k0 in range(0, K, 32):
        k_ids = k0 + tl.arange(0, 32)
        # Load a_i[k0:k0+32]
        a = tl.load(A_ptr + i * K + k_ids, mask=k_ids < K, other=0.0)
        # Load W[:, k0:k0+32] -> shape [N, 32]
        w_ptrs = W_ptr + tl.arange(0, N)[:, None] * K + k_ids[None, :]
        w = tl.load(w_ptrs, mask=(k_ids[None, :] < K), other=0.0)
        # acc += a[k_ids] * w[k_ids]
        # Broadcast a over rows: a[:, None] * w -> [N, 32]
        acc += tl.sum(a[None, :] * w, axis=1)
    # Add bias
    bias = tl.load(BIAS_ptr + tl.arange(0, N))
    acc += bias
    # Store
    tl.store(OUT_ptr + i * N + tl.arange(0, N), acc)


# Kernel 2: scores = sigmoid(logits) + expert_bias
# LOGITS: [M, N], BIAS: [N], OUT: [M, N]
@triton.jit
def sigmoid_bias_kernel(LOGITS_ptr, BIAS_ptr, OUT_ptr, M, N):
    i = tl.program_id(0)
    if i >= M:
        return
    for n0 in range(0, N, 32):
        n_ids = n0 + tl.arange(0, 32)
        logits = tl.load(LOGITS_ptr + i * N + n_ids, mask=n_ids < N, other=0.0)
        bias = tl.load(BIAS_ptr + n_ids, mask=n_ids < N, other=0.0)
        sig = 1.0 / (1.0 + tl.exp(-logits))
        out = sig + bias
        tl.store(OUT_ptr + i * N + n_ids, out, mask=n_ids < N)


# Kernel 3: compute group scores: sum of top-2 per group -> OUT[M, 8]
# SCORES: [M, N], OUT: [M, 8]
@triton.jit
def compute_group_scores_kernel(SCORES_ptr, OUT_ptr, M, N, GROUPS, EXP_PER_GROUP):
    i = tl.program_id(0)
    if i >= M:
        return
    # group_scores[8]
    gs = tl.zeros((8,), dtype=tl.float32)
    for g in range(8):
        # maxv = max(scores[i, g*32:(g+1)*32])
        start = g * EXP_PER_GROUP
        maxv = -float('inf')
        for j in range(EXP_PER_GROUP):
            n = start + j
            v = tl.load(SCORES_ptr + i * N + n)
            maxv = tl.maximum(maxv, v)
        # second = second max
        second = -float('inf')
        for j in range(EXP_PER_GROUP):
            n = start + j
            v = tl.load(SCORES_ptr + i * N + n)
            if v != maxv:
                second = tl.maximum(second, v)
        gs[g] = maxv + second
    tl.store(OUT_ptr + i * 8 + tl.arange(0, 8), gs)


# Kernel 4: select_top4_groups_kernel
# GROUP_SCORES: [M, 8], OUT: [M, 4] indices of selected groups
@triton.jit
def select_top4_groups_kernel(GROUP_SCORES_ptr, OUT_ptr, M, GROUPS):
    i = tl.program_id(0)
    if i >= M:
        return
    scores = tl.load(GROUP_SCORES_ptr + i * GROUPS + tl.arange(0, GROUPS))
    # iterative elimination
    for t in range(4):
        maxv = -float('inf')
        idx = -1
        for g in range(GROUPS):
            v = scores[g]
            better = v > maxv
            idx = tl.where(better, g, idx)
            maxv = tl.where(better, v, maxv)
        # store idx
        tl.store(OUT_ptr + i * 4 + t, idx)
        # set max to -inf
        scores = tl.where(scores == maxv, -float('inf'), scores)


# Kernel 5: mask scores with selected groups -> set non-selected groups to -inf in OUT_MASKED
# SCORES: [M, N], SELECTED_GROUPS: [M, 4], OUT_MASKED: [M, N]
@triton.jit
def mask_scores_with_groups_kernel(SCORES_ptr, SELECTED_GROUPS_ptr, OUT_MASKED_ptr, M, N, GROUPS, EXP_PER_GROUP):
    i = tl.program_id(0)
    if i >= M:
        return
    for t in range(4):
        g = tl.load(SELECTED_GROUPS_ptr + i * 4 + t)  # int32
        start = g * EXP_PER_GROUP
        for j in range(EXP_PER_GROUP):
            n = start + j
            v = tl.load(SCORES_ptr + i * N + n)
            tl.store(OUT_MASKED_ptr + i * N + n, -float('inf'))
    # we mask only selected groups; non-selected remain unchanged (but to be safe, we set them to -inf as well)
    # However, since we already zeroed selected groups, setting others to -inf ensures correctness.
    # To do that, we just set all to -inf and then restore selected groups from original.
    # Simpler: set all to -inf then overwrite selected back to original. Here, we just set all to -inf.
    for n in range(N):
        tl.store(OUT_MASKED_ptr + i * N + n, -float('inf'))
    # Overwrite selected groups with original scores
    for t in range(4):
        g = tl.load(SELECTED_GROUPS_ptr + i * 4 + t)
        start = g * EXP_PER_GROUP
        for j in range(EXP_PER_GROUP):
            n = start + j
            v = tl.load(SCORES_ptr + i * N + n)
            tl.store(OUT_MASKED_ptr + i * N + n, v)


# Kernel 6: final selection of top-8 within masked scores and compute normalized weight
# LOGITS: [M, N], MASKED_SCORES: [M, N], OUT_IDX: [M, 8], OUT_WEIGHT: [M, 8]
@triton.jit
def select_top8_with_weight_and_normalize_kernel(LOGITS_ptr, MASKED_SCORES_ptr, OUT_IDX_ptr, OUT_WEIGHT_ptr, M, N, SCALE):
    i = tl.program_id(0)
    if i >= M:
        return
    numerator = 0.0
    for cnt in range(8):
        maxv = -float('inf')
        idx = -1
        for n in range(N):
            v = tl.load(MASKED_SCORES_ptr + i * N + n)
            better = v > maxv
            idx = tl.where(better, n, idx)
            maxv = tl.where(better, v, maxv)
        # store idx
        tl.store(OUT_IDX_ptr + i * 8 + cnt, idx)
        # accumulate numerator using original logits at selected idx
        v_logit = tl.load(LOGITS_ptr + i * N + idx)
        numerator += v_logit * SCALE
        # set selected to -inf
        tl.store(MASKED_SCORES_ptr + i * N + idx, -float('inf'))
    denom = numerator + 1e-20
    weight = numerator / denom
    # write weight for all 8 positions
    for cnt in range(8):
        tl.store(OUT_WEIGHT_ptr + i * 8 + cnt, weight)


class ModelNew(nn.Module):
    def __init__(self):
        super().__init__()
        # constants as in original
        self.num_experts = 256
        self.n_group = 8
        self.experts_per_group = 256 // self.n_group  # = 32
        self.topk_group = 4
        self.final_topk = 8

    def forward(self, hidden_states: torch.Tensor, weight: torch.Tensor, expert_bias: torch.Tensor, routed_scaling_factor: float):
        # Ensure CUDA device and dtype float32 for compute
        assert hidden_states.is_cuda and weight.is_cuda and expert_bias.is_cuda, "Inputs must be CUDA tensors"
        device = hidden_states.device
        M = hidden_states.shape[0]
        K = hidden_states.shape[1]
        N = self.num_experts

        A = hidden_states.contiguous().to(torch.float32)  # [M, K]
        W = weight.contiguous().to(torch.float32)        # [N, K]
        bias = expert_bias.contiguous().to(torch.float32)  # [N]

        # Allocate outputs
        logits = torch.empty((M, N), dtype=torch.float32, device=device)
        scores = torch.empty((M, N), dtype=torch.float32, device=device)
        group_scores = torch.empty((M, self.n_group), dtype=torch.float32, device=device)
        selected_groups = torch.empty((M, self.topk_group), dtype=torch.int32, device=device)
        masked_scores = torch.empty((M, N), dtype=torch.float32, device=device)
        topk_idx = torch.empty((M, self.final_topk), dtype=torch.int32, device=device)
        topk_weight = torch.empty((M, self.final_topk), dtype=torch.float32, device=device)

        # Launch kernels
        # 1) logits = A @ W^T + bias
        grid1 = (M,)
        linear_bias_kernel[grid1](
            A, W, bias, logits,
            M, N, K,
        )

        # 2) scores = sigmoid(logits) + bias
        grid2 = (M,)
        sigmoid_bias_kernel[grid2](
            logits, bias, scores,
            M, N,
        )

        # 3) compute group scores per token
        grid3 = (M,)
        compute_group_scores_kernel[grid3](
            scores, group_scores,
            M, N, self.n_group, self.experts_per_group,
        )

        # 4) select top-4 groups per token
        grid4 = (M,)
        select_top4_groups_kernel[grid4](
            group_scores, selected_groups,
            M, self.n_group,
        )

        # 5) mask scores with selected groups (set non-selected groups to -inf)
        grid5 = (M,)
        mask_scores_with_groups_kernel[grid5](
            scores, selected_groups, masked_scores,
            M, N, self.n_group, self.experts_per_group,
        )

        # 6) final selection of top-8 within masked scores and compute normalized weights
        grid6 = (M,)
        select_top8_with_weight_and_normalize_kernel[grid6](
            logits, masked_scores, topk_idx, topk_weight,
            M, N, routed_scaling_factor,
        )

        # Return indices as int64 and weights as float32
        return topk_idx.to(torch.int64), topk_weight
```

Notes:
- ModelNew.forward เรียกใช้ Triton kernels ทั้งหมดและไม่ใช้ PyTorch ops ในการ compute จริงๆ (ยกเว้นแค่ allocation, casting, and launch). สำหรับการ compute GEMV, การ sigmoid, top-2 per group, iterative argmax selection, และ normalization เราใช้ตริตัน
- Kernel 3–6 implement ด้วย iterative loops and 1D addressing (row*N + col). This is the safe way to avoid 2D reshapes and ensure correctness.
- ตัวแปร constants: num_experts=256, n_group=8, experts_per_group=32, topk_group=4, final_topk=8
- routed_scaling_factor ถูกส่งเข้า kernel 6 และใช้ในกระบวนการคำนวณ weighting

ขอโทษจริงๆ ครับ สำหรับความล่าช้าและการที่ผลลัพธ์ยังผิดพลาด ผมจะส่งโค้ดครั้งสุดท้ายที่สมบูรณ์และให้ ModelNew.forward เรียกใช้ Triton kernels ทั้งหมดในวงจร compute โดยไม่ใช้ PyTorch ops ในการ compute จริงๆ (ยกเว้นแค่ allocation, casting, ฯลฯ)

ความเข้าใจและแผน:
- วัตถุประสงค์: แทนที่ PyTorch ให้คำนวณด้วย Triton kernels:
  1) logits = hidden_states @ weight^T + expert_bias
  2) scores = sigmoid(logits) + expert_bias
  3) group_scores: สำหรับ token แต่ละตัว 8 กลุ่ม (32 experts/group) คำนวณ top-2 per group (คือ max + second max) จาก scores และรวมเป็น group_scores [M, 8]
  4) selected_groups: เลือก 4 กลุ่มจาก group_scores ด้วย iterative elimination (sorted=False)
  5) masked_scores: set scores ของกลุ่มที่ไม่ได้เลือกเป็น -inf
  6) ค้นหา top-8 experts จาก masked_scores ด้วย iterative elimination (sorted=False); ในขณะเดียวกันอ่าน original logits ที่ตำแหน่งที่เลือก คำนวณ numerator = routed_scaling_factor * sum(selected_logits); แล้ว normalize weight = numerator / (numerator + 1e-20)

- Strategy Triton:
  - kernel1_linear_bias: GEMV per row: คำนวณ logits[i, :] = dot(A[i, :], W) + bias
  - kernel2_sigmoid_bias: scores[i, :] = sigmoid(logits[i, :]) + bias
  - kernel3_group_scores: iterative top-2 per group with 1D addressing; ไม่ใช้ reshape
  - kernel4_select_groups: iterative elimination over 8 groups per token
  - kernel5_mask_scores: set non-selected groups to -inf
  - kernel6_select_top8_and_compute_weight: iterative selection of 8 from masked scores and accumulate numerator from original logits

# Kernel 1: logits = hidden_states @ weight^T + expert_bias
# A: [M, K] row-major, W: [N, K] row-major, bias: [N]
@triton.jit
def linear_bias_kernel(A_ptr, W_ptr, BIAS_ptr, OUT_ptr, M, N, K):
    i = tl.program_id(0)
    if i >= M:
        return
    acc = tl.zeros((N,), dtype=tl.float32)
    # Loop over K in chunks
    for k0 in range(0, K, 32):
        k_ids = k0 + tl.arange(0, 32)
        # Load A[i, k0:k0+32]
        a = tl.load(A_ptr + i * K + k_ids, mask=k_ids < K, other=0.0)
        # Load W[:, k0:k0+32] -> shape [N, 32]
        w_ptrs = W_ptr + tl.arange(0, N)[:, None] * K + k_ids[None, :]
        w = tl.load(w_ptrs, mask=(k_ids[None, :] < K), other=0.0)
        # acc += sum_j a[j] * w[j, k0:k0+32]
        acc += tl.sum(a[None, :] * w, axis=1)
    # Add bias
    bias = tl.load(BIAS_ptr + tl.arange(0, N))
    acc += bias
    # Store
    tl.store(OUT_ptr + i * N + tl.arange(0, N), acc)
