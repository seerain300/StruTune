  - To prevent recurrence, all Triton kernels must be defined, compiled, and actually launched from ModelNew.forward. No PyTorch ops in host code (except for creating inputs/outputs and tensor metadata like .contiguous(), .to(dtype), .view()).

    1) logits = hidden_states @ weight^T + expert_bias
    2) scores = sigmoid(logits) + expert_bias
    3) Group top-2 per group of 32 and sum -> group_scores [M, 8]
    4) Select top-4 groups per token
    5) Mask out experts not in selected groups (set to -inf)
    6) Select top-8 experts from masked scores, normalize by sum of selected logits, apply scaling factor
    We will implement each step in Triton kernels: linear+bias, sigmoid, group_scores, group selection, masking, and final top-8 selection + normalize + scaling.

- Plan:

# Robust vectorized Triton kernel: compute group_scores [M, n_group] by sum of top-2 per group of 32 experts
@triton.jit
def compute_group_scores_vec_kernel(
    SCORES_ptr,    # *fp32 [M, N]
    GROUP_OUT_ptr, # *fp32 [M, n_group]
    M: tl.constexpr,
    N: tl.constexpr,
    n_group: tl.constexpr,
    experts_per_group: tl.constexpr,
    stride_sm, stride_sn,
    stride_gm, stride_gn,
):
    pid_m = tl.program_id(0)
    pid_g = tl.program_id(1)
    start_exp = pid_g * experts_per_group

    # Load all 32 scores for this group into a vector
    idxs = start_exp + tl.arange(0, experts_per_group)
    mask = idxs < N
    vals = tl.load(SCORES_ptr + pid_m * stride_sm + idxs * stride_sn, mask=mask, other=-1.0e30)

    # Compute top-2 sum
    # Sort the vector descending: bubble sort (simple and correct for small fixed size)
    # Note: Sorting in Triton is done by data movement; we implement a fixed-size sort.
    size = experts_per_group  # 32
    for i in range(size):
        for j in range(size - 1, i, -1):
            a = vals[j - 1]
            b = vals[j]
            cond = b > a
            vals = tl.where(cond, [a, b], [b, a])

    top2_sum = vals[0] + vals[1]
    tl.store(GROUP_OUT_ptr + pid_m * stride_gm + pid_g * stride_gn, top2_sum)
