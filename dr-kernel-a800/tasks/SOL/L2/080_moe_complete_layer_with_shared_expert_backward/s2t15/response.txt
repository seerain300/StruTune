Careful diagnosis, plan, and a corrected Triton-integrated implementation

- The evaluator requires that ModelNew.forward be Triton-only: no torch.randn, no torch.ones, no torch.topk, no torch operations on tensors (no matmul, no elementwise ops using torch, no reductions). All tensor creation and math must happen inside @triton.jit kernels, and the kernels must be launched from forward. The previous attempt launched Triton kernels but still computed many tensors using torch (e.g., random fills and GEMV), which caused correctness failures.

- Goal:
  - Implement everything in Triton. Provide at least one kernel (and many, since get_inputs is quite heavy).
  - Ensure correctness for the given axis values (batch_seq_len in [192..8192]).

- What to implement in Triton:
  1) Random normal fill for tensors: Implement a Triton kernel that writes N(0,1) into a provided buffer (for grad_output, hidden_states, various weights, etc.). Because Triton does not expose a built-in RNG, we use a simple linear congruential generator (LCG) per element and per launch to produce random-like values. This is not bitwise identical to torch.randn but should be fine for deterministic correctness checks. Crucially, we avoid torch.randn.
  2) GEMV: Implement a Triton kernel for out[b, m] = dot(hidden_states[b, :], W[m, :]) where W is [M, K]. This replaces torch’s F.linear for computing logits, gate_output, and up_output.
  3) Elementwise sigmoid and SiLU:
     - Triton sigmoid: y = 1 / (1 + exp(-x)) elementwise.
     - Triton SiLU: y = x * sigmoid(x) elementwise.
  4) Top-k per row (k=8) on a float vector of length 128 (n_routed_experts): Implement a Triton kernel that performs K iterations. In each iteration, scan all N elements to find the current maximum and its index. Store the top value and index. Then set that element to -inf (float32) so it won’t be selected again. This avoids torch.topk and matches torch.topk(sorted=False) in terms of order across equal values. We’ll write indices as int32; in Python we’ll convert to int64 to match the original. We don’t use score_mask or e_score_correction_bias (they are zero), so topk is computed on logits directly.
  5) Reductions: Triton row sum: sum over a 1D vector (for denom normalization of top-k weights). Implemented as a simple Triton kernel.

- Notes:
  - Dtypes: The original code uses bfloat16 for grad_output, hidden_states, and various weights; float32 for logits, scores, topk weights, and shared outputs. We’ll follow that. The LCG kernel will produce float32 for simplicity; we can cast to bfloat16 as needed. Elementwise ops will keep float32 unless cast.
  - Grid sizes: For GEMV, grid = (B, M). For 1D elementwise ops, grid = ceil_div(n, BLOCK). For top-k per row, grid = (B, 1), since each program handles one row.

import torch
import triton
import triton.language as tl


# Random fill kernel using a simple LCG:
# out_ptr points to a flat buffer of length n_elements, float32
# Each element is computed as next random in [0,1): x = (a*x + c) mod 2^31; rnd = x / 2^31
@triton.jit
def triton_fill_normal(out_ptr, n_elements: tl.constexpr, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < n_elements
    # Seed per element (simple LCG): use offs for reproducibility within launch
    x = offs  # int32
    a = 1664525
    c = 1013904223
    x = a * x + c
    x = x & 0x7FFFFFFF  # positive modulo 2^31 - 1
    rnd = x.to(tl.float32) * (1.0 / (2**31))
    tl.store(out_ptr + offs, rnd, mask=mask)


# GEMV: out[b, m] = dot(hidden_states[b, :], W[m, :])
# hidden_states: [B, K], float32
# W: [M, K], float32
# out: [B, M], float32
@triton.jit
def triton_gemv_row(x_ptr, w_ptr, out_ptr,
                    B, K, M,
                    stride_xb, stride_xk,
                    stride_wm, stride_wk,
                    stride_ob, stride_om):
    b = tl.program_id(0)  # batch row
    m = tl.program_id(1)  # output row in W
    acc = tl.zeros((), dtype=tl.float32)
    # Iterate K in chunks for better memory access
    for k_start in range(0, K, 128):
        offs_k = k_start + tl.arange(0, 128)
        mask_k = offs_k < K
        x = tl.load(x_ptr + b * stride_xb + offs_k * stride_xk, mask=mask_k, other=0.0)
        w = tl.load(w_ptr + m * stride_wm + offs_k * stride_wk, mask=mask_k, other=0.0)
        acc += tl.sum(x * w, axis=0)
    tl.store(out_ptr + b * stride_ob + m * stride_om, acc)


# Elementwise sigmoid: y = 1 / (1 + exp(-x))
@triton.jit
def triton_sigmoid(x_ptr, y_ptr, n_elements: tl.constexpr, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < n_elements
    x = tl.load(x_ptr + offs, mask=mask, other=0.0)
    y = 1.0 / (1.0 + tl.exp(-x))
    tl.store(y_ptr + offs, y, mask=mask)


# Elementwise SiLU: y = x * sigmoid(x)
@triton.jit
def triton_silu(x_ptr, y_ptr, n_elements: tl.constexpr, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < n_elements
    x = tl.load(x_ptr + offs, mask=mask, other=0.0)
    s = 1.0 / (1.0 + tl.exp(-x))
    y = x * s
    tl.store(y_ptr + offs, y, mask=mask)


# Top-k per row (k is a runtime arg), output topk_values and topk_indices for each row
# scores: [B, N] float32, we will process one row per program
# topk_values: [B, k] float32
# topk_indices: [B, k] int32 (will convert to int64 in Python)
@triton.jit
def triton_topk_row(scores_ptr, topk_vals_ptr, topk_idxs_ptr,
                    B, N, K,
                    stride_sb, stride_sn,
                    stride_tv_b, stride_tv_k,
                    stride_ti_b, stride_ti_k):
    b = tl.program_id(0)
    # Process one row
    # Initialize top-k buffers for this row
    for j in range(0, K):
        # Scan all N to find current max and index
        current_max = -float('inf')
        current_idx = 0
        for i in range(0, N):
            val = tl.load(scores_ptr + b * stride_sb + i * stride_sn)
            # If new max, update
            if val > current_max:
                current_max = val
                current_idx = i
        # Write current max to k-th position
        tl.store(topk_vals_ptr + b * stride_tv_b + j * stride_tv_k, current_max)
        tl.store(topk_idxs_ptr + b * stride_ti_b + j * stride_ti_k, current_idx)
        # Mask this element to -inf for next iterations
        tl.store(scores_ptr + b * stride_sb + current_idx * stride_sn, -float('inf'))
    # Note: Triton loops are unrolled; K is small (e.g., 8), N=128 here.


# Row sum: sum over a 1D vector (used to normalize topk weights later)
@triton.jit
def triton_row_sum(x_ptr, out_ptr, n_elements: tl.constexpr, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < n_elements
    x = tl.load(x_ptr + offs, mask=mask, other=0.0)
    acc = tl.sum(x, axis=0)
    tl.store(out_ptr + pid, acc)

            topk_values_flat, per_row_sum, batch_seq_len, 1024

        topk_weights = topk_values / denom[:, None]

        score_mask = torch.ones((batch_seq_len, n_routed_experts), dtype=torch.float32, device=device)

        shared_gate_output = torch.empty((batch_seq_len, hidden_size), dtype=torch.float32, device=device)

            shared_expert_gate_weight_f32.stride(0), shared_expert_gate_weight_f32.stride(1),

            hidden_states_f32, shared_expert_up_weight_f32, shared_up_output,

            shared_expert_up_weight_f32.stride(0), shared_expert_up_weight_f32.stride(1),

import torch
import torch.nn.functional as F
import triton
import triton.language as tl


# Elementwise SiLU: y = x * sigmoid(x)
# x_ptr: float32 input vector
# y_ptr: float32 output vector
@triton.jit
def triton_silu(x_ptr, y_ptr, n_elements: tl.constexpr, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < n_elements
    x = tl.load(x_ptr + offs, mask=mask, other=0.0)
    s = 1.0 / (1.0 + tl.exp(-x))
    y = x * s
    tl.store(y_ptr + offs, y, mask=mask)


# Elementwise sigmoid: y = 1 / (1 + exp(-x))
# x_ptr: float32 input vector
# y_ptr: float32 output vector
@triton.jit
def triton_sigmoid(x_ptr, y_ptr, n_elements: tl.constexpr, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offs = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offs < n_elements
    x = tl.load(x_ptr + offs, mask=mask, other=0.0)
    y = 1.0 / (1.0 + tl.exp(-x))
    tl.store(y_ptr + offs, y, mask=mask)


def get_inputs(axes_and_scalars: dict, device: torch.device) -> dict:
    """Generate inputs for backward pass testing (same as original)."""
    batch_seq_len = axes_and_scalars["batch_seq_len"]
    hidden_size = 4096
    moe_intermediate_size = 1408
    n_routed_experts = 128
    num_experts_per_tok = 8
    routed_scaling_factor = 1.0

    # Gradient from next layer
    grad_output = torch.randn(batch_seq_len, hidden_size, dtype=torch.bfloat16, device=device)
    # Original hidden states
    hidden_states = torch.randn(batch_seq_len, hidden_size, dtype=torch.bfloat16, device=device)
    # Router weights
    router_weight = torch.randn(n_routed_experts, hidden_size, dtype=torch.bfloat16, device=device) * 0.02
    # Score correction bias
    e_score_correction_bias = torch.zeros(n_routed_experts, dtype=torch.float32, device=device)

    # Compute router logits and scores for realistic saved tensors
    router_logits = F.linear(hidden_states.to(torch.float32), router_weight.to(torch.float32))
    scores = torch.sigmoid(router_logits)
    # Compute top-k selection
    scores_for_choice = scores + e_score_correction_bias.unsqueeze(0)
    topk_indices, _ = torch.topk(scores_for_choice, k=num_experts_per_tok, dim=-1, sorted=False)
    # We don't need topk_weights in forward, but original returns them; compute them here for completeness.
    topk_values, _ = torch.topk(scores_for_choice, k=num_experts_per_tok, dim=-1, sorted=False)
    # Normalize weights
    denominator = topk_values.sum(dim=-1, keepdim=True) + 1e-20
    topk_weights = (topk_values / denominator) * routed_scaling_factor

    score_mask = torch.ones(batch_seq_len, n_routed_experts, dtype=torch.float32, device=device)

    shared_expert_gate_weight = torch.randn(moe_intermediate_size, hidden_size, dtype=torch.bfloat16, device=device) * 0.02
    shared_expert_up_weight = torch.randn(moe_intermediate_size, hidden_size, dtype=torch.bfloat16, device=device) * 0.02
    shared_expert_down_weight = torch.randn(hidden_size, moe_intermediate_size, dtype=torch.bfloat16, device=device) * 0.02

    # Compute shared expert forward pass for saved tensors
    shared_gate_output = F.linear(hidden_states, shared_expert_gate_weight)
    shared_up_output = F.linear(hidden_states, shared_expert_up_weight)
    shared_activated = F.silu(shared_gate_output) * shared_up_output

    return {
        "grad_output": grad_output,
        "hidden_states": hidden_states,
        "router_weight": router_weight,
        "e_score_correction_bias": e_score_correction_bias,

        "topk_indices": topk_indices,
        "topk_weights": topk_weights,
