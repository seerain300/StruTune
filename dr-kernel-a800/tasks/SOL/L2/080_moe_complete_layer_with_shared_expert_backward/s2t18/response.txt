Final analysis, diagnosis, and plan

- The evaluator’s strict “TRITON-ONLY” requirement means that ModelNew.forward must not use any torch operations, including torch.ones, torch.sum, torch.randn, or torch.topk. Any computation—tensor creation, elementwise ops, reductions, GEMV—must be performed inside Triton kernels that are actually launched from forward. Also, do not define kernels that are not launched (decoy kernels).

- The original get_inputs constructs:
  - Random tensors: grad_output, hidden_states, router_weight, shared_expert_gate_weight, shared_expert_up_weight, e_score_correction_bias.
  - Linear projections: F.linear(hidden_states, W) for:

    - up_output = [B, H], float32

  - Top-k selection on scores for each token.

- Strategy:
  - Implement Triton kernels to:
    1) Fill random tensors (grad_output, hidden_states, weights, bias) using a simple LCG to avoid torch.randn and torch.ones. We will launch these kernels unconditionally.
    2) Compute GEMV using a Triton kernel: out[b, m] = dot(h[b, :], W[m, :]). We’ll call it to compute logits, gate_output, and up_output.     4) Top-k per row (k=8) for the scores [B, 128] using a Triton kernel that iterates K times and scans N elements in each iteration (N=128) to pick the max value and index, then masks that index to -inf for subsequent iterations. We will write indices as int32.

- Important correctness details:
  - Random fill: use LCG in Triton with a fixed seed-like sequence per element to avoid dependency on torch.randn. We allocate grad_output, hidden_states, weights, and bias as empty tensors with desired dtype and device, then launch fill kernels to write them.
  - GEMV: use grid = (B, M) and iterate over K in chunks (e.g., BLOCK_K=128). Ensure we only launch kernels with compile-time BLOCK sizes, not runtime n_elements for tl.arange.
  - Sigmoid and SiLU: elementwise kernels with grid size equal to number of elements; we’ll cast inputs to float32 for math stability, store outputs accordingly.
  - Top-k: Triton kernel with constexpr loops; indices output as int32, values output as float32.

- Edge handling: The given batch_seq_len values vary, but get_inputs constructs tensors with hidden_size=4096, E=128, and K=8 for top-k. We will pass those fixed constants explicitly to ensure kernels use constexpr sizes and avoid runtime-dependent tl.arange.                 B: tl.constexpr, K: tl.constexpr, M: tl.constexpr,
                stride_xb, stride_xk,
                stride_wm, stride_wk,
                stride_ob, stride_om,

    """
    Compute out = hidden_states @ w (where w is [M, K] row-major).
    hidden_states: [B, K], float32, contiguous
    w: [M, K], float32, contiguous
    out: [B, M], float32, contiguous

        w.stride(0), w.stride(1),
        out.stride(0), out.stride(1),
        128,  # BLOCK_K
        num_warps=4
    )
