- Constraints and feasibility:

  - The expert_offsets can be computed exactly using Triton histogram and an exclusive prefix sum (bases), and then forming the final offsets tensor by using bases as exclusive prefix sums and appending N. This avoids torch.cumsum entirely.

- Design:

  2) Triton exclusive_scan_bases_kernel: computes bases[i] = sum_{w < i} counts[w] for i in [0..L-1].
