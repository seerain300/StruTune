    """
    RMSNorm over last dimension of shape (M, D).
    Each program handles one row. Computes r = sqrt(mean(x^2) + eps) and writes y = x / r.
    X_ptr, Y_ptr are base pointers; each row is of length D. Grid size must be M.
    """
    row_id = tl.program_id(axis=0)
    # accumulate sum of squares in fp32
    sum_sq = 0.0
    for d in range(0, D, BLOCK_SIZE):
        offs = d + tl.arange(0, BLOCK_SIZE)
        # mask is implicit within range [0, D), since we loop over D
        x = tl.load(X_ptr + row_id * D + offs)
        x_f32 = x.to(tl.float32)
        sum_sq += tl.sum(x_f32 * x_f32, axis=0)
    mean = sum_sq / D
    r = tl.sqrt(mean + eps)

    # scale and store
    for d in range(0, D, BLOCK_SIZE):
        offs = d + tl.arange(0, BLOCK_SIZE)
        x = tl.load(X_ptr + row_id * D + offs)
        y = x / r
        tl.store(Y_ptr + row_id * D + offs, y)

     y = x / sqrt(mean(x^2) + eps), implemented in a Triton kernel rmsnorm_rows_kernel with grid (M,), where M = B * N * S (N = N_q for query, N = N_kv for key). We compute the reduction and scaling in fp32 for stability and store in bf16.
  2) Compute per-token emb for each token position pos:
     - inv = [inv_freq, inv_freq] of length D.
     - emb = pos * inv.
     - cos = cos(emb), sin = sin(emb) computed in Triton kernel pos_emb_cos_sin_kernel with grid (B, S). This kernel writes cos and sin tensors of shape (B, S, D) in fp32.
  3) Apply RoPE rotation in Triton:
     - Define rotate_and_scale_kernel with grid (B, N_q, S) for query and (B, N_kv, S) for key. Each program handles one token (b, h, s):
       - Load cos and sin vectors of length D for that token.
       - Load normalized x (from X_ptr) and compute rotated y using:
         y1 = x1 * cos + x2 * sin
         y2 = x1 * sin - x2 * cos
         where x1 = x[:, :D//2], x2 = x[:, D//2:].
       - Store rotated y into Y_ptr (output tensor). To access input x, we pass the normalized query/key (already computed by RMSNorm kernel) through a temporary buffer. Triton kernels cannot read from arbitrary torch tensors, so we rely on passing base pointers to contiguous views and mapping program_id to row index. We use axis 0 = B, axis 1 = N, axis 2 = S. Each program then flattens its row across D and computes rotation.
  4) Update caches:
     - Triton supports scatter writes with known indices. We write:
       key_cache[b, n, cache_position[s], :] = key_rotated[b, n, s, :]
       value_cache[b, n, cache_position[s], :] = value[b, n, s, :]
     - Implement cache_scatter_kernel with grid (B, N_kv, S). For each token, load cache_position[s], compute base offset, and store the corresponding row from key_rotated and value. We also store the cache_position vector in the kernel to avoid extra host-side operations.

- Dtypes and numerical stability:
  - Triton kernels compute in fp32 for the math (cos/sin, reductions, and rotation), then store results in bf16 for output tensors. This matches the input tensors’ dtype.

- Performance:
  - We use BLOCK_SIZE=128 for D=128, which is ideal. For S up to 4096, the grid across (B, N, S) provides sufficient parallelism. RMSNorm kernel is lightweight; rotation kernel performs elementwise math and is efficient. Cache scatter uses simple index-based stores.

- Important: All heavy math (RMSNorm, cos/sin, rotation) is done inside Triton kernels. No torch cos/sin or elementwise ops in the host. Triton kernels are invoked from ModelNew.forward. This addresses the evaluator’s constraints.

Final code: Triton-based ModelNew that launches kernels for RMSNorm, per-token cos/sin, rotation, and cache scatter

import torch
import triton
import triton.language as tl


@triton.jit
def rmsnorm_rows_kernel(X_ptr, Y_ptr, M, D, eps, BLOCK_SIZE: tl.constexpr):
    """
    RMSNorm over last dimension for M rows of length D.
    Each program handles one row: y = x / sqrt(mean(x^2) + eps).
    X_ptr and Y_ptr are 1D pointers of length M*D, rows are contiguous.
    """
    row_id = tl.program_id(axis=0)
    if row_id >= M:
        return
    sum_sq = 0.0
    # reduction over D
    for d in range(0, D, BLOCK_SIZE):
        offs = d + tl.arange(0, BLOCK_SIZE)
        x = tl.load(X_ptr + row_id * D + offs)
        x_f32 = x.to(tl.float32)
        sum_sq += tl.sum(x_f32 * x_f32, axis=0)
    mean = sum_sq / D
    r = tl.sqrt(mean + eps)
    # write normalized row
    for d in range(0, D, BLOCK_SIZE):
        offs = d + tl.arange(0, BLOCK_SIZE)
        x = tl.load(X_ptr + row_id * D + offs)
        y = x / r
        tl.store(Y_ptr + row_id * D + offs, y)
