- Target computation to implement:
  - RMSNorm on query and key: For each row x of shape [D], compute scale = 1 / sqrt(mean(x^2) + eps), then y = (x * scale) * weight, where weight is a per-dim vector (q_norm_weight for query, k_norm_weight for key).   - Rotary embedding (RotE): For each token s, set pos = cache_len + s. The embedding vector emb is formed as [pos * inv_freq, pos * inv_freq], where inv_freq is of length HALF = D // 2 and is the same as head_dim // 2 (64). Then compute cos and sin from emb. The rotated output x' is x * cos + rotate_half(x) * sin, where rotate_half swaps and negates the second half: rotate_half(x) = [-x2, x1] for x split into x1 = x[..., :HALF], x2 = x[..., HALF:].
