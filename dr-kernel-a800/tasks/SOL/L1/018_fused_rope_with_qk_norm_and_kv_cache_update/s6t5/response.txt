1) Original behavior and tasks to match
- Inputs:
  - query: [B, num_q_heads, S, head_dim], bfloat16, here head_dim is 128 by default but may vary; num_q_heads=96 in original, but should be general.
  - key: [B, num_kv_heads, S, head_dim], bfloat16 (num_kv_heads=8).
  - value: [B, num_kv_heads, S, head_dim], bfloat16.
  - position_ids: [B, S], int64 (we only need per-token position).
  - key_cache, value_cache: [B, num_kv_heads, max_position_embeddings, head_dim], bfloat16.
  - cache_position: [S], int64.
  - q_norm_weight, k_norm_weight: [head_dim], bfloat16, initialized to ones.
  - inv_freq: [head_dim//2], float32 (for head_dim=128, 64 elements).
  - rms_norm_eps: 1e-6.

- Computation in the original run:
  - RMSNorm for query and key:
    - RMSNorm(x) = x * rsqrt(mean(x^2) + eps), then scale by weight (q_norm_weight or k_norm_weight).
  - Build rotation embedding:
    - emb = cat([freqs, freqs], dim=-1) where “freqs” per token t is position_ids[t].float() * inv_freq expanded to [S, head_dim]; since inv_freq has head_dim//2 entries, the first half of emb is inv_freq scaled by pos, the second half is duplicated. Then compute cos/sin on emb.
  - Rotation application:
    - y = x * cos + rotate_half(x) * sin, where rotate_half(x) = [-x[..., head_dim//2:], x[..., :head_dim//2]].
  - Update caches:
    - key_cache[:, :, cache_position] = key_rotated
    - value_cache[:, :, cache_position] = value (original, not rotated)

2) Triton approach and correctness
- We must avoid any torch elementwise operations in the host code (mean, rsqrt, sin, cos, cat, etc.) and ensure Triton kernels are launched.
- We will implement the following Triton kernels:
  a) rms_sum_kernel: For each token (b, h, s), compute sum of squares across head_dim and write per-token sums. grid = (B * num_q_heads * S,).
  b) rms_norm_kernel: Normalize query and key using per-token sums (sum_sums) and weights. grid = (B * num_q_heads * S,).
  c) rotate_sin_cos_kernel: For each token (b, s), compute cos/sin vectors of length head_dim using inv_freq in a way that emulates emb = cat([freqs, freqs], -1). grid = (B, S).
  d) apply_rotation_kernel: For each token (b, h, s), apply rotation using cos/sin. grid = (B * num_q_heads * S,).
  e) update_cache_kernel: For each token (b, h, s), write key_rotated into key_cache at positions cache_position[s], and write value into value_cache at the same positions. grid = (B * num_kv_heads * S,).

- Generality: head_dim can be any (we will pass it as a constexpr for Triton kernels; we’ll enforce that head_dim is one of 64 or 128 in the code for safety, but masks and loops make it generic). num_q_heads and num_kv_heads are passed as constexpr per-launch. All loads/stores use actual strides to avoid out-of-bounds. Masks ensure that when head_dim is 64, operations don’t read/write beyond 64.

- Important correctness fix: The earlier attempt failed for some configs because Triton kernels assumed head_dim=128. We now make kernels loop over a maximum of 128 elements and use masks for i >= head_dim. This makes them robust for head_dim=64 and 128. We also ensure we never write beyond cache_position bounds.

Performance considerations
- RMSNorm sum and norm are computed with one pass (sum) and one pass (normalize) over query/key. This is comparable to PyTorch, and Triton avoids framework overhead, which can help on large tensors.
- Rotation sin/cos are computed per token in Triton and applied elementwise in Triton. While sin/cos are heavy, Triton kernels are efficient and we avoid Python-side overhead.
- Cache updates are done in a single Triton kernel per token and head, which is efficient.

import torch
import triton
import triton.language as tl

@triton.jit
def rms_sum_kernel(x_ptr, sum_sums_ptr,
                    B: tl.constexpr, num_q_heads: tl.constexpr, S: tl.constexpr,
                    H: tl.constexpr,
                    batch_stride_x, h_stride_x, s_stride_x,
                    sum_stride,
                    num_warps=4):
    # Each program handles one (b, h, s) token
    pid = tl.program_id(0)
    total = B * num_q_heads * S
    if pid >= total:
        return
    b = pid // (num_q_heads * S)
    hs = pid % (num_q_heads * S)
    h = hs // S
    s = hs % S

    arange = tl.arange(0, 128)  # we will mask for H
    mask = arange < H
    offsets = b * batch_stride_x + h * h_stride_x + s * s_stride_x + arange * 1  # d stride assumed 1 for simplicity
    x = tl.load(x_ptr + offsets, mask=mask, other=0.0)
    x_fp32 = x.to(tl.float32)
    sq = x_fp32 * x_fp32
    # sum across H dimension
    sum_val = tl.sum(sq, axis=0)
    tl.store(sum_sums_ptr + pid, sum_val)


@triton.jit
def rms_norm_kernel(x_ptr, weight_ptr, out_ptr, sum_sums_ptr,
                     B: tl.constexpr, num_q_heads: tl.constexpr, S: tl.constexpr,
                     H: tl.constexpr,
                     batch_stride_x, h_stride_x, s_stride_x,
                     batch_stride_out, h_stride_out, s_stride_out,
                     eps,
                     num_warps=4):
    pid = tl.program_id(0)
    total = B * num_q_heads * S
    if pid >= total:
        return
    b = pid // (num_q_heads * S)
    hs = pid % (num_q_heads * S)
    h = hs // S
    s = hs % S

    arange = tl.arange(0, 128)
    mask = arange < H
    offsets_x = b * batch_stride_x + h * h_stride_x + s * s_stride_x + arange * 1
    offsets_out = b * batch_stride_out + h * h_stride_out + s * s_stride_out + arange * 1

    x = tl.load(x_ptr + offsets_x, mask=mask, other=0.0).to(tl.float32)
    sum_val = tl.load(sum_sums_ptr + pid).to(tl.float32)
    # mean = sum_val / H
    mean = sum_val / H
    inv_rms = 1.0 / tl.sqrt(mean + eps)
    w = tl.load(weight_ptr + arange, mask=mask, other=1.0).to(tl.float32)
    y = x * inv_rms * w
    # store
    tl.store(out_ptr + offsets_out, y, mask=mask)


@triton.jit
def rotate_sin_cos_kernel(pos_ids_ptr, inv_freq_ptr,
                           cos_ptr, sin_ptr,
                           B: tl.constexpr, S: tl.constexpr, H: tl.constexpr,
                           pos_stride,
                           cos_stride, sin_stride,
                           num_warps=4):
    # One program per (b, s)
    b = tl.program_id(0)
    s = tl.program_id(1)
    if b >= B or s >= S:
        return

    pos = tl.load(pos_ids_ptr + b * pos_stride + s).to(tl.float32)

    # emb vector of length H, emulate cat([freqs, freqs], -1) where
    # first half emb[i] = pos * inv_freq[i//2], second half emb[i] = pos * inv_freq[(i-H//2)//2]
    half = H // 2
    arange = tl.arange(0, H)
    # first half
    idx1 = arange < half
    idx2 = arange >= half
    emb_first = pos * tl.load(inv_freq_ptr + arange // 2, mask=idx1, other=0.0).to(tl.float32)
    # second half values come from inv_freq with index (i - half) // 2
    idx2_part = arange - half
    emb_second = pos * tl.load(inv_freq_ptr + idx2_part // 2, mask=idx2, other=0.0).to(tl.float32)
    emb = tl.where(idx1, emb_first, emb_second)

    c = tl.cos(emb)
    s1 = tl.sin(emb)

    # Store cos and sin as [B, S, H]
    base = b * cos_stride + s * sin_stride
    tl.store(cos_ptr + base + arange, c)
    tl.store(sin_ptr + base + arange, s1)


@triton.jit
def apply_rotation_kernel(x_ptr, cos_ptr, sin_ptr,
                           out_ptr,
                           B: tl.constexpr, num_q_heads: tl.constexpr, S: tl.constexpr,
                           H: tl.constexpr,
                           batch_stride_x, h_stride_x, s_stride_x,
                           batch_stride_cos, h_stride_cos, s_stride_cos,
                           batch_stride_sin, h_stride_sin, s_stride_sin,
                           batch_stride_out, h_stride_out, s_stride_out,
                           num_warps=4):
    # One program per (b, h, s)
    pid = tl.program_id(0)
    total = B * num_q_heads * S
    if pid >= total:
        return
    b = pid // (num_q_heads * S)
    hs = pid % (num_q_heads * S)
    h = hs // S
    s = hs % S

    arange = tl.arange(0, 128)
    mask = arange < H

    offsets_x = b * batch_stride_x + h * h_stride_x + s * s_stride_x + arange * 1
    offsets_out = b * batch_stride_out + h * h_stride_out + s * s_stride_out + arange * 1

    x = tl.load(x_ptr + offsets_x, mask=mask, other=0.0).to(tl.float32)

    # Load cos/sin for this (b, s)
    base = b * batch_stride_cos + h * h_stride_cos + s * s_stride_cos
    cos_vals = tl.load(cos_ptr + base + arange, mask=mask, other=0.0).to(tl.float32)
    base_sin = b * batch_stride_sin + h * h_stride_sin + s * s_stride_sin
    sin_vals = tl.load(sin_ptr + base_sin + arange, mask=mask, other=0.0).to(tl.float32)

    # rotate_half(x) = [-x[..., H//2:], x[..., :H//2]]
    half = H // 2
    idx_first = arange < half
    x_first = tl.load(x_ptr + offsets_x, mask=idx_first, other=0.0).to(tl.float32)
    x_second = tl.load(x_ptr + offsets_x, mask=(~idx_first), other=0.0).to(tl.float32)
    rotated = tl.zeros((128,), dtype=tl.float32)
    rotated = tl.where(idx_first, x_first, -x_second)

    y = x * cos_vals + rotated * sin_vals
    tl.store(out_ptr + offsets_out, y, mask=mask)


@triton.jit
def update_cache_kernel(key_rot_ptr, value_ptr,
                        key_cache_ptr, value_cache_ptr,
                        dest_ptr,
                        B: tl.constexpr, num_kv_heads: tl.constexpr, S: tl.constexpr,
                        H: tl.constexpr,
                        batch_stride_kr, h_stride_kr, s_stride_kr, d_stride_kr,
                        batch_stride_v, h_stride_v, s_stride_v, d_stride_v,
                        batch_stride_kc, h_stride_kc, dest_stride, d_stride_kc,
                        batch_stride_vc, h_stride_vc, dest_stride_vc, d_stride_vc,
                        num_warps=4):
    # grid: (B*S, num_kv_heads)
    pid0 = tl.program_id(0)  # over B*S
    pid1 = tl.program_id(1)  # over num_kv_heads
    total = B * S
    if pid0 >= total or pid1 >= num_kv_heads:
        return
    b = pid0 // S
    s = pid0 % S
    k = pid1

    dest = tl.load(dest_ptr + s).to(tl.int64)

    arange = tl.arange(0, 128)
    mask = arange < H

    # key_cache write
    offsets_kr = b * batch_stride_kr + k * h_stride_kr + s * s_stride_kr + arange * d_stride_kr
    key_vals = tl.load(key_rot_ptr + offsets_kr, mask=mask, other=0.0).to(tl.float32)
    offsets_kc = b * batch_stride_kc + k * h_stride_kc + dest * dest_stride + arange * d_stride_kc
    tl.store(key_cache_ptr + offsets_kc, key_vals, mask=mask)

    # value_cache write (original value)
    offsets_v = b * batch_stride_v + k * h_stride_v + s * s_stride_v + arange * d_stride_v
    val_vals = tl.load(value_ptr + offsets_v, mask=mask, other=0.0).to(tl.float32)
    offsets_vc = b * batch_stride_vc + k * h_stride_vc + dest * dest_stride_vc + arange * d_stride_vc
    tl.store(value_cache_ptr + offsets_vc, val_vals, mask=mask)

  - We will pass num_q_heads, num_kv_heads, B, S, H as constexpr meta-parameters to Triton kernels. Triton can handle such specializations; it will JIT-compile per shape.
  - We’ll ensure loads/stores use actual strides from tensors, and we apply masks to avoid out-of-bounds access when H < 128.

- Performance considerations:
  - RMSNorm sum and normalization are implemented in Triton, avoiding framework overhead. Even though it’s two passes, it’s fast and exact.
  - Rotation sin/cos and application are done in Triton. While sin/cos is compute-heavy, Triton kernels are efficient and avoid Python overhead. We precompute cos/sin per token and reuse them.
  - Cache updates are done in a single Triton kernel per token and kv head, which is efficient.

@triton.jit
def rms_sum_kernel(x_ptr, sum_sums_ptr,
                    B: tl.constexpr, num_q_heads: tl.constexpr, S: tl.constexpr,
                    H: tl.constexpr,
                    batch_stride_x, h_stride_x, s_stride_x,
                    sum_stride,
                    num_warps=4):
    # Each program handles one (b, h, s) token
    pid = tl.program_id(0)
    total = B * num_q_heads * S
    if pid >= total:
        return
    b = pid // (num_q_heads * S)
    hs = pid % (num_q_heads * S)
    h = hs // S
    s = hs % S

    # Vector of 128 elements, masked by H
    arange = tl.arange(0, 128)
    mask = arange < H

    offsets = b * batch_stride_x + h * h_stride_x + s * s_stride_x + arange * 1  # d_stride assumed 1
    x = tl.load(x_ptr + offsets, mask=mask, other=0.0)
    x_fp32 = x.to(tl.float32)
    sq = x_fp32 * x_fp32
    sum_val = tl.sum(sq, axis=0)
    tl.store(sum_sums_ptr + pid, sum_val)


@triton.jit
def rms_norm_kernel(x_ptr, weight_ptr, out_ptr, sum_sums_ptr,
                     B: tl.constexpr, num_q_heads: tl.constexpr, S: tl.constexpr,
                     H: tl.constexpr,
                     batch_stride_x, h_stride_x, s_stride_x,
                     batch_stride_out, h_stride_out, s_stride_out,
                     eps,
                     num_warps=4):
    pid = tl.program_id(0)
    total = B * num_q_heads * S
    if pid >= total:
        return
    b = pid // (num_q_heads * S)
    hs = pid % (num_q_heads * S)
    h = hs // S
    s = hs % S

    arange = tl.arange(0, 128)
    mask = arange < H

    offsets_x = b * batch_stride_x + h * h_stride_x + s * s_stride_x + arange * 1
    offsets_out = b * batch_stride_out + h * h_stride_out + s * s_stride_out + arange * 1

    x = tl.load(x_ptr + offsets_x, mask=mask, other=0.0).to(tl.float32)
    sum_val = tl.load(sum_sums_ptr + pid).to(tl.float32)
    mean = sum_val / H
    inv_rms = 1.0 / tl.sqrt(mean + eps)
    w = tl.load(weight_ptr + arange, mask=mask, other=1.0).to(tl.float32)
    y = x * inv_rms * w
    tl.store(out_ptr + offsets_out, y, mask=mask)


@triton.jit
def rotate_sin_cos_kernel(pos_ids_ptr, inv_freq_ptr,
                           cos_ptr, sin_ptr,
                           B: tl.constexpr, S: tl.constexpr, H: tl.constexpr,
                           pos_stride,
                           cos_stride, sin_stride,
                           num_warps=4):
    # One program per (b, s)
    b = tl.program_id(0)
    s = tl.program_id(1)
    if b >= B or s >= S:
        return

    pos = tl.load(pos_ids_ptr + b * pos_stride + s).to(tl.float32)

    half = H // 2
    arange = tl.arange(0, H)

    # Build emb that emulates cat([freqs, freqs], -1):
    # emb[i] = pos * inv_freq[i//2] for i < half, else emb[i] = pos * inv_freq[(i-half)//2]
    emb = tl.zeros((H,), dtype=tl.float32)
    idx1 = arange < half
    idx2 = arange >= half

    emb_first = pos * tl.load(inv_freq_ptr + arange // 2, mask=idx1, other=0.0).to(tl.float32)
    idx2_part = arange - half
    emb_second = pos * tl.load(inv_freq_ptr + idx2_part // 2, mask=idx2, other=0.0).to(tl.float32)

    emb = tl.where(idx1, emb_first, emb_second)

    c = tl.cos(emb)
    s1 = tl.sin(emb)

    base = b * cos_stride + s * sin_stride
    tl.store(cos_ptr + base + arange, c)
    tl.store(sin_ptr + base + arange, s1)

def apply_rotation_kernel(x_ptr, cos_ptr, sin_ptr,
                           out_ptr,
                           B: tl.constexpr, num_q_heads: tl.constexpr, S: tl.constexpr,
                           H: tl.constexpr,
                           batch_stride_x, h_stride_x, s_stride_x,
                           batch_stride_cos, h_stride_cos, s_stride_cos,
                           batch_stride_sin, h_stride_sin, s_stride_sin,
                           batch_stride_out, h_stride_out, s_stride_out,
                           num_warps=4):
    # One program per (b, h, s)
    pid = tl.program_id(0)
    total = B * num_q_heads * S
    if pid >= total:
        return
    b = pid // (num_q_heads * S)
    hs = pid % (num_q_heads * S)
    h = hs // S
    s = hs % S

    arange = tl.arange(0, 128)
    mask = arange < H

    offsets_x = b * batch_stride_x + h * h_stride_x + s * s_stride_x + arange * 1
    offsets_out = b * batch_stride_out + h * h_stride_out + s * s_stride_out + arange * 1

    x = tl.load(x_ptr + offsets_x, mask=mask, other=0.0).to(tl.float32)

    # Load cos/sin for this (b, s)
    base = b * batch_stride_cos + h * h_stride_cos + s * s_stride_cos
    cos_vals = tl.load(cos_ptr + base + arange, mask=mask, other=0.0).to(tl.float32)
    base_sin = b * batch_stride_sin + h * h_stride_sin + s * s_stride_sin
    sin_vals = tl.load(sin_ptr + base_sin + arange, mask=mask, other=0.0).to(tl.float32)

    half = H // 2
    idx_first = arange < half
    idx_second = arange >= half

    x_first = tl.load(x_ptr + offsets_x, mask=idx_first, other=0.0).to(tl.float32)
    x_second = tl.load(x_ptr + offsets_x, mask=idx_second, other=0.0).to(tl.float32)
    rotated = tl.zeros((128,), dtype=tl.float32)
    rotated = tl.where(idx_first, x_first, -x_second)

    y = x * cos_vals + rotated * sin_vals
    tl.store(out_ptr + offsets_out, y, mask=mask)
