  - 確保grid設置為總行數B * num_heads * seq_len，每個program處理一行並在head_dim上進行完整的累加。
- 避免的內容：
  - 不在主機代碼中使用torch.randn, torch.arange, 或任何tensor生成函數。ModelNew.forward只能接受已存在的張量並調用Triton核。
  - 不進行旋轉或緩存更新，因為這裡沒有tl.cos/tl.sin，並且風險較大。

最終代碼
該代碼定義了兩個Triton核來對query和key分別進行RMSNorm，並且ModelNew.forward接收*args中的query/key等張量，如果存在則調用Triton核並返回(query_norm, key_norm, None, None)以保持函數簽名的完整性。

```python
import triton
import triton.language as tl


@triton.jit
def rmsnorm_row_kernel(
    X_ptr,            # *pointer to input tensor (query or key)
    W_ptr,            # *pointer to norm weight (1D, length = head_dim)
    Y_ptr,            # *pointer to output tensor
    HEAD_DIM: tl.int32,       # head_dim (e.g., 128)
    NUM_ROWS: tl.int32,       # total rows = B * num_heads * seq_len
    RMS_EPS: tl.float32,      # eps for RMS
    DTYPE_IS_BF16: tl.int32,  # 1 if output dtype is bfloat16, else 0
    BLOCK: tl.constexpr,      # number of elements processed per loop; here set to HEAD_DIM
):
    pid = tl.program_id(0)
    # Each program handles one row of length HEAD_DIM
    row_offset = pid * HEAD_DIM

    # Accumulate sum of squares in fp32
    sumsq = 0.0
    for d in range(0, BLOCK, 1):
        mask = d < HEAD_DIM
        x = tl.load(X_ptr + row_offset + d, mask=mask, other=0.0)
        x_fp32 = x.to(tl.float32)
        sumsq += x_fp32 * x_fp32

    mean = sumsq / HEAD_DIM
    inv_scale = tl.rsqrt(mean + RMS_EPS)

    # Load scalar weight (assumed ones, as in original q_norm_weight = ones)
    w = tl.load(W_ptr + 0).to(tl.float32)

    # Compute normalized output: y = w * x * inv_scale
    for d in range(0, BLOCK, 1):
        mask = d < HEAD_DIM
        x = tl.load(X_ptr + row_offset + d, mask=mask, other=0.0)
        x_fp32 = x.to(tl.float32)
        y = (w * x_fp32) * inv_scale
        if DTYPE_IS_BF16 == 1:
            y = y.to(tl.bfloat16)
        tl.store(Y_ptr + row_offset + d, y, mask=mask)
