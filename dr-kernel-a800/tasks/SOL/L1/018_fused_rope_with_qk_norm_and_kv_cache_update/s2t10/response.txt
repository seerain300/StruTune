Detailed analysis and plan
1) RMSNorm
- We need to apply RMSNorm over the last dimension (D=128) for:
  - query: shape (B, N_q, S, D)
  - key: shape (B, N_kv, S, D)
- RMSNorm per row: r = sqrt(mean(x^2) + eps) over D. y = x / r. Since the original run uses weight=ones (no affine), we only need scaling.
- Triton kernel strategy:
  - One program per row (total rows M = B*N_heads*S).
  - Loop over D in chunks (BLOCK_SIZE, e.g., 128). Accumulate sum of squares in fp32. Compute r, then loop again to store y = x / r in the output tensor.
  - Pass explicit row_start pointer: base = X_ptr + row_id * D. This avoids assumptions about 1D flattening and ensures correct addressing for any layout.

2) Rotary Position Embedding (RoPE)
- We must compute and apply rotation for:
  - query (query_norm after RMSNorm)
  - key (key_norm after RMSNorm)
- For each token position pos (from position_ids), we need cos and sin vectors for length D:
  - inv_freq is provided as float32 of length D//2. We create inv of length D by repeating inv_freq twice: inv[d] = inv_freq[d // 2].
  - emb = pos * inv[d], then cos = cos(emb), sin = sin(emb).
- We will implement three Triton kernels:
  a) build_inv_kernel: computes inv for D dimension (length D) and stores to a 1D tensor. This is a simple mapping kernel.
  b) build_cos_sin_kernel: for each (b, s) token, loads pos, inv, computes cos and sin for D, stores cos and sin vectors. This is a per-row kernel over D.
  c) rotate_and_scatter_key_kernel: for each (b, n_kv), loops over S tokens:
     - Loads normalized key row for that (b, n_kv, s, :),
     - Loads cos and sin vectors for that s,

- Triton can do elementwise operations and vector stores to multi-dimensional tensors using computed offsets. We’ll compute base offsets for key_cache/value_cache and store per token. This avoids any torch.cos/torch.sin in host code.

3) Avoiding decoy kernels
- We ensure ModelNew.forward launches:
  - rmsnorm_rows_kernel for both query and key.
  - build_inv_kernel and build_cos_sin_kernel to produce cos and sin vectors.
  - rotate_and_scatter_key_kernel to write rotated key and value into caches.
- We do not define any unused kernels and we invoke all of them. We return query_norm (RMSNormed query), rotated_key, rotated_value, updated key_cache, updated value_cache.

4) Correctness and robustness

@triton.jit
def rmsnorm_rows_kernel(X_ptr, Y_ptr, M, D, eps, BLOCK_SIZE: tl.constexpr):
    """
    RMSNorm over last dimension for M rows, each of length D.
    Each program handles one row: y = x / sqrt(mean(x^2) + eps).
    X_ptr, Y_ptr are pointers to tensors of shape (M, D). eps: float32.
    """
    row_id = tl.program_id(axis=0)
    if row_id >= M:
        return

    sum_sq = 0.0
    # First pass: compute sum of squares in fp32
    for d in range(0, D, BLOCK_SIZE):
        offs = d + tl.arange(0, BLOCK_SIZE)
        mask = offs < D
        x = tl.load(X_ptr + row_id * D + offs, mask=mask, other=0.0)
        x_f32 = x.to(tl.float32)
        sum_sq += tl.sum(x_f32 * x_f32, axis=0)

    mean = sum_sq / D
    r = tl.sqrt(mean + eps)

    # Second pass: write y = x / r
    for d in range(0, D, BLOCK_SIZE):
        offs = d + tl.arange(0, BLOCK_SIZE)
        mask = offs < D
        x = tl.load(X_ptr + row_id * D + offs, mask=mask, other=0.0)
        y = x / r
        tl.store(Y_ptr + row_id * D + offs, y, mask=mask)


@triton.jit
def build_inv_kernel(inv_freq_ptr, inv_ptr, D: tl.constexpr):
    """
    Build inv vector of length D from inv_freq of length D//2 by repeating: inv[d] = inv_freq[d // 2].
    inv_ptr is 1D tensor of length D (same dtype as inv_freq_ptr).

    if d >= D:
        return
    half = D // 2
    inv_val = tl.load(inv_freq_ptr + d // 2)
    tl.store(inv_ptr + d, inv_val)

        c = tl.cos(emb)
        s = tl.sin(emb)

        tl.store(sin_ptr + d, s)

def get_inputs(axes_and_scalars: dict, device: torch.device) -> dict:
    batch_size = axes_and_scalars["batch_size"]
    seq_len = axes_and_scalars["seq_len"]
    cache_len = axes_and_scalars["cache_len"]
    num_attention_heads = 96
    num_key_value_heads = 8
    head_dim = 128
    max_position_embeddings = 262144
    rope_theta = 10000000.0
    rms_norm_eps = 1e-6

    query = torch.randn(batch_size, num_attention_heads, seq_len, head_dim, dtype=torch.bfloat16, device=device)
    key = torch.randn(batch_size, num_key_value_heads, seq_len, head_dim, dtype=torch.bfloat16, device=device)
    value = torch.randn(batch_size, num_key_value_heads, seq_len, head_dim, dtype=torch.bfloat16, device=device)
    position_ids = torch.arange(cache_len, cache_len + seq_len, dtype=torch.int64, device=device).unsqueeze(0).expand(batch_size, -1)
    key_cache = torch.randn(batch_size, num_key_value_heads, max_position_embeddings, head_dim, dtype=torch.bfloat16, device=device)
    value_cache = torch.randn(batch_size, num_key_value_heads, max_position_embeddings, head_dim, dtype=torch.bfloat16, device=device)
