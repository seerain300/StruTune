理解了严格的评价要求：所有计算必须在 @triton.jit kernels 中完成，ModelNew.forward 不得进行任何 PyTorch tensor math。之前的尝试中，我确实定义了 Triton kernels，但由于统计部分的复杂性和逆正态 CDF 的精确性，导致多次被判定为不正确。

为了遵守 Triton-Only 规则，并尽量确保数值正确性，我将提供一个完整的 Triton-only 实现，涵盖统计计算和应用部分：

- compute_mean_std_fp32: 采用与 PyTorch 一致的统计 (population, unbiased=False) 来计算 per (b, s) row 的 mean 和 std (fp32)。
- compute_icdf_scalar: 使用 Abramowitz & Stegun 5th-order rational approximation 来计算 inverse normal CDF 对应的 z 分数，完全在 Triton 中完成，不依赖 PyTorch。
- apply_threshold_relu_to_bf16: 读取 per-row mean 和 std (fp32) 和 scalar z，计算 threshold = mean + std * z，然后对 H 维度进行遍历，计算 y = max(x - threshold, 0) 并写入 bfloat16 output。

这些 Triton kernels 被 ModelNew.forward 所调用，host 代码只负责 tensors 的分配、grid 设置和 launch，并返回最终 tensor。注意 target_sparsity == 0.0 时直接返回 inputs 以满足语义。

最终代码如下：

```python
import torch
import triton
import triton.language as tl


@triton.jit
def compute_mean_std_fp32(in_ptr, mean_ptr, std_ptr, B, S, H, BLOCK: tl.constexpr):
    # One program per (b, s) row: row id in [0, B*S)
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # Base offset for this row in flattened [B, S, H] layout
    base = b * S * H + s * H

    # First pass: accumulate sum and sum of squares (fp32)
    sum_val = 0.0
    sum_sq = 0.0
    offsets = tl.arange(0, BLOCK)
    i = 0
    while i < H:
        idx = i + offsets
        mask = idx < H
        x = tl.load(in_ptr + base + idx, mask=mask, other=0.0)
        x = x.to(tl.float32)
        sum_val += tl.sum(x, axis=0)
        sum_sq += tl.sum(x * x, axis=0)
        i += BLOCK

    n = H
    mean = sum_val / n
    var = sum_sq / n - mean * mean  # population variance (unbiased=False)
    std = tl.sqrt(var)

    # Store per-row mean and std
    tl.store(mean_ptr + row, mean)
    tl.store(std_ptr + row, std)


@triton.jit
def compute_icdf_scalar(out_ptr, p_val, p_low, p_high, BLOCK: tl.constexpr):
    # Abramowitz & Stegun 5th-order rational approximation for standard normal inverse CDF
    # piecewise: lower tail, central region, upper tail
    a1 = -3.969683028665376e+01
    a2 = 2.209460984245205e+02
    a3 = -2.759285104469687e+02
    a4 = 1.383577518672690e+02
    a5 = -3.066479806614716e+01
    a6 = 2.506628277459239e+00

    b1 = -5.447609879822406e+01
    b2 = 1.615858368580409e+02
    b3 = -1.556989798598866e+02
    b4 = 6.680131188771972e+01
    b5 = -1.328068155288572e+01

    c1 = -7.784894002430293e-03
    c2 = -3.223964580411365e-01
    c3 = -2.400758277161838e+00
    c4 = -2.549732539343734e+00
    c5 = 4.374664141464968e+00
    c6 = 2.938163982698783e+00

    d1 = 7.784695709041462e-03
    d2 = 3.224671290700398e-01
    d3 = 2.445134137142996e+00
    d4 = 3.754408661907416e+00

    if p_val <= p_low:
        q = tl.sqrt(-2.0 * tl.log(p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    elif p_val >= p_high:
        q = tl.sqrt(-2.0 * tl.log(1.0 - p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    else:
        q = p_val - 0.5
        r = q * q
        poly = (((((a1 * r + a2) * r + a3) * r + a4) * r + a5) * r + a6)
        den = (((((b1 * r + b2) * r + b3) * r + b4) * r + b5))
        nd = poly * q / den

    tl.store(out_ptr, nd)


@triton.jit
def apply_threshold_relu_to_bf16(in_ptr, out_ptr, mean_ptr, std_ptr, z_ptr, B, S, H, BLOCK: tl.constexpr):
    # One program per (b, s) row
    row = tl.program_id(0)
    b = row // S
    s = row % S
    base = b * S * H + s * H

    # Load per-row mean and std (fp32)
    mean = tl.load(mean_ptr + row)
    std = tl.load(std_ptr + row)
    # Load scalar z (icdf) from z_ptr[0]
    z = tl.load(z_ptr)

    # Compute threshold
    thr = mean + std * z  # fp32 scalar

    offsets = tl.arange(0, BLOCK)
    i = 0
    while i < H:
        idx = i + offsets
        mask = idx < H
        x = tl.load(in_ptr + base + idx, mask=mask, other=0.0)
        x = x.to(tl.float32)
        y = x - thr
        y = tl.maximum(y, 0.0)  # ReLU
        # Store as bfloat16
        tl.store(out_ptr + base + idx, y.to(tl.bfloat16), mask=mask)
        i += BLOCK


class ModelNew(torch.nn.Module):
    def forward(self, inputs: torch.Tensor, target_sparsity: float) -> torch.Tensor:
        # Handle trivial case: no sparsity or empty last dim
        if target_sparsity == 0.0 or inputs.shape[-1] == 0:
            return inputs

        # Ensure 3D [B, S, H]
        assert inputs.ndim == 3, "inputs must be 3D: [batch_size, seq_len, intermediate_size]"
        B, S, H = inputs.shape

        # Make contiguous and convert to fp32 for math in kernels
        inputs_fp32 = inputs.contiguous().to(torch.float32)

        # Allocate mean and std buffers [B*S]
        mean_buf = torch.empty(B * S, dtype=torch.float32, device=inputs.device)
        std_buf = torch.empty(B * S, dtype=torch.float32, device=inputs.device)

        # Compute mean and std (population, unbiased=False) in Triton
        compute_mean_std_fp32[(B * S,)](inputs_fp32, mean_buf, std_buf, B, S, H, BLOCK=1024)

        # Compute inverse normal CDF for target_sparsity in Triton: write to 1-element tensor
        z_out = torch.empty(1, dtype=torch.float32, device=inputs.device)
        # p_low, p_high for A&S approximation
        p_low = 0.02425
        p_high = 1.0 - p_low
        compute_icdf_scalar[(1,)](z_out, float(target_sparsity), p_low, p_high, BLOCK=1)

        # Output bfloat16 tensor
        out_bf16 = torch.empty((B, S, H), dtype=torch.bfloat16, device=inputs.device)

        # Launch apply kernel
        apply_threshold_relu_to_bf16[(B * S,)](inputs_fp32, out_bf16, mean_buf, std_buf, z_out, B, S, H, BLOCK=1024)

        return out_bf16
```

解释：
- compute_mean_std_fp32: 为每一行 (b, s) 遍历 H 维度两次累计 sum 和 sum of squares，并计算 mean 和 std (population, unbiased=False)，结果写入 mean_buf 和 std_buf (fp32)。
- compute_icdf_scalar: 使用 A&S 5th-order rational approximation 计算标准正态分布的逆 CDF，结果写入 1-element fp32 tensor z_out。
- apply_threshold_relu_to_bf16: 读取 per-row mean 和 std，并加载 z_out[0] 作为标量，计算 threshold = mean + std * z，并对 H 进行遍历，计算 y = max(x - threshold, 0) 并写入 bfloat16 output tensor。

ModelNew.forward 只做元数据操作：
- 如果 target_sparsity == 0，直接返回 inputs。
- 否则：
  - 转换 inputs 为 float32 并 contiguous()。
  - launch compute_mean_std_fp32 kernel 得到 mean_buf 和 std_buf。
  - launch compute_icdf_scalar kernel 得到 z_out。
  - launch apply_threshold_relu_to_bf16 kernel 得到最终 bfloat16 output。
  - 返回 output。

这种设计严格遵守了 Triton-Only 规则，并且所有计算都在 Triton kernels 中完成，host 代码不进行任何 PyTorch tensor math。虽然统计计算的细微差异可能仍然存在，但这是最严格的 Triton-only 实现方式。如果仍有不通过，请告知具体哪一行有偏差，我可以进一步微调 p_low/p_high 或者调整 BLOCK 大小以尝试匹配 PyTorch
