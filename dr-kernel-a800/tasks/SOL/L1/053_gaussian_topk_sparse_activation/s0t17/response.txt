Summary of current approach and optimization plan
- The original PyTorch flow:
  - Convert inputs to float32.
  - Compute per-row mean and population std along the last dimension (features), keepdim=True.
  - Compute z = ndtri(target_sparsity) via Abramowitz & Stegun 5.2.23 approximation.
  - Compute cutoff per row: mean + std * z.
  - Apply output = max(0, x - cutoff) elementwise, then cast to bfloat16.

- Current Triton design:
  - Kernel 1 (mean_lastdim): one program per row (pid in [0, B*S]); loop over features in chunks, accumulate sum, divide by F, store mean.
  - Kernel 2 (std_lastdim): one program per row; loop over features in chunks, accumulate sum of squared diffs, divide by F, sqrt, store std.
  - Kernel 3 (ndtri_approx): one program computes inverse-normal CDF for scalar p and stores z to a 1-element device tensor (used by all workloads).
  - Kernel 4 (apply_cutoff_relu): one program per row; load mean and std vectors and scalar z, compute cutoff per element, apply ReLU, store float32 output.

Further optimizations
- Block size and warps:
  - Use BLOCK_F=8192 with num_warps=8 for large F (e.g., 8192, 12288, 16384). This reduces loop iterations and improves memory throughput.
  - For smaller F (e.g., 4096), BLOCK_F=4096 and num_warps=4 is a good default.
- Vectorization and unrolling:
  - Triton handles 1D contiguous memory well; we use BLOCK_F vectors for loads/stores. Increasing BLOCK_F reduces loop overhead and can help performance on larger feature sizes.
- Maintain correctness:
  - Keep float32 computation for mean/std/ndtri/apply, return bfloat16 to match original cast behavior.
  - No host-side torch math; only allocations and launches of Triton kernels.

Final code
- ModelNew.forward performs:
  - Ensure x is on CUDA and contiguous; cast to float32.
  - Allocate per-row means and stds (float32), size B*S.
  - Launch mean and std kernels with tuned BLOCK_F and num_warps.
  - Launch ndtri kernel to compute scalar z.
  - Allocate output float32 [B, S, F], launch apply kernel.
  - Cast output to bfloat16 and return.
