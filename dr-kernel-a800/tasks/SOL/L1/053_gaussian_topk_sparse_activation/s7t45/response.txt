- 问题根源：前两次提交虽然实现了 Triton-only，并且曾经达到 12/12 correctness 与 10.98x 的加速，但在最新的迭代中又回到了 0/12 不正确。这种反复表明 Triton kernels 中的关键部分存在系统性偏差，而不仅仅是边界条件或轻微的数值差异。

- 最可疑的部分有两个：
  1) compute_mean_std_fp32 kernel 中存在严重的逻辑错误：在 while 循环中进行累加时，直接使用 tl.sum(x, axis=0) 对整个 vector x 做 reduction，但实际上 x 包含了 masked elements (因为 offsets 超出了当前 H 区间时 load 了 0.0)。由于 masks 也是 vector 的形式，我们需要通过 mask 来过滤无效的 lanes，否则会错误地将 masked lanes 的 0 值计入 sum 和 sum_sq，在 H 不是 BLOCK 的整数倍时造成偏差。之前我忽略了这一点，这可以解释为什么有时正确有时不正确。

  2) apply kernel 中的增量计算 base = b*S*H + s*H + i*BLOCK 也有类似的潜在错误风险，但通常这部分很难造成大的数值差异；然而确保所有 masked loads 和 reductions 都正确是非常重要的。

- 优化计划：
  - 修正 compute_mean_std_fp32：
    - 在每一迭代中，用 mask 乘以 x 来排除无效 lanes，然后对有效 lanes 求和：sum += tl.sum(x * mask, axis=0)；同样 sum_sq += tl.sum((x * x) * mask, axis=0)。确保只有真正的数据参与统计。
    - 继续使用两遍 pass 设计：第一遍计算 sum 和 sum_sq (fp32)，第二遍计算 apply (write out bf16)。这种设计既准确又避免了存储中间结果的需要。
  - keep icdf kernel 为 A&S approximation 传回标量 z (fp32) 到 device，forward 中 host 只负责传 scalar 但不进行任何 tensor math。
  - apply kernel 中的 base 偏移修正为 base + i*H + offsets，确保每一迭代遍历的是正确的连续区间，并使用 mask = (i*H + offsets) < (b+1)*S*H (但更简单的是 base = b*S*H + s*H + i*H*0 + offsets ？为了清晰，我们重新计算为 base = b*S*H + s*H + i*H + offsets，并且在每轮将 i 重新设定以处理 H 可能不是 BLOCK 整数倍的问题：用 total iteration count j over H with step BLOCK and correct base. 实际上我们可以让 base = b*S*H + s*H 作为初始行偏移，然后每轮 i 从 0 开始遍历 BLOCK 大小的区间 offsets，这样就避免了复杂偏移计算错误。

- 性能方面：
  - 之前 10.98x 说明我们的并行策略是有效的。我们仍使用 BLOCK=2048 来处理 H 较大的情况，循环次数较少，提升性能。两遍遍历已经足够快，因为每遍只是简单的 load-add-reduce 和 load-compare-store，不会成为瓶颈。重点是保证准确性和稳定性。

- Triton-only 规则：
  - ModelNew.forward 仅负责 allocation, launch, grid, scalar 传递，不进行任何 tensor math (torch.mean, torch.std, F.relu, torch.tensor(...))。

import torch
import triton
import triton.language as tl


@triton.jit
def compute_mean_std_fp32(in_ptr, mean_ptr, std_ptr, B, S, H, BLOCK: tl.constexpr):
    # One program per (b, s) row, pid in [0, B*S)
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # Base offset for this row in [B, S, H]
    base = b * S * H + s * H

    # First pass: accumulate sum and sum of squares (fp32), exclude masked lanes
    sum_val = 0.0
    sum_sq = 0.0
    i = 0
    while i < H:
        offsets = i + tl.arange(0, BLOCK)
        mask = offsets < H
        x = tl.load(in_ptr + base + offsets, mask=mask, other=0.0)
        x = x.to(tl.float32)
        # Include only valid lanes in reduction
        sum_val += tl.sum(x * mask, axis=0)
        sum_sq += tl.sum((x * x) * mask, axis=0)
        i += BLOCK

    n = H
    mean = sum_val / n
    var = sum_sq / n - mean * mean  # population variance (unbiased=False)
    std = tl.sqrt(var)

    # Store per-row mean and std
    tl.store(mean_ptr + row, mean)
    tl.store(std_ptr + row, std)


@triton.jit
def compute_icdf_scalar(out_ptr, p_val, p_low, p_high,
                        a1, a2, a3, a4, a5, a6,
                        b1, b2, b3, b4, b5,
                        c1, c2, c3, c4, c5, c6,
                        d1, d2, d3, d4):
    # Abramowitz & Stegun 5th-order rational approximation for standard normal inverse CDF
    # piecewise: lower tail, center, upper tail
    # p_val: scalar float in (0,1)
    p_low_scalar = 0.02425
    p_high_scalar = 1.0 - p_low_scalar

    if p_val <= p_low_scalar:
        q = tl.sqrt(-2.0 * tl.log(p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    elif p_val >= p_high_scalar:
        q = tl.sqrt(-2.0 * tl.log(1.0 - p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    else:
        q = p_val - 0.5
        r = q * q
        poly = (((((a1 * r + a2) * r + a3) * r + a4) * r + a5) * r + a6)
        den = (((((b1 * r + b2) * r + b3) * r + b4) * r + b5))
        nd = poly * q / den

    tl.store(out_ptr, nd)


@triton.jit
def apply_threshold_relu_to_bf16(in_ptr, out_ptr, mean_ptr, std_ptr, B, S, H, z_ptr, BLOCK: tl.constexpr):
    # One program per (b, s) row
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # Load per-row mean and std (fp32)
    mean = tl.load(mean_ptr + row)
    std = tl.load(std_ptr + row)
    # Load scalar z (icdf) from z_ptr[0]
    z = tl.load(z_ptr)

    # Compute threshold
    thr = mean + std * z  # fp32

    # Second pass: apply y = max(x - thr, 0) in fp32, store as bfloat16
    base = b * S * H + s * H
    i = 0
    while i < H:
        offsets = i + tl.arange(0, BLOCK)
        mask = offsets < H
        x = tl.load(in_ptr + base + offsets, mask=mask, other=0.0).to(tl.float32)
        y = x - thr
        y = tl.maximum(y, 0.0)
        # Store as bfloat16
        tl.store(out_ptr + base + offsets, y.to(tl.bfloat16), mask=mask)
        i += BLOCK


class ModelNew(torch.nn.Module):
    def forward(self, input_tensor: torch.Tensor, target_sparsity: float) -> torch.Tensor:
        """
        Triton-only implementation of Gaussian-based top-k sparse activation:
        - Compute per (batch, seq) row mean and std in fp32 over feature dim H.
        - Compute z = inverse-normal CDF(target_sparsity) as scalar on device (A&S).
        - Apply thresholding: y = max(input - (mean + std*z), 0) and return in bfloat16.
        """
        assert input_tensor.is_cuda, "Input must be a CUDA tensor for Triton kernels."

        # Ensure input is contiguous and in bfloat16 for output; stats computed in fp32
        B, S, H = input_tensor.shape
        in_bf16 = input_tensor  # keep original dtype
        in_fp32 = input_tensor.to(torch.float32)  # contiguous in memory

        # Allocate per-row mean and std (fp32) buffers
        mean = torch.empty(B * S, dtype=torch.float32, device=input_tensor.device)
        std = torch.empty(B * S, dtype=torch.float32, device=input_tensor.device)

        # Launch compute_mean_std_fp32
        grid_mean_std = (B * S,)
        compute_mean_std_fp32[grid_mean_std](
            in_fp32, mean, std, B, S, H, BLOCK=2048
        )

        # Compute icdf(target_sparsity) as a 1-element fp32 tensor on device
        # Using A&S constants passed explicitly to kernel
        z_out = torch.empty(1, dtype=torch.float32, device=input_tensor.device)

        p_low = 0.02425
        p_high = 1.0 - p_low
        a1 = -3.969683028665376e+01
        a2 = 2.209460984245205e+02
        a3 = -2.759285104469687e+02
        a4 = 1.383577518672690e+02
        a5 = -3.066479806614716e+01
        a6 = 2.506628277459239e+00

        b1 = -5.447609879822406e+01
        b2 = 1.615858368580409e+02
        b3 = -1.556989798598866e+02
        b4 = 6.680131188771972e+01
        b5 = -1.328068155288572e+01

        c1 = -7.784894002430293e-03
        c2 = -3.223964580411365e-01
        c3 = -2.400758277161838e+00
        c4 = -2.549732539343734e+00
        c5 = 4.374664141464968e+00
        c6 = 2.938163982698783e+00

        d1 = 7.784695709041462e-03
        d2 = 3.224671290700398e-01
        d3 = 2.445134137142996e+00
        d4 = 3.754408661907416e+00

        compute_icdf_scalar[(1,)](z_out, float(target_sparsity), p_low, p_high, a1, a2, a3, a4, a5, a6, b1, b2, b3, b4, b5, c1, c2, c3, c4, c5, c6, d1, d2, d3, d4)

        # Prepare output buffer in bfloat16
        out_bf16 = torch.empty_like(in_bf16, dtype=torch.bfloat16)

        # Launch apply kernel
        apply_threshold_relu_to_bf16[grid_mean_std](
            in_fp32, out_bf16, mean, std, B, S, H, z_out, BLOCK=2048
        )

        # If target_sparsity == 0, we should return original input; but original code returns activation anyway.
        # Here we keep returning the sparsified output, which matches original behavior for target_sparsity > 0.
        return out_bf16

此外，为了进一步确保可靠性，我注意到 Triton 的某些 API 可能有细微的行为差异，特别是在 reduction 和 masked load 的组合上。为了避免任何不确定的因素，我采取了更加保守的设计：

- compute_mean_std_fp32 kernel: 两遍 pass，第一遍只计算 H 的计数 n (sum of masks)，第二遍计算 sum 和 sum_sq 时严格按照 mask 排除无效 lanes。这样可以完全消除 H 不是 BLOCK 整数倍时的偏差，并且确保统计结果与 PyTorch 的 torch.mean/torch.std (unbiased=False) 一致。

- compute_icdf_scalar: 依然使用 A&S approximation 来计算 inverse normal CDF，并将标量 z 写入 1-element fp32 tensor 上，供 apply kernel 使用。host 仅进行 scalar 传递，不进行 tensor math。

- apply_threshold_relu_to_bf16: 读取 per-row mean 和 std 以及 scalar z，遍历 H 计算 y = max(x - (mean + std*z), 0)，写回 bfloat16。

这种设计不仅增强了正确性，同时也保持了 Triton-only 的规则，并且在之前已经展示过良好的性能。现在更注重的是彻底排除 masked lanes 和 count 出错的可能性，以恢复 100% 的 correctness。

import torch
import triton
import triton.language as tl


@triton.jit
def compute_mean_std_fp32(in_ptr, mean_ptr, std_ptr, B, S, H, BLOCK: tl.constexpr):
    # One program per (b, s) row: pid in [0, B*S)
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # Base offset for this row in flattened [B, S, H]
    base = b * S * H + s * H

    # First pass: count number of valid elements (H) as n
    n = 0
    i = 0
    while i < H:
        offsets = i + tl.arange(0, BLOCK)
        mask = offsets < H
        # Count valid lanes
        n += tl.sum(mask, axis=0)
        i += BLOCK

    # Second pass: accumulate sum and sum of squares (fp32), excluding masked lanes
    sum_val = 0.0
    sum_sq = 0.0
    i = 0
    while i < H:
        offsets = i + tl.arange(0, BLOCK)
        mask = offsets < H
        x = tl.load(in_ptr + base + offsets, mask=mask, other=0.0)
        x = x.to(tl.float32)
        # Include only valid lanes in reduction
        sum_val += tl.sum(x * mask, axis=0)
        sum_sq += tl.sum((x * x) * mask, axis=0)
        i += BLOCK

    # Compute mean and std (population, unbiased=False)
    mean = sum_val / n
    var = sum_sq / n - mean * mean
    std = tl.sqrt(var)

    # Store per-row mean and std
    tl.store(mean_ptr + row, mean)
    tl.store(std_ptr + row, std)


@triton.jit
def compute_icdf_scalar(out_ptr, p_val, p_low, p_high,

                        b1, b2, b3, b4, b5,
                        c1, c2, c3, c4, c5, c6,

    # Abramowitz & Stegun 5th-order rational approximation for standard normal inverse CDF
    # piecewise: lower tail, center, upper tail
    p_low_scalar = 0.02425
    p_high_scalar = 1.0 - p_low_scalar

    if p_val <= p_low_scalar:
        q = tl.sqrt(-2.0 * tl.log(p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    elif p_val >= p_high_scalar:
        q = tl.sqrt(-2.0 * tl.log(1.0 - p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    else:
        q = p_val - 0.5
        r = q * q
        poly = (((((a1 * r + a2) * r + a3) * r + a4) * r + a5) * r + a6)
        den = (((((b1 * r + b2) * r + b3) * r + b4) * r + b5))
        nd = poly * q / den

    tl.store(out_ptr, nd)


@triton.jit
def apply_threshold_relu_to_bf16(in_ptr, out_ptr, mean_ptr, std_ptr, B, S, H, z_ptr, BLOCK: tl.constexpr):
    # One program per (b, s) row
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # Load per-row mean and std (fp32)
    mean = tl.load(mean_ptr + row)
    std = tl.load(std_ptr + row)
    # Load scalar z (icdf) from z_ptr[0]
    z = tl.load(z_ptr)

    # Compute threshold
    thr = mean + std * z  # fp32

    # Apply y = max(x - thr, 0) over H, store as bfloat16
    base = b * S * H + s * H
    i = 0
    while i < H:
        offsets = i + tl.arange(0, BLOCK)
        mask = offsets < H
        x = tl.load(in_ptr + base + offsets, mask=mask, other=0.0).to(tl.float32)
        y = x - thr
        y = tl.maximum(y, 0.0)
        tl.store(out_ptr + base + offsets, y.to(tl.bfloat16), mask=mask)
        i += BLOCK
