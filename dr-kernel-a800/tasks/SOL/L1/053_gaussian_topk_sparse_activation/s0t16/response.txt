Detailed analysis and plan
- Original behavior:
  - Input x of shape [B, S, F].
  - Convert to float32.
  - Compute per-row mean and population std along last dim (features), keepdim=True.
  - Compute std_multiplier z = ndtri(target_sparsity) using Abramowitz & Stegun 5.2.23 approximation (piecewise: lower, central, upper regions).
  - cutoff = mean + std * z per row.
  - output = relu(x - cutoff) elementwise, then cast to bfloat16.

- Triton strategy:
  - Kernel 1: mean_lastdim_kernel
    - One program per row (pid in [0, B*S)).
    - Iterate features in chunks of BLOCK_F, sum elements, divide by F, store mean at index pid.
  - Kernel 2: std_lastdim_kernel
    - One program per row.
    - Iterate features in chunks of BLOCK_F, compute squared diff from mean, accumulate sum, divide by F, sqrt, store std at index pid.
  - Kernel 3: ndtri_approx_kernel
    - One program computes z = ndtri(p) for p=target_sparsity.
    - Implement piecewise A&S 5.2.23 approximation and store z to a 1-element device tensor (shared across workloads).
  - Kernel 4: apply_cutoff_relu_kernel
    - One program per row.
    - Load mean and std for this row, load scalar z, compute cutoff = mean + std*z.
    - Iterate features in chunks, compute out = max(0, x - cutoff), store float32 output.

- Host:
  - Ensure x is CUDA and contiguous.
  - Convert x to float32.
  - Allocate per-row means and stds as float32 vectors of length B*S.
  - Launch mean and std kernels.
  - Launch ndtri kernel to compute z (single scalar).
  - Allocate output float32 tensor [B, S, F].
  - Launch apply kernel.
  - Cast output to bfloat16 and return.

- Tuning:
  - Use BLOCK_F=4096 and num_warps=8 for large F (8192, 12288, 16384) to reduce loop iterations and improve throughput.
  - For smaller F, num_warps can be 4, but we keep 8 to favor performance in common cases.

import torch
import triton
import triton.language as tl


@triton.jit
def mean_lastdim_kernel(x_ptr, means_ptr, B, S, F, BLOCK_F: tl.constexpr):
    pid = tl.program_id(axis=0)
    # Each program handles one row: row index = pid
    row = pid
    # Compute base offset for this row in flattened [B*S, F]
    # x_ptr is laid out as [B, S, F] contiguous, so offset = row * F
    row_offset = row * F
    # Accumulate sum over features
    total = 0.0
    for col in range(0, F, BLOCK_F):
        cols = col + tl.arange(0, BLOCK_F)
        mask = cols < F
        vals = tl.load(x_ptr + row_offset + cols, mask=mask, other=0.0)
        total += tl.sum(vals, axis=0)
    mean = total / F
    tl.store(means_ptr + row, mean)


@triton.jit
def std_lastdim_kernel(x_ptr, stds_ptr, means_ptr, B, S, F, BLOCK_F: tl.constexpr):
    pid = tl.program_id(axis=0)
    row = pid
    row_offset = row * F
    # Load mean for this row
    mean = tl.load(means_ptr + row)
    total = 0.0
    for col in range(0, F, BLOCK_F):
        cols = col + tl.arange(0, BLOCK_F)
        mask = cols < F
        vals = tl.load(x_ptr + row_offset + cols, mask=mask, other=0.0)
        diff = vals - mean
        total += tl.sum(diff * diff, axis=0)
    var = total / F
    std = tl.sqrt(var)
    tl.store(stds_ptr + row, std)


@triton.jit
def ndtri_approx_kernel(p_ptr, z_ptr):
    # p_ptr: 1-element tensor, float32, device
    # z_ptr: 1-element tensor, float32, device
    # Implement Abramowitz & Stegun 5.2.23 approximation for inverse normal CDF
    p = tl.load(p_ptr)  # scalar
    # Coefficients
    a1 = -3.969683028665376e+01
    a2 = 2.209460984245205e+02
    a3 = -2.759285104469687e+02
    a4 = 1.383577518672690e+02
    a5 = -3.066479806614716e+01
    a6 = 2.506628277459239e+00

    b1 = -5.447609879822406e+01
    b2 = 1.615858368580409e+02
    b3 = -1.556989798598866e+02
    b4 = 6.680131188771972e+01
    b5 = -1.328068155288572e+01

    c1 = -7.784894002430293e-03
    c2 = -3.223964580411365e-01
    c3 = -2.400758277161838e+00
    c4 = -2.549732539343734e+00
    c5 = 4.374664141464968e+00
    c6 = 2.938163982698783e+00

    d1 = 7.784695709041462e-03
    d2 = 3.224671290700398e-01
    d3 = 2.445134137142996e+00
    d4 = 3.754408661907416e+00

    p_low = 0.02425
    p_high = 1.0 - p_low

    if p < p_low:
        q = tl.sqrt(-2.0 * tl.log(p))
        poly = (((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        denom = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        z = poly / denom
    elif p > p_high:
        q = tl.sqrt(-2.0 * tl.log(1.0 - p))
        poly = (((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        denom = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        z = -poly / denom
    else:
        q = p - 0.5
        r = q * q
        poly = (((((a1 * r + a2) * r + a3) * r + a4) * r + a5) * r + a6)
        denom = (((((b1 * r + b2) * r + b3) * r + b4) * r + b5) * r + 1.0)
        z = poly * q / denom

    tl.store(z_ptr, z)


@triton.jit
def apply_cutoff_relu_kernel(x_ptr, out_ptr, means_ptr, stds_ptr, z_ptr, B, S, F, BLOCK_F: tl.constexpr):
    pid = tl.program_id(axis=0)
    row = pid
    row_offset = row * F

    mean = tl.load(means_ptr + row)
    std = tl.load(stds_ptr + row)
    z = tl.load(z_ptr)  # scalar
    cutoff = mean + std * z

    # Write output = max(0, x - cutoff) for each feature in this row
    for col in range(0, F, BLOCK_F):
        cols = col + tl.arange(0, BLOCK_F)
        mask = cols < F
        vals = tl.load(x_ptr + row_offset + cols, mask=mask, other=0.0)
        out_vals = tl.maximum(vals - cutoff, 0.0)
        tl.store(out_ptr + row_offset + cols, out_vals, mask=mask)


class ModelNew(torch.nn.Module):
    def forward(self, x: torch.Tensor, target_sparsity: float) -> torch.Tensor:
        # Ensure CUDA and contiguity
        if not x.is_cuda:
            x = x.to('cuda')
        x = x.contiguous().to(torch.float32)
        B, S, F = x.shape

        # Allocate per-row means and stds
        means = torch.empty(B * S, device=x.device, dtype=torch.float32)
        stds = torch.empty(B * S, device=x.device, dtype=torch.float32)

        # Launch reduction kernels: one program per row
        grid = (B * S,)
        num_warps = 8 if F >= 8192 else 4
        BLOCK_F = 4096

        mean_lastdim_kernel[grid](x, means, B, S, F, BLOCK_F=BLOCK_F, num_warps=num_warps)
        std_lastdim_kernel[grid](x, stds, means, B, S, F, BLOCK_F=BLOCK_F, num_warps=num_warps)

        # Compute z = ndtri(target_sparsity) in Triton
        p_tensor = torch.empty(1, device=x.device, dtype=torch.float32)  # placeholder for p
        # We need to fill p_tensor with target_sparsity. Triton cannot read Python floats directly,
        # so we store via a device tensor. Since Triton kernel expects p_ptr, we'll set p_tensor[0] = target_sparsity
        # on the host, but to keep Triton-only, we create a scalar tensor and pass it.
        # However, Triton kernels don't see Python floats; they see device tensors. We'll allocate p_tensor,
        # and the kernel will read it. We need to set its value to target_sparsity before launching.
        # Note: Triton kernels cannot accept Python floats as arguments; all numeric inputs must be device tensors.
        # Therefore, we create p_tensor[0] = target_sparsity here.
        p_tensor[0] = float(target_sparsity)
        z_scalar = torch.empty(1, device=x.device, dtype=torch.float32)
        ndtri_approx_kernel[(1,)](p_tensor, z_scalar)

        # Allocate output (float32) and apply cutoff + ReLU
        out_fp32 = torch.empty_like(x, dtype=torch.float32)

        apply_cutoff_relu_kernel[grid](x, out_fp32, means, stds, z_scalar, B, S, F, BLOCK_F=BLOCK_F, num_warps=num_warps)

        # Cast to bfloat16 to match original behavior
        out_bf16 = out_fp32.to(torch.bfloat16)
        return out_bf16

- All host-side numeric computation is now avoided. The target_sparsity is passed into Triton via a device tensor p_tensor, and the ndtri kernel computes the scalar z entirely inside Triton.
- The mean and std reductions are done per row in Triton. The apply kernel computes the final output using these per-row scalars and the scalar z, without any torch operations.
- Dtype handling: We compute in float32 and cast to bfloat16 at the end, matching the original code’s output dtype.
- Tuning: BLOCK_F=4096 and num_warps=8 for larger F improve throughput; for smaller F, 4 warps can be used, but 8 is fine for common sizes.
