深刻的复盘、诊断与根本纠正

- 问题表现：连续几次提交虽然采用了 Triton-only 方案，但最新一轮又报告所有 workload 均不正确 (“INCORRECT_NUMERICAL”)。这意味着我们的计算结果与 PyTorch 参考实现存在系统性偏差。

- 核心逻辑回顾
  - PyTorch 代码：
    - 对每一行 (batch, seq) 的特征维度 H，计算 mean 和 std (torch.std 默认 unbiased=False)。
    - 计算 inverse normal CDF z = icdf(target_sparsity) 作为标准正态分布的分位数。
    - threshold = mean + std * z (per row)。
    - sparse_output = relu(inputs - threshold) = max(inputs - threshold, 0.0)。
    - 返回 bfloat16 的 output。

- Triton-only 严格要求
  - ModelNew.forward 不得进行任何 PyTorch tensor math (torch.mean, torch.std, F.relu, torch.tensor(...)) 生成结果，所有计算都在 Triton kernels 中完成；host 仅负责 allocation、grid/launch，并返回 final tensor。

- 最有可能的根本原因
  - compute_mean_std_fp32 kernel 中的统计求和逻辑存在系统性错误：
    - 在 Triton 的 vectorized loop 中，masked lanes 需要明确排除对 sum/sum_sq 的贡献；虽然我们使用 other=0.0 masked load，但在某些版本的 Triton 中直接对 masked lanes 的 reduction 仍可能产生意外的累积（例如当 H 不是 BLOCK 的整数倍时，无效 lanes 被视为 0.0 并被累加）。这会导致 mean/std 的计算出现偏差，进而使得 threshold 和激活结果不正确。
    - 之前的一次提交曾获得全部正确的结果并且有 10.98x 加速，这表明当统计实现正确时，方案是可行的。因此，修正统计 kernel 是关键。

- 修复策略
  - 修正 compute_mean_std_fp32 kernel：
    - 两遍 pass 设计保持：
      1) 第一遍 pass：严格使用 masked load，并且确保 masked lanes 不贡献到 sum/sum_sq，通过构建 x_masked = tl.where(mask, x, 0.0) 并且只对有效 lanes 累加，即可保证准确性。
      2) 第一遍结束后计算 mean = sum / H 和 var = sum_sq / H - mean^2 (population std, unbiased=False)。
      3) 第二遍 pass：重新遍历 H，应用 threshold y = max(x - (mean + std*z), 0) 到 output (bf16)。这里同样使用 mask 防止 out-of-bound store，并且不要对无效 lanes 产生副作用。
    - 确保 offsets 和 base 计算正确，且没有越界操作。

  - icdf kernel 保持 A&S 5th-order rational approximation，在 Triton 中计算标量 z (fp32) 并写入 device 的 1-element fp32 tensor，forward 中 host 不做任何 tensor math，仅传递 scalar pointer。

  - apply kernel 严格按合法 offsets < H load-compute-store，不修改 out_ptr 中无效位置。

- 性能考虑
  - 保留 BLOCK=2048 以提高并行度，在 H 较大时减少 while 循环次数，从而提升性能，同时保证准确性。

最终完整的 Triton-only 实现

```python
import torch
import triton
import triton.language as tl


@triton.jit
def compute_mean_std_fp32(in_ptr, mean_ptr, std_ptr, B, S, H, BLOCK: tl.constexpr):
    # One program per (b, s) row: row id in [0, B*S)
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # Base offset for this row in flattened [B, S, H] layout
    base = b * S * H + s * H

    # First pass: accumulate sum and sum of squares (fp32), excluding masked lanes
    sum_val = 0.0
    sum_sq = 0.0
    offsets = tl.arange(0, BLOCK)
    i = 0
    while i < H:
        idx = i + offsets
        mask = idx < H
        # Load with mask; other lanes get 0.0
        x = tl.load(in_ptr + base + idx, mask=mask, other=0.0)
        x = x.to(tl.float32)
        # Ensure masked lanes do not contribute
        x_masked = tl.where(mask, x, 0.0)
        sum_val += tl.sum(x_masked, axis=0)
        sum_sq += tl.sum(x_masked * x_masked, axis=0)
        i += BLOCK

    # Compute mean and std (population, unbiased=False)
    n = H
    mean = sum_val / n
    var = sum_sq / n - mean * mean
    std = tl.sqrt(var)

    # Store per-row mean and std (fp32)
    tl.store(mean_ptr + row, mean)
    tl.store(std_ptr + row, std)


@triton.jit
def compute_icdf_scalar(out_ptr, p_val, p_low, p_high, BLOCK: tl.constexpr):
    # Abramowitz & Stegun 5th-order rational approximation for standard normal inverse CDF
    a1 = -3.969683028665376e+01
    a2 = 2.209460984245205e+02
    a3 = -2.759285104469687e+02
    a4 = 1.383577518672690e+02
    a5 = -3.066479806614716e+01
    a6 = 2.506628277459239e+00

    b1 = -5.447609879822406e+01
    b2 = 1.615858368580409e+02
    b3 = -1.556989798598866e+02
    b4 = 6.680131188771972e+01
    b5 = -1.328068155288572e+01

    c1 = -7.784894002430293e-03
    c2 = -3.223964580411365e-01
    c3 = -2.400758277161838e+00
    c4 = -2.549732539343734e+00
    c5 = 4.374664141464968e+00
    c6 = 2.938163982698783e+00

    d1 = 7.784695709041462e-03
    d2 = 3.224671290700398e-01
    d3 = 2.445134137142996e+00
    d4 = 3.754408661907416e+00

    p_low_scalar = 0.02425
    p_high_scalar = 1.0 - p_low_scalar

    if p_val <= p_low_scalar:
        q = tl.sqrt(-2.0 * tl.log(p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    elif p_val >= p_high_scalar:
        q = tl.sqrt(-2.0 * tl.log(1.0 - p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    else:
        q = p_val - 0.5
        r = q * q
        poly = (((((a1 * r + a2) * r + a3) * r + a4) * r + a5) * r + a6)
        den = (((((b1 * r + b2) * r + b3) * r + b4) * r + b5))
        nd = poly * q / den

    tl.store(out_ptr, nd)


@triton.jit
def apply_threshold_relu_to_bf16(in_ptr, out_ptr, mean_ptr, std_ptr, B, S, H, z_ptr, BLOCK: tl.constexpr):
    # One program per (b, s) row
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # Load per-row mean and std (fp32)
    mean = tl.load(mean_ptr + row)
    std = tl.load(std_ptr + row)
    # Load scalar z (icdf) from z_ptr[0]
    z = tl.load(z_ptr)

    # Compute threshold
    thr = mean + std * z  # fp32

    # Base offset for this row in flattened [B, S, H] layout
    base = b * S * H + s * H

    # Apply y = max(x - thr, 0) over H, store as bfloat16
    i = 0
    while i < H:
        offsets = i + tl.arange(0, BLOCK)
        mask = offsets < H
        x = tl.load(in_ptr + base + offsets, mask=mask, other=0.0).to(tl.float32)
        y = x - thr
        y = tl.maximum(y, 0.0)
        tl.store(out_ptr + base + offsets, y.to(tl.bfloat16), mask=mask)
        i += BLOCK


class ModelNew(torch.nn.Module):
    def forward(self, input_tensor: torch.Tensor, target_sparsity: float) -> torch.Tensor:
        """
        Triton-only implementation of Gaussian-based top-k sparse activation:
        - Compute per (batch, seq) row mean and std in fp32 over feature dim H (population, unbiased=False).
        - Compute z = inverse-normal CDF(target_sparsity) as scalar on device (A&S approximation).
        - Apply thresholding: y = max(input - (mean + std*z), 0) and return in bfloat16.
        """
        # Ensure CUDA and contiguous input
        assert input_tensor.is_cuda, "Input must be a CUDA tensor for Triton kernels."
        in_bf16 = input_tensor.contiguous().to(torch.bfloat16)

        B, S, H = in_bf16.shape
        device = in_bf16.device

        # Allocate per-row mean and std (fp32)
        mean = torch.empty(B * S, dtype=torch.float32, device=device)
        std = torch.empty(B * S, dtype=torch.float32, device=device)

        # Launch compute mean/std
        grid_mean_std = (B * S,)
        compute_mean_std_fp32[grid_mean_std](in_bf16, mean, std, B, S, H, BLOCK=2048)

        # Compute icdf scalar z on device
        z_out = torch.empty(1, dtype=torch.float32, device=device)
        p_val = float(target_sparsity)  # pass as Python float
        p_low = 0.02425
        p_high = 1.0 - p_low
        grid_icdf = (1,)
        compute_icdf_scalar[grid_icdf](z_out, p_val, p_low, p_high, BLOCK=1)

        # Prepare output in bfloat16
        out_bf16 = torch.empty_like(in_bf16)

        # Launch apply thresholding
        apply_threshold_relu_to_bf16[grid_mean_std](in_bf16, out_bf16, mean, std, B, S, H, z_out, BLOCK=2048)

        return out_bf16
```

  - compute_icdf_scalar 用 A&S approximation 传回 fp32 标量 z 到 device。
