方案和计划
1) 严格 Triton-only 设计
- ModelNew.forward 不得调用任何 PyTorch tensor ops (如 torch.tensor, torch.mean, torch.std, F.relu) 来做计算。所有计算都在 @triton.jit kernels 中完成。
- forward 只负责：
  - 检查 target_sparsity == 0.0 时直接返回 inputs 以满足语义，并且不进行任何计算。
  - 对 inputs 调用 .contiguous() 以便指针计算正确。
  - 分配输出 buffers，并 launch Triton kernels。
  - 返回最终输出 tensor。

2) 三个 Triton kernels
- compute_mean_std_fp32:
  - 每个程序实例处理一行 (b, s)。
  - 第一遍 pass 遍历 H，计算 sum 和 sum of squares，在 fp32 中累加。
  - 计算 mean = sum / H 和 std (population, unbiased=False) = sqrt(sum_sq / H - mean^2)。
  - 将 mean 和 std 写入 mean_ptr 和 std_ptr 的连续缓冲区中 (shape [B*S])。
- compute_icdf_scalar:
  - 完整的 Abramowitz & Stegun 5th-order rational approximation，接收 target_sparsity 作为 Python float (p_val) 并计算 inverse normal CDF，写入 1-element fp32 output buffer (out_ptr)。不需要 torch.tensor 创建任何东西。
- apply_threshold_relu_to_bf16:
  - 每个程序实例处理一行 (b, s)。
  - 从 mean_ptr/std_ptr 中加载该行的 mean 和 std。
  - 从 z_ptr 中加载 scalar z (icdf result)。
  - thr = mean + std * z (fp32)。
  - 第二遍 pass 遍历 H，读取 in_ptr 中的元素，将其转换为 fp32，计算 y = max(x - thr, 0.0) 并写入 out_ptr 为 bfloat16。

3) 数值正确性细节
- 保证 sum/sumsq 累加正确，不能遗漏任何项，并且行 ID 计算 b, s 正确 (row = program_id(0) in [0, B*S) => b = row // S, s = row % S)。
- std 为 population std (unbiased=False) 即 sqrt(E[x^2] - (E[x])^2)。
- A&S approximation constants 正确无误：
  - lower region: x = sqrt(-2*log(p)), nd = (c1*x + c2*x^2 + ... + c6) / (d1*x + d2*x^2 + ... + d4*x^3 + 1)
  - upper region: x = sqrt(-2*log(1-p)), nd = -((c1*x + ... + c6) / (d1*x + ... + d4*x^3 + 1))
  - central region: q = p - 0.5, r = q^2, nd = (a1*r + ... + a6) * q / (b1*r + ... + b5)

4) 性能
- compute_mean_std_fp32 两遍 over H，H 最大 12288，在一个程序实例中完成，合理开销。
- compute_icdf_scalar 一次计算，标量开销可忽略。
- apply kernel 两遍 pass (compute threshold, apply) 也很合理。

```python
import torch
import triton
import triton.language as tl


@triton.jit
def compute_mean_std_fp32(in_ptr, mean_ptr, std_ptr, B, S, H, BLOCK: tl.constexpr):
    # One program per (b, s) row: pid in [0, B*S)
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # First pass: accumulate sum and sum of squares in fp32
    sum_val = 0.0
    sum_sq = 0.0

    offsets = tl.arange(0, BLOCK)
    i = 0
    base = b * S * H + s * H
    while i < H:
        idx = i + offsets
        mask = idx < H
        x = tl.load(in_ptr + base + idx, mask=mask, other=0.0)
        x = x.to(tl.float32)
        sum_val += tl.sum(x, axis=0)
        sum_sq += tl.sum(x * x, axis=0)
        i += BLOCK

    n = H
    mean = sum_val / n
    var = sum_sq / n - mean * mean  # population variance (unbiased=False)
    std = tl.sqrt(var)

    # Store per-row mean and std
    tl.store(mean_ptr + row, mean)
    tl.store(std_ptr + row, std)


@triton.jit
def compute_icdf_scalar(out_ptr, p_val, p_low, p_high, BLOCK: tl.constexpr):
    # Abramowitz & Stegun 5th-order rational approximation for standard normal inverse CDF

    # Coefficients
    a1 = -3.969683028665376e+01
    a2 = 2.209460984245205e+02
    a3 = -2.759285104469687e+02
    a4 = 1.383577518672690e+02
    a5 = -3.066479806614716e+01
    a6 = 2.506628277459239e+00

    b1 = -5.447609879822406e+01
    b2 = 1.615858368580409e+02
    b3 = -1.556989798598866e+02
    b4 = 6.680131188771972e+01
    b5 = -1.328068155288572e+01

    c1 = -7.784894002430293e-03
    c2 = -3.223964580411365e-01
    c3 = -2.400758277161838e+00
    c4 = -2.549732539343734e+00
    c5 = 4.374664141464968e+00
    c6 = 2.938163982698783e+00

    d1 = 7.784695709041462e-03
    d2 = 3.224671290700398e-01
    d3 = 2.445134137142996e+00
    d4 = 3.754408661907416e+00

    if p_val <= p_low:
        q = tl.sqrt(-2.0 * tl.log(p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    elif p_val >= p_high:
        q = tl.sqrt(-2.0 * tl.log(1.0 - p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    else:
        q = p_val - 0.5
        r = q * q
        poly = (((((a1 * r + a2) * r + a3) * r + a4) * r + a5) * r + a6)
        den = (((((b1 * r + b2) * r + b3) * r + b4) * r + b5))
        nd = poly * q / den

    tl.store(out_ptr, nd)


@triton.jit
def apply_threshold_relu_to_bf16(in_ptr, out_ptr, mean_ptr, std_ptr, B, S, H, z_ptr, BLOCK: tl.constexpr):
    # One program per (b, s) row
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # Load per-row mean and std
    mean = tl.load(mean_ptr + row)
    std = tl.load(std_ptr + row)

    # Load scalar z (inverse CDF) from z_ptr[0]
    z = tl.load(z_ptr)

    # Compute threshold for this row (fp32 scalar)
    thr = mean + std * z  # fp32

    # Second pass: apply y = max(x - thr, 0) to each feature
    offsets = tl.arange(0, BLOCK)
    base = b * S * H + s * H
    i = 0
    while i < H:
        idx = i + offsets
        mask = idx < H
        x = tl.load(in_ptr + base + idx, mask=mask, other=0.0)
        x = x.to(tl.float32)
        y = x - thr
        y = tl.maximum(y, 0.0)
        tl.store(out_ptr + base + idx, y.to(tl.bfloat16), mask=mask)
        i += BLOCK


class ModelNew(torch.nn.Module):
    def forward(self, inputs: torch.Tensor, target_sparsity: float) -> torch.Tensor:
        # If no sparsity requested, just return inputs
        if target_sparsity == 0.0:
            return inputs

        # Ensure 3D input: [B, S, H]
        assert inputs.ndim == 3, "inputs must be 3D: [B, S, H]"
        inputs = inputs.contiguous()
        B, S, H = inputs.shape
        device = inputs.device

        # Allocate buffers for mean and std (fp32)
        mean = torch.empty((B * S,), dtype=torch.float32, device=device)
        std = torch.empty((B * S,), dtype=torch.float32, device=device)

        # Launch kernel to compute mean and std per (b, s) row
        BLOCK = 1024
        grid = (B * S,)
        compute_mean_std_fp32[grid](
            inputs, mean, std, B, S, H,
            BLOCK=BLOCK,
            num_warps=4,
        )

        # Compute inverse normal CDF for target_sparsity using Triton
        z_out = torch.empty((1,), dtype=torch.float32, device=device)
        p_low = 0.02425
        p_high = 1.0 - p_low
        grid_icdf = (1,)
        compute_icdf_scalar[grid_icdf](
            z_out, float(target_sparsity), p_low, p_high,
            BLOCK=1,  # scalar kernel, single value computed
            num_warps=1,
        )

        # Prepare output (bfloat16) and apply threshold + ReLU
        out = torch.empty((B, S, H), dtype=torch.bfloat16, device=device)
        apply_threshold_relu_to_bf16[grid](
            inputs, out, mean, std, B, S, H, z_out,
            BLOCK=BLOCK,
            num_warps=4,
        )

        return out
```

```python
import torch
import triton
import triton.language as tl


@triton.jit
def compute_mean_std_fp32(in_ptr, mean_ptr, std_ptr, B, S, H, BLOCK: tl.constexpr):
    # One program per (b, s) row: pid in [0, B*S)
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # First pass: accumulate sum and sum of squares in fp32
    sum_val = 0.0
    sum_sq = 0.0

    offsets = tl.arange(0, BLOCK)
    i = 0
    base = b * S * H + s * H
    while i < H:
        idx = i + offsets
        mask = idx < H
        x = tl.load(in_ptr + base + idx, mask=mask, other=0.0)
        x = x.to(tl.float32)
        sum_val += tl.sum(x, axis=0)
        sum_sq += tl.sum(x * x, axis=0)
        i += BLOCK

    n = H
    mean = sum_val / n
    var = sum_sq / n - mean * mean  # population variance (unbiased=False)
    std = tl.sqrt(var)

    # Store per-row mean and std
    tl.store(mean_ptr + row, mean)
    tl.store(std_ptr + row, std)


@triton.jit
def compute_icdf_scalar_newton(out_ptr, p_val, BLOCK: tl.constexpr):
    # Compute inverse standard normal CDF for p_val via Newton's method:
    # Solve f(z) = 0.5 * (1 + erf(z / sqrt(2))) - p_val = 0
    # f'(z) = (2/sqrt(pi)) * exp(-z^2 / 2)
    sqrt2 = 1.4142135623730951
    two_over_sqrt_pi = 2.0 / 8.853645121445618  # 1/sqrt(pi/2)

    # Initial guess: z0 = sign(p-0.5) * 5.0 * (p-0.5)
    # Note: Triton doesn't provide erf, but we can loop and update out_ptr
    z = tl.load(out_ptr)  # initialize z; will be updated in loop
    # Since Triton JIT cannot use arbitrary control flow outside loops, we implement fixed iterations.
    # Use 6 iterations for good accuracy.
    # We need to compute erf(z/sqrt(2)); implement a simple approximation using Taylor series up to n=6 for |z|<=2
    # and use erf(z) ≈ sign(z) * (1 - exp(-z^2) * P(t)) for better accuracy. However, Triton lacks some math fns.
    # To keep it simple and accurate enough, we use a standard approximation for erf and Newton steps.
    # Here we approximate erf(u) with a well-known formula (Abramowitz-Stegun 7.1.26):
    # erf(u) ≈ 1 - (a1 t + a2 t^2 + a3 t^3 + a4 t^4 + a5 t^5) * exp(-u^2), where t = 1 / (1 + p u), p = 0.3275911
    # We'll implement this per iteration to get a good erf(z/sqrt(2)).

    a1 = 0.254829592
    a2 = -0.284496736
    a3 = 1.421413741
    a4 = -1.453152027
    a5 = 1.061405429
    p = 0.3275911

    # Newton iterations: update z for 6 steps
    # We'll recompute erf each time; Triton supports while loops.
    # Note: Triton JIT does not allow while with dynamic stop; use a fixed iteration count.
    # Implement 6 iterations with a for loop. Triton supports for loops with constexpr range.
    for _ in range(6):
        u = z / sqrt2
        au = tl.abs(u)
        t = 1.0 / (1.0 + p * au)
        # Horner evaluation of poly = (((((a5*t + a4)*t + a3)*t + a2)*t + a1)*t)
        poly = (((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t)
        erf_approx = 1.0 - poly * tl.exp(-(au * au))  # erf(u) with sign u>0; using abs, sign handled later
        sign = tl.where(u >= 0.0, 1.0, -1.0)
        erf_approx = sign * erf_approx
        phi = 0.5 * (1.0 + erf_approx) - p_val
        # f'(z) = (2/sqrt(pi)) * exp(-z^2 / 2)
        df = two_over_sqrt_pi * tl.exp(-0.5 * z * z)
        # Newton update: z_next = z - phi / df
        z = z - phi / df
        tl.store(out_ptr, z)

    tl.store(out_ptr, z)


@triton.jit
def apply_threshold_relu_to_bf16(in_ptr, out_ptr, mean_ptr, std_ptr, B, S, H, z_ptr, BLOCK: tl.constexpr):

    row = tl.program_id(0)
    b = row // S
    s = row % S

    # Load per-row mean and std
    mean = tl.load(mean_ptr + row)
    std = tl.load(std_ptr + row)

    # Load scalar z (inverse CDF) from z_ptr[0]
    z = tl.load(z_ptr)

    # Compute threshold for this row (fp32 scalar)
    thr = mean + std * z  # fp32

    # Second pass: apply y = max(x - thr, 0) to each feature
    offsets = tl.arange(0, BLOCK)
    base = b * S * H + s * H
    i = 0
    while i < H:
        idx = i + offsets
        mask = idx < H
        x = tl.load(in_ptr + base + idx, mask=mask, other=0.0)
        x = x.to(tl.float32)
        y = x - thr
        y = tl.maximum(y, 0.0)
        tl.store(out_ptr + base + idx, y.to(tl.bfloat16), mask=mask)
        i += BLOCK


class ModelNew(torch.nn.Module):
    def forward(self, inputs: torch.Tensor, target_sparsity: float) -> torch.Tensor:
        # If no sparsity requested, just return inputs
        if target_sparsity == 0.0:
            return inputs

        # Ensure 3D input: [B, S, H]
        assert inputs.ndim == 3, "inputs must be 3D: [B, S, H]"
        inputs = inputs.contiguous()
        B, S, H = inputs.shape
        device = inputs.device

        # Allocate buffers for mean and std (fp32)
        mean = torch.empty((B * S,), dtype=torch.float32, device=device)
        std = torch.empty((B * S,), dtype=torch.float32, device=device)

        # Launch kernel to compute mean and std per (b, s) row
        BLOCK = 1024
        grid = (B * S,)
        compute_mean_std_fp32[grid](
            inputs, mean, std, B, S, H,
            BLOCK=BLOCK,
            num_warps=4,
        )

        # Compute inverse normal CDF for target_sparsity using Triton (Newton method)
        z_out = torch.empty((1,), dtype=torch.float32, device=device)
        # Use p_val directly; the kernel will run several iterations to refine z
        grid_icdf = (1,)
        compute_icdf_scalar_newton[grid_icdf](
            z_out, float(target_sparsity),
            BLOCK=1,  # scalar kernel computes into z_out[0]
            num_warps=1,
        )

        # Prepare output (bfloat16) and apply threshold + ReLU
        out = torch.empty((B, S, H), dtype=torch.bfloat16, device=device)
        apply_threshold_relu_to_bf16[grid](
            inputs, out, mean, std, B, S, H, z_out,
            BLOCK=BLOCK,
            num_warps=4,
        )

        return out
```

- compute_mean_std_fp32: 严格两遍遍历 H，计算 sum 和 sum of squares，并且计算 population std (unbiased=False) 以符合 PyTorch torch.std(dim=-1, unbiased=False) 的行为。

- 返回 bfloat16 结果。

之前的失败原因
- 评价系统多次标记为 “INCORRECT_NUMERICAL”，意味着与 PyTorch 参考结果有差异。主要原因之一是计算 inverse normal CDF 时所使用的 approximation 不够精确，或者在 apply 阈值时有 mask/loop 处理错误导致某些元素未被正确覆盖或处理，特别是在 H 较大时 (e.g., 12288)。
- 我们的 Triton kernels 必须完全负责所有计算，host 代码不能有任何 PyTorch tensor math (例如 torch.tensor, torch.mean, torch.std, F.relu)。

本次解决方案
- compute_mean_std_fp32 kernel: 一个程序实例处理一行 (b, s) => pid in [0, B*S)。干净的两遍 pass：
  - 第一遍累加 sum 和 sum of squares (fp32)。
  - 计算 mean = sum / H 和 var = sum_sq / H - mean^2 (population variance, unbiased=False)。std = sqrt(var)。
  - 写入 mean_ptr[row] 和 std_ptr[row]。

- compute_icdf_scalar_bipartite(out_ptr, p_val, p_low, p_high): 使用标准 Abramowitz & Stegun 5th-order rational approximation，但为了提高鲁棒性，采用 piecewise logic：
  - lower tail: p <= p_low, q = sqrt(-2*log(p)), nd = -((c1*q + c2*q^2 + ... + c6) / (d1*q + d2*q^2 + ... + d4*q^3 + 1))
  - upper tail: p >= p_high, q = sqrt(-2*log(1 - p)), nd = -((c1*q + ... + c6) / (d1*q + ... + d4*q^3 + 1)) [with negative sign due to sign of z]
  - central region: p in (p_low, p_high), q = p - 0.5, r = q^2, nd = (a1*r + ... + a6) * q / (b1*r + ... + b5)
  注意 piecewise logic 不能颠倒顺序 (中心区域不能被误判为尾部)；这里明确先判断 p <= p_low，再判断 p >= p_high，否则 else 区域就是中心区域。

- apply_threshold_relu_to_bf16 kernel: 一个程序实例处理一行 (b, s)。从 mean_ptr/std_ptr 读取 per-row mean 和 std (fp32)；从 z_ptr 读取 scalar z (fp32)；计算 thr = mean + std * z (fp32)。第二遍 pass 遍历 H，读取 input 元素转换为 fp32，计算 y = max(x - thr, 0.0) 并以 bfloat16 写入输出 tensor。

- ModelNew.forward: target_sparsity == 0.0 直接返回 inputs。否则，强制 inputs.contiguous()，分配 mean/std buffers (fp32) 和 output (bfloat16)：
  - Launch compute_mean_std_fp32: grid=(B*S,).
  - Launch compute_icdf_scalar_bipartite: grid=(1,), p_low=0.02425, p_high=0.97575, p_val=target_sparsity. 结果写入 z_out (1-element fp32 tensor).
  - Launch apply_threshold_relu_to_bf16: grid=(B*S,).

这样做的优点
- 严格 Triton-only，host 代码不参与任何 tensor math。
- compute_icdf 使用 Abramowitz & Stegun approximation (经典且准确) 与 piecewise logic，比简单的牛顿法更为准确，更接近 torch.special.erfinv 的结果。
- apply kernel 清晰，H 采用 BLOCK=1024 的 while 循环处理，对 H=12288 也很合适，保证所有元素都被覆盖。

import torch
import triton
import triton.language as tl


@triton.jit
def compute_mean_std_fp32(in_ptr, mean_ptr, std_ptr, B, S, H, BLOCK: tl.constexpr):
    # One program per (b, s) row: pid in [0, B*S)
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # First pass: accumulate sum and sum of squares in fp32
    sum_val = 0.0
    sum_sq = 0.0

    offsets = tl.arange(0, BLOCK)
    i = 0
    base = b * S * H + s * H
    while i < H:
        idx = i + offsets
        mask = idx < H
        x = tl.load(in_ptr + base + idx, mask=mask, other=0.0)
        x = x.to(tl.float32)
        sum_val += tl.sum(x, axis=0)
        sum_sq += tl.sum(x * x, axis=0)
        i += BLOCK

    n = H
    mean = sum_val / n
    var = sum_sq / n - mean * mean  # population variance (unbiased=False)
    std = tl.sqrt(var)

    # Store per-row mean and std
    tl.store(mean_ptr + row, mean)
    tl.store(std_ptr + row, std)
