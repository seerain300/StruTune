明白，之前提交被判定为违反 TRITON-ONLY 要求，主要原因是 host 代码使用了 PyTorch 的 tensor math 方法（如 .log(), .mean(), .std(), torch.quantile）。根据严格要求，所有计算必须在 Triton kernels 中完成，host 仅负责分配 tensors、设置 grid、决定是否 launch，并返回最终 tensor。

经过仔细思考，我发现要完全在 Triton 中精确复现原始 PyTorch 逻辑，尤其是统计计算和逆正态 CDF 的数值一致性，需要高度复杂的 Triton 实现，并且容易出现细微偏差。然而，评价系统明确要求 Triton-only，并且之前多次标记为不正确，因此我将重新设计为完全使用 Triton，即使统计计算的细微差异可能存在，也要尽力保持一致性和准确性。

核心思路
- ModelNew.forward 只做元数据操作：
  - target_sparsity == 0.0 时直接返回 inputs 以满足语义。
  - 强制 inputs 为 contiguous 以便正确指针计算。
  - 准备必要的输出 tensors，但不进行任何 tensor math。
- Triton kernels：
  1) compute_mean_std_fp32: 采用与 PyTorch 一致的统计 (unbiased=False for std) 计算每行 (b, s) 的 mean 和 std (fp32)：
     - 第一遍 pass 遍历 H，计算 sum 和 sum of squares；
     - mean = sum / H, var = sum_sq / H - mean^2, std = sqrt(var)。
     - 将 mean 和 std 写入 [B*S] 的 fp32 buffer 中。
  2) compute_icdf_scalar: 逆正态 CDF (标准正态分布) 采用 Abramowitz & Stegun 5th-order rational approximation，并根据 p <= p_low / p >= p_high / p 中间区域分别处理，直接写入 1-element fp32 buffer (z_ptr)。不依赖任何 PyTorch tensor math，接收 target_sparsity 作为 Python float 参数。
  3) apply_threshold_relu_to_bf16: 读取 per-row mean 和 std (从 mean_ptr/std_ptr 由 row id 访问)，读取 z (从 z_ptr)，计算 threshold = mean + std * z (fp32)，然后对 H 维度进行第二遍遍历，计算 y = max(x - threshold, 0) 并写入 bfloat16 output tensor。这也是真正的 elementwise computation 在 Triton 中完成。

这样，所有的计算都在 Triton kernels 中完成，host 仅管理 tensors 和 launch，满足 TRITON-ONLY 要求。为了减少代码长度并聚焦核心功能，我将只提供最终的 Triton kernels 和 ModelNew.forward 实现，确保没有任何 host-side tensor math。

注意事项
- 由于 Triton 不支持直接定义可变长度的动态 while loop 中的 “other” 常量不同，我将使用 BLOCK 大小为 1024，并在 kernel 中进行 loop 控制，mask 处理保证安全，虽然 H 为 12288，但 12 次迭代是可行的。
- std 使用 unbiased=False 公式 (population) 与 torch.std(..., unbiased=False) 一致。
- 逆正态 CDF 采用 A&S approximation，与 torch.special.erfinv 相比可能存在细微差异，但我们会尽量接近。若仍有不通过，请告知具体哪一行有偏差，我可以调整 p_low/p_high 以改善精度。

完整代码如下：

```python
import torch
import triton
import triton.language as tl


@triton.jit
def compute_mean_std_fp32(in_ptr, mean_ptr, std_ptr, B, S, H, BLOCK: tl.constexpr):
    # One program per (b, s) row: pid in [0, B*S)
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # First pass: accumulate sum and sum of squares over H in fp32
    sum_val = 0.0
    sum_sq = 0.0

    offsets = tl.arange(0, BLOCK)
    base = b * S * H + s * H
    i = 0
    while i < H:
        idx = i + offsets
        mask = idx < H
        x = tl.load(in_ptr + base + idx, mask=mask, other=0.0)
        x = x.to(tl.float32)
        # reduce within the vector
        sum_val += tl.sum(x, axis=0)
        sum_sq += tl.sum(x * x, axis=0)
        i += BLOCK

    n = H
    mean = sum_val / n
    var = sum_sq / n - mean * mean  # population variance (unbiased=False)
    std = tl.sqrt(var)

    tl.store(mean_ptr + row, mean)
    tl.store(std_ptr + row, std)


@triton.jit
def compute_icdf_scalar(out_ptr, p_val, p_low, p_high, BLOCK: tl.constexpr):
    # Abramowitz & Stegun 5th-order rational approximation for standard normal inverse CDF
    # Coefficients
    a1 = -3.969683028665376e+01
    a2 = 2.209460984245205e+02
    a3 = -2.759285104469687e+02
    a4 = 1.383577518672690e+02
    a5 = -3.066479806614716e+01
    a6 = 2.506628277459239e+00

    b1 = -5.447609879822406e+01
    b2 = 1.615858368580409e+02
    b3 = -1.556989798598866e+02
    b4 = 6.680131188771972e+01
    b5 = -1.328068155288572e+01

    c1 = -7.784894002430293e-03
    c2 = -3.223964580411365e-01
    c3 = -2.400758277161838e+00
    c4 = -2.549732539343734e+00
    c5 = 4.374664141464968e+00
    c6 = 2.938163982698783e+00

    d1 = 7.784695709041462e-03
    d2 = 3.224671290700398e-01
    d3 = 2.445134137142996e+00
    d4 = 3.754408661907416e+00

    # piecewise
    if p_val <= p_low:
        q = tl.sqrt(-2.0 * tl.log(p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    elif p_val >= p_high:
        q = tl.sqrt(-2.0 * tl.log(1.0 - p_val))
        poly = -(((((c1 * q + c2) * q + c3) * q + c4) * q + c5) * q + c6)
        den = (((((d1 * q + d2) * q + d3) * q + d4) * q + 1.0))
        nd = poly / den
    else:
        q = p_val - 0.5
        r = q * q
        poly = (((((a1 * r + a2) * r + a3) * r + a4) * r + a5) * r + a6)
        den = (((((b1 * r + b2) * r + b3) * r + b4) * r + b5))
        nd = poly * q / den

    tl.store(out_ptr, nd)


@triton.jit
def apply_threshold_relu_to_bf16(in_ptr, out_ptr, mean_ptr, std_ptr, z_ptr, B, S, H, BLOCK: tl.constexpr):
    # One program per (b, s) row: pid in [0, B*S)
    row = tl.program_id(0)
    b = row // S
    s = row % S

    # Load per-row mean and std (fp32) and z scalar (fp32)
    mean = tl.load(mean_ptr + row)
    std = tl.load(std_ptr + row)
    z = tl.load(z_ptr)

    thr = mean + std * z  # fp32

    # Second pass: y = max(x - thr, 0), store as bfloat16
    offsets = tl.arange(0, BLOCK)
    base = b * S * H + s * H
    i = 0
    while i < H:
        idx = i + offsets
        mask = idx < H
        x = tl.load(in_ptr + base + idx, mask=mask, other=0.0)
        x = x.to(tl.float32)
        y = x - thr
        y = tl.maximum(y, 0.0)
        tl.store(out_ptr + base + idx, y.to(tl.bfloat16), mask=mask)
        i += BLOCK


class ModelNew(torch.nn.Module):
    def forward(self, inputs: torch.Tensor, target_sparsity: float) -> torch.Tensor:
        # Handle trivial case: no sparsity
        if target_sparsity == 0.0:
            return inputs

        # Ensure contiguous input
        inputs = inputs.contiguous()

        assert inputs.ndim == 3, "inputs must be [B, S, H]"
        B, S, H = inputs.shape
        device = inputs.device

        # Prepare buffers
        mean_buf = torch.empty(B * S, dtype=torch.float32, device=device)
        std_buf = torch.empty(B * S, dtype=torch.float32, device=device)
        z_buf = torch.empty(1, dtype=torch.float32, device=device)

        # Launch kernels
        # 1) compute mean and std
        grid = (B * S,)
        compute_mean_std_fp32[grid](inputs, mean_buf, std_buf, B, S, H, BLOCK=1024)

        # 2) compute icdf scalar
        p_low = 0.02425
        p_high = 1.0 - p_low
        grid_icdf = (1,)
        compute_icdf_scalar[grid_icdf](z_buf, float(target_sparsity), p_low, p_high, BLOCK=1)

        # 3) apply threshold and relu, output bfloat16
        out = torch.empty_like(inputs, dtype=torch.bfloat16, device=device)
        apply_threshold_relu_to_bf16[grid](inputs, out, mean_buf, std_buf, z_buf, B, S, H, BLOCK=1024)

        return out
```

重点说明
- 所有 tensor math 都在 Triton kernels 中完成：
  - compute_mean_std_fp32 计算每行 mean 和 std；
  - compute_icdf_scalar 计算逆正态 CDF 并写入 z_buf；
  - apply_threshold_relu_to_bf16 应用 threshold 并写入 bfloat16 output。
- host 代码仅负责：
  - 检查 target_sparsity==0.0；
  - inputs.contiguous()；
  - buffer 分配；
  - kernel launch；
  - 返回结果 tensor。
- 我们使用 unbiased=False 公式来计算 std，与 torch.std(..., unbiased=False) 一致；
- icdf 采用 A&S approximation，在 Triton 中实现，不使用 PyTorch tensor math；
- apply kernel 在 fp32 中进行计算并最终写入 bfloat16，与原始 run 函数返回类型一致。
