Design summary:
- Inputs: hidden_states [B, S, H*D], and projection weights/biases:
  - q_proj_weight: [H*D, K], q_proj_bias: [H*D]
  - k_proj_weight: [Hv*D, K], k_proj_bias: [Hv*D]
  - v_proj_weight: [Hv*D, K], v_proj_bias: [Hv*D]
  - o_proj_weight: [D_out, H_out*D], no bias (the original uses F.linear(..., None) in the last step; we’ll match it by not using bias for O).
  - q_norm_weight, k_norm_weight: [H*D], shape matches head_dim per head.
  - cos, sin: [D], rotation for last half dimension (64).
- Steps in Triton:
  1) Q = linear(hidden_states, q_proj_weight, q_proj_bias) -> [B, S, H*D].
  2) K = linear(hidden_states, k_proj_weight, k_proj_bias) -> [B, S, Hv*D].
  3) V = linear(hidden_states, v_proj_weight, v_proj_bias) -> [B, S, Hv*D].
  4) RMSNorm on Q and K: x_norm = x * rsqrt(mean(x^2)+eps) * weight, where weight per head and eps default 1e-6.
  5) Transpose to [B, H, S, D] for queries and [B, Hv, S, D] for keys/values.
  6) Rotate Q and K for the second half of dimension (64): q_rot = cos*q + sin*(-q2), where q1,q2 split first/second half; similarly for K.
  7) For causal attention: S[b,h,i,j] = sum over k of Q[b,h,i,k] * K[b,h,k,j], scaled by SCALING. Implement in Triton: tile over i and j, loop k in tiles, load Q tile [BM, BK], K tile [BK, BN], accumulate.
  8) Apply causal mask by setting S[b,h,i,j] = -inf when i < j.
  9) Softmax along j (per row) in Triton: for each i, compute max, exp, sum, normalize, write back.
  10) Output = S @ V^T (per head), where S is [B, H, S, S] and V is [B, Hv, S, D], but we expand K/V to 96 heads as in original GQA.   11) Final projection: Out[B,S,H_out*D] = linear(AttentionOut[B,S,H_out*D], o_proj_weight) without bias. Implement as linear_gemm_nobias_kernel.
