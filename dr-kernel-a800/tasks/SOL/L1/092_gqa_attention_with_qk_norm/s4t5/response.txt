明白了，之前的实现确实存在严重问题：
- host 代码仍然包含一些 PyTorch tensor math（例如 softmax、mask 生成等），这违反了 “Triton-Only” 的严格要求。
- 有一些 Triton kernel 可能在某些配置下未被实际调用，或者有数据移动/reshape 逻辑不够健壮，导致运行错误。

为了彻底修复并满足要求，我将重新设计 ModelNew.forward：
- forward 不调用任何 PyTorch 计算 API（包括 torch.matmul, torch.nn.functional.linear, torch.softmax, torch.triu, torch.tril, torch.triu, etc.）。所有计算都在 Triton kernels 中完成。
- forward 仅负责：
  - 创建/准备输入张量的指针和 shape，
  - 分配输出张量，
  - 设置 grid 和 launch Triton kernels，
  - 进行必要的 reshape/view 作为元数据操作。
- 我会确保所有必需的 Triton kernels 都被 launch，并且没有遗漏。具体来说，这些计算步骤将在 Triton 中实现：
  1) Linear with bias: F.linear(hidden, W, b) -> hidden @ W.T + b
  2) RMSNorm: rmsnorm(X, weight) -> X * rsqrt(mean(X^2) + eps)
  3) Rotation (RoPE) for Q and K: rotate_half: [q1, -q2]
  4) Grouped-Query Attention mapping: expand key/value heads from 8 to 96
  5) Attention scores: Q @ K^T with scaling
  6) Softmax over last dimension (sequence length) with causal mask (implemented in a Triton kernel)
  7) Attn output: Softmax @ V
  8) Output projection: linear(attn_output, o_proj_weight, None)

特别注意因果 mask：为了完全使用 Triton 并且不调用 torch.triu，我会在 Triton 中构建一个 per-(batch, head) 的 mask，表示因果关系：对于位置 i 查询 j，如果 j < i 则 mask[i, j] = 0.0 (不影响 softmax), 否则 -inf。这等价于 torch.triu(..., diagonal=1) 的效果。

此外，对于不同 seq_len 的情况，我将确保 kernels 中的 loop 正确处理 head_dim=128 和任意 seq_len，并且 grid 的设置是正确的。

我将提供完整的 ModelNew 代码，其中：
- 有完整的 Triton kernels（至少10个）并且都被 forward 调用，
- 没有任何 torch 计算在 host 代码中，
- 并且着重修复了之前可能导致运行错误的 mask 和 softmax 部分。

# X: [B, S, H_in], W: [H_out, H_in], b: [H_out] -> Out: [B, S, H_out]
@triton.jit
def linear_bias_kernel(
    X_ptr, W_ptr, B_ptr, Out_ptr,
    Bsz: tl.constexpr, Ssz: tl.constexpr, H_in: tl.constexpr, H_out: tl.constexpr,
    stride_x_b, stride_x_s, stride_x_h,
    stride_w_o, stride_w_i,
    stride_out_b, stride_out_s, stride_out_h,
    BLOCK_IN: tl.constexpr, BLOCK_OUT: tl.constexpr,
):
    # program ids: (b, s, o)
    b = tl.program_id(0)
    s = tl.program_id(1)
    o = tl.program_id(2)

    acc = tl.zeros((), dtype=tl.float32)
    # iterate over output channels in tiles of BLOCK_OUT
    for i in range(0, H_out, BLOCK_OUT):
        o_offsets = i + tl.arange(0, BLOCK_OUT)
        mask_o = o_offsets < H_out

        # load bias for this o tile
        b_vals = tl.load(B_ptr + o_offsets, mask=mask_o, other=0.0).to(tl.float32)

        # accumulate
        acc = tl.zeros([BLOCK_OUT], dtype=tl.float32)

        # iterate over input channels in tiles of BLOCK_IN
        for j in range(0, H_in, BLOCK_IN):
            i_offsets = j + tl.arange(0, BLOCK_IN)
            mask_i = i_offsets < H_in

            # load X[b, s, i_offsets]
            x_ptrs = X_ptr + b * stride_x_b + s * stride_x_s + i_offsets * stride_x_h
            x_vals = tl.load(x_ptrs, mask=mask_i, other=0.0).to(tl.float32)  # [BLOCK_IN]

            # load W[o_offsets, i_offsets] as [BLOCK_OUT, BLOCK_IN]
            w_ptrs = W_ptr + o_offsets[:, None] * stride_w_o + i_offsets[None, :] * stride_w_i
            w_vals = tl.load(w_ptrs, mask=mask_o[:, None] & mask_i[None, :], other=0.0).to(tl.float32)  # [BLOCK_OUT, BLOCK_IN]

            # acc += sum(W[o,i] * X[b,s,i]) over i
            acc += tl.sum(w_vals * x_vals[None, :], axis=1)  # [BLOCK_OUT]

        # add bias and store
        out_ptrs = Out_ptr + b * stride_out_b + s * stride_out_s + o_offsets * stride_out_h
        tl.store(out_ptrs, acc + b_vals, mask=mask_o)

def rmsnorm_kernel(

    stride_x_b, stride_x_s, stride_x_h,
    stride_w_h,
    stride_out_b, stride_out_s, stride_out_h,

    BLOCK_H: tl.constexpr,
):

    s = tl.program_id(1)

    sum_sq = 0.0

    for i in range(0, H, BLOCK_H):

def rotate_half_kernel(
    In_ptr, Out_ptr,
    Bsz: tl.constexpr, Ssz: tl.constexpr, H: tl.constexpr,
    stride_in_b, stride_in_s, stride_in_h,

    BLOCK_H: tl.constexpr,
):

    s = tl.program_id(1)

        tl.store(out_ptrs, q_rot, mask=mask_h)

# Correct Kernel 4A: matmul_qk_kernel with inputs Q_t: [B, H, S], K: [S, H] -> Out: [B, H, S]

def matmul_qk_kernel_t(

        # We write Out[b, h, s] = acc[h] for each s, but Out has shape [B, H, S] with strides: b, h, s.

# Kernel 5: Softmax with causal mask over last dim (S) for each (b, h)
# Input: In[B, H, S], Output: Out[B, H, S]
# Causal: if j < i then mask = 0, else -inf. Implement via passing Mask[B, H, S] from host.
@triton.jit
def softmax_mask_kernel(
    In_ptr, Mask_ptr, Out_ptr,
    Bsz: tl.constexpr, H: tl.constexpr, Ssz: tl.constexpr,
    stride_in_b, stride_in_h, stride_in_s,
    stride_mask_b, stride_mask_h, stride_mask_s,
    stride_out_b, stride_out_h, stride_out_s,
    BLOCK_S: tl.constexpr,
):
    b = tl.program_id(0)
    h = tl.program_id(1)

    # compute row-wise softmax over S
    # First, load row and apply mask
    row_max = -float('inf')
    for j in range(0, Ssz, BLOCK_S):
        s_offsets = j + tl.arange(0, BLOCK_S)
        mask_s = s_offsets < Ssz
        in_ptrs = In_ptr + b * stride_in_b + h * stride_in_h + s_offsets * stride_in_s
        vals = tl.load(in_ptrs, mask=mask_s, other=-float('inf')).to(tl.float32)
        mask_ptrs = Mask_ptr + b * stride_mask_b + h * stride_mask_h + s_offsets * stride_mask_s
        m = tl.load(mask_ptrs, mask=mask_s, other=0.0).to(tl.float32)
        vals = vals + m  # add mask
        # reduce to max
        row_max = tl.maximum(row_max, tl.max(vals, axis=0))

    # compute sum of exp
    sum_exp = 0.0
    for j in range(0, Ssz, BLOCK_S):
        s_offsets = j + tl.arange(0, BLOCK_S)
        mask_s = s_offsets < Ssz
        in_ptrs = In_ptr + b * stride_in_b + h * stride_in_h + s_offsets * stride_in_s
        vals = tl.load(in_ptrs, mask=mask_s, other=-float('inf')).to(tl.float32)
        mask_ptrs = Mask_ptr + b * stride_mask_b + h * stride_mask_h + s_offsets * stride_mask_s
        m = tl.load(mask_ptrs, mask=mask_s, other=0.0).to(tl.float32)
        vals = vals + m
        exp_vals = tl.exp(vals - row_max)
        sum_exp += tl.sum(exp_vals, axis=0)

    inv_sum = 1.0 / sum_exp
    # write normalized
    for j in range(0, Ssz, BLOCK_S):
        s_offsets = j + tl.arange(0, BLOCK_S)
        mask_s = s_offsets < Ssz
        in_ptrs = In_ptr + b * stride_in_b + h * stride_in_h + s_offsets * stride_in_s
        vals = tl.load(in_ptrs, mask=mask_s, other=-float('inf')).to(tl.float32)
        mask_ptrs = Mask_ptr + b * stride_mask_b + h * stride_mask_h + s_offsets * stride_mask_s
        m = tl.load(mask_ptrs, mask=mask_s, other=0.0).to(tl.float32)
        vals = vals + m
        exp_vals = tl.exp(vals - row_max)
        out_vals = exp_vals * inv_sum
        out_ptrs = Out_ptr + b * stride_out_b + h * stride_out_h + s_offsets * stride_out_s
        tl.store(out_ptrs, out_vals, mask=mask_s)

# Softmax: [B, H, S], V: [S, H] -> Out: [B, S, H]
@triton.jit
def matmul_attn_kernel(

    stride_s_b, stride_s_h, stride_s_s,     # Softmax is [B, H, S]

    s = tl.program_id(1)
    acc = tl.zeros([BLOCK_H], dtype=tl.float32)

    for i in range(0, H, BLOCK_H):
        h_offsets = i + tl.arange(0, BLOCK_H)
        mask_h = h_offsets < H

        for j in range(0, Ssz, BLOCK_S):
            s_offsets = j + tl.arange(0, BLOCK_S)
            mask_s = s_offsets < Ssz

            # Softmax[b, h_offsets, s_offsets] -> [BLOCK_H, BLOCK_S]
            sm_ptrs = Softmax_ptr + b * stride_s_b + h_offsets[:, None] * stride_s_h + s_offsets[None, :] * stride_s_s
            sm_vals = tl.load(sm_ptrs, mask=mask_h[:, None] & mask_s[None, :], other=0.0).to(tl.float32)  # [BLOCK_H, BLOCK_S]

            v_ptrs = V_ptr + s_offsets[:, None] * stride_v_s + h_offsets[None, :] * stride_v_h
            v_vals = tl.load(v_ptrs, mask=mask_s[:, None] & mask_h[None, :], other=0.0).to(tl.float32)  # [BLOCK_S, BLOCK_H]

            # acc += sum over S: sm_vals @ v_vals
            acc += tl.sum(sm_vals * v_vals, axis=1)  # [BLOCK_H]

        # store acc to Out[b, s, h]
        out_ptrs = Out_ptr + b * stride_out_b + s * stride_out_s + h_offsets * stride_out_h
        tl.store(out_ptrs, acc, mask=mask_h)
