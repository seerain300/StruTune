Recap of the original computation and how we implement it in Triton:
1) Linear projections for Q, K, V:
   - hidden_states: [B, S, 12288]
   - q_proj_weight: [12288, 128], k_proj_weight: [12288, 128], v_proj_weight: [12288, 128]
   - F.linear(hidden_states, W, b) equals hidden_states @ W.T + b. We implement a Triton kernel linear_bias_kernel that computes X @ W.T + b for [B, S, H_in] and [H_out, H_in] with bias.
2) Reshape to heads:
   - query_states = [B, S, 96, 128], key_states = [B, S, 8, 128], value_states = [B, S, 8, 128]
3) RMSNorm on Q and K (optional in original but original code does it; we implement RMSNorm per row over head_dim = 128). We implement a Triton rmsnorm_kernel: for each [B, S, H] row, compute 1/sqrt(mean(x^2) + eps).
4) Rotate Q and K using sin/cos (RoPE):
   - Original rotates only the last 64 dimensions as [-q2, q1]. Implement a Triton rotate_half_kernel that, for a 128-length vector, applies (cos, sin) to split into halves: first 64 unchanged, last 64 rotated as [-q2, q1].
5) GQA: expand K and V to 96 heads:
   - Key/Value heads are 8, we expand to 96 via view() and reshape in Triton launch. The matmul kernel uses this expanded tensor directly (no torch operations).
6) Compute attention scores:
   - attn_scores = (Q_rot @ K_rot^T) * scaling, where scaling = 1/sqrt(head_dim).
   - Apply causal mask: upper-triangular with diagonal=1. We implement this in a Triton kernel that produces -inf for j < i (i.e., future positions). We also implement softmax along the last dimension (sequence length) for each (B, head). This softmax kernel takes the scores and mask as input and returns softmaxed output. Crucially, host code does not call torch.triu or torch.softmax; it launches a Triton softmax kernel.
7) Compute attention output:
   - attn_output = softmax(QK) @ V_expanded, implemented by a Triton matmul kernel matmul_attn_kernel. This kernel performs out[b, s, h] = sum_k softmax[b, s, k] * V[s, k] for each head h.
8) Output projection:
   - Final output = attn_output @ o_proj_weight (no bias). Implement with linear_bias_kernel for [B, S, 11008] @ [11008, 128] -> [B, S, 128] and then repeat the same approach for each head chunk. To avoid host-side Python loops, we implement a general linear_bias_kernel that can handle H_out > 128 via tiling and a grid over output channels. Here, we simplify by using a single launch with grid=(B*S, H_out) where H_out=128. If needed for other shapes, we tile.

Important design choices for performance:
- We implement all major operations in Triton: linear projections, RMSNorm, rotation, attention score computation, softmax, attention output matmul, and final projection. This avoids any PyTorch matmul or softmax.
- We tile over input channels (H_in) and output channels (H_out) inside each kernel using BLOCK sizes (e.g., 64 for H_in, 128 for H_out). These are chosen to match typical head_dim=128 and provide good performance across seq_len in the given workloads.
- We avoid any host-side computation (including mask creation with torch.triu). If we need masks, we create them with torch.zeros or torch.full but do not call torch.triu; the actual softmax is computed by Triton kernels.

# 1) Linear with bias: X @ W.T + b
# X: [B, S, H_in], W: [H_out, H_in], b: [H_out] -> Out: [B, S, H_out]
@triton.jit
def linear_bias_kernel(
    X_ptr, W_ptr, B_ptr, Out_ptr,
    Bsz: tl.constexpr, Ssz: tl.constexpr, H_in: tl.constexpr, H_out: tl.constexpr,
    stride_x_b, stride_x_s, stride_x_h,
    stride_w_o, stride_w_i,
    stride_out_b, stride_out_s, stride_out_h,
    BLOCK_IN: tl.constexpr, BLOCK_OUT: tl.constexpr,
):
    # Grid over (b, s, o)
    b = tl.program_id(0)
    s = tl.program_id(1)
    o = tl.program_id(2)

    acc = tl.zeros((), dtype=tl.float32)

    for i in range(0, H_out, BLOCK_OUT):
        o_offsets = i + tl.arange(0, BLOCK_OUT)
        mask_o = o_offsets < H_out

        b_vals = tl.load(B_ptr + o_offsets, mask=mask_o, other=0.0).to(tl.float32)

        acc = tl.zeros([BLOCK_OUT], dtype=tl.float32)

        for j in range(0, H_in, BLOCK_IN):
            i_offsets = j + tl.arange(0, BLOCK_IN)
            mask_i = i_offsets < H_in

            # Load X[b, s, i_offsets]
            x_ptrs = X_ptr + b * stride_x_b + s * stride_x_s + i_offsets * stride_x_h
            x_vals = tl.load(x_ptrs, mask=mask_i, other=0.0).to(tl.float32)

            # Load W[o_offsets, i_offsets] -> [BLOCK_OUT, BLOCK_IN]
            w_ptrs = W_ptr + o_offsets[:, None] * stride_w_o + i_offsets[None, :] * stride_w_i
            w_vals = tl.load(w_ptrs, mask=mask_o[:, None] & mask_i[None, :], other=0.0).to(tl.float32)

            # Accumulate dot products
            acc += tl.sum(w_vals * x_vals[None, :], axis=1)

        # Store out[b, s, o_offsets] + bias
        out_ptrs = Out_ptr + b * stride_out_b + s * stride_out_s + o_offsets * stride_out_h
        tl.store(out_ptrs, acc + b_vals, mask=mask_o)


# 2) RMSNorm per row over head_dim
# Input X: [B, S, H], weight: [H], Output Out: [B, S, H]
@triton.jit
def rmsnorm_kernel(
    X_ptr, weight_ptr, Out_ptr,
    Bsz: tl.constexpr, Ssz: tl.constexpr, H: tl.constexpr,
    stride_x_b, stride_x_s, stride_x_h,
    stride_w, stride_out_b, stride_out_s, stride_out_h,
    eps: tl.float32,
    BLOCK_H: tl.constexpr,
):
    b = tl.program_id(0)
    s = tl.program_id(1)

    # Compute variance across last dim H
    var = tl.zeros((), dtype=tl.float32)
    for h in range(0, H, BLOCK_H):
        h_offsets = h + tl.arange(0, BLOCK_H)
        mask = h_offsets < H
        x_ptrs = X_ptr + b * stride_x_b + s * stride_x_s + h_offsets * stride_x_h
        x_vals = tl.load(x_ptrs, mask=mask, other=0.0).to(tl.float32)
        var += tl.sum(x_vals * x_vals) / H

    scale = 1.0 / tl.sqrt(var + eps)

    # Scale and apply weight
    for h in range(0, H, BLOCK_H):
        h_offsets = h + tl.arange(0, BLOCK_H)
        mask = h_offsets < H
        x_ptrs = X_ptr + b * stride_x_b + s * stride_x_s + h_offsets * stride_x_h
        x_vals = tl.load(x_ptrs, mask=mask, other=0.0).to(tl.float32)
        w_vals = tl.load(weight_ptr + h_offsets, mask=mask, other=1.0).to(tl.float32)
        y = x_vals * scale * w_vals
        out_ptrs = Out_ptr + b * stride_out_b + s * stride_out_s + h_offsets * stride_out_h
        tl.store(out_ptrs, y, mask=mask)


# 3) Rotate half of a 128-length vector: apply sin/cos as [q1, -q2] on last 64, keep first 64.
@triton.jit
def rotate_half_kernel(

    N: tl.constexpr,  # N = 128
    stride_in_b, stride_in_s, stride_in_h,
    stride_out_b, stride_out_s, stride_out_h,
    BLOCK: tl.constexpr,  # e.g., 128
):

    b = tl.program_id(0)
    s = tl.program_id(1)

    h = tl.program_id(2)

    # Vector offsets
    offsets = h * N + tl.arange(0, N)

    # First half unchanged

    in_ptrs1 = In_ptr + b * stride_in_b + s * stride_in_s + offsets[:64]
    cos1 = tl.load(Cos_ptr + offsets[:64], mask=mask1, other=1.0)
    sin1 = tl.load(Sin_ptr + offsets[:64], mask=mask1, other=1.0)
    out1 = in_ptrs1 * cos1 + (in_ptrs1 >> 64) * sin1  # placeholder, but not used since we load new in_ptrs below

    # For Triton, we will do proper loads/stores:
    # Load first half
    q1 = tl.load(In_ptr + b * stride_in_b + s * stride_in_s + tl.arange(0, 64))
    # Load second half
    q2 = tl.load(In_ptr + b * stride_in_b + s * stride_in_s + tl.arange(64, 128))
    # Rotate: q1' = q1 * cos + q2 * sin; q2' = -q2 * cos + q1 * sin
    q1_new = q1 * tl.load(Cos_ptr + tl.arange(0, 64)) + q2 * tl.load(Sin_ptr + tl.arange(0, 64))
    q2_new = -q2 * tl.load(Cos_ptr + tl.arange(0, 64)) + q1 * tl.load(Sin_ptr + tl.arange(0, 64))
    out_new = tl.concatenate([q1_new, q2_new])

    out_ptrs = Out_ptr + b * stride_out_b + s * stride_out_s + offsets
    tl.store(out_ptrs, out_new)


# 4) QK matmul: Out[b, s, h] = sum_k Q[b, s, k] * K[s, k]
# Inputs: Q: [B, S, H], K: [S, H], Outputs: Out: [B, S, H]
@triton.jit
def matmul_qk_kernel(
    Q_ptr, K_ptr, Out_ptr,
    Bsz: tl.constexpr, Ssz: tl.constexpr, H: tl.constexpr,
    stride_q_b, stride_q_s, stride_q_h,
    stride_k_s, stride_k_h,
    stride_out_b, stride_out_s, stride_out_h,
    BLOCK_K: tl.constexpr, BLOCK_H: tl.constexpr,
):
    b = tl.program_id(0)
    s = tl.program_id(1)
    o = tl.program_id(2)

    acc = tl.zeros((), dtype=tl.float32)
    for k in range(0, Ssz, BLOCK_K):
        k_offsets = k + tl.arange(0, BLOCK_K)
        mask_k = k_offsets < Ssz
        # K[k_offsets, :] -> [BLOCK_K, H]
        k_ptrs = K_ptr + k_offsets[:, None] * stride_k_s + tl.arange(0, H)[None, :] * stride_k_h
        k_vals = tl.load(k_ptrs, mask=mask_k[:, None], other=0.0).to(tl.float32)

        # Q[b, s, k_offsets] -> [BLOCK_K, H]
        q_ptrs = Q_ptr + b * stride_q_b + s * stride_q_s + k_offsets[:, None] * stride_q_h + tl.arange(0, H)[None, :] * stride_q_h
        q_vals = tl.load(q_ptrs, mask=mask_k[:, None], other=0.0).to(tl.float32)

        acc += tl.sum(q_vals * k_vals, axis=1)

    out_ptrs = Out_ptr + b * stride_out_b + s * stride_out_s + o * stride_out_h
    tl.store(out_ptrs, acc)


# 5) Softmax over last dimension with causal mask:
# Input: Scores: [B, H, S, S], Mask: [B, H, S, S], Output: Soft: [B, H, S, S]
@triton.jit
def softmax_mask_kernel(
    Scores_ptr, Mask_ptr, Soft_ptr,
    Bsz: tl.constexpr, Hsz: tl.constexpr, Ssz: tl.constexpr,
    stride_scores_b, stride_scores_h, stride_scores_s, stride_scores_r,
    stride_mask_b, stride_mask_h, stride_mask_s, stride_mask_r,
    stride_soft_b, stride_soft_h, stride_soft_s, stride_soft_r,
):
    # We implement row-wise softmax over S dimension for each (b,h,s)
    for b in range(0, Bsz):
        for h in range(0, Hsz):
            # First pass: compute max
            max_val = -1e30
            for s in range(0, Ssz):
                row_base = b * stride_scores_b + h * stride_scores_h + s * stride_scores_s
                vals = tl.load(Scores_ptr + row_base, mask=True, other=-1e30).to(tl.float32)
                # Apply mask: if Mask[b,h,s,r] < 0, set to -inf; here we use Mask directly as -inf for masked positions
                # Load mask row
                mask_row = tl.load(Mask_ptr + b * stride_mask_b + h * stride_mask_h + s * stride_mask_s, mask=True, other=-1e30).to(tl.float32)
                vals = tl.where(mask_row < 0, -1e30, vals)
                if vals > max_val:
                    max_val = vals

            # Second pass: compute exp and sum
            exp_sum = 0.0
            for s in range(0, Ssz):
                row_base = b * stride_scores_b + h * stride_scores_h + s * stride_scores_s
                vals = tl.load(Scores_ptr + row_base, mask=True, other=0.0).to(tl.float32)
                mask_row = tl.load(Mask_ptr + b * stride_mask_b + h * stride_mask_h + s * stride_mask_s, mask=True, other=-1e30).to(tl.float32)
                vals = tl.where(mask_row < 0, -1e30, vals)
                exp_vals = tl.exp(vals - max_val)
                exp_sum += exp_vals

            # Third pass: write normalized
            for s in range(0, Ssz):
                row_base = b * stride_scores_b + h * stride_scores_h + s * stride_scores_s
                vals = tl.load(Scores_ptr + row_base, mask=True, other=0.0).to(tl.float32)
                mask_row = tl.load(Mask_ptr + b * stride_mask_b + h * stride_mask_h + s * stride_mask_s, mask=True, other=-1e30).to(tl.float32)
                vals = tl.where(mask_row < 0, -1e30, vals)
                soft = tl.exp(vals - max_val) / exp_sum
                tl.store(Soft_ptr + b * stride_soft_b + h * stride_soft_h + s * stride_soft_s, soft)


# 6) Attn output matmul: Out[b, s, h] = sum_k Soft[b, s, k] * V[s, k]
@triton.jit
def matmul_attn_kernel(
    Soft_ptr, V_ptr, Out_ptr,
    Bsz: tl.constexpr, Ssz: tl.constexpr, H: tl.constexpr,
    stride_soft_b, stride_soft_h, stride_soft_s, stride_soft_r,
    stride_v_s, stride_v_h,
    stride_out_b, stride_out_s, stride_out_h,
    BLOCK_K: tl.constexpr, BLOCK_H: tl.constexpr,
):
    b = tl.program_id(0)
    s = tl.program_id(1)
    o = tl.program_id(2)

    acc = tl.zeros((), dtype=tl.float32)
    for k in range(0, Ssz, BLOCK_K):
        k_offsets = k + tl.arange(0, BLOCK_K)
        mask_k = k_offsets < Ssz

        # V[s, k_offsets] -> [BLOCK_K, H]
        v_ptrs = V_ptr + s * stride_v_s + k_offsets[:, None] * stride_v_h + tl.arange(0, H)[None, :] * stride_v_h
        v_vals = tl.load(v_ptrs, mask=mask_k[:, None], other=0.0).to(tl.float32)

        # Soft[b, s, k_offsets] -> [BLOCK_K, H]
        soft_ptrs = Soft_ptr + b * stride_soft_b + s * stride_soft_s + k_offsets[:, None] * stride_soft_r + tl.arange(0, H)[None, :] * stride_soft_h
        soft_vals = tl.load(soft_ptrs, mask=mask_k[:, None], other=0.0).to(tl.float32)

        acc += tl.sum(soft_vals * v_vals, axis=1)

    out_ptrs = Out_ptr + b * stride_out_b + s * stride_out_s + o * stride_out_h
    tl.store(out_ptrs, acc)
