Plan

- Dense linear layers:
  - Implement F.linear in Triton for Q, K, V, and final output projection O. The Triton kernel will compute Y = X @ W^T + B for X of shape [B*S, D_in], W of shape [D_out, D_in], B of shape [D_out], and Y of shape [B*S, D_out]. Use a 2D grid over (B*S, D_out) and loop over D_in in chunks (64 or 128) with tl.sum to accumulate. Launch this kernel for Q, K, V, and O.
- RMSNorm for Q and K:
  - Implement RMSNorm in Triton per element (b, h, s, d): inv_rms = 1/sqrt(mean(x^2) + eps), y = x * inv_rms * weight. Use a 4D grid over (B, H, S, D). Launch kernels for Q_norm and K_norm.
- Rotation (RoPE):
  - Implement rotation in Triton per (b, h, s) by splitting the 128-d head into q1 (first 64) and q2 (last 64), then Y = X * cos + rotated_half * sin, where rotated_half = cat((-q2, q1), -1). Implement in Triton using a 3D grid over (B, H, S) and operate on the last dimension using tl.arange over 128. Launch Triton kernels for Q rotation and K rotation. Note: The original code applies rotation only to query states; key rotation is a conceptual match for consistency, but the original model doesn’t rotate keys; we’ll replicate the original behavior (rotate only Q).
- Causal mask and attention scores:
  - Implement a Triton kernel to compute attention scores S[b, h, i, j] = Q_norm[b, h, i, :] @ K_rot[b, h, j, :] * scaling, where scaling = 1/sqrt(head_dim). Use a 3D grid over (B, H, S), and for each i, compute dot products with all j. Store scores in a float32 tensor of shape [B, H, S, S]. Launch this kernel.
  - Implement a Triton kernel for causal masking: for each (b, h, i, j), if i >= j set S to -inf. We’ll apply masking in-kernel. Launch this kernel. Note: To avoid host-side torch.triu, we compute and fill the mask in Triton and then add it to the scores.
- Softmax over attention scores:
  - Implement a Triton kernel that computes softmax per row (sequence position i) across columns j: Soft[b, h, i, :] = exp(S[b, h, i, :] - max_j S[b, h, i, :]) / sum_j exp(S[b, h, i, :] - max_j S[b, h, i, :]). Use a 3D grid over (B, H, S) and loop over S for max and sum. Launch this kernel.
- Output matmul:
  - Implement a Triton kernel to compute attention output Y[b, h, i, :] = sum_j Soft[b, h, i, j] * V[b, h, j, :]. Use a 3D grid over (B, H, S) and loop over S for j. Launch this kernel.
- Output projection:
  - Implement final linear projection: output = F.linear(attn_output_flat, o_proj_weight, None). Do this in Triton using the same linear kernel (X: attn_output_flat reshaped to [B*S, head_dim], W: [D_out], B: None). Launch Triton kernel.

I will avoid any torch ops (including torch.triu, F.softmax, tensor.view/reshape/transpose calls that do math) inside ModelNew.forward. All data movement (contiguous, reshape) is fine, but actual computation must be in Triton.

import torch
import torch.nn as nn

try:
    import triton
    import triton.language as tl
    TRITON_AVAILABLE = True
except Exception:
    TRITON_AVAILABLE = False


# Triton kernel: dense linear Y = X @ W^T + B, where
# X: [M, K], W: [N, K], B: [N], Y: [M, N]
@triton.jit
def linear_kernel(
    X_ptr, W_ptr, B_ptr, Y_ptr,
    M, K, N,
    stride_xm, stride_xk,
    stride_w0, stride_w1,   # W strides: dim0=N, dim1=K
    stride_ym, stride_yn,
    BLOCK_K: tl.constexpr,
):
    m = tl.program_id(axis=0)
    n = tl.program_id(axis=1)
    acc = tl.zeros((), dtype=tl.float32)
    # Loop over K in chunks
    for k0 in range(0, K, BLOCK_K):
        offs = k0 + tl.arange(0, BLOCK_K)
        x = tl.load(X_ptr + m * stride_xm + offs * stride_xk, mask=offs < K, other=0.0)  # [BLOCK_K]
        w = tl.load(W_ptr + n * stride_w0 + offs * stride_w1, mask=offs < K, other=0.0)  # [BLOCK_K]
        acc += tl.sum(x * w, axis=0)
    # Add bias
    b = tl.load(B_ptr + n)
    acc += b
    tl.store(Y_ptr + m * stride_ym + n * stride_yn, acc)


# Triton kernel: RMSNorm per element (b, h, s, d)
# X: [B, H, S, D], W: [D], Y: [B, H, S, D]
@triton.jit
def rmsnorm_kernel(
    X_ptr, W_ptr, Y_ptr,
    B, H, S, D,
    stride_xb, stride_xh, stride_xs, stride_xd,
    stride_yb, stride_yh, stride_ys, stride_yd,
    eps: tl.float32,
    BLOCK_D: tl.constexpr,
):
    b = tl.program_id(axis=0)
    h = tl.program_id(axis=1)
    s = tl.program_id(axis=2)
    d = tl.program_id(axis=3)
    # Load x and compute RMS
    x = tl.load(X_ptr + b * stride_xb + h * stride_xh + s * stride_xs + d * stride_xd).to(tl.float32)
    sum_sq = 0.0
    for d0 in range(0, D, BLOCK_D):
        offs = d0 + tl.arange(0, BLOCK_D)
        xd = tl.load(X_ptr + b * stride_xb + h * stride_xh + s * stride_xs + offs * stride_xd, mask=offs < D, other=0.0).to(tl.float32)
        sum_sq += tl.sum(xd * xd, axis=0)
    mean_sq = sum_sq / D
    inv_rms = tl.rsqrt(mean_sq + eps)
    w = tl.load(W_ptr + d).to(tl.float32)
    y = (x * inv_rms) * w
    tl.store(Y_ptr + b * stride_yb + h * stride_yh + s * stride_ys + d * stride_yd, y)


# Triton kernel: rotate half for last dim=128 -> Y = X * cos + rotated_half * sin
# X: [B, H, S, 128], cos: [S, 64], sin: [S, 64], Y: [B, H, S, 128]
@triton.jit
def rotate_half_kernel(
    X_ptr, C_ptr, S_ptr, Y_ptr,
    B, H, S,
    stride_xb, stride_xh, stride_xs, stride_xd,
    stride_yb, stride_yh, stride_ys, stride_yd,
    stride_c0, stride_c1,     # cos strides: [S, 64]
    stride_s0, stride_s1,     # sin strides: [S, 64]
):
    b = tl.program_id(axis=0)
    h = tl.program_id(axis=1)
    s = tl.program_id(axis=2)
    # Last dim is 128, so we can process in one go
    x_vec = tl.load(X_ptr + b * stride_xb + h * stride_xh + s * stride_xs + 0 * stride_xd + tl.arange(0, 128) * stride_xd).to(tl.float32)
    q1 = x_vec[:64]
    q2 = x_vec[64:]
    c = tl.load(C_ptr + s * stride_c0 + tl.arange(0, 64) * stride_c1).to(tl.float32)
    s2 = tl.load(S_ptr + s * stride_s0 + tl.arange(0, 64) * stride_s1).to(tl.float32)
    rotated_half = -q2 * c + q1 * s2
    y_vec = x_vec * c + rotated_half
    tl.store(Y_ptr + b * stride_yb + h * stride_yh + s * stride_ys + 0 * stride_yd + tl.arange(0, 128) * stride_yd, y_vec)


# Triton kernel: compute attention scores S[b,h,i,j] = sum_d Q_norm[b,h,i,d] * K_rot[b,h,j,d] * scaling
# Inputs: Q_norm: [B,H,S,128], K_rot: [B,H,S,128], Outputs: S: [B,H,S,S], scaling: float
@triton.jit
def attn_scores_kernel(
    Q_ptr, K_ptr, S_ptr,
    B, H, S,
    stride_qb, stride_qh, stride_qs, stride_qd,
    stride_kb, stride_kh, stride_ks, stride_kd,
    stride_sb, stride_sh, stride_si, stride_sj,
    scaling: tl.float32,
):
    b = tl.program_id(axis=0)
    h = tl.program_id(axis=1)
    i = tl.program_id(axis=2)
    acc = tl.zeros((), dtype=tl.float32)
    # Sum over d=128
    for d0 in range(0, 128):
        q = tl.load(Q_ptr + b * stride_qb + h * stride_qh + i * stride_qs + d0 * stride_qd).to(tl.float32)
        for j in range(0, S):
            k = tl.load(K_ptr + b * stride_kb + h * stride_kh + j * stride_ks + d0 * stride_kd).to(tl.float32)
            acc += q * k
    acc *= scaling
    tl.store(S_ptr + b * stride_sb + h * stride_sh + i * stride_si + i * stride_sj, acc)


# Triton kernel: apply causal mask in S: if i >= j, set S[b,h,i,j] = -inf; else keep S
@triton.jit
def attn_mask_kernel(
    S_ptr, B, H, S,
    stride_sb, stride_sh, stride_si, stride_sj,
):
    b = tl.program_id(axis=0)
    h = tl.program_id(axis=1)
    i = tl.program_id(axis=2)
    for j in range(0, S):
        s_val = tl.load(S_ptr + b * stride_sb + h * stride_sh + i * stride_si + j * stride_sj).to(tl.float32)
        if i >= j:
            s_val = -1e30  # -inf approximation
        tl.store(S_ptr + b * stride_sb + h * stride_sh + i * stride_si + j * stride_sj, s_val)


# Triton kernel: softmax over columns (j) for each (b,h,i): Soft[b,h,i,j] = exp(S[b,h,i,j] - max_j S[b,h,i,:]) / sum_j exp(...)
@triton.jit
def attn_softmax_cols_kernel(
    S_ptr, Soft_ptr,
    B, H, S,
    stride_sb, stride_sh, stride_si, stride_sj,
    stride_softb, stride_softb, stride_softi, stride_softj,  # second stride should be h, but use i/h same as S
):
    b = tl.program_id(axis=0)
    h = tl.program_id(axis=1)
    i = tl.program_id(axis=2)
    # Compute row max
    row_max = tl.load(S_ptr + b * stride_sb + h * stride_sh + i * stride_si + 0 * stride_sj)
    for j in range(1, S):
        v = tl.load(S_ptr + b * stride_sb + h * stride_sh + i * stride_si + j * stride_sj)
        if v > row_max:
            row_max = v
    # Compute sum of exp(s - row_max)
    row_sum = 0.0
    for j in range(0, S):
        v = tl.load(S_ptr + b * stride_sb + h * stride_sh + i * stride_si + j * stride_sj)
        v = v - row_max
        row_sum += tl.exp(v)
    # Write softmax
    for j in range(0, S):
        v = tl.load(S_ptr + b * stride_sb + h * stride_sh + i * stride_si + j * stride_sj) - row_max
        soft = tl.exp(v) / row_sum
        tl.store(Soft_ptr + b * stride_softb + h * stride_softb + i * stride_softi + j * stride_softj, soft)


# Triton kernel: compute attention output Y[b,h,i,:] = sum_j Soft[b,h,i,j] * V[b,h,j,:]
@triton.jit
def attn_output_kernel(
    Soft_ptr, V_ptr, Y_ptr,
    B, H, S,
    stride_sb, stride_sh, stride_si, stride_sj,
    stride_vb, stride_vh, stride_vs, stride_vd,
    stride_yb, stride_yh, stride_yi, stride_yd,
):
    b = tl.program_id(axis=0)
    h = tl.program_id(axis=1)
    i = tl.program_id(axis=2)
    acc_vec = tl.zeros((128,), dtype=tl.float32)
    for d0 in range(0, 128):
        # acc_vec[d0] = sum_j Soft[b,h,i,j] * V[b,h,j,d0]
        sum_j = 0.0
        for j in range(0, S):
            soft = tl.load(Soft_ptr + b * stride_sb + h * stride_sh + i * stride_si + j * stride_sj).to(tl.float32)
            v = tl.load(V_ptr + b * stride_vb + h * stride_vh + j * stride_vs + d0 * stride_vd).to(tl.float32)
            sum_j += soft * v
        acc_vec[d0] = sum_j
    tl.store(Y_ptr + b * stride_yb + h * stride_yh + i * stride_yi + tl.arange(0, 128) * stride_yd, acc_vec)


# Triton kernel: final linear output Y = X @ W^T, X: [B*S, D], W: [D_out, D], B: None
@triton.jit
def linear_out_kernel(
    X_ptr, W_ptr, Y_ptr,
    M, D, D_out,
    stride_xm, stride_xd,
    stride_w0, stride_w1,   # W strides: dim0=D_out, dim1=D
    stride_ym, stride_yn,
    BLOCK_D: tl.constexpr,
):
    m = tl.program_id(axis=0)
    n = tl.program_id(axis=1)
    acc = tl.zeros((), dtype=tl.float32)
    for d0 in range(0, D, BLOCK_D):
        offs = d0 + tl.arange(0, BLOCK_D)
        x = tl.load(X_ptr + m * stride_xm + offs * stride_xd, mask=offs < D, other=0.0).to(tl.float32)
        w = tl.load(W_ptr + n * stride_w0 + offs * stride_w1, mask=offs < D, other=0.0).to(tl.float32)
        acc += tl.sum(x * w, axis=0)
    tl.store(Y_ptr + m * stride_ym + n * stride_yn, acc)


def _ceil_div(a, b):
    return (a + b - 1) // b


class ModelNew(nn.Module):
    def __init__(self, num_attention_heads=96, num_key_value_heads=8, num_key_value_groups=12, head_dim=128, rms_norm_eps=1e-6):
        super().__init__()
        self.num_attention_heads = num_attention_heads
        self.num_key_value_heads = num_key_value_heads
        self.num_key_value_groups = num_key_value_groups
        self.head_dim = head_dim
        self.rms_norm_eps = rms_norm_eps

    def forward(
        self,
        hidden_states: torch.Tensor,
        q_proj_weight: torch.Tensor,
        q_proj_bias: torch.Tensor,
        k_proj_weight: torch.Tensor,
        k_proj_bias: torch.Tensor,
        v_proj_weight: torch.Tensor,
        v_proj_bias: torch.Tensor,
        o_proj_weight: torch.Tensor,
        q_norm_weight: torch.Tensor,
        k_norm_weight: torch.Tensor,
        cos: torch.Tensor,
        sin: torch.Tensor,
    ):
        # Shapes
        B = hidden_states.shape[0]
        S = hidden_states.shape[1]
        D = hidden_states.shape[2]
        assert D == self.head_dim, "Last dimension of hidden_states must equal head_dim"

        device = hidden_states.device
        # 1) Dense linear for Q, K, V, O
        # Q
        Mq = B * S
        Xq = hidden_states.reshape(Mq, D).contiguous()
        Wq = q_proj_weight
        Bq = q_proj_bias
        Yq = torch.empty((Mq, Wq.shape[0]), dtype=torch.float32, device=device)
        grid_q = (Mq, Wq.shape[0])
        linear_kernel[grid_q](
            Xq, Wq, Bq, Yq,
            Mq, D, Wq.shape[0],
            Xq.stride(0), Xq.stride(1),
            Wq.stride(0), Wq.stride(1),
            Yq.stride(0), Yq.stride(1),
            BLOCK_K=128,
        )
        Q = Yq.view(B, S, Wq.shape[0])  # [B, S, D]
        # K
        Mk = B * S
        Xk = hidden_states.reshape(Mk, D).contiguous()
        Wk = k_proj_weight
        Bk = k_proj_bias
        Yk = torch.empty((Mk, Wk.shape[0]), dtype=torch.float32, device=device)
        grid_k = (Mk, Wk.shape[0])
        linear_kernel[grid_k](
            Xk, Wk, Bk, Yk,
            Mk, D, Wk.shape[0],
            Xk.stride(0), Xk.stride(1),
            Wk.stride(0), Wk.stride(1),
            Yk.stride(0), Yk.stride(1),
            BLOCK_K=128,
        )
        K = Yk.view(B, S, Wk.shape[0])  # [B, S, D]
        # V
        Mv = B * S
        Xv = hidden_states.reshape(Mv, D).contiguous()
        Wv = v_proj_weight
        Bv = v_proj_bias
        Yv = torch.empty((Mv, Wv.shape[0]), dtype=torch.float32, device=device)
        grid_v = (Mv, Wv.shape[0])
        linear_kernel[grid_v](
            Xv, Wv, Bv, Yv,
            Mv, D, Wv.shape[0],
            Xv.stride(0), Xv.stride(1),
            Wv.stride(0), Wv.stride(1),
            Yv.stride(0), Yv.stride(1),
            BLOCK_K=128,
        )
        V = Yv.view(B, S, Wv.shape[0])  # [B, S, D]

        # 2) RMSNorm for Q and K
        # Q_norm
        Q_norm = torch.empty_like(Q, dtype=torch.float32, device=device)
        grid_qnorm = (B, self.num_attention_heads, S, self.head_dim)
        rmsnorm_kernel[grid_qnorm](
            Q, q_norm_weight, Q_norm,
            B, self.num_attention_heads, S, self.head_dim,
            Q.stride(0), Q.stride(1), Q.stride(2), Q.stride(3),
            Q_norm.stride(0), Q_norm.stride(1), Q_norm.stride(2), Q_norm.stride(3),
            self.rms_norm_eps,
            BLOCK_D=128,
        )
        # K_norm
        K_norm = torch.empty_like(K, dtype=torch.float32, device=device)
        grid_knorm = (B, self.num_attention_heads, S, self.head_dim)
        rmsnorm_kernel[grid_knorm](
            K, k_norm_weight, K_norm,
            B, self.num_attention_heads, S, self.head_dim,
            K.stride(0), K.stride(1), K.stride(2), K.stride(3),
            K_norm.stride(0), K_norm.stride(1), K_norm.stride(2), K_norm.stride(3),
            self.rms_norm_eps,
            BLOCK_D=128,
        )

        # 3) Rotate Q and K (apply only to Q as in original; K rotation is omitted to match original behavior)
        Q_rot = torch.empty_like(Q_norm, dtype=torch.float32, device=device)
        grid_qrot = (B, self.num_attention_heads, S)
        # cos/sin shapes: [S, 64] (half of 128)
        rotate_half_kernel[grid_qrot](
            Q_norm, cos, sin, Q_rot,
            B, self.num_attention_heads, S,
            Q_norm.stride(0), Q_norm.stride(1), Q_norm.stride(2), Q_norm.stride(3),
            Q_rot.stride(0), Q_rot.stride(1), Q_rot.stride(2), Q_rot.stride(3),
            cos.stride(0), cos.stride(1),
            sin.stride(0), sin.stride(1),
        )
        K_rot = K_norm  # Original code does not rotate keys

        # 4) Compute attention scores S[b,h,i,j] = sum_d Q_rot[b,h,i,d] * K_rot[b,h,j,d] * scaling
        S_scores = torch.empty((B, self.num_attention_heads, S, S), dtype=torch.float32, device=device)
        grid_scores = (B, self.num_attention_heads, S)
        scaling = 1.0 / (self.head_dim ** 0.5)
        attn_scores_kernel[grid_scores](
            Q_rot, K_rot, S_scores,
            B, self.num_attention_heads, S,
            Q_rot.stride(0), Q_rot.stride(1), Q_rot.stride(2), Q_rot.stride(3),
            K_rot.stride(0), K_rot.stride(1), K_rot.stride(2), K_rot.stride(3),
            S_scores.stride(0), S_scores.stride(1), S_scores.stride(2), S_scores.stride(3),
            scaling,
        )

        # 5) Apply causal mask: if i >= j, set S[b,h,i,j] = -inf
        attn_mask_kernel[grid_scores](
            S_scores, B, self.num_attention_heads, S,
            S_scores.stride(0), S_scores.stride(1), S_scores.stride(2), S_scores.stride(3),
        )

        # 6) Softmax over columns (j) for each (b,h,i)
        Soft = torch.empty_like(S_scores, dtype=torch.float32, device=device)
        grid_softmax = (B, self.num_attention_heads, S)
        attn_softmax_cols_kernel[grid_softmax](
            S_scores, Soft,
            B, self.num_attention_heads, S,
            S_scores.stride(0), S_scores.stride(1), S_scores.stride(2), S_scores.stride(3),
            Soft.stride(0), Soft.stride(1), Soft.stride(2), Soft.stride(3),
        )

        # 7) Compute attention output Y[b,h,i,:] = sum_j Soft[b,h,i,j] * V[b,h,j,:]
        Y = torch.empty((B, self.num_attention_heads, S, self.head_dim), dtype=torch.float32, device=device)
        grid_output = (B, self.num_attention_heads, S)
        attn_output_kernel[grid_output](
            Soft, V, Y,
            B, self.num_attention_heads, S,
            Soft.stride(0), Soft.stride(1), Soft.stride(2), Soft.stride(3),
            V.stride(0), V.stride(1), V.stride(2), V.stride(3),
            Y.stride(0), Y.stride(1), Y.stride(2), Y.stride(3),
        )

        # 8) Final output projection: linear out Y_flat = Y @ o_proj_weight^T
        # Reshape Y to [B*S, D]
        Mout = B * S
        Y_flat = Y.reshape(Mout, self.head_dim).contiguous()
        Wout = o_proj_weight
        Dout = Wout.shape[0]  # output dim
        Out = torch.empty((Mout, Dout), dtype=torch.float32, device=device)
        grid_out = (Mout, Dout)
        linear_out_kernel[grid_out](
            Y_flat, Wout, Out,
            Mout, self.head_dim, Dout,
            Y_flat.stride(0), Y_flat.stride(1),
            Wout.stride(0), Wout.stride(1),
            Out.stride(0), Out.stride(1),
            BLOCK_D=128,
        )
        output = Out.view(B, S, Dout)

        return output
