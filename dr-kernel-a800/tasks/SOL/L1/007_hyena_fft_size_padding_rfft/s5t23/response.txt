Understanding the original behavior
- Input x has shape (batch, channels, seqlen).
- The code computes torch.fft.rfft(x, n=2*seqlen) for each (batch, channel) row. Since inputs are real, rfft returns a complex vector of length (2*seqlen)//2 + 1 = seqlen + 1 per row. It then divides by 2*seqlen and returns the real and imaginary parts separately.

Identity for rfft on real inputs
For a real vector x of length N_in (here N_in = seqlen), zero-padded to N = 2*N_in, the rfft output of length M_out = N_in + 1 has:
- real_out[j] = (1/N) * sum_{k=0..N-1} x[k] * cos(2*pi*j*k/N) for j=0..M_out-1
- imag_out[j] = (1/N) * sum_{k=0..N-1} x[k] * sin(2*pi*j*k/N) for j=1..M_out-2
  imag_out[0] = 0, imag_out[M_out-1] = 0 (since sin terms at zero and Nyquist are zero for real input).

Why the previous implementation numerically failed and how to fix
- The earlier version computed cos/sin using torch on the host, which is not allowed. We must compute cos and sin within Triton kernels.
- Also, computing one bin j per program led to numerical discrepancies for some workloads. To improve robustness and performance, we will compute multiple bins j per program and vectorize the reduction over k. This reduces the number of Triton programs and leverages block-level accumulation.
- We’ll construct the padded input on the host (no torch operations), launch Triton kernels that:
  - Compute real_out[j] for j in [0..seqlen] in one kernel.
  - Compute imag_out[j] for j in [1..seqlen-1] in another kernel.
- Each kernel will:
  - Compute a vector of j indices (BLOCK_J at a time).
  - Loop over k in chunks of BLOCK_K to accumulate x[k] * cos(2*pi*j*k/N) or sin(2*pi*j*k/N).
  - Normalize by 1/N and store to output.

Design details
- Inputs:

- Kernels:

  - rfft_imag_kernel: Same structure, computing imaginary parts for j in 1..seqlen-1; we initialize imag[0] and imag[seqlen] to 0.0 before launching the kernel.

def _build_padded_inputs(x, seqlen, device):
    """
    Build a flat padded input tensor of shape (n_rows * (2*seqlen)) with zeros appended.
    x: (batch, channels, seqlen), float32 on device.
    Returns: 1D tensor of length n_rows * (2*seqlen).
    """
    batch, channels = x.shape[0], x.shape[1]
    n_rows = batch * channels
    n = 2 * seqlen
    x_padded_flat = torch.empty(n_rows * n, dtype=torch.float32, device=device)
    for b in range(batch):
        for c in range(channels):
            row_id = b * channels + c
            row_start = row_id * n
            row_vec = x[b, c, :]
            x_padded_flat[row_start : row_start + seqlen] = row_vec
    return x_padded_flat
