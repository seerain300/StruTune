    BLOCK_N: tl.constexpr,    # tiling factor over n

    BLOCK_K: tl.constexpr,  # number of k outputs computed per program (e.g., 1024)
):

    k_offsets = k_start + tl.arange(0, BLOCK_K)

    acc_imag = tl.zeros((BLOCK_K,), dtype=tl.float32)

If you need further speed, a split-radix real FFT implemented in Triton would be faster, but correctness and compliance are the priority here.
