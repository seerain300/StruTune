- The original PyTorch code:
  - Input x has shape (batch, channels, seqlen).
  - It casts to float32 and computes torch.fft.rfft(x, n=2*seqlen) along the last dimension. This implicitly pads with zeros to length 2*seqlen.
  - rfft returns a complex tensor of shape (batch, channels, seqlen+1) when 2*seqlen is even (because the number of output bins equals seqlen+1: k from 0 to seqlen, including Nyquist).
  - The output is normalized by dividing by 2*seqlen.

- Core mathematical identity for real-input rfft:
  For a real signal of length L, rfft produces y_k for k = 0..L-1 (L outputs), where:
    y_k = sum_{j=0}^{L-1} x[j] * (cos(2*pi*k*j/L) - sin(2*pi*k*j/L))
  And at k = L/2 (if L even):
    y_{L/2} = sum_{j=0}^{L-1} x[j] * (-1)^j
  Since the original code pads to 2*L elements and returns L+1 outputs, we must:
  - Use implicit zero-padding for j in [L, 2*L-1] by not including those terms.
  - Compute for k in 0..L (exactly L+1 outputs). Note L here equals seqlen, so k ranges 0..seqlen-1, plus one Nyquist term when seqlen is even (but PyTorch’s rfft with n=2*seqlen yields seqlen+1 outputs regardless of parity, i.e., it includes k=seqlen term; this term corresponds to the last frequency bin, not strictly Nyquist in the sense of L/2, but the output length is seqlen+1).

- Triton implementation approach:
  - Kernel 1 (pad_to_2L_kernel): For each (batch, channel) slice, construct x_padded of shape (B, C, 2*L) by copying x[b, c, :] to the first L entries and writing zeros to the remaining L entries. This matches torch.fft.rfft’s implicit zero-padding.
  - Kernel 2 (rfft_direct_kernel): For each (batch, channel) slice, compute y_k for k = 0..L. Iterate j over 0..2*L-1 in tiles, and accumulate:
      real_sum += x_padded[j] * cos(2*pi*k*j/(2*L))
      imag_sum += x_padded[j] * sin(2*pi*k*j/(2*L))
    Since the original input contributes only j < L, the padded zeros don’t affect results. We then divide by 2*L to normalize and store real and imaginary parts into outputs of shape (B, C, L+1). This approach is mathematically correct but O(N^2). For many workloads, it’s acceptable and guarantees correctness first. If speed is later required, we can implement a split-radix FFT in Triton to reduce complexity to O(N log N).

import torch

# Triton is required for GPU kernels; import here
import triton
import triton.language as tl


@triton.jit
def pad_to_2L_kernel(
    x_ptr,                # *f32, input tensor (B, C, L)
    x_padded_ptr,         # *f32, output tensor (B, C, 2*L), zeros beyond L
    batch: tl.int32,
    channels: tl.int32,
    L: tl.int32,          # seqlen
    stride_b: tl.int32,   # input stride for batch
    stride_c: tl.int32,   # input stride for channel
    stride_l: tl.int32,   # input stride for last dim
    out_stride_b: tl.int32,
    out_stride_c: tl.int32,
    out_stride_l: tl.int32,
    BLOCK_N: tl.constexpr,
):
    # One Triton program per (batch, channel) slice
    pid = tl.program_id(axis=0)
    b = pid // channels
    c = pid % channels

    base_in = b * stride_b + c * stride_c
    base_out = b * out_stride_b + c * out_stride_c
    twoL = 2 * L

    # Copy original L elements into first L positions
    start = 0
    while start < L:
        j = start + tl.arange(0, BLOCK_N)
        mask = j < L
        vals = tl.load(x_ptr + base_in + j * stride_l, mask=mask, other=0.0)
        tl.store(x_padded_ptr + base_out + j * out_stride_l, vals, mask=mask)
        start += BLOCK_N

    # Fill remaining positions with zeros
    zero_vec = tl.zeros([BLOCK_N], dtype=tl.float32)
    start = L
    while start < twoL:
        j = start + tl.arange(0, BLOCK_N)
        mask = j < twoL
        tl.store(x_padded_ptr + base_out + j * out_stride_l, zero_vec, mask=mask)
        start += BLOCK_N


@triton.jit
def rfft_direct_kernel(
    x_padded_ptr,         # *f32, input padded tensor (B, C, 2*L)
    real_out_ptr,         # *f32, output real part (B, C, L+1)
    imag_out_ptr,         # *f32, output imag part (B, C, L+1)
    batch: tl.int32,
    channels: tl.int32,
    L: tl.int32,          # original seqlen
    out_stride_b: tl.int32,  # stride for batch in output
    out_stride_c: tl.int32,  # stride for channel in output
    out_stride_l: tl.int32,  # stride for last dim in output (should be 1)
    BLOCK_N: tl.constexpr
):
    # One Triton program per (batch, channel) slice
    pid = tl.program_id(axis=0)
    b = pid // channels
    c = pid % channels

    base_out = b * out_stride_b + c * out_stride_c
    twoL = 2 * L

    # Iterate over k = 0 .. L (inclusive), i.e., L+1 outputs
    k = 0
    while k <= L:
        real_sum = 0.0
        imag_sum = 0.0

        # Accumulate over j = 0 .. 2*L - 1 in tiles
        j_start = 0
        while j_start < twoL:
            j = j_start + tl.arange(0, BLOCK_N)
            mask = j < twoL

            vals = tl.load(x_padded_ptr + (b * out_stride_b + c * out_stride_c) + j * out_stride_l, mask=mask, other=0.0)

            # Compute angle = 2*pi*k*j/(2*L) = pi*k*j/L
            # Note: k and L are ints; Triton will cast to float for division
            angle = (tl.float32(k) * tl.float32(j)) * 3.141592653589793 / tl.float32(twoL)

            cos_term = tl.cos(angle)
            sin_term = tl.sin(angle)

            # Accumulate real and imaginary parts
            real_sum += tl.sum(vals * cos_term, axis=0)
            imag_sum += tl.sum(vals * sin_term, axis=0)

            j_start += BLOCK_N

        # Normalize by 2*L
        norm = 1.0 / tl.float32(twoL)
        real_val = real_sum * norm
        imag_val = imag_sum * norm

        # Store results at index k
        # real_out and imag_out are (B, C, L+1), so we use k as last dim index
        out_index = base_out + k * out_stride_l
        tl.store(real_out_ptr + out_index, real_val)
        tl.store(imag_out_ptr + out_index, imag_val)

        k += 1

    def forward(self, x: torch.Tensor):

        """

            x.stride(0), x.stride(1), x.stride(2),
            x_padded.stride(0), x_padded.stride(1), x_padded.stride(2),
            BLOCK_N=1024,
            num_warps=4,
        )

        # Allocate outputs (real and imag parts) of shape (B, C, L+1), contiguous
        real_out = torch.empty((batch, channels, L + 1), dtype=torch.float32, device=x.device)
        imag_out = torch.empty((batch, channels, L + 1), dtype=torch.float32, device=x.device)

            imag_out.stride(0), imag_out.stride(1), imag_out.stride(2),
            BLOCK_N=1024,
            num_warps=4,
        )

        return real_out, imag_out
