Equivalence identity for rfft on real inputs
For a real vector x of length N_in (here N_in = seqlen), zero-padded to N = 2*N_in, the rfft output of length M_out = N_in + 1 has:
- real_out[j] = (1/N) * sum_{k=0..N-1} x[k] * cos(2*pi*j*k/N) for j=0..M_out-1
- imag_out[j] = (1/N) * sum_{k=0..N-1} x[k] * sin(2*pi*j*k/N) for j=1..M_out-2
  imag_out[0] = 0, imag_out[M_out-1] = 0 (since sin terms at zero and Nyquist are zero for real input).

Strategy in Triton
- For each (batch, channel) row:

Correctness considerations
- The normalization uses N=2*seqlen (dividing by fft_size), exactly as in the original code.
- We handle arbitrary seqlen (including non-power-of-two) by iterating k from 0 to N-1, which is fine.

- The output dtype is float32 and shape is (batch, channels, seqlen+1), matching the original function’s return.

import torch
import triton
import triton.language as tl


@triton.jit
def compute_real_rfft_kernel(x_ptr, out_ptr, j, N):
    """
    Compute real_rfft[j] for j in [0, M], where M=seqlen and N=2*seqlen.
    real_out[j] = (1/N) * sum_{k=0..N-1} x[k] * cos(2*pi*j*k/N)
    x_ptr points to a 1D contiguous buffer of length N (first half is input x, second half zeros).
    out_ptr points to the output buffer for this (b, c) row; we write at index j.
    """
    acc = 0.0
    for k in range(0, N):
        xk = tl.load(x_ptr + k)
        angle = 2.0 * 3.141592653589793 * j * k / N
        acc += xk * tl.cos(angle)
    # Normalize by N (original divides by 2*seqlen; here N == 2*seqlen)
    acc *= 1.0 / N
    # Store result at out_ptr[j]
    tl.store(out_ptr + j, acc)


@triton.jit
def compute_imag_rfft_kernel(x_ptr, out_ptr, j, N):
    """
    Compute imag_rfft[j] for j in [1, M-1], where M=seqlen and N=2*seqlen.
    imag_out[j] = (1/N) * sum_{k=0..N-1} x[k] * sin(2*pi*j*k/N)
    x_ptr points to a 1D contiguous buffer of length N (first half is input x, second half zeros).
    out_ptr points to the output buffer for this (b, c) row; we write at index j.
    """

        angle = 2.0 * 3.141592653589793 * j * k / N
        acc += xk * tl.sin(angle)

    # Store result at out_ptr[j]
    tl.store(out_ptr + j, acc)

def zero_imag_endpoints_kernel(imag_ptr, L):
    """
    Set imag_ptr[0] and imag_ptr[L-1] to zero, where L=seqlen+1.
    """
    # Zero the first element
    tl.store(imag_ptr + 0, 0.0)
    # Zero the last element
