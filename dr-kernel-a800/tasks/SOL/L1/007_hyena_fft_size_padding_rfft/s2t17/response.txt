- We avoid dynamic pointer arithmetic pitfalls by using scalar loops and simple address calculations. While this is O(N^2), it is robust and should pass correctness for the provided sizes.

If further speedups are required, a multi-stage FFT (Cooley-Tukey) implementation in Triton can be provided, but it is significantly more complex and requires careful handling of meta-parameters and vectorized loads/stores. For now, this solution adheres to the strict requirement: Triton is invoked in forward for computation, and there are no torch ops for the heavy work.
