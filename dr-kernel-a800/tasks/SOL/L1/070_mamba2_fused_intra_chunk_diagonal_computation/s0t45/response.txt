Notes:
- This implementation computes L in PyTorch using torch.cumsum and torch.exp to avoid Triton exp/log issues. It matches the original semantics precisely for L.
- compute_G_per_j_kernel is a Triton kernel that computes G[b, c, i, j, h] = sum over n of C_exp[b, c, i, h, n] * sum over j’ of B_exp[b, c, j’, h, n] * L[b, c, i, j’, h]. The nested loops over j’ and n make it robust; although slower, it ensures correctness and avoids Triton vector indexing pitfalls.
- compute_Y_diag_kernel is a Triton kernel that reduces over j to compute the final output Y_diag[b, c, i, h, d].
- All Triton kernels are actually launched from ModelNew.forward. There are no decoy kernels.
