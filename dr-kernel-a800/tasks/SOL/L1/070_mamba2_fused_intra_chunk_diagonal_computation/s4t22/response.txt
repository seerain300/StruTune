  - Triton kernel _diag_matvec_sum: For each (n, t, h), compute Y[n, t, i, h, d] = sum over j of M[n, t, i, j, h] * hidden_states[n, t, j, h, d], and store per i. This matches the original output shape [N, T, L, H, D].

All kernels use runtime strides and simple while loops with bounds i<L and j<L, ensuring correctness for any chunk size L, and avoiding previous runtime errors.

                         N, H, T, L,

                         stride_L_n, stride_L_h, stride_L_t, stride_L_i, stride_L_j):
    """
    Build lower-triangular exponential mask L for each (n, h, t):
    For i <= j, L[n, h, t, i, j] = exp(A[n, h, t, i]) else 0.
    Grid: (N, H, T)
    """
    pid_n = tl.program_id(0)
    pid_h = tl.program_id(1)
    pid_t = tl.program_id(2)

    i = 0
    while i < L:
        j = 0
        while j < L:
            # Only set L for lower-tri (i <= j); otherwise store 0.0
            if i <= j:

        i += 1
