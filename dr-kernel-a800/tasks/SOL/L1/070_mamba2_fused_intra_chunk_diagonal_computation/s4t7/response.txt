  - B: [N, T, L, G, K], C: [N, T, L, G, K] (G=N_GROUPS=8, K=32 by default).

- Steps and Triton kernels:
  1) Build L lower-triangular exponential mask in Triton:
     - For each (n, h, t), compute segment_sum[i, j] = sum_{m=0..j} A_cumsum[n, h, t, i] when i <= j, else 0.
     - Then L[n, h, t, i, j] = exp(segment_sum[i, j]) for i <= j; upper triangle is 0.
     - Kernel _build_lower_tri_exp: grid=(N, H, T). Inside each program, loop over i and j up to L (runtime). Load A_cumsum with bounds checking. Accumulate segment_sum per j for each i, compute exp, and store L. This avoids torch.tril and torch.cumsum.

  2) Contract B @ C^T to form G in Triton:
     - Grid over (n, t, i, j, h). For each (i, j, h), compute G[n, t, i, j, h] = sum over groups g and K of C[n, t, i, g, k] * B[n, t, j, g, k]. This keeps correctness while using Triton.
     - Kernel _contract_bc_to_g: launched as (N, T, L, L, H). Simple loops over G and K; K is 32 by default.

  3) Apply lower-triangular mask to G using Triton:
     - Kernel _apply_mask: Read G and L and produce M = G * L where L is 1 for i >= j and 0 otherwise. We will compute the lower-triangular condition in-kernel: i >= j. This avoids relying on PyTorch’s tril.

  4) Compute Y_diag via diagonal matvec in Triton:
     - Kernel _diag_matvec_sum: For each (n, t, i, h, d), compute Y[n, t, i, h, d] = sum over j of M[n, t, i, j, h] * hidden_states[n, t, j, h, d] with lower-triangular mask i >= j. We launch a 5D grid (N, T, L, H, D). Inside each program, loop j from 0 to L-1, apply mask, load M and HS, accumulate, store. This ensures all work is inside Triton and avoids any PyTorch ops in forward.

- Important notes:
  - The Triton kernels will handle dynamic sizes robustly: loops iterate up to L, H, D, and K based on inputs. We avoid hardcoding chunk_size=128 and instead use runtime L.
  - We will not call any torch.tril, torch.cumsum, or torch.exp in host code. All these are implemented in Triton kernels or trivial vector ops inside Triton.

@triton.jit
def _build_lower_tri_exp(A_ptr, L_ptr,
                         N, H, T, L,
                         stride_A_n, stride_A_h, stride_A_t, stride_A_l,
                         stride_L_n, stride_L_h, stride_L_t, stride_L_i, stride_L_j):
    # Each program handles one (n, h, t)
    pid_n = tl.program_id(0)
    pid_h = tl.program_id(1)
    pid_t = tl.program_id(2)

    # Loop over i (row) and j (col) for the chunk
    i = 0
    while i < L:
        # Accumulate segment_sum for this row i up to j
        segment_sum = 0.0
        j = 0
        while j < L:
            # Only include A when i <= j (lower-triangular)
            include = i <= j
            # Load A_cumsum[n, h, t, i], safe to load; include mask guards logic
            # Use masking via 'other' for non-includes
            a_val = tl.load(A_ptr + pid_n * stride_A_n + pid_h * stride_A_h + pid_t * stride_A_t + i * stride_A_l,
                            mask=include, other=0.0)
            segment_sum += a_val
            j += 1
        # Compute L[i, j] = exp(segment_sum) for lower-triangular; 0 otherwise
        j = 0
        while j < L:
            lower = i <= j
            val = tl.exp(segment_sum) if lower else 0.0
            tl.store(L_ptr + pid_n * stride_L_n + pid_h * stride_L_h + pid_t * stride_L_t + i * stride_L_i + j * stride_L_j, val)
            j += 1
        i += 1


@triton.jit
def _contract_bc_to_g(B_ptr, C_ptr, G_ptr,
                      N, T, L, G, K,
                      stride_B_n, stride_B_t, stride_B_l, stride_B_g, stride_B_k,
                      stride_C_n, stride_C_t, stride_C_l, stride_C_g, stride_C_k,

    pid_t = tl.program_id(1)
    pid_i = tl.program_id(2)
    pid_j = tl.program_id(3)
    pid_h = tl.program_id(4)

        k = 0
        while k < K:
            b_val = tl.load(B_ptr + pid_n * stride_B_n + pid_t * stride_B_t + pid_j * stride_B_l + g * stride_B_g + k * stride_B_k)
            c_val = tl.load(C_ptr + pid_n * stride_C_n + pid_t * stride_C_t + pid_i * stride_C_l + g * stride_C_g + k * stride_C_k)
            acc += b_val * c_val
            k += 1
        g += 1

    tl.store(G_ptr + pid_n * stride_G_n + pid_t * stride_G_t + pid_i * stride_G_l_i + pid_j * stride_G_l_j + pid_h * stride_G_h, acc)

    pid_t = tl.program_id(1)
    pid_h = tl.program_id(2)

        j = 0

            j += 1
        i += 1

def _diag_matvec_sum(M_ptr, HS_ptr, Y_ptr,
