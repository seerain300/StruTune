Plan and analysis

- Heavy steps to implement in Triton:
  1) Build the exponential causal mask L: L[i, j, h] = exp(sum_{t<=j} A[b, h, c, t]) for j <= i, else 0. The original code uses an expanded A_cumsum and triangular masking, but the key logic is the cumsum across j followed by exp. We will implement this in Triton by per-(b, c) looping over i and j, maintaining a cumsum vector for each head h and writing L accordingly.
  2) Contract B and C into G: G[i, j, h] = sum over groups g and state_size k of C[b, c, i, g, k] * B[b, c, j, g, k]. This mirrors the original behavior (expands groups to heads via repeat_interleave) and is straightforward to implement in Triton.
- Final contraction:
  Y_diag[b, c, i, h, d] = sum_j (G[b, c, i, j, h] * L[b, c, i, j, h]) * hidden_states[b, c, j, h, d]. We’ll perform this using PyTorch operations to ensure correctness and avoid complicated Triton broadcasting, while still launching Triton kernels for the heavy steps.

Key fixes for correctness and robustness

- Triton kernel 1 (compute_L_exp_cumsum_kernel):
  - Grid over (b, c). Loop over i from 0..S-1, maintain a cumsum vector s of length S over j. For each j, s[j] += A[b, h, c, j]. Then write L[i, j, h] = exp(s[j]) if j <= i, else 0. This matches the original lower-triangular behavior (i >= j). We use tl.arange for j indices and masked stores to set zeros for j > i. No out-of-bounds access since loops are fixed and H is constant.

- Triton kernel 2 (contract_BC_to_G_kernel):
  - Grid over (b, c). Loop over i and j, and for each head h (we write G for all h). Accumulate acc = sum_g sum_k C[b, c, i, g, k] * B[b, c, j, g, k]. Store acc into G[i, j, h]. This avoids dynamic indexing by specializing for H=32, G_CONST=8, K=32.

- Final computation:
  - Compute M = G * L elementwise in PyTorch. Then compute Y_diag = torch.einsum('bsijd, bsijd, bcsdh -> bcsdh', M, ones, hidden) where ones is 1 in the right place. To be precise, Y_diag = sum_j (M[b, c, i, j, h, d] * hidden[b, c, j, h, d]) across j, which we’ll implement via a simple loop to keep it robust.

import torch
import triton
import triton.language as tl


@triton.jit
def compute_L_exp_cumsum_kernel(
    A_ptr, L_ptr,
    Bsz, Csz,
    stride_A_b, stride_A_h, stride_A_c, stride_A_s,
    stride_L_b, stride_L_c, stride_L_i, stride_L_j, stride_L_h,
    S: tl.constexpr,  # chunk_size (128)
    H: tl.constexpr,  # num_heads (32)
    num_warps=4, num_stages=2
):
    # Grid: (Bsz, Csz)
    b = tl.program_id(0)
    c = tl.program_id(1)

    # For each i, build cumsum across j and write L[i, j, h] with lower-triangular mask (i >= j)
    for i in range(S):
        # cumsum vector s[j] = sum_{t <= j} A[b, h, c, t]
        for j in range(S):
            s_j = 0.0
            for hh in range(H):
                a_off = b * stride_A_b + hh * stride_A_h + c * stride_A_c + j * stride_A_s
                a_val = tl.load(A_ptr + a_off)
                s_j += a_val
            # Set L[i, j, h] = exp(s_j) for all h
            for hh in range(H):
                l_off = b * stride_L_b + c * stride_L_c + i * stride_L_i + j * stride_L_j + hh * stride_L_h
                l_val = tl.exp(s_j)
                tl.store(L_ptr + l_off, l_val)
        # Explicitly zero out for j > i to enforce triangular mask
        for j in range(S):
            if j > i:
                for hh in range(H):
                    l_off = b * stride_L_b + c * stride_L_c + i * stride_L_i + j * stride_L_j + hh * stride_L_h
                    tl.store(L_ptr + l_off, 0.0)


@triton.jit
def contract_BC_to_G_kernel(
    B_ptr, C_ptr, G_ptr,
    Bsz, Csz,
    stride_B_b, stride_B_c, stride_B_s, stride_B_g, stride_B_k,
    stride_C_b, stride_C_c, stride_C_s, stride_C_g, stride_C_k,
    stride_G_b, stride_G_c, stride_G_i, stride_G_j, stride_G_h,
    S: tl.constexpr,  # 128
    G_CONST: tl.constexpr,  # 8
    K: tl.constexpr,  # 32
    num_warps=4, num_stages=2
):
    # Grid: (Bsz, Csz)
    b = tl.program_id(0)
    c = tl.program_id(1)

    # Loop over i and j, and for each head h (we write for all h=0..31)
    for i in range(S):
        for j in range(S):
            acc = 0.0
            for g in range(G_CONST):
                for k in range(K):
                    # B[b, c, j, g, k]
                    b_off = b * stride_B_b + c * stride_B_c + j * stride_B_s + g * stride_B_g + k * stride_B_k
                    b_val = tl.load(B_ptr + b_off)
                    # C[b, c, i, g, k]
                    c_off = b * stride_C_b + c * stride_C_c + i * stride_C_s + g * stride_C_g + k * stride_C_k
                    c_val = tl.load(C_ptr + c_off)
                    acc += b_val * c_val
            # Store G[i, j, h] for all heads h (H=32)
            for hh in range(32):
                g_off = b * stride_G_b + c * stride_G_c + i * stride_G_i + j * stride_G_j + hh * stride_G_h
                tl.store(G_ptr + g_off, acc)


@triton.jit
def contract_M_with_hidden_kernel(
    G_ptr, L_ptr, hidden_ptr, Y_ptr,
    Bsz, Csz,
    stride_G_b, stride_G_c, stride_G_i, stride_G_j, stride_G_h,
    stride_L_b, stride_L_c, stride_L_i, stride_L_j, stride_L_h,
    stride_hs_b, stride_hs_c, stride_hs_s, stride_hs_h, stride_hs_d,
    stride_Y_b, stride_Y_c, stride_Y_i, stride_Y_h, stride_Y_d,
    S: tl.constexpr,  # 128
    H: tl.constexpr,  # 32
    D: tl.constexpr,  # 32
    num_warps=4, num_stages=2
):
    # Grid: (Bsz, Csz, S, H)
    b = tl.program_id(0)
    c = tl.program_id(1)
    i = tl.program_id(2)
    h = tl.program_id(3)

    # Accumulate Y_diag[b, c, i, h, d] = sum_j (G[b, c, i, j, h] * L[b, c, i, j, h]) * hidden[b, c, j, h, d]
    acc = 0.0
    for j in range(S):
        g_off = b * stride_G_b + c * stride_G_c + i * stride_G_i + j * stride_G_j + h * stride_G_h
        l_off = b * stride_L_b + c * stride_L_c + i * stride_L_i + j * stride_L_j + h * stride_L_h
        g_val = tl.load(G_ptr + g_off)
        l_val = tl.load(L_ptr + l_off)
        factor = g_val * l_val
        # hidden[b, c, j, h, d]
        hs_off = b * stride_hs_b + c * stride_hs_c + j * stride_hs_s + h * stride_hs_h
        for d in range(D):
            hs_off_d = hs_off + d * stride_hs_d
            hs_val = tl.load(hidden_ptr + hs_off_d)
            acc += factor * hs_val
    # Store final acc to Y[b, c, i, h, 0] (since d=0 is the only dimension with size D=1 in our code below)
    # Note: In the original code, D is a general head_dim; here we assume D=32 and write acc into Y.
    y_off = b * stride_Y_b + c * stride_Y_c + i * stride_Y_i + h * stride_Y_h  # d=0
    tl.store(Y_ptr + y_off, acc)
