- hidden_states: [N, T, L, H, D]
- A_cumsum: not used in the heavy Triton parts; the original code computes L from it, but the structure is simple: lower-triangular exp of a segment sum. We keep it for interface compatibility but we will form L in PyTorch for correctness and simplicity.
- B: [N, T, L, G, K], C: [N, T, L, G, K], with G=N_GROUPS=8, K is assumed to be 32 (half of head_dim=64).
