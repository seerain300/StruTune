Root cause analysis
- The operation is scatter-add: for each i, output[token_indices[i]] += expert_outputs[i, :]. Duplicates in token_indices must accumulate correctly, hence atomics are required.
- Our earlier improvement came from:
  - Vectorizing across the hidden dimension in BLOCK_H chunks, issuing one atomic_add per chunk per update. This reduced atomics from H per update to roughly H / BLOCK_H.
  - Processing multiple updates per Triton program (T=4). This reduces the number of programs launched, helps amortize scheduling overhead, and can improve occupancy.
- The regression likely came from:
  - Using a 2D kernel that processes T updates per program but then loops across H in large BLOCK_H (e.g., 1024), increasing register pressure for large N, causing performance variability. While it minimizes atomics, it can underperform on certain shapes.
  - Switching heuristics (BLOCK_H and T) might not be optimal for all hidden sizes. For example, always using T=4 can hurt for very small N, and choosing BLOCK_H=1024 for moderate H can cause register pressure.

Optimization plan
- Revert to the simpler, previously faster pattern:
  - One program per update (grid = N). This tends to give stable performance across diverse shapes.
  - Vectorize across hidden dimension in chunks of BLOCK_H, performing one atomic_add per chunk. Choose BLOCK_H based on hidden_size:
    - If H >= 1024, BLOCK_H = 1024, num_warps = 8.
    - Else if H >= 512, BLOCK_H = 512, num_warps = 4.
    - Else, BLOCK_H = 256, num_warps = 2.
  - Ensure expert_outputs is contiguous and in float32. Accumulate in float32 for correctness and speed; cast back to bfloat16 at the end.
  - Keep the kernel simple (no 2D multi-update), which historically delivered ~1.21–1.22x geomean.

import torch
import triton
import triton.language as tl


@triton.jit
def scatter_add_row_chunks_kernel(
    out_ptr,          # *fp32, shape [M, H], output rows
    token_indices_ptr,# *i32,  shape [N], token indices (0..M-1)
    expert_ptr,       # *fp32, shape [N, H], expert outputs per token
    M: tl.constexpr,  # int, number of rows in output
    H: tl.constexpr,  # int, hidden size
    N: tl.constexpr,  # int, number of updates
    BLOCK_H: tl.constexpr,
):
    # One program per update i
    pid = tl.program_id(0)
    if pid >= N:
        return

    # Load index for this update
    idx = tl.load(token_indices_ptr + pid)
    # Guard: ensure idx in [0, M)
    if idx >= M:
        return

    # Base pointers for this row
    out_row_ptr = out_ptr + idx * H

    # Process hidden dimension in chunks of BLOCK_H
    # For each chunk, load expert_outputs[pid, h:h+BLOCK_H] and atomic add into out_row
    for h in range(0, H, BLOCK_H):
        offs = h + tl.arange(0, BLOCK_H)
        mask = offs < H
        # Load expert vector chunk (float32)
        v = tl.load(expert_ptr + pid * H + offs, mask=mask, other=0.0)
        # Atomic add into output row
        tl.atomic_add(out_row_ptr + offs, v, mask=mask)


class ModelNew(torch.nn.Module):
    def forward(
        self,
        final_hidden_states: torch.Tensor,
        expert_outputs: torch.Tensor,
        token_indices: torch.Tensor,
    ):
        """
        Triton-accelerated scatter-add:
        output = final_hidden_states.clone()
        output.index_add_(dim=0, index=token_indices, source=expert_outputs)

        Returns: output with bfloat16 dtype, matching the original API.
        """
        # Ensure on CUDA and contiguous
        assert final_hidden_states.is_cuda and expert_outputs.is_cuda and token_indices.is_cuda, \
            "All tensors must be on CUDA device"
        device = final_hidden_states.device

        # Make sure dtype is fp32 for atomic accumulation
        # Clone to avoid modifying input; use contiguous buffers
        out_fp32 = final_hidden_states.contiguous().to(torch.float32).clone()

        # Prepare inputs
        M = out_fp32.shape[0]  # batch_seq_len
        H = out_fp32.shape[1]
        N = expert_outputs.shape[0]
        assert token_indices.shape[0] == N
        # Triton prefers int32 indices; ensure contiguous int32
        token_indices_i32 = token_indices.contiguous().to(torch.int32)
        # Ensure expert_outputs is contiguous float32
        expert_outputs_fp32 = expert_outputs.contiguous().to(torch.float32)

        # Choose BLOCK_H and num_warps based on H
        if H >= 1024:
            BLOCK_H = 1024
            num_warps = 8
        elif H >= 512:
            BLOCK_H = 512
            num_warps = 4
        else:
            BLOCK_H = 256
            num_warps = 2

        # Launch kernel: one program per update
        grid = (N,)
        scatter_add_row_chunks_kernel[grid](
            out_fp32,
            token_indices_i32,
            expert_outputs_fp32,
            M, H, N,
            BLOCK_H=BLOCK_H,
            num_warps=num_warps,
            num_stages=2,
        )

        # Cast back to bfloat16 to match original API
        return out_fp32.to(torch.bfloat16)

        v = tl.load(expert_ptr + pid * H + offs, mask=mask, other=0.0)
        # Atomic add into the output row
        tl.atomic_add(out_row_ptr + offs, v, mask=mask)


class ModelNew(torch.nn.Module):
    def forward(
        self,
        final_hidden_states: torch.Tensor,
        expert_outputs: torch.Tensor,
        token_indices: torch.Tensor,
    ):
        """
        Triton-accelerated scatter-add:
        output = final_hidden_states.clone()
        output.index_add_(dim=0, index=token_indices, source=expert_outputs)

        Returns: output with bfloat16 dtype, matching the original API.
        """
        # Ensure tensors are on CUDA
        assert final_hidden_states.is_cuda and expert_outputs.is_cuda and token_indices.is_cuda, \
            "All tensors must be on CUDA device"
        device = final_hidden_states.device

        # Accumulate in float32 for atomic_add support
        out_fp32 = final_hidden_states.contiguous().to(torch.float32).clone()

        # Dimensions
        M = out_fp32.shape[0]  # batch_seq_len
        H = out_fp32.shape[1]
        N = expert_outputs.shape[0]
        assert token_indices.shape[0] == N

        # Triton prefers int32 indices; ensure contiguous and proper dtypes
        token_indices_i32 = token_indices.contiguous().to(torch.int32)
        expert_outputs_fp32 = expert_outputs.contiguous().to(torch.float32)

        # Choose BLOCK_H and num_warps based on H
        if H >= 1024:
            BLOCK_H = 1024
            num_warps = 8
        elif H >= 512:
            BLOCK_H = 512
            num_warps = 4
        else:
            BLOCK_H = 256
            num_warps = 2

        # Launch kernel: one program per update
        grid = (N,)
        scatter_add_row_chunks_kernel[grid](
            out_fp32,
            token_indices_i32,
            expert_outputs_fp32,
            M, H, N,
            BLOCK_H=BLOCK_H,
            num_warps=num_warps,
            num_stages=2,
        )

        # Cast back to bfloat16 to match original API
        return out_fp32.to(torch.bfloat16)
