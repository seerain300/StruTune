Recap of the operation
- We need to mimic:
  - output = final_hidden_states.clone()
  - output.index_add_(dim=0, index=token_indices, source=expert_outputs)
  which, for each selected token i, adds expert_outputs[i, :] into output[token_indices[i], :]. Duplicates in token_indices must accumulate.

What worked and why
- One Triton program per selected token row i (N programs total). Each program:
  - Loads the hidden vector for row i in chunks of BLOCK columns.
  - Computes the destination row index from token_indices[i].
  - Atomically adds the chunk into output at that destination row.
- This approach avoids per-element atomics and preserves accumulation semantics. Using BLOCK=256 with a masked loop ensures correctness for all hidden sizes H because it always covers the entire dimension (grid = ceil_div(H, BLOCK) = 1 when H <= 256, and multiple iterations for larger H), which passed all 16 workloads.

Plan for further performance improvements
- Keep the robust structure, but reduce kernel control overhead and register pressure by tuning BLOCK and num_warps:
  - Use BLOCK=128 for H <= 128 (single iteration, fewer lanes), and BLOCK=256 for larger H.
  - Set num_warps=4 for BLOCK=128, and num_warps=8 for BLOCK=256. Keep num_stages=2 for pipelining.
- Ensure tensors are contiguous and token_indices are int32. Clone final_hidden_states before accumulation to match original semantics.

This change reduces the number of active lanes per program when H is small, potentially improving occupancy and reducing register usage, while maintaining correctness for all H.

Final code (ModelNew)
```python
import math
import torch
import triton
import triton.language as tl


@triton.jit
def _index_add_rows_kernel(
    out_ptr,         # *const half (final_hidden_states clone), we will atomically add into it
    expert_ptr,      # *const half (expert_outputs)
    indices_ptr,     # *const int32 (token_indices)
    N,               # int32: number of selected tokens
    H,               # int32: hidden size
    BLOCK: tl.constexpr,
):
    pid = tl.program_id(axis=0)
    if pid >= N:
        return

    # Destination row index for this selected token
    idx = tl.load(indices_ptr + pid)

    # Iterate over hidden dimension in chunks of BLOCK
    # We'll atomically add each chunk into out[idx, :]
    col_start = 0
    while col_start < H:
        cols = col_start + tl.arange(0, BLOCK)
        mask = cols < H

        # Load chunk from expert_outputs[pid, cols]
        expert_vals = tl.load(
            expert_ptr + pid * H + cols,
            mask=mask,
            other=0.0,
        )

        # Compute destination pointers: out[idx, cols]
        out_ptrs = out_ptr + idx * H + cols
        # Atomic add: out[idx, cols] += expert_vals
        # out_ptr is a clone of final_hidden_states, so it starts as zeros and gets accumulated
        tl.atomic_add(out_ptrs, expert_vals, mask=mask)

        col_start += BLOCK


def _next_block_size(H: int) -> int:
    # Choose a block size to reduce lanes when H is small, and keep good throughput for larger H.
    # This remains deterministic and avoids autotune. It covers all H via masked loop.
    if H <= 128:
        return 128
    elif H <= 256:
        return 256
    else:
        # For H > 256, 256 keeps the number of iterations reasonable. The masked loop ensures full coverage.
        return 256


class ModelNew(torch.nn.Module):
    def forward(
        self,
        final_hidden_states: torch.Tensor,
        expert_outputs: torch.Tensor,
        token_indices: torch.Tensor,
    ) -> torch.Tensor:
        # Ensure contiguity and dtypes
        assert final_hidden_states.is_cuda and expert_outputs.is_cuda and token_indices.is_cuda, "Tensors must be on CUDA device"
        out = final_hidden_states.clone()  # preserve original semantics

        N = expert_outputs.shape[0]
        H = expert_outputs.shape[1]

        # Make sure inputs are contiguous
        out = out.contiguous()
        expert_outputs = expert_outputs.contiguous()
        # Triton prefers int32 for indices
        if token_indices.dtype != torch.int32:
            token_indices = token_indices.to(torch.int32)
        token_indices = token_indices.contiguous()

        # Launch one program per selected token row
        BLOCK = _next_block_size(H)
        grid = (N,)
        num_warps = 4 if BLOCK == 128 else 8
        num_stages = 2

        _index_add_rows_kernel[grid](
            out,
            expert_outputs,
            token_indices,
            N,
            H,
            BLOCK=BLOCK,
            num_warps=num_warps,
            num_stages=num_stages,
        )
        return out
```
