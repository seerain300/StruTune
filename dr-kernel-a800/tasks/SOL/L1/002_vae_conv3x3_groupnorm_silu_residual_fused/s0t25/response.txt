Design for correctness and robustness
- Convolution (bias=None, stride=1, padding=1):
  - Implement a simple Triton kernel that computes one output element per program. This avoids complex tiling and reduces the risk of indexing mistakes.
  - For each output element y[n, co, h_out, w_out], iterate over all input channels ci and the 3x3 kernel, compute h_in = h_out - 1 + kh, w_in = w_out - 1 + kw, and use masked loads to handle padding. Multiply by corresponding weight and accumulate.
  - Keep the weight layout as provided: conv_weight shaped (C_out, C_in, 3, 3), contiguous. Read w[co, ci, kh, kw] directly.
  - Operate in float32 to keep numerical stability and match typical defaults.

- GroupNorm with num_groups=32:
  - Triton kernel over (B, groups) that performs two passes:
    1) First pass: compute sum and sum of squares across the group’s elements (M = C/num_groups per group). We flatten the group’s channels and spatial dims to 1D. Do this per (n, group), iterating over m from 0 to M-1; h and w computed via m // (W * C_group), w = (m % (W * C_group)) % W, c = m % C_group.
    2) Second pass: normalize x with mean and rstd, apply affine scale (gamma) and bias (beta), and store to out.
  - This is robust across any H and W, as we don’t rely on tiling.

- SiLU activation:
  - Elementwise Triton kernel over flattened tensor: y = x * sigmoid(x). Keep it simple and robust.

- Residual addition:
  - Elementwise Triton kernel that adds two flattened tensors: out = y + residual.

- Forward:
  - No torch ops. Allocate inputs/outputs, cast weights to float32, and launch kernels in the order: conv1 -> GroupNorm1 -> SiLU1 -> conv2 -> GroupNorm2 -> SiLU2 -> add residual. Return final output.

This design prioritizes correctness by avoiding complex indexing and tiling; it handles arbitrary H, W, and ensures we don’t use torch ops. Once correctness is established, we can revisit performance optimizations.

):

    pid_n = tl.program_id(0)
    pid_g = tl.program_id(1)

    sum_val = tl.zeros((), dtype=tl.float32)
    sum_sq = tl.zeros((), dtype=tl.float32)

# Triton SiLU elementwise over a flattened buffer
@triton.jit
def silu_kernel(flattened_in_ptr, flattened_out_ptr, N, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offsets = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offsets < N
    x = tl.load(flattened_in_ptr + offsets, mask=mask, other=0.0).to(tl.float32)

    sig = 1.0 / (1.0 + tl.exp(-x))
    y = x * sig
    tl.store(flattened_out_ptr + offsets, y, mask=mask)


# Triton elementwise add: out = a + b (flattened buffers)
@triton.jit
def add_kernel(a_ptr, b_ptr, out_ptr, N, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offsets = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offsets < N

    b = tl.load(b_ptr + offsets, mask=mask, other=0.0).to(tl.float32)
