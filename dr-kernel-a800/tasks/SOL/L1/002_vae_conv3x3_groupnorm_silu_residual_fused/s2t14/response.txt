- Implement convolutions in Triton, but avoid dynamic loops. Use a per-pixel Triton kernel with grid = (B, C_out, H, W) where each program computes exactly one output pixel.     total = B * C * H * W
    if pid < total:

        HW = H_CONST * W_CONST
        n = pid // (C * H * W)
        rem1 = pid % (C * H * W)
        ci = rem1 // (H * W)
        rem2 = rem1 % (H * W)
        h = rem2 // W_CONST
        w = rem2 % W_CONST
        idx = ((n * C + ci) * H_CONST + h) * W_CONST + w

        tl.store(out_ptr + idx, y)
