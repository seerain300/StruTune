Root cause analysis
- The earlier conv3x3 Triton kernel indexed input channels with ic = ic_base + tl.arange(0, BLOCK_IC), then used ic_vec in tl.load(x_ptrs). Triton’s vectorized operations require indices to be applied correctly. While tl.load supports vector pointers, mixing a vector ic_vec with vectorized pointer arithmetic and then iterating elementwise over kh/kw with scalar pointer increments can produce incorrect accumulation or partial updates if the pointer increments aren’t aligned with the vectorized dimension. This likely caused the numerical mismatches you saw.
- To eliminate this class of errors, I will implement the conv accumulation in a pure scalar loop over input channels: for ic in range(C_in):. This avoids vectorized pointer handling for input channels and guarantees correct per-element accumulation. We will still use vectorized addressing for the 3x3 neighborhood, which is fine since we’re computing a scalar acc per output element. This approach is robust and will match PyTorch conv2d results for stride=1, padding=1, no bias.

Plan
1) Convolution Triton kernel (no bias):
   - Grid: (B, C_out, H_out*W_out) where H_out = H and W_out = W for padding=1, stride=1.
   - Each program computes one output element y[b, oc, h, w].
   - Loop over input channels ic in [0, C_in). For each ic, loop over the 3x3 neighborhood (kh, kw in 0..2), compute ih = h + kh - 1, iw = w + kw - 1, load x[b, ic, ih, iw] (masking for boundaries), load w[ic, oc, kh, kw], multiply and accumulate into a scalar acc. Store acc at y[b, oc, h, w].

2) GroupNorm + affine + SiLU Triton kernel:
   - Grid: (B, num_groups). For each (b, group):
     - First pass: compute sum and sum of squares over all elements in the group (group_channels * H * W), then mean and variance.
     - Second pass: normalize each element, apply per-channel scale and bias, then SiLU activation, and store.

3) Residual addition:
   - Launch a Triton elementwise add kernel over the flattened tensor: out = y2 + x.

4) Launch order:
   - conv3x3_triton for conv1 and conv2.
   - group_norm_affine_silu for both norms (after conv1 and after conv2).
   - add_residual_kernel at the end.

5) Optimization:
   - While not as fast as cuDNN conv, the simple scalar loop per element is correct and stable. To improve performance later, we can fuse Conv1 + GroupNorm1 + SiLU into a single Triton kernel, reducing intermediate memory writes. For now, correctness is the priority. import torch
import triton
import triton.language as tl


# Triton kernel: 3x3 conv forward (no bias), stride=1, padding=1
# x: (B, C_in, H, W), w: (C_in, C_out, 3, 3), y: (B, C_out, H, W)
# Grid: (B, C_out, H*W). Each program computes one output element y[b, oc, h, w].
@triton.jit
def conv3x3_triton(
    x_ptr, w_ptr, y_ptr,
    B, C_in, H, W, C_out,
    x_stride_b, x_stride_c, x_stride_h, x_stride_w,
    w_stride_cin, w_stride_cout, w_stride_kh, w_stride_kw,
    y_stride_b, y_stride_c, y_stride_h, y_stride_w,
):
    b = tl.program_id(0)
    oc = tl.program_id(1)
    sp = tl.program_id(2)  # linear index over H*W
    h = sp // W
    w = sp % W

    # scalar accumulator
    acc = tl.zeros((), dtype=tl.float32)

    # loop over input channels (scalar)
    for ic in range(0, C_in):
        # 3x3 neighborhood, padding=1, stride=1
        for kh in range(0, 3):
            ih = h + kh - 1  # -1, 0, 1; valid for padding=1
            for kw in range(0, 3):
                iw = w + kw - 1  # -1, 0, 1

                # load input with masks (padding ensures out-of-range inputs are zero)
                x_ptrs = x_ptr \
                         + b * x_stride_b \
                         + ic * x_stride_c \
                         + ih * x_stride_h \
                         + iw * x_stride_w
                x_val = tl.load(x_ptrs, mask=True, other=0.0)

                # load weight scalar
                w_ptrs = w_ptr \
                         + ic * w_stride_cin \
                         + oc * w_stride_cout \
                         + kh * w_stride_kh \
                         + kw * w_stride_kw
                w_val = tl.load(w_ptrs)

                acc += x_val * w_val

    # store result
    y_ptrs = y_ptr \
             + b * y_stride_b \
             + oc * y_stride_c \
             + h * y_stride_h \
             + w * y_stride_w
    tl.store(y_ptrs, acc)


# Triton kernel: GroupNorm forward + affine (scale, bias) + SiLU
# Assumes num_groups=32 and C % 32 == 0.
# x: (B, C, H, W), weight: (C,), bias: (C,), y: (B, C, H, W)
@triton.jit
def group_norm_affine_silu(
    x_ptr, weight_ptr, bias_ptr, y_ptr,
    B, C, H, W, num_groups: tl.constexpr, eps: tl.constexpr,
    x_stride_b, x_stride_c, x_stride_h, x_stride_w,
    y_stride_b, y_stride_c, y_stride_h, y_stride_w,
    BLOCK: tl.constexpr,  # reduction tile
):
    b = tl.program_id(0)
    g = tl.program_id(1)
    group_channels = C // num_groups
    group_elements = group_channels * H * W

    # first pass: compute sum and sum of squares
    sum_val = 0.0
    sum_sq = 0.0
    for start in range(0, group_elements, BLOCK):
        idx = start + tl.arange(0, BLOCK)
        mask = idx < group_elements

        ch = g * group_channels + (idx // (H * W))
        sp = idx % (H * W)
        h = sp // W
        w = sp % W

        x_ptrs = x_ptr \
                 + b * x_stride_b \
                 + ch * x_stride_c \
                 + h * x_stride_h \
                 + w * x_stride_w
        x_vals = tl.load(x_ptrs, mask=mask, other=0.0)

        sum_val += tl.sum(x_vals, axis=0)
        sum_sq += tl.sum(x_vals * x_vals, axis=0)

    mean = sum_val / group_elements
    var = sum_sq / group_elements - mean * mean
    inv_std = 1.0 / tl.sqrt(var + eps)

    # second pass: normalize, affine, SiLU
    for start in range(0, group_elements, BLOCK):
        idx = start + tl.arange(0, BLOCK)
        mask = idx < group_elements

        ch = g * group_channels + (idx // (H * W))
        sp = idx % (H * W)
        h = sp // W
        w = sp % W

        x_ptrs = x_ptr \
                 + b * x_stride_b \
                 + ch * x_stride_c \
                 + h * x_stride_h \
                 + w * x_stride_w
        x_vals = tl.load(x_ptrs, mask=mask, other=0.0)

        norm_vals = (x_vals - mean) * inv_std

        scale = tl.load(weight_ptr + ch, mask=mask, other=1.0)
        bias = tl.load(bias_ptr + ch, mask=mask, other=0.0)
        z = norm_vals * scale + bias

        s = 1.0 / (1.0 + tl.exp(-z))
        y_vals = z * s

        y_ptrs = y_ptr \
                 + b * y_stride_b \
                 + ch * y_stride_c \
                 + h * y_stride_h \
                 + w * y_stride_w
        tl.store(y_ptrs, y_vals, mask=mask)


# Triton kernel: elementwise residual add y = y + x
@triton.jit
def add_residual_kernel(out_ptr, y_ptr, x_ptr, N, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offsets = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offsets < N
    x_vals = tl.load(x_ptr + offsets, mask=mask, other=0.0)
    y_vals = tl.load(y_ptr + offsets, mask=mask, other=0.0)
    tl.store(out_ptr + offsets, x_vals + y_vals, mask=mask)


# ModelNew forward: use Triton for all computations
class ModelNew(torch.nn.Module):
    def __init__(self, eps=1e-5):
        super().__init__()
        self.eps = eps

    def forward(self, x, conv1_weight, norm1_weight, norm1_bias, conv2_weight, norm2_weight, norm2_bias):
        # Ensure contiguous float32 tensors on CUDA
        assert x.is_cuda and conv1_weight.is_cuda and norm1_weight.is_cuda and norm1_bias.is_cuda \
               and conv2_weight.is_cuda and norm2_weight.is_cuda and norm2_bias.is_cuda, "All tensors must be CUDA."
        B, C, H, W = x.shape
        assert conv1_weight.shape == (C, C, 3, 3) and conv2_weight.shape == (C, C, 3, 3), "Weight shapes must be (C, C, 3, 3)."
        num_groups = 32
        assert C % num_groups == 0, "C must be divisible by num_groups (32)."

        # 1) First conv
        y1 = torch.empty((B, C, H, W), device=x.device, dtype=torch.float32)
        x_c = x.contiguous()
        w1 = conv1_weight.contiguous()
        y1_ptr = y1
        grid1 = (B, C, H * W)
        conv3x3_triton[grid1](
            x_c, w1, y1_ptr,
            B, C, H, W, C,
            x_c.stride(0), x_c.stride(1), x_c.stride(2), x_c.stride(3),
            w1.stride(0), w1.stride(1), w1.stride(2), w1.stride(3),
            y1.stride(0), y1.stride(1), y1.stride(2), y1.stride(3),
        )

        # 2) GroupNorm + affine + SiLU for first block
        y1g = torch.empty_like(y1)
        grid_g1 = (B, num_groups)
        group_norm_affine_silu[grid_g1](
            y1, norm1_weight.contiguous(), norm1_bias.contiguous(), y1g,
            B, C, H, W, num_groups, self.eps,
            y1.stride(0), y1.stride(1), y1.stride(2), y1.stride(3),
            y1g.stride(0), y1g.stride(1), y1g.stride(2), y1g.stride(3),
            BLOCK=1024,
        )

        # 3) Second conv
        y2 = torch.empty((B, C, H, W), device=x.device, dtype=torch.float32)
        w2 = conv2_weight.contiguous()
        y2_ptr = y2
        grid2 = (B, C, H * W)
        conv3x3_triton[grid2](
            y1g, w2, y2_ptr,
            B, C, H, W, C,
            y1g.stride(0), y1g.stride(1), y1g.stride(2), y1g.stride(3),
            w2.stride(0), w2.stride(1), w2.stride(2), w2.stride(3),
            y2.stride(0), y2.stride(1), y2.stride(2), y2.stride(3),
        )

        # 4) GroupNorm + affine + SiLU for second block
        y2g = torch.empty_like(y2)
        grid_g2 = (B, num_groups)
        group_norm_affine_silu[grid_g2](
            y2, norm2_weight.contiguous(), norm2_bias.contiguous(), y2g,
            B, C, H, W, num_groups, self.eps,
            y2.stride(0), y2.stride(1), y2.stride(2), y2.stride(3),
            y2g.stride(0), y2g.stride(1), y2g.stride(2), y2g.stride(3),
            BLOCK=1024,
        )

        # 5) Residual add: y = y2g + x
        N = B * C * H * W
        out = torch.empty(N, device=x.device, dtype=torch.float32)
        y2g_flat = y2g.view(-1)
        x_flat = x_c.view(-1)
        grid_add = (triton.cdiv(N, 2048),)
        add_residual_kernel[grid_add](
            out, y2g_flat, x_flat, N, BLOCK=2048
        )
        out = out.view(B, C, H, W)

        return out

- The previous Triton conv kernel had indexing and tiling issues. The simplest robust approach for correctness is to compute exactly one output element per Triton program using a 3D grid over (B, C_out, H*W). This ensures full coverage without complicated spatial tiling.
- I previously used a vectorized accumulation over input channels and the 3x3 neighborhood. That can be error-prone. I’ll switch to scalar loops over input channels and the 3x3 neighborhood, with proper masked loads for padding=1, stride=1. This mirrors PyTorch’s F.conv2d behavior when bias is None.

Plan
- Implement conv3x3 Triton kernel:
  - Grid: (B, C_out, H*W). Each program computes y[b, oc, h, w].
  - Scalar loop over input channels ic in [0, C_in), and scalar loops over kh, kw in [0, 3) with ih = h + kh - 1, iw = w + kw - 1. Use masks to load zeros for out-of-range (due to padding), accumulate into a scalar, store.
- Implement GroupNorm + affine + SiLU Triton kernel:
  - Grid: (B, num_groups). For each (b, group), compute sum and sum of squares over the group (channels in the group × H × W), then normalize, apply per-channel scale and bias, then SiLU, and store. This matches F.group_norm behavior with num_groups=32 and C divisible by 32.
- Implement residual addition Triton kernel (elementwise y = y2 + x) and launch it at the end.
- Launch all kernels in ModelNew.forward with contiguous float32 tensors on CUDA.

This approach prioritizes correctness across diverse shapes and ensures Triton is used everywhere.

import triton
import triton.language as tl


# Triton kernel: 3x3 conv forward (no bias), stride=1, padding=1
# x: (B, C_in, H, W), w: (C_in, C_out, 3, 3), y: (B, C_out, H, W)
# Grid: (B, C_out, H*W). Each program computes one output element y[b, oc, h, w].
@triton.jit
def conv3x3_triton(
    x_ptr, w_ptr, y_ptr,
    B, C_in, H, W, C_out,
    x_stride_b, x_stride_c, x_stride_h, x_stride_w,
    w_stride_cin, w_stride_cout, w_stride_kh, w_stride_kw,
    y_stride_b, y_stride_c, y_stride_h, y_stride_w,
):
    b = tl.program_id(0)
    oc = tl.program_id(1)
    sp = tl.program_id(2)  # linear index over H*W
    h = sp // W
    w = sp % W

    # scalar accumulator
    acc = tl.zeros((), dtype=tl.float32)

    # loop over input channels (scalar), padding=1, stride=1
    for ic in range(0, C_in):
        for kh in range(0, 3):
            ih = h + kh - 1  # -1, 0, 1 (valid due to padding)
            for kw in range(0, 3):
                iw = w + kw - 1  # -1, 0, 1

                # input pointer (masked to handle padding)
                x_ptrs = x_ptr \
                         + b * x_stride_b \
                         + ic * x_stride_c \
                         + ih * x_stride_h \
                         + iw * x_stride_w
                # bounds check for padding
                x_in_bounds = (ih >= 0) & (ih < H) & (iw >= 0) & (iw < W)
                x_val = tl.load(x_ptrs, mask=x_in_bounds, other=0.0)

                # weight pointer
                w_ptrs = w_ptr \
                         + ic * w_stride_cin \
                         + oc * w_stride_cout \
                         + kh * w_stride_kh \
                         + kw * w_stride_kw
                w_val = tl.load(w_ptrs)

                acc += x_val * w_val

    # store result
    y_ptrs = y_ptr \
             + b * y_stride_b \
             + oc * y_stride_c \
             + h * y_stride_h \
             + w * y_stride_w
    tl.store(y_ptrs, acc)
