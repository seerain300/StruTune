Design and plan
- Implement both conv3x3 operations in Triton:
  - conv3x3_nchw_4d: grid over (N, C_out, H, W). Each Triton program computes exactly one output element y[n, co, h, w]. It loops over input channels ci and the 3x3 neighborhood (kh, kw). Use masks to enforce padding=1, stride=1. Accumulate in float32 and store.
  - Launch two times: conv1 (x, conv1_weight) and conv2 (result of conv1, conv2_weight).
- Implement GroupNorm in Triton:
  - groupnorm_reduce_sums: grid over (N, groups). For each (n, group), iterate over all channels in that group and all spatial positions (H*W), accumulate sum and sumsq. Store in a buffer of shape (N, groups, 2) as float32.
  - groupnorm_apply_affine_silu: grid over (N, C). For each (n, c), iterate H*W, compute group index g = c // (C // groups), load sum and sumsq, compute mean = sum / (H*W), var = sumsq / (H*W) - mean^2, rstd = 1/sqrt(var + eps). Normalize: y_norm = (y - mean) * rstd. Apply per-channel affine: y_aff = y_norm * norm_weight[c] + norm_bias[c]. Apply SiLU: y = y_aff * sigmoid(y_aff). Store result.
  - Launch twice: for conv1 result and conv2 result.
- Implement residual addition as a Triton kernel add_residual_kernel over all elements N*C*H*W: load y and x, compute y + x, store. Launch once at the end.
- Ensure tensors are contiguous and float32 for accumulation. Use stride-based addressing and masks for padding.

This preserves the original computation order: Conv3x3 -> GroupNorm -> SiLU -> Conv3x3 -> GroupNorm -> SiLU -> Add residual, but in Triton kernels. It avoids “decoy kernels” and should provide stable correctness across varied axes.

@triton.jit
def groupnorm_apply_affine_silu(y_ptr, sums_ptr, scale_ptr, bias_ptr, out_ptr,
                                N, C, H, W,
                                groups: tl.constexpr,
                                y_sN, y_sC, y_sH, y_sW,
                                out_sN, out_sC, out_sH, out_sW):

    pid_c = tl.program_id(1)

    # compute group index for channel pid_c
    group_size_c = C // groups
    g = pid_c // group_size_c

    sumsq_val = tl.load(sums_ptr + (pid_n * groups + g) * 2 + 1)

    count = H * W
    mean = sum_val / count
    # var = E[x^2] - (E[x])^2
    var = sumsq_val / count - mean * mean
    rstd = 1.0 / tl.sqrt(var + 1e-5)

    # per-channel affine parameters
    scale = tl.load(scale_ptr + pid_c)
    bias = tl.load(bias_ptr + pid_c)

    # Iterate over spatial and compute normalized + affine + SiLU, store to out
