Design and kernel strategy

- Inputs:
  - q: [total_q, num_qo_heads, head_dim] (bf16). We’ll upcast to float32 for compute.
  - k_cache: [num_pages, 1, num_kv_heads, head_dim], v_cache similarly. We’ll flatten to [num_pages, num_kv_heads, head_dim].
  - qo_indptr: [len_indptr], int32, cumulative sums of sequence lengths in q.
  - kv_indptr: [len_indptr], int32, cumulative sums of sequence lengths in KV per batch.
  - kv_indices: [num_kv_indices], int32, per-batch mapping from batch index to cache page IDs.
  - sm_scale: float32 scalar (1/sqrt(head_dim)).
- Output:
  - output: [total_q, num_qo_heads, head_dim] (bf16).
  - lse: [total_q, num_qo_heads] (float32), logsumexp of scaled logits divided by ln(2).

Mapping and loop structure:
- For each batch b (from 0 to len_indptr-2):
  - q_start = qo_indptr[b], q_end = qo_indptr[b+1], num_q_tokens = q_end - q_start.
  - kv_start = kv_indptr[b], kv_end = kv_indptr[b+1], num_kv_tokens = kv_end - kv_start.
  - If either is zero, skip.
  - Compute delta = num_kv_tokens - num_q_tokens (handles causal consideration). For each q_idx in [0..num_q_tokens-1]:
    - global_q_idx = q_start + q_idx.
    - max_kv_idx = min(q_idx + 1 + delta, num_kv_tokens). If max_kv_idx <= 0, skip (no valid KV to process).
    - For each query head h in [0..num_qo_heads-1] (we process in chunks of BLOCK):
      - kv_head = h // (num_qo_heads // num_kv_heads) = h // 4 (since 32/8 = 4).
      - q_vec = q[global_q_idx, h, :]. float32 [head_dim].
      - Gather k_list_all = k_cache_flat[page_ids[:max_kv_idx], kv_head], v_list_all similarly, both [max_kv_idx, head_dim].
      - Compute logits = q_vec · k_list_all^T -> [max_kv_idx].
      - scaled = logits * sm_scale.
      - lse_val = logsumexp(scaled)/ln(2) and store to lse[global_q_idx, h].
      - attn = softmax(scaled) and out_vec = attn · v_list_all -> [head_dim].
      - Store out_vec to output[global_q_idx, h, :].

Implementation details:
- Flatten k_cache and v_cache across the size-1 dimension to k_cache_flat and v_cache_flat (view or squeeze), then gather rows by k_ids and kv_head.
- Triton kernel attention_qkv_kernel is launched with grid (len_indptr - 1) (one program per batch element b). Inside each program, we process all q indices and all heads. We use while loops to handle dynamic lengths since Triton supports while loops with runtime bounds. We upcast q, k, v to float32 for stability, compute logits, softmax, and matvec. We store output and lse directly.
- We avoid any torch operations in the host code. We allocate outputs and lse tensors and move them to CUDA before launching the kernel. If tensors are on CPU, we move them to the current CUDA device for Triton.

Correctness considerations:
- Handles num_q_tokens = 0 or num_kv_tokens = 0 by early returns in the kernel.
- Handles max_kv_idx <= 0 by skipping (matches original behavior).
- GQA head mapping: kv_head = h // 4.
- Data types: compute in float32, store output as float32 then cast to bfloat16 outside. lse as float32.

Performance considerations:
- This Triton kernel removes Python-level per-head and per-query loops and performs the entire attention per (b, q_idx, h) in a single kernel, vectorized. While Triton’s small reductions are simple, the fused approach should outperform the original PyTorch loops for large workloads.
- The kernel uses while loops to build k_list_all and v_list_all; for head_dim=128 and max_kv_idx modest, this is fine. If max_kv_idx is large, more sophisticated kernels could be written, but the provided workloads appear small per batch.

import torch
import triton
import triton.language as tl


@triton.jit
def attention_qkv_kernel(
    q_ptr,          # *f32, shape [total_q, num_qo_heads, head_dim]
    k_ptr,          # *f32, shape [num_pages, num_kv_heads, head_dim] (flattened view created on host)
    v_ptr,          # *f32, shape [num_pages, num_kv_heads, head_dim]
    kv_indices_ptr, # *i32, shape [num_kv_indices]
    qo_indptr_ptr,  # *i32, shape [len_indptr]
    kv_indptr_ptr,  # *i32, shape [len_indptr]
    out_ptr,        # *f32, shape [total_q, num_qo_heads, head_dim]
    lse_ptr,        # *f32, shape [total_q, num_qo_heads]
    num_qo_heads: tl.constexpr,   # 32
    num_kv_heads: tl.constexpr,   # 8
    head_dim: tl.constexpr,       # 128
    sm_scale: tl.float32,
):
    b = tl.program_id(0)  # one program per batch element (interval)

    # Load qo_indptr[b], qo_indptr[b+1]
    qo_start = tl.load(qo_indptr_ptr + b)
    qo_end = tl.load(qo_indptr_ptr + b + 1)
    num_q_tokens = qo_end - qo_start

    # Load kv_indptr[b], kv_indptr[b+1]
    kv_start = tl.load(kv_indptr_ptr + b)
    kv_end = tl.load(kv_indptr_ptr + b + 1)
    num_kv_tokens = kv_end - kv_start

    # If intervals are invalid, skip
    if (num_q_tokens <= 0) or (num_kv_tokens <= 0):
        return

    # Compute delta for causal consideration
    delta = num_kv_tokens - num_q_tokens

    # Process each query token in this batch
    q_idx = 0
    while q_idx < num_q_tokens:
        global_q_idx = q_idx + qo_start

        # Compute max_kv_idx for this query (causal + delta)
        # If q_idx + 1 + delta <= num_kv_tokens, use that; else 0
        max_kv_idx = q_idx + 1 + delta
        if max_kv_idx > num_kv_tokens:
            max_kv_idx = num_kv_tokens
        else:
            max_kv_idx = max(0, max_kv_idx)

        # If no valid KV entries for this query, skip
        if max_kv_idx <= 0:
            q_idx += 1
            continue

        # Process heads in chunks (BLOCK=32 covers all 32 heads)
        h = 0
        while h < num_qo_heads:
            # Current head h, and corresponding KV head
            h_i = h
            kv_head = h_i // (num_qo_heads // num_kv_heads)  # 32 // 8 = 4
            kv_head = kv_head  # integer division

            # Load q vector for this head: q[global_q_idx, h, :]
            q_row = q_ptr + global_q_idx * (num_qo_heads * head_dim) + h_i * head_dim
            q_vec = tl.load(q_row + tl.arange(0, head_dim))  # [head_dim] f32

            # Build k_list_all and v_list_all: [max_kv_idx, head_dim]
            k_list_all = tl.zeros([max_kv_idx, head_dim], dtype=tl.float32)
            v_list_all = tl.zeros([max_kv_idx, head_dim], dtype=tl.float32)

            k_offset = kv_start
            j = 0
            while j < max_kv_idx:
                k_id = tl.load(kv_indices_ptr + k_offset + j)  # int32
                # row index in flattened k_ptr is k_id * num_kv_heads + kv_head
                row_k = k_id * num_kv_heads + kv_head
                k_vec = tl.load(k_ptr + row_k * head_dim + tl.arange(0, head_dim))
                k_list_all[j, :] = k_vec
                j += 1

            # For v_list_all, rows are same k_ids and kv_head
            j = 0
            while j < max_kv_idx:
                k_id = tl.load(kv_indices_ptr + k_offset + j)  # int32
                row_v = k_id * num_kv_heads + kv_head
                v_vec = tl.load(v_ptr + row_v * head_dim + tl.arange(0, head_dim))
                v_list_all[j, :] = v_vec
                j += 1

            # Compute logits = q_vec · k_list_all^T -> [max_kv_idx]
            logits = tl.zeros([max_kv_idx], dtype=tl.float32)
            for idx in range(0, max_kv_idx):
                dot = 0.0
                for d in range(0, head_dim):
                    dot += q_vec[d] * k_list_all[idx, d]
                logits[idx] = dot

            # Scale and compute lse = logsumexp(logits * sm_scale) / ln(2)
            scaled = logits * sm_scale
            # max trick
            max_scaled = -float('inf')
            for idx in range(0, max_kv_idx):
                if scaled[idx] > max_scaled:
                    max_scaled = scaled[idx]
            sumexp = 0.0
            for idx in range(0, max_kv_idx):
                sumexp += tl.exp(scaled[idx] - max_scaled)
            lse_val = (max_scaled + tl.log(sumexp)) * 1.44269504  # 1/ln(2)

            # Store lse to lse_ptr[global_q_idx, h_i]
            lse_offset = global_q_idx * num_qo_heads + h_i
            tl.store(lse_ptr + lse_offset, lse_val)

            # Compute attn = softmax(scaled)
            sumexp_shift = 0.0
            for idx in range(0, max_kv_idx):
                sumexp_shift += tl.exp(scaled[idx] - lse_val)
            attn = tl.zeros([max_kv_idx], dtype=tl.float32)
            for idx in range(0, max_kv_idx):
                attn[idx] = tl.exp(scaled[idx] - lse_val) / sumexp_shift

            # Compute out_vec = attn · v_list_all (matvec), store to output
            out_row = out_ptr + global_q_idx * (num_qo_heads * head_dim) + h_i * head_dim
            out_vec = tl.zeros([head_dim], dtype=tl.float32)
            for d in range(0, head_dim):
                dot_v = 0.0
                for idx in range(0, max_kv_idx):
                    dot_v += attn[idx] * v_list_all[idx, d]
                out_vec[d] = dot_v
            # Store out_vec
            for d in range(0, head_dim):
                tl.store(out_row + d, out_vec[d])

            h += 32  # process 32 heads per chunk; here num_qo_heads is 32, so one iteration
        q_idx += 1


class ModelNew(torch.nn.Module):
    def __init__(self):
        super().__init__()

    def forward(self, q, k_cache, v_cache, qo_indptr, kv_indptr, kv_indices, sm_scale):
        # Ensure CUDA tensors for Triton
        if q.device.type != 'cuda':
            q = q.to('cuda')
        if k_cache.device.type != 'cuda':
            k_cache = k_cache.to('cuda')
        if v_cache.device.type != 'cuda':
            v_cache = v_cache.to('cuda')
        if qo_indptr.device.type != 'cuda':
            qo_indptr = qo_indptr.to('cuda')
        if kv_indptr.device.type != 'cuda':
            kv_indptr = kv_indptr.to('cuda')
        if kv_indices.device.type != 'cuda':
            kv_indices = kv_indices.to('cuda')

        # Upcast to float32 for compute
        q_f32 = q.to(torch.float32)
        k_cache_f32 = k_cache.squeeze(1).to(torch.float32)  # [num_pages, num_kv_heads, head_dim]
        v_cache_f32 = v_cache.squeeze(1).to(torch.float32)

        total_q = q_f32.shape[0]
        num_qo_heads = 32
        num_kv_heads = 8
        head_dim = 128
        num_batches = qo_indptr.shape[0] - 1  # len_indptr - 1

        # Allocate outputs
        output = torch.empty((total_q, num_qo_heads, head_dim), dtype=torch.float32, device='cuda')
        lse = torch.full((total_q, num_qo_heads), -float('inf'), dtype=torch.float32, device='cuda')

        # Launch Triton kernel: one program per batch element
        grid = (num_batches,)
        attention_qkv_kernel[grid](
            q_f32, k_cache_f32, v_cache_f32, kv_indices, qo_indptr, kv_indptr,
            output, lse,
            num_qo_heads=num_qo_heads, num_kv_heads=num_kv_heads, head_dim=head_dim,
            sm_scale=float(sm_scale),
        )

        # Cast output back to bfloat16 as in original
        output_bf16 = output.to(torch.bfloat16)
        return output_bf16, lse
