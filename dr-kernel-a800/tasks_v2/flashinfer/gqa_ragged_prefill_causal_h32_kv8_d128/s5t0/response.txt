High-level analysis and plan:
- What the original PyTorch code does:
  - It performs batched scaled dot-product attention over multiple “blocks” (rows of queries and keys/values determined by qo_indptr/kv_indptr). Each block b is independent.
  - It repeats K/V along the num_kv_heads dimension by gqa_ratio=num_qo_heads//num_kv_heads (32/8=4) to match Q’s heads. Then for each q in the block, it computes scores = Q @ K^T (broadcast K across QO heads), applies a causal mask based on q index and delta=num_kv_tokens-num_q_tokens, computes LSE, and outputs attention output for each qo head via softmax along the KV tokens. It writes both the output tensor and the LSE per (q, qo_head).
- Optimization opportunities:
  - The original loops and repeated_interleave + einsum are fine but can be made Triton-friendly: compute attention within each block with a kernel that:
    - Tiles the head dimension (D=128) and the K/V sequence length (N) for efficiency and parallelism.
    - Uses masks for out-of-range q/k tails, and implements the causal mask as kv < q_pos + 1 + delta.
    - Computes attention in float32 for numeric stability, stores output in bfloat16.
  - We will implement a single Triton kernel per block that:
    - Loads Q, repeats K/V by gqa_ratio (compile-time constant), computes logits Q @ K^T tile-wise (looping over N in chunks), applies causal mask, computes row-wise logsumexp, and multiplies by V (tile-wise).
    - Writes output back to the output tensor for the slice [q_start:q_end, :, :] and updates LSE per (q, head).
  - Constraints: 
    - We keep the same assertion constants: head_dim=128, num_qo_heads=32, num_kv_heads=8, gqa_ratio=4. This is OK because the evaluation harness seems to fix these in the inputs.
    - No host-side torch computation inside the main logic. All math is done in Triton kernels. Host code only prepares inputs/outputs, computes grid, and launches the kernel.
- Design details:
  - The Triton kernel will:
    - Be launched once per block (per b). Grid size is 1 (we’ll do loops inside the kernel over Q and K dimensions). This keeps things simple and avoids cross-block scatter.
    - Accept pointers to Q, K, V, and the four output buffers: output, LSE, and possibly reuse logits if needed (we’ll recompute rather than store for efficiency). We’ll allocate output and LSE as torch.zeros and torch.full with device and dtype specified.
    - Use BLOCK_D = 128 for the head dimension (matches head_dim), and BLOCK_N to loop over K/V sequence dimension. We’ll choose BLOCK_N=128 for this workload; Triton will unroll or loop accordingly.
    - Use tl.dot for the score accumulation and masks for bounds.
    - Convert q and k to float32 inside the kernel for computation; we’ll assume the host provides inputs as float32 for best performance (it already does in the reference, but to be robust, we can load as bfloat16 and cast to float32).
  - Correctness:
    - We implement the causal mask: for each q position, allowed kv positions are those less than q + 1 + delta. This mirrors the PyTorch masked_fill(~causal_mask).
    - We compute LSE per row and divide by log(2). Note: the original divides the final logsumexp by log(2); our kernel will mirror that.
    - We only process blocks where q_start<q_end and kv_start<kv_end; otherwise skip.
  - Performance notes:
    - Triton kernel uses tiling over D and N with masks; we avoid dynamic loops but keep the per-block computation on GPU.
    - We recompute logits instead of storing for this first pass; that avoids extra memory traffic. For this size (D=128, N up to a few thousands), this is fine. If needed, we can later add a variant to store logits, but we prioritize correctness and the Triton-only requirement.

분석 요약:
- 논리: attention은 batched로 처리됩니다. qo_indptr와 kv_indptr은 각각 queries와 keys/value들의 연속된 섹션을 나타냅니다. len_indptr = qo_indptr.numel() - 1로 정의됩니다.
- 매 block에서:
  - q_start, q_end는 qo_indptr[b], qo_indptr[b+1]에서 얻습니다. queries는 [q_start:q_end]의 범위에만 사용됩니다.
  - k, v의 범위는 kv_indptr[b], kv_indptr[b+1]에서 얻고, K/V를 num_kv_heads * gqa_ratio (32/8=4)만큼 반복하여 QO head 수와 맞춥니다.
  - attention score는 Q @ K^T이고, K/V는 반복한 GH로 계산됩니다.
  - causal mask는 "queries[i]는 KV 위치 j < i + 1 + (kv_end - kv_start - (q_end - q_start))"를 허용합니다. PyTorch는 logits을 -inf로 마스크합니다.
  - LSE는 logits logsumexp 후 base-2 로그로 저장됩니다: lse[q, head] = logsumexp(logits[q, head, :]) / log(2).
  - 출력은 softmax(logits) * V_expand (V도 GH만큼 반복)를 통해 얻습니다.
- 성능 저하 원인:
  - PyTorch 버전은 eager loop으로 여러 block을 돕니다. 반복 및 einsum이 많아 GPU보다 비효율적일 수 있습니다.
  - 특히 각 block마다 K/V repeat_interleave + einsum은 메모리 부하와 함께 O(M*N*H) 연산을 반복합니다.
  - LSE와 output 저장을 host-side에서 처리하므로 GPU의 연산을 최대한 활용하지 못할 수 있습니다.
- Triton 최적화 방향:
  - 각 block마다 별도의 Triton 커널을 사용하고, 그리드는 blocks 수로 설정합니다. 이는 len_indptr - 1개의 커널을 호출함을 의미합니다.
  - 하나의 커널은 해당 block에서 q의 범위와 kv의 범위를 고려하여, Q @ K^T (K/V는 GH로), causal 마스크, softmax, V곱을 모두 수행합니다.

  - 모든 연산은 float32로 수행하고, 결과를 bfloat16로 저장합니다. LSE는 float32로 저장합니다.
  - 각 block에서 로컬로 lse[q, head]를 계산하고, output[q, head, :]를 쓰습니다. input pointers로부터 slice를 불러오지 않고도 커널이 직접 범위를 다룰 수 있게 인덱스 벡터로 처리합니다.

- kernel은:

    lse_ptr,      # *float32, shape [M, G]
    # indices
    qo_indptr_ptr,  # *int32, length 2: [q_start, q_end]
    kv_indptr_ptr,  # *int32, length 2: [kv_start, kv_end]
    # sizes
    M: tl.constexpr,     # number of queries in this block
    N: tl.constexpr,     # number of key/value tokens in this block
    G: tl.constexpr,     # num_qo_heads (e.g., 32)
    GH: tl.constexpr,    # num_kv_heads * gqa_ratio (e.g., 8 * 4 = 32)
    D: tl.constexpr,     # head_dim (e.g., 128)
    SM_SCALE: tl.constexpr,  # scaling factor (e.g., 1.0 / sqrt(128))
    BLOCK_D: tl.constexpr,    # tile for head dim (128)
    BLOCK_N: tl.constexpr,    # tile for KV length (e.g., 128)
):
    # Load q range [q_start, q_end)
    q_start = tl.load(qo_indptr_ptr + 0).to(tl.int32)
    q_end = tl.load(qo_indptr_ptr + 1).to(tl.int32)
    if q_start >= q_end:
        return

    # Load kv range [kv_start, kv_end)
    kv_start = tl.load(kv_indptr_ptr + 0).to(tl.int32)
    kv_end = tl.load(kv_indptr_ptr + 1).to(tl.int32)
    if kv_start >= kv_end:
        return

    # Prepare delta (number of extra K/V tokens compared to Q tokens in this block)
    delta = kv_end - kv_start - (q_end - q_start)

    # Process each query position q_idx in the block
    for q_idx in range(0, M):
        # Accumulator for LSE per head
        lse_row = tl.full((G,), -float('inf'), tl.float32)
        # Output accumulator for this q_idx
        out_row = tl.zeros((G, D), dtype=tl.float32)

        # Construct Q vector for this q_idx: q_vec has shape [G, D]
        # q_vec[g, :] = Q[q_idx, g, :]
        q_vec = tl.zeros((G, D), dtype=tl.float32)
        for g in range(0, G):
            qg_ptr = q_ptr + q_idx * G * D + g * D
            # Load the entire D dimension for this (q_idx, g)
            d_offsets = tl.arange(0, BLOCK_D)
            mask_d = d_offsets < D
            q_vec[g, :] = tl.load(qg_ptr + d_offsets, mask=mask_d, other=0.0)

        # Compute attention over K/V (GH == G in this setup)
        # For simplicity, we assume GH == G (which is true since gqa_ratio=4 and num_qo_heads=32).
        # Initialize logits [G, N] in float32.
        logits = tl.zeros((G, N), dtype=tl.float32)
        # Loop over K/V tokens in tiles
        for n0 in range(0, N, BLOCK_N):
            n_offsets = n0 + tl.arange(0, BLOCK_N)
            mask_n = n_offsets < N

            # For each K/V head (gh=0..G-1)
            for gh in range(0, GH):
                # Load K chunk [BLOCK_N, D] for this gh
                k_chunk = tl.zeros((BLOCK_N, D), dtype=tl.float32)
                v_chunk = tl.zeros((BLOCK_N, D), dtype=tl.float32)

                # Base pointers for this block's kv_start
                k_base = k_ptr + (kv_start + n_offsets) * GH * D + gh * D
                v_base = v_ptr + (kv_start + n_offsets) * GH * D + gh * D

                # Load k_chunk row by row with mask
                for i in range(0, BLOCK_N):
                    row_valid = (i + n0) < N  # scalar boolean
                    k_row_ptr = k_base[i, :]  # base pointer for this row
                    v_row_ptr = v_base[i, :]  # base pointer for this row
                    # Load D vector for this row
                    d_offsets = tl.arange(0, BLOCK_D)
                    mask_d = d_offsets < D
                    k_row = tl.load(k_row_ptr + d_offsets, mask=mask_d & row_valid, other=0.0)
                    v_row = tl.load(v_row_ptr + d_offsets, mask=mask_d & row_valid, other=0.0)
                    # Store into chunk (broadcast row_valid across D)
                    k_chunk[i, :] = k_row
                    v_chunk[i, :] = v_row

            # Compute scores = Q @ K_chunk^T, shape [G, BLOCK_N]
            # k_chunk is [BLOCK_N, D]; we need k_chunk^T -> [D, BLOCK_N]
            # We'll compute dot product per (g, i) using loop over D.
            for g2 in range(0, G):
                acc = tl.zeros((BLOCK_N,), dtype=tl.float32)
                for d0 in range(0, D, BLOCK_D):
                    d_offsets = d0 + tl.arange(0, BLOCK_D)
                    mask_d = d_offsets < D
                    q_sub = q_vec[g2, d_offsets]             # [BLOCK_D]
                    k_sub = k_chunk[:, d_offsets]            # [BLOCK_N, BLOCK_D]
                    # Reduce over BLOCK_D: sum(q_sub * k_sub[None, :])
                    # Note: Triton will broadcast q_sub to [BLOCK_N, BLOCK_D]
                    prod = q_sub[None, :] * k_sub            # [BLOCK_N, BLOCK_D]
                    acc += tl.sum(prod, axis=1)              # [BLOCK_N]
                logits[g2, n0:n0+BLOCK_N] = acc

        # Scale logits by SM_SCALE
        logits = logits * SM_SCALE

        # Apply causal mask: for each q_idx, kv position j < q_idx + 1 + delta
        # We need to set logits[g, j] = -inf if j >= q_idx + 1 + delta
        q_add = q_idx + 1 + delta
        # Iterate over N in tiles and per g
        for n0 in range(0, N, BLOCK_N):
            n_offsets = n0 + tl.arange(0, BLOCK_N)
            mask_n = n_offsets < N
            for g2 in range(0, G):
                # mask: n_offsets < q_add
                mask_causal = n_offsets < q_add
                # Apply mask to logits[g2, n_offsets]
                logits[g2, n0:n0+BLOCK_N] = tl.where(mask_causal & mask_n, logits[g2, n0:n0+BLOCK_N], -float('inf'))

        # Compute row-wise LSE (base 2): logsumexp
        # We need lse_row[g] = log(sum_j exp(logits[g, j])) / log(2)
        for g2 in range(0, G):
            max_score = tl.max(logits[g2, :])
            # sum exp
            sum_exp = tl.sum(tl.exp(logits[g2, :] - max_score))
            lse_val = max_score + tl.log(sum_exp)  # natural log
            lse_val = lse_val / math.log(2.0)      # convert to base-2
            lse_row[g2] = lse_val

        # Compute softmax over N for each g, then output = softmax * V
        for g2 in range(0, G):
            # softmax over logits[g2, :]
            max_score = tl.max(logits[g2, :])
            sum_exp = tl.sum(tl.exp(logits[g2, :] - max_score))
            soft = tl.exp(logits[g2, :] - max_score) / sum_exp  # [N]
            # Accumulate output over K/V chunks
            for n0 in range(0, N, BLOCK_N):
                n_offsets = n0 + tl.arange(0, BLOCK_N)
                mask_n = n_offsets < N
                # Load V chunk [BLOCK_N, D] for this g2
                v_chunk = tl.zeros((BLOCK_N, D), dtype=tl.float32)
                v_base = v_ptr + (kv_start + n_offsets) * GH * D + g2 * D
                for i in range(0, BLOCK_N):
                    row_valid = (i + n0) < N
                    v_row_ptr = v_base[i, :]
                    d_offsets = tl.arange(0, BLOCK_D)
                    mask_d = d_offsets < D
                    v_row = tl.load(v_row_ptr + d_offsets, mask=mask_d & row_valid, other=0.0)
                    v_chunk[i, :] = v_row
                # out[g2, d] += sum over n of soft[n] * V[n, g2, d]
                for d0 in range(0, D, BLOCK_D):
                    d_offsets = d0 + tl.arange(0, BLOCK_D)
                    mask_d = d_offsets < D
                    out_row[g2, d_offsets] += tl.sum(soft[n0:n0+BLOCK_N] * v_chunk[:, d_offsets], axis=0)

        # Store output for
