- The original PyTorch code performs, per batch element:

  - It uses two matmuls (conceptually q @ Kc.T and q @ Kp.T) plus elementwise ops and reductions.

- Optimization strategy:
  - The benchmark workloads vary len_indptr (number of batch elements). The previous approach tried to process multiple batch elements per kernel and used some torch operations; that was invalid. We’ll implement a simple, robust Triton kernel that processes exactly one batch element per launch. In ModelNew.forward, we will loop over b in range(len_indptr - 1) and call this Triton kernel once per batch element. This guarantees correctness and uses Triton across all len_indptr > 1.
  - Inside the kernel:
    - Compute q_len = qo_indptr[b+1] - qo_indptr[b], kv_len = kv_indptr[b+1] - kv_indptr[b], and q_start = qo_indptr[b].
    - Reconstruct tok_idx for this batch element by indexing kv_indices[page_beg:page_end] where page_beg = kv_indptr[b], page_end = kv_indptr[b+1].
    - Preselect Kc_sel = ckv_cache[tok_idx] and Kp_sel = kpe_cache[tok_idx], both of shape [kv_len, head_dim_ckv] and [kv_len, head_dim_kpe]. We can build these in the host for each b and pass them to the kernel.
    - Loop over queries i from 0 to q_len-1:
      - Load qn[h, :] and qp[h, :] for all heads h (fixed NUM_HEADS=16), convert to float32.
      - Compute logits per head: for each j in [0, kv_len), compute dot(qn, Kc_sel[j, :]) + dot(qp, Kp_sel[j, :]).
      - Scale logits, apply causal mask: valid j >= prefix_len + i + 1, otherwise -inf; prefix_len = kv_len - q_len.
      - Compute logsumexp in log2: lse = logsumexp(logits) / ln(2).
      - Compute softmax (stable) across j.
      - Output vector: out[h, :] = sum_j softmax[h, j] * Kc_sel[j, :] and store to output[q_abs, h, :].
    - Store lse[q_abs, h] for each head h.
  - This kernel avoids any PyTorch ops in forward. The host only allocates output, lse, and computes Kc_sel/Kp_sel per batch element; it then launches the Triton kernel. The Triton kernel does all math: matmul equivalents via dot products, scaling, masking, reductions, softmax, and final output multiplication.

- Device/dtype handling:
  - The provided get_inputs returns tensors on CUDA (because of .to(torch.int32) and default torch.randn producing float tensors; the evaluation harness will place them on GPU). We’ll cast loads to float32 inside the kernel for stable math and store outputs as float32; outside the kernel we can return the requested dtype. To match the original interface, the output is bfloat16 and lse is float32. We can allocate output as bfloat16 in forward and cast when storing inside the kernel (Triton can write to bf16 pointers). For simplicity, we’ll keep output in float32 in forward and cast to bfloat16 at the end; but since forward must not perform torch operations, we can return float32 lse and cast output to bfloat16 outside. To keep everything Triton-only, we will allocate output as bf16 and cast q_nope/q_pe to float32 via Triton pointer loads; no torch ops.
  - Asserts: num_qo_heads == 16, head_dim_ckv == 512, head_dim_kpe == 64. We’ll assert these and use them as compile-time constants in the kernel.

- Robustness:
  - For len_indptr <= 1, qo_indptr[-1] is not defined; the original code also relies on len_indptr > 1. In our ModelNew, we will only run the Triton kernel when len_indptr > 1. For len_indptr == 1, we’ll use a pure PyTorch fallback to ensure correctness (even though the benchmark workloads show len_indptr >= 2).

import torch
import math
import triton
import triton.language as tl


@triton.jit
def _forward_batch_kernel(
    # Input pointers
    q_nope_ptr,       # *fp16, shape [Q_total, 16, 512], row-major
    q_pe_ptr,         # *fp16, shape [Q_total, 16, 64], row-major
    Kc_sel_ptr,       # *fp16, shape [kv_len, 512], contiguous rows
    Kp_sel_ptr,       # *fp16, shape [kv_len, 64], contiguous rows
    qo_indptr_ptr,    # *int32, [len_indptr]
    output_ptr,       # *bf16, shape [Q_total, 16, 512], row-major
    lse_ptr,          # *fp32, shape [Q_total, 16]
    # scalar args
    q_len,            # int
    kv_len,           # int
    q_start,          # int
    sm_scale: tl.constexpr,       # fp32
    ln2_inv: tl.constexpr,        # fp32 = 1.0 / ln(2.0)
    NUM_HEADS: tl.constexpr,      # 16
    HEAD_DIM_CKV: tl.constexpr,   # 512
    HEAD_DIM_KPE: tl.constexpr,   # 64
):
    # Loop over queries in this batch element
    for i in range(q_len):
        q_abs = q_start + i

        # Load qn[h, :] and qp[h, :] for all heads
        qn = tl.zeros((NUM_HEADS, HEAD_DIM_CKV), dtype=tl.float32)
        qp = tl.zeros((NUM_HEADS, HEAD_DIM_KPE), dtype=tl.float32)

        for h in range(NUM_HEADS):
            k_vec = tl.arange(0, HEAD_DIM_CKV)
            offset_qn = q_abs * (NUM_HEADS * HEAD_DIM_CKV) + h * HEAD_DIM_CKV + k_vec
            qn[h, :] = tl.load(q_nope_ptr + offset_qn, mask=k_vec < HEAD_DIM_CKV, other=0.0).to(tl.float32)

            kpe_vec = tl.arange(0, HEAD_DIM_KPE)
            offset_qp = q_abs * (NUM_HEADS * HEAD_DIM_KPE) + h * HEAD_DIM_KPE + kpe_vec
            qp[h, :] = tl.load(q_pe_ptr + offset_qp, mask=kpe_vec < HEAD_DIM_KPE, other=0.0).to(tl.float32)

        # Compute logits per head: [NUM_HEADS, kv_len]
        logits = tl.zeros((NUM_HEADS, kv_len), dtype=tl.float32)

        for j in range(kv_len):
            k_vec = tl.arange(0, HEAD_DIM_CKV)
            Kc_j = tl.load(Kc_sel_ptr + j * HEAD_DIM_CKV + k_vec, mask=k_vec < HEAD_DIM_CKV, other=0.0).to(tl.float32)
            dot_qn = tl.sum(qn * Kc_j[None, :], axis=1)  # [NUM_HEADS]

            kpe_vec = tl.arange(0, HEAD_DIM_KPE)
            Kp_j = tl.load(Kp_sel_ptr + j * HEAD_DIM_KPE + kpe_vec, mask=kpe_vec < HEAD_DIM_KPE, other=0.0).to(tl.float32)
            dot_qp = tl.sum(qp * Kp_j[None, :], axis=1)  # [NUM_HEADS]

            logits[:, j] = dot_qn + dot_qp

        # Scale
        logits = logits * sm_scale

        # Causal mask: valid j >= prefix_len + i + 1, where prefix_len = kv_len - q_len
        prefix_len = kv_len - q_len
        valid_start = prefix_len + i + 1
        j_vec = tl.arange(0, kv_len)
        causal_mask = j_vec >= valid_start
        logits = tl.where(causal_mask, -float("inf"), logits)

        # logsumexp in log2
        m = tl.max(logits, axis=1)  # [NUM_HEADS]
        sumexp = tl.sum(tl.exp(logits - m[:, None]), axis=1)
        lse_val = m + tl.log(sumexp) * ln2_inv  # [NUM_HEADS]
        for h in range(NUM_HEADS):
            tl.store(lse_ptr + q_abs * NUM_HEADS + h, lse_val[h])

        # Softmax (stable)
        logits = logits - m[:, None]
        exp_logits = tl.exp(logits)
        denom = tl.sum(exp_logits, axis=1)[:, None]  # [NUM_HEADS, 1]
        softmax = exp_logits / denom  # [NUM_HEADS, kv_len]

        # Output: out[h, :] = sum_j softmax[h,j] * Kc_sel[j, :]
        out_vec = tl.zeros((HEAD_DIM_CKV,), dtype=tl.float32)
        for h in range(NUM_HEADS):
            for j in range(kv_len):
                k_vec = tl.arange(0, HEAD_DIM_CKV)
                Kc_j = tl.load(Kc_sel_ptr + j * HEAD_DIM_CKV + k_vec, mask=k_vec < HEAD_DIM_CKV, other=0.0).to(tl.float32)
                out_vec += softmax[h, j] * Kc_j
            # Store to output[q_abs, h, :]
            k_out_vec = tl.arange(0, HEAD_DIM_CKV)
            out_offset = q_abs * (NUM_HEADS * HEAD_DIM_CKV) + h * HEAD_DIM_CKV + k_out_vec
            # Cast to bf16 for storage (output_ptr is bf16)
            tl.store(output_ptr + out_offset, out_vec.to(tl.bfloat16), mask=k_out_vec < HEAD_DIM_CKV)
