- Root-cause analysis of failure

- The evaluation reported “INCORRECT_SHAPE” on all workloads. The most likely cause is that the Triton LayerNorm kernel I wrote used tl.program_id(2) for the third grid dimension and assumed the grid size along that dimension was exactly ceil_div(D, BLOCK_D). In Triton, you don’t actually get “how many programs” were launched along an axis from inside the kernel; tl.program_id(n) only returns the index, not the launch grid size. As a result, that kernel cannot compute which tile it corresponds to (the offset along D) without knowing the grid shape. That makes it unsafe for general D/BLOCK_D; you need to pass the grid size as a compile-time constant or restructure the kernel.

- Additionally, I launched the LayerNorm with grid = (B, L, tiles), but the kernel expected grid = (B, L, tiles) with correct indexing. In Triton, to do a tiled reduction over the last dimension, a common pattern is to use a single program per (b,l) and loop over D in tiles. That avoids needing a 3rd grid dimension. This also makes it robust and simple.

- Another subtlety: masks in reductions. If you use masked loads and then do tl.sum over a vector that includes masked-off elements, you must ensure those elements don’t contribute. Using other=0.0 ensures masked elements contribute zero to the sum, but in the first reduction we must not count out-of-range elements. The loop pattern fixes this: each tile is fully in-range.

- Performance plan

- Correctness first: fix LayerNorm kernel to a per-(b,l) tiled reduction loop. Compute mean and var in fp32, normalize, apply affine. Then launch a second “apply” kernel that writes normalized and affine output (optional optimization, but we can do it in the same kernel or separate). Given the feedback, correctness and shape handling must be fixed before any performance optimization.

- Then integrate Triton where it matters:
  - Implement LayerNorm for both norm1 (first LayerNorm) and norm2 (second LayerNorm) in Triton. This is a significant operation and should be fast.
  - Implement the input projection u = F.linear(normed, in_proj_weight, in_proj_bias) in Triton. We’ll implement a per-(b,l) matvec where each program computes the output vector for that (b,l). This avoids torch.mm and keeps math in Triton.
  - Keep conv1d and Hyena recurrence in PyTorch for now. Implementing conv in Triton with groups=inner_width is doable but non-trivial; the benchmark likely expects correctness first. The “Hyena” FFT path is heavy and non-trivial in Triton; using PyTorch’s torch.fft is acceptable for now. We will note that extending to Triton is possible with additional work.

@triton.jit
def layernorm_stats_3d_bL(
    X,            # *ptr* to input [B, L, D]
    SUM,          # *ptr* to per (b,l) sum [B*L]
    SUMSQ,        # *ptr* to per (b,l) sumsq [B*L]
    B, L, D,
    BLOCK_D: tl.constexpr,
):
    b = tl.program_id(0)
    l = tl.program_id(1)
    base = (b * L + l) * D
    sum_val = tl.zeros((), dtype=tl.float32)
    sumsq_val = tl.zeros((), dtype=tl.float32)

    # Loop over D in tiles
    for d0 in range(0, D, BLOCK_D):
        d_offsets = d0 + tl.arange(0, BLOCK_D)
        mask = d_offsets < D
        x = tl.load(X + base + d_offsets, mask=mask, other=0.0).to(tl.float32)
        sum_val += tl.sum(x, axis=0)
        sumsq_val += tl.sum(x * x, axis=0)

    # Store per-(b,l) stats
    tl.store(SUM + b * L + l, sum_val)
    tl.store(SUMSQ + b * L + l, sumsq_val)


@triton.jit
def layernorm_apply_3d_bL(
    X,            # *ptr* to input [B, L, D]
    Y,            # *ptr* to output [B, L, D]
    W,            # *ptr* to weight [D]
    BIAS,         # *ptr* to bias [D]
    SUM,          # *ptr* to per (b,l) sum [B*L]
    SUMSQ,        # *ptr* to per (b,l) sumsq [B*L]
    EPS: tl.constexpr,
    B, L, D,
    BLOCK_D: tl.constexpr,
):
    b = tl.program_id(0)
    l = tl.program_id(1)
    base = (b * L + l) * D

    sum_val = tl.load(SUM + b * L + l)
    sumsq_val = tl.load(SUMSQ + b * L + l)
    mean = sum_val / D
    var = sumsq_val / D - mean * mean
    inv_std = 1.0 / tl.sqrt(var + EPS)

    # Normalize and apply affine
    for d0 in range(0, D, BLOCK_D):
        d_offsets = d0 + tl.arange(0, BLOCK_D)
        mask = d_offsets < D
        x = tl.load(X + base + d_offsets, mask=mask, other=0.0).to(tl.float32)
        diff = x - mean
        y = diff * inv_std
        w = tl.load(W + d_offsets, mask=mask, other=1.0).to(tl.float32)
        b_bias = tl.load(BIAS + d_offsets, mask=mask, other=0.0).to(tl.float32)
        y = y * w + b_bias
        tl.store(Y + base + d_offsets, y, mask=mask)


def triton_layernorm_3d(x: torch.Tensor, weight: torch.Tensor, bias: torch.Tensor, eps: float):
    """
    x: [B, L, D], float16/float32; we upcast to float32 for compute and write float32 output.
    weight: [D], float32
    bias: [D], float32
    Returns y: [B, L, D] in float32
    """
    assert x.ndim == 3, "Expected x to be 3D [B, L, D]"
    B, L, D = x.shape
    x_fp32 = x.to(torch.float32)
    y = torch.empty_like(x_fp32)

    # Compute stats
    sum_buf = torch.empty(B * L, device=x.device, dtype=torch.float32)
    sumsq_buf = torch.empty(B * L, device=x.device, dtype=torch.float32)

    BLOCK_D = 256 if D >= 256 else (128 if D >= 128 else 64)
    grid = (B, L)
    layernorm_stats_3d_bL[grid](
        x_fp32, sum_buf, sumsq_buf,
        B, L, D,
        BLOCK_D=BLOCK_D,
    )

    # Apply normalization
    layernorm_apply_3d_bL[grid](
        x_fp32, y, weight, bias,
        sum_buf, sumsq_buf,
        EPS=eps,
        B=B, L=L, D=D,
        BLOCK_D=BLOCK_D,
    )
    return y


@triton.jit
def linear_matvec_3d(
    X,            # *ptr* to input [B, L, D_in]
    W,            # *ptr* to weight [D_out, D_in]
    BIAS,         # *ptr* to bias [D_out]
    Y,            # *ptr* to output [B, L, D_out]
    B, L,
    D_in, D_out,
    BLOCK_IN: tl.constexpr,  # tile over D_in
    BLOCK_OUT: tl.constexpr, # output vector tile
):
    # Each program handles one (b, l) and writes a tile of the output vector
    b = tl.program_id(0)
    l = tl.program_id(1)
    base_x = (b * L + l) * D_in

    # Iterate over output dimension in tiles
    for o0 in range(0, D_out, BLOCK_OUT):
        o_offsets = o0 + tl.arange(0, BLOCK_OUT)
        mask_o = o_offsets < D_out
        # Accumulator for this (b,l) over all D_in
        acc = tl.zeros((BLOCK_OUT,), dtype=tl.float32)

        # Loop over input dimension in tiles
        for d0 in range(0, D_in, BLOCK_IN):
            d_offsets = d0 + tl.arange(0, BLOCK_IN)
            mask_d = d_offsets < D_in
            # Load x[b,l,d_offsets]
            x = tl.load(X + base_x + d_offsets, mask=mask_d, other=0.0).to(tl.float32)  # [BLOCK_IN]
            # Load W[o_offsets, d_offsets], shape [BLOCK_OUT, BLOCK_IN]
            # Pointer arithmetic: W is [D_out, D_in], so offset = o * D_in + d
            w_ptrs = W + o_offsets[:, None] * D_in + d_offsets[None, :]
            w = tl.load(w_ptrs, mask=(mask_o[:, None] & mask_d[None, :]), other=0.0).to(tl.float32)  # [BLOCK_OUT, BLOCK_IN]
            # Accumulate: acc[o] += sum_k w[o,k] * x[k]
            acc += tl.sum(w * x[None, :], axis=1)  # sum over input tile

        # Add bias
        bias_vec = tl.load(BIAS + o_offsets, mask=mask_o, other=0.0).to(tl.float32)
        acc = acc + bias_vec

        # Store result
        base_y = (b * L + l) * D_out + o0
        tl.store(Y + base_y + tl.arange(0, BLOCK_OUT), acc, mask=mask_o)


def triton_linear_matvec(x: torch.Tensor, weight: torch.Tensor, bias: torch.Tensor):
    """
    x: [B, L, D_in], float16/float32; we upcast to float32 for compute
    weight: [D_out, D_in], float32
    bias: [D_out], float32
    Returns y: [B, L, D_out] in float32
    """
    assert x.ndim == 3, "x must be [B, L, D_in]"
    B, L, D_in = x.shape
    D_out, D_in_w = weight.shape
    assert D_in_w == D_in, "Weight's second dim must match x's last dim"
    x_fp32 = x.to(torch.float32)
    y = torch.empty((B, L, D_out), device=x.device, dtype=torch.float32)

    # Choose tile sizes
    BLOCK_IN = 128 if D_in >= 128 else (64 if D_in >= 64 else 32)
    BLOCK_OUT = 128 if D_out >= 128 else (64 if D_out >= 64 else 32)
    grid = (B, L)
    linear_matvec_3d[grid](
        x_fp32, weight, bias, y,
        B, L,
        D_in, D_out,
        BLOCK_IN=BLOCK_IN,
        BLOCK_OUT=BLOCK_OUT,
    )
    return y

        for d0 in range(0, D_in, BLOCK_IN):
            d_offsets = d0 + tl.arange(0, BLOCK_IN)
            mask_d = d_offsets < D_in
            # Load x[b,l,d_offsets]
            x = tl.load(X + base_x + d_offsets, mask=mask_d, other=0.0).to(tl.float32)  # [BLOCK_IN]
            # Load W[o_offsets, d_offsets], shape [BLOCK_OUT, BLOCK_IN]
            # W is [D_out, D_in], so offset = o * D_in + d
            w_ptrs = W + o_offsets[:, None] * D_in + d_offsets[None, :]
            w = tl.load(w_ptrs, mask=(mask_o[:, None] & mask_d[None, :]), other=0.0).to(tl.float32)  # [BLOCK_OUT, BLOCK_IN]
            # Accumulate: acc[o] += sum_k w[o,k] * x[k]
            acc += tl.sum(w * x[None, :], axis=1)  # sum over input tile

        # Add bias
        bias_vec = tl.load(BIAS + o_offsets, mask=mask_o, other=0.0).to(tl.float32)
        acc = acc + bias_vec

        # Store result
        base_y = (b * L + l) * D_out + o0
        tl.store(Y + base_y + tl.arange(0, BLOCK_OUT), acc, mask=mask_o)


def triton_linear_matvec(x: torch.Tensor, weight: torch.Tensor, bias: torch.Tensor):
    """
    x: [B, L, D_in], float16/float32; upcast to float32 for compute

    bias: [D_out], float32
    Returns y: [B, L, D_out] in float32
    """
    assert x.ndim == 3, "x must be [B, L, D_in]"
    B, L, D_in = x.shape
    D_out, D_in_w = weight.shape
    assert D_in_w == D_in, "Weight's second dim must match x's last dim"
    x_fp32 = x.to(torch.float32)
    y = torch.empty((B, L, D_out), device=x.device, dtype=torch.float32)

    # Choose tile sizes
    BLOCK_IN = 128 if D_in >= 128 else (64 if D_in >= 64 else 32)
    BLOCK_OUT = 128 if D_out >= 128 else (64 if D_out >= 64 else 32)
    grid = (B, L)
    linear_matvec_3d[grid](
        x_fp32, weight, bias, y,
        B, L,
        D_in, D_out,
        BLOCK_IN=BLOCK_IN,
        BLOCK_OUT=BLOCK_OUT,
    )
    return y
