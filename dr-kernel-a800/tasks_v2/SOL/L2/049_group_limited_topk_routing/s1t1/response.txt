  2) Apply sigmoid to logits to get scores.

  B) A sigmoid kernel: one Triton program per token row, apply sigmoid elementwise to the 256-element vector and write back.
  C) A bias add kernel: one Triton program per token row, add expert_bias vector to each element.
  D) A per-row top-k selection kernel (without group masking): find the top-8 positions in the 256-vector via iterative argmax (8 iterations), writing indices and values.   E) A group-reduction kernel: one program per token row, compute top-2 per group by iterating over 8 groups and 32 experts per group. For each group, find the two maxima via small loop and sum. Then select top-4 groups via another small iterative argmax across 8 groups. This produces group_idx (top-4 group IDs) per token row.
  F) A mask construction kernel: one program per token row, build a [8]-length mask vector (float32) with ones at the 4 selected group positions, zeros elsewhere.
  G) A mask-expand kernel: one program per token row, expand the [8]-length group mask to [256] using group_idx: for each group g, set 32 contiguous slots to 1.0; else 0.0. Then convert to a boolean or write float and use in masked_fill.

These kernels will fully replace all PyTorch operations in the host code. Note: Triton does not provide built-in topk or easy dynamic indexing for returning multiple values, so I will implement iterative argmax loops, which are acceptable given the small fixed top_k and group sizes.

Implementation notes
- Triton matmul kernel: each program handles one token row, accumulates across hidden_dim in BLOCK_K chunks, writes [num_experts] results. Use BLOCK_K=64 and num_warps=4 or 8, which works for typical hidden sizes; loops handle arbitrary hidden_dim.
- Triton sigmoid/bias kernels: simple elementwise vector loads and stores. One program per row, load 256-element vector, compute tl.sigmoid(x) and add bias vector.
- Triton topk kernel: one program per row. Initialize out_idx and out_vals as tensors of size 8. In each iteration k, compute global argmax among remaining 256 elements (scan with a for loop and track current max and index). Store the argmax index to out_idx[k] and value to out_vals[k], then set input vector at that index to NEG_INF for next iteration.
- Group reduction kernel: one program per row. Loop over groups g=0..7, compute group_scores[g] = top2_sum for group (g*32 : g*32+31), using iterative argmax twice to find top-2. Then perform iterative argmax across 8 group_scores to get top-4 group_idx. Output: int32 group_idx [4]. I’ll implement as 8-length int32 vector and use only first 4.
- Mask construction: one program per row, output int32 group_mask [8], set ones at positions group_idx.
- Mask expand: one program per row, load group_mask and group_idx, write score_mask [256] as described.
- Masked_fill: one program per row, compare masked_scores with score_mask (converted to 0/1). If score_mask == 0, write NEG_INF, else write original value.

These kernels will be invoked from ModelNew.forward, which will allocate inputs/outputs, make tensors contiguous, and launch the appropriate kernel for each step, avoiding any torch operations.

import torch.nn as nn

try:

    import triton.language as tl
    TRITON_AVAILABLE = True

@triton.jit
def _matmul_rowwise_kernel(
    hidden_ptr,         # *f32, [num_tokens, hidden_dim]
    weight_ptr,         # *f32, [num_experts, hidden_dim]
    logits_ptr,         # *f32, [num_tokens, num_experts]
    num_tokens: tl.constexpr,
    num_experts: tl.constexpr,
    hidden_dim: tl.constexpr,
    BLOCK_K: tl.constexpr,
):
    # Each program handles one token row
    token_id = tl.program_id(0)
    base_hidden = token_id * hidden_dim

    # Accumulator for the 256 expert scores
    acc = tl.zeros((num_experts,), dtype=tl.float32)

    # Loop over hidden_dim in chunks
    for k in range(0, hidden_dim, BLOCK_K):
        offs_k = k + tl.arange(0, BLOCK_K)
        mask_k = offs_k < hidden_dim
        hidden_vec = tl.load(hidden_ptr + base_hidden + offs_k, mask=mask_k, other=0.0)

        # For each expert, dot product with hidden_vec
        for e in range(0, num_experts):
            base_weight = e * hidden_dim
            w_vec = tl.load(weight_ptr + base_weight + offs_k, mask=mask_k, other=0.0)
            acc[e] += tl.sum(hidden_vec * w_vec, axis=0)

    # Store the logits for this token row
    base_logits = token_id * num_experts
    tl.store(logits_ptr + base_logits + tl.arange(0, num_experts), acc)


@triton.jit
def _sigmoid_row_kernel(
    input_ptr,          # *f32, [num_tokens, num_experts]
    output_ptr,         # *f32, [num_tokens, num_experts]
    num_tokens: tl.constexpr,
    num_experts: tl.constexpr,
):
    token_id = tl.program_id(0)
    base = token_id * num_experts
    vec = tl.load(input_ptr + base + tl.arange(0, num_experts))
    # sigmoid(x) = 1 / (1 + exp(-x))
    y = 1.0 / (1.0 + tl.exp(-vec))
    tl.store(output_ptr + base + tl.arange(0, num_experts), y)


@triton.jit
def _bias_add_row_kernel(
    scores_ptr,         # *f32, [num_tokens, num_experts]
    bias_ptr,           # *f32, [num_experts]
    output_ptr,         # *f32, [num_tokens, num_experts]
    num_tokens: tl.constexpr,
    num_experts: tl.constexpr,
):
    token_id = tl.program_id(0)
    base = token_id * num_experts
    scores_vec = tl.load(scores_ptr + base + tl.arange(0, num_experts))
    bias_vec = tl.load(bias_ptr + tl.arange(0, num_experts))
    y = scores_vec + bias_vec
    tl.store(output_ptr + base + tl.arange(0, num_experts), y)


@triton.jit
def _topk_select_kernel(
    input_ptr,          # *f32, [num_experts]
    out_idx_ptr,        # *i32, [top_k]
    out_vals_ptr,       # *f32, [top_k]
    num_experts: tl.constexpr,
    top_k: tl.constexpr,
    NEG_INF: tl.constexpr,  # e.g., -1e20
):
    # One program handles one token; perform iterative argmax to get top-k
    # We assume input_ptr holds the vector for this token. In caller, we pass the relevant vector.
    # Initialize outputs
    for k in range(0, top_k):
        max_val = NEG_INF
        max_idx = 0
        # Scan all elements to find max
        for e in range(0, num_experts):
            x = tl.load(input_ptr + e)
            if x > max_val:
                max_val = x
                max_idx = e
        # Write result
        tl.store(out_idx_ptr + k, max_idx)
        tl.store(out_vals_ptr + k, max_val)
        # Remove the selected element by setting to NEG_INF
        tl.store(input_ptr + max_idx, NEG_INF)


@triton.jit

        group_start = g * experts_per_group
        # Find top-2 in this group (indices 0..experts_per_group-1)

        idx1 = 0
        m2 = -1e20
        idx2 = 0

            val = tl.load(scores_ptr + base + e)

                idx2 = idx1
                m1 = val
                idx1 = e
            elif val > m2:
                m2 = val
                idx2 = e

        max_idx = 0

                max_idx = g

        tl.store(out_groups_ptr + k, max_idx)
        # Remove this group from consideration by setting its score to -inf
        group_scores[max_idx] = -1e20


@triton.jit
def _build_group_mask_kernel(
    group_idx_ptr,      # *i32, [4] per token
    out_mask_ptr,       # *i32, [8] per token
    n_group: tl.constexpr,

    # Assume group_idx_ptr points to the token's 4 indices. For simplicity, we assume contiguous groups.

    # write group_idx to out_mask directly. This kernel assumes out_mask is initialized to zeros.
    for k in range(0, 4):

        tl.store(out_mask_ptr + idx, 1)   # 1 means selected


@triton.jit
def _mask_expand_kernel(
    group_mask_ptr,     # *i32, [8]
    group_idx_ptr,      # *i32, [4]
    score_mask_ptr,     # *i32, [num_experts]

    n_group: tl.constexpr,
    experts_per_group: tl.constexpr,

    # Initialize score_mask to zeros
    for e in range(0, num_experts):
        tl.store(score_mask_ptr + e, 0)
    # Set ones for selected groups: slots [g*experts_per_group : (g+1)*experts_per_group]
    for k in range(0, 4):
        g = tl.load(group_idx_ptr + k)  # i32 group index
        start = g * experts_per_group
        for i in range(0, experts_per_group):
            e = start + i
            tl.store(score_mask_ptr + e, 1)


@triton.jit
def _masked_fill_kernel(
    scores_ptr,         # *f32, [num_experts]
    score_mask_ptr,     # *i32, [num_experts] (0/1)
    output_ptr,         # *f32, [num_experts]
    num_experts: tl.constexpr,
    NEG_INF: tl.constexpr,  # e.g., -1e20
):
    token_id = tl.program_id(0)
    base = token_id * num_experts
    for e in range(0, num_experts):
        val = tl.load(scores_ptr + base + e)
        mask = tl.load(score_mask_ptr + base + e)
        # mask is 0 or 1; if 0, set to NEG_INF
        new_val = tl.where(mask == 1, val, NEG_INF)
        tl.store(output_ptr + base + e, new_val)

        mask_k = offs_k < hidden_dim
        hidden_vec = tl.load(hidden_ptr + base_hidden + offs_k, mask=mask_k, other=0.0)

        for e in range(0, num_experts):
            base_weight = e * hidden_dim
            w_vec = tl.load(weight_ptr + base_weight + offs_k, mask=mask_k, other=0.0)
            acc[e] += tl.sum(hidden_vec * w_vec, axis=0)

    base_logits = token_id * num_experts
    tl.store(logits_ptr + base_logits + tl.arange(0, num_experts), acc)


# Kernel 2: Elementwise sigmoid on a [num_experts] row
@triton.jit
def _sigmoid_row_kernel(
    input_ptr,          # *f32, [num_tokens, num_experts]
    output_ptr,         # *f32, [num_tokens, num_experts]
    num_tokens: tl.constexpr,
    num_experts: tl.constexpr,
):
    token_id = tl.program_id(0)
    base = token_id * num_experts
    vec = tl.load(input_ptr + base + tl.arange(0, num_experts))
    y = 1.0 / (1.0 + tl.exp(-vec))
    tl.store(output_ptr + base + tl.arange(0, num_experts), y)


# Kernel 3: Add expert bias elementwise
@triton.jit
def _bias_add_row_kernel(
    scores_ptr,         # *f32, [num_tokens, num_experts]
    bias_ptr,           # *f32, [num_experts]
    output_ptr,         # *f32, [num_tokens, num_experts]
    num_tokens: tl.constexpr,
    num_experts: tl.constexpr,
):
    token_id = tl.program_id(0)

    scores_vec = tl.load(scores_ptr + base + tl.arange(0, num_experts))

    tl.store(output_ptr + base + tl.arange(0, num_experts), y)


# Kernel 4: Per-row top-2 per group (8 groups, 32 experts per group)
# input: scores_for_routing [num_tokens, 256], output: group_scores [num_tokens, 8]
@triton.jit
def _group_top2_sum_kernel(
    scores_ptr,         # *f32, [num_tokens, num_experts]
    out_ptr,            # *f32, [num_tokens, n_group]
    num_tokens: tl.constexpr,
    num_experts: tl.constexpr,
    n_group: tl.constexpr,
    experts_per_group: tl.constexpr,
):
    token_id = tl.program_id(0)
    base = token_id * num_experts
    group_scores = tl.zeros((n_group,), dtype=tl.float32)

    for g in range(0, n_group):
        group_start = g * experts_per_group
        m1 = -1.0e20
        m2 = -1.0e20
        for i in range(0, experts_per_group):
            e = group_start + i
            val = tl.load(scores_ptr + base + e)
            if val > m1:
                m2 = m1
                m1 = val
            elif val > m2:
                m2 = val
        group_scores[g] = m1 + m2

    base_out = token_id * n_group
    tl.store(out_ptr + base_out + tl.arange(0, n_group), group_scores)


# Kernel 5: Select top-4 groups from group_scores [num_tokens, 8]
@triton.jit
def _top4_groups_kernel(
    group_scores_ptr,   # *f32, [num_tokens, n_group]
    out_groups_ptr,     # *i32, [num_tokens, 4]
    num_tokens: tl.constexpr,
    n_group: tl.constexpr,
):
    token_id = tl.program_id(0)
    base_gs = token_id * n_group
    gs = tl.load(group_scores_ptr + base_gs + tl.arange(0, n_group))

    top4 = tl.full((4,), -1.0e20, dtype=tl.float32)
    for k in range(0, 4):
        max_val = -1.0e20
        max_idx = 0
        for g in range(0, n_group):
            val = gs[g]
            if val > max_val:
                max_val = val
                max_idx = g
        tl.store(out_groups_ptr + token_id * 4 + k, max_idx)
        gs[max_idx] = -1.0e20


# Kernel 6: Build group mask [8] for each token (ones at selected 4 groups, zeros elsewhere)
@triton.jit
def _build_group_mask_kernel(
    group_idx_ptr,      # *i32, [num_tokens, 4]
    out_mask_ptr,       # *i32, [num_tokens, n_group]
    num_tokens: tl.constexpr,
    n_group: tl.constexpr,
):
    token_id = tl.program_id(0)
    base_out = token_id * n_group
    # initialize to zeros
    for g in range(0, n_group):
        tl.store(out_mask_ptr + base_out + g, 0)
    # set ones at selected groups
    for k in range(0, 4):
        g = tl.load(group_idx_ptr + token_id * 4 + k)  # i32
        tl.store(out_mask_ptr + base_out + g, 1)


# Kernel 7: Expand group mask to expert-level score_mask [num_experts]
@triton.jit
def _mask_expand_kernel(
    group_mask_ptr,     # *i32, [num_tokens, n_group]
    group_idx_ptr,      # *i32, [num_tokens, 4]
    score_mask_ptr,     # *i32, [num_tokens, num_experts]
    num_tokens: tl.constexpr,
    num_experts: tl.constexpr,
    n_group: tl.constexpr,
    experts_per_group: tl.constexpr,
):
    token_id = tl.program_id(0)
    base_out = token_id * num_experts
    # Initialize score_mask to zeros
    for e in range(0, num_experts):
        tl.store(score_mask_ptr + base_out + e, 0)
    # Set ones for selected groups
    for k in range(0, 4):
        g = tl.load(group_idx_ptr + token_id * 4 + k)  # i32
        start = g * experts_per_group
        for i in range(0, experts_per_group):
            e = start + i
            tl.store(score_mask_ptr + base_out + e, 1)

        val = tl.load(scores_ptr + base + e)
