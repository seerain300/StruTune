Triton kernel design details
- Kernel signature: rfftnorm_kernel(x_ptr, real_ptr, imag_ptr, N_total, norm, BLOCK: tl.constexpr)
  - x_ptr: pointer to complex64 tensor (output of rfft). Even though torch stores complex64 internally as two float32s, you cannot treat it as a Triton tensor directly. Therefore, we compute rfft using torch and then use a separate Triton kernel to extract real/imag via view. In PyTorch, x_freq.real and x_freq.imag return float32 tensors; we can pass those to Triton.
  - real_ptr and imag_ptr: pointers to output float32 tensors, shape (batch, channel, seqlen+1) flattened.
  - N_total: total number of elements (batch*channels*(seqlen+1)).
  - norm: scalar float32 normalization factor = 2*seqlen.
  - BLOCK: constexpr tile size, e.g., 1024; we iterate with a for-loop in Triton over tiles.
- Grid: (triton.cdiv(N_total, BLOCK),)
- Within each program:
  - Compute offsets = pid * BLOCK + arange(0, BLOCK)
  - mask = offsets < N_total
  - Load v_real = tl.load(real_ptr + offsets, mask=mask, other=0.0)
  - Load v_imag = tl.load(imag_ptr + offsets, mask=mask, other=0.0)
  - v_real = v_real / norm; v_imag = v_imag / norm
  - Store v_real and v_imag to their respective outputs (they are the same as the inputs here, since we are not modifying the original complex tensor; but we can write to newly allocated tensors if needed).
- In our case, we will allocate real_out and imag_out as zeros (or empty) and store directly into them. To ensure we don’t modify the original complex tensor, we’ll first do x_freq.real and x_freq.imag, then launch the kernel to produce real_out and imag_out.

import triton
import triton.language as tl

# Triton kernel: elementwise normalization of real and imaginary parts
# It reads from input_real and input_imag (which are already x_freq.real/imag),
# divides by 'norm', and writes to output_real and output_imag (new tensors).
@triton.jit
def rfft_divide_kernel(input_real_ptr, input_imag_ptr, output_real_ptr, output_imag_ptr,
                        N_total, norm, BLOCK: tl.constexpr):
    pid = tl.program_id(axis=0)
    offsets = pid * BLOCK + tl.arange(0, BLOCK)
    mask = offsets < N_total

    # Load real and imag parts
    v_real = tl.load(input_real_ptr + offsets, mask=mask, other=0.0)
    v_imag = tl.load(input_imag_ptr + offsets, mask=mask, other=0.0)

    # Divide by normalization factor (2*seqlen)
    # norm is a scalar; Triton will broadcast it across the vector.
    v_real = v_real / norm
    v_imag = v_imag / norm

    # Store results
    tl.store(output_real_ptr + offsets, v_real, mask=mask)
    tl.store(output_imag_ptr + offsets, v_imag, mask=mask)

import triton
import triton.language as tl


@triton.jit
def rfft_divide_kernel(input_real_ptr, input_imag_ptr,
                       output_real_ptr, output_imag_ptr,
                       N_total, norm, BLOCK: tl.constexpr):
    """
    Elementwise normalize real and imaginary parts by 'norm'.
    Reads from input_real_ptr/input_imag_ptr (flattened),
    writes to output_real_ptr/output_imag_ptr (flattened).

    pid = tl.program_id(axis=0)
