Understanding and plan

- What the original code does
  - It defines a model that runs a sequence of steps on hidden representations of patches:
    1) Layer normalization (LN) on the patch hidden dimension (1536) with learnable weight and bias, in fp32 then back to bf16.
    2) Spatial shuffle to merge 2x2 patches into one dimension: for each grid, it reshapes and permutes to combine two spatial positions per original patch.
    3) Two-layer MLP: first fully connected (in fp32) with GELU activation, then a second fully connected. All weights are bf16; the code does the matmuls via torch.nn.functional.linear (which is a GEMM under the hood).
  - The grid_thw tensor dictates how many patches are associated with each grid (num_patches / num_grids). Each grid’s T, H, W must be divisible by merge_size=2. The shuffle always combines merge_size=2 along spatial dims, producing hidden_size_expanded=6144 (2*2*1536) and final out_hidden_size=3584.
  - The host code does all computation (LN, permute/reshape, matmuls, GELU) using PyTorch ops.

- Where we can optimize with Triton
  - PyTorch’s matmul/linear are already highly optimized (cuBLAS/cuBLASLt), so replacing them might not be faster or even valid if we must keep math identical. GEMMs are generally best left to cuBLAS unless we have a very specific structure that Triton can exploit efficiently. Doing GEMMs in Triton requires careful tiling, scheduling, and often FP32 accumulation for precision. Given the complexity and the risk of numerical mismatch, I will not replace torch.nn.functional.linear with a custom Triton GEMM here.
  - The clear target for a Triton kernel is Layer Normalization. The LN step is a per-row reduction (mean and variance across hidden_size=1536, then elementwise normalization) and a pointwise affine. That’s perfect for a Triton kernel that:
    - Launches one program per patch (i.e., per row).
    - Loads the 1536 elements in a vectorized way, computes mean/var in FP32, applies normalization and scale/bias, and writes back in BF16. This avoids PyTorch’s tensor ops on the LN step and shows Triton involvement while preserving exact math semantics.
  - Keep the permute/reshape logic in PyTorch (it’s just shape transformations, no arithmetic). We can do:
    - hidden_norm = Triton-LN(hidden)  (bf16 in)
    - view/permute/reshape to get hidden_shuffled for fc1
  - Keep the two-layer MLP in PyTorch. As before, compute fc1 (bf16 input, bf16 weights/biases, FP32 GEMM), GELU, fc2 (bf16 input, bf16 weights/biases, FP32 GEMM), and return output. This ensures correctness and stability while still using Triton where it’s straightforward and maintainable.

- Why this approach
  - It satisfies the requirement: ModelNew.forward must invoke Triton kernels. We provide a Triton kernel for LN, which is the main reduction/elementwise transformation that can be cleanly expressed in Triton. We avoid risky custom GEMM in Triton, which could jeopardize correctness and performance for these sizes.
  - It’s maintainable: The Triton kernel is simple, robust, and numerically stable (FP32 accumulations for mean/var, then write back BF16). We keep the rest of the code identical to the original for correctness.

- Kernel design for Layer Normalization
  - Inputs: pointer to hidden (bf16), pointer to output (bf16), N (number of rows/patches), C (hidden size 1536), ln_weight (bf16 vector of length C), ln_bias (bf16 vector of length C), eps (float32).
  - Launch: grid = (N,), BLOCK = 1024 (works for C=1536 in 2 iterations).
  - Inside kernel:
    - Compute base offsets for the row.
    - First loop: sum across C in blocks to compute mean.
    - Second loop: compute sum of squares to compute variance.
    - mean = sum / C; var = sumsq / C - mean^2; inv_std = 1 / sqrt(var + eps).
    - Third loop: load x, compute y = ((x - mean) * inv_std), y = y * ln_weight + ln_bias, store to output.
  - This is the standard per-row LN implemented in Triton. It’s memory-bound but fast, and exact math can be preserved by keeping mean/var in FP32 and using FP32 arithmetic.

- Handling device and dtype
  - The Triton kernel runs on CUDA. In ModelNew.forward, if inputs are not on CUDA, we can fall back to PyTorch LN. In the benchmarking scenarios, inputs are generated on a CUDA device, so Triton will be used.
  - We keep LN in bf16 input/output, but do math in FP32 inside the kernel to ensure numerical stability.

- Result
  - ModelNew.forward:
    - Receives the same inputs as the original run function.
    - Calls Triton LN kernel to produce hidden_norm.
    - Proceeds with permute/reshape to form hidden_shuffled, then fc1, GELU, fc2, and returns output.
  - Triton kernel: layer_norm_kernel as described above.

Code (ModelNew with Triton LN, rest in PyTorch)

```python
import math
import torch
import triton
import triton.language as tl


@triton.jit
def layer_norm_kernel(
    hidden_ptr,        # *bf16, [N, C]
    out_ptr,           # *bf16, [N, C]
    ln_weight_ptr,     # *bf16, [C]
    ln_bias_ptr,       # *bf16, [C]
    N,                 # int32
    C,                 # int32 (hidden size, e.g., 1536)
    eps,               # float32
    BLOCK_SIZE: tl.constexpr,
):
    """
    Per-row layer normalization:
    For each row i in [0, N):
      mean = sum(x_i) / C
      var  = sum(x_i^2) / C - mean^2
      inv_std = 1 / sqrt(var + eps)
      out_i = ((x_i - mean) * inv_std) * ln_weight + ln_bias
    All math in fp32, output cast back to bf16.
    """
    row = tl.program_id(0)
    if row >= N:
        return

    # We'll process the row in BLOCK_SIZE chunks. For C=1536, 2 iterations with BLOCK_SIZE=1024.
    # Compute sums in fp32
    sum_x = 0.0
    sum_x2 = 0.0

    col = 0
    while col < C:
        offs = col + tl.arange(0, BLOCK_SIZE)
        mask = offs < C
        x = tl.load(hidden_ptr + row * C + offs, mask=mask, other=0.0)
        x = x.to(tl.float32)
        sum_x += tl.sum(x, axis=0)
        sum_x2 += tl.sum(x * x, axis=0)
        col += BLOCK_SIZE

    mean = sum_x / C
    var = sum_x2 / C - mean * mean
    inv_std = 1.0 / tl.sqrt(var + eps)

    # Second pass: normalize and apply affine
    col = 0
    while col < C:
        offs = col + tl.arange(0, BLOCK_SIZE)
        mask = offs < C
        x = tl.load(hidden_ptr + row * C + offs, mask=mask, other=0.0).to(tl.float32)
        w = tl.load(ln_weight_ptr + offs, mask=mask, other=1.0).to(tl.float32)
        b = tl.load(ln_bias_ptr + offs, mask=mask, other=0.0).to(tl.float32)
        y = (x - mean) * inv_std
        y = y * w + b
        # Store as bf16
        tl.store(out_ptr + row * C + offs, y.to(tl.bfloat16), mask=mask)
        col += BLOCK_SIZE


class ModelNew(torch.nn.Module):
    def forward(self, hidden: torch.Tensor, grid_thw: torch.Tensor,
                ln_weight: torch.Tensor, ln_bias: torch.Tensor,
                fc1_weight: torch.Tensor, fc1_bias: torch.Tensor,
                fc2_weight: torch.Tensor, fc2_bias: torch.Tensor,
                eps: float):
        """
        Triton-optimized version:
        - Layer normalization with Triton (fp32 math, bf16 I/O).
        - Spatial shuffle, fc1 (fp32 GEMM), GELU, fc2 (fp32 GEMM) using PyTorch.
        """
        # Ensure we are on CUDA and Triton is usable. If not, fallback to PyTorch LN.
        use_triton = hidden.is_cuda and ln_weight.is_cuda and ln_bias.is_cuda
        hidden_fp32 = hidden
        out_hidden_fp32 = None

        if use_triton:
            N = hidden.shape[0]
            C = hidden.shape[1]
            # Output buffer for LN in bf16
            out_hidden = torch.empty_like(hidden, dtype=torch.bfloat16, device=hidden.device)
            # Launch Triton kernel: one program per row
            grid = (N,)
            layer_norm_kernel[grid](
                hidden, out_hidden, ln_weight, ln_bias,
                N, C, eps,
                BLOCK_SIZE=1024,
                num_warps=4,
            )
            hidden_fp32 = out_hidden
        else:
            # Fallback: PyTorch LN (fp32 math), but original code did LN in fp32 and back to bf16.
            # We mimic: normalize and affine in fp32, then cast back.
            x = hidden
            # To fp32 for math
            x32 = x.to(torch.float32)
            mean = x32.mean(dim=-1, keepdim=True)
            var = x32.var(dim=-1, keepdim=True, unbiased=False)
            x_norm = (x32 - mean) / torch.sqrt(var + eps)
            # Apply affine
            ln_weight32 = ln_weight.to(torch.float32)
            ln_bias32 = ln_bias.to(torch.float32)
            hidden_fp32 = x_norm * ln_weight32 + ln_bias32
            hidden_fp32 = hidden_fp32.to(torch.bfloat16)

        # Step 2: Spatial shuffle to merge patches (pure shape transforms)
        # We reproduce the original logic: for each grid in grid_thw, do reshape/permute to
        # combine 2x2 spatial positions into a single vector of length hidden_size_expanded=6144.
        # Then concatenate all grids into hidden_shuffled.
        offset = 0
        shuffled_patches = []
        for i in range(grid_thw.shape[0]):
            t = grid_thw[i, 0].item()
            h = grid_thw[i, 1].item()
            w = grid_thw[i, 2].item()
            num_patches_this = t * h * w
            patches = hidden_fp32[offset:offset + num_patches_this]
            h_merged = h // 2
            w_merged = w // 2
            patches = patches.view(t, h_merged, 2, w_merged, 2, C)
            patches = patches.permute(0, 1, 3, 2, 4, 5)  # to (T, H/2, W/2, 2, 2, C)
            patches = patches.reshape(t * h_merged * w_merged, 4 * C)  # 4*C = 2*2*1*C per original assumption -> hidden_size_expanded
            shuffled_patches.append(patches)
            offset += num_patches_this
        hidden_shuffled = torch.cat(shuffled_patches, dim=0)  # [num_merged_patches, hidden_size_expanded]

        # Note: hidden_size_expanded is hardcoded to 6144 in the original setup, and 4*C should equal 6144.
        # The original code uses hidden_size=1536 and merge 2x2 -> 4*1536=6144. We assert this for safety.
        assert hidden_shuffled.shape[1] == fc1_weight.shape[0], "hidden_shuffled last dim must match fc1_weight in_features"

        # Step 3: Two-layer MLP (fp32 GEMMs via PyTorch, GELU)
        hidden_fc1 = torch.nn.functional.linear(hidden_shuffled, fc1_weight, fc1_bias)  # [num_merged_patches, hidden_size_expanded]
        hidden_gelu = torch.nn.functional.gelu(hidden_fc1)  # default is exact GELU
        output = torch.nn.functional.linear(hidden_gelu, fc2_weight, fc2_bias)  # [num_merged_patches, out_hidden_size]

        return output
```

    C,                 # int32 (hidden size, e.g., 1536)
    eps,               # float32

    For each row i in [0, N):

import torch
import triton
import triton.language as tl


@triton.jit
def layer_norm_kernel(
    hidden_ptr,        # *bf16, [N, C]
    out_ptr,           # *bf16, [N, C]
    ln_weight_ptr,     # *bf16, [C]
    ln_bias_ptr,       # *bf16, [C]
    N,                 # int32
    C,                 # int32 (hidden size, e.g., 1536)
    eps,               # float32
    BLOCK_SIZE: tl.constexpr,
):
    """
    Per-row Layer Normalization:
    For each row i in [0, N):
      mean = sum(x_i) / C
      var  = sum(x_i^2) / C - mean^2
      inv_std = 1 / sqrt(var + eps)
      out_i = ((x_i - mean) * inv_std) * ln_weight + ln_bias
    All math in fp32, output cast back to bf16.
    """
    row = tl.program_id(0)
    if row >= N:
        return

    sum_x = 0.0
    sum_x2 = 0.0

    col = 0
    while col < C:
        offs = col + tl.arange(0, BLOCK_SIZE)
        mask = offs < C
        x = tl.load(hidden_ptr + row * C + offs, mask=mask, other=0.0)
        x32 = x.to(tl.float32)
        sum_x += tl.sum(x32, axis=0)
        sum_x2 += tl.sum(x32 * x32, axis=0)
        col += BLOCK_SIZE

    mean = sum_x / C
    var = sum_x2 / C - mean * mean
    inv_std = 1.0 / tl.sqrt(var + eps)

    col = 0
    while col < C:
        offs = col + tl.arange(0, BLOCK_SIZE)
        mask = offs < C
        x = tl.load(hidden_ptr + row * C + offs, mask=mask, other=0.0).to(tl.float32)
        w = tl.load(ln_weight_ptr + offs, mask=mask, other=1.0).to(tl.float32)
        b = tl.load(ln_bias_ptr + offs, mask=mask, other=0.0).to(tl.float32)
        y = (x - mean) * inv_std
        y = y * w + b
        tl.store(out_ptr + row * C + offs, y.to(tl.bfloat16), mask=mask)
        col += BLOCK_SIZE
