  - Build rotation embedding:

2) Where Triton can help:
- Elementwise operations (rotation, RMSNorm), and index-based updates are well-suited for Triton. Even the cache update can be done with Triton.

  - Rotation: elementwise per token, per head, using cos/sin arrays. We can implement a Triton kernel that applies rotation and returns rotated tensors (so we can return query_rotated and key_rotated).
  - Cache updates: per token per kv head, write rotated key and original value into cache at positions cache_position[t].

3) Important notes:
- We must produce identical outputs to the original:

  - cos/sin will be computed in Triton and produced as float32 (we can cast to bfloat16 later only for rotation kernels if needed). RMSNorm needs float32 to compute mean and rsqrt.

4) Strategy:
- RMSNorm in Triton:
  - Kernel 1: For each (b, h, s), compute sum of squares across head_dim. Since head_dim=128, we can handle it in a single tile. We’ll pass H as a constexpr and loop i from 0 to H-1. Load q[b, h, s, i] as float32, accumulate sum += x*x. This is a Triton reduction per token.
  - Kernel 2: For each (b, h, s), compute inv_rms = rsqrt((sum/H) + eps) (eps passed), apply q_norm_weight (per dim) to normalized x and store as output.
  - We’ll do this for query (q_norm) and for key (k_norm).
- Rotation:

  - Then, Triton rotation kernels:

- Cache updates:

5) Addressing the “cat([freqs, freqs])” issue:
- In the original, emb = cat([freqs, freq_vec], dim=-1) where each “freqs” is position_ids expanded and multiplied by inv_freq; and “freq_vec” is the same multiplied by inv_freq. This yields an emb of size 128 where first 64 entries are inv_freq scaled by pos, second 64 duplicated. We’ll mirror this exactly in Triton by constructing inv_freq_128 = torch.cat([inv_freq, inv_freq], dim=0) in Python (since Triton doesn’t do torch.cat), then in the Triton kernel compute emb = pos * inv_freq_128, cos/sin per token. This is the only torch tensor creation we keep (and it’s necessary to produce cos/sin). No torch elementwise ops in host code (no .mean, .rsqrt, sin, cos, cat), only tensor creation for cache.

6) Grids and launches:
- RMSNorm kernels: grid = (B*num_q_heads*S,) for query, and (B*num_kv_heads*S,) for key.
- Rotation kernels: same grid. These kernels iterate over head_dim=128.
- Cache update kernel: grid = (B*S, num_kv_heads).

7) Final return:
- Return query_rotated, key_rotated, key_cache, value_cache, all produced by Triton kernels.

# RMSNorm reduction: compute sum of squares across head_dim for each (b, h, s)
@triton.jit
def rms_sum_kernel(query_norm_ptr, sum_ptr,
                    B: tl.constexpr, num_q_heads: tl.constexpr, S: tl.constexpr,
                    H: tl.constexpr,  # head_dim, assumed 128 in this task
                    batch_stride, qh_stride, s_stride, d_stride,
                    num_warps=4):
    pid = tl.program_id(0)
    # map pid -> (b, h, s)
    total_q = B * num_q_heads * S
    # Use integer division to recover indices
    b = pid // (num_q_heads * S)
    rem = pid % (num_q_heads * S)
    h = rem // S
    s = rem % S

    # Accumulate sum of squares across H
    total = tl.zeros((), dtype=tl.float32)
    for i in range(H):
        offs = b * batch_stride + h * qh_stride + s * s_stride + i * d_stride
        x = tl.load(query_norm_ptr + offs, eviction_policy="evict_last")
        x = x.to(tl.float32)
        total += x * x
    # store total sum for this (b,h,s)
    tl.store(sum_ptr + pid, total)


# RMSNorm normalization: apply inv_rms = 1/sqrt(mean + eps) and weight
@triton.jit
def rms_norm_kernel(query_norm_ptr, weight_ptr, out_ptr, sum_ptr,
                     B: tl.constexpr, num_q_heads: tl.constexpr, S: tl.constexpr,
                     H: tl.constexpr,
                     eps: tl.float32,
                     batch_stride, qh_stride, s_stride, d_stride,
                     out_batch_stride, out_qh_stride, out_s_stride, out_d_stride,
                     num_warps=4):
    pid = tl.program_id(0)
    total_q = B * num_q_heads * S
    b = pid // (num_q_heads * S)
    rem = pid % (num_q_heads * S)
    h = rem // S
    s = rem % S

    sum_val = tl.load(sum_ptr + pid)
    mean = sum_val / H
    inv_rms = tl.rsqrt(mean + eps)

    # write normalized and scaled to output
    for i in range(H):
        in_offs = b * batch_stride + h * qh_stride + s * s_stride + i * d_stride
        out_offs = b * out_batch_stride + h * out_qh_stride + s * out_s_stride + i * out_d_stride

        w = tl.load(weight_ptr + i, eviction_policy="evict_last").to(tl.float32)
        y = x * inv_rms * w
        tl.store(out_ptr + out_offs, y)


# Precompute cos/sin for rotation: input inv_freq_128 (float32), output cos/sin of shape [S, 128]
@triton.jit
def precompute_sin_cos_kernel(inv_freq_128_ptr, cos_ptr, sin_ptr,
                               S: tl.constexpr, H: tl.constexpr,
                               pos_ptr,  # int32 cache_position [S]
                               num_warps=4):

    t = tl.program_id(0)
    # read position
    pos = tl.load(pos_ptr + t).to(tl.float32)
    # emb = pos * inv_freq_128
    emb = pos * tl.load(inv_freq_128_ptr + tl.arange(0, H), eviction_policy="evict_last")
    c = tl.cos(emb)
    s = tl.sin(emb)
    # store cos[s, :], sin[s, :]
    # We assume cos_ptr and sin_ptr are 2D and we write row t. Triton expects pointers and uses vectorized store.
    # We can implement row-wise by adding t * H to indices for columns.
    offs = tl.arange(0, H)
    tl.store(cos_ptr + t * H + offs, c)
    tl.store(sin_ptr + t * H + offs, s)


# Apply rotation: y = x * cos + [-x64, x[:64]] * sin
@triton.jit
def rotate_kernel(x_ptr, cos_ptr, sin_ptr, y_ptr,
                   B: tl.constexpr, num_heads: tl.constexpr, S: tl.constexpr,
                   H: tl.constexpr,
                   batch_stride, h_stride, s_stride, d_stride,
                   cos_s_stride, sin_s_stride,
                   out_batch_stride, out_h_stride, out_s_stride, out_d_stride,
                   num_warps=4):
    pid = tl.program_id(0)
    total = B * num_heads * S
    b = pid // (num_heads * S)
    rem = pid % (num_heads * S)
    h = rem // S
    s = rem % S

    # cos/sin for this token s
    offs = tl.arange(0, H)
    cos_t = tl.load(cos_ptr + s * H + offs, eviction_policy="evict_last").to(tl.float32)
    sin_t = tl.load(sin_ptr + s * H + offs, eviction_policy="evict_last").to(tl.float32)

    # Load x
    x = tl.load(x_ptr + b * batch_stride + h * h_stride + s * s_stride + offs * d_stride, eviction_policy="evict_last").to(tl.float32)
    x1 = x[:H//2]  # first half
    x2 = x[H//2:]  # second half
    rotated = -x2 * sin_t + x1 * cos_t  # rotate_half: [-x2, x1], apply sin/cos
    y = x * cos_t + rotated * sin_t

    # Store y
    tl.store(y_ptr + b * out_batch_stride + h * out_h_stride + s * out_s_stride + offs * d_stride, y)


# Update caches: for each (b, s, k), write key_rotated[b,k,s,:] to key_cache[b,k,cache_position[s],:],

    pid1 = tl.program_id(1)  # over num_kv_heads
    total = B * S
    b = pid0 // S
    s = pid0 % S
    k = pid1

    dest = tl.load(dest_ptr + s).to(tl.int64)

    # Load key_rotated[b, k, s, :]
    offs = tl.arange(0, H)
    key_vals = tl.load(key_rot_ptr + b * batch_stride_kr + k * h_stride_kr + s * s_stride_kr + offs * d_stride_kr, eviction_policy="evict_last").to(tl.float32)
    # Store to key_cache[b, k, dest, :]
    tl.store(key_cache_ptr + b * batch_stride_kc + k * h_stride_kc + dest * dest_stride + offs * d_stride_kc, key_vals)

    # Load value[b, k, s, :]
    vals = tl.load(value_ptr + b * batch_stride_v + k * h_stride_v + s * s_stride_v + offs * d_stride_v, eviction_policy="evict_last").to(tl.float32)

    h = rem // S
    s = rem % S

    total_sum = tl.zeros((), dtype=tl.float32)
    for i in range(H):
        offs = b * batch_stride + h * qh_stride + s * s_stride + i * d_stride
        x = tl.load(query_ptr + offs)
        x = x.to(tl.float32)
        total_sum += x * x
    tl.store(sum_ptr + pid, total_sum)


# 2) RMSNorm: normalize and apply weight (per-dim)
@triton.jit
def rms_norm_kernel(query_ptr, weight_ptr, out_ptr, sum_ptr,
                     B: tl.constexpr, num_q_heads: tl.constexpr, S: tl.constexpr,
                     H: tl.constexpr,
                     eps: tl.float32,
                     batch_stride, qh_stride, s_stride, d_stride,
                     out_batch_stride, out_qh_stride, out_s_stride, out_d_stride):
    pid = tl.program_id(0)
    total = B * num_q_heads * S
    b = pid // (num_q_heads * S)
    rem = pid % (num_q_heads * S)
    h = rem // S
    s = rem % S

    sum_val = tl.load(sum_ptr + pid)
    mean = sum_val / H
    inv_rms = tl.rsqrt(mean + eps)

    for i in range(H):
        in_offs = b * batch_stride + h * qh_stride + s * s_stride + i * d_stride
        out_offs = b * out_batch_stride + h * out_qh_stride + s * out_s_stride + i * out_d_stride
        x = tl.load(query_ptr + in_offs).to(tl.float32)
        w = tl.load(weight_ptr + i).to(tl.float32)
        y = x * inv_rms * w
        tl.store(out_ptr + out_offs, y)


# 3) Precompute cos/sin for rotation: emb = pos * inv_freq_128, cos/ sin over 128 dims
#    inv_freq_128 is [128] on host; we pass cos_ptr, sin_ptr as 2D [S, 128] buffers.
@triton.jit
def precompute_sin_cos_kernel(inv_freq_128_ptr, cos_ptr, sin_ptr,
                               S: tl.constexpr, H: tl.constexpr,
                               pos_ptr,  # int32 [S]
                               num_warps=4):
    t = tl.program_id(0)  # one program per token
    pos = tl.load(pos_ptr + t).to(tl.float32)
    arange = tl.arange(0, H)
    emb = pos * tl.load(inv_freq_128_ptr + arange)
    c = tl.cos(emb)
    s = tl.sin(emb)
    tl.store(cos_ptr + t * H + arange, c)
    tl.store(sin_ptr + t * H + arange, s)


# 4) Apply rotation: y = x * cos + rotate_half(x) * sin, rotate_half: [-x2, x1]
@triton.jit
def rotate_kernel(x_ptr, cos_ptr, sin_ptr, y_ptr,
                   B: tl.constexpr, num_heads: tl.constexpr, S: tl.constexpr,
                   H: tl.constexpr,
                   batch_stride_x, h_stride_x, s_stride_x, d_stride_x,
                   cos_s_stride, sin_s_stride,  # cos_ptr/sin_ptr are [S, H], strides accordingly
                   out_batch_stride, out_h_stride, out_s_stride, out_d_stride,
                   num_warps=4):
    pid = tl.program_id(0)
    total = B * num_heads * S
    b = pid // (num_heads * S)
    rem = pid % (num_heads * S)
    h = rem // S
    s = rem % S

    arange = tl.arange(0, H)
    cos_t = tl.load(cos_ptr + s * H + arange).to(tl.float32)  # [H]
    sin_t = tl.load(sin_ptr + s * H + arange).to(tl.float32)  # [H]

    x = tl.load(x_ptr + b * batch_stride_x + h * h_stride_x + s * s_stride_x + arange * d_stride_x).to(tl.float32)  # [H]
    x1 = x[:H//2]  # first 64
    x2 = x[H//2:]  # second 64
    rotated = -x2 * sin_t + x1 * cos_t
    y = x * cos_t + rotated * sin_t
    tl.store(y_ptr + b * out_batch_stride + h * out_h_stride + s * out_s_stride + arange * out_d_stride, y)


# 5) Update caches: write key_rotated and value into cache at positions cache_position[s]
@triton.jit
def update_cache_kernel(key_rot_ptr, value_ptr,
                        key_cache_ptr, value_cache_ptr,
                        dest_ptr,  # int64 [S]
                        B: tl.constexpr, num_kv_heads: tl.constexpr, S: tl.constexpr,
                        H: tl.constexpr,
                        batch_stride_kr, h_stride_kr, s_stride_kr, d_stride_kr,
                        batch_stride_v, h_stride_v, s_stride_v, d_stride_v,
                        batch_stride_kc, h_stride_kc, dest_stride, d_stride_kc,
                        batch_stride_vc, h_stride_vc, dest_stride_vc, d_stride_vc,
                        num_warps=4):
    pid0 = tl.program_id(0)  # over B*S
    pid1 = tl.program_id(1)  # over num_kv_heads
    total = B * S
    b = pid0 // S
    s = pid0 % S
    k = pid1

    dest = tl.load(dest_ptr + s).to(tl.int64)

    arange = tl.arange(0, H)
    key_vals = tl.load(key_rot_ptr + b * batch_stride_kr + k * h_stride_kr + s * s_stride_kr + arange * d_stride_kr).to(tl.float32)
    tl.store(key_cache_ptr + b * batch_stride_kc + k * h_stride_kc + dest * dest_stride + arange * d_stride_kc, key_vals)

    vals = tl.load(value_ptr + b * batch_stride_v + k * h_stride_v + s * s_stride_v + arange * d_stride_v).to(tl.float32)
    tl.store(value_cache_ptr + b * batch_stride_vc + k * h_stride_vc + dest * dest_stride_vc + arange * d_stride_vc, vals)
