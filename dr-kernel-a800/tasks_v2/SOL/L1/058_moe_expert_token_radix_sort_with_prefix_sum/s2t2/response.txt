- 实现全局排名 ranks[i] = number of j such that flat[j] < flat[i] plus number of j such that flat[j] == flat[i] and j < i. 这种定义实现了 stable ordering: 相同值时，index 较小的排在前面。

- 我们可以使用以下步骤在 Triton 中计算 ranks：
  1) counts[i] = number of tokens with flat[i] == v. We can compute counts per v for all v in 0..num_experts-1 using a Triton kernel that loops over v and atomic adds for each match. Since num_experts is small (256), this is acceptable.

  3) tie[i] = sum of counts[flat[i]] for all j < i. We can implement a Triton kernel that loops over i and sums counts[flat[i]] for j < i into tie[i].
  4) ranks[i] = less[i] + tie[i]. Then sorted_token_indices[i] = i.

- 有了 ranks，我们就可以重新排列 global token indices by ranks. Triton 不提供高级的 shuffle APIs，但我们可以构造一个 Triton kernel来进行重排：
